This is the first patch in Ævar Arnfjörð Bjarmason’s four-part RFC series aimed at making Git’s `.clang-format` file more closely match the project’s current coding style. The patch adds new Makefile targets (`style-all`, `style-all-diff`, `style-all-diff-ok`, and `style-all-diff-apply`) that allow developers to test `.clang-format` rules across the *entire* codebase—not just the files changed in the working tree, as the existing `style` target does. This is a tooling patch: it doesn’t change any formatting rules yet, but it provides the infrastructure to measure and refine them.

The immediate payoff is visible in the commit message: by tweaking just one `.clang-format` rule (`AlignEscapedNewlines` from `Left` to `DontAlign`), the patch reduces the formatting delta between `clang-format` output and Git’s current style by roughly 1,300 lines (from ~32 k to ~30 k lines of diff). That’s a small but measurable step toward closing the gap, and the new Makefile targets make it easy to test further rule changes. The patch also demonstrates that the delta is not intractable—small tweaks can yield meaningful progress.

This patch is part of the ongoing debate about whether Git should adopt an automatic code formatter. It doesn’t take sides in the `clang-format` vs. pluggable-formatter debate, but it gives both camps a concrete artifact to work with: a `.clang-format` file that can be iteratively improved, and tooling to measure its impact. The patch is clearly marked as RFC and is not intended to be merged as-is; it’s a proof-of-concept for the idea that the formatting gap can be narrowed without requiring major style compromises.

The patch itself is well-structured and self-contained. It adds about 70 lines to the Makefile, all focused on the new `style-all` targets, and changes one line in `.clang-format`. There are no new files, symbols, or on-disk changes, and the patch doesn’t touch any code that would affect Git’s behavior. The commit message is thorough, explaining the motivation, the change, and the measurable impact. This looks like a serious, incremental contribution to the larger discussion.
