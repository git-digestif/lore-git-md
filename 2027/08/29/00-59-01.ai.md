This is the v3 patch in the `defaultBranchName` advice documentation fix series, targeting the advice subsystem. The patch implements the agreed-upon design to recommend globally scoped configuration commands (e.g., `git config --global advice.defaultBranchName false`) instead of repository-local ones when disabling the `defaultBranchName` advice message. The author, Vsevolod Myalitsin, has incorporated all prior feedback: replacing the `global_hint` boolean with a `scope_hint` field in the `advice_setting` struct, passing the entire struct to `vadvise()` for better encapsulation, and using `NULL` for backward compatibility with the existing `advise()` function. The patch touches only `advice.c` and changes no on-disk formats or test coverage.

The architectural direction is now settled, with Junio C Hamano and Jeff King (Peff) agreeing on the `NULL` pointer approach for backward compatibility and confirming the intentional design distinction between `advise()` (used after `advice_is_enabled()` checks to avoid unnecessary work) and `advise_if_enabled()` (used when turn-off instructions are explicitly desired). The only remaining loose end is a minor syntax preference debate between `--global` and `set --global` in the displayed command, but this is not a blocker. The patch is effectively ready for merging once Junio reviews v3.
