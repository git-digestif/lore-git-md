This thread is about a small but useful quality-of-life improvement to Git’s advice system. When Git tells users how to disable an advice message (e.g., `git config --global advice.detachedHead false`), the command will now include the correct config scope (`--global`, `--local`, etc.) instead of always suggesting `--global`. Vsevolod Myalitsin posted the third version of the patch after addressing earlier feedback, and it’s currently under review.

The patch itself is straightforward, touching only `advice.c` and adding a `scope_hint` field to the `advice_setting` struct. Two open questions remain from Jeff King’s review: whether the translatable string with a `%s` placeholder might confuse translators, and whether the patch should reuse Git’s existing `CONFIG_SCOPE` enum instead of defining a new one. Junio C Hamano recently reviewed the patch and suggested minor mechanical improvements—better commit message clarity, standard indentation, and documenting an interface change—along with a structural suggestion to split the patch into three parts. No decisions have been made yet, and the series hasn’t been queued for integration. The discussion is still focused on presentation rather than substance, so the next step is likely a v4 incorporating Junio’s feedback.
