This thread is about adding a scope hint to Git’s advice messages—telling users how to disable them (e.g., `git config --global advice.detachedHead false`). The series has evolved through several iterations, with the latest development being a maintainer-proposed patch that simplifies the design to always recommend `--global` for *all* `advice.*` settings.

Vsevolod Myalitsyn initially proposed a three-patch v4 series, but Junio C Hamano has now posted a single-patch v5 that replaces it. This patch eliminates the earlier `is_global_hint` field entirely, adopting a uniform `--global` hint for every advice setting. The rationale is that advice messages are about silencing chatter for a *user*, not a specific repository, so `--global` is the most appropriate scope. Junio and Jeff King (Peff) both endorsed this approach, resolving the thread’s central design debate. The patch updates `advice.c` and twelve test scripts to reflect the new wording, with no new fields or enums introduced.

The series is now effectively complete, with the implementation being minimal and mechanical. The next step is for reviewers to verify the test updates and confirm the string change. If no further objections arise, this patch is likely to be merged as-is. The thread’s loose ends—such as Vsevolod’s response to the consensus and the resolution of a tangential documentation patch—are now secondary to the core implementation.
