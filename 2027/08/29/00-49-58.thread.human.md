This thread is about a patch series by Vsevolod Myalitsin that adds a `scope_hint` field to Git’s advice settings, ensuring that users receive accurate configuration scope hints (e.g., `--global`, `--local`) when disabling advice messages. The series is now at v3, with a v4 reroll planned to address feedback from Junio and Peff.

The key discussion points remain the same: whether to reuse Git’s existing `CONFIG_SCOPE` enum or define a new `ADVICE_SCOPE` enum (with a minor edge case around the `UNKNOWN` default), and how to structure the translatable string for clarity. Junio suggested splitting the patch into three parts (API change, scope mechanism, and default-branch-name scope assignment) for better readability, and Vsevolod has agreed to this restructuring while seeking clarification on whether each patch should have its own subject line. Additionally, the author will address mechanical issues like commit message motivation, interface documentation, and indentation fixes.

The series is still under active review, with no new technical objections raised in the latest exchange. Peff’s feedback on enum reuse and translation clarity remains unresolved but is not blocking the reroll. The next step is the v4 submission, after which Junio will likely re-evaluate the series for inclusion.
