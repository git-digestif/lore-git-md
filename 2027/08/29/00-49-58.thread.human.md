This thread is about a patch series by Vsevolod Myalitsin that improves Git's advice messages by adding a `scope_hint` field, ensuring users are told the correct configuration scope (e.g., `--global`, `--local`) when disabling advice. The series is now preparing its fourth version (v4) to address mechanical feedback from Junio Hamano and adopt a clearer three-part structure: one patch for the API change, one for the scope mechanism, and one for assigning the global scope to the `defaultBranchName` advice.

The latest email covers the third patch in the series, which assigns the `ADVICE_SCOPE_GLOBAL` hint to the `defaultBranchName` advice. This change is straightforward and uncontroversial, reflecting the fact that the default branch name is a global configuration. The patch follows the series' established pattern and doesn't introduce new technical questions. The only unresolved issue from Jeff King's review—whether to reuse the existing `CONFIG_SCOPE` enum or define a new `ADVICE_SCOPE`—is unrelated to this patch and will be addressed in the API-change patch. Junio's feedback on patch organization has already been incorporated, with each patch now having its own subject line and commit message. The series remains under review, with no indication of merger yet.
