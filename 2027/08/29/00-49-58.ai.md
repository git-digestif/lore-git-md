This is the third patch in Vsevolod Myalitsin’s four-patch series that adds a `scope_hint` field to Git’s advice settings. The series is preparing a v4 reroll to address Junio’s mechanical feedback and adopt a clearer three-part split.

This patch assigns the `ADVICE_SCOPE_GLOBAL` hint to the `defaultBranchName` advice. The change is minimal: one line in the `advice_setting[]` array (`[ADVICE_DEFAULT_BRANCH_NAME] = { "defaultBranchName", ADVICE_SCOPE_GLOBAL }`). No other advice settings are touched, and the rest of the patch is just the plumbing that the earlier patches already introduced. The commit message explains the rationale: the default branch name is a global configuration, so the advice message should suggest disabling it with `--global`.

The patch is well-scoped and uncontroversial. It follows the series’ established pattern and does not introduce new technical questions. The only remaining open question from Peff’s review—whether to reuse the existing `CONFIG_SCOPE` enum or define a new `ADVICE_SCOPE`—is orthogonal to this patch and will be resolved in the API-change patch. Junio’s guidance on the three-part split is already reflected here: this patch has its own distinct subject line and commit message, focusing solely on the default-branch-name scope assignment.
