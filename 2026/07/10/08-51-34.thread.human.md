This thread is about Christian Couder’s five-patch series (v5) replacing the earlier `GIT_NO_LAZY_FETCH=fromAccepted` proposal with `uploadpack.lazyFetchTrusted`, a server-side configuration variable that lets operators mark repositories as trusted for lazy fetching. The goal is to address security concerns about untrusted repositories triggering arbitrary code execution via lazy-fetch hooks or configuration, shifting trust decisions entirely to the server operator.
