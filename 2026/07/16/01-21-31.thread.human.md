This is the eighth iteration of a Google Summer of Code patch series that adds seven new path-related keys to `git repo info`, exposing filesystem locations of repository components (hooks directory, index file, superproject root, and relative paths between the top-level working tree and current directory). The series is now mechanically complete, design-resolved, and ready for final review after addressing all prior feedback, including a critical correctness bug in `get_superproject_working_tree()` and the controversial `path.grafts` keys (dropped in this version).

All patches are uncontroversial and technically sound. The fifth patch in this series adds `path.index.absolute` and `path.index.relative`, providing a scriptable interface to the index file location that aligns with `git rev-parse --git-path` behavior. While the implementation retains a latent `BUG()` invocation in `repo_get_index_file()`, this is consistent with Git’s current behavior and not a blocker. The series has received thorough review from Junio C Hamano, Justin Tobler, and others, but Junio has warned it may be dropped from the integration branch unless additional reviewers engage soon. The only remaining open question is whether to refactor shared logic into a new helper library post-merge, but this is now contingent on the series progressing.
