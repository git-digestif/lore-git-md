This thread is about teaching `git history` to sign rewritten commits (for `drop`, `fixup`, `reword`, `split`, and `squash`) using the same GPG-signing configuration and command-line options already supported by other Git commands. The series, authored by Souma, has reached its fifth version after addressing all substantive review feedback from Patrick Steinhardt and Junio C Hamano.

The feature is now ready to move forward: Junio has explicitly marked the series as "ready for 'next'" after the completion fix resolved the last regression found during integration testing in `seen`. The implementation touches the `git history` command, replay API, documentation, and test suite, ensuring all five subcommands respect `commit.gpgsign` and the `-S/--gpg-sign` options. While there remains an unresolved conceptual question about whether signing rewritten commits is desirable, the technical work is complete and unblocked. The series is expected to graduate to `next` shortly.
