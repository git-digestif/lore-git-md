This thread is about teaching `git history` to sign rewritten commits (`drop`, `fixup`, `reword`, `split`) using the same GPG configuration (`commit.gpgsign`) and command-line options (`-S/--gpg-sign`, `--no-gpg-sign`) as `git commit`. The series, now at version 3, has addressed all substantive review feedback from Patrick Steinhardt, who has signaled it is ready for integration.

The only remaining blocker was a procedural question from Junio C Hamano about whether "Souma" is a real name under the Developer Certificate of Origin (DCO). Souma has now confirmed that it is their legal first name, clearing the way for Junio to queue the series in `next`. No code changes are needed. The series touches `builtin/history.c`, `replay.c`, and related documentation and test files, adding GPG signing support for rewritten commits while preserving the existing configuration and command-line behavior. The conceptual question of whether signing others' commits is desirable remains unresolved but is not a blocker for integration.
