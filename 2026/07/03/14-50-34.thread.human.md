This thread is about teaching `git history` to sign rewritten commits (for subcommands like `drop`, `fixup`, `reword`, `split`, and `squash`) using the same GPG-signing configuration and command-line options already supported by other Git commands. The series, now at version 5, was authored by Souma and has been cooking in Junio C Hamano’s `seen` branch for integration testing.

The core implementation is complete, with all five subcommands respecting `commit.gpgsign`, `-S/--gpg-sign`, and `--no-gpg-sign`, and the plumbing has been split into a preparatory patch for clarity. The series touched `builtin/history.c`, `replay.c`, and related documentation and test files, adding test coverage for all flag/config combinations and fixing a completion regression in `t9902-completion.sh`. The only unresolved discussion point is a conceptual trade-off: whether signing rewritten commits (which may have different authorship) is desirable or potentially misleading—this is documented but not settled.

All substantive feedback from Patrick Steinhardt and Junio has been addressed. Patrick’s early reviews focused on mechanical cleanups and the conceptual trade-off, while Junio raised a procedural DCO question and later clarified the completion test behavior, confirming the literal `...` placeholder is correct. The series is now unblocked and ready to graduate to `next`.
