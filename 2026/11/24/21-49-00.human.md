This is a documentation patch -- the fourth and final one in a four-patch series from Jean-Noël Avila converting the `git-fast-export` man page to the standard AsciiDoc synopsis style. It is part of his ongoing project-wide effort to give every Git man page a consistent synopsis format.

The patch touches only `Documentation/git-fast-export.adoc` and makes purely cosmetic changes: the `[verse]` block becomes `[synopsis]`, single-quoted command names and options are converted to backtick-quoted style (`` `git fast-export` ``, `` `--progress=<n>` ``), placeholders are normalized to `_<placeholder>_` form, and inline value lists for options like `--signed-tags` and `--reencode` are restructured into definition lists with `;;` separators. There are no substantive content changes -- just formatting standardization to match the style being applied across the rest of the documentation.

The patch looks clean and follows the same pattern as the previous three patches in the series, which converted `git-svn.adoc` and `git-fast-import.adoc` and extracted the `svn.*` configuration documentation into a shared include file. Together the series is under review with no feedback recorded yet.
