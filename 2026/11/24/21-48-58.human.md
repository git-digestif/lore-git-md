This is a documentation patch, specifically the second in a four-patch series from Jean-Noël Avila that continues his project-wide effort to standardize Git's man pages. While the series overall converts `git-svn`, `git-fast-import`, and `git-fast-export` to a consistent AsciiDoc synopsis style, this particular patch addresses a structural gap: the `svn.*` configuration options were documented only in the `git-svn` man page and were missing from the main `git-config` documentation.

The patch extracts all the Subversion-related configuration documentation -- 175 lines covering keys like `svn.noMetadata`, `svn-remote.<name>.pushurl`, `svn.brokenSymlinkWorkaround`, and `svn.pathnameencoding` -- from `Documentation/git-svn.adoc` into a new dedicated file, `Documentation/config/svn.adoc`. It then adds an include directive to `Documentation/config.adoc` so these options now appear in the `git-config` man page alongside all other configuration keys, and replaces the original text in `git-svn.adoc` with an include of the same new file. This keeps the documentation DRY while making the options discoverable from both contexts.

The commit message is brief but clear about the motivation: git-svn's configuration options were not being treated like other options in the documentation. This is a well-crafted, low-risk change that follows the recurring pattern in Avila's conversion work of moving config documentation into `Documentation/config/*.adoc` files. The patch is purely structural -- no wording of the actual option descriptions changes, only their location. It looks like a solid, uncontroversial improvement that fits cleanly into the larger series.
