This is a documentation patch, the third in a four-part series from Jean-Noël Avila that converts the `git-fast-import` man page to AsciiDoc synopsis style as part of his ongoing project-wide standardization of all Git man pages.

The patch touches two files: `Documentation/git-fast-import.adoc` and `Documentation/config/fastimport.adoc`. In the main man page, the SYNOPSIS section changes from a `[verse]` block with single-quoted command names to a `[synopsis]` block with backtick-quoted names (e.g., `` `git fast-import` [<options>] ``). All command-line options are converted from `--option::` to the backtick-quoted `` `--option`:: `` form, and placeholder terms like `<fd>` or `<path>` are normalized to the `_<placeholder>_` style throughout the prose and command grammar sections. The `--signed-commits=<mode>` description is restructured from a bulleted list into a definition list using `;;` separators. Minor prose tightening occurs in several sections including PARALLEL OPERATION and the Date Formats documentation. In `Documentation/config/fastimport.adoc`, the single entry `fastimport.unpackLimit` is similarly converted from `fastimport.unpackLimit::` to `` `fastimport.unpackLimit`:: ``.

This patch follows patch 2/4 in the series, which extracted the `svn.*` configuration documentation into a new `Documentation/config/svn.adoc` file, and precedes patch 4/4, which is expected to apply the same conversion to `git-fast-export.adoc`. The series as a whole covers three command man pages (`git-svn.adoc`, `git-fast-import.adoc`, `git-fast-export.adoc`) plus the shared config include files. The changes are purely cosmetic and structural with no behavioral modifications; the net diff is 194 insertions and 189 deletions across the two files. The series is currently under review with no recorded feedback or integration branch status.
