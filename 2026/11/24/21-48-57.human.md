This is a documentation patch, specifically the first of four in a series converting Git man pages to the standardized AsciiDoc synopsis style. It rewrites `Documentation/git-svn.adoc` to replace the `[verse]` block with `[synopsis]`, switches command names and flags from single-quote formatting to backticks, and normalizes placeholder syntax throughout. The diff is large -- 491 insertions and 488 deletions -- but almost entirely mechanical, cleaning up the presentation without changing the substance of the documentation.

The patch continues Jean-Noël Avila's long-running project to give every Git man page a consistent synopsis format. As noted in the cover letter for this series, the goal is to standardize `git-svn`, `git-fast-import`, and `git-fast-export`, with the fourth patch handling missing `svn.*` config options. This particular commit focuses solely on the `git-svn` command page, touching roughly a thousand lines of AsciiDoc to align it with the project's documentation conventions.

The work is well-crafted and thorough. The conversion follows the established pattern of replacing loose quoting with proper inline code formatting and tightening the prose descriptions. Since this is a formatting-only change, there is little risk of controversy, though the sheer size of the diff reflects how deeply the old style had penetrated the page. It is currently under review as part of the v1 series.
