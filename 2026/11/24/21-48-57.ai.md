Documentation patch, first of a four-patch series converting man pages to AsciiDoc synopsis style.

This is `[PATCH 1/4]` from Jean-Noël Avila, applying the standardized synopsis conversion to `Documentation/git-svn.adoc` alone (491 insertions, 488 deletions). The changes are purely cosmetic: `[verse]` blocks become `[synopsis]`, single-quoted command names like `'git svn'` are converted to backtick-quoted `` `git svn` ``, all flags and options are backtick-quoted (e.g., `'--stdlayout'` becomes `` `--stdlayout` ``), and placeholder terms are normalized to `_<placeholder>_` form. Literal block delimiters are shortened from 73 to 71 dashes, and some prose is tightened (e.g., "This allows one to specify" becomes "Specify").

The patch touches every major section of the page -- COMMANDS (`init`, `fetch`, `clone`, `rebase`, `dcommit`, `branch`, `tag`, `log`, `blame`, `find-rev`, `set-tree`, etc.), OPTIONS, ADVANCED OPTIONS, CONFIG FILE-ONLY OPTIONS, BASIC EXAMPLES, and CAVEATS -- but introduces no behavioral or structural changes to the documentation content itself. Key config keys referenced throughout include `svn.noMetadata`, `svn.useSvmProps`, `svn.useSvnsyncProps`, `svn-remote.<name>.rewriteRoot`, `svn-remote.<name>.rewriteUUID`, `svn-remote.<name>.pushurl`, `svn.brokenSymlinkWorkaround`, `svn.pathnameencoding`, and `svn-remote.<name>.automkdirs`.

This continues Jean-Noël Avila's long-running project-wide effort to give every Git man page a consistent synopsis section. The cover letter for the series indicates that patches 2/4 and 3/4 apply the identical conversion to `Documentation/git-fast-import.adoc` and `Documentation/git-fast-export.adoc`, while patch 4/4 extracts the `svn.*` configuration documentation into a new `Documentation/config/svn.adoc` file included from both `git-svn.adoc` and `Documentation/config.adoc`. Reviewers should note that this specific patch only reformats the existing `git-svn` page; the config extraction is handled separately in the final patch of the series.
