This is a **bugfix cover letter** for a three-patch series that fixes a data-loss race in `git repack -d`. The author, Qin ShiCheng, describes a production incident on Git 2.43 where a concurrent push dropped a `.keep` file onto a pack after `repack` had already decided to delete it but before `pack-objects` scanned the repository, leaving a dangling ref pointing at a missing commit. The v5 iteration is purely a rebase onto current `master` to resolve a test-file conflict; the substantive work happened in v4.

The fix replaces the old `--honor-pack-keep` mechanism with an explicit snapshot. Instead of letting `pack-objects` rescan for `.keep` files at runtime, `repack` now writes the list of packs it intends to delete to a file and passes it via a new `--ignore-pack-keep-from=<file>` option, instructing `pack-objects` to treat those specific packs as if they had no `.keep` file. This closes the timing window where a newly appeared `.keep` could cause objects to be skipped during packing yet still have their pack deleted.

The series is well-reviewed and ready for integration. Patch 1/3 fixes a latent bug in the cruft-pack walk where a stale kept-pack cache could hide objects reachable through alternates or `--keep-pack` packs; Jeff King provided a Reviewed-by for this. Patch 2/3 introduces the `--ignore-pack-keep-from` plumbing with tests proving it behaves identically to `--keep-pack` for exclusion purposes. Patch 3/3 wires `repack` to generate the snapshot and pass it through, with Taylor Blau's Reviewed-by confirming the approach; tests in `t7703-repack-geometric.sh` reproduce the original race across `-a -d`, `-A -d`, `-k`, `--cruft`, and `--geometric` modes.

One trade-off is noted: fixing the cruft walk now requires traversing alternate object stores, which in a `clone --shared` of git.git slowed the walk from roughly 2ms to 3.3s. The author frames this as an intentional safety-over-speed choice that matches what `master` already does when a `.keep` file is present. The series touches `builtin/pack-objects.c`, `builtin/repack.c`, `packfile.c`, and related headers, and is based on current `master` with no remaining external dependencies.
