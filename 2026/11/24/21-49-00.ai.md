This is the final patch (4/4) in a documentation series from Jean-Noël Avila converting the `git-fast-export` man page to the standard AsciiDoc synopsis style. It is part of the ongoing project-wide effort to give every Git man page a consistent synopsis section, and it completes the four-patch set that also covered `git-svn`, `git-fast-import`, and the extraction of `svn.*` and `fastimport.*` configuration into shared include files under `Documentation/config/`.

The patch touches only `Documentation/git-fast-export.adoc` (98 insertions, 95 deletions) and applies the same mechanical conversions seen in the earlier patches of the series: the SYNOPSIS block changes from `[verse]` with single-quoted command names to `[synopsis]` with backtick-quoted `git fast-export`, all option definitions switch from `--option::` to `` `--option`:: ``, placeholders like `<file>` become `_<file>_`, and inline enumerations of option values (such as those for `--signed-tags`, `--signed-commits`, `--tag-of-filtered-object`, and `--reencode`) are restructured into definition lists using `;;` separators. Literal block delimiters are shortened from 73 to 71 dashes, and command references in prose are converted from single quotes to backticks.

For future thread summaries: the key file modified here is `Documentation/git-fast-export.adoc`; the series as a whole also created `Documentation/config/svn.adoc` and modified `Documentation/config.adoc`, `Documentation/config/fastimport.adoc`, `Documentation/git-svn.adoc`, and `Documentation/git-fast-import.adoc`. The substantive structural change beyond formatting was the relocation of `svn.*` configuration documentation into `config/svn.adoc` so it is included from both `git-svn.adoc` and the main `git-config` page.

The series is v1 and under review with no integration branch status mentioned yet. It is a routine, well-formed documentation cleanup with no behavioral impact; no review feedback or controversy has been recorded at this point.
