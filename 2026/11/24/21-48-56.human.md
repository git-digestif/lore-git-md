This is a documentation cover letter for a four-patch series converting three man pages to synopsis style, part of Jean-Noël Avila's ongoing effort to standardize Git's AsciiDoc documentation format.

The series converts `git-svn`, `git-fast-import`, and `git-fast-export` to use the consistent synopsis style that Jean-Noël Avila has been driving across the `Documentation/` directory. Beyond the formatting changes, the series extracts the `git-svn` configuration documentation from the main man page into a dedicated `Documentation/config/svn.adoc` file, which is then included in `git-config` as well, following the same pattern used for other config sections.

This is routine but valuable housekeeping work. The patches are large in line count -- touching nearly a thousand lines in the `git-svn` page alone -- but the changes are mechanical restructuring rather than substantive content edits. The commit messages and cover letter are clear about what is being done, and the separation of config into its own file improves navigability for users looking up configuration options.

As the context notes, Jean-Noël Avila is the primary driver of this synopsis-style conversion effort, and this series represents continued progress on that front. The work is under review; there is no indication yet of merge status.
