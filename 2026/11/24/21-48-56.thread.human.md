This thread is a four-patch documentation series from Jean-Noël Avila that converts the `git-svn`, `git-fast-import`, and `git-fast-export` man pages to the standardized AsciiDoc synopsis style, continuing his long-running effort to give every Git man page a consistent synopsis section. One patch per command page handles the reformatting (roughly 917 insertions and 814 deletions overall), and a fourth patch adds missing configuration options to `git-svn`.

The substantive structural change is that the Subversion configuration documentation is extracted from `git-svn.adoc` into a new dedicated file, `Documentation/config/svn.adoc` (175 lines of `svn.*` config keys), which is then included from both `git-svn.adoc` and the main `Documentation/config.adoc`. This makes the `svn.*` options discoverable from the `git-config` man page as well as the command page -- a recurring pattern in these conversions. `Documentation/config/fastimport.adoc` also gets a minor synopsis adjustment.
