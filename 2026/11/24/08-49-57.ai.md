This is a feature patch for the `contrib/diff-highlight` Perl helper that adds support for `git range-diff` output. The tool previously passed range-diff lines through unhighlighted because it did not recognize the commit-pair headers (such as `1:  abc1234 ! 1:  def5678`) that introduce each diff-of-diffs, nor the four-column indentation and dual markers (outer and inner) that characterize those lines.

The patch modifies `contrib/diff-highlight/DiffHighlight.pm` to detect the range-diff commit-pair header and strip the following four-column indent in the same way it handles a `--graph` prefix. It relaxes the hunk-header regex to tolerate ANSI color codes between `@@` and the trailing space, and updates `is_pair_interesting()` so that either the outer or the inner marker can qualify a line as part of a removed/added pair. A new `show_inner()` routine handles the case where lines share the same outer marker but form a removed/added pair in the inner diff -- for example pairing `+-old` with `++new` -- and is invoked as a fallback when the outer hunk cannot be matched line-for-line.

All new logic is guarded by a `$range_diff` state variable that is set only when the commit-pair header is seen, so plain diffs and graph output behave exactly as before. The patch adds three tests to `contrib/diff-highlight/t/t9400-diff-highlight.sh` covering cross-version highlighting, within-version highlighting, and colored range-diff input. The commit message clearly enumerates the four behavioral changes and confirms that non-range-diff input is unaffected; the tests appear thorough, making this a well-scoped contribution to a contrib tool currently under review.
