This is **patch 2/4** in Jean-Noël Avila's four-part documentation series, and it is the substantive structural change of the set: extracting all `git-svn` configuration option documentation out of the command man page and into a dedicated config file so it can be shared with the main `git-config` man page. The patch creates a new file `Documentation/config/svn.adoc` containing 175 lines of `svn.*` and `svn-remote.<name>.*` config key definitions, adds an `include::config/svn.adoc[]` directive to `Documentation/config.adoc` (placing the options in alphabetical order between `submodule.adoc` and `tag.adoc`), and replaces the inline "CONFIG FILE-ONLY OPTIONS" section in `Documentation/git-svn.adoc` with an `include::config/svn.adoc[]` line, removing 87 lines from that file.

The config keys relocated include `svn.noMetadata`, `svn.useSvmProps`, `svn.useSvnsyncProps`, `svn-remote.<name>.rewriteRoot`, `svn-remote.<name>.rewriteUUID`, `svn-remote.<name>.pushurl`, `svn.brokenSymlinkWorkaround`, `svn.pathnameencoding`, `svn-remote.<name>.automkdirs`, `svn.addAuthorFrom`, `svn.authorsfile`, `svn.authorsProg`, `svn.edit`, `svn.findcopiesharder`/`svn.l`, `svn.followparent`, `svn.pushmergeinfo`, `svn.rmdir`, `svn.useLogAuthor`, `svn-remote.<name>.commiturl`/`svn.commiturl`, `svn-remote.<name>.ignore-paths`, `svn-remote.<name>.ignore-refs`, and `svn-remote.<name>.include-paths`. The net diff is 178 insertions and 86 deletions across the three files. The commit message states the motivation plainly: the `git-svn` config options were not treated like other config options because they were neither listed in `config.adoc` nor documented in a dedicated file.

This patch continues Jean-Noël Avila's long-running project-wide effort to standardize man page synopsis styles and to split per-command config documentation into `Documentation/config/*.adoc` includes. The pattern ensures that `svn.*` options now appear both in the `git-svn` man page and in `git-config`, making them discoverable from the main configuration reference. Patches 1/4, 3/4, and 4/4 of this series handle the synopsis-style conversion of `git-svn.adoc`, `git-fast-import.adoc`, and `git-fast-export.adoc` respectively; this patch (2/4) is the one that moves the actual content.
