This is a documentation patch -- specifically the third of four in Jean-Noël Avila's series converting the `git-svn`, `git-fast-import`, and `git-fast-export` man pages to a consistent AsciiDoc synopsis style. The bulk of the change rewrites `Documentation/git-fast-import.adoc` (381 lines touched) to replace `[verse]` blocks with `[synopsis]`, convert single-quoted command names and flags to backtick-quoted form (`` `--force` `` instead of `'--force'`), and normalize placeholder variables from `<path>` to `_<path>_` throughout the extensive sections describing the fast-import stream protocol, date formats, and command syntax.

The patch also makes a small companion fix to `Documentation/config/fastimport.adoc`, changing the `fastimport.unpackLimit::` config key definition to `` `fastimport.unpackLimit`:: `` so it matches the backtick style used elsewhere in the config documentation. The net diff is 194 insertions and 189 deletions across the two files, confirming this is purely mechanical formatting with no substantive content changes.

As patch 3/4, this follows the `git-svn` synopsis conversion and the extraction of `svn.*` config documentation into a shared include file (patches 1 and 2) and precedes the `git-fast-export` conversion in patch 4. It continues Jean-Noël Avila's long-running project-wide effort to standardize synopsis sections across all Git man pages. The patch looks clean and well-formed -- typical of this recurring series of mechanical doc conversions -- and touches only files under `Documentation/`, so it carries no risk to runtime behavior.
