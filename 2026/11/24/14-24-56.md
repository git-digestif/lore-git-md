> ```
>     $ git branch --dry-run test v1.5.0

>     fatal: would fail to rename a non-existent branch 'foo'
>     $ git branch --dry-run -m foo bar
>     fatal: would avoid clobbering existing branch 'bar' by renaming
> ```
>
