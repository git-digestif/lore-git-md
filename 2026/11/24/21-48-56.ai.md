This is a documentation cover letter for a four-patch series converting three man pages to AsciiDoc synopsis style, part of Jean-Noël Avila's ongoing effort to standardize all Git man pages.

The series converts `git-svn.adoc`, `git-fast-import.adoc`, and `git-fast-export.adoc` to the synopsis style, with individual patches for each conversion plus a separate patch adding missing config options to `git-svn`. Beyond the formatting changes, the series extracts the Subversion configuration documentation from the `git-svn` page into a new dedicated file `Documentation/config/svn.adoc`, which is then included from both `git-svn.adoc` and `Documentation/config.adoc` so that the config options appear in the main `git-config` man page as well.

The technical scope touches six files: the three command man pages themselves undergo substantial reformatting (roughly 917 insertions and 814 deletions across the series), `Documentation/config/fastimport.adoc` gets a minor synopsis adjustment, and `Documentation/config.adoc` gains an include directive. The new `Documentation/config/svn.adoc` file carries 175 lines of moved content documenting `svn.*` configuration keys.

This work continues the long-running documentation synopsis-style conversion effort led by Jean-Noël Avila, which aims to give every Git man page a consistent synopsis section. The config extraction pattern seen here -- moving config docs to `Documentation/config/*.adoc` and including them from both the command page and `git-config` -- is a recurring structural improvement in these conversions, ensuring that configuration options are discoverable from both contexts.

For future thread summaries: the key files are `Documentation/git-svn.adoc`, `Documentation/git-fast-import.adoc`, `Documentation/git-fast-export.adoc`, `Documentation/config/svn.adoc` (new), `Documentation/config/fastimport.adoc`, and `Documentation/config.adoc`. The substantive change beyond formatting is the relocation of `svn.*` config documentation into `config/svn.adoc` for inclusion in `git-config`.
