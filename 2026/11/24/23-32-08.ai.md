This is a feature patch cover letter for the fourth iteration of Erik Cervin-Edin's series enabling all message specification options (`-m`, `-F`, `-c`, `-C`) across all `--fixup` variants (plain `--fixup`, `--fixup=amend:`, and `--fixup=reword:`). The v4 reroll restructures the series into three patches: patch 1/3 refactors `prepare_to_commit()` in `builtin/commit.c` to write the `--fixup` subject line up front in a block before the message-source chain -- mirroring how `--squash` already behaves -- which eliminates the need for `!fixup_message` guards on the `-m` and `-F` arms; patch 2/3 enables `-m`/`-F` for all variants; patch 3/3 enables `-c`/`-C` using `prepare_amend_commit()` (which strips "amend!" lines from source commits). Tests in `t/t7500-commit-template-squash-signoff.sh` now use `GIT_EDITOR=false` for the `-C` case and `GIT_EDITOR="echo edited >>"` for the `-c` case to address Phillip Wood's final test hygiene feedback from v3. The series touches only `builtin/commit.c`, `Documentation/git-commit.adoc`, and the test suite, preserving backward compatibility where an editor launches when no message option is given. All substantive design feedback from earlier rounds has been addressed; this v4 is awaiting final review.
