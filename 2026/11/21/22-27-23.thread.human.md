brian m. carlson has sent a documentation-only patch warning users not to use the `http.extraheader` configuration for authentication credentials. The change touches three files -- `Documentation/config/http.adoc`, `Documentation/git.adoc`, and `Documentation/gitfaq.adoc` -- adding notes that passing credentials via `http.extraheader` can expose them to every server Git contacts (or to other local users when set globally), and that setting an `Authorization` header this way can break external tools like Git LFS by producing duplicate headers. The patch recommends credential helpers as the secure alternative, since they support modern methods like Bearer tokens and are only invoked by such tools when credentials are absent. No code or tests are modified, and the series is currently under review with no maintainer decision recorded yet.
