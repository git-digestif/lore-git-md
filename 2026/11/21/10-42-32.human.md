This is a cover letter for a two-patch bugfix series targeting `combine-diff.c`, the machinery behind combined diffs for merge commits. Aniket Gupta addresses a bug reported by Sami Jawhar where `git log --cc` and friends produce garbled output for merges with more than 32 parents: lines appear in the wrong columns, and with 64 parents no hunks show at all.

The first patch fixes the root cause, an integer shift that overflowed when setting the bit for the 33rd parent and beyond, causing those parents' bits to collide with others. The second patch handles the even larger case of merges with more than 62 parents (or 30 on Windows, where `long` is 32 bits), which still exceeds what the bitmask can represent. Instead of printing incorrect output, Git now prints an error and skips the patch for that commit but continues processing the rest of the log rather than dying.

The series is based on `maint` since the bug is longstanding, and it includes new tests in `t/t4038-diff-combined.sh`. The author notes that CI passes on Linux, macOS, and Windows, with the high-parent-count tests appropriately skipped on Windows due to the narrower `long` type.
