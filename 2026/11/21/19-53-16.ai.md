This is the first patch of a two-patch refactoring series (v3 1/2) targeting `builtin/reflog.c`, part of Laveesh Bansal's effort to consolidate `git reflog expire` processing into a single loop. The patch is a pure mechanical refactoring with no behavior change; it merges the previously separate code paths for `--all` (worktree reflogs) and explicitly named command-line refs into one unified `for_each_string_list_item` loop.

The implementation collects all reflogs into a single `collected.reflogs` string_list before processing. Worktree reflogs gathered via `collect_reflog` during the `--all` scan are appended first, followed by command-line arguments. Each command-line entry is marked with `item->util = (void *)1` to flag that it still requires resolution through `repo_dwim_log` (necessary for dynamic refs like `@{-1}`), while `--all` entries use their already-resolved names directly. The single loop then iterates this combined list, performing the `repo_dwim_log` lookup only when `item->util` is set, and calls `refs_reflog_expire` exactly once per reflog with the same callback setup (`reflog_expiry_prepare`, `should_prune_fn`, `reflog_expiry_cleanup`) for every entry.

Within the broader thread, this patch remains identical to v2 and serves as the foundation for patch 2, which adds `strset`-based deduplication so that a ref appearing both via `--all` and as a command-line argument is expired only once. The v3 iteration specifically addressed Patrick Steinhardt's performance concerns about the deduplication mechanism in patch 2 (switching from a sorted `string_list` to a `strset` for O(1) lookups while preserving output order), but patch 1 itself introduces no new symbols beyond the relocated `collected` structure and maintains identical output, exit status, and error reporting to the previous two-loop version. The series is under review with endorsements from Junio C Hamano and Patrick Steinhardt, and the author reports the full test suite passing including reftable, SHA-256, and leak-sanitized configurations.
