This is a trivial contributor-housekeeping patch from Ophir Bleicher (sent via GitGitGadget as PR #2498) that touches a single comment in `git-gui/git-gui.sh`, the startup script for the Tcl-based Git GUI. Inside the loop that normalizes and deduplicates `$env(PATH)` entries using the `_path_seen` dictionary, the patch changes the misspelled word "occurence" to "occurance" -- which is itself still a misspelling of the correct "occurrence", so the fix swaps one typo for another. The change is purely cosmetic with no functional impact on Git, introduces no new code or tests, and carries no indication of merge status. There is nothing contested or open here; any replies will almost certainly be limited to pointing out that the replacement word is also wrong.
