This is a preparatory refactoring patch within Harald Nordgren's v10 series that adds `git branch --delete-integrated`. It modifies `delete_branches()` in `builtin/branch.c` to accept an optional `struct strmap *landed_commits` mapping branch names to the upstream commit where their changes landed. When a branch appears in this map, the function skips the usual merge-base reachability check and instead reports output like `Deleted branch topic (was 1a2b3c4, landed as 9f8e7d6).`

The patch also flattens the deletion message logic into a static `msg_templates[2][3]` array indexed by dry-run state, replacing the previous nested conditionals. No caller passes the map yet, so there is no behavior change in this commit; it simply lays the groundwork for patches 3/5 through 5/5, which will populate the map when detecting squash-merged or rebased branches. The change looks clean and directly addresses Junio's earlier suggestion to simplify the message selection, setting up the series to report precise "landed as" attribution once the detection machinery is wired in.
