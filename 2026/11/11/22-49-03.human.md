This is a bugfix patch, part 3 of a 15-patch series that systematically eliminates Git segfaults when config settings are given without values. The series is effectively approved for merge, with only test conflicts remaining to be resolved.

This specific patch fixes a crash in `git add -p` (and other interactive patch modes) when a color slot like `color.interactive.prompt` or `color.diff.frag` is set without a value. The current code passes the NULL value to `color_parse()`, causing a segfault. The fix replaces `repo_config_get_value()` with `repo_config_get_string_tmp()`, which rejects missing values with `config_error_nonbool()`, matching the behavior already used for diff colors in `git diff`.

The change is minimal and targeted: a one-line code modification in `add-patch.c` and a new test in `t/t3701-add-interactive.sh` that verifies the error message when `color.interactive.prompt` lacks a value. The test is straightforward, using `test_must_fail` and `test_grep` to confirm the expected error.
