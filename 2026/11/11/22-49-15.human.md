This is the final patch in Thomas Bachem’s 15-part bugfix series that eliminates Git segfaults when config keys are given without values. Patch 15/15 fixes a regression introduced in Git 2.54.0 (commits 2d4ab5a885 and 9cb4a5e1ba) where `git config list --type=color` and `--type=expiry-date` would crash when encountering a valueless key.

The fix is minimal and targeted: it adds a NULL check in `format_config_color()` and `format_config_expiry_date()` so that valueless keys are skipped quietly, matching the existing behavior for unparseable values and for `--type=int`. The change is uncontroversial and aligns with the rest of the series’ philosophy of graceful handling rather than rejection. A new test in `t/t1300-config.sh` verifies that the commands no longer crash and omit the malformed key from the output.

This patch is effectively a cherry on top of an already well-reviewed series. The regression it fixes is recent, the fix is straightforward, and the test coverage is adequate. No further discussion or objections are expected. The only remaining blocker for the entire series is resolving test conflicts with two topics in `seen`.
