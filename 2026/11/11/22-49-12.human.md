This is the twelfth patch in the v3 series fixing Git segfaults when config keys are given without values. It targets the `scalar` subsystem, specifically the `scalar reconfigure --all` command, which crashes when `scalar.repo` is set without a value. The crash occurs because `get_scalar_repos()` passes the NULL value to `string_list_append()`, which then tries to copy it with `xstrdup()`.

The fix is straightforward: add a NULL check in the config callback and reject missing values with `config_error_nonbool()`, the same pattern used elsewhere in the series. The commit message explains why this cannot break existing setups—`scalar register` always writes `scalar.repo` with a path—so the change is purely defensive. The patch also adds a test in `t/t9210-scalar.sh` to verify the error message and ensure the command fails cleanly.
