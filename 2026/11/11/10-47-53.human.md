This is a CI/build system patch, part of Patrick Steinhardt’s v3 series to speed up GitLab CI pipelines. This specific patch (2/7) targets Windows runners, where test execution is notoriously slow.

The problem: Windows CI shards tests across 10 runners, each of which downloads a ~2300-file build artifact from a preliminary build job. About 1800 of those files are intermediate `*.obj` files that the test jobs don’t need. Downloading and extracting these unused files takes 34 seconds per runner.

The fix: add an `exclude` rule to the `build:msvc-meson` job in `.gitlab-ci.yml` to skip `build/**/*.obj` files. The change is minimal—two lines—and cuts artifact handling time in half (34 s → 17 s). No behavior changes, no new symbols, and no risk to other platforms.

This is a well-motivated, low-risk optimization that directly addresses a known bottleneck. The commit message is clear, the diff is tiny, and the before/after metrics are concrete. If the series lands, this patch alone saves ~3 minutes across the Windows test matrix.
