This is a test infrastructure patch, now in its final form after three iterations. Patrick Steinhardt reviews the latest version of Kristofer Karlsson’s `test-tool genbytes` series and gives it a clear thumbs-up. The patch replaces slow `tr(1)` invocations in the test suite with a direct byte-generation helper, eliminating a 70–79 % performance bottleneck on macOS CI jobs.

The interface is settled: `test-tool genzeros [<count>]` for NUL bytes and `test-tool genbytes <char> [<count>]` for any other single literal character. Patrick’s review highlights that the literal-character design is both intuitive and future-proof—users no longer need to worry about encoding, and the door is left open for later extensions like `\x00` or `\000` without breaking existing callers. The updated callers in the test scripts are now simpler and more readable, replacing `genzeros | tr "\000" "a"` with `genbytes a 500`.

No new issues are raised; this is a surface-level review that confirms the implementation matches the agreed design. With Junio already signaling readiness for `next` and Patrick’s explicit approval, the series looks poised for integration.
