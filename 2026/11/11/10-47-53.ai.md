This is a CI/build system patch (part 2/7 of Patrick Steinhardt’s v3 GitLab CI speedup series). It targets a specific bottleneck in Windows CI pipelines: the build artifact archive passed from the `build:msvc-meson` job to downstream test runners contains ~1,800 intermediate “*.obj” files that are never used by the test jobs. By excluding these files, the patch cuts artifact download and extraction time in half—from 34 seconds to 17 seconds per test job.

The change is a two-line addition to `.gitlab-ci.yml`, adding an `exclude` rule under the `artifacts` section of the `build:msvc-meson` job. No new symbols or behavior changes are introduced; the patch simply trims the artifact payload. The motivation is purely performance: Windows runners are the slowest in Git’s CI matrix, and every second saved compounds across the ten shards that run the test suite.

This patch is uncontroversial and well-motivated. The commit message provides clear before/after metrics, and the implementation is minimal and self-contained. It directly addresses feedback from earlier rounds (v1 and v2) that focused on measurable speedups, and Junio C Hamano has already signaled no technical objections to the series as a whole. The patch is ready for `next` unless a reviewer surfaces a portability or correctness concern with the `exclude` syntax.
