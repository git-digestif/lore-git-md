This is the ninth patch in Thomas Bachem’s 15-patch v3 series fixing Git segfaults when config keys lack values. It plugs a crash in `git fetch <group>` and `git push <group>` when `remotes.<group>` is given without a value: the callback `get_remote_group()` blindly dereferenced the NULL value while splitting the remote list. The fix adds a NULL check and rejects the malformed key with `config_error_nonbool()`, using a separate variable to preserve the full key name (`remotes.valueless`) in the error message. A new test in `t/t5506-remote-groups.sh` verifies the error message and ensures the command fails cleanly. The change is minimal, well-motivated, and consistent with the series’ overall approach of rejecting unvalued keys to prevent crashes. No controversy or open questions remain for this patch.
