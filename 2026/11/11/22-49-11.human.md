This is part 11 of Thomas Bachem’s 15-patch bugfix series that plugs Git segfaults when config keys are given without values. The patch targets the pseudo-merge bitmap subsystem: a `bitmapPseudoMerge.<name>.pattern` setting without a value causes `git repack -adb` to crash because `pseudo_merge_config()` blindly dereferences the NULL value. The fix adds a NULL check and rejects the malformed key with `config_error_nonbool()`, matching the callback’s existing validation for the threshold keys. A new test in `t/t5333-pseudo-merge-bitmaps.sh` verifies the error message and ensures the command fails cleanly. The change is uncontroversial and aligns with the series’ established pattern of rejecting missing values where no sensible default exists.
