This is a review reply on the third patch of Justin Tobler’s ODB transaction series. Karthik Nayak proposes a refactoring of `tmp_objdir_create()` that would eliminate the need to save and restore `errno` after every syscall. Instead, he suggests inlining the `setup_tmp_objdir()` helper, setting `errno` only at the points where failure actually occurs, and using a single `goto fail` exit path. The change is motivated by maintainability—avoiding future breakage if new syscalls are added—and is presented as a cleaner alternative to the current patch’s “finicky” save/restore pattern. No technical objections to the patch’s correctness are raised; this is purely about code structure.
