This is patch 7/12 in the now-merged `ps/rerere-subcommands` refactoring series. It extracts the "status" subcommand of `git rerere` into a dedicated function, `cmd_rerere_status()`, using Git’s standard `parse_options()` machinery. The change is purely mechanical: the new function preserves the existing logic, including the `RERERE_READONLY` flag, the `merge_rr` string list, and the loop that prints each conflicted path. The only difference is that the subcommand now has its own empty option table and usage string, preparing the ground for the later switch to `OPT_SUBCOMMAND()` in patch 11. The patch touches only `builtin/rerere.c` and is a straightforward, low-risk step in the overall modernization.
