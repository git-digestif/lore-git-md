This is the **v3 submission of a 15-patch bugfix series** that systematically eliminates Git segfaults triggered by config settings given without values (e.g., `git -c foo.bar` or a bare `bar` under `[foo]`). The series targets 20 distinct crash sites across commands like `git rebase -i`, `git fetch`, `git add -p`, `git grep`, `git blame`, and `git clone --bundle-uri`, as well as server-triggered crashes via malformed bundle lists.

The v3 update addresses feedback from Phillip Wood and aligns error handling for two settings (`remote.<name>.tagOpt` and `color.blame.repeatedLines`) with the behavior for invalid values: missing values now trigger a warning and are ignored, rather than being rejected with `config_error_nonbool()`. This harmonization reduces inconsistency while preserving the stricter validation for `branch.<name>.mergeOptions` and bundle list keys, where historical config semantics (missing values = boolean `true`, empty values = empty strings) justify the asymmetry. The test for `rebase.missingCommitsCheck` has also been simplified to use `test_commit_message` and a three-commit rebase scenario.

The series is **effectively approved for merge** pending resolution of test conflicts with two topics in `seen` (`iw/connected-deepen-fetch-no-alternate-refs` and `kk/quarantine-alternate-refs`). No design questions remain, and the fixes are well-motivated, with clear commit messages and thorough test coverage. The audit’s completeness suggests it addresses most (if not all) remaining instances of this bug class. Only one patch (15/15) fixes a regression introduced in Git 2.54.0; the rest address latent crashes.

Key technical details:
- **Files touched**: 12 source files (e.g., `add-patch.c`, `bundle-uri.c`, `grep.c`) and 15 test files (e.g., `t/t5558-clone-bundle-uri.sh`, `t/t7810-grep.sh`).
- **Subsystems affected**: rebase, ODB, interactive add, bundle URIs, grep, remote handling, blame, merge, pseudo-merges, scalar, config parsing, and setup.
- **Behavior changes**: Missing values now consistently trigger warnings, `config_error_nonbool()`, or graceful handling (e.g., default values, omission, or silent skipping). The v3 update harmonizes two settings (`remote.<name>.tagOpt` and `color.blame.repeatedLines`) to ignore missing values with a warning, aligning with their behavior for invalid values.
- **Edge cases**: Patch 14/15 fixes a server-triggered crash via malformed bundle lists, and patch 13/15 ensures `includeIf` conditions skip remote URLs without values. The unresolved case (`remote.*.followRemoteHEAD`) is intentionally deferred to a separate topic in `seen`.

The series is based on `master` (3c60ef1e38) and merges cleanly into `next` and `seen`, though the test conflicts must be resolved before it can graduate. The fixes are targeted and uncontroversial, with no API changes or new symbols introduced. The audit methodology (static analysis of config callbacks and dynamic testing of common commands) ensures broad coverage.
