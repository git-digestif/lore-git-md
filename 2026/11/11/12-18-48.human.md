This is the final patch in Patrick Steinhardt’s now-merged 12-patch series that modernizes `git rerere`’s subcommand handling. The patch adds proper per-subcommand usage strings to both the man page (`Documentation/git-rerere.adoc`) and the C code (`builtin/rerere.c`).

The change is purely cosmetic in terms of user-visible output, but it completes the internal consistency goal of the series: each subcommand (“clear”, “diff”, “forget”, “gc”, “remaining”, “status”, and the fallback “perform”) now has its own `N_()`-wrapped usage string, and the top-level `SYNOPSIS` section in the man page is split into one line per subcommand. The C code defines seven usage constants (e.g., `RERERE_CLEAR_USAGE`) and passes the correct array to each `parse_options()` call. The patch is mechanical, low-risk, and directly addresses the last remaining polish item from earlier reviews. With this applied, the series is fully integrated into `master`.
