This is the second patch in the v3 series fixing Git segfaults when config settings are given without values. It targets the `core.alternateRefsCommand` and `core.alternateRefsPrefixes` settings in the ODB subsystem, which previously passed NULL values to `strvec_push()` and `strvec_split()`, causing crashes in commands like `git fetch`, `git receive-pack`, and `git rev-list --alternate-refs`.

The fix replaces `repo_config_get_value()` with `repo_config_get_string_tmp()`, which rejects missing values with `config_error_nonbool()`, consistent with the series' overall approach. The patch includes a new test in `t/t5618-alternate-refs.sh` that verifies the error message for both settings when they lack values. No design questions remain for this patch, and the change aligns with the series' goal of systematically eliminating this class of crashes. The fix is minimal, well-motivated, and touches only the affected code paths.
