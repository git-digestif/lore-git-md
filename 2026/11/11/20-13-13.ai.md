It replaces the `...` syntax with `--merge-base` for clarity, adds cross-references to option definitions, and includes both `--staged` and `--cached` as synonyms while clarifying their relationship. The DESCRIPTION now links to the EXAMPLES section to improve discoverability.

Key changes since v2 include reverting modifications to the SYNOPSIS and DESCRIPTION (keeping `--cached` as the primary form), squashing Junio’s formatting fixes for anchor syntax, and restoring `git diff AUTO_MERGE` with reworded phrasing. The patch touches `Documentation/git-diff.adoc` and `Documentation/diff-options.adoc`, adding compatible anchor syntax (`--name-only[[name_only]]::`) to ensure it builds with both AsciiDoc processors.
