This is a CI/build system patch (part 3 of 7 in Patrick Steinhardt’s GitLab CI speedup series). It addresses a specific bottleneck in the `fedora-breaking-changes-meson` job, which runs roughly twice as long as other Linux jobs due to unoptimized Meson builds.

The patch changes the Meson build configuration to use `--buildtype=debugoptimized` (equivalent to `-g -O2` in the Makefile), replacing the default `debug` build type (`-O0`). This optimization cuts the Fedora job’s runtime nearly in half—from 2100 to 1000 seconds—by significantly improving SHA256 performance (hashing a 500MB blob drops from 9.6s to 1.5s). Other Linux and macOS jobs see smaller but measurable speedups (~10%), while Windows builds remain roughly unchanged overall due to a trade-off between slower compilation and faster test execution.

The implementation is minimal: a one-line change in `.gitlab-ci.yml` for Windows and another in `ci/run-build-and-tests.sh` for other platforms. The patch is uncontroversial and aligns with the series’ goal of reducing CI feedback time. Junio C Hamano has already signaled no technical objections to the series, and this patch directly addresses the most severe slowdown identified in the cover letter. The change is low-risk, as it only adjusts build flags without altering functionality or test logic.
