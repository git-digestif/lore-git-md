This is part of Thomas Bachem’s 15-patch bugfix series that plugs segfaults when config keys are given without values. Patch 8/15 teaches `git merge` to reject a missing value for `branch.<name>.mergeOptions` with `config_error_nonbool()`, matching the existing pattern for other string-valued settings in the same callback. The fix is a two-line NULL check in `builtin/merge.c` plus a new test in `t/t7600-merge.sh` that verifies the error message. The patch is uncontroversial, historically validated (Git’s config parser has treated missing values as boolean `true` since 2005), and already approved for merge once the series’ test conflicts are resolved.
