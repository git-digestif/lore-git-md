This is a surface-level review comment from Junio C Hamano on the second patch in Wyatt Holden’s three-patch series introducing `checkout.orphanedCommitWarning`. The patch adds an advice message that triggers when the orphaned-commit reachability check takes more than two seconds, guiding users to disable the warning via configuration.

Junio points out a test fragility: the test currently greps for the exact string `git config set advice.checkoutOrphanedCommitWarning false`, but the advice message in the codebase now uses `--global` (e.g., `git config set --global advice.FOO false`). He suggests loosening the grep pattern to `git config .* advice\.checkoutOrphanedCommitWarning` to avoid test failures when the advice message evolves. The fix is trivial and does not affect the patch’s functionality or design. This is a nit, not a substantive objection, and the thread’s larger design questions (whether the config knob is the right approach, cost factors, and the omission of a CLI option) remain unresolved.
