This is the first review comment on the first patch of Justin Tobler’s four-patch series that makes Git’s object database (ODB) transaction temporary directory creation eager. The patch itself is a simple, uncontroversial refactoring: it renames the default prefix for the temporary directory from `"bulk-fsync"` to `"transaction"` to reflect the directory’s broader role beyond just batching fsyncs. Karthik Nayak’s review is surface-level and positive, noting only that the new prefix makes sense given the general use of ODB transactions. There are no objections or requests for changes here, and the patch is effectively approved.

The context for this patch is the ongoing ODB abstraction effort led by Patrick Steinhardt. The series as a whole aims to fix a correctness gap by ensuring the temporary directory is created at transaction start rather than lazily on the first object write, which risks inconsistencies if the transaction fails. While Karthik has not yet weighed in on the series’ core design (his later review challenges the motivation for eager creation), this particular patch is a straightforward cleanup that aligns with the series’ direction. The discussion so far suggests the patch will likely be merged as-is, with any substantive debate focused on the later patches.
