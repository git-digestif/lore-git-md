This is a documentation patch that rewrites the EXAMPLES section of the `git diff` man page. The author, Julia Evans, has gathered feedback from Git users to modernize the examples, making them more relevant and easier to understand. The new version organizes examples into five clear subsections (uncommitted changes, diffing specific files/directories, diffing branches or commits, summarizing output, and alternative diff displays), replaces the confusing `...` syntax with `--merge-base`, and adds cross-references to option definitions.

This is the third iteration (v3) of the patch, incorporating all prior feedback: Junio’s squashable fixes for AsciiDoc compatibility, anchor placement, and the `-h` help output oversight are now included, and the unintended `--cached`/`--staged` changes in the SYNOPSIS and DESCRIPTION have been reverted. The patch builds correctly and passes all tests. The presentation format has shifted from tables to AsciiDoc horizontal definition lists, which keeps examples compact but may pose cut-and-paste issues—this remains the sole unresolved dispute, with Junio objecting to the new format. The broader question of whether to drop Python AsciiDoc support is no longer blocking this patch.

The rewrite is well-motivated and thorough, addressing long-standing user complaints about outdated examples. The commit message clearly explains the design choices, such as preserving both `--staged` and `--cached` for user familiarity and improving readability with sub-subsection headings. If the formatting dispute is resolved, this patch is ready for `next`.
