This is patch 5/15 in the v3 series fixing Git segfaults when config settings lack values. It targets the `grep.patternType` config key, which currently causes `git grep`, `git log`, and `git show` to crash when given without a value (e.g., `git -c grep.patternType`). The fix adds a NULL check in `grep_config()` to reject missing values with `config_error_nonbool()`, matching the existing error handling for `color.grep.*` slots. The patch includes a new test in `t/t7810-grep.sh` verifying the error message.

The change is minimal and uncontroversial, following the established pattern from earlier patches in the series. No feedback was received on this specific patch in prior rounds, but its approach aligns with the series' overall goal of systematically eliminating NULL-dereference crashes in config callbacks. The fix is well-motivated and clearly explained in the commit message, with test coverage confirming the expected behavior. This patch is ready for merge alongside the rest of the series once the test conflicts in `seen` are resolved.
