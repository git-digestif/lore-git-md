This is the fourteenth patch in Thomas Bachem’s v3 series fixing Git segfaults when config keys are given without values. It plugs a server-triggered crash in the bundle-URI subsystem: if a bundle list advertises `bundle.mode`, `bundle.heuristic`, `bundle.<id>.uri`, or `bundle.<id>.creationToken` without a value, `bundle_list_update()` passes the NULL pointer to `strcmp()`, `relative_url()`, or `sscanf()`, causing a segfault in both `git clone --bundle-uri` and `git fetch`. The fix adds NULL checks at each of the four sites and rejects the malformed entry with `config_error_nonbool()`, making the list invalid so the operation continues without the bundles. The new test in `t/t5750-bundle-uri-parse.sh` verifies that each key without a value triggers the expected error message. The patch is uncontroversial and aligns with the series’ established pattern of rejecting missing values for non-boolean config keys.
