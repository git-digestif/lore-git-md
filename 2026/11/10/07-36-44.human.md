This is the fourteenth patch in Thomas Bachem’s 15-patch bugfix series that systematically eliminates Git segfaults when config keys are given without values. This installment targets the bundle-uri subsystem: if a bundle list contains `bundle.mode`, `bundle.heuristic`, `bundle.<id>.uri`, or `bundle.<id>.creationToken` without a value, `git clone --bundle-uri` or `git fetch` would previously dereference NULL in `strcmp()`, `relative_url()`, or `sscanf()`, causing a crash. The fix adds NULL checks in `bundle_list_update()` and rejects missing values with `config_error_nonbool()`, making the list invalid so the operation continues without the bundles. The accompanying test verifies that Git emits a clear error message instead of crashing when these keys lack values. While the fix prevents the segfault, Derrick Stolee noted in the v1 discussion that the error message may not clearly indicate the issue stems from a malformed server response; that UX improvement is deferred to a follow-up. The patch is well-motivated, narrowly scoped, and follows the series’ established pattern of graceful error handling.
