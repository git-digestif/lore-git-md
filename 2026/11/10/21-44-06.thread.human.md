This is an announcement for **Git for Windows 2.56.1**, a security-focused release addressing six critical vulnerabilities (CVEs) that could lead to remote code execution, path traversal, memory corruption, and other severe issues. The update tracks upstream Git v2.56.1 but is a separate release for the Windows platform, maintained by Johannes Schindelin.

The vulnerabilities affect submodules, ref backends, merge machinery, and binary patch processing, with impacts ranging from denial-of-service to arbitrary code execution. No new features are introduced—this is purely a security update. The email provides download links for multiple variants (64-bit, ARM64, portable, MinGit, and busybox builds) along with checksums for verification. This release supersedes Git for Windows v2.56.0(4) from October 2026.

Windows users and packagers are urged to update immediately. The announcement was sent to both the Git mailing list and `git-packagers@googlegroups.com`, indicating broad relevance to downstream distributors. Note that this is *not* an upstream Git release—it’s specific to Git for Windows.
