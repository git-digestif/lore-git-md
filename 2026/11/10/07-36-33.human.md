This is a bugfix patch, part 3 of a 15-patch series that systematically eliminates Git segfaults triggered by unvalued config keys. The series is under active review and effectively approved for merging once test conflicts are resolved.

This specific patch fixes a crash in `git add -p` (and other interactive patch modes) when a color slot like `color.interactive.prompt` or `color.diff.frag` is given without a value. The bug surfaces when `init_color()` passes the NULL value to `color_parse()`, causing a segfault. The fix replaces `repo_config_get_value()` with `repo_config_get_string_tmp()`, which rejects missing values with `config_error_nonbool()`, matching the behavior already established for `git diff` color slots. The change is minimal—just one line in `add-patch.c`—and includes a new test in `t/t3701-add-interactive.sh` that verifies the error message is clear and the command fails gracefully.
