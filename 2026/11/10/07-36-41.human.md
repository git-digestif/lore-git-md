This is the eleventh patch in Thomas Bachem’s v2 series fixing Git segfaults when config keys lack values. It plugs a crash in the pseudo-merge bitmap subsystem: when `bitmapPseudoMerge.<name>.pattern` is given without a value (e.g., `git -c bitmapPseudoMerge.test.pattern repack -adb`), the callback dereferences NULL while checking whether the pattern starts with `^`. The fix adds a NULL check and rejects the missing value with `config_error_nonbool()`, matching the established pattern used elsewhere in the series. A new test in `t/t5333-pseudo-merge-bitmaps.sh` verifies that Git emits a clear error message instead of crashing. The change is minimal, well-motivated, and consistent with the rest of the series.
