This is a **test infrastructure patch** that has reached its final form. Junio C Hamano reviews the v3 submission of `test-tool genbytes`—a new helper designed to replace slow `tr(1)` invocations in Git’s test suite, particularly on macOS—and signals readiness for integration.

The patch consolidates the existing `genzeros` and new `genbytes` commands into a single file (`test-genzeros.c`), avoiding unnecessary file renames. The implementation uses a shared 256 KB static buffer and a `generate_bytes` helper to write arbitrary bytes directly, with `git_parse_signed()` for stricter input validation. Junio’s review notes the straightforward correctness of the code and its callers, including the use of an infinite byte stream in `t9850-shell.sh` to test command-length limits.

This is the culmination of a three-iteration design process, with all prior feedback addressed. The series is now **ready for `next`**, having resolved performance bottlenecks (70–79% speedup on macOS) and design questions (e.g., buffer allocation, interface choices). No behavioral changes or on-disk format modifications are introduced; the patch touches only test infrastructure and is unlikely to spark controversy.
