This is the seventh patch in Karthik Nayak’s 20-patch **test modernization** series that splits the monolithic `t9300-fast-import.sh` into smaller, self-contained files. This specific patch refactors the “series P” tests (gitlinks / submodule handling) so they no longer depend on state left behind by earlier tests.

The patch introduces a new helper, `setup_gitlinks_repo()`, that spins up a fresh repository for each test, eliminating the need for the tests to run in a fixed order. It also fixes two small correctness issues: the “fail on inline gitlink” and “fail on blob mark in gitlink” tests now use `subuse1` (created in the helper) instead of `subuse2` (which was only written by the “verbatim SHA gitlinks” test). The diff is purely mechanical—no new functionality is added, and the on-disk behavior of `git fast-import` is unchanged.

The patch is clean, well-scoped, and follows the established pattern of the series. It touches only `t9300-fast-import.sh` and keeps the same test coverage while making the tests more maintainable.
