This is the first patch in Wyatt Holden’s three-patch series introducing `checkout.orphanedCommitWarning`, a new configuration knob that lets users disable the expensive reachability check Git performs when leaving a detached HEAD. The patch adds the config key itself (defaulting to `true`), wires it into the checkout built-in, and wraps the existing `orphaned_commit_warning()` function in a Trace2 region so its cost can be measured. Tests verify that both `git checkout` and `git switch` respect the setting and that Trace2 telemetry confirms the check is skipped when disabled. The commit message cites internal Microsoft data showing the check can consume 193 of 205 seconds in a large mono-repo, motivating the opt-out for performance-critical workflows.
