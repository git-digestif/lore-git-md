This is the fifteenth patch in Karthik Nayak’s 20-patch **test modernization** series refactoring `t9300-fast-import.sh`. It makes the eight “cat-blob” tests self-contained by running each in a fresh repository created with `git init` and wrapped in `test_when_finished`. The patch converts the shared “setup: big file” test into a reusable `setup_big_file()` helper that writes the large file into the caller’s repository, eliminating the dependency on the trash directory’s global state. The diff is purely mechanical: every test block is wrapped in `(cd repo && ...)` and the helper is invoked where needed. No behavior changes; the patch is part of the broader effort to break up the monolithic `t9300` file into smaller, independent test scripts.
