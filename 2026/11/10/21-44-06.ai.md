This is an **announcement email** for **Git for Windows 2.56.1**, a security-focused release addressing six CVEs. The update tracks upstream Git v2.56.1 but is a distinct release for the Windows platform, maintained by Johannes Schindelin.

The security fixes target critical vulnerabilities, including remote code execution (CVE-2026-111760), path traversal in ref updates (CVE-2026-113408), stack memory corruption during GPG signature stripping (CVE-2026-114467), out-of-bounds reads in patch application (CVE-2026-114469), heap corruption during large merges (CVE-2026-105437), and unsafe fast-import features (CVE-2026-114466). These issues span submodule handling, ref backends, merge machinery, and binary patch processing, with potential impacts ranging from denial-of-service to arbitrary code execution.

No new features are introduced beyond the upstream Git version bump. The email provides download links for multiple variants (64-bit, ARM64, portable, MinGit, and busybox builds) along with SHA-512 checksums for verification. This release supersedes Git for Windows v2.56.0(4) from October 2026.

The vulnerabilities are severe enough to warrant immediate attention from Windows users and packagers. The announcement is directed at both the general Git mailing list and the `git-packagers@googlegroups.com` group, indicating broad relevance to downstream distributors. No upstream Git release announcement is referenced, suggesting this is a Git for Windows-specific security update.
