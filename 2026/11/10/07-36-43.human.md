This is the thirteenth patch in Thomas Bachem’s 15-patch bugfix series that stops Git from segfaulting when config keys are given without values. It specifically addresses a crash in the `includeIf` logic: when a `remote.<name>.url` entry lacks a value, the code used to pass NULL to `string_list_append()`, which then tried to `xstrdup()` it. The fix is simple—skip any valueless URL in `add_remote_url()`—so that `includeIf.hasconfig:remote.*.url:...` patterns never see NULL strings. The patch adds a 22-line test that verifies the include rule still fires for valid URLs while silently ignoring the valueless one. No new error messages are introduced; the existing `handle_config()` in `remote.c` already rejects valueless URLs with the usual `config_error_nonbool()` when commands actually read the remotes.
