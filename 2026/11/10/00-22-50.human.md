This is the third patch in Justin Tobler’s four-patch series that makes Git’s ODB transaction machinery more robust by creating the temporary object directory eagerly at transaction start. The patch itself is a small but important correctness fix: it preserves `errno` across cleanup in `tmp_objdir_create()` so that callers can reliably inspect why directory creation failed. The change touches only `tmp-objdir.c` and its header, adding a few lines to save and restore `errno` around `mkdir()` and cleanup calls. No behavior change is visible to users; this is purely plumbing-level hygiene that prepares for the main functional change in patch 4. The patch is well-scoped, clearly motivated, and uncontroversial.
