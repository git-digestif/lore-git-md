The Git project has released Git 2.56.1 and six other maintenance versions (2.55.2 through maint-2.43) to address six critical security vulnerabilities discovered by Luke Martin and pwn2addr. These include remote code execution via malicious submodule gitfiles, path traversal in the files ref backend, stack corruption from multi-signature commits, and several memory corruption issues. The fixes are now available across all supported maintenance tracks, with no unresolved technical concerns.

The release also includes defense-in-depth hardening—such as rejecting over-long cache entries and stricter symref validation in protocol v2—and updates to CI/build systems for macOS 15, Debian 12, and OpenSSL 4.0 compatibility. Contributors like Toon Claes, Karthik Nayak, Jeff King, and Johannes Schindelin played key roles in implementing fixes and coordinating the release. A minor logistical issue—GitLab work item links being inaccessible to non-privileged users—was reported by Todd Zullinger and has since been resolved, as confirmed by Kaartic Sivaraam. The thread remains purely informational, with no ongoing technical debates or open questions.
