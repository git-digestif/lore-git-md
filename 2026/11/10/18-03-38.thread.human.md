The Git 2.56.1 security release, announced by Junio C Hamano, addressed six critical CVEs discovered by Luke Martin and pwn2addr, including remote code execution via malicious submodule gitfiles, path traversal in the files ref backend, and heap corruption during large merges. The fixes were backported across seven maintenance tracks (2.56.1 through maint-2.43) and included defense-in-depth hardening like rejecting over-long cache entries and stricter symref validation in protocol v2. Key contributors included Toon Claes (protocol v2 fixes), Karthik Nayak (multi-signature handling), Jeff King (HTTP header redaction), and Johannes Schindelin (CI updates for macOS 15 and OpenSSL 4.0).

The release is now complete, with tarballs available on kernel.org and all vulnerabilities resolved. A minor logistical issue—GitLab work item links being initially restricted—was addressed shortly after the announcement, with Toon Claes confirming they are now accessible to all users. No further discussion or unresolved questions remain in the thread.
