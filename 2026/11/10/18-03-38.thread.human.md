This thread is about the recent security release of Git 2.56.1 and other maintenance versions, addressing six CVEs discovered by Luke Martin and pwn2addr. The vulnerabilities include remote code execution risks, path traversal, stack corruption, and unsafe `fast-import` features, among others. Junio C Hamano announced the coordinated release, which spans seven maintenance tracks (2.56.1 through maint-2.43), with contributions from Toon Claes, Karthik Nayak, Kaartic Sivaraam, Jeff King, and Johannes Schindelin, among others. The fixes are now available, and no unresolved issues remain.

The only follow-up so far is a minor logistical note from Todd Zullinger, who pointed out that the GitLab work item links in Junio’s announcement are currently inaccessible to non-privileged users. He suspects this is unintentional and has looped in Patrick Steinhardt to investigate. This doesn’t affect the security fixes themselves but may limit visibility into the internal tracking of the issues. The thread remains focused on the release and its distribution.
