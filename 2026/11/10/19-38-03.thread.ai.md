Thread identity: l10n patch for `add-patch` pluralization in Polish translation. Series version: v2 (`[GSoC PATCH v2]`), standalone patch. Originating author: Abhishek Agarwal (previously contributing as aeron-gh), GSoC 2027 microproject participant.

Core problem or goal: Fix incorrect plural forms in the Polish translation of the "Split into %d hunks." message in `git add -p` by replacing the singular-only `_()` wrapper with the plural-aware `Q_()` wrapper in `patch_update_file()`. The change enables translators to provide grammatically correct plural forms (e.g., "2 skrawki" instead of "2 skrawków") while preserving English output.

Current status: Under review at v2. The v2 revision rebased onto current master with no code changes, switched the sign-off from the pseudonym aeron-gh to the real name Abhishek Agarwal, and updated the commit message to explicitly note the trade-off for translators of languages with only singular and plural forms (e.g., German) that must now translate the message twice, following a suggestion Junio C Hamano made on a similar patch. The underlying issue was originally flagged by Mahmoud in March 2026 but remained unaddressed until now.

Key technical details:
- Files touched: `add-patch.c` (translation string only, around line 1942).
- Symbols: Replaces `_("Split into %d hunks.")` with `Q_("Split into %d hunk.", "Split into %d hunks.", splittable_into)` in `patch_update_file()`.
- Behavior: No change for English users; the count `splittable_into` is always at least 2 in this path (the split option is only offered when `hunk->splittable_into > 1`), so the English singular string is never displayed, though `Q_()` still requires it as an argument. Enables correct pluralization in Polish and other languages with complex plural rules.
- On-disk format: Unaffected.
- Test coverage: No test updates needed (translation strings only).
