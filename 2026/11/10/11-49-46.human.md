This is a test modernization patch, the first in a 20-patch series from Karthik Nayak. It moves a `fastimport.unpackLimit` configuration setting from the "empty stream succeeds" test to the "A: create pack from stdin" test where it is actually needed. The change is preparatory: a later commit will run the "empty stream" test in its own repository, so the setting would no longer affect subsequent tests if left where it is. The patch is small (one line moved) and the rationale is clearly explained in the commit message. It looks like a clean, uncontroversial step in what is likely a larger effort to improve test isolation in the `git fast-import` test suite.
