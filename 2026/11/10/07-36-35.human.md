This is a bugfix patch, part of a 15-patch series that systematically eliminates Git segfaults when config keys are given without values. This specific patch (5/15) fixes a crash in `` `git grep` ``, `` `git log` ``, and `` `git show` `` when ``grep.patternType`` is set without a value (e.g., ``git -c grep.patternType``).

The fix is minimal and targeted: it adds a NULL check in ``grep_config()`` to reject missing values with ``config_error_nonbool()``, following the same pattern already used for ``color.grep.*`` slots in the same function. The test verifies that Git now emits a clear error message instead of crashing. The change is uncontroversial and aligns with the series' overall approach of using ``config_error_nonbool()`` for most unvalued config keys.

This patch touches only ``grep.c`` and the corresponding test file, with no cross-subsystem impact.
