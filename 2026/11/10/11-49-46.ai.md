This is a test refactoring patch, the first in a 20-patch series. It moves the `fastimport.unpackLimit=0` configuration from the "empty stream succeeds" test to the "A: create pack from stdin" test, which is the first test that actually needs it. The motivation is that a later patch in the series will run the "empty stream succeeds" test in its own repository, so the configuration would no longer be visible to subsequent tests. The change uses `git config` (persistent) rather than `test_config` (temporary) to ensure the setting remains available for the "verify pack" tests that follow. The patch is mechanical and preparatory, touching only the test script `t/t9300-fast-import.sh`.
