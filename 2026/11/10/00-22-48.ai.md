This is the first patch in Justin Tobler’s four-patch series that makes the ODB transaction temporary directory creation eager. It is a pure refactoring with no behavior change: the default prefix for the temporary directory is renamed from `"bulk-fsync"` to `"transaction"` to reflect the broader role the directory now plays beyond just batching fsyncs. The patch touches only `object-file.c` and consists of a single line change. The motivation is clarity and future-proofing—preparing for the subsequent patches that will make the directory creation eager for all transactions, not just those with batched fsync. The commit message explains the historical context and why the old name would soon be misleading. No controversy is expected; this is a straightforward cleanup.
