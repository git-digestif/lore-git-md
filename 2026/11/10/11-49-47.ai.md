This is a test modernization patch, the second in a 20-patch series that prepares `t9300-fast-import.sh` for splitting into smaller files. The patch makes the "series B" tests self-contained by running each in a fresh repository that is discarded afterward. Previously, these tests relied on state left by earlier tests (e.g., a `main` branch) or assumed a clean object store; now they explicitly create any needed preconditions and avoid cross-test contamination. The changes are mechanical: each test block is wrapped in `git init repo && (cd repo && ...)` and paired with `test_when_finished "rm -rf repo"`, and any missing setup (like `test_commit base`) is added. No behavior is altered, only test isolation. The patch is clean, well-motivated, and a necessary step toward the series’ goal of breaking up the 4000-line `t9300` file.
