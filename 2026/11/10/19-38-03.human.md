This is a small but well-targeted i18n (translation) patch from a GSoC contributor. The patch fixes a pluralization bug in the interactive `git add -p` ("add --patch") command. Currently, the message "Split into %d hunks." always uses the same translation string regardless of the number, which breaks grammatical agreement in languages like Polish that have multiple plural forms. The fix switches from `_()` to `Q_()`, Git's plural-aware translation macro, so translators can provide the correct singular ("hunk") and plural ("hunks") forms while keeping the English output unchanged.

The commit message is clear and cites both the original issue report (from March) and the GSoC microproject context. The change itself is minimal: one line in `add-patch.c`, replacing the translation call and adding the necessary plural variants. This is a textbook example of a low-risk, high-impact i18n fix—exactly the kind of contribution that benefits from early attention from translation maintainers. If you care about Git's internationalization, this patch is worth a quick review.
