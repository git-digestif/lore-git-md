This is the tenth patch in Karthik Nayak's 20-patch **test modernization** series refactoring `t9300-fast-import.sh`. It makes the ref-update tests (series F, G, J, and K) self-contained by removing their dependency on prior test state.

The patch introduces a new helper, `setup_two_commit_repo()`, which creates a fresh repository with two commits on `main` for each test to use. This replaces the previous shared state where tests built on the `branch` branch from earlier tests. The patch also folds verification steps directly into the tests that perform the import, eliminating standalone "verify pack" and "verify commit" tests that couldn't run independently. To ensure packs are written (since `fastimport.unpackLimit` is no longer set globally), the patch explicitly sets it for the F and G imports and replaces the now-removed `verify_packs()` helper with an inline loop that calls `git verify-pack` on every pack file.

The changes are mechanical and focused on test organization, not Git behavior. The patch maintains the same test coverage while making the tests more maintainable and debuggable. This continues the series' pattern of systematically eliminating shared state in `t9300` to enable future test relocation. The new `setup_two_commit_repo()` helper will likely be reused in later patches. No regressions or edge cases are introduced, and the patch keeps the same test logic while improving isolation.
