This is the eleventh patch in Thomas Bachem’s v2 series fixing Git segfaults when config keys lack values. It plugs a crash in the pseudo-merge bitmap subsystem: when `bitmapPseudoMerge.<name>.pattern` is given without a value (e.g., `git -c bitmapPseudoMerge.test.pattern repack -adb`), `pseudo_merge_config()` dereferences the NULL pointer while checking whether the pattern starts with `^`. The fix adds a NULL check and rejects the missing value with `config_error_nonbool()`, matching the callback’s existing behavior for malformed `threshold` keys. The test verifies that Git emits a clear error message instead of crashing. This follows the series’ established pattern and touches no other code paths.
