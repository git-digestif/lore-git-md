This is an **announcement email** from Junio C Hamano for coordinated **security releases** of Git: versions 2.56.1, 2.55.1, 2.54.1, 2.53.1, 2.52.1, 2.51.3, and 2.50.2. These releases address six CVEs (CVE-2026-111760, CVE-2026-113408, CVE-2026-114466, CVE-2026-114467, CVE-2026-114469, and CVE-2026-105437) that include remote code execution, path traversal, stack memory corruption, and heap corruption vulnerabilities. Users are strongly urged to update immediately.

The vulnerabilities affect core Git functionality: recursive clones (CVE-2026-111760), ref advertisement (CVE-2026-113408), GPG signature stripping (CVE-2026-114467), binary patch application (CVE-2026-114469), large merge conflict handling (CVE-2026-105437), and `fast-import` features (CVE-2026-114466). The fixes were contributed by Toon Claes, Karthik Nayak, Kaartic Sivaraam, and others, with Johannes Schindelin coordinating the release process. The xdiff hardening work is based on an earlier patch by Jeff King.

In addition to the security fixes, the releases include defense-in-depth hardening (e.g., rejecting cache entries with over-long names), CI/build system updates (macOS 15, Debian 12, OpenSSL 4.0, and cURL compatibility), and platform-specific fixes (Windows, macOS iconv workarounds). The changelog lists 100+ commits from 15 contributors, including Elijah Newren, Jeff King, Patrick Steinhardt, and René Scharfe, covering everything from memory safety improvements to test suite adjustments.

This is a **must-read** for anyone running Git in production or on shared infrastructure. The vulnerabilities are serious enough to warrant immediate attention, and the release notes provide clear links to detailed advisories for each CVE. The announcement itself is concise and action-oriented, making it easy for busy readers to grasp the urgency.
