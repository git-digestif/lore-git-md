This is the tenth patch in Karthik Nayak’s 20-patch **test modernization** series that splits the monolithic `t9300-fast-import.sh` into smaller, self-contained files.

This patch makes the ref-update tests (series F, G, J, and K) independent of earlier test state. It introduces a new helper, `setup_two_commit_repo()`, that creates a fresh repository with two commits on `main` so each test can start from a known state. The tests are folded together where possible, and the now-removed `verify_packs()` helper is replaced with an inline loop that calls `git verify-pack` on every pack file. The patch also sets `fastimport.unpackLimit=0` explicitly for the F and G imports to ensure a pack is written, matching the original behavior.

The changes are mechanical and confined to `t9300-fast-import.sh`; no new test files are created here. The commit message is clear and the diff is easy to follow. This looks like another well-executed step in the overall goal of making the fast-import test suite more maintainable. No objections or loose ends have surfaced yet.
