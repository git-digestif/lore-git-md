This is the latest "What's cooking in git.git" report from Junio Hamano, summarizing the state of Git development as of November 2026. Here’s a high-level digest of what’s happening:

### **Graduated to 'master' (now part of the next release)**
Several patches have been deemed stable and merged into the main branch:
- **Bugfixes and performance improvements**: Fixes for `git fetch` connectivity checks (ignoring shallow/grafted alternates), `git multi-pack-index write` (skipping empty writes), and `git unpack-objects` (correctly handling large blobs on Windows).
- **Documentation updates**: A new beginner-friendly tutorial (`gittutorial.adoc`), clarifications for SSH key lifetime checks, and improvements to `git diff` examples.
- **Refactoring**: Cleanups in `unpack-trees`, `commit-graph`, and `prune-packed` to remove reliance on the global `the_repository` variable.
- **Test modernizations**: Replacing raw shell commands (`test -e`, `test -f`) with Git’s test helpers (`test_path_is_file`, `test_path_exists`) for better diagnostics.
- **CI/build fixes**: GitLab CI optimizations (disabling shallow clones for whitespace checks) and fixes for Ubuntu 26.04 runner issues.

### **New Topics (Under Active Review)**
- **`jc/unpack-trees-repo`**: Further removal of `the_repository` usage in `unpack-trees.c`.
- **`bc/setup-default-hash-algo`**: Ensures `git init` uses the default hash algorithm (SHA-256 in breaking-change mode).
- **`hs/doc-promisor-fetch-order`**: Documents the order in which promisor remotes are tried during partial clones.
- **`kk/test-tool-genbytes`**: Replaces slow `tr(1)` calls in tests with a native `test-tool genbytes` helper.
- **`ps/ci-speedups`**: Optimizes GitLab CI by building with Meson and using reftables for large-ref tests.

### **Stalled Topics (Needing Attention)**
Several patches are stuck due to unresolved feedback or lack of response:
- **`ap/http-preserve-wwwauth-redirect`**: Preserves WWW-Authenticate headers across HTTP redirects (stalled since August).
- **`vv/branch-recurse-no-start-ref`**: Fixes a crash in `git branch --recurse-submodules` with non-ref start points.
- **`ec/commit-fixup-options`**: Allows `-m/-F/-c/-C` options with `git commit --fixup` (needs reroll).
- **`js/coverity-overflow-fixes`**: Integer overflow fixes (stalled since October).
- **`mc/repo-structure-filtering`**: Adds revision filtering to `git repo structure`.

### **Cooking in 'next' (Integration Testing)**
Topics here are candidates for the next release but may still be tweaked:
- **`kj/repo-info-more-path-keys`**: Extends `git repo info` to output more repository paths (e.g., hooks, superproject root).
- **`jt/object-file-error-handling`**: Improves error reporting for `index-pack` failures.
- **`ps/storage-format-improvements`**: Enhances object/refs storage format handling (e.g., automatic directory creation).
- **`ps/rerere-subcommands`**: Converts `git rerere` to use `OPT_SUBCOMMAND()` for consistency.
- **`tb/sideband-skip-unrecognized`**: Fixes an infinite loop in `sideband.allowControlCharacters` parsing.

### **Notable Discussions**
- **`lt/describe-commit-date-skew`**: Linus Torvalds proposed a fix for `git describe` to use generation numbers when commit dates are skewed (sparking debate about correctness vs. performance).
- **`mv/log-follow-speedup`**: Optimizes `git log --follow` for non-linear history by checking unmodified paths first.
- **`hn/branch-delete-merged-squash`**: Introduces `--delete-integrated` to detect squash-merged branches (controversial due to edge cases).
- **`ps/grep-recurse-submodules-fix`**: Fixes a regression in `git grep --recurse-submodules` where nested trees were missed.

### **Security and Compatibility**
- A **security release (2.56.1)** was recently published, with fixes merged into all integration branches.
- **`bc/restrict-hex-to-lowercase`**: Prepares for Git 3.0 by rejecting uppercase hex characters in object IDs (breaking change).

### **Ongoing Efforts**
- **`the_repository` removal**: Patches continue to eliminate global state (e.g., `bundle-uri`, `merge-blobs`, `range-diff`).
- **Rustification**: No major updates, but the topic remains contentious (e.g., NonStop port compatibility concerns).
- **SHA-256 interoperability**: `cc/pack-index-v3` adds support for pack index v3 to map between hash algorithms.

### **What to Watch**
- **`rm/http-retry-improvements`**: Enhances HTTP retry logic with exponential backoff and configurable status codes.
- **`hn/fetch-refmap`**: Changes default refspecs for shallow repositories to avoid fetching all branches.
- **`hn/status-push-rebased-on-newer-upstream`**: Improves `git status` and `git push` advice for rebased branches.

This report is a snapshot of a busy development cycle, with a mix of bugfixes, performance work, and foundational refactoring. The most active areas are CI optimizations, `the_repository` removal, and storage format improvements.
