This is the sixth patch in Karthik Nayak’s 20-patch **test modernization** series that splits the sprawling `t9300-fast-import.sh` into smaller, self-contained files. Here the focus is on the “series Q” tests, which verify fast-import’s notes handling. The patch replaces the original monolithic test that relied on side effects from earlier tests with a new `setup_notes_repo()` helper that creates a fresh repository for each test, runs the import with `fastimport.unpackLimit=0` to force a pack, and exports the commit hashes the tests need. Every test now calls this helper, making it trivial to move the group to a separate file later. The diff is large (220 insertions, 124 deletions) but purely mechanical; no behavior changes are introduced.
