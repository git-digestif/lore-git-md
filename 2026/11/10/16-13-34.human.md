This is the final patch in Patrick Steinhardt’s six-patch refactoring series that isolates the loose-object backend into its own source file (`odb/source-loose.c`). The series is part of the ongoing ODB abstraction effort to make Git’s object storage more modular.

This patch removes the blanket `#include "git-zlib.h"` from `object-file.h` and adds it explicitly to the nine files that directly use zlib (`apply.c`, `builtin/fast-import.c`, `builtin/index-pack.c`, `builtin/pack-objects.c`, `diff.c`, `object-file.c`, `odb/source-loose.c`, `pack-check.c`, and `packfile.c`). The change is purely mechanical and completes the header hygiene work begun in earlier patches. By making dependencies explicit, it reduces unnecessary header exposure and supports future backend isolation.

Kaartic Sivaraam’s review confirms the patch is straightforward and correct. No substantive concerns have been raised, and the patch appears ready for integration once the rest of the series is accepted. This is a small but necessary step in the ODB abstraction effort, with no behavior changes or new API exposure.
