This is the ninth patch in Karthik Nayak’s 20-patch **test modernization** series that splits the monolithic `t9300-fast-import.sh` into smaller, self-contained test files.

The patch makes the “big blob” tests (series R) independent of earlier test state. The original three tests—one that imports two large blobs, one that verifies the pack, and one that checks the blob contents—are folded into a single test that does everything in a fresh repository. The helper `verify_packs` is replaced with an inline loop that calls `git verify-pack` on every pack file, so the test remains self-contained when it is later moved to a new file. The repository is configured with `fastimport.unpackLimit=0` to ensure a pack is written, matching the original behavior.
