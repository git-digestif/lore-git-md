Subject: [ANNOUNCE] Git 2.56.1 and other maintenance releases to address security vulnerabilities
Series version: N/A (maintenance release)
Originating author: Junio C Hamano
Thread type: security release announcement

Core problem or goal
A coordinated security release addressing six CVEs (CVE-2026-111760, CVE-2026-113408, CVE-2026-114467, CVE-2026-114469, CVE-2026-105437, CVE-2026-114466) discovered by Luke Martin and pwn2addr. The vulnerabilities include remote code execution via malicious submodule gitfiles, path traversal in the files ref backend, stack corruption from multi-signature commits, out-of-bounds reads from oversized binary patches, heap corruption during large merges, and unsafe `fast-import` features. The release also includes defense-in-depth hardening (e.g., rejecting over-long cache entries) and CI/build system updates (macOS 15, Debian 12, OpenSSL 4.0 compatibility).

Current status
Released across seven maintenance tracks (2.56.1, 2.55.2, 2.54.3, 2.53.3, 2.52.4, 2.51.5, maint-2.43). No unresolved discussions or controversial changes. The fixes are backported to all supported maintenance tracks, ensuring broad coverage. Tarballs are available at kernel.org and mirrored repositories. The GitLab work item link accessibility issue is now fully resolved: Toon Claes confirms that non-privileged users can access the links as of midnight CET following the release announcement.

Key technical details
- **Files and subsystems touched**: xdiff (size_t overflow checks), `remove_signature()` (multi-signature handling), files ref backend (path traversal), protocol v2 (symref validation), `fast-import` (unsafe feature hardening), submodule gitfile parsing, merge machinery (heap corruption), HTTP header redaction.
- **New or renamed symbols**: None explicitly mentioned.
- **Behavior changes**: Rejects over-long cache entries, stricter symref validation in protocol v2, hardened `fast-import` features.
- **On-disk format changes**: None mentioned.
- **Test coverage**: Not explicitly detailed in the announcement, but CVEs are linked to advisories with reproduction details.

Open questions and loose ends
None. All vulnerabilities are addressed, and the GitLab work item link accessibility issue is resolved.
