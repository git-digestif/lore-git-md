This is a "What's cooking" report from Junio, summarizing the current state of integration branches in git.git as of November 2026. The report covers topics that have graduated to 'master', new topics under review, stalled topics, and those cooking in 'next' or 'seen'.

Key highlights from this report:

**Graduated to 'master' (since last report):**
- Several small fixes and cleanups, including documentation updates (e.g., `cr/doc-gpg-ssh-key-lifetime`, `je/doc-new-git-tutorial`), test modernizations (e.g., `ot/t5300-test-path-is-file`, `tk/t5402-test-path-helper`), and performance fixes (e.g., `iw/connected-deepen-fetch-no-alternate-refs`).
- Notable graduated topics:
  - `ps/odb-object-storage-extension`: Makes the object storage format configurable via `extensions.objectStorage`.
  - `ps/odb-reload-alternates`: Fixes a performance bug where alternates were not reloaded during concurrent repository rewrites.
  - `jc/mark-static`: Hides several functions that were unnecessarily exposed globally.
  - `je/doc-new-git-tutorial`: Rewrites the beginner's tutorial for clarity.

**New Topics (since last report):**
- `jc/unpack-trees-repo`: Updates the unpack-trees API to avoid relying on `the_repository`.
- `bc/setup-default-hash-algo`: Ensures `git init` uses the default hash algorithm (SHA-256 in breaking changes mode).
- `hs/doc-promisor-fetch-order`: Documents the order in which promisor remotes are tried during partial clone fetches.
- `kk/test-tool-genbytes`: Replaces `test-tool genzeros` with a native `genbytes` helper to avoid slow `tr` on macOS.
- `kj/repo-info-more-path-keys`: Extends `git repo info` to output more repository path keys (e.g., `path.git-prefix`, `path.superproject-root`).

**Stalled Topics (no progress for a while):**
- `ap/http-preserve-wwwauth-redirect`: Preserves WWW-Authenticate headers across HTTP redirects.
- `vv/branch-recurse-no-start-ref`: Fixes a crash in `git branch --recurse-submodules` when the start point is not a ref.
- `ec/commit-fixup-options`: Adds `-m/-F/-c/-C` support to `git commit --fixup`.
- `js/coverity-overflow-fixes`: Fixes integer overflows reported by Coverity.
- `mc/repo-structure-filtering`: Adds filtering options to `git repo structure`.

**Cooking Topics (in 'next' or under active review):**
- **Performance and CI optimizations:**
  - `ps/ci-speedups`: Optimizes GitLab CI by building optimized binaries with Meson and speeding up tests with reftables.
  - `ps/storage-format-improvements`: Improves handling of reference and object storage formats with payloads.
- **Bugfixes and correctness:**
  - `jt/object-file-error-handling`: Improves error handling in object file writing paths.
  - `ps/grep-recurse-submodules-fix`: Fixes a regression in `git grep --recurse-submodules`.
  - `ik/fsmonitor-untracked-cache-trivial-response`: Fixes stale untracked cache entries after FSMonitor trivial responses.
  - `kk/quarantine-alternate-refs`: Fixes a performance issue where hidden refs were loaded unnecessarily during connectivity checks.
- **Refactoring and cleanup:**
  - `ps/commit-graph-write-refactor`: Refactors commit-graph writing code in preparation for pluggable backends.
  - `ps/rerere-subcommands`: Converts `git rerere` subcommand parsing to use `OPT_SUBCOMMAND()`.
  - `oa/merge-without-the-repository`: Removes reliance on `the_repository` in merge.c.
- **New features and enhancements:**
  - `hn/reflog-operations`: Adds `%gb` to `git reflog` to show the branch name for each entry.
  - `hn/fetch-shallow-v2-fix`: Optimizes shallow boundary computation for protocol v2 fetches.
  - `hn/status-push-rebased-on-newer-upstream`: Improves `git status` and `git push` advice for rebased branches.
  - `mv/log-follow-speedup`: Optimizes rename detection in `git log --follow` for non-linear history.

**Discarded Topics:**
- Several topics were discarded due to lack of interest or because they were superseded by other work (e.g., `ds/fsmonitor-invalidate-untracked` was replaced by `ik/fsmonitor-untracked-cache-trivial-response`).

**Notable Observations:**
- The `the_repository` removal effort continues to progress, with several topics (`oa/bundle-uri-drop-the-repository`, `oa/range-diff-repo`, `oa/merge-without-the-repository`) graduating or cooking.
- The object storage and ref storage format work (`ps/odb-object-storage-extension`, `ps/storage-format-improvements`) is nearing completion, enabling more flexible backends.
- Performance optimizations in CI and testing (`ps/ci-speedups`, `ps/ci-consolidate-test-variables`) are a recurring theme, reflecting ongoing efforts to reduce build and test times.
- Several topics address long-standing edge cases or regressions (e.g., `ps/grep-recurse-submodules-fix`, `hn/fetch-shallow-v2-fix`), indicating a focus on correctness and robustness.
