This is the third patch in Justin Tobler’s four-patch series that makes Git’s ODB transaction machinery more robust by creating the temporary object directory eagerly at transaction start.  The patch itself is a small but critical correctness fix: it preserves `errno` across cleanup in `tmp_objdir_create()` so that callers can reliably inspect why directory creation failed.  The change touches only `tmp-objdir.c` and its header, adding a few lines to save and restore `errno` around `mkdtemp()` and `setup_tmp_objdir()` calls.  The commit message explains that this is a prerequisite for the next patch, which will report more specific errors when eager creation fails.  No controversy is evident; the patch is mechanical and well-scoped.
