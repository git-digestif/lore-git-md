This is a test infrastructure patch that introduces `test-tool genbytes` to eliminate a performance bottleneck in Git's test suite on macOS. The patch is the culmination of a three-iteration series and is now ready for submission.

The problem is concrete: tests that generate large amounts of data by piping `test-tool genzeros` through `tr(1)` run unacceptably slowly on macOS—up to 70–79% slower in CI—because macOS’s `tr` processes every byte through `getwchar()`/`putwchar()`, even in the C locale. The new `genbytes` command writes arbitrary bytes directly, bypassing `tr` entirely. The interface is simple: `test-tool genbytes <char> [<count>]` writes `<count>` copies of `<char>` (or an endless stream if `<count>` is omitted), while `genzeros` is preserved for callers that specifically need NUL bytes.

The implementation is clean and conservative. The code lives in `test-genzeros.c` (no file rename), uses a static 256 KB buffer to avoid stack pressure, and parses counts with `git_parse_signed()` for idiomatic error handling. The patch updates 14 test scripts to use `genbytes` instead of `genzeros | tr`, touching files like `t4205-log-pretty-formats.sh`, `t5300-pack-object.sh`, and `t0613-reftable-write-options.sh`. Performance measurements in the commit message show macOS CI jobs improving from ~800–900 seconds to ~200 seconds, while Linux jobs see modest gains of 2–7%.

All design decisions are settled. The two-command interface (`genzeros` for NUL, `genbytes` for arbitrary bytes) was endorsed by Patrick Steinhardt and Johannes Sixt after earlier proposals (hexadecimal byte specification, chunked `printf` helpers) were ruled out due to readability, reliability, or performance concerns. Junio C Hamano’s last open question—whether the buffer should be static or on the stack—was resolved in favor of static to avoid stack exhaustion, with no thread-safety concerns for this run-once helper. The series is well-motivated, thoroughly tested, and addresses a real pain point for macOS contributors. It looks ready to merge.
