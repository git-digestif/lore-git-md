This is the ninth patch in Karthik Nayak’s 20-patch **test modernization** series that splits the monolithic `t9300-fast-import.sh` into smaller, self-contained files. This patch focuses on the “big blob” tests (series R in the original file). Instead of importing blobs in one test and inspecting them in three follow-up tests that all depend on the same repository state, the patch folds everything into a single test that creates a fresh repository, imports the blobs, and immediately verifies the pack, the blob contents, and that the blob is stored only once. The legacy `verify_packs()` helper is replaced with an inline loop, and `fastimport.unpackLimit=0` is set to ensure a pack is written. The result is a cleaner, isolated test that can be moved to its own file in a later patch without breaking anything. No behavior change, just test hygiene.
