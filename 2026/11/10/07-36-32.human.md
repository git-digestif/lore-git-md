This is the second patch in a 15-part bugfix series that systematically eliminates Git segfaults triggered by unvalued config keys. This specific patch targets the ODB (object database) subsystem, fixing crashes in `git fetch`, `git receive-pack`, and `git rev-list --alternate-refs` when `core.alternateRefsCommand` or `core.alternateRefsPrefixes` are set without values (e.g., `git -c core.alternateRefsCommand`).

The fix replaces `repo_config_get_value()` with `repo_config_get_string_tmp()` for both config keys, ensuring missing values are rejected with `config_error_nonbool()` rather than being passed as NULL to `strvec_push()` or `strvec_split()`, which would cause a segfault. The change is minimal and follows the established pattern from the first patch in the series. A new test in `t/t5618-alternate-refs.sh` verifies the error message and prevents regressions.

The test coverage is thorough, and the change aligns with the series' overall goal of hardening config parsing.
