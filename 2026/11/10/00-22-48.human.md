This is a small preparatory patch in Justin Tobler’s four-part series to make Git’s ODB transaction machinery more robust. It renames the default prefix for the temporary directory used during "files" ODB transactions from `"bulk-fsync"` to `"transaction"`. The old name reflected the original purpose of the directory—batching fsyncs for loose objects—but the directory is now used for all transactional object writes, regardless of fsync method. The rename is purely internal and has no user-visible effect.

The change is mechanical (one line in `object-file.c`) and uncontroversial. It sets the stage for the later patches in the series, which will make temporary-directory creation eager rather than lazy. Justin is a regular contributor to the ODB abstraction effort, and this patch is consistent with the ongoing work to clean up and generalize Git’s object storage layer.
