This is an **announcement** of Git for Windows 2.56.1, a security-focused release from Johannes Schindelin.

The update addresses six critical security vulnerabilities (CVE-2026-111760, CVE-2026-113408, CVE-2026-114466, CVE-2026-114467, CVE-2026-114469, and CVE-2026-105437). The most severe is CVE-2026-111760, which allows remote code execution during recursive clones by exploiting symbolic links in gitfiles to overwrite hooks or config with malicious code. Other issues include path traversal in ref updates, stack corruption from GPG signatures, buffer overflows in merge handling, and bypassed size checks for binary patches. These vulnerabilities affect core Git operations like cloning, merging, and patch application, with potential for denial-of-service or arbitrary code execution.

The release bundles upstream Git v2.56.1, which presumably contains the fixes for these CVEs. No new features are highlighted beyond the security patches. Downloads are available for multiple architectures (x86_64, ARM64, 32-bit) and variants (full installer, portable, MinGit, and busybox-based builds), each with SHA-512 checksums for verification.

This is a **Git for Windows** release, not an upstream Git release—users of Git on other platforms should watch for a corresponding upstream announcement. The urgency of these fixes suggests administrators should prioritize upgrading, especially in environments where users interact with untrusted repositories. The announcement itself is clear and actionable, listing each CVE with enough detail to assess risk without requiring deep technical investigation.
