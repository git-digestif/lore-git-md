This is a security-focused maintenance release announcement for Git. Junio C Hamano announces coordinated releases across seven maintenance tracks (2.56.1 down to maint-2.43) to address six CVEs discovered by Luke Martin and pwn2addr, with fixes implemented by Toon Claes, Karthik Nayak, Kaartic Sivaraam, and others. The vulnerabilities include remote code execution via malicious submodule gitfiles (CVE-2026-111760), path traversal in the files ref backend (CVE-2026-113408), stack corruption from multi-signature commits (CVE-2026-114467), out-of-bounds reads from oversized binary patches (CVE-2026-114469), heap corruption during large merges (CVE-2026-105437), and unsafe `fast-import` features (CVE-2026-114466). Defense-in-depth hardening (e.g., rejecting over-long cache entries) and CI/build system updates (macOS 15, Debian 12, OpenSSL 4.0 compatibility) are also included.

The release notes detail each CVE’s impact and mitigation, with links to GitHub/GitLab advisories. Notable technical changes include size_t overflow checks in xdiff (Kaartic Sivaraam), multi-signature handling in `remove_signature()` (Karthik Nayak), and protocol v2 symref validation (Toon Claes). Jeff King contributed 30 patches, primarily addressing const-correctness warnings and HTTP header redaction. Johannes Schindelin coordinated the release and fixed CI issues (e.g., sudo-rs on Ubuntu 25.10, macOS iconv workarounds). The tarballs are available at kernel.org and mirrored repositories.

This is a critical update for all users, particularly those using recursive clones, `git merge` with signed tags, or `fast-import`. The fixes are backported to all supported maintenance tracks, ensuring broad coverage. The announcement credits the coordinated effort across multiple contributors, highlighting the project’s response to security disclosures. No controversial changes or unresolved discussions are noted.
