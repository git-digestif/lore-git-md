Thread identity: Subject "[PATCH 0/4] odb: eagerly create tmp-objdir at transaction start", series version v1, originating author Justin Tobler, thread type patch series (correctness/refactoring) within the ODB abstraction effort.

Core problem or goal: The series addresses a correctness gap in Git's ODB transaction machinery where the temporary directory is created lazily on first object write, causing some writes (those not using batched fsync) to bypass the temporary directory entirely. The goal is to make temporary-directory creation eager at transaction start so all transactional object writes go to the temporary directory immediately.
