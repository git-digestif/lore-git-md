This thread is a small but correct fix to Polish (and other complex-plural-language) output in `git add -p`: the "Split into %d hunks" message shown when a hunk is split was wrapped in the singular-only `_()` gettext macro, producing ungrammatical results like "2 skrawków" instead of "2 skrawki". The patch replaces it with the plural-aware `Q_("Split into %d hunk.", "Split into %d hunks.", splittable_into)` in `add-patch.c`, a three-line change with no effect on English output and no test updates needed. The issue was originally flagged by Mahmoud in March 2026 but went unaddressed until now.

The series is now at version 2, posted by Abhishek Agarwal -- the same contributor who sent v1 under the pseudonym aeron-gh as part of a GSoC 2027 microproject. The v2 revision contains no code changes: it rebases onto current master, switches the sign-off from the pseudonym to the author's real name, and improves the commit message by adding an explicit note that translators of languages with only singular/plural forms (e.g., German) must now translate the message twice, a trade-off suggested by Junio on a similar patch.

Nothing has been decided yet -- the patch remains under review with no objections or Reviewed-by trailers recorded. It is narrowly scoped and appears uncontroversial, so the only open item is whether Junio or another reviewer picks it up; the broader question of whether other plural-sensitive messages elsewhere in the codebase need the same `Q_()` treatment remains unaddressed.
