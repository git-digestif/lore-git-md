This is the seventh patch in Thomas Bachem’s 15-patch bugfix series that systematically eliminates Git segfaults when config keys are given without values. This installment fixes a crash in `git blame` when either `color.blame.repeatedLines` or `color.blame.highlightRecent` is set without a value (e.g., `git -c color.blame.repeatedLines blame file.c`). The patch adds NULL checks in `git_blame_config()` and rejects missing values with `config_error_nonbool()`, matching the existing pattern for `blame.date` and `blame.coloring`. A new test in `t/t8012-blame-colors.sh` verifies that Git emits a clear error message instead of crashing. The fix is minimal, well-motivated, and consistent with the rest of the series.
