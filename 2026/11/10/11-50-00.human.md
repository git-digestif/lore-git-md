This is a **test modernization** patch, the fifteenth in Karthik Nayak’s 20-patch series refactoring `t9300-fast-import.sh`. It makes the “cat-blob” tests self-contained by running each test in a fresh repository and converting the shared “setup: big file” test into a reusable `setup_big_file()` helper. The patch removes the last inter-test dependencies in this section of `t9300`, leaving only the final “quiet option” test still sharing state. The diff is mechanical and well-scoped: every test now starts with `git init repo` and uses `test_when_finished` to clean up, so the tests can be run in any order or in isolation. No behavior changes are introduced, and the commit message clearly explains the motivation. This continues the series’ goal of making `git fast-import` tests more maintainable.
