Originating author: Tanga Joris
Thread type: bugfix patch

Core problem or goal
The command-line completion for `git annotate --<TAB>` incorrectly offers `git diff` options instead of `git annotate`'s own options. This happens because `cmd_annotate()` redundantly prepends `"-c"` to the argument list before calling `cmd_blame()`, which confuses the completion helper. The fix removes this redundant prepending, letting `cmd_blame()` handle `annotate` vs `blame` internally as it already does.
