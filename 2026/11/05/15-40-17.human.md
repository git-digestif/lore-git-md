This is a documentation patch that revises the EXAMPLES section of the `git diff` man page. Julia Evans has sent a second version (`v2`) of her rewrite, incorporating some—but not all—of the feedback from Junio C Hamano.

The new version replaces the table-based layout with AsciiDoc horizontal definition lists, keeping the description and command side-by-side for better readability. It also restores the `AUTO_MERGE` example (reworded to use “merge conflict” instead of “textual conflict”) and now lists both `--staged` and `--cached` as synonyms, with `--cached` still listed first in the synopsis. The five subsections (uncommitted changes, specific files/directories, branches/commits, summarizing output, and alternative displays) remain, and cross-references to option definitions are preserved.

Junio’s two remaining objections are still unresolved: he dislikes the horizontal definition-list format because it wraps awkwardly on 80-column terminals and makes cut-and-paste harder, and he wants `--staged` to replace `--cached` consistently throughout the entire man page rather than just in one example. Julia has not yet responded to these points, so the patch is still under active discussion. No other reviewers have weighed in.
