This thread introduces a new `--show-object-format` option for `git ls-remote`, allowing tools like Jujutsu to detect a remote repository's hash algorithm (SHA-1 or SHA-256) without cloning. The feature is particularly useful for empty repositories, where the format cannot be inferred from existing objects, and addresses a concrete interoperability gap (Jujutsu issue #3813). The initial patch, submitted by Adrian Ratiu, is self-contained, touching `builtin/ls-remote.c`, documentation, and tests, and reuses existing transport APIs without protocol changes.

Patrick Steinhardt provided the first substantive review, raising three technical points. First, he suggests prefixing the output (e.g., `object-format: sha1`) to ensure forward compatibility for future extensions. Second, he notes the lack of null-checking for `transport_get_hash_algo()`, which could lead to edge-case failures. Finally, he proposes improving test ergonomics by making the test helper accept the expected format as a parameter. The review also includes minor typo and wording fixes but does not challenge the patch's core design or motivation. The thread is now awaiting Adrian's response to these actionable concerns.
