This thread is about adding a `--show-object-format` option to `git ls-remote`, letting tools like Jujutsu detect a remote repository's hash algorithm (SHA-1 or SHA-256) without cloning. The feature addresses a specific interoperability gap where empty repositories can't reveal their format, risking silent mismatches.

Adrian Ratiu sent the initial patch, which Patrick Steinhardt reviewed thoroughly. Patrick raised three technical points—output format extensibility, null-checking, and test ergonomics—and two minor wording issues. Adrian has now agreed to all feedback: he'll prefix the output (e.g., `object-format: sha1`), parameterize the test helper to reduce boilerplate, and clean up documentation wording. The null-check concern remains unaddressed in this reply, but Adrian notes the function will always return a valid pointer in this context.

The series is still under review, with no fundamental objections. Adrian plans to send a v2 patch incorporating all changes after a one-week review period. The thread remains focused on refining a well-motivated feature with clear utility for Git-based tools.
