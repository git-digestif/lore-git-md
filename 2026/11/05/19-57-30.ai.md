This is an Outreachy proposal draft from Tanga Joris targeting the December 2026 round. The project aims to improve how Git command arguments and options are scanned and parsed, addressing inconsistencies in how early requests like `-h`, `--help-all`, and `--git-completion-helper` are handled across built-in commands.

The proposal is well-structured and demonstrates deep engagement with the Git codebase. Tanga has already contributed several patches to Git, including a microproject (merged to `master`), a four-iteration series removing `NO_PARSEOPT` from built-ins, and a fix for `git annotate` that prevents a segfault when `--git-completion-helper` is used outside a repository. These contributions show a clear understanding of the problem space and the ability to navigate the review process. The proposal also includes active participation in bug triage and patch reviews for other contributors.

The plan is concrete and incremental. It starts by making entry points consistent (e.g., ensuring `--git-completion-helper` works outside a repository for all commands), then converts specific commands like `merge-index` where option parsing order currently matters, and finally explores a "dry run" mode for `parse_options()` to unify early scanning. Each step is tied to a user-visible improvement or test coverage. The timeline is realistic, with fallback options if progress stalls.

Tanga’s motivation and technical preparation are strong. The proposal references prior art (Christian Couder’s `early-scan-options` series) and aligns with Junio’s stated long-term direction for `parse-options`. The focus on testing—ensuring every change is guarded by a failing test on `master`—is particularly noteworthy and reflects a mature approach to refactoring.

This looks like a promising project with clear value for Git’s usability and maintainability. The proposal is detailed enough to give confidence in its feasibility, and Tanga’s track record suggests they can execute it effectively. The mailing list feedback on sections 4 and 5 will likely refine the plan further, but the core direction is sound.
