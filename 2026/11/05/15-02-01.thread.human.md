This thread is Patrick Steinhardt’s five-patch series laying the groundwork for Git’s test suite to run with alternative object storage backends. The goal is to allow tests to specify a non-default backend via `GIT_TEST_DEFAULT_OBJECT_STORAGE_FORMAT`, exposing hard-coded assumptions about `.git/objects` by attaching payloads (like `files://objdir`) to the default format string. The series is currently under review at v1, with no merge status claimed.

The technical work focuses on test infrastructure: ref backends and the "files" object backend now create missing leading directories when initializing, and `setup.c` and `rev-parse` have been extended to parse and print payloads for both object and ref storage formats. The series touches `refs/`, `odb/`, `setup.c`, and `builtin/rev-parse.c`, and updates tests in `t0001-init.sh`, `t1423-ref-backend.sh`, and `t1500-rev-parse.sh`. No on-disk format changes are introduced—this is purely preparatory.

The main loose end is the ~1100 failing tests under the new regime, which are deferred for follow-up. No alternative backend exists yet, so the payload mechanism remains a placeholder. So far, only Patrick has weighed in, and the series is part of his broader ODB abstraction effort.
