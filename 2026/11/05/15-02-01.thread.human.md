This thread is about preparing Git’s test suite to support non-default object storage backends, a key step in Patrick Steinhardt’s ongoing ODB abstraction effort. The five-patch series introduces the `GIT_TEST_DEFAULT_OBJECT_STORAGE_FORMAT` environment variable, mirroring the existing ref storage counterpart, and adds payload support (e.g., `files://objdir`) to expose tests that hard-code assumptions about `.git/objects`. While ~1,100 tests currently fail under this new regime, fixing them is deferred to follow-up work.

The series is under review but not yet merged, with no objections to its technical approach. Karthik Nayak provided substantive feedback on test design in `t1423-ref-backend.sh`, suggesting a simplification, but Patrick declined, arguing the current implementation better tests payload interaction. Junio C Hamano’s review of the final patch was surface-level, catching only a typo and an unrelated merge conflict, which Patrick addressed locally. The series remains at v1, based on Patrick’s `ps/odb-object-storage-extension` branch, and is ready for integration unless new concerns arise. No alternative object storage backend exists yet, so the payload mechanism is a placeholder for now.
