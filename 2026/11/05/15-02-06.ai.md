This is the final patch in Patrick Steinhardt’s five-part series preparing the Git test suite for non-default object storage backends. It adds the `GIT_TEST_DEFAULT_OBJECT_STORAGE_FORMAT` environment variable to `t/test-lib.sh`, defaulting it to the "files" backend. The patch is purely test infrastructure: it does not introduce a new backend or fix any failing tests, but it enables the ~1100 tests that currently break when objects are moved out of `.git/objects` to be identified and deferred for later repair. The change is minimal (four lines) and mechanical, mirroring the existing `GIT_TEST_DEFAULT_REF_STORAGE_FORMAT` plumbing.
