This is Junio’s biweekly "What’s cooking in git.git" report for early November 2026, summarizing the state of 130+ in-flight topics across the integration branches.

The report is a snapshot of what Junio considers ready for the next release, what is still being polished, and what has stalled.  It is not a review of the patches themselves—only a status dashboard.

### What graduated to master
A dozen small, uncontroversial patches landed in the last cycle.  Highlights:
- **`dk/stash-completion-updates`** finally drops the deprecated `stash save` subcommand from shell completion and fixes a Zsh quoting bug.
- **`jc/advice-config-set-global`** makes the advice subsystem suggest `--global` when recommending config snippets, since user-level advice settings belong in the global scope.
- **`je/doc-merge-conflicts`** adds a new `gitmergeconflicts(7)` man page and links every command that can encounter conflicts to it.
- **`tb/ci-pin-actions`** pins GitHub Actions to full commit IDs in the main workflow, hardening the CI environment against supply-chain attacks.
- **`pw/allow-compound-literals`** officially blesses C99 compound literals in the coding guidelines after a two-year trial period.

### New topics that look ready
Junio has marked these as “Will merge to next?”, meaning they are likely to graduate in the next cycle unless last-minute objections surface.

- **`kk/connectivity-check-ignore-replace`** teaches `rev-list --objects` to ignore replacement refs during connectivity checks, matching the behavior of `fsck` and `pack-objects`.
- **`tc/security-boundary-doc`** adds `gitsecurityboundary(7)`, a new document that spells out Git’s security boundary and what counts as a vulnerability.
- **`jc/freeze-repo-config-values`** freezes the `struct repo_config_values` API to discourage new fields until the repository settings cleanup lands.
- **`rm/http-retry-improvements`** overhauls HTTP retries: exponential backoff without `Retry-After`, configurable transient status codes, and retries for POST operations like `git-upload-pack`.
- **`ep/pack-objects-streamed-large-blobs-fix`** fixes a 32-bit truncation bug when streaming blobs larger than 4 GiB on 64-bit Windows.
- **`hn/ci-ubuntu-26.04-fixes`** works around Ubuntu 26.04 CI breakages: networking in the `linux32` job, permission issues when replacing system binaries, and `apt-get` vs `apt` CLI stability.
- **`ps/odb-loose-stale-cache`** fixes a race in the loose-object cache that could cause existence checks to fail for newly written objects, breaking lazy fetches in partial clones.
- **`cd/shift-root-in-graph-fix`** stops the graph renderer from mis-indenting visual roots when columns lie to their right.
- **`ps/commit-graph-write-refactor`** (10 patches) consolidates the commit-graph writer flags into a single options structure, paving the way for pluggable backends.
- **`ps/ci-consolidate-test-variables`** deduplicates test environment setup in CI, reducing redundancy and speeding up the test matrix.

### Topics needing review or a reroll
- **`kk/quarantine-alternate-refs`** optimizes the quarantine connectivity check by skipping the repository’s own refs when listing alternate refs.  Peff requested a reroll to clarify the commit message.
- **`je/doc-git-diff-examples`** rewrites the `git diff` EXAMPLES section as a cheat sheet.  Eric Sunshine asked for a few wording tweaks.
- **`tj/drop-no-parseopt`** removes `NO_PARSEOPT` from commands that now use `parse-options`, so they appear in `git --list-cmds=parseopt`.  Junio asked for a follow-up to handle `git fast-import`’s stdin blocking.
- **`ds/fsmonitor-invalidate-untracked`** and **`ds/path-walk-tagged-tree-revisit`** are two correctness fixes from Derrick Stolee that need a second set of eyes.
- **`ps/grep-recurse-submodules-fix`** fixes a regression in `git grep --recurse-submodules` where nested trees in submodules were not read.  The fix also plugs latent bugs in `grep_cache()` and `grep_objects()` that still referenced `the_repository`.
- **`ps/rerere-subcommands`** (12 patches) converts `git rerere` to `OPT_SUBCOMMAND()`, removing ad-hoc parsing.  Junio asked for a final polish pass on the usage strings.

### Stalled topics
Several long-running efforts remain stalled without recent activity:
- **`mh/rust-crate-subdir`** (moving Rust code to `rust/`) has seen no uptake since September.
- **`tb/midx-incremental-custom-base`** (fixing `--base` in incremental MIDX writes) has been waiting for a reroll since June.
- **`mm/diff-process-hunks`** (external hunk providers via `diff.<driver>.process`) has been stalled since August.
- **`mc/refs-rename-transaction`** (unifying ref rename/copy under transactions) breaks `seen` when merged and needs a rethink.
- **`pm/replay-add-signing-support`** (GPG signing in `git replay`) has been waiting for a response since late September.

### Notable ongoing efforts
- **`ps/odb-object-storage-extension`** (configurable object storage backends via `extensions.objectStorage`) graduated to `next` and looks ready for master.
- **`hn/remote-simple-push-triangular`** makes `@{push}` resolution mirror `git push` behavior when the push remote differs from the fetch remote.
- **`ps/odb-reload-alternates`** reloads alternates on retry, restoring the ability to find objects moved to a newly added alternate during a concurrent repository rewrite.
- **`tb/sideband-skip-unrecognized-allow-control-characters`** fixes an infinite loop in the sideband config parser when an unknown control character keyword is encountered.
- **`hn/branch-delete-merged-squash`** adds `--delete-integrated` to `git branch` to find and remove branches whose work has been squash-merged or rebase-merged, by comparing blobs of changed files.

### Low-hanging fruit for reviewers
If you are looking for something small to review:
- **`hn/ccache-sloppiness-for-pch`** exports `CCACHE_SLOPPINESS` to allow `ccache` to cache objects built with the precompiled header.
- **`sm/test-chmtime-parse-options`** converts `test-chmtime` to `parse_options()`.
- **`ag/fsck-connectivity-count`** makes `git fsck` report the actual object count in its “Checking connectivity” message instead of the hash bucket size.
- **`sp/diff-delta-safe-arithmetic`** hardens the delta index allocation with safe integer helpers.
- **`os/rebase-doc-incompatible-options`** cleans up outdated cross-references in the `git rebase` documentation.

### Summary
The integration branches are in good shape for the upcoming release.  The main action is on the new HTTP retry logic, the commit-graph writer refactoring, and the loose-object cache fix—all of which are close to graduation.  Reviewers are encouraged to focus on the “needs review” and “expecting a reroll” sections to help clear the backlog.
