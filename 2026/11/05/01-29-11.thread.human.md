This "What's cooking" report from Junio Hamano gives a snapshot of Git development as of November 2026. The most significant recent changes include the graduation of several user-facing improvements: stash completion updates, a new `gitmergeconflicts(7)` man page, HTTP retry improvements with exponential backoff, and the introduction of object storage backend configuration via `extensions.objectStorage`.

The integration branches are cooking with about two dozen active topics. Notable among these are Patrick Steinhardt's ongoing ODB abstraction work (`ps/odb-object-storage-extension`, `ps/odb-reload-alternates`), which continues to advance pluggable object storage, and several repository context cleanups removing reliance on `the_repository`. Han-Wen Nienhuys has contributed multiple user-facing changes, including a new `--delete-integrated` option for branch deletion and modified `git status` behavior that now compares against both upstream and push branches by default - both of which may prove contentious due to their potential to disrupt existing workflows.

Several stalled topics await rerolls or responses, including Rust-related work (`mh/rust-crate-subdir`) and MIDX incremental write improvements. The documentation effort continues with a new beginner-focused tutorial and security boundary documentation. CI improvements remain a focus, with recent changes hardening workflows against supply-chain attacks and addressing Ubuntu 26.04 runner issues.
