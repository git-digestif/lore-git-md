This is the second patch in Patrick Steinhardt’s five-part series preparing Git’s test suite for ODB abstraction. It extends the "files" object backend (`odb/source-files.c`) to create leading directories when initializing on-disk storage, mirroring the behavior already added to the ref backends in the previous patch. The change is minimal: a single call to `safe_create_leading_directories_no_share()` before creating the object directory. The test script `t/t0001-init.sh` is updated to verify that nested paths (e.g., `files:///absolute/objdir`) are handled correctly, replacing the old flat-path test with one that uses a two-level directory structure. No new symbols or environment variables are introduced; this is purely a plumbing fix to ensure the backend can be instantiated at arbitrary locations.
