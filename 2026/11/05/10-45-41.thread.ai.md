Thread identity: Patch series introducing `--show-object-format` option to `git ls-remote` to query a remote repository's hash algorithm (SHA-1/SHA-256) without cloning. Originating author: Adrian Ratiu. Thread type: patch series (single patch).

Core problem or goal: Enable Git-based tools (notably Jujutsu) to detect a remote repository's object format upfront, preventing silent mismatches—especially critical with empty repositories where the format cannot be inferred from existing objects. The change addresses a concrete interoperability gap (JJ issue #3813) by exposing the hash algorithm via an existing transport API.

Current status: Under review. Version: v2 (addresses all feedback from v1). No merge status change; remains in review.

- Implementation: reuses `transport_get_hash_algo()`; null-check on the returned pointer remains unresolved (Patrick flags it as a broader robustness concern, but Adrian considers it unnecessary in this context).
