This is the fourth patch in Patrick Steinhardt’s five-patch series preparing the Git test suite for ODB abstraction. It extends ``git rev-parse --show-ref-storage-format`` to print the payload (e.g., ``files:///path/to/refdir``) when one is present, matching the behavior already implemented for ``--show-object-storage-format``. The change is mechanical: the code in ``builtin/rev-parse.c`` now checks ``the_repository->ref_storage_payload`` and formats the output accordingly, and ``t/t1500-rev-parse.sh`` gains a single test that verifies the new output format. No new symbols or environment variables are introduced; the patch simply exposes existing repository state. The diff is small (14 lines added, 1 removed) and self-contained.
