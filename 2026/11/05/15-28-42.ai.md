This is the final patch in Aniket Gupta's three-part bugfix series for the bundle-uri subsystem. It changes the code to stop dying when it encounters an unresolvable relative URI in a bundle list, instead reporting the error and skipping the problematic bundle.

The patch replaces the direct call to `relative_url()` (which dies on failure) with `relative_url_gently()` (which returns NULL and populates an error message). When the gentle variant fails, `bundle_list_update()` now logs the error, leaves the bundle's URI unset, and returns -1. The download code already skips bundles without URIs, so the operation continues with the remaining bundles. The test in `t5750-bundle-uri-parse.sh` is updated to match the new behavior: instead of expecting a fatal error, it expects two non-fatal errors (one for the anonymized URL and one for the bad line) and verifies that the rest of the bundle list is parsed correctly.

The change is confined to `bundle-uri.c` and its test file, with no cross-subsystem impact. The commit message is clear and the test expectations are tightened to match the new behavior. This patch completes the series, which is now ready for substantive review.
