This is the fifth patch in Okhuomon Ajayi’s six-patch series refactoring the notes subsystem to remove implicit uses of the global `the_repository`. The patch updates the `combine_notes` callbacks—`combine_notes_concatenate()`, `combine_notes_overwrite()`, `combine_notes_ignore()`, and `combine_notes_cat_sort_uniq()`—to accept an explicit `struct repository *` parameter, allowing them to operate on the correct repository when combining notes from different trees.

The change is mechanical and well-scoped: each callback now uses the passed repository instead of `the_repository` when reading or writing note blobs via the object database. The patch also updates `copy_note()` to use the tree’s hash algorithm for its null object ID, ensuring consistency. The updated function signatures are reflected in `notes.h`, and the callbacks are invoked with `t->repo` in `note_tree_insert()`.

No user-visible behavior changes are introduced, and the patch maintains the existing API contract while making it repository-agnostic. The series as a whole is part of the ongoing `the_repository` removal effort, and this patch directly addresses the architectural concern Patrick Steinhardt raised by eliminating the need for downstream guards. The patch is clean, well-explained, and ready for review from René Scharfe (the `the_repository` removal driver) and others familiar with the notes subsystem.
