This is the second patch in Aniket Gupta’s three-patch bugfix series for the bundle-uri subsystem. It plugs a minor but real information-disclosure hole: when `relative_url_gently()` (introduced in patch 1) fails to resolve a relative URI, the error message it generates now anonymizes any credentials that were present in the original URL before printing it. The patch also improves diagnosability by showing the full, unmodified input URL rather than a partially-stripped version.

The change is confined to `remote.c` and adds a single test in `t0060-path-utils.sh` that verifies the anonymization works when the helper fails. The implementation is straightforward: `transport_anonymize_url()` is called on the original URL, the anonymized string is used in the error message, and the temporary string is freed. The test covers the credential case explicitly, ensuring the fix is exercised.

This patch is a direct follow-up to the gentle-helper refactoring in patch 1 and is needed before patch 3 can safely use that helper in the bundle-uri code path. It is small, well-motivated, and uncontroversial.
