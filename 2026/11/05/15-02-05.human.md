This is a small but necessary patch in Patrick Steinhardt’s five-part series preparing Git’s test suite for pluggable object storage backends. It extends `` `git rev-parse --show-ref-storage-format` `` to print the payload (e.g., ``files:///path/to/refdir``) when one is configured, matching the behavior already implemented for ``--show-object-storage-format``. The change is mechanical: a single conditional printf in ``builtin/rev-parse.c`` and a new test in ``t1500-rev-parse.sh`` that verifies the payload is printed correctly. No controversy or open questions here—just symmetry with the object-storage side. If the series as a whole looks worth following, this patch is a safe, uncontroversial step.
