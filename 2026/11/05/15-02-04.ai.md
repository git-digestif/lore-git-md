This is the third patch in Patrick Steinhardt’s five-patch series preparing the Git test suite for ODB abstraction. It extends the existing logic that parses default storage formats (`init.defaultRefStorageFormat`, `init.defaultObjectStorageFormat`, and their environment-variable equivalents) to allow payloads—e.g., `files:///path/to/objdir`—to be attached to the format string. The patch touches `setup.c` to parse these payloads and `t/t0001-init.sh` to add tests that verify the payload is correctly recorded in the repository’s configuration and that the specified directory is created. No on-disk format changes are introduced; this is purely test infrastructure plumbing. The patch is clean, well-tested, and directly advances the series’ goal of making the test suite backend-agnostic.
