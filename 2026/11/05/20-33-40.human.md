This is the second patch in Okhuomon Ajayi’s six-patch series refactoring the notes subsystem to remove implicit uses of the global `the_repository`. The patch updates five core functions in `notes.c`—`note_tree_find()`, `add_non_note()`, `load_subtree()`, `remove_note()`, and `format_note()`—to read object data and hash algorithms from the repository stored in `struct notes_tree` (`t->repo`) instead of `the_repository`.

The changes are mechanical and narrowly scoped: each function now uses `t->repo->hash_algo` for hash operations and `t->repo->objects` for object database access. The patch maintains the existing behavior while making the API repository-agnostic, which aligns with the series’ goal of eliminating the need for downstream guards like `USE_THE_REPOSITORY_VARIABLE`. No user-visible changes or on-disk format modifications are introduced.

This patch builds directly on the first patch in the series, which added the `repo` field to `struct notes_tree` and updated `init_notes()` and `load_notes_trees()` to populate it.
