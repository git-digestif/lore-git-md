This patch adds a `--show-object-format` option to `git ls-remote`, allowing users to query the hash algorithm (e.g., `sha1` or `sha256`) used by a remote repository without cloning it. The feature is motivated by interoperability needs with Jujutsu (JJ), which uses Git for networking and requires knowing the remote's object format upfront to avoid silent mismatches—especially problematic with empty repositories. The implementation is minimal: the option prints the format on its own line before listing references, leveraging existing transport infrastructure (`transport_get_hash_algo`). Tests cover both SHA-1 and SHA-256 repositories, empty and non-empty, across protocol versions (v0 and v2), and confirm the option works outside a Git repository.

The patch is well-scoped and addresses a clear gap in Git's remote inspection capabilities. The commit message explains the problem concretely (silent format mismatches with empty repos) and ties it to a real-world use case (JJ issue #3813). The code changes are straightforward, reusing established APIs, and the test coverage is thorough, including edge cases like nongit environments. The documentation update is clear and includes a practical example of why the feature matters. This looks like a solid, uncontroversial addition that fills a genuine need for tools building on Git's protocol.
