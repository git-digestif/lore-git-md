This is the first patch in Patrick Steinhardt’s five-patch series preparing the Git test suite for ODB abstraction. It is a small but essential refactoring of the ref backends.

The patch makes both the "files" and "reftable" ref backends automatically create any missing leading directories when they initialize. Previously, if a user specified a non-default ref location (e.g., `files://refdir`), Git would die unless the directory already existed. Now, Git creates the directory on demand, making the feature more ergonomic. The change uses `safe_create_leading_directories_no_share()` to avoid adjusting permissions on directories outside the repository.

Files touched: `refs/files-backend.c`, `refs/reftable-backend.c`, and the test script `t/t1423-ref-backend.sh`. The test script gains a new loop that verifies both backends correctly create their payload directories (`refdir/refs` for "files", `refdir/reftable` for "reftable") when given a format string with a payload. No new symbols are introduced; the patch simply adds a single line to each backend’s `create_on_disk` function.

The patch is clean, well-motivated, and directly supports the series’ goal of making the test suite backend-agnostic. It is a straightforward mechanical change with no behavioral impact beyond the new directory-creation behavior.
