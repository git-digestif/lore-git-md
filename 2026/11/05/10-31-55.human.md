This is a documentation patch that updates `Documentation/technical/api-parse-options.adoc` to reflect the current state of the `parse-options` API. Karthik Nayak adds missing flags (`PARSE_OPT_ONE_SHOT`, `PARSE_OPT_SHELL_EVAL`) and macros (`OPT__VERBOSITY`, `OPT__SUPER_PREFIX`, `OPT_CONTAINS`, and many others) that have been part of the codebase for years but were never documented. The patch also fixes a missing `flags` argument in the `OPT__FORCE` macro.

The motivation is straightforward: the technical documentation should match the header file (`parse-options.h`) so that developers can rely on it when writing new commands or reviewing existing ones. Some of the newly documented features are rarely used, but Karthik argues that complete documentation makes it easier for contributors to choose the right tool for the job. The commit message is clear and the diff is mechanical, touching only the documentation file. No code behavior changes, so this is a pure housekeeping update that looks uncontroversial and well-motivated.
