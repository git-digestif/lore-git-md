This is an Outreachy internship proposal for the December 2026 cohort, targeting the Git project's ongoing effort to reduce global state to enable libification. The author, Srujith Poojary, proposes a focused investigation into a specific global dependency in Git's pathspec code: the `find_pathspecs_matching_skip_worktree()` function, which currently accesses the index via the global `the_repository->index` pointer instead of receiving it as an explicit parameter.

The proposal is thorough and well-structured, spanning 14 sections that cover the author's background, understanding of the problem, prior contributions, technical plan, risks, and timeline. The core technical goal is to refactor this function to accept a `struct index_state *istate` parameter, making its dependency explicit and improving testability and reusability. Two API approaches are considered: modifying the existing helper or extending the `find_pathspecs_matching_against_index()` API. The author emphasizes a cautious, incremental approach, with a strong focus on preserving existing behavior and thorough testing, including a proposed regression test using two separate index states.

Notable strengths include the author's hands-on preparation (four prior Git contributions, three of which are in `seen` or `next`), clear technical reasoning, and realistic scope boundaries. The proposal acknowledges risks like overlapping upstream work, sparse-checkout edge cases, and test infrastructure limitations, and includes mitigation strategies. The 13-week plan prioritizes completing one focused contribution, with follow-up work contingent on mentor approval and technical justification.

The proposal is not yet a patch or RFC, but a detailed plan for an Outreachy internship. It demonstrates a solid understanding of Git's internals, the `the_repository` removal effort, and the challenges of reducing global state. The author's communication with the community (e.g., the mailing list discussion linked in Section 9) and feedback from Usman Akinyemi are well-documented, showing engagement with the project's review culture.
