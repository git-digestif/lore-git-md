This is a reply in the ODB abstraction series, specifically addressing feedback on patch 6/10. Patrick Steinhardt responds to Kristofer Karlsson’s surface-level review of the patch that moves the last remaining optional parameters (`pack_indexes` and `commits`) into `struct commit_graph_write_options`.

Patrick acknowledges Kristofer’s stylistic suggestion to replace an `if/else` chain with a `switch` statement in `builtin/fetch.c` but does not commit to making the change, noting it is purely a matter of preference. More substantively, he floats a design idea: replacing the current loose coupling of flags and parameters with a tagged union (`mode` + `mode_args`) to make it clearer which options apply to which write modes. He sketches a diff showing how this might look but ultimately decides against pursuing it in this series, citing complexity concerns. The proposal remains a future possibility rather than an immediate change.

No new code is introduced in this email, and the discussion remains conceptual. The thread’s core goal — consolidating commit-graph write options into a single struct as part of the ODB abstraction effort — is unchanged. The tagged union idea, if adopted later, would further tighten the internal interface but is not a blocker for the current series.
