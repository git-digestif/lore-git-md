This is the third and final patch in Tanga Joris's v5 Outreachy series, adding a defensive test to catch future regressions where built-in commands are converted to use `parse-options` but retain the `NO_PARSEOPT` flag in `git.c`. The test runs `git <cmd> --git-completion-helper` for every built-in not listed in `git --list-cmds=parseopt` and fails if the command prints any long option (starting with `--`). This ensures that once a command is converted to `parse-options`, its completion behavior remains consistent and the flag is removed.

The test skips five diff-related commands (`diff`, `diff-files`, `diff-index`, `diff-tree`, `rev-list`) because they print diff options, and `rev-parse` because it echoes arguments verbatim. It does not catch `var` because that command only has short options, which the helper does not list. The patch addresses Kaartic Sivaraam's suggestion for a defensive test and incorporates feedback from the thread, though it leaves the test as a separate patch rather than squashing it into the second patch as suggested by some reviewers.

This is a test-only patch with no functional changes to Git itself. It is well-motivated and directly targets the regression the series fixes, but its coverage is limited by the inherent constraints of the `--git-completion-helper` mechanism (e.g., short options are not listed). The test is ready for review and depends on the first two patches in the series, which have already addressed all prior feedback.
