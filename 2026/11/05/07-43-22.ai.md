This is the **v3 patch** in the thread targeting the object quarantine performance regression. It implements **Jeff King’s commondir comparison approach** as the definitive short-term fix, replacing the v2/v3 quarantine-specific logic with a minimal, generic rule: skip any alternate whose path matches the repository’s own `commondir`.

The patch is a **bugfix and performance improvement** for `receive-pack`’s connectivity check. During a push, Git’s quarantine mechanism passes the repository’s own object directory as an alternate to child processes. When `rev-list --alternate-refs` runs inside the quarantine, it lists *all* refs from that alternate—including hidden ones—despite earlier work (`bcec6780b2`) explicitly excluding hidden refs from connectivity checks. This creates a measurable performance regression: in repositories with 200,000 hidden refs, the patch delivers a **65.5% speedup** (0.29s → 0.10s) for small pushes, and even without hidden refs, every ref is still listed twice, causing a **16.7% slowdown**.

The core change is a **10-line addition** in `odb.c`’s `refs_from_alternate_cb()`: it compares the alternate’s realpath against the repository’s `commondir` and skips the alternate if they match. This approach is **minimal, future-proof, and generic**, avoiding quarantine-specific heuristics entirely. The commit message now frames this as a **tightening of `--alternate-refs`’s meaning**, aligning with how Git already ignores the object directory itself when loading alternates.

The patch includes **three test files**:
- A **new perf test** (`p5552-push-hidden-refs.sh`) demonstrating the performance regression and the fix’s impact.
- **Two functional tests** in `t5547-push-quarantine.sh` verifying that:
  - The repository’s own refs are *not* listed as alternate refs during quarantine.
  - Refs from *real* alternates (other repositories) are still listed correctly.
- A **test in `t5618-alternate-refs.sh`** confirming that passing the repository’s own object directory as an alternate by hand also skips its refs.
