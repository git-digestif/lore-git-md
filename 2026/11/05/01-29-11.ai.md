This is a "What's cooking in git.git" report from Junio Hamano, summarizing the current state of integration branches and in-flight topics as of November 2026. Below is a technical digest of the key developments, organized by status and theme, to help an AI follow-up agent track future discussion.

**Graduated to master (since last report)**
These topics are now part of the next release. Notable items:
- `dk/stash-completion-updates`: Removed deprecated `stash save` from completions and documentation; fixed Zsh formatting.
- `jc/advice-config-set-global`: Advice subsystem now suggests `--global` when recommending config snippets.
- `je/doc-merge-conflicts`: New `gitmergeconflicts(7)` man page, linked from `git merge`, `rebase`, `cherry-pick`, `revert`, and `pull`.
- `je/doc-remove-gittutorial-2`: Removed obsolete `gittutorial-2` and its references.
- `pw/allow-compound-literals`: CodingGuidelines now officially allow C99 compound literals.
- `tb/ci-pin-actions`: CI workflows now pin GitHub Actions to full commit IDs for supply-chain security.
- `ps/odb-object-storage-extension`: Introduced `extensions.objectStorage` config to specify object storage backends.

**New Topics (cooking in next or seen)**
- `kk/connectivity-check-ignore-replace`: `rev-list --connectivity-check` now ignores replacement objects, aligning with `fsck` and `pack-objects`.
- `tc/security-boundary-doc`: New `gitsecurityboundary(7)` document clarifying Git’s security guarantees and user responsibilities.
- `kk/quarantine-alternate-refs`: Optimized `git-receive-pack` connectivity check to skip listing own refs as alternates during quarantine.
- `jc/freeze-repo-config-values`: Documented `struct repo_config_values` as frozen pending wider config cleanup.
- `rm/http-retry-improvements`: HTTP retry mechanism now supports exponential backoff, configurable transient status codes, and retries for POST operations.
- `ep/pack-objects-streamed-large-blobs-fix`: Fixed truncation of large object sizes on 64-bit Windows (32-bit `long`).
- `hn/ci-ubuntu-26.04-fixes`: CI fixes for Ubuntu 26.04 runner images, including networking workarounds and permission fixes.
- `ps/odb-loose-stale-cache`: Loose object cache now tracks newly written objects to avoid stale cache entries during lazy-fetch.
- `cd/shift-root-in-graph-fix`: Graph drawing logic fixed to avoid indenting visual roots when columns exist to their right.
- `ds/fsmonitor-invalidate-untracked`: FSMonitor now fully invalidates untracked cache when losing event history.
- `ds/path-walk-tagged-tree-revisit`: Path-walk traversal corrected to allow revisiting paths from tagged trees.
- `ps/commit-graph-write-refactor`: Refactored commit-graph writing code to consolidate parameters into an options struct, preparing for pluggable backends.
- `tc/push-multiple-force-with-lease`: Fixed `--force-with-lease` forwarding in `push_multiple()` to handle both bare and `<ref>:<expect>` forms.

**Stalled Topics (awaiting reroll or response)**
- `mh/rust-crate-subdir`: Rust code moved to `rust/` subdirectory; stalled without interest.
- `tb/midx-incremental-custom-base`: MIDX incremental writes now honor `--base`; stalled for reroll.
- `mm/diff-process-hunks`: External hunk provider interface via `diff.<driver>.process`; stalled for reroll.
- `ij/subtree-reject-v2-config`: Shell `git subtree` bails if Rust rewrite config is present; stalled for reroll.
- `pm/replay-add-signing-support`: `git replay` now supports GPG signing; stalled for response.
- `mc/refs-rename-transaction`: Ref rename/copy now use transactions; breaks `seen` when merged.

**Cooking Topics (under active review or testing)**
- `ps/grep-recurse-submodules-fix`: Fixed `git grep --recurse-submodules` to read submodule trees via their repository context.
- `ps/rerere-subcommands`: Converted `git rerere` subcommand parsing to `OPT_SUBCOMMAND()`.
- `ps/ci-consolidate-test-variables`: CI test environment setup deduplicated and consolidated.
- `ps/commit-graph-cleanups`: Cleaned up `git commit-graph` builtin to remove global state and `the_repository`.
- `hn/remote-simple-push-triangular`: `git rev-parse @{push}` now resolves to the push remote’s branch when fetch/push remotes differ.
- `sp/submodule-abbrev-fix`: Submodule diff headers now abbreviate commits using the submodule’s ODB.
- `oa/checkout-wo-the-repository`: `unique_tracking_name()` now takes a `struct repository` parameter.
- `hn/branch-delete-merged-squash`: New `--delete-integrated` option for `git branch` to delete squash-merged branches.
- `hn/status-compare-branches-default`: `git status` now compares against both upstream and push branches by default.
- `hn/imap-send-header-fix`: `git imap-send` now matches headers case-insensitively and accepts `Subject` before `Date`.
- `tb/sideband-skip-unrecognized-allow-control-characters`: Fixed infinite loop in sideband config parser.
- `ps/odb-reload-alternates`: ODB files backend now reloads alternates on retry, restoring concurrent repository rewrite support.
- `jt/tmp-objdir-loose-idx-merge`: Temporary object directory migration now merges loose object index correctly.
- `tb/merge-ort-valueless-rename-config`: `merge-ort` now accepts valueless `diff.renames`/`merge.renames` as `true`.

**Key Subsystems and Efforts**
- **`the_repository` removal**: Multiple topics (`oa/merge-blobs-stop-using-the-repository`, `oa/range-diff-repo`, `oa/negotiator-default-no-the-repository`) continue to thread repository context through functions.
- **ODB abstraction**: `ps/odb-object-storage-extension` and `ps/odb-reload-alternates` advance pluggable object storage.
- **Ref storage**: `tb/merge-ort-valueless-rename-config` and `mc/refs-rename-transaction` (stalled) touch ref backend behavior.
- **HTTP/transport**: `rm/http-retry-improvements` and `hn/imap-send-header-fix` improve robustness.
- **Documentation**: `je/doc-new-git-tutorial` introduces a beginner-focused tutorial; `jc/doc-gitignore-wildcard` clarifies `.gitignore` wildcards.

**Likely Points of Contention**
- `hn/branch-delete-merged-squash`: Blob-based branch deletion may surprise users expecting commit-based logic.
- `hn/status-compare-branches-default`: Changing `git status` default behavior could disrupt existing workflows.
- `ps/commit-graph-write-refactor`: Large refactor may introduce subtle bugs or regressions in commit-graph writing.

**Test and CI Improvements**
- Multiple test scripts modernized to use `test_path_is_file`/`test_path_exists` helpers.
- CI workflows hardened against supply-chain attacks (`tb/ci-pin-actions`) and Ubuntu 26.04 breakages (`hn/ci-ubuntu-26.04-fixes`).
