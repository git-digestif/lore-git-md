This is a brief exchange in the now-closed `ps/rerere-subcommands` thread, which modernized `git rerere`'s subcommand handling and was merged to `master` in June 2025. Junio C Hamano, the maintainer, asks whether his manual workflow for applying fixup commits (`git commit --fixup` followed by `git rebase --autosquash`) can be simplified. Phillip Wood suggests using `git rebase --autosquash --keep-base` to avoid counting commits, but Junio replies that he prefers not to set upstream branches for all his topic branches. He then muses about a hypothetical `git fixup` command that would combine the `commit` and `rebase` steps into one, naming only the target commit (`HEAD~10`). The exchange is purely about workflow convenience and does not reopen any technical discussion about the series itself.
