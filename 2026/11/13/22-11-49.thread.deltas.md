# Thread deltas

## 2026/11/13

- [2026/11/13/22-11-49 by Adithya Chakilam via GitGitGadget <gitgitgadget@gmail.com>] Adithya Chakilam submitted a two-patch series introducing `--filter-to-loose=dir` for `git repack` to write filtered-out objects directly as loose objects into a destination object directory by streaming the filtered pack into `unpack-objects`, with the first patch handling objects already in packs and the second extending coverage to loose objects excluded by the filter.
- [2026/11/13/22-11-50 by Adithya Chakilam via GitGitGadget <gitgitgadget@gmail.com>] Adithya Chakilam added the `--filter-to-loose=<dir>` option, which treats `<dir>` as an object directory and writes filtered-out objects there as loose objects by piping the filtered pack (built with `--stdin-packs`) into `unpack-objects` rather than writing an intermediate pack; this initially handles only objects already stored in packs, leaves source loose objects in place, and cannot be combined with `--filter-to` or `--max-pack-size`.
- [2026/11/13/22-11-51 by Adithya Chakilam via GitGitGadget <gitgitgadget@gmail.com>] Adithya Chakilam extended the option to also copy loose objects excluded by the filter to the destination, since the `--stdin-packs`-based approach only covered packed objects; objects already present in the destination are not rewritten, and with `-d` the source copies are removed after all objects have been written successfully.
