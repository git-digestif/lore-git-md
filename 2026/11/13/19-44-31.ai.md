Phillip Wood provides a concise, tested tip for Junio C Hamano’s rebase workflow: if an upstream branch is set, `git rebase --autosquash --keep-base` will rebase onto the current topic’s base without requiring an explicit commit range, eliminating the need to count commits or specify `HEAD~11`. The suggestion is purely mechanical and does not reopen any technical discussion about the series itself, which remains merged to `master`.
