This thread is about a simple but long-standing bugfix for `for-each-ref` and `git refs list`, which crash when run with `--no-format`. The issue dates back to 2007 and occurs because `--no-format` sets the format string to `NULL`, leading to a segmentation fault when the code tries to use it. Abhishek Agarwal’s patch moves the default format assignment after command-line parsing, ensuring `--no-format` restores the default output instead of crashing. This matches the behavior of `git branch` and `git tag`, which already handle `--no-format` correctly.

The fix is minimal—just four lines of code in `builtin/for-each-ref.c`—and includes a new test in `t/for-each-ref-tests.sh` to verify the behavior. Junio Hamano, the maintainer, confirmed the bug and agreed with the approach, while Patrick Steinhardt reviewed and approved the patch. The only change in the second version was updating the Signed-off-by line to comply with the real-name policy. There are no open questions or objections, and the patch is ready for integration.
