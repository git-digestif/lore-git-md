This is a documentation patch. It adds the `fmt-merge-msg` configuration section to Git's central configuration reference (`git-config(1)`), so that the three settings it defines (`merge.branchdesc`, `merge.log`, and `merge.suppressDest`) appear in `git help config` rather than being buried in the `git-fmt-merge-msg` man page.

The change is a two-line addition to `Documentation/config.adoc`, inserting the include directive alphabetically between `filter` and `format`. The patch is minimal, well-scoped, and clearly motivated: it fixes a discoverability gap without touching any code. No controversy is expected.
