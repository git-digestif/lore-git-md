Series version: standalone patch

Core problem or goal
Fix a crash in `git ls-remote` when invoked outside any Git repository with promisor-remote configuration (`promisor.acceptFromServerUrl` or `promisor.acceptFromServer` with `promisor.storeFields`) enabled. The crash occurs because `filter_promisor_remote()` dereferences `repo->gitdir` without checking for NULL.

- Regression introduced by: 3e20258d11 and 7a56394fc6 (both 2026)
