This is the eleventh patch in Thomas Bachem’s 15-patch bugfix series that systematically eliminates Git segfaults triggered by unvalued config keys. It targets a crash in the pseudo-merge bitmap subsystem: when `bitmapPseudoMerge.<name>.pattern` is given without a value (e.g., `git -c bitmapPseudoMerge.test.pattern repack -adb`), the callback `pseudo_merge_config()` dereferences the NULL value while checking whether the pattern starts with `^`, causing a segfault.

The fix is straightforward and consistent with the series’ established pattern: the callback now checks for a NULL value and rejects it with `config_error_nonbool()`, the same helper used for the threshold keys in the same function. The patch includes a dedicated test in `t/t5333-pseudo-merge-bitmaps.sh` that verifies the error message when the config key is unvalued.

This is a clean, well-scoped fix that plugs another latent crash site. The commit message clearly explains the scenario and the chosen remedy, and the test coverage ensures the fix is verifiable. No controversial design decisions are involved; the approach aligns with the rest of the series. The patch touches only `pseudo-merge.c` and its test file, making it easy to review in isolation.
