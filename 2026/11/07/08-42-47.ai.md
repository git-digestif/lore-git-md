This is the final patch in Thomas Bachem’s 15-patch series fixing Git segfaults on unvalued config keys. It plugs a regression introduced in Git 2.54.0 (commits 2d4ab5a885 and 9cb4a5e1ba) where `git config list --type=color` and `--type=expiry-date` would crash when encountering a key without a value. The fix is minimal: both formatters now check for NULL before calling their respective parsers (`color_parse_quietly()` and `parse_expiry_date()`), matching the behavior already established for `--type=int` and for malformed values. The test verifies that valueless keys are silently skipped, leaving no trace in the output or stderr.
