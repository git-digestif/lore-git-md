This is the ninth patch in Thomas Bachem’s 15-patch bugfix series that eliminates Git segfaults when config keys are given without values. It plugs a crash in `get_remote_group()`: when `remotes.<group>` is defined without a value (e.g., `git -c remotes.mygroup fetch mygroup`), the function dereferences the NULL value while splitting the remote list. The fix adds a NULL check and rejects the missing value with `config_error_nonbool()`, using a separate variable to preserve the full key (`remotes.valueless`) for the error message. A new test in `t/t5506-remote-groups.sh` verifies that the error message is clear and the command fails gracefully. The patch is a straightforward, well-scoped fix that follows the series’ established pattern.
