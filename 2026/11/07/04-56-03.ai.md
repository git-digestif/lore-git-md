This is a **substantive review** of Antoni Borowski’s i18n cleanup patch for `git describe --debug` output, now cooking in `next`. Junio C Hamano identifies an incomplete aspect of the patch: while the patch removes gettext wrappers (`_()`) from the `fprintf()` calls in `describe_commit()`, it leaves the `prio_names[]` array marked for translation (`N_()`) and still translates its elements in the debug output. The array is only used for debug output, so its translation is unnecessary and inconsistent with the patch’s goal of keeping debug messages untranslated.

Junio suggests three follow-up actions: remove the `N_()` markers from `prio_names[]`, remove all remaining `_()` calls around `prio_names[]` elements, and consider moving the array into the `if (debug)` block (or renaming it to clarify its debug-only purpose). These changes would fully align the patch with the precedent set by `transport-helper.c` and the patch’s stated rationale. The review is technical and specific, targeting a narrow but important oversight in the current implementation. No objections to the broader goal; this is a refinement request.
