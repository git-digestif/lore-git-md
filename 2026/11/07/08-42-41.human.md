This is the ninth patch in Thomas Bachem’s 15-patch series fixing Git segfaults when config keys are given without values. It plugs a crash in `git fetch <group>` and `git push <group>` when the `remotes.<group>` key exists but has no value. The fix is straightforward: `get_remote_group()` now checks for NULL before dereferencing the value, and rejects the missing value with `config_error_nonbool()`, following the same pattern used elsewhere in the series. A new test in `t/t5506-remote-groups.sh` verifies that the error message is clear and the command fails gracefully.

The patch is uncontroversial and well-scoped. It touches only `remote.c` and its test file, and the change aligns with the series’ established error-handling pattern. No design questions or edge cases are introduced here; this is a clean, targeted fix for a latent crash. If the rest of the series holds up under review, this patch should be a straightforward merge.
