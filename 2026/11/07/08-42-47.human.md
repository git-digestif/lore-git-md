This is the final patch in Thomas Bachem’s 15-patch series fixing Git segfaults on unvalued config keys. It addresses a regression introduced in Git 2.54.0 (commits 2d4ab5a885 and 9cb4a5e1ba) where `git config list --type=color` and `--type=expiry-date` crash when encountering a key without a value. The fix is minimal: both formatters now skip NULL values quietly, matching the behavior of `--type=int` and the existing handling of unparseable values. The patch adds a test to `t/t1300-config.sh` that verifies the commands no longer output valueless keys or emit errors.

The change is uncontroversial and aligns with the series’ overall goal of eliminating crashes without altering Git’s existing error-handling philosophy. Since this is the only patch in the series that fixes a regression (rather than a latent bug), it may attract extra scrutiny, but the fix itself is straightforward and well-tested.
