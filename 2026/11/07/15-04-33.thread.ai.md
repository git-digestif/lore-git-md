Core problem or goal
Clarify the fetch ordering behavior for promisor remotes in the partial-clone subsystem. Specifically, document that (1) remotes explicitly accepted from a server are tried before other promisor remotes, and (2) Git falls back to the next remote in the list if a fetch fails.
