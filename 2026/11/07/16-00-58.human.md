This is the fifth patch in the v8 series adding new path-related keys to `git repo info`. It introduces `path.index.absolute` and `path.index.relative`, which expose the repository’s current index file location in a scriptable format, respecting the `GIT_INDEX_FILE` environment override.

The implementation is straightforward: both keys use `repo_get_index_file(repo)` to retrieve the index path, then apply `format_path()` with either canonical or relative formatting. The patch includes thorough test coverage for standard paths, overrides via `GIT_INDEX_FILE`, and bare-repository edge cases. Documentation is clear and follows the established pattern for other `path.*` keys.

This patch is uncontroversial and mechanically clean. The only latent issue is the `BUG()` invocation in `repo_get_index_file(repo)`, which the author retained as-is despite Junio’s suggestion to replace it with a null check. This is a pre-existing problem in the codebase, not one introduced by this patch, and does not affect the correctness of the new functionality. The patch is ready for merging as part of the series.
