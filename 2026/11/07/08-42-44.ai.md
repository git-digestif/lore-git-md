This is the twelfth patch in Thomas Bachem’s 15-patch bugfix series addressing Git segfaults when config keys are given without values. It targets the `scalar` subsystem, fixing a crash in `scalar reconfigure --all` when `scalar.repo` is unvalued.

The patch adds a NULL check in `get_scalar_repos()` (the config callback for `scalar.repo`) and rejects missing values with `config_error_nonbool()`, consistent with the series’ established pattern. The fix is minimal and safe: `scalar register` always writes `scalar.repo` with a path, so this cannot break existing setups. A new test in `t/t9210-scalar.sh` verifies the error message and exit code.

The change touches only `scalar.c` and its test file, with no cross-subsystem impact. Like the rest of the series, it is uncontroversial and aligns with the project’s error-handling conventions. The patch is ready for review and should merge cleanly once the earlier patches in the series are accepted.
