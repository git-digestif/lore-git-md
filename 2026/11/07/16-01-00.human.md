This is the final patch in the v8 series adding path-related keys to `git repo info`. It introduces `path.cdup`, which returns the relative path from the current directory to the top-level working tree (e.g., `../../` in a subdirectory, empty string at the root, or the absolute path when outside the working tree). The patch completes the symmetry with `path.git-prefix` (the inverse operation) and addresses Junio C Hamano’s earlier design objection by providing a scriptable alternative to `git rev-parse --show-cdup`.

The implementation is straightforward: `get_path_cdup()` checks `is_inside_work_tree(repo)` and, if false, returns the absolute path to the working tree. When inside the working tree, it counts slashes in the repository’s `prefix` field to construct the relative path. The patch adds documentation, the getter function, and three tests covering the root directory, a subdirectory, and the outside-working-tree edge case. All prior mechanical feedback (curly braces, control flow, test hygiene) has been resolved, and the patch is uncontroversial.
