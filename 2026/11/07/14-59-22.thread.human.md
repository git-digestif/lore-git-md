This thread is about a test infrastructure improvement to replace slow `tr(1)` invocations in the Git test suite with a new `test-tool genbytes` command, addressing a performance bottleneck on macOS. The series is currently at version 1, with a planned version 2 to incorporate feedback.

The key discussion in this latest email revolves around patch workflow: Junio C Hamano prefers combining the file rename (`test-genzeros.c` → `test-genbytes.c`) and functional changes into a single commit for clarity in Git's history, rather than splitting them as currently proposed. This is a presentation preference, not a technical objection, and the author, Kristofer Karlsson, will address it in the next version. The technical direction—using a two-digit hexadecimal interface for `genbytes`—has been settled, with the author already prototyping the change. The series touches 26 test scripts and shows significant performance gains on macOS (70–79% improvement). Open questions remain about whether to keep `genzeros` as a wrapper or fold it entirely into `genbytes`, and the author has flagged this as optional for feedback. No other participants have raised new concerns, and the series remains under review with no evidence of integration yet.
