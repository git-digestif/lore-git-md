This is a test infrastructure patch series introducing a new `test-tool genbytes` command to replace slow `tr(1)` invocations on macOS.

The series targets a measurable performance bottleneck in the test suite: the `EXPENSIVE` tests in `t4205-log-pretty-formats.sh` run several times slower on macOS than on Linux because they generate 2 GB of data and pipe it through `tr(1)`, which is unusually slow on that platform. The new `genbytes` command writes arbitrary bytes directly, eliminating the need for `tr`.

Patch 1 mechanically renames `test-genzeros.c` to `test-genbytes.c` to prepare for the functional change. Patch 2 implements `genbytes` and updates the Makefile, Meson build, and test-tool plumbing. Patch 3 (marked as optional) folds the existing `genzeros` functionality into `genbytes` by allowing the byte to be specified as "NUL", which would replace the 10 call sites of `genzeros` with a single command. The author kept this separate to make it easy to drop if the project prefers to keep `genzeros` as a thin wrapper.

The implementation uses a 256 KB local buffer (matching the previous static buffer size) and preserves the existing silent handling of invalid counts. The series touches 16 files, mostly test scripts that previously used `genzeros | tr`. The cover letter explicitly flags the optional nature of patch 3 and invites feedback on whether to keep it.
