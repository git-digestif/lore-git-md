This is a cleanup patch in the `git history` subsystem, part of Jelle van der Waa’s RFC series to add `--verbose` support to `git history reword`. The patch removes a redundant call to `strbuf_stripspace()` in `builtin/history.c`.

The change is straightforward: `cleanup_message()` with `COMMIT_MSG_CLEANUP_ALL` already calls `strbuf_stripspace()` internally, so the explicit call is unnecessary. The patch deletes a single line, making the code slightly cleaner without altering behavior. This kind of mechanical cleanup is uncontroversial and aligns with Git’s preference for minimal, self-contained patches.

The patch is the first of two in the series, setting the stage for the feature addition in the next patch. While small, it demonstrates attention to detail and avoids introducing redundancy that could complicate future changes. There’s no test coverage here, but none is needed since the patch doesn’t change functionality.

This is a low-risk, high-value cleanup that should be easy to review and merge. It’s a good example of the kind of incremental improvement that keeps the codebase maintainable. If the series progresses, this patch will likely be absorbed without much discussion.
