This is the third patch in the v8 series adding path-related keys to `git repo info`. It introduces `path.superproject-root.absolute` and `path.superproject-root.relative`, which expose the working tree root of the superproject when the current repository is an initialized submodule. The implementation uses the fixed `get_superproject_working_tree()` function (corrected in patch 2/7) and the existing `format_path()` helper to handle absolute and relative path formatting.

The patch touches `builtin/repo.c` to add the two new getter functions (`get_path_superproject_absolute` and `get_path_superproject_relative`), updates `Documentation/git-repo.adoc` to document the new keys, and extends `t/t1900-repo-info.sh` with tests covering submodule contexts, `--git-dir` usage, and edge cases (e.g., not in a submodule). The getter functions are streamlined to eliminate redundant early returns, and the tests verify that both keys return an empty string when not inside a submodule.
