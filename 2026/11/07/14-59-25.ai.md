This is the third and final patch in Kristofer Karlsson’s test infrastructure series, completing the transition from `test-tool genzeros` to `test-tool genbytes`. The patch folds the existing `genzeros` functionality into `genbytes` by teaching the latter to accept "NUL" as a byte specifier, then updates the remaining 10 call sites in the test suite and removes the now-redundant `genzeros` command.

The implementation is straightforward: a new `parse_byte()` helper maps the string "NUL" to the zero byte, and the command-line parser is updated to accept either a single character or "NUL". The patch touches eight files—mostly test scripts that previously used `genzeros`—and preserves the existing behavior of silently handling invalid counts. No new tests are added, but the existing test coverage in the updated scripts remains in place.

This patch is optional, as the author explicitly flagged in the cover letter. The project could choose to keep `genzeros` as a thin wrapper around `genbytes` instead of merging them, but folding them together reduces the test-tool surface without changing any test behavior. The conversion is mechanical and low-risk, affecting only test infrastructure rather than core Git functionality.

The series as a whole addresses a real performance bottleneck on macOS, where `tr(1)` invocations in large-data tests were measurably slow. The new `genbytes` command eliminates that overhead while maintaining backward compatibility for tests that depend on NUL bytes. The optional nature of this final patch makes it easy to drop if reviewers prefer the wrapper approach.
