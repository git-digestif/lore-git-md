This is the third patch in Thomas Bachem’s 15-patch bugfix series that eliminates Git segfaults when config keys are given without values. It fixes a crash in the interactive patch modes (`` `git add -p` ``, `` `git add -i` ``, etc.) when a color slot such as `color.interactive.prompt` or `color.diff.frag` is left unvalued. The patch replaces the unsafe `repo_config_get_value()` call with `repo_config_get_string_tmp()`, which rejects NULL values with `config_error_nonbool()`, matching the behavior already used for diff colors. A new test in `t/t3701-add-interactive.sh` verifies that the error message is shown instead of a segfault. The fix is narrow, well-motivated, and follows the established error-handling pattern from the rest of the series.
