This is a surface-level review comment on the first patch of Kristofer Karlsson’s three-patch test-infrastructure series introducing `test-tool genbytes`. Junio C Hamano notes that applying only patch 1/3 will break ten existing test scripts that still expect `test-tool genzeros` to exist. He suggests an alternative workflow: apply both patches 1 and 2, squash them into a single commit, and use `git format-patch -M3` to produce a rename-aware diff that shows the file rename and the functional changes together. This would avoid the intermediate breakage while preserving the same end state. The comment is purely mechanical and does not engage with the design or motivation of the series.
