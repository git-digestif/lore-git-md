This is the twelfth patch in Thomas Bachem’s 15-patch bugfix series that systematically eliminates Git segfaults triggered by unvalued config keys. It fixes a crash in `scalar reconfigure --all` when the `scalar.repo` key is present without a value: the code previously passed the NULL value to `string_list_append()`, which tried to copy it with `xstrdup()`. The fix rejects the missing value with `config_error_nonbool()`, following the established pattern in the rest of the series. A new test in `t/t9210-scalar.sh` verifies that the command now fails cleanly with an error message instead of crashing.

The patch is narrowly targeted and uncontroversial. The commit message explains why this cannot break existing setups (`scalar register` always writes `scalar.repo` with a path), and the fix aligns with the series’ consistent error-handling approach. No new symbols or API changes are introduced. This is a straightforward, well-motivated bugfix that fits neatly into the larger effort.
