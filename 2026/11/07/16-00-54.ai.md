This is the first patch in the **v8 series** adding path-related keys to `` `git repo info` ``. It introduces ``path.toplevel.absolute`` and ``path.toplevel.relative``, which expose the repository’s working tree root in absolute and relative forms. The implementation is straightforward: it uses ``repo_get_work_tree()`` and the existing ``format_path()`` helper, returning an empty string in bare repositories. Tests cover both subdirectory execution and bare-repository edge cases.

The patch is **mechanically clean** and **design-resolved**; no substantive feedback remains. It is part of a **GSoC-driven feature** that has been through eight iterations, addressing all prior review comments. The only open question is whether the series as a whole will attract enough reviewer attention to avoid being dropped from ``seen``. This patch itself is uncontroversial and ready for merging.
