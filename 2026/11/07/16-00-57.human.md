This is the fourth patch in the v8 series adding path-related keys to `git repo info`. It introduces `path.hooks.absolute` and `path.hooks.relative` to expose the hooks directory in a scriptable, structured format, respecting the `core.hooksPath` configuration.

The patch is straightforward and well-tested. It uses `repo_git_path_replace()` to resolve the hooks path, then applies `format_path()` to produce absolute or relative output. A key usability improvement is that both keys now return `/dev/null` verbatim when `core.hooksPath` is set to that value, avoiding platform-specific path mangling and making the output more predictable for scripts. The documentation clearly explains this behavior, and the tests cover standard paths, overrides, and the `/dev/null` edge case using direct config file manipulation to avoid MSYS2 issues on Windows.

There are no unresolved mechanical or design issues here. The implementation aligns with the established pattern for other path keys in the series, and the `/dev/null` handling was explicitly agreed with Justin Tobler in response to his review of v7. The patch is ready for merging as part of the larger series, which itself is now technically complete and awaiting final review.
