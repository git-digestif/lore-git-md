This is the fourth patch in the v8 `[PATCH v8 0/7]` series adding path-related keys to `git repo info`. It introduces `path.hooks.absolute` and `path.hooks.relative`, exposing the hooks directory location in a scriptable format while respecting `core.hooksPath` configuration.

The implementation uses `repo_git_path_replace()` to resolve the hooks path, then applies `format_path()` with either canonical or relative formatting. Both keys now return `/dev/null` verbatim when `core.hooksPath` is set to that value, a usability improvement that avoids platform-specific path mangling and aligns with the behavior of `git rev-parse --git-path hooks`. Tests cover standard hooks paths, custom overrides via `core.hooksPath`, and the `/dev/null` edge case, using direct config file manipulation to sidestep MSYS2 path issues on Windows.

This patch is mechanically clean and uncontested, with no substantive feedback remaining. The `/dev/null` handling was a point of debate in v7 but is now resolved in favor of returning the literal value for both absolute and relative keys.
