This is the fifth patch in Thomas Bachem’s 15-patch bugfix series that stops Git from segfaulting when config keys are given without values. It plugs a crash in `git grep`, `git log`, and `git show` when `grep.patternType` is set without a value (e.g., `git -c grep.patternType`). The fix is a two-line guard in `grep_config()` that rejects the NULL value with `config_error_nonbool()`, matching the existing pattern for `color.grep.*` slots. A new test in `t/t7810-grep.sh` verifies the error message. The patch is uncontroversial, well-targeted, and follows the series’ established error-handling style.
