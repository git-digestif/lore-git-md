This is a documentation patch (v2) from brian m. carlson warning users against using `http.extraheader` for authentication credentials. It is a standalone contribution, not part of a series, and is currently under review with no substantive objections outstanding.

The patch modifies three files. In `Documentation/config/http.adoc`, it adds a paragraph to the `http.extraHeader` entry stating the option "should not be used to pass credentials," explaining that the non-URL-qualified variant exposes credentials to every server Git contacts while global or command-line usage exposes them to other users. It also notes that using `http.extraheader` to set the `Authorization` header can break external tools like Git LFS, which may append their own `Authorization` header and produce duplicates; credential helpers avoid this because Git LFS only invokes them when credentials are absent. The text recommends credential helpers as "almost always more secure" and notes they can implement Bearer authentication. In `Documentation/git.adoc`, the patch removes the specific example naming `http.extraHeader` as a variable with sensitive values, replacing it with a generic statement about variables where sensitive data is part of the value. In `Documentation/gitfaq.adoc`, it appends to the existing advice against passwords in URLs a sentence stating that `http.extraheader` is similarly not recommended for credentials.

The motivation addresses a recurring misuse where users pass credentials via `http.extraheader`, creating both security risks (credential leakage) and interoperability breakage with tools that manage their own auth headers. The commit message does not cite a specific bug report but describes this as a common pattern that needs clearer guidance now that credential helper support is robust.

Version 2 incorporates a minor grammatical fix requested in review: the text now reads "should not be used to pass credentials" (adding the missing word "used"). No code or tests are touched, and no Reviewed-by or Acked-by trailers have been added yet.
