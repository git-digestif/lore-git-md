This is a "What's cooking in git.git" integration status report from Junio C Hamano, summarizing which topics have graduated to `master`, which are queued in `next` or `seen`, and which have been discarded.

Six topics graduated to `master` this cycle, most notably `tb/config-null-values`, a 15-commit series hardening various subsystems against NULL pointer dereferences when config keys are present without values (covering colors, bundle-uri, scalar, remotes, blame, grep, and rebase). Also landing in `master` are `ps/ci-speedups` (7 commits optimizing GitLab CI with Meson, reftables, and artifact caching), `hn/imap-send-header-fix` (case-insensitive header matching and ordering fixes for `git imap-send`), and several documentation and test hygiene fixes.

Among new topics awaiting review are `ar/compat-object-format-fixes` (rejecting matching `extensions.objectFormat`/`compatObjectFormat` values and fixing `rev-parse --output-object-format` mapping), `cc/fetch-promisor-remote-reply` (consolidating protocol v2 capability writing and sending promisor-remote replies with fetch to fix partial clones over stateless HTTP), and `dg/utf8-strnwidth-bounds` (boundary fixes for `utf8_strnwidth()` when skipping ANSI sequences). Several small documentation and typo fixes from "ob" are marked "Will merge to 'next'?".

The cooking section highlights ongoing architectural work: `ps/odb-pluggable-commit-graphs` refactors commit-graph chain validation and reading for the pluggable ODB effort, `ps/rerere-subcommands` converts `git rerere` to `OPT_SUBCOMMAND()` while dropping `the_repository`, and `cc/pack-index-v3` implements pack index v3 for SHA-1/SHA-256 interoperability. New features include `hn/branch-delete-merged-squash` adding `--delete-integrated` to `git branch` for squash/rebased branches, `hn/reflog-operations` adding the `%gb` pretty placeholder for reflog branch names, and `ar/ls-remote-show-object-format` adding `--show-object-format`. Several `the_repository` removal patches (`oa/negotiator-default-no-the-repository`, `oa/checkout-wo-the-repository`) are also in review. Notably stalled or discarded topics include `js/coverity-overflow-fixes` (expecting reroll), and several long-stalled items like `iy/sigchain-recover-concurrent-pops` and `vs/refs-seek-fix`.
