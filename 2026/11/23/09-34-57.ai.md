This is a documentation patch clarifying existing behavior of `git commit --date=now` when amending.

The patch adds two lines to the `--date=<date>` entry in `Documentation/git-commit.adoc`, noting that when amending a commit, `--date=now` sets the author date to the current time rather than preserving the original commit's author date. The commit message explains that amending normally preserves the original author date, so this addition makes the `now` value's effect explicit in that context. The change touches only the man page and does not modify any code or tests. It appears to be a standalone patch rather than part of a larger series.
