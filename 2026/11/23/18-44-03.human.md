This is Junio C Hamano's periodic "What's cooking in git.git" status report for late November 2026, summarizing which topics have graduated to `master`, which are newly submitted, which are actively cooking in `next` or `seen`, and which have been discarded.

Seven topics graduated to `master` this cycle. The largest is a 15-commit series hardening config handling against NULL values across many commands (colors, remotes, bundle-uri, scalar, etc.) to prevent crashes when keys are set without values. Other graduates include fixes to `git imap-send` for header ordering and case-insensitivity, a rewrite of the `git diff` EXAMPLES section, a new `test-tool genbytes` to speed up tests on macOS, CI speedups using Meson and reftables, and a `t2401` worktree test fix.

Among new topics, Adrian Ratiu proposes stricter validation around `extensions.compatObjectFormat` and object format mapping, while Christian Couder has an 8-patch series consolidating protocol v2 capability writing in `connect.c` and fixing promisor-remote replies over stateless HTTP for partial clones. Several small documentation and typo fixes are also queued for `next`.

The cooking section shows active work across many subsystems. Patrick Steinhardt has a 7-patch series refactoring commit-graph chain validation in preparation for pluggable ODB backends, and another large series converting `git rerere` to proper subcommands. Christian Couder's 13-patch series implements pack index v3 for SHA-1/SHA-256 interoperability. Other notable in-flight topics include a new `--delete-integrated` option for `git branch`, default `git status` comparison against both upstream and push branches, and various `the_repository` removal steps.

Several stalled topics were discarded, including HTTP WWW-Authenticate header preservation across redirects, `git commit --fixup` with `-m`/`-F`, and libsecret explicit loading, all noted as lacking recent interest.
