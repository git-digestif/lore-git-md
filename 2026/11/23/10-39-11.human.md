This is a bugfix for the experimental `git history` command that prevents it from corrupting the state of other worktrees. When `git history` rewrites a commit with the default `--update-refs=branches`, it moves every local branch that descends from that commit. If one of those branches is checked out in a different worktree, the branch pointer advances but that worktree's index and working tree remain on the old commit, leaving phantom staged changes and potentially breaking an in-progress rebase. The patch adds a pre-flight check that scans local branches for ones contained in the commit being rewritten and currently used by any worktree (including branches mid-rebase or mid-bisect), refusing to proceed if any are found, and points users to `--update-refs=head` as the safe alternative.

The implementation introduces `reject_checked_out_branches()` in `builtin/history.c`, which uses `branch_checked_out()` to identify branches locked by other worktrees or by the current worktree's ongoing rebase/bisect, while deliberately skipping the branch checked out in the current worktree since `git history` already updates that one correctly. The check runs even under `--dry-run` so the preview matches what a real run would do, and the existing `advice.historyUpdateRefs` hint is extended to cover this new refusal case. Documentation in `Documentation/git-history.adoc` and `Documentation/config/advice.adoc` is updated to explain the new behavior.

The patch comes from Aniket Gupta, picking up a suggestion Patrick Steinhardt made earlier and originally reported by Toon Claes and Nikita Bobko. It is based on `master` and changes user-visible behavior, so it is not a maintenance-track candidate. The commit includes seven new tests in `t/t3450-history.sh` covering refusal for other-worktree branches, dry-run behavior, advice suppression, the `--update-refs=head` escape hatch, rewriting the current worktree's own branch, and refusal during active rebase and bisect. The coverage looks thorough and the commit message clearly explains the motivation and the fix, so this appears to be a well-crafted, ready-for-review contribution.
