This is **patch 4 of 5** in Adrian Ratiu's v2 bugfix series addressing the crash when a submodule is itself a linked worktree. It closes a validation gap in `setup_submodule_git_dir()` (introduced by the refactoring in patch 3) where the git directory was not checked after `absorb_git_dir_into_superproject()` had run.

The patch restructures the `old_head` branch of `setup_submodule_git_dir()` in `submodule.c` so that validation happens unconditionally after ensuring `path/.git` is a gitfile. Previously, if the submodule already used a gitfile, the code validated the target immediately; if it did not, the code absorbed the `.git` directory and skipped validation entirely. Now, after optionally calling `absorb_git_dir_into_superproject()`, the code always reads the resulting gitfile via `read_gitfile()`, calls `validate_submodule_git_dir()` on the target, and dies via `die_refusing_submodule_git_dir()` if the path is invalid. This prevents a scenario where a submodule with a nested `.git` directory triggers absorption but retains a stale or forged gitfile pointing to an invalid location, which Git would otherwise silently replace without checking.

The commit message notes that absorbing only moves `.git` directories, so a submodule that already used a gitfile would keep pointing to its old git dir even after absorption; validating after the fact ensures Git refuses a bad target instead of silently overwriting it. The change is marked `Suggested-by: Junio C Hamano`.

Test coverage is added in `t/t7450-bad-git-dotfiles.sh` with a new case, `checkout --recurse-submodules rejects gitfile not matching submodule name after absorbing`, which constructs a nested submodule scenario: it clones a submodule, renames its git dir from `hippo` to `elephant`, points the gitfile at the renamed dir, then adds an inner clone to force the absorb path. It verifies that `git checkout -f --recurse-submodules` fails with the expected "not a suffix of git dir" error and leaves the gitfile untouched, confirming the validation fires after absorption.
