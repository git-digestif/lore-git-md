This thread is Junio C Hamano's latest "What's cooking in git.git" report, summarizing the current state of the integration branches. Six topics graduated to `master` this cycle, including Taylor Blau's NULL-dereference hardening series, Patrick Steinhardt's CI speedups, and an `imap-send` header fix, while several new topics were queued for review such as Adrian Ratiu's object-format compatibility fixes and Christian Couder's promisor-remote fetch reply work. A number of architectural efforts remain in cooking, including pluggable commit-graphs, `rerere` subcommands, and various `the_repository` removal patches, while a few topics were marked stalled or discarded.

Following the report, Torsten Bögershausen wrote in to ask what is needed to move the stalled topic `cs/read-cache-conversion-size` forward. Authored by Curtis Allen Smith, the patch adjusts the index refresh logic in `read-cache` so that a file size change is no longer treated as proof of modification when the path is subject to content conversion like line-ending changes, which had caused false dirty statuses. Bögershausen notes the patch appears sound, fixes a long-standing problem, and includes test cases; he also mentions that a related optimization was previously sent as a separate patch and offers to resend it if there is interest.
