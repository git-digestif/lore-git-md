This is a documentation clarification in the ongoing bugfix thread that teaches `git rev-list --connectivity-check` to ignore replacement objects. Kristofer Karlsson responds to Karthik Nayak’s surface-level review by defending the existing wording in `git-replace.adoc`. He argues that the patch actually *improves* the documentation’s accuracy: the connectivity check is part of pack transfer (fetch and push), so the current text—claiming that "pack transfer" ignores replacements—was already misleading before the patch, since the connectivity check *did* follow replacements. He also notes that the list of commands ignoring replacements was never meant to be exhaustive (other examples include `index-pack`, `unpack-objects`, `commit-graph`, and `multi-pack-index`), framing it as a set of illustrative examples rather than a definitive catalog. No changes to the patch or documentation are proposed; the discussion is purely about whether the existing text needs updating.
