This is a bugfix patch for the `pack-objects` subsystem, now marked for queuing by Junio C Hamano. The patch fixes a data corruption issue where blob sizes ≥4GiB are truncated in the pack header on platforms with 32-bit `long` and 64-bit `size_t` (e.g., 64-bit Windows). The fix updates variable types in `builtin/pack-objects.c` to use `size_t` and `off_t` instead of `unsigned long`, ensuring accurate size tracking for large blobs during pack creation.

The patch is narrowly scoped to the streaming path for large blobs, with no changes to the on-disk format or other `pack-objects` functionality.
