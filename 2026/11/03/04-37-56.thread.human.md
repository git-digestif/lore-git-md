This thread is about a small but important bugfix in Git's Rust codebase. A contributor, shrimech, has submitted a patch to the `hash` module that prevents a panic when formatting an `ObjectID` with an unrecognized hash algorithm. The issue arises because `ObjectID::algo` is publicly mutable, meaning callers can set it to an invalid value, which previously caused a panic during formatting. The patch preserves existing behavior for valid algorithms while gracefully handling invalid ones. This is part of Git's broader Rustification effort, but the patch itself is narrowly focused on a correctness fix.
