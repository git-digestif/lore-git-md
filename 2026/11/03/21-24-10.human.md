This patch fixes a latent bug in `odb_transaction_files_write_pack()`: when `git index-pack` exits abnormally, the function records an error message in `err_msg` but still returns success. While current callers discard the return value, this is misleading and could mask failures in future code. The patch updates the function to return an error in this case and simplifies the child process exit status checks. The changes are mechanical and confined to `object-file.c` (10 insertions, 10 deletions), with no new test coverage or on-disk format changes.
