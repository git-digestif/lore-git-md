This is a bugfix patch targeting the graph-drawing subsystem in `graph.c`. It addresses a rendering error in `git log --graph --all --oneline` where orphaned commits (like commit R in the test case) are incorrectly drawn with a spurious parent connection, causing the rightmost lane to extend into empty space. The fix is narrowly scoped: it modifies `graph_is_visual_root()` to avoid treating commits as visual roots when there are columns to their right, preventing misalignment between `graph_output_pre_root_line()` and `graph_output_commit_line()`.

The patch is well-motivated and surgically precise. The commit message clearly explains the root cause (a regression introduced in a34c00d96, "graph: indent visual root in graph", 2026-07-14) and includes ASCII-art illustrations of both the bug and the corrected output. The fix itself is a single-line addition to `graph_is_visual_root()` that adds a condition (`graph->commit_index + 1 >= graph->num_columns`) to avoid spurious indentation. Test coverage is thorough: a new test case in `t/t4218-log-graph-indentation.sh` verifies the corrected behavior using `lib_test_check_graph` to validate the ASCII-art layout.
