This thread is about Julia Evans’s rewrite of the EXAMPLES section in the `git diff` man page, now in its second version. The goal is to modernize the examples, replace outdated syntax like `...` with `--merge-base`, and improve readability. All mechanical issues—such as inconsistencies between `--staged` and `--cached`—have been resolved in v2, which now passes the previously failing test.

The patch itself is technically ready, but three disputes remain unresolved. Junio Hamano objects to the use of horizontal definition lists (citing cut-and-paste difficulties), Jeff King points out a build toolchain incompatibility with the `[[name_only]]` anchor syntax in Python AsciiDoc, and Junio has broadened the discussion to question whether Python AsciiDoc support should be dropped entirely. D. Ben Knoble’s recent note about `--staged` and `--cached` being documented in `git help cli` adds context but doesn’t address these core issues. Until the presentation format, build compatibility, and toolchain policy questions are settled, the patch won’t move forward.
