# Thread deltas

## 2026/11/03

- [2026/11/03/14-14-14 by Jean Abou Samra <jean@abou-samra.fr>] Jean Abou Samra reported that `git diff --no-index --word-diff` between file1.txt and file3.txt (where file3.txt adds a blank line to file2.txt, which itself differs from file1.txt by a few words) produces a strange word diff that matches scattered words while missing unchanged entire long sentences, and asked whether this is a bug, noting it occurs with all `--diff-algorithm` option values.
- [2026/11/03/16-38-03 by Phillip Wood <phillip.wood123@gmail.com>] Phillip Wood replied that the diff is correct but useless for seeing word-level changes, explaining that git first computes the line-by-line diff and then splits it at context lines (here the blank line) before diffing words, which makes the entire first paragraph appear deleted; he suggested feeding whole hunks from the line diff into the word diff instead of splitting at context lines, and noted that a modified patience algorithm without the Myers fallback yields a sensible word-diff for this example.
