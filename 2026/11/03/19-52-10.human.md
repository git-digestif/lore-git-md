This is a small but important refactoring guardrail patch from Junio C Hamano. It adds a comment block to `environment.h` that explicitly forbids adding new members to the `repo_config_values` structure until the repository settings system is redesigned to work with arbitrary repository instances, not just `the_repository`.

The patch is a direct response to an earlier discussion (linked in the comment) where Patrick Steinhardt pointed out that `repo_config_values()` is currently unusable outside the global repository. The commit message and comment make it clear that this is a temporary freeze, not a permanent decision, but one that is necessary to prevent further technical debt in an area that is already messy.

Junio’s patch is minimal and self-contained: it touches only one file, adds no code, and carries Patrick’s Acked-by, indicating that the freeze is uncontroversial. The change itself is documentation, but its purpose is refactoring hygiene — it stops a leak in the ongoing `the_repository` removal effort. If you care about multi-repository support or the settings subsystem, this patch is worth noting as a marker of what not to touch until the redesign lands.
