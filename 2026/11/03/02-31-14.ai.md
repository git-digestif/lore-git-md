This is a "What's cooking" report from Junio, summarizing the current state of integration branches for Git as of November 2026. The report lists topics cooking in `next` and `seen`, those that graduated to `master`, and stalled topics needing attention.

Key highlights for a future AI summarizer session:

Several small test modernization patches graduated to `master`, including updates to `t5300`, `t0410`, `t5402`, and `t7104` to use `test_path_is_file` and related helpers instead of raw `test -f` or `test -e`. These are part of an ongoing effort to improve test diagnostics and maintainability.

Notable new topics in `next` include:
- **hn/ccache-sloppiness-for-pch**: Allows `ccache` to cache objects built with precompiled headers by setting `CCACHE_SLOPPINESS`.
- **ps/grep-recurse-submodules-fix**: Fixes a regression in `git grep --recurse-submodules` where nested trees in submodules were not read correctly, by passing the correct repository context instead of relying on `the_repository`.
- **hn/remote-simple-push-triangular**: Updates `git rev-parse @{push}` to resolve to the branch of the same name on the push remote when the push remote differs from the fetch remote, mirroring `git push` behavior.
- **lt/describe-commit-date-skew**: Teaches `git describe` to use commit generation numbers to accurately calculate commit distance even when commit dates are skewed.
- **ps/rerere-subcommands**: Converts `git rerere` subcommand parsing to use `OPT_SUBCOMMAND()`, removing ad-hoc parsing logic.
- **tb/merge-ort-valueless-rename-config**: Updates `merge-ort` to accept valueless settings for `diff.renames`, `merge.renames`, and `merge.directoryRenames`, treating them as `true`.
- **sp/submodule-abbrev-fix**: Fixes commit ID abbreviation in submodule diff headers to use the submodule's object database, avoiding ambiguity.
- **ep/pack-objects-streamed-large-blobs**: Uses `size_t` for streamed large blobs in `git pack-objects` to prevent truncation on platforms where `long` is 32-bit.
- **ps/commit-graph-cleanups**: Removes global state and `the_repository` usage from the `commit-graph` builtin in preparation for making the commit-graph subsystem pluggable.
- **ps/odb-reload-alternates**: Makes the object database files backend reload alternates when an object lookup fails on retry, restoring lost capability to find objects moved to newly added alternates.
- **hn/reflog-operations**: Adds `%gb` format placeholder to `git reflog` and `git log -g` to show the branch name for each reflog entry, even during rebase.
- **ps/ci-consolidate-test-variables**: Consolidates and deduplicates test environment setup in CI scripts to simplify flag management.
- **hn/branch-delete-merged-squash**: Adds `--delete-integrated` to `git branch` to find and remove branches whose work has been squash-merged or rebase-merged into the upstream.
- **je/doc-new-git-tutorial**: Rewrites the beginner's tutorial to focus on a minimal set of commands for quick learning.
- **ps/odb-object-storage-extension**: Makes the object storage format configurable via `extensions.objectStorage`, allowing users to specify the storage backend and optional payload.

Stalled topics include:
- **mh/rust-crate-subdir**: Moves Rust code into a dedicated `rust/` subdirectory to avoid confusing Cargo.
- **tb/midx-incremental-custom-base**: Fixes `--base` option handling in `git multi-pack-index write --incremental`.
- **mm/diff-process-hunks**: Introduces `diff.<driver>.process` to allow external tools to act as hunk providers.
- **ij/subtree-reject-v2-config**: Makes `git subtree` (shell version) bail out if the Rust rewrite's config is present.
- **pm/replay-add-signing-support**: Teaches `git replay` to GPG-sign commits.
- **mc/refs-rename-transaction**: Refactors reference rename and copy operations to use the generic reference transaction API.

The report also notes that `master` is the only branch where "merged" is correct; topics in `next` are "cooking" and may still be dropped, while `seen` is ephemeral and rebuilt frequently. Several topics are marked as needing review or waiting for responses, indicating active discussion or pending updates.
