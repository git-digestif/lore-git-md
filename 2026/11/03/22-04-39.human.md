This is a CI/build system patch series that Junio has queued for integration. The series fixes four GitHub Actions CI jobs that broke after the `ubuntu-latest` runner image was updated to Ubuntu 26.04. The patches are minimal and pragmatic, addressing immediate breakage without redesigning the CI infrastructure.

The first patch switches the `linux32` job from `apt` to `apt-get` to silence CLI interface warnings, though Junio notes this is only a warning and questions its urgency. The second works around a permission issue when creating symlinks during dependency installation by running `ln` with `sudo`; this affects the `documentation`, `fuzz-smoke`, and `static-analysis` jobs. Junio wonders aloud whether the Rust rewrite of `dirname` has been fixed yet, making this workaround unnecessary. The third patch pins the `linux32` job to Ubuntu 24.04 to restore networking (DNS resolution for `deb.debian.org`), bypassing a temporary Docker issue that will eventually be resolved in future runner images. Junio acknowledges this as a straightforward but temporary fix, noting the need to revert it later.

The series touches only `.github/workflows/main.yml` and `ci/install-dependencies.sh`, with no changes to core Git functionality. The fixes are based on prior work by Johannes Schindelin in Git for Windows, suggesting they have been tested in a similar environment. Junio’s decision to queue the series indicates he finds the approach acceptable, though the `sudo` workaround and the temporary nature of the networking fix may draw further discussion if other contributors have concerns about long-term maintainability. The patches are small (5 insertions, 3 deletions) and focused on restoring CI functionality rather than introducing new features or refactoring.
