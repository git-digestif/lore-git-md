This is the first patch in a two-patch refactoring series targeting the `the_repository` removal effort. It updates `create_notes_commit()` and `commit_notes()` in `notes-utils.c` to use the `struct repository *` parameter they receive instead of the global `the_repository`. The change is purely mechanical: it replaces `the_repository` with the passed `r` in calls to `get_main_ref_store()`, `refs_read_ref()`, and `refs_update_ref()`.

The patch is small (2 insertions, 2 deletions) and self-contained, touching only `notes-utils.c`. It does not alter behavior or affect test coverage. The commit message explains that `USE_THE_REPOSITORY_VARIABLE` is retained for now because `init_copy_notes_for_rewrite()` still depends on the global variable — this dependency is addressed in the second patch of the series.

This patch directly addresses Patrick Steinhardt’s feedback on v1, which noted that the original change was incomplete because it left `USE_THE_REPOSITORY_VARIABLE` in place. The author has responded by expanding the scope in v2 to fully eliminate the macro, demonstrating responsiveness to review. The change aligns with the ongoing `the_repository` removal effort led by René Scharfe and is a well-scoped, incremental step in that larger project.

It is part of a focused refactoring with no user-visible impact, and the author’s clear communication and attention to feedback suggest this is a serious contribution.
