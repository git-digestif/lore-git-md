This is a Rust-focused bugfix patch targeting Git's object ID formatting logic.

The patch addresses a panic that occurs when an `ObjectID` struct contains an unrecognized hash algorithm identifier. Currently, the `Display` implementation for `ObjectID` calls `as_slice()`, which returns an error for invalid algorithms, causing a crash during formatting. The fix modifies the formatting logic to handle invalid algorithms gracefully by displaying the raw hash storage and appending an `:invalid-hash-algo-<id>` marker.

The change is contained to `src/hash.rs` and includes a new regression test that verifies the fix while preserving existing behavior for valid algorithms. The test constructs an `ObjectID` with an invalid algorithm identifier (0) and checks that the output matches the expected format.
