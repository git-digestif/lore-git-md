This is a **substantive review** of Kristofer Karlsson’s `v2` patch addressing the quarantine alternate refs performance regression. Patrick Steinhardt identifies a **gap in the patch’s logic**: it does not account for object directories specified via the `files://<payload>` object storage format extension, which can define a primary object directory that differs from `<commondir>/objects`. The current `is_borrowed_object_dir()` function would incorrectly classify such directories as "borrowed," leading to missing refs in `--alternate-refs` output.

Patrick also proposes a **more ambitious alternative**: instead of modifying the primary object directory to point to the quarantine, append the quarantine directory to the alternates list and use `GIT_QUARANTINE_ENVIRONMENT` as a read-only flag. This would eliminate the need to juggle alternates during connectivity checks, making the alternate refs logic "just work." However, he acknowledges this is a **higher-risk change** with greater potential for regressions, and does not demand it as a prerequisite for merging the current patch.

The review is **tested-level**: Patrick demonstrates deep familiarity with the ODB abstraction layer (including the object storage format extension) and the quarantine plumbing. His feedback is narrowly scoped to the patch’s correctness and does not reopen the broader design debate settled in earlier iterations. The tone suggests the current patch is still viable for `next`, but may require a follow-up to handle the `files://` case.
