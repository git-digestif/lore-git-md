This is a bugfix patch that aligns `git rev-list --connectivity-check` with the established behavior of other Git commands by ignoring replacement objects. The author, Kristofer Karlsson, clarifies in this reply that the existing documentation in `git-replace.adoc` is actually *more accurate* after the patch than before. The documentation states that commands doing reachability traversal (including pack transfer) ignore replacements, but until now, the connectivity check—which runs during pack transfer—*did* follow replacements, creating an inconsistency. Kristofer notes that the list of commands in the documentation was never meant to be exhaustive, and other internal operations (like `index-pack` and `unpack-objects`) also disable replacements. This response effectively closes the documentation concern raised by Karthik Nayak, leaving no open technical or editorial issues in the patch. The design question about whether to ignore replacements has already been resolved in favor of the patch, and the implementation looks well-scoped and consistent with Git’s existing behavior.
