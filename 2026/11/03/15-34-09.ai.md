This is an RFC proposing a new feature for the `git branch` command. The author, Johannes Welsch, suggests adding a `-s`/`--switch` option to `git branch` that would create a new branch *and* switch to it in a single step, mirroring the behavior of `git switch -c <branch>`. The motivation is that users who think of the operation as "creating a branch" (rather than "switching to a new branch") might find `git branch -s` more intuitive than `git switch -c`.

The patch itself is not included—this is a pure RFC email soliciting feedback on the idea. The author acknowledges that the functionality already exists via `git switch -c` but argues that the proposed alternative would better align with users who mentally model the operation as branch creation first. The behavior would match `git switch -c`: fail if the branch already exists, and otherwise create and switch to the new branch.
