This is a bugfix patch targeting the `graph.c` graph-drawing logic. The patch addresses the recently reported issue where `git log --graph --all --oneline` incorrectly renders an orphaned branch (e.g., commit R in the test case) with a spurious parent connection, causing the rightmost lane to extend into empty space. The fix is well-motivated, clearly explained in the commit message, and includes a new test case that reproduces the problem and verifies the fix.

The patch modifies `graph_is_visual_root()` in `graph.c` to avoid indenting a commit when there are columns to its right. The rationale is that such indentation is unnecessary and causes misalignment in the graph layout, as the columns to the right collapse into the root's column once rendered. The change is minimal and surgical, touching only the logic that determines whether a commit should be treated as a visual root. The new test case (`visual root with columns to its right is not indented`) is self-contained and confirms the fix works as intended.
