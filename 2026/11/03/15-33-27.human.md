This is a documentation patch that completely rewrites the EXAMPLES section of the `git diff` man page. Julia Evans (with co-author Marie Claire LeBlanc Flanagan) overhauls the examples to reflect how users actually work with `git diff` today, based on feedback gathered from Mastodon. The old section dated back to 2007 and used a footnote-style format that was hard to follow; the new version uses a table layout with clear subheadings and links to option definitions.

The patch also adds a pointer to the EXAMPLES section in the DESCRIPTION, since many users miss it entirely. Design choices include preferring `--merge-base` over the cryptic `...` syntax, using tables for compactness, and linking options so readers can quickly look them up. Julia’s self-review notes that the table format may wrap on 80-character terminals but argues that conciseness is more important than exhaustive detail in a cheat-sheet section.

The rewrite looks thoughtful and user-focused. It’s a single patch, not part of a larger series, and touches only the `git-diff.adoc` and `diff-options.adoc` files. If you care about Git’s documentation or teach Git to others, this is worth reviewing.
