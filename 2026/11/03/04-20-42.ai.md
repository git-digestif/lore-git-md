This is a Rust bugfix patch targeting the `hash` module in Git's nascent Rust codebase. The patch addresses a panic that occurs when formatting an `ObjectID` whose algorithm field contains an unrecognized identifier. The fix ensures that invalid algorithms are handled gracefully by displaying the full raw hash storage and appending an `:invalid-hash-algo-<id>` marker, rather than unwrapping a function that returns an error for such cases.

The test case is minimal but sufficient, verifying that the output matches the expected format for an invalid algorithm identifier.
