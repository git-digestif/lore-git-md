This thread is a request for comments (RFC) on a proposed user-experience improvement to `git branch`. Johannes Welsch suggests adding a `-s` or `--switch` option to `git branch` that would create a new branch *and* switch to it in one step, effectively duplicating the existing `git switch -c <branch>` functionality. The motivation is to cater to users who think of the operation as "creating a branch" rather than "switching to a new branch," and who might therefore find `git branch -s` more intuitive.

The proposal is purely conceptual at this stage—no patch has been submitted yet. The discussion is likely to focus on whether this addition would reduce cognitive load for users or instead introduce unnecessary redundancy by duplicating an existing command. Since this is the first email in the thread, no feedback or decisions have been recorded yet. The outcome will depend on whether the community sees value in providing an alternative entry point for the same operation.
