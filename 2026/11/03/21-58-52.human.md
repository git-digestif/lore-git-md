This is a documentation patch from Junio C Hamano. It updates the `git-branch` man page to consistently promote `` `git switch` `` over `` `git checkout` `` in an example comment.

The inconsistency was introduced in 2019 when an earlier patch replaced `` `git checkout` `` with `` `git switch` `` in one part of the example but left a nearby comment still referring to `` `checkout -b` ``. This patch changes that comment to use `` `git switch -c` `` instead, matching the rest of the example.

The commit message notes that while `` `git checkout` `` is not going away (and the `switch`/`restore` split was not fully successful), the documentation should at least be internally consistent. The change is minimal—one line in `Documentation/git-branch.adoc`—and does not alter the actual command shown in the example, only the explanatory text.

This is a small, uncontroversial cleanup that aligns the documentation with the project’s current messaging. It looks ready for merging.
