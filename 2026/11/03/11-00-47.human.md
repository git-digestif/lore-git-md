This is a **substantive review** of Kristofer Karlsson’s performance and bugfix patch that skips self-referential alternates during object quarantine. The patch is already in `seen` and on track for `next`, but Patrick Steinhardt raises a fundamental architectural concern: the current fix relies on fragile heuristics to detect whether an alternate is the repository’s own object directory, and these heuristics break when the object storage format extension (`files://<payload>`) is used.

Patrick points out that the patch’s `is_borrowed_object_dir()` function does not account for all cases—specifically, it cannot detect the primary object directory when it is specified via the object storage format extension. He suggests a more radical alternative: instead of modifying the primary object directory to point to the quarantine, Git should **append the quarantine directory to the alternates list** and use `GIT_QUARANTINE_ENVIRONMENT` as a read-only flag. This would eliminate the need to juggle alternates entirely, making the alternate refs logic "just work" without special-casing.

His proposal is framed as a larger semantic change with higher regression risk, but also as a cleaner long-term solution. The review does not block the current patch—Patrick acknowledges the trade-off—but it plants a seed for future work. If this direction gains traction, it could reshape how Git handles quarantines and alternates, potentially obsoleting the current fix. For now, the patch remains the pragmatic choice, but this thread is worth watching for anyone interested in the ODB abstraction effort or quarantine plumbing.
