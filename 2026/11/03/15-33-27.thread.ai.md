Core problem or goal
Rewrite the EXAMPLES section of the `git diff` man page to modernize usage patterns, improve readability, and replace outdated syntax. The revised version organizes common `git diff` invocations into five subsections, replaces the `...` syntax with `--merge-base`, and adds cross-references to option definitions. The presentation format (AsciiDoc horizontal definition lists vs. tables) remains contested, but all mechanical issues—AsciiDoc processor compatibility, misplaced anchor, `-h` help output oversight, and unintended `--cached`/`--staged` replacement—have been resolved by Junio’s squashable fix-ups and Julia’s corrections.

Current status

The patch builds correctly with both AsciiDoc processors, passes all tests (`t4500.218`), and incorporates all prior feedback. The only remaining blocker is Junio’s objection to horizontal definition lists due to cut-and-paste usability concerns. The broader policy question about dropping Python AsciiDoc support is no longer a blocker for this patch but remains unresolved as a long-term project decision.
