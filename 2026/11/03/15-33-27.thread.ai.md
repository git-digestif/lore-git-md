Core problem or goal
Rewrite the EXAMPLES section of the `git diff` man page to modernize usage patterns, improve readability, and replace outdated syntax. The revised version organizes common `git diff` invocations into five subsections, replaces the `...` syntax with `--merge-base`, and adds cross-references to option definitions. The presentation format (AsciiDoc horizontal definition lists vs. tables) remains contested, but all mechanical inconsistencies in `--staged`/`--cached` usage, the AsciiDoc processor compatibility issue, the misplaced anchor, and the `-h` help output oversight have been resolved by Junio’s squashable fix-ups and Julia’s latest corrections.
