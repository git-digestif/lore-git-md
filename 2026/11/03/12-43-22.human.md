This is the third and final patch in Patrick Steinhardt’s v2 bugfix series for `git grep --recurse-submodules`. It applies the same defensive pattern as the earlier patches: instead of reading `.gitmodules` via the global `the_repository`, it now uses the repository instance (`opt->repo`) that was explicitly passed to `grep_objects()`. The change is a single-line substitution in `builtin/grep.c` (line 886) and carries no risk of introducing new bugs—it merely future-proofs the code against scenarios where `opt->repo` might not be `the_repository`. The commit message is clear and concise, explaining both the current safety and the long-term hygiene motivation. This patch, like the rest of the series, is explicitly intended for backporting to stable branches.
