This thread is a minor but important guardrail in the ongoing effort to remove Git's global `the_repository` variable. Junio C Hamano has added a comment block to `environment.h` explicitly forbidding new members in `struct repo_config_values` until the structure can work with arbitrary repository instances, not just the global one. The change is tiny—just a comment and a one-line patch—but it carries weight because it formalizes a technical constraint that emerged from earlier discussions between Junio, Patrick Steinhardt, and others about how to generalize Git's settings machinery.

Patrick Steinhardt has already acked the patch, signaling agreement with the direction. There’s no controversy here; this is a straightforward documentation update that serves as a reminder to contributors that any future work on this part of the codebase must first address its current limitation. The patch is now part of the `the_repository` removal effort, which remains an active, high-volume project touching nearly every subsystem in Git.
