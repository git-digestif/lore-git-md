This is a bugfix patch for the graph-drawing logic in `git log --graph`. It addresses a rendering glitch introduced in commit a34c00d96 (July 2026) where orphaned commits—such as those created with `git merge --allow-unrelated-histories`—are incorrectly drawn with a spurious parent connection when using `git log --graph --all --oneline`. The issue manifests as a misaligned rightmost lane that extends into empty space, making the graph harder to read.

The patch modifies `graph_is_visual_root()` in `graph.c` to avoid treating a commit as a visual root when there are columns to its right. This prevents the graph engine from adding an unnecessary indentation row (`GRAPH_PRE_ROOT`) that was causing the misalignment. The fix is minimal and surgical: it adds a single condition (`graph->commit_index + 1 >= graph->num_columns`) to the existing logic, ensuring orphaned commits are rendered as standalone nodes without spurious connections.

The patch includes a new test case in `t/t4218-log-graph-indentation.sh` that verifies the corrected behavior. The test creates a repository with an orphaned branch, merges it into the main history, and checks that the ASCII-art output matches the expected layout. The reproduction is self-contained and platform-agnostic, though the original bug report noted the issue on Git for Windows 2.56.0.

Caspar Duregger, the patch author, has provided a clear commit message with before/after ASCII-art illustrations and a detailed explanation of the root cause. The patch aligns with the diagnosis Pablo Sabater shared earlier in the thread, who identified the `GRAPH_PRE_ROOT` state as the source of the misalignment. While the patch itself is ready for review, it was not sent using `git send-email`, so the `b4` tool cannot apply it—this procedural hurdle is the only remaining blocker before substantive review can begin.

The fix looks well-motivated and narrowly scoped. It touches only the graph-drawing logic and does not affect on-disk formats or other Git commands. If the rendering issue bothers you, this patch is worth tracking.
