This is a documentation patch. Junio C Hamano updates the `git-branch` man page to consistently recommend `git switch` over `git checkout` in an example comment. The change replaces a reference to `checkout -b` with `switch -c` in a note explaining how to create and switch to a new branch in one step.

The patch is a follow-up to 328c6cb853 (2019), which began promoting `git switch` in the same document but missed this one instance. The commit message acknowledges that `git checkout` remains supported (and that the `switch`/`restore` split was not fully successful), but opts for internal consistency in the documentation rather than listing both alternatives.

Only one line in `Documentation/git-branch.adoc` is touched. The patch is self-contained, well-motivated, and unlikely to be controversial.
