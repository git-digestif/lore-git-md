This is a documentation patch that completely rewrites the EXAMPLES section of the `git diff` man page. The author, Julia Evans, gathered feedback from Git users (via Mastodon) to identify the most common and useful `git diff` incantations, then restructured the section to reflect modern usage patterns.

The new EXAMPLES section is organized into five subsections with table-formatted command summaries: uncommitted changes, diffing specific files/directories, diffing branches or commits, summarizing output, and alternative diff displays. The tables link to option definitions elsewhere in the man page, and the section now uses `--merge-base` instead of the `...` syntax to reduce confusion. The patch also adds a pointer to the EXAMPLES section in the DESCRIPTION to help users discover it.

Julia notes in a self-review that the table format improves readability and conciseness but may wrap on 80-character terminals. She suggests adding `git diff AUTO_MERGE` as a "cool little-known example" but has not yet included it. The patch touches only `Documentation/git-diff.adoc` and `Documentation/diff-options.adoc`, adding anchors for cross-referencing. No code or test changes are involved. The motivation is clear: user feedback indicates the current examples are outdated and hard to follow.
