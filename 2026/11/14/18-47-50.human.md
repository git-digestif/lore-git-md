This is the first patch in Wasswa Edson’s three-part series converting `git credential` to use `OPT_SUBCOMMAND`. It fixes a long-standing mismatch between the command’s `-h` output and its documentation: the usage string omitted the `capability` subcommand, while the SYNOPSIS in the man page listed it but used plain literal formatting instead of the `[verse]` markup that the test suite expects. The patch adds `capability` to the usage string, switches the SYNOPSIS to `[verse]`, and removes `credential` from the list of known mismatches in `t0450/adoc-help-mismatches`.

The change is purely mechanical and uncontroversial—it aligns the help text with the actual implementation without altering any behavior. The patch touches only three files and is a clear prerequisite for the later refactoring steps. No review feedback has surfaced yet, but given the straightforward nature of the fix, it looks ready to proceed.
