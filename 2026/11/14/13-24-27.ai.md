This is the first patch in Harald Nordgren’s v7 series introducing `git branch --delete-integrated`. It extracts the `branch.<name>.deleteMerged` opt-out check into a reusable helper, `branch_opted_out()`, so the same logic can be used for both `--delete-merged` and the new `--delete-integrated` flag. The helper takes a `strbuf` for the config key, the branch name, and the `flags` bitmask, returning `true` if the branch should be processed (config unset or `true`) and `false` if opted out. In non-quiet mode, it emits an informational message when skipping. The patch is a pure refactoring with no behavior change and remains uncontroversial, as noted in the thread context. It touches only `builtin/branch.c` and is ready for integration.
