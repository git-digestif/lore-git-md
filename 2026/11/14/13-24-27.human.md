This is the first patch in Harald Nordgren’s v7 series introducing `git branch --delete-integrated`. It is a pure refactoring that extracts the `branch.<name>.deleteMerged` opt-out check into a reusable helper, `branch_opted_out()`. The helper takes a `strbuf` for the config key, the branch name, and the `flags` bitmask, returning `true` if the branch should be processed (config unset or `true`) and `false` if opted out. When skipping, it emits an informational message unless `--quiet` is set.

The patch is explicitly uncontroversial: it makes no behavioral changes and is a straightforward code move. The helper will be reused in the third patch, which implements the `--delete-integrated` flag. This patch is ready for integration and has no open review feedback.
