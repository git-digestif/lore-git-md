> I noticed that worktree_git_path() returns a pointer to a static buffer managed
> by get_pathname(). I'll copy the result into tmp immediately, before calling
> other functions that might overwrite the buffer:
>
> ```
>     modules_dir = worktree_git_path(wt, "modules/");
>     if (is_absolute_path(modules_dir))
>         relative_path(modules_dir, wt->path, &tmp);
>     else
>         strbuf_addstr(&tmp, modules_dir);
>     modules_dir = tmp.buf;
> ```
>


Correction: relative_path() does not always store the result in tmp.
The code should be:

```
    modules_dir = worktree_git_path(wt, "modules/");
    if (is_absolute_path(modules_dir)) {
        modules_dir = relative_path(modules_dir, wt->path, &tmp);
    } else {
        strbuf_addstr(&tmp, modules_dir);
        modules_dir = tmp.buf;
    }

```
