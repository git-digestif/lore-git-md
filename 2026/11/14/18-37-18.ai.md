This is a bugfix patch for the `for-each-ref` and `git refs list` commands, resolving a long-standing segmentation fault when `--no-format` is used.

The patch moves the default format assignment to *after* command-line parsing, ensuring that `--no-format` (which sets the format string to `NULL`) does not cause a crash. Instead, it now restores the default output, matching the behavior of `git branch` and `git tag`. The fix is minimal—just four lines of code—and includes a new test in `t/for-each-ref-tests.sh` to verify that `--format=<fmt> --no-format` produces the same output as no format option at all.

This version (v2) updates only the Signed-off-by line to comply with the project's real-name policy, with no changes to the code or logic. The patch is effectively converged, with Junio confirming the bug and favoring the approach. The crash has existed since 2007 (commit `c3428da87f`), and the fix aligns the command with the rest of Git's ref-listing tools.

Files touched: `builtin/for-each-ref.c` and `t/for-each-ref-tests.sh`. The change is uncontroversial, well-tested, and ready for integration.
