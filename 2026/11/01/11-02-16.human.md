This is the third and final patch in a CI/build system series that restores Ubuntu 26.04 compatibility for Git's GitHub Actions workflows. It pins the `linux32` job to Ubuntu 24.04 to work around a temporary Docker networking issue where DNS resolution fails in i386 containers on the newer runner image.

The problem is specific to Docker 29.4.2 on Ubuntu 26.04, where the seccomp profile blocks `socketcall` in 32-bit glibc containers, breaking DNS lookups for `deb.debian.org` before the repository is even checked out. The fix is minimal: the job now conditionally uses Ubuntu 24.04 only for the `linux32` matrix entry, while all other jobs continue using `ubuntu-latest`. This matches the approach taken in Git for Windows by Johannes Schindelin, whose prior work the author cites as tested precedent.

The patch touches only `.github/workflows/main.yml` and changes just three lines, making it a targeted, low-risk fix. The underlying Docker issue is tracked in a GitHub Actions runner-images issue and is expected to be resolved in future updates, so this is framed as a temporary measure rather than a permanent change. No other jobs or CI infrastructure are affected, and the fix is self-contained.

This looks like a pragmatic solution to an immediate breakage. The patch is well-motivated, clearly explains the technical root cause, and avoids broader CI refactoring. It should be uncontroversial, though reviewers may note that the workaround will eventually need to be reverted once the upstream Docker issue is fixed.
