This is the third patch in a CI/build system series addressing Ubuntu 26.04 compatibility breakage in GitHub Actions. It pins the `linux32` job to Ubuntu 24.04 to work around a temporary Docker networking issue where DNS resolution fails in i386 containers on Ubuntu 26.04 hosts. The problem stems from Docker 29.4.2's seccomp profile blocking `socketcall` for 32-bit glibc containers, a regression that does not affect Ubuntu 24.04. The fix is minimal: a conditional `runs-on` expression in `.github/workflows/main.yml` that selects `ubuntu-24.04` only for the `linux32` job, leaving all other jobs on `ubuntu-latest`.

The patch references a GitHub Actions runner-images issue (#14790) documenting the regression, signaling this is a known upstream problem expected to be resolved in future runner updates. The author credits Johannes Schindelin for the underlying approach, reinforcing the fix's tested precedent in Git for Windows. No new symbols or on-disk formats are introduced, and the change is self-contained to the CI workflow file. While the workaround is temporary, it restores functionality without broader CI redesign, aligning with the series' pragmatic goal of unblocking failing jobs. The patch is unlikely to be controversial, though reviewers may note the temporary nature of the fix and its reliance on a specific runner version.
