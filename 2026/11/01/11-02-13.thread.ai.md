Subject: CI: Fix Ubuntu 26.04 compatibility after GitHub Actions update
Series version: v1 (initial submission)
Originating author: Harald Nordgren (via GitGitGadget)
Thread type: patch series (build system / CI)

Core problem or goal
Restore four failing CI jobs on GitHub Actions after the `ubuntu-latest` runner image was updated to Ubuntu 26.04. The breakage is caused by (1) CLI interface warnings from `apt` vs `apt-get`, (2) a permission error when creating symlinks during dependency installation, and (3) a temporary Docker networking issue (DNS resolution for `deb.debian.org`) in the `linux32` job. The series applies minimal, targeted fixes without redesigning the CI infrastructure.

Current status
Under review; no prior versions. The patches touch only `.github/workflows/main.yml` and `ci/install-dependencies.sh`. The fixes are based on prior work by Johannes Schindelin in Git for Windows, suggesting they have been tested in a similar environment.

Key technical details
- Files: `.github/workflows/main.yml`, `ci/install-dependencies.sh`
- Jobs affected: `linux32`, `documentation`, `fuzz-smoke`, `static-analysis`
- Changes:
  1. Switch from `apt` to `apt-get` to silence CLI interface warnings (hygiene).
  2. Run `ln` with `sudo` to work around a permission issue when creating symlinks during dependency installation (affects `documentation`, `fuzz-smoke`, `static-analysis`).
  3. Pin the `linux32` job to Ubuntu 24.04 to bypass a temporary Docker networking issue (DNS resolution for `deb.debian.org`).
- New or renamed symbols: none
- On-disk format changes: none
- Test coverage: CI jobs themselves; no new test files

Open questions and loose ends
- The `sudo` workaround may draw scrutiny if reviewers prefer a more robust solution (e.g., adjusting file permissions or avoiding symlinks).
- The networking fix for `linux32` is a temporary measure; the underlying Docker issue is expected to be resolved in future runner images.
