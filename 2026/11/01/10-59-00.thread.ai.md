Core problem or goal
Improve observability and consistency of `git maintenance run` lock handling. The series adds a Trace2 data event for `--auto` skips due to lock existence and aligns manual invocations (`git maintenance run` without `--auto`) with `git gc`’s fail-fast behavior when the lock cannot be acquired. The latent design question about lock-handling consistency between `--auto` and non-`--auto` modes is explicitly addressed and resolved.

Current status
Under review; v3 posted with all requested mechanical refinements incorporated. The series remains uncontroversial and is ready for final review. No maintainer decisions or merge status reported.

Key technical details
- Files modified: `builtin/gc.c` (Trace2 event and lock-acquisition logic), `t/t7900-maintenance.sh` (updated test).
- New Trace2 event: `"lock/skip": {"reason": <strerror(err)>, "errno": <code>}` under the `"maintenance"` category, using `strerror(err)` unconditionally for the `reason` field. The event is emitted in `--auto` mode even when `--quiet` is specified, ensuring diagnostic data is always available.
- Behavioral change: manual `git maintenance run` now fails with exit code 128 and an error message when the lock cannot be acquired, matching `git gc`’s behavior. `--auto` mode continues to skip silently but logs the Trace2 event. The `--quiet` flag is respected in both cases: output is suppressed, but manual invocations still fail with exit code 128.
- Code organization: the series is split into two focused patches—one for the behavioral change (v3 1/2) and one for the Trace2 event (v3 2/2)—to improve reviewability and bisectability. Duplicated error-message formatting is refactored into the existing `unable_to_lock_message()` helper shared with `git gc`.
- Test updates: verifies both the Trace2 event emission (including error code and `strerror`-based `reason`) and the new exit-code behavior for manual invocations. The lock file is preserved on failure, maintaining the existing design that stale locks require manual inspection. Three new tests in `t/t7900-maintenance.sh` cover manual failure, `--auto` skip, and `--quiet` suppression.
- No on-disk format changes; purely behavioral and diagnostic.
