This is a process update from Junio C Hamano about the Rust reorganization patch series. The fifth version of Mike Hommey’s patch to move Git’s Rust code from `src/` to a dedicated `rust/` subdirectory has been queued in `next`, but Junio now signals it may be dropped unless someone else advocates for it. He acknowledges Mike’s personal interest but says it isn’t enough to justify keeping the patch, especially given the lack of broader enthusiasm and unresolved questions about how Git 3.0’s mandatory Rust components will interact with downstream projects that vendor Git’s C code. The patch itself is technically complete and applies cleanly, but its future now hinges on whether another contributor steps forward to champion it. No new technical feedback is offered—this is purely about the patch’s viability in the integration queue.
