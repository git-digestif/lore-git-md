This is the fifth and final patch in Andy Koppe’s v2 series updating Git’s documentation, tests, and code comments to align with the 2024 terminology change that narrowed "pseudoref" to mean only FETCH_HEAD and MERGE_HEAD, while introducing "root ref" for refs outside the "refs/" hierarchy (e.g., HEAD, ORIG_HEAD). The series as a whole is a documentation and terminology cleanup, and this patch specifically updates test scripts to stop using "pseudoref" in its old, broader sense.

The patch touches ten test scripts, replacing outdated terminology in test titles, comments, and variable names. In `t1400-update-ref.sh` and `t4013-diff-various.sh`, it renames test-specific root refs from PSEUDOREF to ROOT_REF_HEAD and from REVERSE to REVERSE_HEAD to follow the naming rules for root refs, including updating the expected output file in `t4013`. It also corrects references to FETCH_HEAD and MERGE_HEAD as "special refs" (the old term) to "pseudorefs" (the current term). The changes are mechanical and do not alter test behavior, but they ensure consistency with the glossary and documentation updates in the earlier patches.

The patch appears uncontroversial and ready for merging. It addresses all remaining instances of the old terminology in the test suite and completes the series’ goal of aligning Git’s documentation, code comments, and tests with the 2024 terminology change. No new test cases are added, and the changes are limited to terminology and naming. The series as a whole has addressed most review feedback from Junio C Hamano and Patrick Steinhardt, and this patch should not introduce new issues. The only remaining loose ends from the series are minor documentation nits in Patch 3/5, which are unrelated to this patch.
