This thread is about fixing four CI jobs that broke after GitHub Actions updated its `ubuntu-latest` runner to Ubuntu 26.04. Harald Nordgren sent a three-patch series that restores functionality with minimal changes: switching from `apt` to `apt-get` to silence CLI warnings, adding `sudo` to a symlink command to bypass a permission error, and pinning the `linux32` job to Ubuntu 24.04 to work around a Docker networking issue. The fixes are based on prior work by Johannes Schindelin in Git for Windows and are now under review.

Junio C Hamano has queued the series for integration, signaling acceptance of the pragmatic approach. He noted the `sudo` workaround is temporary, the `apt-get` change is a hygiene improvement, and the networking pin will need to be reverted once the upstream Docker issue is resolved. The series is small, touching only `.github/workflows/main.yml` and `ci/install-dependencies.sh`, and is headed for the `seen` branch unless objections arise. The only remaining question is whether the `sudo` workaround will face deeper scrutiny, but so far it hasn’t.
