This thread is about a small but urgent patch series from Harald Nordgren that fixes four failing CI jobs on GitHub Actions after the `ubuntu-latest` runner was updated to Ubuntu 26.04. The changes are minimal and pragmatic, targeting only the immediate breakage rather than redesigning the CI infrastructure.

The series consists of three patches: one switches the `linux32` job from `apt` to `apt-get` to silence CLI warnings, another works around a permission issue when creating symlinks during dependency installation by using `sudo`, and the third pins the `linux32` job to Ubuntu 24.04 to restore networking (specifically DNS resolution for `deb.debian.org`), bypassing a temporary Docker issue. These fixes are based on prior work by Johannes Schindelin in Git for Windows, suggesting they’ve been tested in a similar environment. The changes are confined to `.github/workflows/main.yml` and `ci/install-dependencies.sh`, with no impact on core Git functionality.

The motivation is straightforward: the CI jobs are broken, and these patches restore them to working order. The approach is conservative, avoiding broader refactoring in favor of targeted fixes. While the series is unlikely to be controversial, the `sudo` workaround might draw scrutiny if reviewers prefer a more robust solution. So far, there’s been no review feedback, so the series is still open for discussion.
