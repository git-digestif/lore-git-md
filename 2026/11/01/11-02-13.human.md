This is a CI/build system patch series fixing four failing GitHub Actions jobs after Ubuntu’s default runner image upgraded to 26.04.

The failures are concrete and recent: the documentation, fuzz smoke-test, and static-analysis jobs all break because `ln` cannot overwrite `/usr/bin/dirname` without `sudo`, while the linux32 job loses DNS resolution for `deb.debian.org`. The series works around the first issue by running `ln` with elevated permissions and pins the linux32 job to Ubuntu 24.04 until the Docker image update in `actions/runner-images#15205` rolls out. It also switches the linux32 job from `apt` to `apt-get` to silence CLI-interface warnings.

The fixes are borrowed from Johannes Schindelin’s Git for Windows patches, so they have already been battle-tested in a similar environment. The changes are small (two files, five insertions, three deletions) and narrowly target the CI breakage without touching core Git code.

If you care about CI stability or run GitHub workflows yourself, this series is worth a quick look—it restores green builds with minimal risk.
