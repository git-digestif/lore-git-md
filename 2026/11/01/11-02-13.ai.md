This is a CI/build system patch series targeting Ubuntu 26.04 compatibility. The series fixes four failing CI jobs after GitHub Actions updated `ubuntu-latest` to Ubuntu 26.04. The changes are minimal and pragmatic, addressing immediate breakage rather than redesigning the CI infrastructure.

The first patch switches the `linux32` job from `apt` to `apt-get` to silence CLI interface warnings. The second works around a permission issue when creating symlinks during dependency installation by running `ln` with `sudo`. The third pins the `linux32` job to Ubuntu 24.04 to restore networking (specifically DNS resolution for `deb.debian.org`), bypassing a temporary Docker issue that will eventually be fixed in the runner images.

The fixes are based on prior work by Johannes Schindelin in Git for Windows, suggesting they are tested in a similar environment. The series touches only `.github/workflows/main.yml` and `ci/install-dependencies.sh`, with no changes to core Git functionality. The motivation is clear: CI jobs are broken, and these patches restore them to working order. The approach is conservative, avoiding broader refactoring in favor of targeted fixes.

Key technical details: the symlink issue affects the `documentation`, `fuzz-smoke`, and `static-analysis` jobs; the networking fix is specific to `linux32`; and the `apt-get` change is a hygiene improvement. The series is self-contained and unlikely to be controversial, though the `sudo` workaround might draw scrutiny if reviewers prefer a more robust solution. The patches are small (5 insertions, 3 deletions) and focused on immediate breakage rather than long-term CI improvements.
