This is the first patch in Harald Nordgren’s four-part series introducing `git branch --delete-integrated`. It is a pure refactoring patch that extracts the existing `branch.<name>.deleteMerged` opt-out check from `delete_merged_branches()` into a new helper function, `branch_opted_out()`. The helper will be reused in the upcoming `--delete-integrated` logic to ensure consistent behavior for both flags. The patch makes no functional changes and is explicitly marked as uncontroversial and ready for integration. It touches only `builtin/branch.c` and is a straightforward code reorganization with no user-visible impact.
