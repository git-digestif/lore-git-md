This thread is about a small but important documentation update to `Documentation/CodingGuidelines` to reflect Git’s new minimum Perl version requirement (5.26.0, up from 5.8.1). The change was prompted by commit 702d8c1f3b, which enforced this version bump in the codebase using `require v5.26`. The discussion has focused on ensuring the documentation matches the code’s syntax precisely.

The key point of contention—now resolved—was whether the guideline should use `require v5.26` or `use Perl 5.026000`. Junio C Hamano and brian m. carlson confirmed that `require v5.26` is the correct choice, as it enforces the version requirement without enabling Perl features that could unintentionally alter Git’s behavior. The thread has clarified this detail, and the only remaining step is for the author, Tuomas Ahola, to send a revised patch with the corrected wording. The update is uncontroversial and expected to merge once submitted. No other changes or objections have been raised.
