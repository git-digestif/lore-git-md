This thread is about a small but necessary documentation update to `Documentation/CodingGuidelines` to reflect Git's new minimum Perl version requirement (5.26.0, up from 5.8.1). The change was introduced by commit 702d8c1f3b in October 2024, and Tuomas Ahola sent a patch to update the documentation accordingly.

The patch itself is straightforward—it only touches a single line—but Junio C Hamano spotted a mismatch between the proposed wording (`"use Perl 5.026000"`) and the actual code, which uses `require v5.26` to avoid enabling Perl features. This is the only remaining issue, and once fixed, the patch should be ready to merge. No other participants have weighed in, and the thread remains uncontroversial. The update is purely mechanical, with no broader implications for Git's codebase or behavior.
