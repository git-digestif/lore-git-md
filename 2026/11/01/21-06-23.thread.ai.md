Thread identity: Outreachy proposal for *"Improve how command arguments and options are scanned and parsed"* by Cynthia Uche (also using the name Priestess), targeting the December 2026 Outreachy round. Thread type: project proposal (RFC).

Core problem or goal: Extend the `early_scan_options()` API (introduced in Christian Couder’s `cc/early-scan-options` series, currently in `seen`) to additional Git commands that currently perform ad-hoc argument scanning before `parse_options()`. The goal is to eliminate discrepancies between early scanning and `parse_options()` by converting commands to use the new API, prioritizing test coverage, incremental conversion, and preserving backward compatibility where intentional. The proposal has been refined to focus on `git bisect` as the primary target, with other commands removed or deferred due to intentional restrictions or concurrent work.
