Thread identity: Outreachy proposal for *"Improve how command arguments and options are scanned and parsed"* by Cynthia Uche (also using the name Priestess), targeting the December 2026 Outreachy round. Thread type: project proposal (RFC).

Core problem or goal: Extend the `early_scan_options()` API (introduced in Christian Couder’s `cc/early-scan-options` series, now in `next` as of 6 Nov) to additional Git commands that currently perform ad-hoc argument scanning before `parse_options()`. The goal is to eliminate discrepancies between early scanning and `parse_options()` by converting commands to use the new API, with a focus on `git bisect` as the primary target. The proposal prioritizes test coverage, incremental conversion, and backward compatibility, including preserving `BISECT_LOG` contents for replay. `git column` is excluded (its "must be first" rule for `--command` is intentional), `git check-ref-format` is deferred to Hussain Sitamouwala’s concurrent work, and `git unpack-objects` remains a stretch goal.
