This is an Outreachy proposal draft from Cynthia Uche for the project *"Improve how command arguments and options are scanned and parsed"*. The proposal targets the December 2026 Outreachy round and is a well-structured, detailed plan to extend the recently introduced `early_scan_options()` API (currently in `seen` as `cc/early-scan-options`) to additional Git commands.

The core problem is that some Git commands perform ad-hoc argument scanning before calling `parse_options()`, leading to discrepancies where the early scan and `parse_options()` interpret arguments differently. The `early_scan_options()` API (introduced in Christian Couder’s series) addresses this by providing a lightweight, table-driven way to scan arguments consistently with `parse_options()`. Cynthia’s proposal focuses on identifying and converting commands that still use hand-rolled parsing to this new API.
