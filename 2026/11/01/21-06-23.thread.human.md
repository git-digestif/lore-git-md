This Outreachy proposal by Cynthia Uche (also using the name Priestess) aims to extend the `early_scan_options()` API to more Git commands, building on Christian Couder’s ongoing `cc/early-scan-options` series. The project has narrowed its scope after feedback: `git column` is now excluded (its "must be first" rule for `--command` is intentional), and `git check-ref-format` is deferred due to Hussain Sitamouwala’s concurrent work. The primary target is now `git bisect`, with Cynthia planning to convert its subcommands (`bisect_start()`, `bisect_run()`, `bisect_terms()`) incrementally, starting with tests to document current behavior. The proposal remains dependent on Christian’s series graduating from `seen` to `next`, but no other blockers are identified. Cynthia has demonstrated readiness through prior contributions and reviews, and her latest adjustments reflect close engagement with maintainer feedback. The next steps are to finalize the proposal (v3) and await the dependency’s integration.
