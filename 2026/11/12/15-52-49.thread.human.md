Jakub Kulik sent a one-line patch fixing a platform compatibility bug in Git's build-time system information collection. In `get_uname_info()` within `version.c`, the error check `if (uname(&uname_info))` incorrectly treated any non-zero return as failure, but POSIX.1 permits `uname()` to return a positive value on success -- which Solaris does, causing a spurious error report. The fix changes the condition to `if (uname(&uname_info) < 0)`, treating only negative returns as errors per the standard.

Junio C Hamano reviewed the patch and replied "Perfect. Thanks.", confirming it aligns with POSIX.1 and is correct for all compliant platforms. With the maintainer's approval secured, the patch is ready for integration; there are no open questions or follow-ups, and no test coverage was added.
