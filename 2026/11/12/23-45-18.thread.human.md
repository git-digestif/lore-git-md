This "What's cooking" report from Junio Hamano provides a November 2026 snapshot of Git's integration branches, covering what has recently graduated to `master`, what is cooking in `next`, and what is under active review. Here’s the narrative for a developer catching up:

The past month saw several bugfixes and small improvements graduate to `master`, including fixes for large blob handling on Windows (`ep/pack-objects-streamed-large-blobs`), alignment of `git rev-parse @{push}` with triangular workflows (`hn/remote-simple-push-triangular`), and a new security boundary man page (`tc/security-boundary-doc`). Documentation updates also landed, such as a rewritten `git diff` examples section and a standalone guide for detached HEAD.

In `next`, the most impactful topics are refactoring efforts and performance optimizations. The `the_repository` removal continues, with `jc/unpack-trees-repo` and `oa/negotiator-default-no-the-repository` threading repository context through APIs. Performance work includes opt-in merge rename detection in `git log --follow` (`mv/log-follow-merge-opt-in`) and CI speedups using Meson and reftables (`ps/ci-speedups`). A notable behavioral change is `hn/status-compare-branches-default`, which makes `git status` compare against both upstream and push branches by default—this may break existing workflows and is likely to spark discussion.

Under active review, `tb/config-null-values` stands out as a widespread bugfix preventing NULL pointer dereferences in config callbacks, while `ps/odb-loose-stale-cache` addresses false negatives in loose object existence checks. The HTTP retry improvements (`rm/http-retry-improvements`) add exponential backoff and extend retries to POST operations, with Peff and Junio engaged on edge cases. Controversial topics include `wh/checkout-orphaned-commit-warning`, which introduces a config to skip orphaned commit checks (disabled by default in Scalar), and `bc/setup-default-hash-algo`, which defaults `git init` to SHA-256 in breaking changes mode.

The report also highlights stalled topics like `ap/http-preserve-wwwauth-redirect` and `vv/branch-recurse-no-start-ref`, which may be dropped if no progress is made. Dependencies are minimal but notable: `kn/fast-import-tests` relies on `cc/early-scan-options` and `tj/drop-no-parseopt`. Overall, the focus remains on refactoring, performance, and edge-case fixes, with a few behavioral changes that could affect user workflows.
