This is the second patch in Yoichi NAKAYAMA’s three-part series introducing worktree-specific submodule configuration. It implements the core logic that stores submodule settings (`submodule.<name>.active`, `submodule.<name>.url`, etc.) in the worktree config file when `extensions.worktreeConfig` is enabled, rather than in the shared repository config.

The patch modifies `builtin/submodule--helper.c` to use the new `repo_config_set_worktree_gently()` helper (introduced in the series) for all submodule settings except `submodule.<name>.gitdir`, which is handled separately because it must never be shared between worktrees. It also updates `builtin/worktree.c` to filter out `submodule.*.gitdir` entries when copying config during `git worktree add`, ensuring these settings don’t leak into new worktrees. The documentation in `Documentation/config/submodule.adoc` is updated to clarify that `submodule.<name>.gitdir` is stored per-worktree when `extensions.worktreeConfig` is enabled.

The test coverage is thorough, with new tests in `t/t2405-worktree-submodule.sh` verifying that submodule settings are correctly stored in the worktree config, that `git submodule deinit` updates the worktree config rather than the shared config, and that `submodule.*.gitdir` entries are not copied during `git worktree add`. Additional tests in `t/t7425-submodule-gitdir-path-extension.sh` confirm that `gitdir` paths are stored in the worktree config for both main and linked worktrees.

This patch is well-motivated and addresses a clear gap in worktree support for submodules. The implementation is clean, leveraging existing infrastructure (`extensions.worktreeConfig`) and avoiding on-disk format changes. The test coverage appears comprehensive, and the commit message clearly explains the rationale and behavior changes. No controversial design choices are evident, though the interaction with existing submodule workflows (e.g., `git submodule update --init`) may draw further scrutiny in review. The series as a whole looks like a solid, incremental improvement to worktree functionality.
