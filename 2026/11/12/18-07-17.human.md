This is a feature patch adding the `--show-object-format` option to `git ls-remote`, allowing tools like Jujutsu to detect a remote repository’s hash algorithm (SHA-1 or SHA-256) without cloning. Junio C Hamano’s reply to the v2 submission is brief and positive, confirming the implementation’s soundness and test coverage.

Junio explicitly notes that `transport_get_hash_algo()` safely defaults to `GIT_HASH_SHA1_LEGACY` even over older protocols, so the lack of a null-check (previously flagged by Patrick Steinhardt as a broader robustness concern) is not an issue here. He also approves the test design, which exercises both SHA-1 and SHA-256 repositories (empty and non-empty), protocol versions v0 and v2, and nongit environments. The patch is now effectively unblocked: all technical feedback has been addressed, and Junio’s tone suggests it is likely to proceed toward `next` unless new objections arise.
