Core problem or goal
Refactor the archive subsystem (`archive-tar.c`, `archive-zip.c`, `archive.c`, and related builtins) to accept explicit `struct repository *` parameters instead of relying on the global `the_repository` variable. This advances the project-wide goal of eliminating implicit global state.

Current status
Under review. The patch is a self-contained unit within the larger `the_repository` removal effort. No prior versions have been posted. René Scharfe’s review identifies two issues: (1) `init_zip_archiver()` is given a `struct repository *` parameter it does not use, and (2) the commit message overstates the scope by claiming `USE_THE_REPOSITORY_VARIABLE` is removed from all archival modules when only the tar handler is modified. A v2 is expected to address these.
