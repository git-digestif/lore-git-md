Subject: [PATCH] ref-filter: fix double-free crash in for-each-ref
Series version: standalone patch (no series)
Originating author: Mustafa Bayar
Thread type: bugfix

Core problem or goal
Fix a double-free crash in `git for-each-ref` when processing refs that point to missing objects. The crash is a regression introduced in v2.53.0 by commit a29e2e8fe ("ref-filter: parse objects on demand") and later exacerbated by bea37f1d6 ("ref-filter: fix stale parsed objects"). The root cause is a dangling pointer in `oi->content` after `get_object()` frees the buffer but fails to reset the pointer; a subsequent ref lookup failure triggers a second free of the same buffer.
