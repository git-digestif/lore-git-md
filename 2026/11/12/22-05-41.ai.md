This is the final patch (5/5) in Andy Koppe’s v4 series to align Git’s documentation and tests with the 2024 terminology change that narrowed "pseudoref" to `FETCH_HEAD` and `MERGE_HEAD` only, while introducing "root ref" for refs outside the `refs/` hierarchy (e.g., `HEAD`, `ORIG_HEAD`). The series is now uncontroversial and ready for merging, with all prior review feedback incorporated.

This patch updates test scripts to stop using "pseudoref" for root refs, renames test refs to follow root ref naming rules (`PSEUDOREF` → `ROOT_REF_HEAD`, `REVERSE` → `REVERSE_HEAD`), and corrects outdated references to `FETCH_HEAD`/`MERGE_HEAD` as "special refs." It touches ten test files, including `t1400-update-ref.sh` (which tests root ref creation, deletion, and overwriting) and `t4013-diff-various.sh` (which updates expected output to reflect the renamed ref). The changes are mechanical and do not alter test logic—only terminology and naming. The patch also updates a test title in `t1460-refs-migrate.sh` to clarify that pseudorefs (not root refs) are left alone during ref storage migration.

No new test cases are added, and the patch is purely cosmetic. The updates are consistent with the glossary and documentation changes in earlier patches, completing the series’ goal of eliminating outdated terminology. The patch is well-scoped and uncontroversial, with no open questions or deferred issues. Key symbols modified include test ref names (`ROOT_REF_HEAD`, `REVERSE_HEAD`) and test titles/comments in `t/show-ref-exists-tests.sh`, `t6302-for-each-ref-filter.sh`, and `t9902-completion.sh`.
