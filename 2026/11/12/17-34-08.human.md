This is the eighth patch in Karthik Nayak’s 20-patch **test modernization** series that splits the sprawling `t9300-fast-import.sh` into smaller, self-contained files. The patch refactors the “series O” tests (stream-comment handling) so they no longer depend on side effects from earlier tests.

The core change is replacing the hard-coded `from refs/heads/branch^0` with a fresh repository created by the new `setup_import_repo()` helper, which also sets `fastimport.unpackLimit=0` to keep packs around for later inspection. Each test now runs in its own subshell, imports a reference commit via `import_reference_commit()`, and verifies the result by comparing trees and commit hashes instead of relying on the old `N3` commit. The “repack before next test” test is dropped, and the repack is moved into the test that actually needs it.

The patch is purely mechanical, touching only `t9300-fast-import.sh` and introducing no new test files. It follows the same isolation pattern established in earlier patches, so the risk of regressions is low. Junio has already praised the overall direction, and the v2 resolves all known conflicts, so this looks like a safe, incremental step toward a more maintainable test suite.
