The patch set aligns Git’s glossary, man pages, code comments, and tests with the 2024 terminology change that narrowed "pseudoref" to `FETCH_HEAD` and `MERGE_HEAD` only, while introducing "root ref" for refs outside the `refs/` hierarchy (e.g., `HEAD`, `ORIG_HEAD`). Key symbols touched include `REFS_FOR_EACH_INCLUDE_ROOT_REFS` in `refs.h`, the `--merge` error message in `revision.c`, and the help text for `git for-each-ref --include-root-refs`. The glossary now explicitly lists the exhaustive set of root refs, their naming rules, and the behavioral distinction that pseudorefs can record multiple object IDs and carry metadata, unlike root refs. Test scripts were updated to use the new terminology, and man pages like `git-ls-remote(1)` now describe default behavior (showing `HEAD` and refs under `refs/`) and peeling behavior more clearly.

No behavioral changes are introduced—this is a pure documentation and terminology cleanup. The series resolves long-standing inconsistencies and provides clearer guidance for users and contributors. All substantive and editorial review feedback from Junio, Patrick Steinhardt, and Julia Evans has been incorporated. The series is uncontroversial and ready for graduation to `master`.
