This is the ninth patch in Karthik Nayak’s **v2 test modernization series** that splits the monolithic `t9300-fast-import.sh` into smaller, self-contained test files. The patch targets the "series R" tests, which verify Git’s handling of very large blobs (larger than the `--big-file-threshold`).

The original tests relied on shared state: one test imported the blobs, and later tests inspected the results. This patch folds all three tests (`R: blob bigger than threshold`, `R: verify created pack`, `R: verify written objects`, and `R: blob appears only once`) into a single self-contained test that imports the blobs, verifies the pack, checks the blob contents, and confirms the blob is stored only once. The new test uses a fresh repository created by `git init repo` and sets `fastimport.unpackLimit=0` to ensure a pack is written. It replaces the legacy `verify_packs()` helper (which won’t be available after the test is moved) with an inline loop that runs `git verify-pack -v` on each pack file.

The patch is a clean, mechanical refactoring that maintains the original test coverage while eliminating shared state. The diffstat shows 41 lines removed and 38 lines added, reflecting the consolidation and the addition of the inline pack verification loop. No changes to Git’s behavior or core functionality are introduced; this is purely a test organization improvement.
