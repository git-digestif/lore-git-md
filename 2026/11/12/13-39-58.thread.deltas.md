# Thread deltas

## 2026/11/12

- [2026/11/12/13-39-58 by Windl, Ulrich <u.windl@ukr.de>] Ulrich Windl reported that in Git 2.51.0, "git diff" did not show the shell function name "run_query()" in the hunk header for a function defined with uncommon line-breaking (where a continuation line begins with "_COUNT="), instead showing "get_params()" and the "_COUNT=" line.
- [2026/11/12/20-51-21 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano explained that built-in userdiff patterns have not changed since Git 2.51.0 (only Swift was added and scheme tweaked), so the behavior should reproduce in current code, and diagnosed that for files without a known language suffix any line beginning with a non-whitespace character is treated as a function header, causing the "_COUNT=" line to override "run_query()"; he also noted that the "get_params()" header is expected because function-name detection does not look ahead.
