Core problem or goal
Reduce memory usage in the commit subsystem by eliminating padding in `struct commit` on 64-bit platforms. The change reorders fields to move `unsigned int index` into the 4-byte gap after `struct object`, shrinking the struct from 80 to 72 bytes (10% reduction) with no behavioral change.

Current status
Under review; no prior versions. Patch is minimal (one-line change in `commit.h`), based on commit `1891de46f79dc444a47db1c87bd0c8c76b5463f2`.

- Symbols: `struct commit` (reordered fields: `index` moved after `object`)
- Old vs new: 80 bytes with 8-byte padding → 72 bytes with no padding on 64-bit; no change on 4-byte-aligned platforms (e.g., i386)
- On-disk format: unchanged
