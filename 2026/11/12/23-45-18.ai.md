### **Graduated to `master` (irreversibly part of the next release)**
These topics were in `next` and are now merged to `master`:
- **ep/pack-objects-streamed-large-blobs**: Fixes size truncation for large blobs (>4GiB) on 64-bit Windows by using `size_t` and `off_t` instead of `long`.
- **hn/remote-simple-push-triangular**: Aligns `git rev-parse @{push}` with `git push` behavior for triangular workflows (push remote ≠ fetch remote).
- **jk/test-env-quoting-fix**: Makes `t5702` resilient to GNU coreutils quoting changes by avoiding `env | grep`.
- **oa/range-diff-repo**: Removes reliance on `the_repository` in `range-diff` by using `diffopt->repo`.
- **ps/ci-consolidate-test-variables**: Deduplicates CI test environment variables and optimizes setup.
- **tb/merge-ort-valueless-rename-config**: Accepts valueless config settings (e.g., `diff.renames`) as `true`.
- **tc/security-boundary-doc**: Adds `gitsecurityboundary(7)` to clarify Git’s security guarantees.

### **New Topics (under active review/discussion)**
#### **Performance/Optimizations**
- **wh/checkout-orphaned-commit-warning** (4 commits):
  Introduces a config (`checkout.orphanedCommitCheck`) to skip expensive orphaned commit calculations during `git checkout` from detached HEAD. *Status*: Waiting for author response to Junio’s feedback about default behavior (scalar disables by default).
- **mv/log-follow-merge-opt-in** (1 commit):
  Makes the expensive rename detection in `git log --follow` across merges opt-in via `--follow=merges` or `log.follow=merges`. *Status*: Needs review; fast-tracked as a simpler alternative to a retracted series.
- **kk/large-pack-assertions** (2 commits):
  Fixes `unpack-objects` to use `size_t` for large blobs and updates `t5608` to assert pack sizes >2GiB. *Status*: Will merge to `next`.
- **ps/ci-speedups** (7 commits):
  Optimizes GitLab CI by building with Meson, caching test outputs, and using reftables for large-ref tests. *Status*: Will merge to `next` pending minor feedback.

#### **Bugfixes**
- **tb/config-null-values** (15 commits):
  Prevents NULL pointer dereferences in config callbacks (e.g., `color.blame.*`, `remote.<name>.tagOpt`). *Status*: Will merge to `next`; addresses a widespread issue.
- **ak/t2401-w2-path-fix** (1 commit):
  Fixes `t2401` test failure when trash directory paths contain `w2`. *Status*: Will merge to `next`.
- **yh/refs-drop-peel-iterated-oid** (1 commit):
  Removes unused `peel_iterated_oid()` declaration. *Status*: Will merge to `next`.
- **ps/odb-loose-stale-cache** (2 commits):

#### **Refactoring/Code Cleanup**

  Blocks `git worktree remove` during rebase/bisect unless `--force` is given; adds `%(currentworktree)` atom. *Status*: Needs review.
- **kk/commit-struct-padding** (1 commit):

- **kn/fast-import-tests** (20 commits):

- **ps/rerere-subcommands** (12 commits):
