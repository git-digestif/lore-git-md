This is the sixth patch in Karthik Nayak’s 20-patch **test modernization** series that splits the sprawling `t9300-fast-import.sh` into smaller, self-contained files. The patch refactors the “series Q” tests (notes-related functionality) so each test runs in its own fresh repository, eliminating hidden dependencies on earlier test state.

The core change replaces the original “Q: commit notes” test with a new `setup_notes_repo()` helper that creates a clean repository, runs the fast-import stream, and exports the commit hashes (`commit1`, `commit2`, `commit3`) that the subsequent verification tests need. Every test now calls `setup_notes_repo()` at the start, ensuring isolation. The patch also drops the redundant “Q: verify pack” test, since pack verification is already covered elsewhere.

The diff is purely mechanical: 212 lines added (the new helper and per-test repository scaffolding) and 127 lines removed (the old shared-state setup). No behavior changes are introduced, and the patch keeps the same test coverage while making the tests easier to debug and modify. This continues the pattern established in earlier patches and keeps the series on track for eventual graduation to `next`.
