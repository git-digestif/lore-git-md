This is the second patch in Patrick Steinhardt’s six-patch refactoring series that moves the loose-object backend into its own source file (`odb/source-loose.c`). The patch specifically relocates the logic for deriving loose-object filesystem paths from `object-file.c` to the backend file.

The change is mechanical: the `odb_loose_path()` function and its helper `fill_loose_path()` are moved verbatim into `odb/source-loose.c`, and the helper is inlined. The function’s declaration remains in `object-file.h` because the dumb transport still needs it, but the implementation is now backend-specific. No behavior changes are introduced; this is purely a code reorganization step in the ongoing ODB abstraction effort. The patch is clean, well-contained, and directly advances the series’ goal of isolating backend internals.
