This is the fourth patch in Patrick Steinhardt’s six-patch refactoring series that moves the loose-object backend into its own source file (`odb/source-loose.c`). The patch itself is a small, focused cleanup: it removes 20 lines of duplicated mmap logic by consolidating the mapping code into the existing `map_fd()` helper. The only difference between the two call sites was path derivation, which is now handled by passing the correct path to `map_fd()`.

The change is purely mechanical and maintains existing behavior. It’s a natural follow-up to the earlier patches in the series, which relocated loose-object reading logic to the new backend file. No new public symbols are introduced, and the patch doesn’t touch any other files, making it a low-risk step in the broader ODB abstraction effort. The series is still under review, and this patch looks like a straightforward improvement that should be uncontroversial.
