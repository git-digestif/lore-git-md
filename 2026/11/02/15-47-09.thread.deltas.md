# Thread deltas

## 2026/11/02

- [2026/11/02/15-47-09 by Kristofer Karlsson via GitGitGadget <gitgitgadget@gmail.com>] Kristofer Karlsson submitted a patch to make rev-list's connectivity check ignore replacement objects (by calling `disable_replace_refs()` when `--connectivity-check` is given and dropping `OBJECT_INFO_LOOKUP_REPLACE` from `tree-verify.c`), so that it verifies the same original objects that fsck, prune, pack-objects and upload-pack read.
- [2026/11/02/22-05-16 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano endorsed the change as "absolutely the right thing to do," approved verifying the underlying real objects, and noted that ensuring replacement objects are also backed by reachable objects could be addressed separately.

## 2026/11/03

- [2026/11/03/18-36-55 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano agreed with Kristofer Karlsson that no extra work is needed to check both original and replacement objects, saying the "ignore replacements" wording had misled him into thinking only the underlying objects' connections were checked.
