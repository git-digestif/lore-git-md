This is the fourth patch in Patrick Steinhardt’s seven-patch CI/build system cleanup series. It refactors `ci/lib.sh` to merge three separate `case` statements over `$jobname` into a single block, eliminating 25 lines of redundant code while adding 16 lines of consolidated logic. The change moves the `linux-musl-meson` and `linux-feature-testbed` job configurations into the primary `case` statement, with `linux-musl-meson` now explicitly disabling Rust support via `-Drust=disabled`. This is a mechanical refactoring with no behavior change—only the structure of the code is altered to reduce duplication and improve maintainability.

The patch is part of the broader effort to centralize CI environment variable overrides, making the configuration more resilient to future job additions. Earlier patches in the series (1–3) laid the groundwork by moving hardcoded variable assignments into `ci/lib.sh` and replacing per-distribution rules with platform-wide patterns. This patch continues that consolidation, using the same pattern-matching approach to avoid explicit job-name lists. The `linux-musl-meson` job’s Rust disablement is now co-located with its other settings, and the `linux-feature-testbed` job’s 14 environment variables are deduplicated from a redundant `case` block.

No new symbols or behaviors are introduced here; the patch simply reorganizes existing logic. The change is uncontroversial and aligns with the positive feedback received on earlier patches in the series (Jeff King called them "obviously good," Phillip Wood "nice," and Toon Claes "noncontroversial"). The only functional addition is the `-Drust=disabled` flag for `linux-musl-meson`, which was previously set in a separate `case` block and is now merged into the primary one. This patch is likely to be merged as-is, pending Junio C Hamano’s final review of the series.
