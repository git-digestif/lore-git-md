This is the second patch in Patrick Steinhardt’s six-patch refactoring series that moves the loose-object backend into its own source file (`odb/source-loose.c`). Specifically, this patch relocates the logic for deriving loose-object filesystem paths from `object-file.c` to the backend file.

The change is mechanical: the `odb_loose_path()` function and its helper `fill_loose_path()` are moved verbatim into `odb/source-loose.c`, and the external declaration in `object-file.h` is replaced with one in `odb/source-loose.h`. The only behavioral tweak is inlining the helper, which simplifies the call chain without altering functionality. The patch leaves the function exposed for use by the dumb transport, acknowledging that a future abstraction step will be needed to fully hide backend internals.

No new symbols or APIs are introduced; the patch is purely about code organization. The diff is clean and focused, touching only the four files listed in the commit message. This step is a straightforward continuation of the ODB abstraction effort, isolating another piece of loose-backend logic while maintaining compatibility with existing callers.
