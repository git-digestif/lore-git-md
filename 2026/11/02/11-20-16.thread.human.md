This thread is a six-patch refactoring series by Patrick Steinhardt that moves Git's loose-object backend logic into a dedicated source file (`odb/source-loose.c`). The goal is to advance the broader ODB abstraction effort, making backends more modular and exposing dependencies that still tie subsystems to backend internals. The series is now under review, with no substantive technical objections raised so far.

The refactoring touches 20 files, primarily splitting loose-object reading, path derivation, and iteration logic out of `object-file.c` into the new backend file. The changes are mechanical, preserving existing behavior while consolidating mmap logic and cleaning up header includes. Kaartic Sivaraam reviewed all patches, confirming their correctness and noting minor follow-up opportunities—such as moving documentation comments and removing unnecessary includes—but nothing that blocks the series. The final patch (6/6) completed the header hygiene work by making zlib dependencies explicit.

The series conflicts with the in-flight `bc/restrict-hex-to-lowercase` topic, but Patrick provided a resolution in the cover letter. While the refactoring is a stepping stone toward full ODB abstraction, some work remains, like tightening the iteration function signature and hiding backend internals from callers like the dumb transport. For now, the series appears ready for integration once the broader ODB effort progresses.
