This thread is a six-patch refactoring series by Patrick Steinhardt that moves Git's loose-object backend logic into a dedicated source file (`odb/source-loose.c`). The goal is to advance the broader ODB abstraction effort, making backends more modular and exposing subsystems that still depend on backend internals. The series is under review as version 1, with no substantive feedback yet, though it conflicts with the in-flight `bc/restrict-hex-to-lowercase` topic (a resolution is provided).

The refactoring touches 19 files, primarily relocating loose-object reading, path derivation, and iteration logic from `object-file.c` to `odb/source-loose.c`. Key changes include deduplicating mmap logic and cleaning up header includes to make backend dependencies explicit. The latest patch (6/6) finalizes header hygiene by removing a blanket `#include "git-zlib.h"` from `object-file.h` and adding it explicitly to the nine files that still need zlib. No functional changes are introduced—this is purely structural work.

The series is a stepping stone toward isolating other backends (packed, files) and fully abstracting backend internals, though some loose ends remain, like tightening the iteration function signature and hiding `odb_loose_path()` from dumb transport. Integration timing may depend on resolving the conflict with `bc/restrict-hex-to-lowercase`. So far, only Patrick has weighed in, and the patches appear uncontroversial if the rest of the series is accepted.
