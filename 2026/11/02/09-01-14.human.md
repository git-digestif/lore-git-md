This is a gentle nudge from Junio about the two-patch `git-svn` series that Wesley Schwengle posted in August. The series—now at v2—quietly fixes a long-standing annoyance (spurious migration messages and empty `.git/svn` directories when `git svn info` is run in a plain Git repo) and adds a `NO_GIT_SVN` Makefile knob so users who don’t need SVN support can skip building it entirely.

The only feedback so far was a trivial typo fix that Wesley already addressed in v2. No substantive objections have surfaced, and the changes are narrow and well-motivated. Despite that, the series has sat in Junio’s `seen` branch since late August without attracting further review. Junio is now warning that unless someone steps up to give it a thorough look in the next few weeks, he’ll drop it from the queue. If you care about `git-svn` or build-time flexibility, this is a low-risk, uncontroversial series that could use a second set of eyes.
