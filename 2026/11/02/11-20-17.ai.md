This is the first patch in Patrick Steinhardt’s six-part refactoring series to isolate the loose-object backend into its own source file (`odb/source-loose.c`). It moves the core loose-object reading logic—`read_loose_object()`, `unpack_loose_header()`, `unpack_loose_rest()`, `parse_loose_header()`, and the `map_fd()` helper—from `object-file.c` into the backend file. The patch deletes 300 lines from `object-file.c` and adds 306 lines to `odb/source-loose.c`, with corresponding header declarations removed from `object-file.h`. No new public symbols are exposed; the changes are purely internal reorganization. The patch maintains existing behavior while making the loose backend more self-contained, which is a key step in the broader ODB abstraction effort.
