This is the second patch in Patrick Steinhardt’s seven-patch CI/build system cleanup series. It simplifies how the `GIT_TEST_USE_SET_E` environment variable is set in Git’s CI workflows by replacing per-distribution assignments with a single Linux-wide rule.

The patch addresses a minor but persistent maintenance annoyance: the variable, which enables `set -e` behavior in the test suite, was previously set explicitly for each Linux distribution job (e.g., `almalinux-*`, `debian-*`, `fedora-*`). This approach missed edge cases like the `linux32` job and required manual updates whenever new jobs were added. The fix moves the assignment into a `case` statement keyed on `CI_OS_NAME`, ensuring all Linux jobs (including future ones) inherit the setting automatically. The change is small—six lines added, four removed—but eliminates redundancy and future-proofs the configuration.

Reviewers have already endorsed the series as uncontroversial, and this patch in particular aligns with the broader goal of consolidating test environment variables. No behavioral changes are introduced; the patch merely ensures consistency across Linux jobs. The only platform-specific caveat (macOS’s older Bash version) is preserved, as the rule remains scoped to Linux. This is a straightforward, well-motivated cleanup that should merge without further discussion.
