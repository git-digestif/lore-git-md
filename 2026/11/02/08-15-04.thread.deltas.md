# Thread deltas

## 2026/11/02

- [2026/11/02/08-15-04 by Ebele Lynda Okolo via GitGitGadget <gitgitgadget@gmail.com>] Lynndabel submitted a patch moving `diff_auto_refresh_index` from a global variable into `repo_config_values` so each repository can have its own setting for library use, adding a `repo_diff_auto_refresh_index()` getter that falls back to 1 when the repository is not initialized, updating the config handler and the caller in `builtin/diff.c` to use the new getter, and adding tests verifying `diff.autorefreshindex` can be set to both true and false.

## 2026/11/03

- [2026/11/03/06-21-14 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano rejected the proposal to move diff_auto_refresh_index into repo_config_values, explaining that access to that structure fails when given anything other than the_repository (so the move would not help the library use case), and that the variable is set in diff.c only when the ui-related configuration is read via the git_config() callback, which is not repository-specific but a synthesized result of system, global, and repository configuration files, making repo_config_values an unsuitable place for this setting.
