This is a **contributor housekeeping** patch for the bash-completion script in `contrib/`, updating it to support tab-completion for three recently added `git log` options: `--graph-indent`, `--no-graph-indent`, and `--graph-lane-limit`. The patch is a reroll of Mirko Faina’s earlier submission, now incorporating feedback from Pablo Sabater to include all missing `--graph`-related options and place them alongside `--graph` in the `__git_log_gitk_options` block (rather than the shared `__git_log_common_options` list).

The change is mechanical and low-risk: it adds the three options to the completion script without altering Git’s core behavior or introducing new logic. The commit message is clear and references the commits that introduced the options, making the motivation self-evident. This version of the patch addresses the only substantive review feedback from the first iteration—grouping the options with `--graph`—and expands the scope to include `--graph-lane-limit`, which was previously overlooked.

The patch remains uncontroversial and is likely to be merged once Junio picks it up. The broader architectural discussion about conditional completion (e.g., suppressing `--graph`-dependent options unless `--graph` is present) and self-maintaining completion hints via `parse-options.h` is acknowledged in the thread but not addressed here; those ideas remain speculative and forward-looking. For now, this patch simply fills a gap in the existing completion logic.
