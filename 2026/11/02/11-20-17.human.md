This is the first patch in Patrick Steinhardt’s six-part refactoring series to isolate the loose-object backend into its own source file (`odb/source-loose.c`). It moves the core logic for reading loose objects—including mmap handling, zlib stream unpacking, header parsing, and OID verification—from `object-file.c` into the backend file.

The patch is purely mechanical: 300 lines are deleted from `object-file.c` and 306 lines are added to `odb/source-loose.c`, with no new symbols exposed. All moved functions remain static, preserving the existing behavior. The commit message is concise but clear about the goal: removing loose-backend implementation details from the generic object-file layer. This is a well-scoped step in the broader ODB abstraction effort, and the patch itself looks clean and focused.
