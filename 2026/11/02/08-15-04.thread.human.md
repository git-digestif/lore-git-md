This thread is about a patch from Ebele Lynda Okolo that migrates the `diff_auto_refresh_index` global variable into Git’s repository-scoped configuration as part of the ongoing `the_repository` removal effort. The goal is to eliminate global state so Git can be used as a library with proper isolation between repository instances.

The patch itself is straightforward: it introduces a getter function, `repo_diff_auto_refresh_index()`, removes the global variable, and updates the config handler and caller in `builtin/diff.c`. However, Junio C Hamano has raised a fundamental objection. He argues that placing the variable in `repo_config_values` doesn’t actually solve the isolation problem, since accessing that struct still requires `the_repository`. He also points out that the config callback merges values from system, global, and repository config files, making it unclear how a repository-scoped variable would work in practice. The thread is now stalled, awaiting a response from the author on how to proceed—or whether the variable even needs to be migrated at all. No other reviews have been posted yet.
