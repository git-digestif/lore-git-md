This is the fifth patch in Patrick Steinhardt’s six-patch refactoring series that moves the loose-object backend into its own source file (`odb/source-loose.c`). The series is part of the ongoing ODB abstraction effort to make Git’s object storage layer more modular.

This patch removes the blanket include of `odb/source-loose.h` from `object-file.h` and instead adds explicit includes in every compilation unit that still needs loose-backend internals. The result is a clear map of which files still depend on loose-backend details and will need further abstraction work. Seven files gain the new include; `object-file.h` drops the loose-backend header and gains `odb/streaming.h` instead.

The change is purely mechanical and does not alter behavior. It is a clean, final step in isolating the loose backend and exposing the remaining callers that are not yet backend-agnostic.
