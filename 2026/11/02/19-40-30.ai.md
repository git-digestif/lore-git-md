This patch extends test coverage to SHA-256 repositories by making the existing test hash-agnostic. The core test logic remains unchanged: it still verifies that submodule commit abbreviations are checked against the submodule's object database rather than the superproject's, preventing collisions where the same abbreviated ID could refer to different objects.

The patch touches only the test file `t/t4041-diff-submodule-option.sh`, adding a `test_oid_cache` block to define the expected abbreviated commit ID for each hash algorithm and updating the `printf` statement to use the hash-agnostic value.
