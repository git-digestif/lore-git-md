This thread is about documenting Git’s governance structures in a new `Documentation/Governance.adoc` file. Antonin Delpeuch posted an initial RFC to make the project’s implicit conventions explicit, covering roles, decision processes, and security practices. Junio C Hamano and Jiang Xin provided substantive feedback, most of which has been addressed in preparation for a v2 patch.

The draft now clarifies the Software Freedom Conservancy’s role as a fiscal sponsor, the process for joining the security list, and the straightforward mechanics of transitioning the localization maintainer role. One remaining open question is who moderates the project’s Discord and IRC channels, as Junio does not know the answer. Antonin has also confirmed that the existing `po/` directory documentation is sufficient for describing the localization team, so the governance document will simply link to it rather than duplicate the information.

The series is still in RFC phase, with no merge status reported. Antonin continues to engage stakeholders—including Johannes Schindelin for security team details—and expects to post a revised version once the unresolved questions are settled.
