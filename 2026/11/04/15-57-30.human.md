This is the eighth patch in Patrick Steinhardt’s ten-patch series refactoring the commit-graph write code to consolidate options into a single struct, part of the broader ODB abstraction effort. The patch eliminates an unnecessary layer of indirection in the `git commit-graph` built-in command by removing separate flag fields from `struct opts_commit_graph` and setting the flags directly via `OPT_BIT()` macros.

The change is purely internal and affects only `builtin/commit-graph.c`. It removes 35 lines of boilerplate code that previously copied flags from the command-line options struct into the write/verify flags enums, replacing it with direct assignment. The diff shows the flags for `--reachable`, `--append`, `--split`, `--shallow`, and `--progress` now being set directly into the appropriate `enum commit_graph_write_flags` or `enum commit_graph_verify_flags` variables. The patch also updates the validation logic to check the new flag locations.

This is a clean, mechanical refactoring that aligns with the series’ goal of simplifying the commit-graph write interface. The patch is well-contained and unlikely to introduce regressions, though reviewers may comment on whether the direct flag setting is clearer than the previous indirection. No new behavior or user-visible changes are introduced.
