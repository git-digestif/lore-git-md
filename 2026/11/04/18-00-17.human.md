This is a **bugfix for `git log --graph`** that corrects a misrendering of orphaned branches when using `git log --graph --all --oneline`. The issue—a spurious parent connection extending into empty space—was introduced in commit `a34c00d96` and affects any repository with orphaned commits (e.g., after `git merge --allow-unrelated-histories`). The fix, authored by Caspar Duregger and approved by Pablo Sabater, surgically adjusts `graph.c` to avoid incorrect indentation for orphaned commits with columns to their right.

Junio has now **queued the patch** for integration, signaling it’s ready for `next`. The fix is minimal, well-tested (with a new test case in `t/t4218-log-graph-indentation.sh`), and addresses the root cause without side effects. No substantive objections or edge cases remain, and the regression’s origin is clearly documented. This is a clean, uncontroversial correction that should land smoothly in the next release. If you use `--graph` with `--all`, this patch will restore the expected rendering of orphaned branches.
