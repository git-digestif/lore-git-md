Core problem or goal
Refactor `find_pathspecs_matching_skip_worktree()` in `pathspec.c` to eliminate its implicit use of the global `the_repository->index` by making the index state an explicit parameter. This is a targeted step in the ongoing `the_repository` removal effort and Git’s broader libification goal.

Current status
Proposal stage; no code has been written or merged. The author has identified the function and its four call sites (`pathspec.c`, `builtin/add.c`, `builtin/rm.c`) and proposed two API approaches: (1) add an explicit `struct index_state *istate` parameter to the existing helper, or (2) extend `find_pathspecs_matching_against_index()` with a new `ps_skip_worktree_action` option.
