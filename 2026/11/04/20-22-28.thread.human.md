This thread is about a patch series by Wasswa Edson that converts `git credential` to use Git's standard `OPT_SUBCOMMAND` mechanism, replacing manual subcommand dispatch with a more idiomatic approach. The change enables per-subcommand help text and shell completion while fixing minor documentation inconsistencies. The patch touches `builtin/credential.c`, `git.c`, the man page, and the test suite, but does not alter the core credential operations.

The initial version was posted as a clean refactoring, but a substantive review by Tanga Joris has since raised two key concerns. First, the commit message's claim that the patch makes the code "shorter" is incorrect—the file grows significantly due to repetitive boilerplate, and the reviewer suggests a helper function could reduce duplication. Second, the patch adds argument validation for subcommands but lacks corresponding tests, leaving an edge case unchecked. The reviewer provided a concrete test case to address this gap.

The patch remains under review, with no maintainer decisions or merge status reported. No other participants have weighed in yet, and the thread is still focused on addressing these technical feedback points.
