Core problem or goal
Refactor built-in Git commands in the `builtin/` directory to use the `parse-options` API, replacing ad-hoc argument parsing with a standardized, i18n-friendly mechanism. This is a recurring cleanup effort in the Git codebase, targeting improved maintainability, consistency, and internationalization support.
