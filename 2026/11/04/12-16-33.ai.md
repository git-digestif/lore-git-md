This is a two-patch bugfix series targeting the loose object database (ODB) cache in Git. The issue occurs during `git merge` when newly written merged blobs cannot be read back because the loose object cache remains stale, leading Git to incorrectly conclude the objects don’t exist locally. This triggers unnecessary backfill fetches from promisor remotes, which fail because the remote doesn’t have the objects either.

The series is authored by Patrick Steinhardt, a prolific contributor deeply involved in Git’s ODB abstraction and refactoring efforts. The patches touch `odb/source-loose.c`, a core component of the object storage layer, and add a new test in `t/t5616-partial-clone.sh` to verify the fix. The problem is well-scoped: the cache invalidation logic for newly written loose objects is incomplete, and the fix involves extracting and correcting the subdirectory bitmap handling.
