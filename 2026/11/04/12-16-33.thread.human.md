This thread is about a two-patch bugfix series from Patrick Steinhardt that addresses a subtle but important issue in Git's loose object database (ODB) cache invalidation during `git merge`. The bug causes Git to incorrectly assume that newly written merged blobs are missing locally, triggering unnecessary and failing backfill fetches from promisor remotes. The fix targets the loose object cache's subdirectory bitmap handling, ensuring the cache is properly updated after writing new objects.

The series is currently at version 1 and under active review. The first patch refactors the subdirectory bitmap retrieval logic into a reusable helper function, while the second patch implements the core fix by introducing a new helper, `loose_cache_mark_seen()`, to update the cache after writing objects. The fix is well-motivated, includes thorough test coverage in `t/t5616-partial-clone.sh`, and touches only the ODB subsystem (`odb/source-loose.c`). No design objections or open questions have been raised so far, and the approach aligns with Patrick Steinhardt's deep expertise in the ODB layer.

He independently arrived at the same logical approach, which further validates the solution.
