This thread is about a two-patch bugfix series from Patrick Steinhardt that addresses a loose object database (ODB) cache invalidation bug during `git merge`. The issue causes Git to incorrectly assume newly written merged blobs are missing locally, triggering unnecessary and failing backfill fetches from promisor remotes. The fix targets the subdirectory bitmap handling in `odb/source-loose.c`.

The series is now effectively ready for merging. Patch 1/2 refactors the subdirectory bitmap retrieval logic into a reusable helper function, while patch 2/2 implements the core fix by introducing `loose_cache_mark_seen()` to update the cache after writing new objects. Kristofer Karlsson provided a substantive review, confirming the fix works as intended and adding both `Tested-by` and `Reviewed-by` trailers. Junio C Hamano’s recent review is surface-level but positive, focusing on code clarity and explicitly endorsing the patch as "very good." Derrick Stolee also reviewed the series, though his feedback was lightweight. The series includes thorough test coverage in `t/t5616-partial-clone.sh` and touches only the loose object cache and promisor remote logic, with no on-disk format changes or broader subsystem impact.
