This is a refactoring series targeting the commit-graph writing code, part of Patrick Steinhardt’s larger effort to make commit-graph reading and writing pluggable via the object database backend. The series consists of ten patches that progressively reorganize how commit-graph write options are passed and managed.

The main thrust is consolidating all write-related parameters into a single `struct commit_graph_write_options`, replacing scattered flags and global variables. Patch 1 renames the existing `struct commit_graph_opts` to clarify its purpose, and subsequent patches migrate individual flags and parameters into this struct. By patch 6, all remaining write parameters have been moved, and the two separate commit-graph writer functions are merged into one. Along the way, redundant flags are dropped, NULL checks are removed where unnecessary, and a mixup between write and verify flags is fixed.

The series also modernizes function names for consistency and adds commit-graph verification to the object database’s fsck routine (patch 9). The changes touch core commit-graph logic in `commit-graph.c`, the built-in commands that trigger writes (`commit-graph.c`, `fetch.c`, `gc.c`), and test helpers. The documentation in `gitformat-chunk.adoc` is updated to reflect the new struct name.

This is preparatory work for the ODB abstraction effort, so the patches are mechanical and focused on interface hygiene rather than new behavior. The diffstat shows a net reduction in code (183 insertions, 215 deletions), suggesting the refactoring is simplifying rather than complicating the codebase. No new user-visible features or config options are introduced.
