This is a **substantive review** from Jeff King (Peff) on Kristofer Karlsson’s v2 patch, which is already cooking in `next`. Peff proposes a simpler, more localized fix for the same problem: instead of marking alternates as "borrowed" or not, the code should just compare the alternate’s path to the repository’s own `<commondir>/objects` and skip it if they match.

The core idea is to move the logic entirely into `refs_from_alternate_cb()` and avoid the broader ODB-layer changes. Peff’s diff is minimal—just a few lines that compute the real path of the repository’s commondir and compare it to the alternate path. He argues this is cleaner because it confines the fix to the alternate-refs code path, where the problem manifests, rather than introducing a new "borrowed" flag in the ODB layer. The quarantine case (where the alternate is the parent of `GIT_QUARANTINE_PATH`) would then be handled automatically, since the quarantine’s object directory is the same as the repository’s own.

Peff acknowledges the v2 approach is reasonable but questions whether the extra complexity is necessary. He also notes that while the current callers treat alternate refs as negative tips, the option is public, so tightening its behavior is fine but should be documented. The review is constructive and suggests a clear alternative, but it does not block the v2 patch—it’s an invitation to consider a simpler design before the topic graduates to `master`.
