This thread is about a critical bugfix for a regression in Git 2.55.0 that causes missing objects during repack operations with path-walking enabled. Derrick Stolee identified the issue, which was introduced by commit 5111520e2a1 in May 2026. The bug occurs when a tagged tree contains a blob at a path already visited by a prior tree batch—the path-walk machinery incorrectly skips revisiting the path, leading to dropped objects.

The fix is minimal and targeted: a single-line change in `path-walk.c` ensures paths are removed from `path_stack_pushed` when their queue entries are consumed, allowing later objects at the same path to be discovered. The patch includes a new test in `t/t7700-repack.sh` that verifies the fix by creating a commit and an annotated tree tag with distinct blobs at the same path, then repacking and running `git fsck` to confirm no objects are lost. The regression was triggered in the wild by the `torvalds/linux` repository, underscoring the fix’s importance.

The patch is well-documented, with a clear explanation of the root cause and a reproduction case. It’s ready for review and appears to be a straightforward, high-impact fix for a serious issue. No objections or alternative approaches have been raised yet.
