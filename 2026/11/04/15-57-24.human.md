This is the second patch in Patrick Steinhardt’s ten-patch series refactoring the commit-graph write code to consolidate options into a single struct. The series is part of his broader ODB abstraction effort, preparing the commit-graph subsystem for pluggable backends.

This patch moves the `enum commit_graph_write_flags` parameter into the `struct commit_graph_write_options` struct, making the options struct mandatory for all callers. The change affects the core commit-graph writing functions (`write_commit_graph` and `write_commit_graph_reachable`) and updates their callers in `builtin/commit-graph.c`, `builtin/fetch.c`, and `builtin/gc.c`. The diff is mechanical: flags like `COMMIT_GRAPH_WRITE_APPEND` and `COMMIT_GRAPH_WRITE_PROGRESS` are now set via `write_opts.flags` instead of being passed as a separate argument.

The patch is clean and well-scoped, with no user-visible behavior changes. It reduces the number of parameters to the write functions and makes the calling convention more consistent. Since all existing callers already pass an options struct, the change is backward-compatible in practice. The diffstat shows a net reduction in code (33 deletions, 31 insertions), reflecting the simplification. This looks like a solid step in the refactoring series and should not be controversial.
