This is the third patch in Patrick Steinhardt’s ten-patch series refactoring the commit-graph write code to consolidate options into a single struct. The patch removes redundant `NULL` checks for the write options (`ctx->opts`) that were left over after the previous patch moved all write flags into the options struct.

The change is mechanical: every conditional that previously tested `ctx->opts` before accessing its fields is simplified to an unconditional dereference. The patch touches only `commit-graph.c` and reduces the code by ten lines, reflecting the removal of now-unnecessary fallback logic. No new symbols are introduced; the patch merely enforces that `ctx->opts` is always non-NULL, which the preceding patch already ensured by making the options struct mandatory for all callers. The diff is straightforward and does not alter behavior or on-disk format.
