This thread is about a simple but long-overlooked documentation fix. In 2009, the word "stopping" was accidentally dropped from the description of `PARSE_OPT_KEEP_UNKNOWN_OPT` in the API documentation for Git's parse-options machinery. Cynthia Uche, an Outreachy contributor, spotted the typo and sent a patch to restore the missing word and re-wrap the following line for consistency. The change is purely textual—no code or behavior is affected—and Junio C Hamano, the maintainer, has already approved it with a clear "Makes sense. Thanks for finding and fixing." The patch is now ready to be merged.
