This is the fifth patch in Patrick Steinhardt’s ten-patch series refactoring the commit-graph write code as part of the ODB abstraction effort. The patch merges the two existing commit-graph writer functions (`write_commit_graph()` and `write_commit_graph_reachable()`) into a single entry point by introducing a new `COMMIT_GRAPH_WRITE_REACHABLE` flag in the `commit_graph_write_options` struct.

The change is mechanical and internal: no user-visible behavior is altered. The patch updates all callers (`builtin/commit-graph.c`, `builtin/fetch.c`, `builtin/gc.c`, and the test helper) to use the unified `write_commit_graph()` function, passing the new flag when reachable commits are intended. The `write_commit_graph_reachable()` function is removed, and its logic is folded into `write_commit_graph()` via a new helper (`fill_oids_from_reachable()`) that populates an oidset from all refs. A BUG() check ensures the three mutually exclusive input modes (pack indexes, explicit commits, or reachable commits) are never combined.

The diffstat shows a net reduction in code (38 lines deleted, 33 added), continuing the series’ trend of simplifying the internal interface. This patch is a prerequisite for the eventual goal of making commit-graph writing pluggable via the object database backend. No new test coverage is introduced; existing tests are expected to verify correctness.
