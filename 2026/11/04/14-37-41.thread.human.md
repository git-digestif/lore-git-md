This thread is an Outreachy internship proposal by Keryle Fondji to refactor built-in Git commands to use the `parse-options` API, replacing ad-hoc argument parsing for better maintainability and i18n support. Fondji, mentored by Christian Couder and Siddharth Asthana, plans to work on this during the December 2026–March 2027 Outreachy round. The proposal is still in the early stages, with no code submitted yet, and targets commands in the `builtin/` directory.

The project is uncontroversial—`parse-options` refactoring is an established cleanup effort—but Usman Akinyemi recently noted two procedural gaps: the proposal email omitted project details, and the formal application must be submitted via the Outreachy platform, not just the mailing list. Fondji will need to address these before the deadline. No technical objections or design discussions have emerged so far, though questions remain about which commands will be prioritized and how edge cases (like nested subcommands) will be handled. Reviewer bandwidth for the volume of patches may also be a concern. Fondji’s prior contributions (one merged patch and one superseded attempt) demonstrate familiarity with the review process.
