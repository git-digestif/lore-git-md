This Outreachy internship thread is about Srujith Poojary’s proposal to refactor `find_pathspecs_matching_skip_worktree()` in Git’s pathspec code to remove its dependency on the global `the_repository->index`. The goal is to make the index state an explicit parameter, aligning with Git’s broader effort to eliminate global state and improve libification. So far, no code has been written; the discussion is still in the proposal stage, with Srujith outlining two possible API approaches and a 13-week plan.

The only feedback so far has been from Usman Akinyemi, who provided surface-level editorial suggestions—wording tweaks, formatting fixes, and a reminder to submit the application on time—but did not engage with the technical aspects of the proposal, such as API design, testability, or edge cases like sparse-checkout compatibility. The thread is still open for substantive input from maintainers or other contributors on the preferred approach, potential pitfalls, or how to verify the refactoring works as intended.
