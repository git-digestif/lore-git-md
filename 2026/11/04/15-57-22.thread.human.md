This thread is about Patrick Steinhardt’s ten-patch series refactoring Git’s commit-graph write code to consolidate scattered flags and global variables into a single `struct commit_graph_write_options`. The work is part of his larger ODB abstraction effort, preparing the commit-graph subsystem for pluggable backends. The series also fixes a latent bug in verification, moves verification logic into the ODB backend, and modernizes function naming to follow Git’s `<subsystem>_<verb>` convention.

The series is currently under review at v1, with no merge status reported. Junio C Hamano and Derrick Stolee have both given surface-level endorsements, while Kristofer Karlsson suggested minor stylistic improvements to patch 6. In the latest email, Patrick responds to Kristofer’s feedback, acknowledging the stylistic suggestion but not committing to it. He also floats a design idea—using a tagged union to clarify which options apply to which write modes—but decides against pursuing it in this series, citing complexity. The core goal of the series remains unchanged, and no new code or open questions have emerged from this exchange. The only substantive discussion so far revolves around the unification of writer functions, which Derrick Stolee previously noted may need deeper scrutiny for edge cases, though his "LGTM" did not address this concern further.
