This thread is an Outreachy proposal by Srujith Poojary to reduce Git’s global state—particularly the `the_repository` global variable—to make Git’s core functionality more modular and reusable as a library. The proposal aligns with the ongoing `the_repository` removal effort led by René Scharfe and others, but it is still in the early stages, with no code patches submitted yet. Srujith is seeking community feedback on four key aspects: the technical scope’s appropriateness for an Outreachy internship, the implementation approach, the regression-testing strategy, and any technical concerns or improvements.

So far, the only response has been from Okhuomon Ajayi, another Outreachy applicant, who provided procedural feedback rather than technical input. Okhuomon noted that Git’s mailing list conventions prefer proposals to be sent inline as plain text in the email body, not as attachments, and suggested resending the proposal with a clearer subject line and the mentors cc’d. This is typical early-stage Outreachy guidance, focusing on process rather than substance. Once the proposal is resent in the preferred format, deeper technical discussion is expected to follow. For now, the thread remains open, with no substantive reviews or objections yet raised.
