This is a maintainer response in the ongoing `git describe` regression fix thread, weighing in on Kristofer Karlsson’s alternative algorithm proposal. Junio C Hamano briefly acknowledges the proposal as "interesting" but does not endorse or reject it, leaving the algorithmic debate open.

The thread has been focused on fixing `git describe`’s miscomputation of commit distances when commit dates are skewed, with two competing solutions on the table: Linus Torvalds’ one-line fix using commit generation numbers (with an opt-out `--exact` flag and warning mechanism) and Kristofer’s prototype, which delivers near-exact distances without relying on generation numbers. Junio’s earlier signals favored Linus’s approach, but this email shows he is now considering Kristofer’s alternative.

Kristofer’s proposal replaces the priority queue logic with a two-counter algorithm that tracks commits visited versus commits carrying a tag’s bit, using an epsilon-based heuristic (one week) to handle commits outside the commit-graph. The prototype produces correct distances for the regression case, matches `rev-list --count` on the Linux kernel’s merge window, and passes existing tests under both commit-graph settings. It avoids the performance cost of `ensure_generations_valid()` and works with partial commit-graphs, potentially making the `--exact` flag unnecessary.

Junio’s response is minimal and noncommittal. He does not address the trade-offs between the two approaches, the implications for the warning mechanism, or the commit-graph write-back proposal that was previously discussed. The thread’s key participants—Linus, Patrick Steinhardt, and Derrick Stolee—have not yet responded to Kristofer’s proposal, so the design direction remains unresolved. The patch is still cooking in `next`, but the algorithmic choice is now the main open question. If Kristofer’s approach gains traction, it could simplify the user interface and reduce reliance on commit-graph freshness, but the thread will need further input from the other stakeholders to converge.
