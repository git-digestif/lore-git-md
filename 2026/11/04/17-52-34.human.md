This is a documentation patch. A brief, surface-level review from Ben Knoble endorses Junio C Hamano’s one-line update to the `git-branch` man page, which replaces a lingering reference to `` `git checkout -b` `` with `` `git switch -c` `` for consistency with the rest of the document.

The patch itself is a follow-up to 328c6cb853 (2019), which began steering users toward the newer `switch`/`restore` commands. Junio’s commit message acknowledges that `checkout` is not going away, but opts for internal consistency rather than listing both alternatives. Ben’s reply adds a light, anecdotal note that learners he teaches have adopted `switch` and prefer it, though this is not a technical review. No controversy or further discussion is expected.
