This is a performance optimization for `git send-pack`, specifically targeting the common workflow of force-pushing a rebased feature branch. The author, Marc Strapetz, is making a renewed case for the patch series after Junio C Hamano raised concerns about its redundancy with existing push negotiation mechanisms.

The core idea remains unchanged: when force-pushing a rebased branch where the old tip is locally available, `send-pack` can inspect the old tip’s tree to exclude objects the receiver already has, avoiding redundant transfers of large unchanged blobs. The optimization is opt-in at the packing layer via a new `--inspect-have` option, enabled only for forced non-fast-forward updates of existing branches (`refs/heads/`), and requires no server or protocol changes. The author emphasizes that this targets the *default* packing path, avoiding the latency of negotiation while still reducing network traffic for small history rewrites.

Strapetz acknowledges the trade-off: while micro-benchmarks show substantial improvements for small rewrites (e.g., a single-file reword drops packing time from 2.776 ms to 1.338 ms), a worst-case scenario with widespread changes incurs an 8% packing-time overhead for negligible size reduction. He argues that the real-world benefits—reduced network transfer and server-side processing—outweigh this cost, but invites further feedback on the balance. The series has thorough test coverage, adding 62 new tests across two scripts to verify behavior with identical trees, shared blobs, partial clones, and replacement refs.

The email directly addresses Junio’s earlier concern by clarifying that the series does not compete with push negotiation but instead optimizes the default path where negotiation is not used. Strapetz also loops in Taylor Blau and Derrick Stolee, likely for their expertise in pack generation and revision traversal, signaling a desire for deeper technical scrutiny. The thread remains open, with no maintainer decision yet, but the author’s framing suggests this is a serious, well-considered proposal worth attention from anyone interested in push performance.
