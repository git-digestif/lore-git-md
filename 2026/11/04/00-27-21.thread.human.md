This thread is about a bugfix patch from Tyler Cipriani that addresses two edge cases in `--force-with-lease` behavior during remote group pushes. The patch fixes a regression introduced in Git 2.56.0 where `--force-with-lease` options were not properly forwarded to individual remotes in a group: (1) bare `--force-with-lease` was silently ignored, and (2) `--force-with-lease=<ref>:` (expecting the ref to be absent) incorrectly overwrote remote branches when the remote-tracking branch was up-to-date. The fix modifies `builtin/push.c` and includes new tests in `t/t5533-push-cas.sh` to verify both edge cases.

The patch is currently under review and targets the `maint` branch. So far, the only feedback has been a surface-level correction from Kristoffer Haugsbakk, who noted a typo in the `Reported-by` trailer (a misspelled name). No substantive technical review has been posted yet, so the correctness of the fix remains unconfirmed by other contributors. The patch itself is well-documented and includes thorough test coverage, but it will need deeper scrutiny before it can be merged.
