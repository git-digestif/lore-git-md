This is a surface-level review reply from Junio C Hamano in the `git history --verbose` RFC thread. Junio endorses D. Ben Knoble’s call for a CLI opt-out mechanism, reinforcing the need for deterministic behavior in interactive and scripted workflows. He suggests two possible implementations: `--quiet` (the conventional opposite of `--verbose`) or the existing `OPT__VERBOSITY()` macro (which provides `--verbose`/`--no-verbose` pairs). The reply does not engage with the broader output format debate, the generalizability requirement for future subcommands, or any technical implementation details. It is a brief, focused comment on user interface design.
