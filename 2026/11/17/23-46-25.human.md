This is a brief review acknowledgment within Justin Tobler's four-patch series on eagerly creating the temporary object directory at ODB transaction start. Replying to Karthik Nayak's comment on patch 3/4 (`tmp-objdir: preserve errno when directory creation fails`), Justin agrees with Karthik's suggestion to refactor `tmp_objdir_create()` to use a single `goto fail` exit path rather than saving and restoring `errno` around individual syscalls, and confirms he will incorporate this change in the next version of the series.
