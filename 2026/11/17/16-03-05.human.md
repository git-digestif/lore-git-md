This is a small bugfix for `git fast-import`'s error messaging. Kaartic Sivaraam noticed while backporting a security fix that when a stream uses `feature export-marks=<path>` without `--allow-unsafe-features`, the resulting error message included the full feature string with the path attached, unlike the `import-marks` variants which show only the feature name. The patch passes just `"export-marks"` to `check_unsafe_feature()` so the message reads consistently, and it strengthens the existing test in `t/t9300-fast-import.sh` to grep for the expected error text rather than merely checking that the command fails. It is a tidy, well-motivated two-line change that touches only `builtin/fast-import.c` and its test.
