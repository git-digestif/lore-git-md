A standalone bugfix from Kaartic Sivaraam addresses an information leak in `git fast-import`'s error reporting. Since commit 68061e3470 in 2019 made `feature export-marks=<path>` forbidden unless `--allow-unsafe-features` is supplied, the resulting error message has included the full feature string -- leaking the user-supplied filesystem path into the diagnostic. The patch makes `export-marks` consistent with `import-marks` by passing only the bare feature name to the check, so the message now reads `feature 'export-marks' forbidden` rather than exposing the path. The change is a one-liner in `builtin/fast-import.c` plus a strengthened test in `t/t9300-fast-import.sh` that now greps stderr for the corrected message. Enforcement behavior is unchanged; only the wording of the error is fixed.
