This is a **refactoring** patch, the first of four in Harald Nordgren's v8 series that adds change-based branch deletion to `git branch`.

The patch moves the existing `branch.<name>.deleteMerged` opt-out check in `builtin/branch.c` into a new helper function, `branch_opted_out()`. This is pure preparation for the later patches in the series, which introduce a new `--delete-integrated` flag; that flag needs to honor the same per-branch config setting, so the logic is being factored out now for reuse. There is no behavior change.
