This is a preparatory refactoring patch, the second of four in Harald Nordgren's v8 series introducing `git branch --delete-integrated`. It extends `delete_branches()` in `builtin/branch.c` to accept an optional map from branch names to the upstream commits where those branches landed. When a branch appears in that map, the function skips the usual merge-reachability check and reports the landing commit in its output, changing the message from `Deleted branch topic (was 1a2b3c4)` to `Deleted branch topic (was 1a2b3c4, landed as 9f8e7d6)`.

Both existing call sites currently pass `NULL` for the new parameter, so there is no change in user-visible behavior; this simply lays the groundwork for the later patches in the series, particularly the squash-merge detection in 4/4, which will populate the map. The thread context indicates this patch has been explicitly reviewed and found uncontroversial, ready for integration.
