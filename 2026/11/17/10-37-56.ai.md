This is the fourth and final patch in a v2 bugfix series fixing integer truncation in large-file handling, specifically targeting overflow bugs in `git diff --stat` output. It modifies `diff.c` and `diff.h` to widen diffstat total accumulators from `int` to `uintmax_t`, preventing the summary line from overflowing when a single file or aggregate changes exceed `INT_MAX` lines, and fixes `scale_linear()` to compute its product in `uintmax_t` rather than `int` so that wide stat graphs no longer produce empty or truncated output for large changes. A new cheap test in `t/t4052-stat-output.sh` verifies the graph-scaling case using a 50,000-line file with a graph width of 46,000.

The patch changes the signatures of `print_stat_summary()` and its static helper `print_stat_summary_inserts_deletes()` to accept `uintmax_t` for insertion and deletion counts, switching their format strings from `%d` to `PRIuMAX`; since `print_stat_summary()` is also called by `git apply --stat`, its prototype in `diff.h` is updated accordingly, though `apply.c` itself continues to sum its own totals in `int` and is left unchanged. In `show_stats()`, the locals `adds` and `dels` become `uintmax_t`, and the logic for assigning `graph_width` is adjusted to cap `max_change` at `width` when it exceeds the available space, avoiding an `int` overflow in the assignment. The `scale_linear()` function now takes `uintmax_t` parameters for the change count and maximum change, ensuring the multiplication `it * (width - 1)` is performed in 64-bit arithmetic even on LLP64 platforms.

This patch was added in v2 after the complete-rewrite path was fixed in patch 2/4, since that change made it possible for a single file to legitimately reach 2^31 lines and trigger the diffstat overflow. The author notes that the totals themselves are not covered by a committed test because exceeding `INT_MAX` lines requires a multi-gigabyte input, but the graph overflow case is tested. The series remains under review with no merge status reported, and this patch awaits substantive technical review alongside patches 1/4 and 3/4.
