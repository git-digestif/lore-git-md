This is a substantive review by the maintainer of a documentation patch. Junio C Hamano responds to Omri Sarig's v2 patch, which adds backtick quoting around `--refresh` and `--remove` in `Documentation/git-update-index.adoc` so they render as code literals. Junio confirms the fix is correct and necessary, but points out it is incomplete: the patch should also convert enumeration headers like `-q::` to `` `-q`:: `` and single-quoted command names like `'git update-index'` to use backticks, matching the convention used in Jean-Noël Avila's recent synopsis-style conversion series (citing e9a99ef2da as an example). He also notes a preference for present tense in commit messages and gently cautions against an excess of narrowly-scoped low-value patches, while acknowledging this one addresses a real typesetting issue. The review engages with AsciiDoc markup conventions and compares against existing documentation standards rather than just nitpicking wording, and the thread remains open for the author to expand the patch accordingly.
