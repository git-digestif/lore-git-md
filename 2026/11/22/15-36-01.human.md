This is a documentation patch, the second version of a standalone fix. Omri Sarig corrects AsciiDoc markup in the `git update-index` man page so that option names render as inline code instead of plain text. The patch wraps five occurrences of `--refresh` and one occurrence of `--remove` in backticks within `Documentation/git-update-index.adoc`, changing lines like "If --refresh finds" to "If `--refresh` finds" so the generated man page displays them as code references.

The only difference from v1 is a commit-message tweak: the subject line's "Format" is lowercased to "format" to match Git's convention. The actual diff is unchanged -- five insertions and five deletions in a single file, with no functional change to `git update-index` itself.
