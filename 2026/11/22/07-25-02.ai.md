This is a **surface-level review** of patch v4 1/5, specifically commenting on the new unit tests in `t/unit-tests/u-utf8-ansi.c`. Andy Koppe identifies two correctness issues in the test code: first, passing two different string literals (such as `""` and `""`) as `start` and `end` arguments technically compares pointers to different objects, which is undefined behavior in C even though compilers often optimize them to the same address; second, the use of `sizeof(sgr_3)` and `sizeof(sgr_4)` returns the size of the pointer (8 bytes on 64-bit systems) rather than the string length, so the calculated end pointers are incorrect and the lines exceed typical length limits. These are test-only nits that do not affect the core logic of `display_mode_esc_sequence_len()` itself but should be fixed before the series advances.
