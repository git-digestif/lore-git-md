This is a **refactoring** patch, the first of four in Harald Nordgren's v9 series that introduces `git branch --delete-integrated`. It extracts the existing `branch.<name>.deleteMerged=false` opt-out check from `delete_merged_branches()` in `builtin/branch.c` into a new static helper `branch_opted_out(struct strbuf *key, const char *branch_name, unsigned int flags)`, which performs the config lookup and prints the "Skipping" message unless `DELETE_BRANCH_QUIET` is set. The change is explicitly behavior-neutral; its sole purpose is to make the opt-out logic reusable so that the upcoming `--delete-integrated` implementation in patch 3/4 can honor the same config key. Only `builtin/branch.c` is touched (19 insertions, 13 deletions). Per the thread context, this patch is considered uncontroversial and ready for integration.
