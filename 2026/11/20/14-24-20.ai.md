This is a feature patch series (v9 of 4 patches) introducing `git branch --delete-integrated <pattern>`, with this iteration serving as a bugfix that resolves a confirmed crash in the previous version. The series as a whole extends branch deletion beyond strict tip-reachability to recognize branches whose changes landed upstream via squash or rebase merges, even when upstream modified the same files. The CLI design is settled: `--delete-merged` remains strict (tip must be reachable), while the new opt-in `--delete-integrated` performs change-based detection and reports where work landed via `Deleted branch %s (was %s, landed as %s)`.

What is new in v9 is the fix for the gitlink-to-blob type confusion that Jasper Mayone confirmed reachable in v8 4/4: when a path was a submodule (gitlink) at the merge base but became a regular file on both the branch and upstream, `collect_branch_changes()` recorded the base OID without its mode, causing `merge_keeps_upstream()` to pass a commit OID to `read_mmblob()`, which died with `fatal: unable to read blob object`. The fix adds a `base_mode` field to `struct branch_change`, populates it from `p->one->mode` in `collect_branch_changes()`, and extends the guard in `change_state_at()` to return `CHANGE_MISSING` when `!S_ISREG(change->base_mode)`, correctly keeping such branches. A regression test in `t/t3200-branch.sh` covers this scenario. Patches 1/4 through 3/4 are unchanged from v8.

The implementation lives in `builtin/branch.c` with documentation in `Documentation/git-branch.adoc` and `Documentation/config/branch.adoc`, plus 315 lines of tests in `t/t3200-branch.sh`. Key internals include the `DELETE_BRANCH_INTEGRATED` flag, `landing_search` struct, `branch_change` array (now carrying `base_oid`, `base_mode`, `branch_oid`, `branch_mode`, `upstream_oid`, and `state`), and `find_landed_commits()` which walks upstream commits comparing changed paths. Patch 4/4 specifically adds `merge_keeps_upstream()` using `ll_merge()` for path-by-path three-way merge approximation with `.gitattributes` support, reading the index once before the walk. The squash-detection path may fetch blobs in partial clones; rename detection is not implemented.
