This is a documentation patch fixing a single line of AsciiDoc syntax in `Documentation/MyFirstContribution.adoc`. Ophir Bleicher noticed that the guide for new contributors accidentally used Markdown-style link syntax (`[here](url)`) instead of proper AsciiDoc (`url[here]`), and corrected it so the rendered documentation displays the link correctly. The change is a one-line substitution with no behavioral impact -- just making sure the contributor tutorial renders as intended on git-scm.com. It is a straightforward, well-scoped fix that any maintainer can pick up without discussion.
