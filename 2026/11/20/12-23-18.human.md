This is a documentation patch correcting a single typo in the Git 2.46.0 release notes. Ophir Bleicher noticed that the entry describing the `git describe --dirty --broken` fix contained the misspelling "chang" where it should read "change". The patch alters one word in `Documentation/RelNotes/2.46.0.adoc`, leaving the surrounding explanation of the index-refresh behavior untouched.

The correction appears in the "Fixes since v2.45" section, in the paragraph noting that `git describe --dirty --broken` previously forgot to refresh the index before checking for local modifications. The fix is purely cosmetic and does not change the meaning of the release note.

This is a trivial, well-formed typo fix typical of the steady stream of small documentation maintenance on the list. It requires no substantive review and is the sort of patch that typically gets picked up quickly without discussion.
