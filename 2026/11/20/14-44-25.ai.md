This is a documentation patch -- specifically a comment fix in `utf8.c`, and the second patch in a four-patch v3 series.

Dirk Gouders corrects the doc comment for `utf8_strnwidth()`. The diff touches only the two-line comment block above the function at line 213 of `utf8.c`; no code changes.
