This is Junio C Hamano's periodic "What's cooking in git.git" status report for November 2026, summarizing which topics have landed in `master`, which are cooking in `next` and `seen`, and which have been dropped. Eighteen topics graduated to `master` this cycle, including several more steps in the long-running `the_repository` global removal effort covering the unpack-trees API and blob merging, plus performance improvements to push refspec matching and `git repo structure` object counting. Notable bugfixes also landed, fixing a double free in `for-each-ref` with missing objects, a segfault on `--no-format`, stale untracked cache after trivial FSMonitor responses, and a `size_t` truncation affecting packs over 2GB on Windows.

New topics queued in `seen` include pluggable commit-graph reading and writing through the ODB backend interface, size validation when streaming loose objects, HTTP retry improvements with exponential backoff and configurable `http.retryStatusCodes`, and a proposed `--delete-integrated` option for `git branch` to detect squash-merged branches. In `next`, topics marked "Will merge to 'master'" include a new `--show-object-format` option for `ls-remote`, extensive hardening of NULL config values across the codebase, CI speedups, an opt-in `--follow=merges` flag for `git log` to make expensive rename-following across merges explicit, and removal of 8 bytes of padding from `struct commit`. Several topics remain only in `seen` awaiting review, such as pack index v3 for SHA-1/SHA-256 interoperability and fixes to `push --force-if-includes`, while a few others are marked as expecting a reroll or stalled. The previous `mv/log-follow-speedup` topic was discarded in favor of the opt-in version now cooking in `next`.
