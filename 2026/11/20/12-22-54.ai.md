This is a refactoring patch, the sixth of seven in Patrick Steinhardt's v2 part 1 series introducing pluggable commit graphs for the ODB abstraction effort. It modifies `write_commit_graph_file()` in `commit-graph.c` to establish a single common exit path using a `goto out` pattern, converting all early `return -1` error exits to set a local `ret` variable and jump to the new `out:` label instead. The success path now sets `ret = 0` before falling through to the same label, which unconditionally calls `rollback_lock_file(&lk)` before returning, ensuring the lock file is always properly handled on every exit. This change is purely preparatory: the commit message notes that the next patch in the series will introduce additional allocations in this function that need cleanup, and consolidating the exit path now keeps that future diff small and readable. There is no behavior change in this patch itself, only a restructuring of control flow within `commit-graph.c` to make cleanup semantics uniform. The patch touches only `commit-graph.c` with 19 insertions and 15 deletions, and remains under review as part of the broader series that defers the actual pluggable backend hooks to a follow-up part 2.
