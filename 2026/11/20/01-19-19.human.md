This is Junio C Hamano's periodic "What's cooking in git.git" status report for mid-November 2026, tracking which patch series have graduated to `master`, which are queued in `next`, and which are still under review or have been discarded.

Eighteen topics have graduated to `master` since the last report. Several continue the ongoing `the_repository` removal effort, including patches for `unpack-trees`, `merge`, and `merge-blobs`. Performance improvements landed for client-side refspec matching during `git push` (replacing linear scans with strmap lookups) and for `git repo structure` (avoiding full parsing of unnecessary objects). Bug fixes include a double-free in `for-each-ref` when refs point to missing objects, a segfault on `for-each-ref --no-format`, and a regression where `git grep --recurse-submodules` failed to read nested submodule trees. Smaller cleanups include test modernizations, removal of the defunct Cirrus CI configuration, and an update to the required Perl version in the CodingGuidelines.

Among the new topics, several are marked "Will merge to 'master'" and already sit in `next`: a fix for the untracked cache with FSMonitor trivial responses, a new `--show-object-format` option for `git ls-remote`, a performance fix for `git log --follow` on non-linear history (making expensive rename detection opt-in via `--follow=merges`), and a commit-graph write refactoring series that prepares for pluggable commit-graph backends. Patrick Steinhardt's 12-patch series making commit-graphs pluggable in the ODB interface is in `seen` and waiting for response.

The cooking section shows continued work on the SHA-1/SHA-256 interoperability effort with pack index v3 support from Christian Couder, plus new work on HTTP retry logic with exponential backoff and configurable status codes. Several topics address `the_repository` removal in the fetch negotiator and checkout code. A new `--delete-integrated` option for `git branch` aims to clean up squash-merged or rebase-merged branches. Two topics are marked as stalled after long inactivity: a sigchain concurrency fix and a loose-ref seeking fix. The discarded section notes that a Coverity overflow-fixes series and several older topics have been dropped or are expecting rerolls indefinitely.
