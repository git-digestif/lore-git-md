This is a maintainer review of the fourth patch in Harald Nordgren's v9 series, which fixes a gitlink-to-blob type-confusion crash in the new `--delete-integrated` machinery.

Junio C Hamano acknowledges that the patch correctly addresses the crash identified in v8: the new `base_mode` field in `struct branch_change` and the added `!S_ISREG(change->base_mode)` guard in `change_state_at()` now prevent `read_mmblob()` from being called on a submodule commit OID when a path changed from a gitlink to a regular file. He notes that the accompanying regression test -- covering a branch that replaces a submodule with a file while upstream does the same -- correctly expects the branch to be kept rather than deleted.

Beyond confirming the fix, Junio offers candid process feedback: he observes that this appears to be the only corner case addressed in v9 and expresses hope that the author would proactively hunt for additional edge cases rather than merely reacting to issues reported by reviewers. The review is otherwise light, treating the fix as correct and the test as appropriate, with no new technical objections raised.
