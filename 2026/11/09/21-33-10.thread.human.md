This thread covers a new beginner-friendly tutorial on Git branches (`gittutorial-branches`) authored by Julia Evans and Marie Claire LeBlanc Flanagan, intended as the second part of a two-part series with the first part already merged. The documentation is purely additive, integrated into the build system so it will be accessible via `git help gittutorial-branches`, and targets users without a computer science background using conversational examples and step-by-step commands. The patch remains under review and is not in any integration branch.

Reviewers have engaged substantively with the draft. D. Ben Knoble raised two structural concerns: that Step 8 uses hypothetical branches to explain merges before the concept is introduced, and that the flat-text format blurs the line between the hands-on practicum and later conceptual material. Junio C Hamano flagged several correctness issues in the examples, including inconsistent shell prompts, the non-standard `git commit -am` (should be `git commit -a -m`), a logical gap in the Emilia example where work on a branch isn't shown before presenting merge options, and a missing commit step in the Daniela and Carmen collaboration scenario. Julia Evans has accepted all of these points and committed to a v2 that reorganizes the document with a clearer introduction, moves merge-conflict material into a note, and fixes the example sequencing. Knoble has now confirmed in his latest reply that her planned revisions fully address his earlier concerns, leaving no outstanding objections from his side.

The main open item is the actual v2 patch, which Evans has promised to deliver despite her current funding ending November 30. No merge decision has been made; the series is still awaiting revision and further review.
