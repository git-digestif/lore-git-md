Julia Evans and Marie Claire LeBlanc Flanagan have proposed a new beginner tutorial, `gittutorial-branches`, intended as a follow-up to the already-merged `gittutorial`. The patch adds `Documentation/gittutorial-branches.txt` and wires it into the build so it appears via `git help gittutorial-branches`, targeting users without computer science backgrounds through conversational examples and `git log --graph` visuals. The series remains under review and has not entered any integration branch.

The discussion has drawn substantive feedback from two reviewers. D. Ben Knoble raised structural concerns about prerequisite ordering—specifically that Step 8 uses hypothetical branches before merges are introduced and that the hands-on practicum does not clearly conclude at Step 13—which Evans accepted and detailed a plan to fix in a v2, including moving merge-conflict material into a note and adding a document overview. Now Junio C Hamano has added a maintainer review focusing on correctness and consistency in the code examples: he notes the inconsistent use of the `$` shell prompt across blocks, requests `git commit -a -m` instead of `git commit -am`, points out that the "Emilia the PhD student" example omits that work happens on the new branch before merging or discarding and that `git branch -D` fails if the user is still on that branch, and asks that the "Daniela and Carmen" collaboration example clarify that changes are committed before `git pull --no-rebase`. Evans has committed to shepherding the revision through review despite her funding ending November 30, and no merge decision has been made.
