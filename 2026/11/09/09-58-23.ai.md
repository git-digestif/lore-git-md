This is a CI/build system patch (part 2/7 of Patrick Steinhardt’s v2 series targeting GitLab CI speedups). It addresses a specific bottleneck in Windows CI pipelines by excluding intermediate `*.obj` files from build artifacts.

The patch modifies `.gitlab-ci.yml` to add an `exclude` rule for `build/**/*.obj` under the `build:msvc-meson` job’s artifacts section. This change cuts the time required to download and extract artifacts from 34 seconds to 17 seconds per test job by reducing the artifact size—from ~2300 files to ~500 (removing ~1800 unnecessary `*.obj` files). The optimization is straightforward and low-risk, with no behavior changes or new symbols introduced.

This is one of the smaller but still meaningful improvements in the series, complementing larger optimizations like SDK extraction speedups (patch 1/7) and test script refactoring (patches 4–7/7).
