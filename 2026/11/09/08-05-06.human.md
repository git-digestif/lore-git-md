This is a refactoring patch in the log subsystem, part of a five-patch series by Miklos Vajna. It extracts the logic that decides whether to show a remerge diff or a combined diff for a merge commit into a new helper function, `log_tree_merge_diff()`. The commit message states this is preparatory work for a later patch in the series that will reuse this logic, avoiding code duplication.

The patch touches only `log-tree.c`, moving 14 lines of conditional logic into a new 22-line static function. No behavior change is intended, and the diff is purely mechanical. The new function is called from the existing `log_tree_diff()` function when either the `remerge_diff` or `combine_merges` option is set.
