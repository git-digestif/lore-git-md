This is a review comment on the second patch in Farid Zakaria’s v2 series fixing race conditions in the Git credential-cache daemon. The patch itself is a narrow, uncontroversial bugfix that makes the daemon ignore `EEXIST` from `mkdir()` when the socket directory already exists, preventing a fatal error during concurrent daemon starts. Jeff King and Patrick Steinhardt have both confirmed the logic is correct.

Patrick’s reply here is a surface-level nit about the commit message. He questions why the message explains how the directory is created with mode `0700` when the patch does not change that behavior, and why anyone would consider the alternative (`mkdir(..., 0777) && chmod(..., 0700)`) preferable. The comment is purely stylistic and does not engage with the patch’s substance. Farid can address it by simply removing the explanatory sentence, which is not essential to the fix’s motivation or mechanics. The patch remains ready for integration once the architectural concern in patch 3 is resolved.
