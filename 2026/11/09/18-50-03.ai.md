Key technical details:

- The `odb_has_object()` API has evolved: callers now get `QUICK`-like behavior by default and must opt into full rescans via `ODB_HAS_OBJECT_RECHECK_PACKED`.
- If `QUICK` were removed from object retrieval (not `has_object()`), the scope would be smaller, but Peff warns that removing it from both would require auditing many call sites.
