Core problem or goal
Joy Gundu proposes a 13-week Outreachy internship to continue the Git project’s long-running effort to eliminate global state (e.g., `the_repository`) and enable libification. The immediate focus is on migrating global variables to explicit repository-scoped state, starting with in-flight work on repository configuration values (`repo_config_values_init()`), then identifying and converting other suitable candidates while ensuring test coverage and coordination with related refactoring efforts (e.g., ODB abstraction).

Current status
Under discussion; no code merged yet. Joy’s prior patch (PR #2298, zero-initializing repository configuration values) is still under review. The proposal itself is now open for feedback from the Git community and Outreachy mentors (Usman Akinyemi, Christian Couder).

Key technical details
- Files/subsystems: `repository.c`, `config.c` (initial focus); future work may touch other subsystems with global state (e.g., object database, refs).
- New/renamed symbols: `repo_config_values_init()` (existing function, target of current patch).
- Behavior: Zero-initialization of repository-scoped configuration values to avoid uninitialized memory access.
- Test coverage: Joy’s plan emphasizes adding tests for migrated state and coordinating with existing test suites (e.g., `t/` scripts).
- On-disk format: No changes anticipated.

Open questions and loose ends
- Community feedback on the proposal’s scope and feasibility.
- Review of Joy’s in-flight patch (PR #2298) and any requested changes (e.g., Junio’s suggestion to use a C99 compound literal).
- Identification of additional global variables suitable for migration (prioritized by risk and impact).
- Coordination with Patrick Steinhardt’s ODB abstraction effort to avoid conflicts.
