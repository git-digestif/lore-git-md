This is a CI/build system patch (part 3 of 7 in the GitLab CI speedups series). It addresses a specific bottleneck in the `fedora-breaking-changes-meson` job, which runs roughly twice as long as other Linux-based CI jobs due to unoptimized Meson builds. The patch changes the Meson build type from `debug` (which defaults to `-O0`) to `debugoptimized` (which uses `-O2`), cutting the job's runtime from 2100 to 1000 seconds. Other Linux and macOS jobs also see minor speedups (~10%), while Windows builds remain roughly neutral in total runtime despite a slight slowdown in the build step.

The commit message provides clear technical context: the Fedora job is uniquely impacted because it enables SHA256 with the "block" backend, which benefits disproportionately from compiler optimizations (e.g., hashing a 500MB blob is 6x faster with `-O2`). The change is minimal—just two lines in `.gitlab-ci.yml` and `ci/run-build-and-tests.sh`—and preserves debug symbols while enabling optimizations. This aligns the Meson build flags with Git's traditional Makefile defaults (`-g -O2`).

The trade-offs (e.g., Windows build-time regression) are explicitly acknowledged and outweighed by the gains elsewhere.
