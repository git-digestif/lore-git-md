This is the fifth patch in Patrick Steinhardt’s v2 CI speedup series (7 patches total). It targets the `t0027-auto-crlf.sh` test script, which is a known CI bottleneck. The patch caches the expected output files (`.expect` and `.ws-expect`) to avoid repeatedly regenerating them via `tr` and `sed` in the `compare_files()` and `compare_ws_file()` helper functions. These functions are called over 1,000 times during the test, so the optimization yields a measurable 20–25% runtime reduction—on Windows, the test now completes in 380 seconds instead of 480.

The change is a straightforward performance tweak: it adds a file existence check (`test -f`) before recomputing the expected output, and removes the `rm` calls so the cached files persist for the duration of the test. The diff touches only `t/t0027-auto-crlf.sh` and introduces no new symbols or on-disk format changes.
