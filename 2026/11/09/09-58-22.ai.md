This is the first patch in Patrick Steinhardt’s v2 CI/build system series, targeting GitLab CI speedups. It replaces the slow `Expand-Archive` PowerShell cmdlet with `tar(1)` to extract the Git for Windows SDK, cutting extraction time from ~3 minutes to ~10 seconds. The change also makes the script more robust by enabling strict error handling (`$ErrorActionPreference = 'Stop'`) and suppressing noisy progress output (`$ProgressPreference = 'SilentlyContinue'`).

The patch touches only `ci/install-sdk.ps1` and introduces no new symbols or behavior changes beyond the performance improvement. This is a straightforward, low-risk optimization that directly addresses a known bottleneck in the Windows CI pipeline. The v2 revision drops the SDK archive cache that was present in v1 (due to staleness concerns raised by Junio), but retains the core speedup. No substantive objections remain; the change is mechanical and well-motivated.
