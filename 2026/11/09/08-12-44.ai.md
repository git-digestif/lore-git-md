This is a refactoring patch converting the `git check-ref-format` command to use Git's `parse-options` API.

The patch replaces the manual argument parsing loop in `cmd_check_ref_format()` with a declarative `struct option` array and a call to `parse_options()`. The existing options (`--normalize`, `--print`, `--allow-onelevel`, `--refspec-pattern`) are preserved with identical behavior, but now use the standard `OPT_BOOL_F`, `OPT_BIT`, and `OPT_BIT_F` macros. The patch also introduces a new `builtin_check_ref_format_usage_options` array to hold the two usage strings that were previously inlined in the `usage()` call.

The change is purely internal: no user-visible behavior is altered, and the commit message does not claim any functional improvement. The patch touches only `builtin/check-ref-format.c` and adds the necessary `#include "parse-options.h"` header. The conversion is mechanical and follows the established pattern seen in other built-in commands that have already been converted to `parse-options`.
