This is a documentation patch that has just been merged to `master`. Junio Hamano sent the final acknowledgment, confirming that the third iteration of Karthik Nayak’s patch is now complete. The patch updates `Documentation/technical/api-parse-options.adoc` to document all previously undocumented flags (`PARSE_OPT_ONE_SHOT`, `PARSE_OPT_SHELL_EVAL`) and macros (`OPT__VERBOSITY`, `OPT__SUPER_PREFIX`, `OPT_CONTAINS`, and seventeen others) exposed by Git’s `parse-options` API.

The patch is purely additive, touching only the documentation file and making no behavioral changes to the codebase. All review feedback across three iterations has been addressed, including the final copy-edits suggested by Cynthia Uche.

This is a clean, uncontroversial cleanup that improves the developer experience without introducing risk. The patch is now in `master` and will appear in the next Git release.
