This is an Outreachy proposal update from Tanga Joris, refining their plan to improve Git's command argument scanning and parsing. The proposal targets three specific, user-visible issues: (1) `git stash show` misinterpreting `-G`/`-S` values as stash references, (2) silent failures in numeric parsing for `git index-pack` and `git fetch-pack` on malformed inputs, and (3) `--no-index` detection in `git diff` failing when preceded by short options like `-G`.

Key changes since the last draft include moving `git daemon` into the primary plan (removing dependency on Christian Couder’s `early-scan-options` work), testing `early_scan_options()` on `git diff` (which revealed limitations in handling short options), and tightening the minimum outcome to exclude a fallback fix for `git diff`. The timeline is now more concrete, with work split into four phases: `git stash show` (weeks 1-2), numeric parsing fixes and `git diff` tests (weeks 3-4), `git daemon` conversion (weeks 5-7), and `git diff`’s `--no-index` fix (weeks 8-12).

Tanga’s approach is methodical and test-driven, with each change preceded by tests that fail on `master`. The proposal demonstrates strong technical preparation, particularly in diagnosing edge cases (e.g., `git diff -G x --no-index` vs. `git diff -S --no-index HEAD~1 HEAD`) and evaluating tradeoffs (e.g., whether to extend the early scan or fix the existing loop). The `git diff` question—whether to adapt Christian’s framework or modify the current parser—remains the most significant design decision, and Tanga flags it for mentor input.

The proposal’s clarity and focus on incremental, regression-safe improvements make it compelling. Tanga’s prior contributions (two merged patches, an in-progress series, and active reviews) show they’re well-prepared for the work. The plan balances ambition with pragmatism, prioritizing plumbing fixes while leaving room for broader refactoring if time allows. Key discussion points for the list will likely center on the `git diff` design choice and whether to expand scope to revision options or other commands.
