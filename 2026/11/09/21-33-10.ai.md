This is a **documentation** patch introducing a new tutorial (`gittutorial-branches`) aimed at Git beginners. The tutorial explains branches in a conversational, example-driven style, using imaginary characters to illustrate different workflows (e.g., open-source contributions, solo projects, team collaboration). It avoids jargon (e.g., "directed acyclic graph") and focuses on practical usage, including step-by-step commands, output examples, and visualizations via `git log --graph`.

Key features:
- **Target audience**: New users unfamiliar with branches, including those without a CS background.
- **Structure**: Covers core concepts (e.g., "main" branch, commits, merging), then walks through hands-on exercises (creating branches, merging, deleting branches). Includes sections on collaboration patterns (e.g., open-source vs. corporate workflows).
- **Pedagogical choices**: Uses `git log --graph` for visualization (instead of abstract diagrams), explains `git log` output in detail, and links to related topics (e.g., merge conflicts, `git-prompt.sh`).
- **Feedback integration**: Incorporates test reader feedback (70+ comments from 16 people) to address common pain points, such as confusion about `git log` output or the "tree" metaphor.

The patch adds the tutorial to `Documentation/Makefile`, `meson.build`, and `command-list.txt`, making it accessible via `git help gittutorial-branches`.
