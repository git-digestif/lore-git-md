Git only uses mmap for content-addressed files (packs, indexes) or files replaced atomically via `rename(2)`. He notes that APFS’s behavior (not updating `mtime` until `msync()`) is technically allowed by POSIX, but argues that relying on mmap for mutable files is poor practice, which is why text editors and similar tools avoid it.

The response suggests the project’s stance is that this is not a Git bug but rather a limitation of APFS’s mmap implementation. Carlson implicitly discourages Harold’s proposed fix (checking APFS generation numbers or falling back to content examination) by emphasizing the risks of mmap for mutable files and pointing to the `SubmittingPatches` guidelines, which prohibit AI-generated patches.
