This is a documentation patch introducing a new tutorial for beginners on how to use Git branches. Julia Evans (with co-author Marie Claire LeBlanc Flanagan) proposes adding `Documentation/gittutorial-branches.adoc`, a 940-line guide that walks new users through branch concepts and workflows.

The tutorial is designed to be accessible to non-CS audiences, avoiding jargon like "directed acyclic graph" while still explaining Git's data model. It uses a narrative approach with four fictional personas (Abdul the open source contributor, Betsy the corporate developer, etc.) to illustrate different branch workflows. Key pedagogical choices include: showing command output for every example, using `git log --graph` for visualization, and focusing on the "tree" mental model before introducing Git's technical representation of branches.

The patch adds the new file to the build system (Makefile and meson) and updates `command-list.txt`. Self-review notes mention 70 comments from 16 test readers, with overwhelmingly positive feedback ("This is the best tutorial for git branches", "I finally feel like I get it"). The only open question is whether to keep the GUI tools section, given many popular tools are proprietary.

This appears to be a well-crafted addition to Git's documentation suite, filling a gap between the existing `gittutorial` (commits/push) and more advanced guides. The tutorial's structure and tone align with Julia Evans' reputation for clear technical explanations.
