This is a **substantive review comment** on the second patch of Farid Zakaria’s v2 series fixing credential-cache daemon races. Patrick Steinhardt flags a confusing commit message claim: the text explains that the directory is created with mode `0700` to avoid a race, yet the patch itself does not change the `mkdir()` call—it only adds an `EEXIST` check. The implication that the patch avoids a race by using `mkdir(..., 0700)` is therefore misleading, and the reviewer asks for clarification on why anyone would consider the two-step `mkdir(..., 0777) && chmod(...)` pattern preferable in the first place. The comment does not challenge the patch’s correctness but highlights a documentation issue that could mislead future readers.
