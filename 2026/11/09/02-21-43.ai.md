This is a **substantive review** of brian m. carlson’s patch to fix the default object format in `git init` for Git v3. Junio C Hamano identifies two key issues in the current implementation: a latent bug in the existing code and a regression introduced by the patch.

First, Junio explains why the original behavior (new repositories defaulting to SHA-1) persisted despite `REPOSITORY_FORMAT_INIT` setting `.hash_algo = GIT_HASH_DEFAULT`. The culprit is `read_repository_format()`, which forces the hash algorithm to `GIT_HASH_SHA1_LEGACY` when `version == -1` (indicating no configuration exists yet). This logic overrides the intended default, which the patch aims to correct.

Second, Junio highlights a structural flaw in `repository_format_configure()`: the hash-algo block lacks the same guard as the ref-storage block. Specifically, the `else if (cfg.hash != GIT_HASH_UNKNOWN)` branch is unguarded, meaning `init.defaultObjectFormat` in `~/.gitconfig` (or the new `GIT_HASH_DEFAULT`) can silently overwrite an existing repository’s object format during reinitialization. This is the same edge case Junio raised earlier, now traced to a missing `repo_fmt->version >= 0` check.

Junio proposes a refactor to fix both issues: restructure the `if/else` cascade to ensure all default-setting logic (command-line, environment, config, or built-in) only executes when `repo_fmt->version < 0` (i.e., for new repositories). For existing repositories (`version >= 0`), the code should either preserve the current format or fail if an incompatible hash is specified. The suggested change would make the behavior consistent with the ref-storage logic, which already handles reinitialization safely.

This review is **tested** (Junio’s earlier email included a failing test case) and **substantive**, as it pinpoints the root cause of the regression and proposes a structural fix. The patch will need revision to address these issues before integration. The discussion remains focused on the initialization logic in `setup.c`, with no new design questions introduced.
