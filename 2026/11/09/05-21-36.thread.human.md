This thread is an Outreachy internship proposal from Fien Dora, aiming to improve Git's command-line argument parsing subsystem over a three-month period (December 2026–March 2027). Fien, mentored by Christian Couder and Siddharth Asthana, proposes to convert manual argument-parsing loops in `git diff-index` and `git diff-tree` to Git's shared `parse_options()` API. Their background in C and prior contributions to Git—including an accepted microproject patch—demonstrate readiness for this work.

The proposal focuses on two commands that currently mix `setup_revisions()` (for revision/diff arguments) with manual parsing for command-specific options. For `git diff-index`, the goal is to replace a loop handling `--cached`, `--merge-base`, and `-m` with `parse_options()`, while preserving interactions with `diff_merges_suppress_m_parsing()`. For `git diff-tree`, the challenge involves `--stdin` and `--merge-base`, which cannot be used together. Fien has thoroughly researched the current implementations, test coverage, and edge cases (e.g., abbreviated options), and the timeline emphasizes incremental work, design discussions, and regression testing.

This is a well-scoped and practical proposal, addressing a real maintainability issue while aligning with Git's ongoing efforts to standardize command-line handling. The attention to detail—particularly around preserving existing behavior and test coverage—makes it a strong candidate for the internship. If executed as planned, it would deliver meaningful improvements to Git's codebase.
