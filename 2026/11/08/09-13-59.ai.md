This is a brief follow-up in the `test-tool genbytes` thread, responding to Junio C Hamano’s design proposal for the byte-specification interface.

Kristofer Karlsson accepts Junio’s suggestion to switch the `genbytes` interface from accepting a literal character or the string "NUL" to a two-digit lowercase hexadecimal value (e.g., `00` for NUL, `20` for space). He confirms having prototyped this approach locally but hesitated due to the larger semantic change; now, however, he agrees it improves ergonomics and commits to implementing it. The change will require updating all 26 call sites across the test suite to use hex values instead of literal characters or "NUL". No new workflow decisions or patch-series revisions are announced; the focus remains on the interface adjustment. The thread’s next step is a v2 series incorporating this hexadecimal parser and the previously agreed consolidation of the file rename and functional changes into a single patch.
