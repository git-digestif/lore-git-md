This is a brief follow-up in the ongoing test infrastructure thread introducing `test-tool genbytes` to replace slow `tr(1)` invocations on macOS. The author, Kristofer Karlsson, accepts Junio C Hamano’s design alternative: instead of the current interface that accepts a literal character or the string "NUL", the command will now take a two-digit lowercase hexadecimal value (e.g., `00` for NUL, `20` for space). This change eliminates the need for special-casing NUL and simplifies the parser, though it requires updating all 26 call sites in the test scripts. Kristofer notes he already prototyped this approach locally and agrees it improves consistency, despite the slightly larger semantic change. No new patches have been sent yet; the next iteration will reflect this interface redesign.
