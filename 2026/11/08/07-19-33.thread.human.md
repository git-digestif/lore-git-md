This thread is about a refactoring patch that moves Git’s `assume_unchanged` flag from a global variable into the repository-specific `repo_config_values` struct, continuing the long-running effort to eliminate the `the_repository` global. The patch is a mechanical change with no user-visible effects, touching index and repository-setting code in four files. It was posted by Hussain Sitamouwala and is still awaiting its first substantive review.

In a separate but related development, Junio C Hamano has signaled that Hussain’s earlier documentation patch (v3) on partial-clone promisor remote fetch ordering is ready to be queued, pending only an Ack from Christian Couder. That patch is now effectively in its final review stage and is expected to land shortly. The two patches remain independent threads; the documentation update does not affect the status or review of the refactoring patch.
