This is a test infrastructure patch that introduces `test-tool genbytes` to eliminate a significant performance bottleneck in Git's test suite on macOS.

The patch replaces slow `tr(1)` invocations with a new `test-tool genbytes` command that writes arbitrary bytes directly. The key improvement is the interface: `genbytes` now accepts the byte as two lowercase hexadecimal digits (e.g., `00` for NUL, `61` for 'a'), addressing prior design feedback and allowing clean specification of any byte value. The implementation uses a 256 KB buffer and preserves backward compatibility by keeping `genzeros` as a thin wrapper around the same core code.

Performance measurements in the commit message show dramatic improvements on macOS CI runners: jobs now complete 70–79% faster (from ~800–900 seconds to ~200 seconds). Linux jobs see modest gains of 2–7%, reflecting the already-efficient `tr(1)` implementation on that platform. The patch updates 14 test scripts that previously used `genzeros | tr` pipelines, making `genbytes` the obvious choice for future test development.

This is a well-motivated, thoroughly tested change that addresses a real cross-platform performance issue without introducing behavioral changes. The hexadecimal interface is a clean design that future-proofs the test suite for generating arbitrary bytes. All prior review feedback has been addressed, and the implementation appears solid. Worth noting for anyone running Git's test suite on macOS.
