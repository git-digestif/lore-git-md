This is a follow-up surface-level review comment from Junio C Hamano on the first patch of Kristofer Karlsson’s `test-tool genbytes` series. Junio retracts his earlier concern about intermediate breakage: after closer inspection, he confirms that the rename in patch 1/3 does not actually break the ten test scripts that still call `test-tool genzeros`, because the dispatcher inside the renamed binary continues to recognize the old command name and invokes the original `cmd__genzeros` function. He reiterates his workflow suggestion—applying patches 1 and 2 together, squashing them into a single commit, and using `git format-patch -M3` to produce a rename-aware diff—so that the series avoids any intermediate state where the file rename and the functional changes appear as separate steps.
