Core problem or goal
Refactor `git reflog expire` to consolidate two separate loops (one for `--all`, one for named refs) into a single loop, addressing a maintainer suggestion from an earlier fix (d1536ac3e2). The goal is to eliminate code duplication while preserving existing behavior: error reporting, exit status, output order, and handling of dynamic refs like `@{-1}`. The patch also presents an opportunity to deduplicate refs (e.g., if the same ref appears via `--all` and a command-line argument), which would simplify error handling and avoid redundant work.

Patrick Steinhardt has raised two requests for improvement: (1) the commit message should better explain the *why* (not just the *what*), and (2) the new loop structure could deduplicate refs.
