This is a documentation patch from the maintainer updating `Documentation/CodingGuidelines`. It deletes a four-line clause that warned against "clever tricks" and specifically cited using the `!!` operator with arithmetic constructs as confusing. The commit message notes that `!!value` is a standard technique for normalizing a value to a 0/1 boolean, not an exotic trick, and mentions the idea to remove the rule was floated in a recent review thread but not followed through until now. No code is touched; the change only removes the prohibition from the contributor guidelines. As a standalone patch signed off by Junio C Hamano, it is under review on the list.
