This is a documentation patch, specifically the fourth and final patch of Patrick Steinhardt's four-part performance series on reflog expiration. It fixes a simple cross-reference typo in `Documentation/config/maintenance.adoc`: the description of `maintenance.reflog-expire.auto` incorrectly pointed readers to `maintenance.loose-objects.auto` when explaining the threshold semantics, and now correctly refers to `maintenance.reflog-expire.auto` itself.

The change is a one-line correction with no behavioral impact. As the closing patch of the series, it completes the set that includes the reftable backend optimizations and the `builtin/gc.c` reachability fix described in the earlier patches, all aimed at eliminating the unnecessary `git reflog expire` spawns during `git maintenance run --auto`.
