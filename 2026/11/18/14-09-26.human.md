This is a post-merge documentation follow-up in the `ps/rerere-subcommands` thread, which modernized `git rerere`'s subcommand handling and was merged to `master` in June 2025. Junio C Hamano spotted a long-standing discrepancy while reviewing the final patch: the man page for `git rerere diff` still claims that additional arguments are passed to the system `diff` command, but the code has not actually accepted or forwarded any arguments since commit 658f365027 ("Make git-rerere a builtin") in 2006. The new per-subcommand usage strings added in this series preserved the stale prose.

Patrick Steinhardt acknowledges the oversight and commits to sending an additional patch to correct the documentation while the topic is still fresh. The observation is purely documentary -- no code behavior changes are needed -- but it closes a two-decade-old gap where users reading the man page could expect functionality that does not exist. The broader refactoring series remains closed and merged; this is a minor cleanup riding on the same thread.
