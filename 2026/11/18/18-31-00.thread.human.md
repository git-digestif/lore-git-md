This thread opens with a standalone documentation patch from Junio C Hamano, the Git maintainer, proposing to delete a four-line clause from `Documentation/CodingGuidelines`. The removed text had warned contributors against "clever tricks" and singled out the `!!` operator in arithmetic constructs as confusing. Junio argues that `!!value` is a standard, widely understood technique for normalizing a value to a 0/1 boolean rather than an exotic trick, and notes that the idea of dropping the rule had been floated in a recent review thread but not acted on until now.

The patch touches no code -- it only edits the contributor guidelines -- and is signed off by Junio himself. As a standalone submission it is currently under review on the mailing list, with no decisions or reviewer responses recorded yet.
