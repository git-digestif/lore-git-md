This is a surface-level review reply to the documentation patch in Dirk Gouders' v2 series. This particular patch (2/4) is documentation-only, and Koppe's note simply catches a second misleading phrase in the same comment that the patch author missed.

The series remains under review with no outstanding technical objections; Junio C Hamano has already given style nits on patch 3 and approved patch 4.
