This is a documentation patch, specifically the fourth and final patch of Patrick Steinhardt's four-part performance series on reflog expiration during auto-maintenance. It fixes a copy-paste typo in `Documentation/config/maintenance.adoc`: the description of `maintenance.reflog-expire.auto` incorrectly referenced `maintenance.loose-objects.auto` when explaining the threshold semantics; the patch corrects the reference to point to `maintenance.reflog-expire.auto` itself. The change is a single-line edit in the AsciiDoc source for the maintenance config documentation, touching no code or tests. With this patch, the series is complete -- patches 1 through 3 addressed the reftable backend write optimizations and the reachability logic in `builtin/gc.c` that caused unnecessary `git reflog expire` invocations, while this patch merely cleans up the documentation for the config key that controls that behavior.
