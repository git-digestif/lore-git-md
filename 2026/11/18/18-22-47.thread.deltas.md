# Thread deltas

## 2026/11/18

- [2026/11/18/18-22-47 by Maik Riechert via GitGitGadget <gitgitgadget@gmail.com>] Maik Riechert posted a patch to diff-lib.c that makes check_removed() return immediately via fake_lstat() for entries with CE_FSMONITOR_VALID set, skipping the has_symlink_leading_path() check; the commit message explains that fsmonitor would have reported any leading-directory symlink replacement and cleared the valid bit, and reports that "git diff HEAD" on Linux with 100,000 files and a warm cache drops from 57ms to 26ms, with three new tests in t/t7519-status-fsmonitor.sh covering the shortcut and reported-directory cases.
- [2026/11/18/19-01-42 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano reviewed the patch, suggested retiring the now-single-use stat_err variable by inlining lstat() into the if() condition, and stated that, assuming the CE_FSMONITOR_VALID bit is trustworthy, the change looks OK, noting that avoiding the expensive has_symlink_leading_path() is a big plus already done in read-cache.c:refresh_cache_ent() and preload-index.c:preload_thread().
