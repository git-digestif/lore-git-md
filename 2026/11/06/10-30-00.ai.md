This is a CI/build system patch series targeting GitLab CI speedups. The author, Patrick Steinhardt, addresses slow test execution in Git's continuous integration pipelines, with improvements that benefit both GitLab and generic CI environments.

The series consists of seven patches that collectively reduce end-to-end CI runtime by optimizing specific bottlenecks. Key changes include: replacing Extract-Archive with tar(1) to cut Git for Windows SDK installation from 3 minutes to 10 seconds; optimizing t0027's repository reset logic to reduce Windows test time from over 10 minutes to 6 minutes; and enabling reftable usage in t5551/t5559 to achieve 10x speedups on macOS (from 20 minutes to 2 minutes per test). The series also introduces Meson-optimized builds and template-based repository setup in t1092.

Notable technical details include the observation that Git's SHA256 implementation performs poorly with "-O0" optimization, and that Windows runners remain the critical path despite these improvements. The patches touch CI configuration (.gitlab-ci.yml, install-sdk.ps1), test scripts (t0027, t1092, t5551), and build infrastructure (run-build-and-tests.sh). While GitLab-specific changes dominate, several optimizations (like the Meson build flag and reftable usage) have broader applicability.

The series demonstrates measurable impact: macOS jobs improve from 29 to 18 minutes, Fedora jobs from 35 to 16 minutes, and overall Windows pipeline time reduces by ~10 minutes. The author provides a GitLab merge request link for verification. This appears to be a well-motivated, practical improvement to CI infrastructure rather than a fundamental architectural change.
