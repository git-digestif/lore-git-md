This is a CI/build system patch, the second in Patrick Steinhardt’s seven-part series to speed up Git’s GitLab CI pipelines. It targets a specific bottleneck in the Windows test sharding setup: the build artifacts passed from the build job to the test runners include thousands of unnecessary `*.obj` files that inflate download and extraction time.

The patch adds a two-line exclusion rule to `.gitlab-ci.yml` that drops all `*.obj` files from the artifact archive. The result is a measurable improvement: artifact handling time is cut from 34 seconds to 17 seconds. This is a straightforward, low-risk change that directly addresses the stated goal of reducing CI runtime without altering any code or test logic. The commit message is clear and includes before/after metrics, making the benefit obvious. No open questions or controversy are evident; this looks like a well-justified, incremental optimization.
