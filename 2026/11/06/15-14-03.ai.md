This is patch 9/12 in the v3 series modernizing `git rerere`'s subcommand handling. It extracts the "diff" action into a dedicated `cmd_rerere_diff()` function with standard `parse_options()` machinery, preserving the existing logic: the function calls `rerere_cache_setup()` with `RERERE_READONLY`, iterates over the conflicted paths in `MERGE_RR`, and invokes `diff_two()` on each preimage. The change is purely mechanical—no behavior change, no new CLI options, and no on-disk format changes—and touches only `builtin/rerere.c`. The patch follows the same pattern established in earlier patches (5–8) for the "forget", "clear", "status", and "remaining" subcommands, preparing the codebase for the upcoming `OPT_SUBCOMMAND()` conversion in patch 11. The function signature (`argc`, `argv`, `prefix`, `repo`) and empty option table match the style used for the other subcommands, and the existing hand-rolled `if (!strcmp(argv[0], "diff"))` branch in `cmd_rerere()` is updated to delegate to the new function. The series remains uncontested and on track for integration. Key symbols: `cmd_rerere_diff()`, `RERERE_READONLY`.
