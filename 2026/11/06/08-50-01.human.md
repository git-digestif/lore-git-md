This is a documentation patch updating `Documentation/technical/api-parse-options.adoc` to document previously undocumented flags and macros in Git's `parse-options` API. It is the second iteration (v2) of a standalone cleanup effort by Karthik Nayak, addressing feedback from the initial review.

The patch adds missing documentation for two flags (`PARSE_OPT_ONE_SHOT` and `PARSE_OPT_SHELL_EVAL`) and nineteen macros (`OPT__SUPER_PREFIX`, `OPT__VERBOSITY`, `OPT_BITOP`, `OPT_STRVEC`, `OPT_UYN`, `OPT_NOOP_ARG`, `OPT_COLUMN`, `OPT_CONTAINS`, `OPT_NO_CONTAINS`, `OPT_WITH`, `OPT_WITHOUT`, `OPT_CLEANUP`, `OPT_PATHSPEC_FROM_FILE`, `OPT_PATHSPEC_FILE_NUL`, `OPT_AUTOSTASH`, `OPT_DIFF_UNIFIED`, `OPT_DIFF_INTERHUNK_CONTEXT`, `OPT_IPVERSION`, and `OPT_ALIAS`). It also corrects the signature of `OPT__FORCE` to include its `flags` argument. The changes are purely additive, aligning the documentation with the current state of `parse-options.h` without altering code behavior.

The v2 update incorporates minor copy-editing fixes (e.g., "follow" → "following") and commit-message corrections (e.g., `OPT_NO_WITH` → `OPT_WITHOUT`), along with the addition of `OPT_ALIAS`, which was overlooked in the initial version. The patch remains uncontroversial, as it simply fills gaps in the technical documentation to make the API more accessible to contributors. No substantive technical feedback was raised in the review, and the changes are likely to be merged without further debate.

This is a well-scoped, low-risk improvement that enhances the project's documentation coverage. It is worth noting for developers who work with Git's command-line option parsing, but requires no action from users or maintainers of other subsystems.
