This is patch 10/12 in Patrick Steinhardt’s `ps/rerere-subcommands` series (v3), a refactoring that converts `git rerere` to Git’s standard `OPT_SUBCOMMAND()` mechanism. The patch extracts the "gc" action into a dedicated `cmd_rerere_gc()` function with its own `parse_options()` machinery, preserving the existing `rerere_gc()` call and behavior. It also removes the now-redundant global `--skip-locked` flag from the top-level parser, since the option is now scoped to the "gc" subcommand and declared in its local option table as a hidden boolean. The change is purely mechanical: no behavior change, no new CLI options, and no on-disk format changes. The test suite (`t/t4200-rerere.sh`) loses one negative test that checked the now-removed global flag. Karthik Nayak’s review of this patch in v2 confirmed it is a straightforward refactoring that aligns with the series’ goal. The patch is uncontested and ready for integration.
