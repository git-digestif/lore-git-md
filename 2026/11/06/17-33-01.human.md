This is the fourth patch in Patrick Steinhardt’s seven-patch series to speed up GitLab CI pipelines. The patch optimizes the `t0027-auto-crlf.sh` test script by reducing the number of process spawns during repository state reset—replacing ten separate `rm` and `git checkout` commands with a single invocation of each. The change is purely mechanical, confined to the test script, and delivers a measurable 20 % runtime reduction across platforms, saving roughly 2.5 minutes on Windows.

Junio C Hamano’s reply suggests a small stylistic refinement: instead of hard-coding the list of filenames twice (once for `rm` and once for `git checkout`), he proposes building the list programmatically inside the loop. This would make the code more maintainable if the list ever changes, though it does not affect the performance gain. The suggestion is non-blocking and the patch remains well-motivated and uncontroversial.
