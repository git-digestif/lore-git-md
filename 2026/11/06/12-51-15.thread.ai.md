Subject: [PATCH 1/2] unpack-objects: fix type mismatch on 32-bit platforms

Thread type: bugfix patch series

Core problem or goal
Fix a type mismatch in `unpack-objects` that causes blob sizes larger than 4GB to be truncated on 32-bit platforms (notably Windows), leading to a fatal write error. The regression was introduced in `f2063855fb` (May 2026) when object sizes were migrated to `size_t` but `stream_blob()` was left using `unsigned long`.

Current status
Under review. Patch 1/2 (this email) provides the minimal fix—changing `stream_blob()` to accept `size_t`—while patch 2/2 (not yet summarized) adds the test case. No prior versions of this series exist.

Key technical details
- File: `builtin/unpack-objects.c`
- Function: `stream_blob()`
- Symbol: `struct odb_stream` (already uses `size_t` for object sizes)
- Type change: `unsigned long` → `size_t`
- Error symptom: `"write stream object 4294967296 != 8"` (truncation)
- On-disk format: unchanged
- Test coverage: added in patch 2/2
