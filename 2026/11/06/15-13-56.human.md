This is the second patch in Patrick Steinhardt’s 12-patch refactoring series that modernizes `git rerere`’s subcommand handling. The patch converts the existing `#define` flag constants (`RERERE_AUTOUPDATE`, `RERERE_NOAUTOUPDATE`, `RERERE_READONLY`, `RERERE_NOWAIT`) into a proper C enum (`enum rerere_flags`) and updates all function signatures in `rerere.c` and `rerere.h` to use the new type.

The change is purely mechanical and aligns with Git’s modern coding guidelines, which prefer enums for flag parameters because they make the expected values self-documenting. The enum values are assigned the same bit positions as the old `#define` constants, so there is no behavior change. The patch also expands the documentation for each flag: the comment for `RERERE_NOAUTOUPDATE` now explicitly clarifies that it updates the working tree but leaves the index untouched while still printing conflict-resolution messages to stderr, addressing feedback from Karthik Nayak on the previous iteration.

Files touched are `rerere.c` and `rerere.h`; no other code or documentation is modified. The patch is uncontested and ready for integration. It is a low-risk, guideline-driven refactoring that sets the stage for the later patches in the series, which replace the hand-rolled subcommand parsing with Git’s standard `OPT_SUBCOMMAND()` mechanism.
