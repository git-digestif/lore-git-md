This is a **substantive review** of the `%gb` reflog format placeholder patch series (v4). Phillip Wood identifies two remaining correctness issues in the branch-name detection logic for `%gb`:

1. **Detached HEAD labeling**: The current implementation labels detached HEAD entries with the commit *before* switching away, rather than the commit where HEAD was originally detached. This is misleading—users expect "detached at <commit>" to refer to the commit where HEAD became detached, not the last commit visited in that state.

2. **Rebase checkout parsing**: The logic for parsing `rebase: checkout <revision>` messages is fragile. It incorrectly treats remote branch names (e.g., `origin/main`) as local branch names, and it can be confused by commit subjects that start with "checkout " (e.g., `git commit -m "checkout main"`). Phillip suggests a fix: verify that the reflog message does not match the commit subject before parsing it as a checkout.

Phillip provides a **failing test case** that exercises both issues, along with a `GIT_REFLOG_ACTION` edge case (URLs containing `:`). The test creates a complex history involving:
- A clone with local and remote branches
- Interactive and non-interactive rebases (including `git rebase <upstream> <branch>`)
- Detached HEAD states
- Custom `GIT_REFLOG_ACTION` values
- Commits with subjects that could confuse the parser

The test expects `%gb` to correctly label each reflog entry with the branch name or "detached at <commit>", but the current implementation fails for the detached HEAD and rebase checkout cases.

This review is **actionable and technical**, focusing on correctness rather than design. The issues are subtle but important for usability—mislabeling detached HEAD entries or branch names would undermine the feature’s reliability. The test case is thorough and should be incorporated into the series. No alternative approaches are suggested; the feedback is prescriptive and targets specific implementation flaws. The series remains under review, with no maintainer decision yet.
