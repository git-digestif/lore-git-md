This is the third patch in Patrick Steinhardt's seven-part CI/build system series aimed at speeding up GitLab CI pipelines. It addresses a specific bottleneck in the `fedora-breaking-changes-meson` job, which runs roughly twice as long as other Linux jobs due to unoptimized Meson builds.

The patch changes the Meson build type from "debug" (which translates to `-O0`) to "debugoptimized" (equivalent to `-O2`). This optimization has a dramatic impact on the Fedora job, cutting its runtime from 2100 seconds to 1000 seconds. The improvement is particularly noticeable because the job enables SHA256 with the "block" backend, which benefits heavily from compiler optimizations—hashing a 500MB blob with SHA256 takes 9.6 seconds at `-O0` but only 1.5 seconds at `-O2`. Other Linux and macOS jobs see smaller but still meaningful speedups (~10%), while Windows builds show mixed results: the build step slows by about two minutes, but tests run ~10% faster, leaving total runtime roughly unchanged.

The change is minimal, touching only two files: `.gitlab-ci.yml` (for Windows builds) and `ci/run-build-and-tests.sh` (for Linux/macOS). The patch adds the `--buildtype=debugoptimized` flag to Meson setup commands, ensuring consistent optimization across all CI jobs. This is a targeted, low-risk optimization that directly addresses a clear performance bottleneck without altering Git's behavior or on-disk formats. The author provides concrete before/after metrics, making the impact easy to verify.
