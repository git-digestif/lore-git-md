This is patch 11/12 in Patrick Steinhardt’s v3 series modernizing `git rerere`’s subcommand handling. The patch replaces the hand-rolled `if (!strcmp(...))` ladder with Git’s standard `OPT_SUBCOMMAND()` mechanism, introducing `cmd_rerere_perform()` as the fallback subcommand and removing the global `--[no-]rerere-autoupdate` flag from the top-level parser. The change is framed as a bug fix: the flag was previously accepted but ignored for all subcommands except the default, so removing it is a correctness improvement. The `PARSE_OPT_SUBCOMMAND_OPTIONAL` flag ensures backward compatibility—if no subcommand is given, the parser invokes `cmd_rerere_perform()` instead of erroring out. Karthik Nayak’s review raised minor questions about code structure (suggesting an early `return fn(...)` to reduce nesting) and requested a comment clarifying that `"perform"` is a dummy placeholder subcommand name; Patrick declined the restructuring but added the requested comment. The patch touches only `builtin/rerere.c` and is a mechanical refactoring with no behavioral changes beyond the flag removal. All prior feedback has been addressed, and the patch is uncontested.
