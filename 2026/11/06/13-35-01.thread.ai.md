Thread identity: standalone feature request for `git ls-files` to add a `--type` filter option (e.g., `--type f` to exclude symlinks). Originating author: Alejandro Colomar. Thread type: feature proposal, now closed by maintainer feedback and author concession.

Core problem or goal: enable `git ls-files` to filter output by file type (e.g., exclude symlinks) natively, improving workflow efficiency for tools like `grep`/`sed` in large directories (e.g., built Linux kernel trees). The goal was to replace slower workarounds (e.g., `find . -type f` or `git ls-files --format=%(objectmode) | grep 100644`) with a Git-native solution that avoids post-processing complexity, particularly for filenames with spaces. The proposal is now abandoned in favor of a local wrapper script.
