This is a CI/build system patch series from Patrick Steinhardt targeting GitLab CI speedups. The seven-patch series aims to reduce end-to-end CI runtime by addressing specific bottlenecks, with some improvements also benefiting GitHub Actions.

The series delivers measurable wins: Git for Windows SDK installation drops from 3 minutes to 10 seconds, macOS jobs shrink from 29 to 18 minutes, and Fedora jobs halve from 35 to 16 minutes. Windows runners remain the critical path (only ~10 minutes saved), but other platforms see faster feedback. Key optimizations include switching to `tar` for SDK extraction, building optimized Meson binaries, caching test outputs, and using reftables for ref-heavy tests.

The patches touch `.gitlab-ci.yml`, PowerShell scripts, and test files (`t0027`, `t1092`, `t5551`). While some changes are GitLab-specific (e.g., artifact handling), others like Meson optimizations and test caching are generic. The series is well-motivated with clear before/after metrics, and the linked MR provides real-world validation. Worth attention if CI performance is a pain point for your workflow.
