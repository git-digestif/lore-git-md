This is an Outreachy internship project proposal (v3) for implementing promisor remote fetch ordering in Git. The author, Shashank S, is applying for the December 2026 Outreachy round with a well-structured plan to add configurable ordering to Git's promisor remote fetching mechanism in partial clones.

The proposal targets a real gap in Git's partial clone functionality: while the current promisor remote fetch order is deterministic, users cannot configure it, and servers cannot express ordering preferences. The project would allow users to prioritize which promisor remotes Git tries first when fetching missing objects, potentially improving performance and reliability in multi-remote setups. The author demonstrates solid understanding of the current code through hands-on experimentation with Trace2 tracing and analysis of `promisor-remote.c`.

Shashank has already made meaningful contributions during the Outreachy contribution period, with four patches merged or queued for merging - two test modernizations, one `the_repository` removal, and one option-parsing improvement. The proposal shows careful evolution from v2, with clearer technical risks, better coordination with upstream work, and removal of premature design commitments (like the `promisor.fetchOrder` configuration name). The 13-week plan is realistic, starting with baseline documentation and tests before diving into RFC discussions and implementation.

The proposal stands out for its balanced approach to design questions. Rather than committing to specific implementation choices upfront, Shashank plans to send RFCs to the mailing list to decide key aspects like configuration format (ordered list vs numeric priorities), server advertisement mechanisms, and precedence rules between local and server preferences. This demonstrates good understanding of Git's consensus-driven development process. The technical risks section shows thoughtful consideration of implementation challenges like configuration parsing, protocol backward compatibility, and interaction with active patches.
