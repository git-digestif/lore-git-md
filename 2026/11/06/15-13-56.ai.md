This is the second patch in Patrick Steinhardt’s 12-patch series modernizing `git rerere`’s subcommand handling. It converts the four `#define` rerere flags (`RERERE_AUTOUPDATE`, `RERERE_NOAUTOUPDATE`, `RERERE_READONLY`, `RERERE_NOWAIT`) into an `enum rerere_flags` and updates all function signatures in `rerere.h` and `rerere.c` to use the new type. The change is purely mechanical: no behavior changes, no new functionality, and no on-disk format changes.

The patch extends the documentation for each flag, most notably clarifying that `RERERE_NOAUTOUPDATE` updates the working tree but leaves the index untouched while still printing conflict-resolution messages to stderr. This addresses Karthik Nayak’s feedback from v2 and is the only substantive difference from the previous iteration. The enum values are defined as bit shifts (`1 << 0`, `1 << 1`, etc.) to preserve the existing bitmask semantics.

Files touched: `rerere.c` and `rerere.h`. Key symbols: `enum rerere_flags` (new), `rerere_cache_setup()`, `rerere()`, and `rerere_gc()` (updated signatures). The patch is uncontested and ready for integration.
