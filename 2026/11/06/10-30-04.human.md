This is a test optimization patch, part of Patrick Steinhardt’s seven-patch series to speed up GitLab CI. It targets `t0027-auto-crlf.sh`, a test script that verifies Git’s CRLF conversion logic across 2,600 combinations of attributes and configuration. On Windows, this test was a major bottleneck, taking over ten minutes to run.

The patch replaces a loop that removed and checked out files one by one with a single `rm` and `git checkout` invocation. This reduces process spawning and index rewrites, cutting runtime by about 20% across all platforms and saving roughly 2.5 minutes on Windows. The change is straightforward and low-risk, touching only the test script’s setup logic without altering the test cases themselves.

This is a well-motivated, practical improvement that directly addresses a known CI pain point. The commit message clearly explains the problem, the solution, and the measurable impact, making it easy to assess. If the rest of the series holds up similarly, these CI speedups look like a solid win for the project.
