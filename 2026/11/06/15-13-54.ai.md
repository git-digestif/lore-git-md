This is the third iteration of Patrick Steinhardt’s 12-patch refactoring series that converts `git rerere` to use Git’s standard `OPT_SUBCOMMAND()` mechanism. The series is purely internal: no new user-visible behavior, no on-disk format changes, and no new CLI options or config keys. It builds on the already-merged `ps/rerere-remove-global-state` topic (b948c10c8b3), which eliminated the global rerere cache state and made this subcommand conversion possible.

The only change in v3 is a clarification in patch 2: the `RERERE_NOAUTOUPDATE` enum comment now explicitly states that it updates the working tree but leaves the index untouched, while still printing conflict-resolution messages to stderr. This addresses Karthik Nayak’s feedback from v2 and is purely documentary—no code or behavior changes. All other patches are carried forward unchanged from v2, which already incorporated Junio’s feedback (renaming the fallback subcommand to `rerere()`, extending enum documentation, and completing the `the_repository` removal).

Files touched are `builtin/rerere.c` (primary), `rerere.h`, `Documentation/git-rerere.adoc`, and callers in `apply.c`, `builtin/am.c`, `builtin/commit.c`, `builtin/merge.c`, `builtin/stash.c`, `rerere.c`, and `sequencer.c`. The test suite (`t/t4200-rerere.sh`) loses one negative test for a now-removed global flag. Each of the six subcommands ("forget", "clear", "status", "remaining", "diff", "gc") now has a dedicated function (`cmd_rerere_*()`) with its own usage string, and the fallback subcommand is `cmd_rerere_perform()`. The series is uncontested and ready for integration.

Key symbols introduced or modified: `rerere()` (replaces `repo_rerere()`), `enum rerere_flags` (replaces `#define` constants), and the six `cmd_rerere_*()` functions. The `the_repository` usage is fully removed from `builtin/rerere.c` as of patch 3. Patch 11 switches the command-line parser to `OPT_SUBCOMMAND()`, and patch 12 adds per-subcommand usage strings to the man page. The series is a textbook example of a low-risk, high-consistency refactoring that aligns `git rerere` with the rest of Git’s built-in commands.
