This is a bugfix patch targeting the `unpack-objects` command, part of a two-patch series. The issue is a type mismatch on 32-bit platforms (notably Windows) where `unsigned long` is only 32 bits wide, causing truncation of blob sizes larger than 4GB. The patch changes the `stream_blob()` function to accept `size_t` instead of `unsigned long` to match the rest of the codebase, which already uses `size_t` for object sizes following a prior change (`f2063855fb`). The fix is minimal—one line in `builtin/unpack-objects.c`—and aligns with the existing type usage in `struct odb_stream`.
