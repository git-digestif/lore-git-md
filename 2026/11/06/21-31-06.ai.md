This is the third patch in Andy Koppe’s v3 series (5/5) that aligns Git’s documentation with the 2024 terminology change distinguishing *root refs* (e.g., HEAD, ORIG_HEAD) from *pseudorefs* (only FETCH_HEAD and MERGE_HEAD). This patch updates six man pages and `gitdatamodel.adoc` to replace outdated uses of "pseudoref" with "root ref" where appropriate, correct inaccuracies, and improve clarity.

Key changes in this patch:
- **`git-worktree(1)`**: Now explicitly states that both root refs and pseudorefs are per-worktree, drops the outdated claim that they live directly under `$GIT_DIR` (which doesn’t hold for reftable), and restructures the list of non-shared ref prefixes (e.g., `refs/worktree/`) for better readability.
- **`git-ls-remote(1)`**: Corrects `--refs` to describe its behavior accurately (omitting refs outside `refs/`), fixes a typo ("symbolics" → "symbolic refs"), and updates the example to reference HEAD (the only root ref advertised by `git-upload-pack`).
- **`git-update-ref(1)`**: Removes the incorrect mention of ORIG_HEAD from the reflog documentation and clarifies that `core.logAllRefUpdates` applies to root refs (e.g., ORIG_HEAD) as well as refs under `refs/`.
- **`gitdatamodel.adoc`**: Adds dedicated sections for *root refs* and *pseudorefs* under the "References" heading, with cross-references to the glossary for definitions. The pseudorefs section now explicitly notes their non-ref status and compatibility with commands like `git log`.

The patch also makes minor corrections in `for-each-ref-options.adoc` (help text for `--include-root-refs`), `config/core.adoc` (scope of `core.logAllRefUpdates`), and `rev-list-options.adoc` (removes "pseudoref" from `--merge` description).

No behavioral changes are introduced—this is purely a documentation cleanup. The updates are precise and address prior review feedback, including Patrick Steinhardt’s suggestions for `gitdatamodel.adoc` (though two minor editorial tweaks remain unresolved). The patch is uncontroversial and ready for merging. Files touched: 7 documentation files (no code or tests).
