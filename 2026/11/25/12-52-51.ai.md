This is a refactoring patch, the first of five in Harald Nordgren's v11 series adding `git branch --delete-integrated`. It moves the existing `branch.<name>.deleteMerged` opt-out check out of `delete_merged_branches()` and into a new static helper `opted_out_of_delete_merged()` in `builtin/branch.c`, so that the upcoming change-based deletion mode (patch 5/5) can consult the same configuration without duplicating the logic. The commit message states there is no change in behavior; the helper takes a `struct strbuf *` for the config key, the branch name, and flags, returns `true` when the branch is opted out (printing the skip message unless `DELETE_BRANCH_QUIET` is set), and the caller now simply adds the branch to the deletable set when the helper returns `false`. The diff is mechanical: 20 insertions and 13 deletions in `builtin/branch.c`, introducing the helper above `delete_merged_branches()` and replacing the inline config lookup with a call to it. This prepares the ground for `--delete-integrated` to honor the same `deleteMerged=false` opt-out, though Junio has separately questioned whether that config key is the right one for the new mode or whether a separate key should exist.
