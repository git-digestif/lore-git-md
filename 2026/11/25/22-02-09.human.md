This is a refactoring patch -- the first of six in Okhuomon Ajayi's v5 series that removes implicit uses of the global `the_repository` from the notes subsystem.

The patch introduces a small static helper, `notes_tree_or_default()`, which encapsulates the repeated pattern of substituting `&default_notes_tree` for a NULL tree pointer and asserting the tree is initialized. Six public entry points in `notes.c` -- `add_note()`, `remove_note()`, `get_note()`, `for_each_note()`, `write_notes_tree()`, and `prune_notes()` -- now call this helper instead of duplicating the check inline. Three functions (`notes_tree_init()`, `free_notes()`, and `format_note()`) keep their own logic because they handle initialization or teardown differently.

The change is purely mechanical with no behavior change, but it lays the groundwork for the rest of the series, which will store a `struct repository *` inside `struct notes_tree` and use it instead of the global. The commit message is clear about the scope, and the patch looks clean and ready for review as part of the ongoing `the_repository` removal effort.
