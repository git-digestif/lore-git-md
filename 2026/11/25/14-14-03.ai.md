This is a substantive review of **patch 2/4** in Jean-Noël Avila's four-part documentation series, which extracts `svn.*` configuration documentation out of `Documentation/git-svn.adoc` into a new shared include file `Documentation/config/svn.adoc`. Junio C Hamano's feedback identifies several concrete issues that would need addressing in a v2, along with open questions about the scope of the new file.

Junio first notes a discrepancy between the patch subject ("add missing config options") and the commit message body (which describes moving existing descriptions to `config/svn.adoc`), suggesting the explanation should acknowledge both the addition to `git-config(1)` and the relocation from the command man page. He also points out that grouping `svn.findcopiesharder` and `svn.l` under a single definition-list entry in `config/svn.adoc` obscures the fact that the former is a boolean while the latter takes an integer limit, which matters when the content appears in `git-config(1)`. Regarding the `svn.useSvmProps` entry, he observes that the final sentence about introducing a helper function is pre-existing implementation detail from `git-svn.adoc` and suggests trimming it now that the text is exposed in the central config reference.

The most substantive part of the review lists approximately sixteen `svn.*` and `svn-remote.<name>.*` keys that are used in the code (`read_git_config()` in `git-svn.perl` and `perl/Git/SVN.pm`) but are absent from `config/svn.adoc`, including `svn.username`, `svn.repack`, `svn.repackflags`, `svn.nocheckout`, `svn.quiet`, `svn.logwindowsize`, `svn.localtime`, `svn.copysimilarity`, `svn.configdir`, `svn.noauthcache`, `svn-remote.<name>.url`, `svn-remote.<name>.fetch`, `svn-remote.<name>.branches`, `svn-remote.<name>.tags`, `svn-remote.<name>.preserve-empty-dirs`, `svn-remote.<name>.placeholder-filename`, and `svn-remote.<name>.followparent`. He asks the author to clarify in the commit message which subset of keys the file aims to cover, or whether the intention is to eventually document all of them.

Finally, Junio challenges the placement of the included content under the "CONFIG FILE-ONLY OPTIONS" heading in `git-svn.adoc`, noting that many of the relocated `svn.*` variables (such as `svn.addAuthorFrom` and `svn.authorsfile`) do have corresponding command-line flags documented earlier in the same man page. He suggests that if `config/svn.adoc` is meant to serve as the complete `git-config(1)` list, it would fit better under a "CONFIGURATION" section in `git-svn.adoc` using `Documentation/includes/cmd-config-section-all.adoc`, rather than under a heading that implies these options are only settable in the config file. No response from the author or updated version is recorded yet; the series remains under review with no integration branch status indicated.
