This is a refactoring patch, the first of five in version 11 of Harald Nordgren's series to add `--delete-integrated` to `git branch`. It extracts the existing `branch.<name>.deleteMerged` opt-out check from `delete_merged_branches()` into a new static helper, `opted_out_of_delete_merged()`, so that the upcoming change-based deletion logic can reuse the same config lookup without duplicating code.

The patch touches only `builtin/branch.c`, moving thirteen lines into the helper and replacing the inline check with a call. The commit message is explicit that there is no change in behavior; it is pure preparation for patch 4/5 and 5/5, which will introduce `git branch --delete-integrated` and need to honor the same per-branch opt-out.

The change is small, mechanical, and well-motivated. By isolating the config check now, the series avoids a larger diff later and makes the intent clear: both strict tip-reachability deletion (`--delete-merged`) and the new change-based deletion will respect `branch.<name>.deleteMerged=false`. This is exactly the kind of preparatory cleanup that keeps a larger feature series reviewable.
