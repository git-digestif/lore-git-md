This is a "What's cooking" report from Junio Hamano, summarizing the current state of integration branches in git.git as of November 2026. The report lists topics that have graduated to `master`, new topics under review, and those cooking in `next` or `seen`.

Key highlights for a future AI summarizer session:

**Graduated to `master` (irreversible for next release):**
- **cc/early-scan-options**: Unified command-line option parsing for early-scan commands like `git fast-import` using a new `early_scan_options()` API.
- **cd/shift-root-in-graph-fix**: Fixed graph drawing artifacts by avoiding indentation of visual roots when columns exist to their right.
- **ep/pack-objects-streamed-large-blobs-fix**: Corrected size truncation for large blobs (>4GiB) on 32-bit platforms by using `size_t` and `off_t`.
- **hn/ci-ubuntu-26.04-fixes**: Fixed GitHub Actions CI breakages on Ubuntu 26.04, including networking issues in the `linux32` job.
- **jt/object-file-error-handling**: Improved error handling in object file writing paths, surfacing `index-pack` failures and warning on lockfile cleanup failures.
- **pw/stash-change-check-only-once**: Optimized `git stash` by eliminating redundant index loads and change detection checks.
- **tb/repack-cruft-less-midx-corner-cases**: Fixed corner cases in cruft-less MIDX feature to ensure reachability closure when writing bitmaps.
- **jc/config-honor-file-permission**: Configuration file writing now respects read-only permissions of the original file.
- **jc/freeze-repo-config-values**: Documented `struct repo_config_values` as frozen to discourage new additions pending cleanup.

**New Topics (under review or queued for `next`):**
- **ar/ls-remote-show-object-format**: Added `--show-object-format` to `git ls-remote` to output the hash algorithm of empty repositories.
- **mb/ref-filter-missing-object-double-free**: Fixed a double-free in `git for-each-ref` when a ref points to a missing object.
- **cr/missing-ssh-revocation-file**: SSH signature verification now errors out if a configured revocation file is missing (unless marked `:(optional)`).
- **aa/for-each-ref-no-format-fix**: Fixed a segfault in `git for-each-ref --no-format` by deferring default format assignment.
- **ps/repo-count-objects-speedup**: Optimized `git repo structure` by parsing only necessary objects and reading raw tree buffers.
- **we/credential-parse-options**: Converted `git credential` subcommand parsing to use `OPT_SUBCOMMAND` for consistent error reporting.
- **mv/log-follow-merge-opt-in**: Made `--follow` rename detection across merges opt-in via `--follow=merges` or `log.follow=merges` to address performance regressions.

**Cooking (in `next` or awaiting response):**
- **wh/checkout-orphaned-commit-warning**: Added config to skip computing orphaned commits during `git checkout` for performance.
- **tb/config-null-values**: Fixed NULL pointer dereferences in config callbacks when keys lack values (e.g., `key` vs. `key=`).
- **ps/rerere-subcommands**: Converted `git rerere` subcommands to use `OPT_SUBCOMMAND`, removing ad-hoc parsing.
- **hn/fetch-refmap**: Changed default refspec for remotes in shallow repos to avoid fetching all branches.
- **hn/branch-delete-merged-squash**: Added `--delete-integrated` to `git branch` to delete branches squash-merged or rebase-merged into upstream.
- **rm/http-retry-improvements**: Enhanced HTTP retry logic with exponential backoff and configurable status codes for transient errors.
- **ps/odb-loose-stale-cache**: Fixed loose object cache to track newly written objects, preventing false negatives during lazy fetches.

**Notable Refactoring/Themes:**
- **`the_repository` removal**: Several topics (e.g., `jc/unpack-trees-repo`, `oa/merge-blobs-stop-using-the-repository`) continue the effort to eliminate global state.
- **SHA-1/SHA-256 interop**: `cc/pack-index-v3` adds pack index v3 support for mapping object IDs between hash algorithms.
- **Performance**: Optimizations in `git stash`, `git repo structure`, and `git grep --recurse-submodules`.
- **Error handling**: Improvements in object file writing, SSH signature verification, and config parsing.

**Controversial/Stalled Topics:**
- **hn/status-compare-branches-default**: Proposes defaulting `git status` to compare against both upstream and push branches.
- **bc/restrict-hex-to-lowercase**: Prepares for Git 3.0 by rejecting uppercase hex characters in object IDs (breaking change mode).
- **js/push-refspec-match-speedup**: Optimized refspec matching but faced review feedback on edge cases.

**Discarded Topics:**
- **mv/log-follow-speedup**: Retracted in favor of the simpler `mv/log-follow-merge-opt-in`.
- **js/coverity-overflow-fixes**: Awaiting reroll for Coverity-reported integer overflow fixes.

**Key Files/Subsystems Touched:**
- `parse-options.h`/`parse-options.c`: New `early_scan_options()` API and subcommand parsing.
- `builtin/repo.c`: Optimizations for object counting.
- `refs/`: Fixes for double-free, loose ref seeking, and reflog operations.
- `t/`: Test modernizations (e.g., `t9300-fast-import.sh` refactoring).
- `Documentation/`: Updates for `git ls-remote`, `git diff`, and `gitignore` wildcards.

**Likely Points of Contention:**
- **`hn/status-compare-branches-default`**: Default behavior change may surprise users with triangular workflows.
- **`hn/branch-delete-merged-squash`**: New `--delete-integrated` heuristic could misidentify squash merges.
- **`bc/restrict-hex-to-lowercase`**: Breaking change for Git 3.0; may affect scripts/tools expecting uppercase hex.
