This is a lighthearted follow-up in the now-closed `ps/rerere-subcommands` thread. The series itself—a 12-patch refactoring that modernized `git rerere`’s subcommand handling—was merged to `master` in June 2025, but a UI regression (option-ordering enforcement) was later identified and remains unfixed.

In this email, Patrick Steinhardt playfully responds to Tuomas Ahola’s remark that `git history fixup` already implements the workflow Junio C Hamano wished for (`git fixup`). Patrick notes that the only missing piece for Junio’s use case is support for replaying merge commits, which would allow targeting a commit by message (`HEAD^{/^rerere: convert flags}`) rather than counting back. The tone is conversational and not a serious proposal; no code changes or technical discussion are implied. The thread remains closed, and the regression identified in the merged series is still unresolved.
