This is the second patch in Patrick Steinhardt’s v2 series improving performance and memory usage of `git repo structure`. It targets the tree-parsing logic in `builtin/repo.c`: instead of fully parsing every tree object via `parse_object_buffer()`, the code now counts tree entries directly from the raw object buffer. The change is purely internal—no CLI, config, or on-disk format changes—and yields a further 20 % wall-time improvement and 80 % memory reduction (5.1× less) on top of the gains from patch 1. Benchmarks on `git.git` show the combined effect: from 9.6 s and 3.4 GiB down to 7.7 s and 0.7 GiB. The patch is uncontroversial, addresses no open feedback, and is ready for maintainer pickup.
