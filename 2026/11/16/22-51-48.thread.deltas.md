# Thread deltas

## 2026/11/16

- [2026/11/16/22-51-48 by Andreas Wendleder <gonsolo@gmail.com>] Andreas Wendleder reported that with submodule.recurse=true, switching branches in a superproject worktree whose submodule is a linked worktree of the submodule repository aborts with BUG() in validate_submodule_legacy_git_dir() because the linked worktree's git dir (modules/<name>/worktrees/<id>) never ends in the submodule name; he provided a reproduction script, explained that the legacy path calls BUG() instead of returning an error where submodule_move_head() expects a value < 0, noted that with extensions.submodulePathConfig enabled the same commands die with a "refusing to create/use..." message that recommends enabling the already-enabled extension, and proposed either accepting linked worktrees as valid submodule git dirs or returning an error instead of BUG() in the legacy path with a corrected hint.

## 2026/11/17
