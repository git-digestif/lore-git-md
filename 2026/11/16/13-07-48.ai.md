This is the **final patch in a 12-patch series** introducing **pluggable commit graphs** as part of the **ODB (object database) abstraction** effort. It completes the isolation of commit-graph path logic by making all path-derivation functions private to the "files" ODB backend and exposing only backend-specific entry points for reading and writing commit graphs.

The patch **removes the last external caller** of path-derivation logic (in `git-commit-graph verify`) by introducing two new backend-specific functions: `odb_source_files_read_commit_graph_dir()` and `odb_source_files_write_commit_graph_dir()`. These functions allow the built-in `commit-graph` command to operate on a specific object directory without knowing the exact paths, while preserving backward compatibility for the default "files" backend. The patch also **drops public declarations** for path helpers (`get_commit_graph_filename`, `get_commit_graph_chain_filename`, `open_commit_graph`, `open_commit_graph_chain`) and makes them `static` in `odb/source-files.c`.

Key changes:
- **Files touched**: `builtin/commit-graph.c` (adapts to new backend-specific entry points), `commit-graph.h` (removes public path helpers), `odb/source-files.c` (makes path helpers private, adds new backend-specific functions), and `odb/source-files.h` (declares the new functions).
- **Behavior**: No user-facing changes. The `--object-dir` option in `git commit-graph` now delegates path logic entirely to the backend, and the "files" backend continues to use the same paths as before.
- **Design**: The new functions are explicitly marked as "should not be used" except for the `commit-graph` command’s `--object-dir` option, signaling that future backends are expected to expose their own abstractions rather than relying on path-based logic.

This patch is **purely mechanical**—it moves the last remnants of path logic into the backend and cleans up the public interface. The series as a whole is now **feature-complete** for its goal of enabling pluggable commit-graph storage, though the author notes that future backends may require further abstraction of the commit-graph data structure itself. The patch is well-motivated and aligns with the project’s long-term ODB abstraction goals. No new tests are added, as this is infrastructure-only work.
