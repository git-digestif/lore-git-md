Key technical details: Files touched: utf8.c, utf8.h, pretty.c, Makefile, t/meson.build, plus new unit tests t/unit-tests/u-utf8-ansi.c and t/unit-tests/u-utf8-width.c wired into both Makefile and t/meson.build. Symbols: utf8_strnwidth(), utf8_width(), and display_mode_esc_sequence_len_counted(const char *s, size_t len) in patch 1 authored by Junio C Hamano; it scans for an ANSI SGR sequence bounded by index/length using `len <= i` comparison style rather than an end pointer. The existing NUL-terminated display_mode_esc_sequence_len(const char *s) is retained as a thin wrapper calling the counted variant with SIZE_MAX; the v4 end-pointer form and proposed display_mode_esc_sequence_len_all() are absent. Patch 1 adopts the counted variant at two bounded-buffer call sites: utf8_strnwidth() passes `orig + len - string` when skipping escape sequences, and strbuf_utf8_replace() passes `end - src`. Patch 2 is documentation-only, saying the string is "bounded by len" rather than NUL-terminated and fixing the documented invalid-UTF-8 return from strlen() to len. Patch 3 makes utf8_strnwidth() respect len after skipping ANSI sequences, adding `if (string >= orig + len) break;` after escape consumption; its commit message uses the concrete "\033[31mhello" example where len = 5 ends exactly at orig + len and the old code returned width 1 instead of 0 by reading orig + len. Patch 4 declares `size_t remainder`, computes `orig + len - string`, and passes `&remainder` to utf8_width(&string, &remainder) so chopped multibyte characters do not cause out-of-bounds reads, while noting the 3/4 bounds check remains necessary because utf8_width() with zero remainder could still read orig + len. pretty.c passes ch + 1 in format_and_pad_commit() through the counted API; strbuf_add_wrapped_text() intentionally does not use the _counted variant because the input is NUL-terminated there. Tests: t/unit-tests/u-utf8-ansi.c covers the counted function, wrapper behavior with SIZE_MAX, and truncated boundary sequences using cl_assert_equal_u(); t/unit-tests/u-utf8-width.c covers bounded utf8_strnwidth() including test_utf8_width__strnwidth_ansi() for "\033[31mhello" at lengths 4, 5, 6 giving widths 3, 0, 1, and test_utf8_width__strnwidth_cjk_chopped() for chopped CJK input.
