This thread is Junio C Hamano's November 2026 "What's cooking in git.git" report, tracking the state of in-flight topics across his integration branches. Several topics have graduated to `master`, including fixes for large-blob handling on 32-bit platforms, GitHub Actions breakages on Ubuntu 26.04, cruft-less MIDX corner cases, and various error-handling and performance improvements to `git stash` and object-file writing. Among the new topics, Adrian Ratiu's `ar/ls-remote-show-object-format` -- which adds a `--show-object-format` flag to `git ls-remote` to reveal the hash algorithm of empty repositories -- has now been explicitly confirmed by Junio to advance to `next`, with no objections raised. Other new patches address a double-free in `for-each-ref`, missing SSH revocation files, and a segfault in `for-each-ref --no-format`.

Several topics remain cooking in `next` or awaiting further review, including Han-Wen Nienhuys's `--delete-integrated` option for `git branch` and Ramsay Jones's HTTP retry improvements, which Junio is "reasonably happy" with but wants a second opinion on before advancing. The report also flags two potentially contentious proposals: defaulting `git status` to compare against both upstream and push branches, and a Git 3.0 preparation to reject uppercase hex in object IDs. A few older topics have been discarded in favor of replacements, such as Martin von Zweigbergk's opt-in `--follow=merges` for `git log` superseding an earlier speedup attempt.
