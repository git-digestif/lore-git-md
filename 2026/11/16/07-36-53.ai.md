This is a surface-level review of the first patch in Adrian Ratiu’s three-patch series fixing bugs in Git’s `compatObjectFormat` interoperability layer. The patch itself remains uncontroversial and well-justified: it prevents a crash when `extensions.compatObjectFormat` is set to the same hash algorithm as the repository’s `objectFormat`, replacing the BUG() with a clear error message. Patrick Steinhardt’s feedback is purely cosmetic, pointing out two minor issues: (1) the user-facing error message should use the correct capitalization (`compatObjectFormat` instead of `compatobjectformat`), and (2) the test script could use the modern `git config unset` syntax for consistency with earlier `git config set` calls. Neither comment questions the technical correctness or necessity of the fix; both are straightforward to address in a reroll. The patch is still likely to be accepted as-is once these nits are fixed.
