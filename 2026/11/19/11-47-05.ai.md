This is a refactoring patch -- specifically the fourth of thirteen in Patrick Steinhardt's v5 series that modernizes `git rerere`'s subcommand handling by replacing its custom parser with `OPT_SUBCOMMAND()`.

The patch touches only `builtin/rerere.c` and modifies the `status` and `diff` subcommand handlers: both previously called `rerere_cache_setup(&cache, repo, &merge_rr, flags | RERERE_READONLY)`, but now pass just `RERERE_READONLY`. The `flags` variable holds the `--rerere-autoupdate`/`--no-rerere-autoupdate` value, which these read-only subcommands ignore anyway, so dropping it is purely preparatory cleanup with no behavior change. This establishes the pattern that read-only subcommands receive only `RERERE_READONLY` while the default (no-subcommand) path retains the user-supplied autoupdate flags; future patches in the series build the `OPT_SUBCOMMAND()` dispatch on top of this separation.
