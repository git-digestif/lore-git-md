Dominik Maier has sent a standalone security patch fixing a command injection vulnerability in the `git-cvsexportcommit.perl` contrib script. In `-W` (working-tree) mode, the script captured the current HEAD branch name via backticks and later passed it to single-argument `system()` calls, which invoke `/bin/sh -c` and therefore interpret shell metacharacters; a branch named something like `topic;false` could execute unintended commands or corrupt HEAD restoration. The patch switches all affected `system()` calls to the list form, chomps the captured newline, and adds `--end-of-options` and `--` guards against option injection, along with a regression test in `t/t9200-git-cvsexportcommit.sh` using a branch literally named `topic;false`. The change touches only the contrib script and its test, and as of this first email it is under review with no maintainer decision or integration status yet.
