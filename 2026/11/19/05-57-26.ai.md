This is a bugfix refining the user-facing message that `git status` and `git checkout` print when a local branch tracks a remote branch that does not exist. The patch changes the wording from "the upstream is gone" to "which does not exist" so the message is correct both when the upstream was deleted and when it was never created (as happens when cloning an empty repository), and replaces the unconditional "git branch --unset-upstream" advice with conditional guidance: it suggests `git push` only when a plain push would actually create the missing upstream, otherwise it suggests `git branch --unset-upstream`. The short-format `[gone]` indicator in `git status -sb`, `git branch -vv`, and `%(upstream:track)` of `git for-each-ref` is intentionally left unchanged to avoid breaking scripts that grep for it.

The implementation lives in `remote.c`, introducing a `push_creates()` helper that determines whether `@{push}` resolves to the tracked upstream (thereby ruling out `push.default=nothing`, narrow push refspecs, mirror remotes pushing to a different name, and `pushRemote` configurations) and accounting for the `push.default=matching` edge case unless explicit push refspecs or mirroring override it, plus a `format_missing_upstream()` function called from `format_tracking_info()`. This v3 moves the `push_creates()` call inside `format_missing_upstream()` so the computation is skipped when `advice.statusHints` is disabled, expands the comment above `push_creates()` to explain the `@{push}`-based logic, and adds roughly 150 lines to `t/t6040-tracking-info.sh` covering empty clones, deleted upstreams, all `push.default` values, explicit `remote.<name>.push` refspecs (including narrow ones excluding the current branch and mirror remotes pushing to another name), `branch.<name>.pushRemote` pointing to a different remote, and the `advice.statusHints=false` case. The patch is based on commit 47fdf2208c and remains queued in `seen` as `ep/status-missing-upstream`; it is under review with no announced merge to `next` or `master`.
