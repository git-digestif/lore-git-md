This is a preparatory refactoring patch, specifically the fourth of six in Justin Tobler's v2 series moving ODB transaction temporary-directory creation from lazy to eager. The patch modifies `tmp-objdir.c` and `tmp-objdir.h` so that `tmp_objdir_create()` preserves `errno` across its internal cleanup when directory creation fails, allowing callers to reliably determine the cause of failure. It introduces a local `saved_errno` variable, converts the two early-return failure paths (after `mkdtemp` and after `mkdir` of the `pack` subdirectory) to jump to a single `error` label, and restores `errno` from `saved_errno` before returning NULL. The header comment is updated to document that the function now sets `errno` on failure. This change is explicitly framed as groundwork for the subsequent patch (6/6) in the series, which will create the temporary object directory eagerly at transaction start and emit specific error messages based on the preserved `errno`. The patch touches only `tmp-objdir.c` and `tmp-objdir.h` with no behavior change visible to callers beyond the now-guaranteed `errno` value.
