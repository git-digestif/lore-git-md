This is a mechanical refactoring patch, the first of a 13-patch series (v5) by Patrick Steinhardt that modernizes `git rerere`'s subcommand handling. The patch simply renames the internal `repo_rerere()` function to `rerere()` so that every public function in `rerere.h` carries the `rerere_` prefix, and it expands the function's header comment to explain that it records and replays conflict resolutions. All nine call sites across `apply.c`, `builtin/am.c`, `builtin/commit.c`, `builtin/merge.c`, `builtin/rerere.c`, `builtin/stash.c`, and `sequencer.c` are updated mechanically. There is no behavior change; this is pure cleanup that precedes the larger `OPT_SUBCOMMAND()` restructuring later in the series.
