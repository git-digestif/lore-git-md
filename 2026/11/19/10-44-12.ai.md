This is a surface-level review reply from Phillip Wood to Junio C Hamano's documentation patch that removes the prohibition on using the `!!` operator from `Documentation/CodingGuidelines`.

Phillip Wood confirms that the use of `!!` to normalize values to 0/1 booleans has indeed come up in recent review threads and thanks Junio for putting together the patch. The reply contains no technical critique, no alternative suggestions, and no requests for changes -- it is a brief acknowledgment that the proposed deletion is welcome.

The underlying patch deletes four lines from the "For C programs" section of `Documentation/CodingGuidelines` (around line 522) that warned against "clever tricks, like using the `!!` operator with arithmetic constructs" as confusing to others. The commit message argues that `!!value` is a standard boolean normalization technique rather than an exotic trick, and notes that while the idea to remove this rule was floated in a previous review discussion, it was not acted upon until now. Only the documentation file is touched; no code changes are involved.

The thread remains open with no objections recorded. The patch is under review on the mailing list and has not been stated to be in any integration branch.
