This is a small refactoring patch, the first of six in Justin Tobler's v2 series on ODB transaction temporary directories. It renames the default prefix used for the temporary object directory from `"bulk-fsync"` to `"transaction"` in `object-file.c`. The old name is a leftover from when the directory existed solely to batch fsync operations for loose objects, but transactions have since become a general mechanism for writing objects, making the previous prefix misleading.

The change itself is a one-line edit with a clear commit message explaining the historical context and the reason for the rename. It sits within the broader ODB abstraction effort and prepares the ground for the later patches in the series, which move temporary directory creation from lazy to eager at transaction start. Because the series has not yet landed, this rename is still under review alongside the rest of the v2 respin.

As a standalone patch it is straightforward and low-risk: it touches no behavior, only the name of a temporary directory, and the motivation is well documented. It addresses a naming inconsistency that would become more confusing once the temporary directory is created for every transaction regardless of fsync configuration.
