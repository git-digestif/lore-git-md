This is a review reply in the `ls-tree` `-z` `--format` bugfix thread. Junio C Hamano responds to Noam Cohen's defense of using a non-ASCII filename in the regression test, agreeing that synthesizing the tree with `git mktree` would make the test noticeably more complicated than a simple `test_commit`. He clarifies that his earlier comment was not a requirement to avoid non-US-ASCII bytes in tests -- tests using such bytes are better than none -- but merely a preference for avoiding potential platform anomalies on systems that cannot store characters outside the US-ASCII range. He notes that forcing `core.quotePath` was the alternative approach he had in mind. The underlying patch -- which makes `show_tree_fmt()` in `builtin/ls-tree.c` emit the raw path when `-z` is set -- remains assessed as trivially correct with no objections raised, and the thread stays in a settled state pending integration.
