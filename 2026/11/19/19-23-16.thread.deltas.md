## 2026/11/19

- [2026/11/19/19-23-16 by Dominik Maier <dmnk@google.com>] Dominik Maier submitted a patch to git-filter-branch that validates each "from:to" line loaded from a --state-branch filter.map: it requires "$from_commit" to be non-empty lowercase hex and "$to_commit" to contain only lowercase hex digits and spaces (allowing an empty "$to_commit" for pruned commits) before writing "../map/$from_commit", so malformed entries with empty keys, slashes, backslashes, or ".." segments die with "Unable to load state from ...:filter.map" instead of writing outside "$tempdir/map"; the patch also adds t/t7003-filter-branch.sh tests for a "../.."-traversal entry and a backslash entry.
