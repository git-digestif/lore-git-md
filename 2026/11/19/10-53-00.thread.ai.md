Thread identity: Single documentation patch (not a series) from Okhuomon Ajayi proposing to codify the line-length and paragraph conventions for emailed contributions. Currently at version 2.

Core problem or goal: Add explicit guidance to three contributor-facing documents stating that emailed text -- including patch commit messages and review replies -- should be wrapped near 70 columns so it remains readable on an 80-column terminal after a few levels of quoting, and that paragraphs (including blocks of quoted text) should be separated by blank lines. This codifies existing informal conventions.
