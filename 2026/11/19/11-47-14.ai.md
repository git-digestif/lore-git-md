This is a documentation patch, specifically the thirteenth and final patch of Patrick Steinhardt's v5 series "Modernize git-rerere's subcommand handling". It touches only `Documentation/git-rerere.adoc` and removes the stale claim that `git rerere diff` passes additional arguments to the system `diff` command. The commit message traces this discrepancy to 658f3650273 ("Make git-rerere a builtin", 2006-12-20), which inadvertently dropped that argument-forwarding behavior when rerere was converted from a shell script to a C builtin; the documentation was never updated to match. The patch notes that since nobody has complained in roughly two decades, the documentation is being aligned with the actual long-standing behavior rather than restoring the old feature. It carries a Suggested-by trailer from Junio C Hamano and makes no code changes. For future thread context: this closes out the documentation cleanup portion of the series, complementing patch 12/13 which updated the man page synopsis to list subcommands individually.
