Thread identity: standalone security patch submitted by Dominik Maier <dmnk@google.com> to fix a command injection vulnerability in the `git-cvsexportcommit.perl` contrib script; no series version or cover letter, currently under review.

Core problem or goal: when the `-W` (working-tree) option is used, the script captures HEAD via backticks into `$go_back_to` and later restores it using single-argument `system("git checkout $go_back_to")` and `system("git symbolic-ref HEAD $go_back_to")`, which invokes `/bin/sh -c` and allows shell metacharacters in branch names (e.g. `refs/heads/topic;false`) to execute unintended commands or corrupt the HEAD restoration.

Current status: standalone submission under review; no prior versions or integration branch status mentioned.

Key technical details: modifies `contrib/git-cvsexportcommit.perl` and `t/t9200-git-cvsexportcommit.sh`; converts all affected `system()` calls to list form `system('git', 'checkout', ...)` to bypass shell interpretation, adds `chomp $go_back_to` to strip the trailing newline from the backtick capture, hardens the final checkout with `--end-of-options` and `--` to prevent option injection from dash-prefixed branch names, and applies the same list-form conversion to intermediate `git checkout -q "$parent^0"` and `git checkout -q "$commit^0"` calls; regression test creates a branch literally named `topic;false`, runs `git cvsexportcommit -W -p -u -c HEAD`, and asserts HEAD remains `refs/heads/topic;false`.
