Dominik Maier has sent a security hardening patch addressing out-of-bounds reads and memory corruption when Git loads malformed `.bitmap` files. The fix targets `ewah_read_mmap()` in `ewah/ewah_io.c`, which previously trusted serialized header fields -- buffer size, RLW offset, and literal word counts -- without checking them against the actual mmap length. This allowed corrupt bitmaps to trigger memory leaks, oversized reallocations, and out-of-bounds heap reads in `ewah_each_bit()`, `rlwit_init()`, `next_word()`, and `rlwit_discharge()`.
