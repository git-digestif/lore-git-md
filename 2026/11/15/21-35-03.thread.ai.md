Thread identity: bugfix for ANSI color handling in `git log --format=...` output, affecting the `pretty` subsystem. Single-patch series, currently at version `v3`, originating author Andy Koppe.

Core problem or goal: fix two related bugs in custom log formats where ANSI color escape sequences are lost across line breaks (e.g., bold-wrapped subject lines only bold on first line) or leak into subsequent content (e.g., graph markers or unrelated lines). The goal is to make each line self-contained by tracking active colors and replaying them after line breaks, while avoiding buffer copies. The runtime approach is justified by the API gap (no per-line color control in `%w` or `%b`).

Current status: patch `v3` posted; under review. No merge status reported.
