The v9 patches introduce four new keys to `git repo info`:
- `path.workingtree.absolute` / `path.workingtree.relative`: The root of the working tree (empty in bare repositories).
- `path.superprojectworkingtree.absolute` / `path.superprojectworkingtree.relative`: The superproject’s working tree when inside a submodule (empty otherwise).
- `path.index.absolute` / `path.index.relative`: The active index file path (returns paths even if the file doesn’t exist or the repository is bare).
- `path.prefix`: The relative path from the working tree root to the current directory (e.g., `sub/dir/`), including a trailing slash.

Key changes since v8:
- **Dropped controversial keys**: `path.hooks` and `path.cdup` are removed, resolving Phillip Wood’s final objections.
- **Naming convention enforced**: All keys now use underscores (`_`) instead of hyphens (`-`), aligning with Git’s configuration variable conventions.
- **Test efficiency**: Tests no longer initialize a new repository for each case, addressing a low-weight suggestion from Phillip Wood.
