This thread is about a small but meaningful improvement to Git’s test suite. Hardik Kumar submitted a patch replacing seven instances of the `!` operator with the more robust `test_must_fail` helper in four test scripts (`t5564-http-proxy.sh`, `t6030-bisect-porcelain.sh`, `t7400-submodule-basic.sh`, and `t9001-send-email.sh`). The change is purely mechanical but important: it ensures that unexpected crashes or signals in Git commands are properly caught as test failures, rather than being mistakenly treated as passes.

Junio C Hamano reviewed and approved the patch, noting it aligns with the project’s goals for test robustness. The patch has been queued in the `seen` branch for integration, and no further changes are expected. While this patch addresses only the simplest cases of `! git`, Junio and Hardik both acknowledged that other instances—particularly those involving pipes—will require more complex fixes in future patches. This is part of the broader community effort to modernize Git’s test suite by adopting more reliable test helpers. The thread is now effectively closed.
