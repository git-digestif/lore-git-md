Subject: test modernization: replace `!` with `test_must_fail` in four test scripts
Series version: standalone patch (no series)
Originating author: Hardik Kumar
Thread type: patch (test modernization)

Core problem or goal
Replace the `!` (NOT) operator with the `test_must_fail` helper in seven instances across four test scripts (`t5564-http-proxy.sh`, `t6030-bisect-porcelain.sh`, `t7400-submodule-basic.sh`, `t9001-send-email.sh`). The change is purely mechanical and improves test robustness by ensuring that unexpected crashes or signals are not mistakenly treated as test passes.

Under review; no prior versions or review feedback recorded.

Key technical details
- Files touched: `t/t5564-http-proxy.sh`, `t/t6030-bisect-porcelain.sh`, `t/t7400-submodule-basic.sh`, `t/t9001-send-email.sh`
- Subsystems: HTTP proxy, bisect porcelain, submodule basics, `git send-email`
- New/renamed symbols: none (only the test helper `test_must_fail` is referenced)
- Old behavior: `! git <command>` would pass if the command died unexpectedly
- New behavior: `test_must_fail git <command>` explicitly checks for expected failure and fails the test if the command crashes or is killed by a signal
- On-disk format: unchanged
- Test coverage: improved robustness of seven existing test cases
