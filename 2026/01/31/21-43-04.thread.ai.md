Key technical details:
- Files touched: `builtin/submodule--helper.c`, `git-submodule.sh`, `t/t7427-submodule-foreach-reversive.sh` (to be renumbered `t7428` in v3), `Documentation/git-submodule.txt`, `contrib/completion/git-completion.bash`.
- New flags:
  - `--reverse-traversal`: post-order processing (children before parents). Hatfield clarifies the semantic: unlike a tree-walk order (which would imply pre/in/post variants), this literally reverses the existing traversal order, siblings included, and behaves the same whether or not `--recursive` is given; the options no longer require `--recursive` (a change from v1).
  - `--include-superproject`: execute command in superproject after submodules; preserves environment context, sets `$displaypath`, and runs only if all submodule commands succeed.
  - `--reversive`: shorthand combining `--recursive`, `--reverse-traversal`, and `--include-superproject`.
- Test coverage: detached worktrees, alternate indexes, partially initialized submodules, dynamic submodule checkout during traversal, nested foreach calls, failure handling (superproject command skipped on submodule failure), environment variable propagation, and verification that `--reversive` produces identical output to the three long options.
- Documentation uses backticks for option names and follows synopsis conventions.
