This thread is about enabling Rust compilation in Git’s GitHub Actions Windows CI workflows, a small but essential build-system adjustment that unblocks the broader Rustification effort in Git. Johannes Schindelin authored the series, which was fast-tracked to `master` after four revisions. The final version configures the Rust toolchain to target the GCC ABI (used by Git for Windows) instead of the default MSVC ABI, ensuring Cargo produces a static library compatible with MinGW’s linker. The series also removes the `NO_RUST` opt-out in CI and adds a step to install the precompiled Rust standard library via `rustup`.

Junio C Hamano and James Le Cuirot provided substantive reviews, focusing on technical details like Cargo’s expected behavior and variable naming consistency. All feedback was addressed in the final version. The last open question—whether Rust is preinstalled on GitLab’s Windows runners—has now been definitively answered: it is not, and Johannes is handling this in a separate thread by installing Rust via `rustup`. This follow-up from Junio simply closes the loop on that loose end, confirming the issue is resolved and no further changes are needed to the original CI configuration.
