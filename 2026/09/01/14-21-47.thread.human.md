This thread is about enabling Rust compilation in Git’s GitHub Actions Windows CI workflows. Johannes Schindelin sent a two-patch series (v1) to configure the Rust toolchain to target the GCC ABI used by Git for Windows, ensuring compatibility with MinGW’s linker. The series is a build-system adjustment, touching CI workflow files and the Makefile, and is a prerequisite for Git’s broader Rustification effort.

Junio C Hamano reviewed the first patch and identified a minor inconsistency in how the UCRT64 environment’s Rust target triple was mapped—between the Makefile (which used `-gnu`) and the shell script (which used `-gnullvm`). Johannes has now confirmed that UCRT64 should indeed use `-gnu`, aligning the shell script with the Makefile. This resolves the only open question from the initial review. The series is otherwise uncontroversial and ready for a v2 update, after which it should be suitable for merging. No other objections or design concerns have been raised.
