This thread is a 13-patch series from Patrick Steinhardt refactoring Git’s object database (ODB) subsystem to remove an ad-hoc mechanism for registering in-memory sources, primarily used for submodules and temporary object directories. The goal is to simplify the codebase and eliminate implicit dependencies on global state, preparing for future ODB abstraction work. The series is now in its second version, posted on September 5, 2026, with all patches complete and addressing feedback from the first iteration.

Key changes include removing the `odb_add_to_alternates_memory()` function, eliminating the last non-test caller of the submodule ODB registration API, and enforcing an existing constraint that `git multi-pack-index --object-dir=` only accepts alternate directories. The series also fixes a memory leak in the packed ODB source backend and updates test infrastructure to manage ODB sources explicitly. Junio C Hamano provided substantive approval for two patches in the first version, while Karthik Nayak and Justin Tobler reviewed several patches in the second version, confirming the correctness of the refactoring. The series is uncontroversial, with no outstanding objections or merge intent from Junio yet.
