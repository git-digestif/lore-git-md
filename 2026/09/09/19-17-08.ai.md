This is the fourth patch in Johannes Schindelin’s 12-patch series upstreaming Git for Windows build adjustments. It refines the MinGW linker flags in `config.mak.uname` so that the `-Wl,--large-address-aware` option is applied **only to 32-bit builds** (`MINGW32`). The flag is irrelevant (and sometimes unsupported) in 64-bit environments (`MINGW64` and `CLANGARM64`), so the patch removes it from those cases. The change is a straightforward correctness fix with no behavior impact on non-Windows platforms.

The patch is uncontroversial and ready for integration. It touches only the build system and carries no risk outside MinGW environments. If you are not involved in Windows builds, this patch can be safely ignored.
