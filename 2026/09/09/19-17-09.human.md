This is the fifth patch in Johannes Schindelin’s 12-part series updating MinGW/Windows build and runtime settings. It removes redundant entry-point specifications (`-e,_mainCRTStartup` and `-e,mainCRTStartup`) from the `-Wl,--pic-executable` linker flag in `config.mak.uname`. The commit message explains that these symbols are already the default, so the explicit definitions are unnecessary. The change affects only Windows builds and is uncontroversial: it simplifies the build configuration without altering behavior. If you’re not working on Windows-specific builds, this patch can be safely ignored.
