This is a build system patch series from SZEDER Gábor that speeds up Git builds by about 35% on the author’s setup by precompiling the central `git-compat-util.h` header.

The series is four patches long.  The first two are small cleanups: one drops an unused `XDIFF_OBJS` variable from the Makefile, the other adjusts the CMake build so it no longer stumbles over the `*_OBJS` variables when parsing the Makefile for source files.  Patch 3 restores the `REFTABLE_OBJS` variable that had been removed in an earlier refactoring.  The final patch is the meat: it teaches the Makefile to precompile `git-compat-util.h` and then include that precompiled header in every compilation unit, cutting down on redundant parsing of the same large header.

The commit messages are clear and the changes look mechanical and well-scoped.  No new platform issues are introduced, and the CMake build is kept in sync.  If the claimed 35 % speed-up holds across typical developer machines, this is a straightforward win for anyone building Git from source.
