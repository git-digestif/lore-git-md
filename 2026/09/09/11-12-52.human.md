This is part of Patrick Steinhardt’s 13-patch series to standardize Git’s terminology around "ref storage format." Patch 6/13 updates `` `git rev-parse` `` to rename the `--show-ref-format` option to `--show-ref-storage-format`, keeping the old name as a hidden backward-compatible alias. The change touches the command’s documentation, implementation, shell completions, and ten test scripts, all of which now use the new option name.

The patch is a straightforward mechanical rename that aligns with the series’ goal of eliminating inconsistent terminology before introducing an analogous `--object-storage-format` option. The backward-compatible alias ensures scripts and users relying on the old name continue to work without interruption. No functional changes are introduced beyond the rename and aliasing.

This patch is well-crafted and uncontroversial. The test coverage is thorough, and the commit message clearly explains the rationale. If the broader series lands, this change will be a small but necessary part of the cleanup.
