This is the first patch in Johannes Schindelin’s 12-part series updating the MinGW/Windows build and runtime for Git. It removes the `NO_PYTHON` setting in `config.mak.uname` for the MINGW platform, allowing users to build Git with Python support when using Git for Windows’ SDK environment. The change is motivated by MSYS2’s provision of Python interpreters, which users can leverage without Git for Windows needing to ship Python itself. The patch is a one-line change with no impact on non-Windows platforms and no new symbols or behavior changes. It is uncontroversial and ready for integration. If you care about Windows build flexibility or Python integration, this is a small but useful step forward. Otherwise, it can be safely ignored.
