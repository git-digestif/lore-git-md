This is the eleventh and final patch in Patrick Steinhardt’s ref-storage terminology unification series. Kaartic Sivaraam’s review is surface-level: he spots a documentation glitch in `Documentation/ref-storage-format.adoc` where the newly added URI syntax (`files[://<path>]`, `reftable[://<path>]`) is not mirrored in `Documentation/git-refs.adoc`, which also includes the same file. The rest of the patch — URI parsing, immutability enforcement, and test coverage — meets his approval.

The patch itself enables `--ref-storage-format=` to accept URIs like `files://path/to/alt-refs` or `reftable://path/to/db`, storing the payload in the repository config and using it to locate the ref storage directory. It completes the series’ functional scope and is uncontroversial beyond the documentation oversight.
