This is the third patch in SZEDER Gábor’s four-patch series introducing precompiled headers for `git-compat-util.h` to speed up Git builds. The patch resurrects the `REFTABLE_OBJS` Makefile variable—without reinstating the static library—to isolate the reftable object files so they can be excluded from precompiled-header processing in the next patch.

The motivation is technical: the reftable implementation is designed to be embeddable in other projects, so its source files (except `reftable/system.c`) deliberately avoid including `git-compat-util.h`. Precompiling that header for them would therefore be incorrect. By listing the reftable objects in a dedicated variable, the next patch can easily filter them out and compile them the traditional way.

The change is mechanical: it moves the reftable object files from `LIB_OBJS` back into `REFTABLE_OBJS` and adds `REFTABLE_OBJS` to `LIB_OBJS` so the final link remains unchanged. The CMake build system is updated to parse `REFTABLE_OBJS` and include those sources in the `libgit` target, mirroring the Makefile logic. No runtime behavior is affected, and the patch is a prerequisite for the precompiled-header rollout.
