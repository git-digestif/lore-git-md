This is a **surface-level review** of the final patch in Patrick Steinhardt’s 11-patch series unifying Git’s ref-storage terminology. Kaartic Sivaraam points out a documentation oversight: the updated `ref-storage-format.adoc` file (which now documents URI payload syntax for the "files" and "reftable" backends) is included by `Documentation/git-refs.adoc` and `Documentation/git-repo.adoc`, but the changes may not be appropriate for both contexts. Specifically, `git-refs.adoc` (the man page for `git refs`) might need explicit support for URI syntax, while `git-repo.adoc` (a conceptual overview) may not require functional documentation. The rest of the patch—URI parsing, immutability enforcement, and test coverage—is uncontroversial and receives a "looks good" from Kaartic. This feedback is minor and unlikely to block the series, but it highlights a small but important documentation consistency issue that should be addressed before merging.
