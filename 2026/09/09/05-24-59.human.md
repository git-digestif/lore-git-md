This is a small documentation housekeeping series from Tuomas Ahola, part of the ongoing effort to keep Git’s manual page build system in sync. The two patches ensure that the `command-list.txt` file—which drives the generation of the `git(1)` command reference—also includes the two recently added concept guides (`gitformat-loose(5)` and `gitpacking(7)`), and that the `lint-manpages.sh` script actively checks for missing guides in the future.

The change is mechanical and uncontroversial: it plugs a gap in the documentation linter so that new guides cannot accidentally be left out of the generated command list. The commit message is clear, the diff is tiny, and the series builds on an earlier topic (`kh/doc-datamodel`) that already landed in `next`. If you care about documentation hygiene, this is a safe, low-risk update that keeps the build system honest.
