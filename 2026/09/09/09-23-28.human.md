This is patch 9/11 in Patrick Steinhardt’s v2 series to unify Git’s terminology for "ref storage format." The patch renames environment variables (`GIT_REFERENCE_BACKEND` → `GIT_REF_STORAGE_FORMAT`, `GIT_DEFAULT_REF_FORMAT` → `GIT_DEFAULT_REF_STORAGE_FORMAT`) while retaining backward-compatible aliases, and adds the missing `GIT_REF_STORAGE_FORMAT_ENVIRONMENT` macro.

Patrick has now acknowledged and agreed to fix the two minor issues Kaartic Sivaraam raised in his review. First, error messages in `setup.c` will be updated to cite the correct environment variable name (old or new) depending on which one supplied the value, avoiding misleading diagnostics. Second, the test helper variable `GIT_TEST_DEFAULT_REF_FORMAT` will be renamed to `GIT_TEST_DEFAULT_REF_STORAGE_FORMAT` for consistency with the rest of the series. Neither issue affects functionality, but both improve clarity and reduce potential confusion for users and test authors. The rest of the patch remains uncontroversial and aligns with the series’ goal of preparing for the upcoming `--object-storage-format=` extension.
