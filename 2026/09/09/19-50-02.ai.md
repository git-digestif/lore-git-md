This is a **build system** patch series (4 patches) from SZEDER Gábor that introduces precompiled headers to the Git build process, targeting the `git-compat-util.h` header. The goal is to speed up builds by roughly 35% on the author’s setup.

The series starts with two cleanup patches: one removes an unused `XDIFF_OBJS` initialization in the Makefile, and another adjusts the CMake build system to avoid misinterpreting `*_OBJS` variables when parsing the Makefile for sources. The third patch reintroduces `REFTABLE_OBJS` (likely a regression fix from earlier refactoring). The core change is the fourth patch, which adds precompilation support for `git-compat-util.h`, a frequently included header that underpins much of Git’s low-level infrastructure.

The commit messages are concise but clear, and the changes touch only the build system (`Makefile` and `CMakeLists.txt`), with no impact on runtime behavior. The 35% speedup claim is plausible given that `git-compat-util.h` is included by nearly every source file, but the series does not include benchmark details beyond the author’s anecdotal measurement. The patches are mechanical and unlikely to be controversial, though the CMake adjustments might draw attention from Windows or cross-platform builders.

Key files modified: `Makefile`, `contrib/buildsystems/CMakeLists.txt`, and `.gitignore` (to exclude the precompiled header artifact). The series is self-contained and not part of a larger ongoing effort.
