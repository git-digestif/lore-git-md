This is the eleventh patch in Patrick Steinhardt’s v3 series unifying Git’s terminology for "ref storage format." It’s a test-only patch that mechanically renames the environment variable `GIT_TEST_DEFAULT_REF_FORMAT` to `GIT_TEST_DEFAULT_REF_STORAGE_FORMAT` across the test suite and CI scripts.

The change is straightforward: twelve files in `t/` and `ci/` are updated to use the new variable name, and the old name is dropped entirely (no backward-compatible alias is retained, since this is test-only). The patch also updates the `test_detect_ref_format()` helper in `test-lib-functions.sh` to reflect the new variable. No functional changes are introduced; the patch is purely a rename to align with the rest of the series. The diff is clean and the motivation is clear: consistency with the new `--ref-storage-format=` CLI option and related configuration keys.
