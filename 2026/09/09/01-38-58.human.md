This is the third iteration of Mike Hommey’s patch to reorganize Git’s experimental Rust code into a dedicated `rust/` subdirectory. The patch moves all Rust-related files (Cargo.toml, build scripts, and source files) from `src/` to `rust/`, updates both the Makefile and meson.build to reflect the new paths, and adjusts .gitignore to track Rust build artifacts in their new location.

The motivation remains twofold: first, a top-level Cargo.toml misleadingly suggests that running `cargo build` directly would produce something useful (it doesn’t), and second, embedding Git as a submodule in a Rust project causes Cargo to skip the entire directory, breaking downstream tools like git-cinnabar. The patch addresses the first concern and sets the stage for future work on the second, though it does not itself resolve the git-cinnabar build issue.

The changes are mechanical and thorough: every reference to `src/` in the build system is updated to `rust/`, and the Rust sources are relocated without modification. The patch is clean, well-explained, and carries Mike’s sign-off. Given that earlier technical objections about mrustc compatibility have been resolved, the remaining question is whether the community will accept the reorganization on project-hygiene grounds. This version looks ready for integration if no new objections surface.
