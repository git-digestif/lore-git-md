This is the fourth patch in Patrick Steinhardt’s 13-patch v3 series unifying Git’s terminology around "ref storage format." It updates the `git refs migrate` command to rename the `--ref-format=` option to `--ref-storage-format=`, retaining the old name as a hidden backward-compatible alias via the new `OPT_ALIAS_F()` infrastructure introduced in patch 1/13. The change touches the command’s usage string, help text, error messages, and all test invocations, ensuring consistency with the rest of the series.

The patch is mechanical: it replaces every occurrence of `--ref-format=` in `builtin/refs.c`, `Documentation/git-refs.adoc`, and the test suite (`t/t1423-ref-backend.sh`, `t/t1460-refs-migrate.sh`, `t/t7424-submodule-mixed-ref-formats.sh`) with `--ref-storage-format=`, and adds the old name as an alias using `OPT_ALIAS_F(0, "ref-format", "ref-storage-format", PARSE_OPT_HIDDEN)`. The `PARSE_OPT_NONEG` flag is retained for consistency with the command’s existing behavior, though this remains an unresolved inconsistency with other commands in the series (e.g., `git init` and `git clone` do not use this flag). The help text in `Documentation/git-refs.adoc` now marks `--ref-format=` as a deprecated alias, matching the pattern established in earlier patches.

The `builtin/fetch.c` change updates an error message to use the new option name, ensuring users see consistent terminology when Git suggests migrating to the reftable backend. Test scripts are updated to use the new option name, with no changes to test logic or coverage. The patch does not introduce new functionality or edge cases; it is purely a refactoring to align terminology and leverage the `OPT_ALIAS_F()` infrastructure added earlier in the series.

This patch is uncontroversial and addresses all prior feedback on the `git refs migrate` command. The only remaining loose end is the `PARSE_OPT_NONEG` flag inconsistency, which Patrick has declined to resolve in this series. The patch is ready for integration once the series as a whole lands. Key files modified: `builtin/refs.c`, `Documentation/git-refs.adoc`, `builtin/fetch.c`, and three test scripts.
