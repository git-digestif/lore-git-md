This is the third iteration of Mike Hommey's patch to relocate Git's experimental Rust code from `src/` to a dedicated `rust/` subdirectory, part of the ongoing Rust infrastructure reorganization effort. The patch is now concrete implementation rather than RFC discussion, reflecting the resolution of earlier technical constraints around mrustc compatibility.

The patch moves all Rust-related files (Cargo.toml, build scripts, and source files) into `rust/` and updates both the Makefile and meson.build to reference the new locations. The changes are mechanical but thorough: `.gitignore` is updated for Rust build artifacts, Makefile paths are adjusted for both single-target and multi-target builds, and meson.build now points to the new subdirectory. The patch also fixes a duplicate entry in `RUST_SOURCES` that was introduced in this version.

This iteration appears well-crafted and directly addresses the project hygiene concerns raised in earlier discussion: the top-level Cargo.toml was misleading because it didn't produce useful standalone builds, and the mixed-language structure could confuse contributors. The patch leaves the separate git-cinnabar build issues for future work, focusing cleanly on directory reorganization. The build system changes are complete and appear to maintain all existing functionality while establishing a clearer project structure for future Rust development.
