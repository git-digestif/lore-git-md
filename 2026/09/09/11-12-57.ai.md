This is the 11th patch in Patrick Steinhardt’s v3 series unifying Git’s terminology for "ref storage format." It is a test-only change that mechanically renames the environment variable `GIT_TEST_DEFAULT_REF_FORMAT` to `GIT_TEST_DEFAULT_REF_STORAGE_FORMAT` across the test suite and CI scripts.

The patch updates 12 files: 10 test scripts (all reftable- or reffiles-specific), `t/README`, `t/test-lib-functions.sh`, `t/test-lib.sh`, and `ci/run-build-and-tests.sh`. Unlike the user-facing environment variables in earlier patches, the old test-only name is *not* retained as a backward-compatible alias—this is intentional, as the variable is only used in test contexts. The change is purely mechanical: every occurrence of `GIT_TEST_DEFAULT_REF_FORMAT` is replaced with `GIT_TEST_DEFAULT_REF_STORAGE_FORMAT`, and the default value in `t/test-lib.sh` is updated to match.

The patch is uncontroversial and aligns with the series’ goal of consistent naming. It touches no production code, so there are no functional risks. The only potential follow-up would be if any out-of-tree test scripts or CI jobs rely on the old variable name, but the commit message explicitly states that backward compatibility is not needed here.
