This is the **final patch (4/4)** in SZEDER Gábor’s **build system** series introducing precompiled headers to the Git Makefile, targeting `git-compat-util.h` for a ~35% build speedup. The patch is purely a build-time optimization with no runtime behavior changes.

The implementation wires up precompiled headers in the Makefile by:
- Adding a new rule to generate `tools/precompiled.h.gch` (the precompiled header) from `git-compat-util.h`, mirroring the existing Meson support (671df48df8).
- Defining `PRECOMPILED_HEADER_USERS` to include all object files except those in `COMPAT_OBJS`, `REFTABLE_OBJS`, and `THIRD_PARTY_SOURCES` (which avoid `git-compat-util.h` for embeddability or compatibility reasons).
- Introducing a new build rule for `PRECOMPILED_HEADER_USERS` that uses `-include tools/precompiled.h` and `-Winvalid-pch` to enforce correctness.
- Adding a `NO_PRECOMPILED_HEADER` knob to disable the feature for testing or unsupported compilers.

Key technical details:
- The precompiled header is built **once** per build (unlike Meson, which redundantly rebuilds it for each target group).
- Dependencies are tracked via computed header dependencies (when enabled) or a fallback to `LIB_H`/`GENERATED_H`.
- The `.gch` suffix is hardcoded for GCC/Clang compatibility; future compilers might require a configurable knob.
- The patch avoids `EXTRA_CPPFLAGS` in the precompiled header rule to prevent `make` quirks with target-specific variables (a lesson from a2673cfede6).

The commit message includes a benchmark showing a **1.35x speedup** (29.4s → 21.7s) with `-j12`, though this is anecdotal (no CI validation). The implementation is careful to exclude files that don’t include `git-compat-util.h`, noting that finer-grained filtering would yield only a 1% improvement (0.2s).

**Files touched**: `Makefile` (core logic), `.gitignore` (exclude `.gch` artifact). The patch is self-contained and unlikely to be controversial, though the CMake adjustments in earlier patches (2/4 and 3/4) may draw scrutiny from Windows builders. The series is **not** part of a larger effort (e.g., ODB abstraction or Rustification).
