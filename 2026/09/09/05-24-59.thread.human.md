This thread is a small but important housekeeping patch series from Tuomas Ahola, now in its third iteration, that ensures the `command-list.txt` file stays in sync with Git’s non-command manual pages—concept guides like `gitformat-loose(5)` and `gitpacking(7)`. The series adds two missing entries to the file and extends the `lint-manpages.sh` script to catch future omissions automatically, with an explicit exemption for the now-obsolete `gittutorial-2(7)`. Junio Hamano’s feedback on earlier versions was purely mechanical (quoting fixes and commit message tweaks), and the series is otherwise uncontroversial and ready for acceptance.

The only open question comes from Julia Evans, who in a substantive review of the second patch flags a design inconsistency: the script now sources variables from two different Makefiles (`../Makefile` for command-related variables and `Documentation/Makefile` for the new `MAN_GUIDES`), which could create confusion or maintenance headaches down the line. She suggests consolidating all variable extraction to `Documentation/Makefile` for clarity. The suggestion is constructive and aligns with Git’s preference for clean, maintainable build infrastructure, but Tuomas hasn’t yet responded, so a fourth version may be needed to address it. The rest of the series—adding the missing entries and exempting the obsolete tutorial—remains unchanged and uncontested.
