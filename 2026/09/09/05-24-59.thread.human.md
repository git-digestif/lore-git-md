This thread is a small but useful housekeeping patch series from Tuomas Ahola, part of the broader `kh/doc-datamodel` effort to improve Git’s documentation infrastructure. The goal is to keep the `command-list.txt` file in sync with non-command manual pages—specifically, concept guides and interface manuals like `gitformat-loose(5)` and `gitpacking(7)`. The series consists of two patches: the first adds the missing entries to `command-list.txt`, and the second updates the `lint-manpages.sh` script to catch future omissions automatically.

The changes are mechanical and confined to the `Documentation/` directory, with no runtime or on-disk format changes. The linter now fails if `command-list.txt` is incomplete, acting as a regression test. The only intentional omission is `gitweb.conf(5)`, excluded to avoid a confusing display name in `git help -a`. The series is under review but has no recorded objections or requests for changes, and the rationale for the exclusion is well-documented.
