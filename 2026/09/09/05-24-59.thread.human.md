This thread is a small but useful housekeeping series from Tuomas Ahola to keep Git’s `command-list.txt` in sync with its non-command manual pages—things like `gitformat-loose(5)` and `gitpacking(7)`. The goal is to add two missing entries and extend the `lint-manpages.sh` script so future omissions are caught automatically. The series is now at v3, incorporating Junio’s feedback on quoting and exempting the obsoleted `gittutorial-2(7)` manual page.

The changes are purely mechanical: one patch adds the missing entries to `command-list.txt`, and the other updates the linter to verify completeness, using a new `MAN_GUIDES` variable derived from the Makefile. There’s no runtime impact—this is about preventing future documentation drift. The only exclusions are `gitweb.conf(5)` (to avoid a confusing display name in `git help -a`) and the now-removed `gittutorial-2(7)`. Junio’s review was surface-level but positive, and the series is ready for acceptance with no open questions. It’s a quiet but solid improvement to Git’s documentation infrastructure.
