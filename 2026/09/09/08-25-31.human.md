This patch disables auto maintenance in commands spawned by the sequencer—such as `git commit`, `git merge`, and exec commands—by passing `maintenance.auto=false` via `GIT_CONFIG_PARAMETERS`. This ensures auto maintenance runs exactly once at sequence completion, preventing interference with intermediate steps (e.g., `rerere gc` holding `MERGE_RR.lock` or repacks deleting active packs). The implementation is clean: it introduces a helper function (`disable_auto_maintenance()`) to build and cache the config string in `replay_ctx`, and the environment variable is appended *after* the user's own settings to ensure it takes precedence.
