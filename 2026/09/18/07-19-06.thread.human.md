This thread is about a small but important bugfix for `git diff --no-index -R`. The issue was that when comparing a file against a directory (or vice versa) with the `-R` (reverse) flag, Git incorrectly reported the changes as deletions or additions instead of reversing them properly. Haokai Ding identified the problem and submitted a minimal two-line fix in `diff-no-index.c`, along with regression tests to verify both directions of the conflict.

The patch has been well-reviewed by René Scharfe and Jacob Keller, both of whom confirmed the fix and test design. Junio C Hamano has now picked it up for integration, signaling that it’s ready to be queued in his `next` branch. There are no open questions or objections, and the fix is self-contained with no dependencies or follow-up work needed. The thread is effectively closed, and the patch should graduate to `master` in the near future if no issues arise during integration testing.
