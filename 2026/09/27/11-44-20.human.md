This is the final patch in the v7 series adding path-related keys to `git repo info`. It introduces `path.cdup`, which returns the relative path from the current working directory to the repository’s top-level working tree (e.g., `../../` in a subdirectory, empty string at the root). The implementation now correctly handles the edge case where the current directory is outside the working tree by returning the absolute path to the working tree root, matching `git rev-parse --show-cdup` behavior.

The patch is straightforward: it adds a new `get_path_cdup()` helper in `builtin/repo.c`, wires it into the `repo_info_field` table, documents the key in `git-repo.adoc`, and includes thorough tests in `t/t1900-repo-info.sh`. The tests cover the root directory, subdirectories, and the outside-working-tree scenario (including when `GIT_WORK_TREE` is set). The implementation is clean and aligns with the rest of the series, which has already resolved all high-weight correctness issues from earlier rounds.

This patch directly addresses Junio’s design objection from v4 by providing symmetry with `path.git-prefix` and strict compatibility with `git rev-parse --show-cdup`. The edge-case fix in v7 ensures the behavior is consistent even when the current directory is outside the working tree, which was a substantive concern in earlier reviews. The patch is uncontroversial and ready for merging alongside the rest of the series.
