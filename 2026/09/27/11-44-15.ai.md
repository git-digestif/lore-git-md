This is the third patch in the v7 series adding new path-related keys to `` `git repo info` ``. It introduces ``path.superproject-root.absolute`` and ``path.superproject-root.relative``, which expose the working-tree root of the superproject when the current repository is a submodule. The implementation relies on the fixed ``get_superproject_working_tree()`` helper (patched in 2/8) and uses the standard ``format_path()`` machinery to produce canonical absolute or relative paths. Tests cover both the submodule case (with ``--git-dir`` and relative-path expectations) and the non-submodule case (empty-string output). The patch is clean, well-tested, and directly addresses the correctness bug that Junio identified in v6. No new issues are introduced; this is ready for substantive review.
