The `git name-rev` man page still refers to "SHA-1" and "40-character hexes" even though the command itself has been hash-algorithm-agnostic since 2023. Jyotish Kumar identified this discrepancy and has now posted a patch to update the documentation to use generic "object ID" terminology instead. The change is small—just two lines in the man page—and aligns with the project's broader effort to remove hard-coded SHA-1 references. brian m. carlson previously confirmed this is a straightforward documentation fix, so the patch is uncontroversial and likely to be merged quickly unless minor wording tweaks are requested. No functional changes or test updates are needed.
