Core problem or goal
Clarify the documentation of `git remote` commands to prevent the common misconception that they modify the remote repository. The current man page wording for individual commands (e.g., `set-head`, `prune`) has been misread as implying remote-side changes, which Git does not support.

Current status
Under review. No prior versions. The discussion has expanded from a targeted fix for `set-head` to a broader proposal: adding a general statement at the top of the `git-remote` man page that *all* `git remote` commands operate locally. No revised patch has been posted yet.
