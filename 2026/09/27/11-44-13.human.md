This is the first patch in the v7 series adding new path-related keys to `` `git repo info` ``. It introduces ``path.toplevel.absolute`` and ``path.toplevel.relative``, which expose the top-level working tree directory in absolute and relative (to the current working directory) formats. In bare repositories, both keys return an empty string.

The implementation is straightforward: ``get_path_toplevel_absolute`` uses ``repo_get_work_tree`` and ``format_path`` with ``PATH_FORMAT_CANONICAL``, while ``get_path_toplevel_relative`` uses the same functions with ``PATH_FORMAT_RELATIVE`` and the repository’s prefix. The tests cover both subdirectory execution (confirming the expected ``../`` relative path) and bare-repository edge cases, and the documentation is clear and concise.
