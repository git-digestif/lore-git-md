This is a localization (l10n) pull request for Git 2.56.0. Jiang Xin, the coordinator for Git's translation efforts, submits a batch of updates to the project's `.po` files, which contain translated strings for Git's user interface.

The update adds two new languages: Afrikaans (af) and Brazilian Portuguese (pt_BR). It also refreshes translations for Catalan, French, Irish, Indonesian, Swedish, Turkish, Ukrainian, and Simplified Chinese. The pull request restores two translations that were temporarily lost when Git reverted a previous merge (en/no-amend-during-conflicts). Additionally, the `po/AGENTS.md` file, which documents the localization workflow, receives several improvements, including better handling of PO entry counting and zsh compatibility fixes.

The changes are substantial: over 61,000 lines added and nearly 3,000 deleted, with new files created for the two new languages. The pull request is signed and tagged as `l10n-2.56.0-v1`, targeting the upcoming Git 2.56.0 release. This is a routine but important contribution, ensuring Git remains accessible to non-English speakers. No technical issues or controversies are apparent; the update looks like a straightforward integration of community-contributed translations.
