This is the sixth patch in the v7 series adding path-related keys to `git repo info`. It introduces `path.grafts.absolute` and `path.grafts.relative`, exposing the location of the repository’s grafts file in a scriptable format. The implementation uses `repo_get_graft_file(repo)` and respects the `GIT_GRAFT_FILE` environment variable, returning the configured path regardless of whether the file exists or the repository is bare. This aligns with the behavior of `git rev-parse --git-path info/grafts` and the precedent set by earlier patches in the series (`path.index` and `path.hooks`).
