This is a documentation patch targeting the `git(1)` man page. Julia Evans proposes a rewrite of the introductory section to better orient users toward Git’s help system. The patch removes references to the outdated `gittutorial` and `giteveryday` documents and replaces them with concrete, actionable instructions: `git push -h` for short help, `git push --help` for full documentation, and `git help --guides` / `git help --user-interfaces` to surface the concept guides. The change is motivated by user feedback that the current text is aspirational rather than practical, and by a desire to make the guides more discoverable. Kristoffer Haugsbakk is cc’d as the most recent editor of this section. The patch touches only `Documentation/git.adoc` and is a single commit.
