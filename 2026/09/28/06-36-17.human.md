This is a CI/build system patch that has reached consensus on its core fix. Patrick Steinhardt, the reviewer, confirms that replacing `test_cmp` with `test_cmp_bin` in `t/t4205-log-pretty-formats.sh` is the right approach after seeing Tamir Duberstein’s benchmark data: `cmp` uses only 1.2 MiB of memory and finishes in 0.5 seconds, compared to `diff -u`’s 4 GiB peak and 5-second runtime. The OOM kills that motivated the patch occurred in private GitHub repositories where runners have half the memory of public ones.

The only remaining question was whether to keep the `rm expect actual` line that deletes the temporary files after comparison. Patrick concludes it buys little because the files are rewritten in subsequent tests, so the deletion can be dropped without harm. Tamir is now expected to send a v2 that keeps the `test_cmp_bin` change, omits the deletion, and adds the benchmark data to the commit message. Once that lands, this patch will be ready for integration.
