This is the sixth patch in Patrick Steinhardt’s seven-patch v2 series refactoring the `create_repository()` interface to enforce statelessness. The patch overhauls `repo_clear()` to fully reset the repository by zeroing the entire struct with `memset`, replacing all `FREE_AND_NULL()` calls with plain `free()` to avoid redundant zeroing. The change is purely mechanical—no behavior change, just stricter cleanup—and moves the `repo_clear()` declaration next to `repo_init()` in `repository.h` for better grouping.

The patch is a prerequisite for patch 7/7, which will call `repo_clear()` at the start of `create_repository()` to enforce that the input repository is stateless. The commit message now explicitly explains the rationale for dropping `FREE_AND_NULL()` (avoiding double-zeroing), addressing a minor documentation nit from v1. The change is uncontroversial and aligns with the series’ goal of simplifying repository initialization. No review feedback has surfaced concerns about this patch.
