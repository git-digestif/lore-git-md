# Thread deltas

## 2026/09/28

- [2026/09/28/20-32-54 by Julia Evans via GitGitGadget <gitgitgadget@gmail.com>] Julia Evans submitted a patch to `man git` explaining that `git push -h` gives short help and `git push --help` gives full documentation, removing references to gittutorial and giteveryday, and instead mentioning `git help`, `git help --guides`, and `git help --user-interfaces`.
- [2026/09/28/21-02-24 by Ben Knoble <ben.knoble@gmail.com>] Ben Knoble appreciated the concision but argued that `git help cmd` is more useful than `git cmd --help` because the former supports aliases, HTML formats, and various other documents, while noting he did not know how to fit that into the proposal and doubting that mentioning bare `git help` would lead users to discover `git help cmd`.
- [2026/09/28/21-02-24 by Ben Knoble <ben.knoble@gmail.com>] Ben Knoble noted as unrelated that Git lacks easy access to the content in `git --html-path`, mentioning he uses a custom script for it and that even `git help` in web mode cannot open all of it.
