This thread is an announcement for **Git for Windows 2.56.0**, the downstream distribution of Git tailored for Windows users. Johannes Schindelin ("Dscho") released this version, which bundles the upstream Git 2.56.0 release alongside tools like Git LFS 3.8.0, cURL 8.22.0, and OpenSSL 3.5.8. The release drops support for Windows 8.1 (following MSYS2's lead), which changes some internal paths—for example, `/ucrt64/bin/git.exe` replaces `/mingw64/bin/git.exe`, though users are encouraged to use `/cmd/git.exe` for stability if their setups break.

The release includes several Windows-specific fixes: it resolves an installer bug that disabled the "Use external OpenSSH" option in the previous version (2.55.0(5)), enables commits of 4GB+ objects, fixes a stack-smashing bug in parallel checkouts, addresses a vim-related issue that omitted the first line of files, and prevents `git difftool` crashes with Windows-illegal filenames. The email also provides SHA-256 checksums for all downloadable artifacts (installers, portable builds, and MinGit variants). This announcement is primarily relevant to Windows users and packagers; upstream Git developers are unlikely to engage unless cross-platform compatibility issues arise, as the changes are specific to the Git for Windows fork and do not affect upstream Git itself.
