This thread is an RFC from Isabella Caselli, an undergraduate student, proposing to add an `includeIf "hostname:..."` condition to Git’s configuration system. The goal is to let users share dotfiles across machines by conditionally including Git config files based on the machine’s hostname. The proposal extends Git’s existing `includeIf` mechanism, modeled after the `onbranch:` implementation, and is motivated by a GitHub issue (gitgitgadget/git#1665).

So far, the discussion has been constructive. Jeff King (Peff) replied, confirming the feature is reasonable and not already in progress. He addressed the key technical question of hostname normalization—whether the condition should match short names, fully qualified domain names (FQDNs), or both—by pointing to a 2024 patch series by Ignacio Encinas. That series stalled, but the consensus at the time was to document the system-dependency rather than enforce normalization. Peff also suggested adding a `git var GIT_HOSTNAME` command to help users debug hostname resolution, a detail not in the original proposal. No objections have been raised, and the thread is now better framed for further discussion, though the normalization question remains open.

The next steps would be for Isabella to decide whether to proceed with a patch series, incorporating Peff’s feedback on hostname handling and the debugging aid. The files likely to be touched are `config.c`, `t1305-config-include.sh` (tests), and `config.adoc` (documentation). No maintainer decisions or merge status updates have been made yet.
