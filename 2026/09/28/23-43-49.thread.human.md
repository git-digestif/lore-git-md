This thread is an RFC from Isabella Caselli, an undergraduate student, proposing a new `includeIf "hostname:..."` condition for Git's configuration system. The feature would let users automatically include different Git config files based on the machine's hostname, making it easier to share dotfiles across multiple systems. Isabella frames this as a natural extension of Git's existing `includeIf` mechanism, citing a GitHub issue where the feature was requested and noting that a related but separate 2022 proposal for an OS-based condition stalled.

The proposal is well-scoped, with Isabella planning to model the implementation after the existing `onbranch:` condition, touching `config.c`, the test suite, and documentation. The main open question is hostname normalization—whether Git should use the short hostname, fully qualified domain name, or something else—which could spark discussion. So far, there are no objections or indications that anyone else is working on this, but the thread is just starting, so feedback from maintainers and other contributors is still pending. The feature itself seems uncontroversial and aligns with Git's existing config flexibility.
