This is the first patch in a three-part documentation cleanup series. It removes the bulk of `gittutorial-2.adoc`, an obsolete tutorial document that has not been substantially updated in 20 years. The patch leaves behind a six-line stub that redirects readers to `gitdatamodel[7]` and `gitcore-tutorial[7]` for explanations of Git’s internals, replacing the original 422-line content.

The commit message explains why the document is being removed: its approach—introducing Git by exploring the contents of `.git/`—is no longer pedagogically effective for most beginners, and its technical details (e.g., ref storage, index terminology) are outdated. The author argues that deleting `gittutorial-2` frees the project to rewrite the main `gittutorial` without being constrained by a legacy sequel. The patch itself deletes all sections except the NAME, SYNOPSIS, and DESCRIPTION headers, which are repurposed to point users to modern alternatives. No other files are modified in this patch; cross-references and translations are handled in the subsequent two patches. The change is purely documentation-focused and does not affect functionality.
