This is Junio’s "What’s cooking" report for September 2026, summarizing the state of Git’s integration branches as the project prepares for the next development cycle (Git 2.98). The report lists new topics, ongoing work, and discarded patches, giving a snapshot of what’s queued for review, testing, or eventual release.

The most immediate news is that Git 2.56 has just been tagged, and the tree is temporarily quiet while the project watches for urgent regressions. The next release will be Git 2.98, followed by Git 2.99 as a stabilization step toward Git 3.0. This versioning reflects the project’s long-standing practice of using the 2.99.x series to finalize breaking changes before a major-number bump.

Several topics are already in `next` and likely to graduate to `master` soon. Among them:

- **`jk/pull-null-merge-head`** fixes a segfault in `git pull` when it encounters unparseable objects.
- **`je/doc-asciidoc-xrefs`** improves documentation cross-references by using explicit AsciiDoc syntax, making web and man-page rendering more reliable.
- **`js/ci-debian-12-http2-workaround`** works around a Debian 12 curl bug that occasionally causes HTTP/2 authentication failures in CI.
- **`ps/reflog-expiry-fix`** corrects a regression that swapped the default expiry periods for reachable and unreachable reflog entries.
- **`tb/rerere-wait-for-merge-rr-lock`** prevents `rerere` from failing when `rerere gc` is running concurrently, by waiting for the lock instead of erroring out.
- **`gg/http-ssl-verify-status`** adds support for checking stapled OCSP responses during TLS handshakes via a new `http.sslVerifyStatus` config.

A few topics are marked as needing review and could use attention:

- **`hn/shallow-history-advice`** improves error messages in shallow clones when `~N` or `^N` references fail due to missing parents.
- **`mc/refs-hook-report-old-values`** updates the `reference-transaction` hook to report the old object ID for unconditional updates, rather than the null OID.
- **`td/ls-files-untracked-cache`** optimizes `git ls-files` by reusing the untracked cache, reducing filesystem traversals.
- **`je/doc-merge-conflicts`** introduces a new `gitmergeconflicts(7)` man page and updates several commands to link to it, centralizing conflict-resolution guidance.
- **`ps/meson-improvements`** speeds up Meson builds by using precompiled headers and avoiding redundant recompilation of HTTP sources.
- **`tc/push-force-if-includes-fixes`** fixes a long-standing bug in `--force-if-includes` where it incorrectly checked the reflog of the wrong branch, and allows fast-forwards even when reflogs are expired.

Two topics are particularly notable for their scope:

- **`ps/ref-storage-format`** (already in `next`) standardizes terminology around reference storage formats, renaming options, environment variables, and config keys from "ref-format" to "ref-storage-format". This is part of ongoing work to support pluggable ref backends.
- **`ps/setup-enforce-repo-passed-to-create-repository-has-no-state`** refactors repository initialization to treat the repository object passed to `create_repository()` as a pure out-parameter, avoiding subtle bugs where the object carries unexpected state.

There are also a few topics that have been cooking for a while and may need a nudge:

- **`cc/lazy-fetch-trusted-bit`** introduces `uploadpack.lazyFetchTrusted` to allow lazy fetching from promisor remotes when serving trusted repositories.
- **`tb/midx-incremental-custom-base`** fixes a bug in `git multi-pack-index write --incremental --base` where packs above the custom base were incorrectly excluded.
- **`mm/diff-process-hunks`** introduces `diff.<driver>.process`, allowing external tools to act as hunk providers for Git’s diff machinery.

Finally, a handful of topics have been marked as "discarded" after stalling for too long, including `fz/rebase-autosquash-empty`, `jc/checkout-refactor`, and `as/utimensat-utimes`. These may resurface if new interest or maintainer bandwidth emerges.

Overall, the report shows a healthy pipeline of fixes, cleanups, and small features, with a few larger efforts (ref storage, repository setup, and diff infrastructure) still in progress. The tone is business-as-usual, with no major controversies or surprises.
