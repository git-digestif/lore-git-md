Thread identity: Git v2.56.0 release announcement by Junio C Hamano. This is a release announcement, not a patch series or RFC.

Core problem or goal: Announce the availability of Git v2.56.0, summarize its key changes, new features, performance improvements, architectural shifts, and contributor statistics to inform the community of the project's current state and progress.

Current status: Released. Git v2.56.0 is now available, incorporating 748 non-merge commits from 104 contributors, including 39 first-time contributors. The release is final; no further changes or versions are expected for this release cycle.

Key technical details:
- **Performance & Scalability**: Optimizations in ref handling (memoized commit traversal for `--contains`), pack-objects (concurrent bitmaps/delta-islands), index scanning (quadratic slowdown fixes), and lazy-loading of configuration (e.g., `core.packedRefsTimeout`). Reftable backend improvements include tombstone handling and reduced syscalls.
- **New Commands/Features**:
  - `git history drop`: Experimental command to remove commits and replay descendants.
  - `git refs` toolbox: New subcommands (`create`, `delete`, `update`, `rename`) for reference management.
  - `git replay --linearize`: Mimics `git rebase --no-rebase-merges`.
  - `git add --resolved`: Stages conflict-resolved paths while preserving unrelated changes.
  - `git branch --delete-merged`: Bulk-deletes merged local branches.
  - `git bisect --reset-when-found`: Automatically resets after finding a culprit.
  - `git cat-file --batch-command=remote-object-info`: Fetches object metadata from remotes without downloading full objects.
- **Architectural Changes**:
  - **ODB Abstraction**: Packfile generation now pluggable (used by `upload-pack`, `send-pack`, `bundle`). ODB transactions for `git receive-pack` replace `tmp_objdir`. Housekeeping (repacking, pruning) moved into backend-specific code. Loose object backend refactored into `odb/source-loose.c`.
  - **`the_repository` Removal**: Global state (e.g., `ignore_case`, `trust_executable_bit`) migrated into `struct repo_config_values`. Refactoring of `setup.c` to split repository discovery/configuration phases. Worktree and ref APIs now pass repository pointers explicitly.
  - **Rustification**: Rust support enabled by default (still optional; mandatory in Git 3.0). macOS universal binary support via `RUST_TARGETS`. Fixes for cross-compilation and memory leaks in Rust/C interop.
- **Security & Robustness**: Hardening against corrupt trees (e.g., `ort` merge backend aborts on errors). Fixes for NULL-dereferences, use-after-free bugs, and Coverity-flagged issues. Reftable backend hardened against OOB reads/writes. Windows: Symlink auto-detection disabled for network paths to prevent NTLM credential leaks.
- **UX Improvements**:
  - `git status`: Updated advice for diverged branches (suggests `git pull <remote> <branch>`).
  - `git checkout`/`worktree add`: Better error messages for ambiguous remote branches.
  - `git mv`: Improved error reporting for missing destination directories.
  - `git send-email`: Clearer error for missing `Subject:` headers.
  - `git imap-send --draft`: Marks uploaded messages as drafts for client-side editing.
- **Documentation**: New `gitdatamodel(7)` tutorial linked from key docs (e.g., `git(1)`, glossary). Clarified `git interpret-trailers` key format and comment handling. Added config variable references for `git replay`. Synopsis-style standardization for `fast-export`, `imap-send`, etc.
- **Test & CI Modernization**: `test_grep` helper replaces bare `grep` in tests. `greplint` linter prevents new bare `grep` assertions. CI updates include Ubuntu 24.04 (Coccinelle performance fix), Debian 12, GitLab CI for long tests. Dockerized CI with explicit PID/file limits to avoid resource exhaustion.
- **Platform Support**: Windows migration from MINGW64 to UCRT64; `git.exe` usable directly (no wrapper). NonStop fixes for `MAX_IO_SIZE` limits and writev(3p) compatibility. macOS universal binary support for Rust.
- **Notable Fixes**: Regression fixes for `git clone --revision` segfault (protocol v0), `git diff --relative --cached` segfault on unmerged paths, `git rebase` skipping `fixup -c` commands. Memory leaks plugged in `format-patch`, `merge`, `reftable`, Bloom filters, and Rust/C interop. Edge cases fixed for `git history` segfault on corrupt repos, `sparse-index` crash on intent-to-add paths, `pack-bitmap` handling of position zero. Protocol v2 fixes for bundle-URI desync and promisor-remote capability parsing.
