This is a test fix for the `t5520-pull.sh` test script. The patch prevents reflog expiration from interfering with a test that relies on reflog entries to compute the fork point during a `--rebase -f` operation.

The issue arises because the test suite hardcodes commit dates to 2005, making reflog entries vulnerable to immediate expiration when `git maintenance` or `git gc` runs. Since the default `maintenance.reflog-expire.auto` setting triggers reflog cleanup after 100 entries, the test could fail unpredictably depending on prior test activity. The fix disables reflog expiration entirely for the test by setting `gc.reflogExpire` and `gc.reflogExpireUnreachable` to `never`, mirroring a similar fix (`ea7d894f44`) applied earlier to rebase tests.

The patch touches only `t/t5520-pull.sh`, adding two `git config` lines in the `setup` block. It is a targeted fix for a flaky test, with a clear commit message that traces the problem to a specific maintenance behavior change (geometric reflog expiry introduced in `452b12c2e0`).
