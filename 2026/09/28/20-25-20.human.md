This is the first patch in a three-part documentation cleanup series. Julia Evans proposes removing `gittutorial-2`, an outdated tutorial document that hasn’t been substantially updated in 20 years. The patch deletes the bulk of `gittutorial-2.adoc` but leaves a six-line stub that redirects readers to `gitdatamodel[7]` and `gitcore-tutorial[7]` for explanations of Git’s internals.

The motivation is clear: the tutorial’s approach—introducing Git by exploring `.git/` directory contents—is no longer pedagogically effective for most users, and its technical details (like ref storage locations) are obsolete. Removing it frees the project to revise the main `gittutorial` without being constrained by a now-irrelevant sequel. The commit message includes a `git diff` showing the document’s age and explains why the content is no longer suitable.

The patch itself is mechanical: 416 lines removed, 6 added. No functional code or build logic is touched, and the author verified that no other documentation or code references `gittutorial-2` outside of build infrastructure and example text in `user-manual.adoc`. This looks like a well-scoped, uncontroversial cleanup that simplifies the documentation landscape.
