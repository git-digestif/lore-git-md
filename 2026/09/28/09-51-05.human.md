This is the fourth patch in Patrick Steinhardt’s seven-patch refactoring series that simplifies the `create_repository()` interface. The patch moves the handling of `core.sharedRepository` from `builtin/init-db.c` into `setup.c`, eliminating the last in-out usage of the `struct repository` parameter and making the interface stateless.

The change is minimal—three lines removed from `cmd_init_db()` and three added to `create_repository()`—and purely mechanical. The commit message explains the awkwardness of the current in-out pattern and confirms that the other caller (`git clone`) already passes `-1`, so there is no behavior change. The patch is part of the series’ broader goal of unifying repository initialization and looks clean and uncontroversial. No review feedback has yet surfaced on this specific patch.
