Core problem or goal
Remove the obsolete `gittutorial-2` document and all references to it from the Git codebase to simplify the documentation landscape and enable future tutorial improvements. The broader goal is to modernize the tutorial material: the current series (v1) removes `gittutorial-2`; follow-up work is planned to remove the older `gittutorial` and introduce a new, modern replacement. The replacement will not replicate the old content, focusing instead on current needs and avoiding duplication with existing documentation like `gitdatamodel[7]` and `gitcore-tutorial[7]`. The original `gittutorial-2` introduced Git’s object model through low-level commands (`git cat-file`, `git ls-tree`, `git ls-files --stage`) and key filesystem paths (`.git/objects`, `.git/refs/head/*`, `.git/HEAD`), but this material is already covered by `gitdatamodel[7]` and `gitcore-tutorial[7]` in greater depth, making a direct replacement unnecessary.

Current status
Under review. Three-patch series posted (v1); no prior versions. Patches:
1. Delete `gittutorial-2.adoc` content (retaining a six-line stub redirecting to `gitdatamodel[7]` and `gitcore-tutorial[7]`).
2. Remove cross-references from other documentation files (`MyFirstObjectWalk.adoc`, `git.adoc`, `gitcore-tutorial.adoc`, `gitcvs-migration.adoc`, `gitglossary.adoc`, `gittutorial.adoc`), replacing some with redirects to `gitdatamodel[7]`.
3. Delete translations of the tutorial’s description from all `.po` files (20 languages) and remove the entry from `command-list.txt`.
