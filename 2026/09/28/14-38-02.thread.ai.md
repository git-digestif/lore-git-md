Core problem or goal
A test in `t5520-pull.sh` that exercises `git pull --rebase -f` relies on reflog entries to compute the fork point. Because the test suite hard-codes commit dates to 2005, reflog entries are immediately eligible for expiration under the default `maintenance.reflog-expire.auto` setting (100 entries), causing the test to fail unpredictably when `git maintenance` or `git gc` runs. The goal is to stabilize the test by disabling reflog expiration for its duration.
