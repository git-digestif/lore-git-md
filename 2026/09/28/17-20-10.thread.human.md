Git v2.56.0 has been released, marking a substantial update with 748 non-merge commits from 104 contributors, including 39 first-time participants. This release is particularly notable for its architectural advancements, with Patrick Steinhardt’s work on the pluggable Object Database (ODB) abstraction reaching a new milestone—packfile generation and housekeeping are now backend-agnostic, and loose object handling has been refactored into a dedicated module. The `the_repository` global variable removal also saw significant progress, with key state like `ignore_case` and `trust_executable_bit` migrated into `struct repo_config_values`, and APIs for worktrees and refs now explicitly passing repository pointers.

The release introduces several new commands and features that address real-world workflow needs. `git history drop` (experimental) allows removing commits and replaying descendants, while `git refs` provides a toolbox for reference management with subcommands like `create`, `delete`, and `rename`. Other additions include `git replay --linearize` (mimicking `git rebase --no-rebase-merges`), `git add --resolved` for staging conflict-resolved paths, and `git branch --delete-merged` for bulk-deleting merged branches. Performance optimizations are widespread, from memoized commit traversal in ref handling to concurrent bitmaps in `pack-objects` and lazy-loading of configuration to avoid recursive initialization issues. The reftable backend also saw improvements in tombstone handling and syscall reduction.

On the platform side, Windows users will benefit from the migration to UCRT64 and the ability to use `git.exe` directly, while macOS now supports universal binaries for Rust. The Rustification effort continues, with Rust support enabled by default (though still optional until Git 3.0) and fixes for cross-compilation and memory leaks in Rust/C interop. Documentation saw a major addition with the new `gitdatamodel(7)` tutorial, and the test suite was modernized with helpers like `test_grep` and a `greplint` to prevent regressions. While the release includes numerous regression fixes and memory leak plugs, the ODB abstraction and Rust support are likely to generate the most discussion, particularly around platform compatibility and long-term maintainability.
