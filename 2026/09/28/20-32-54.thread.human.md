This thread is about Julia Evans’s patch to rewrite the introduction of the `git(1)` man page, replacing outdated references to guides like `gittutorial` and `user-manual` with direct instructions for accessing Git’s help system (`git push -h`, `git help push`, etc.). The goal is to improve discoverability for new users by steering them toward actionable, up-to-date resources.

The patch is now in its third iteration and is uncontroversial. All substantive feedback from Junio C Hamano, D. Ben Knoble, and Kristoffer Haugsbakk has been incorporated, including mechanical corrections and clarifications about why certain guides were removed. The only remaining task is for Julia to update the commit message to include the rationale for dropping outdated guides and preferring `git-scm.com/docs` over other documentation sources. Junio’s latest feedback suggests a minor refinement: instead of removing the `cli` guide entirely, it might be worth updating it to better serve its audience, as it currently explains useful command-line parsing rules. However, this is a suggestion for future work, not a blocker for the current patch.

The patch is ready for Junio to pick up and is expected to land in `master` once the commit message is finalized. No further technical changes are needed, and the discussion has already addressed all prior concerns.
