This thread is about a documentation patch by Julia Evans that rewrites the introduction of the `git(1)` man page to better orient new users toward Git’s help system. The patch replaces outdated references to guides like `gittutorial` and `user-manual` with direct, actionable instructions for accessing help (`git cmd -h`, `git help cmd`, etc.), aiming to improve discoverability and practicality. After three iterations, the patch itself is finalized and uncontroversial, with all substantive feedback from Junio C Hamano, D. Ben Knoble, and Kristoffer Haugsbakk addressed.

The only remaining step was updating the commit message to incorporate Junio’s feedback on the design philosophy behind the change. Julia has now done this, framing the patch as part of a shift toward an "every page is page one" model, where documentation is self-contained and prioritizes user-tested sequences over linear, book-like structures. She also clarifies that the removal of outdated guides (like `cli`) is not permanent but a step toward revising them to better serve interactive users. With this update, the patch is ready for integration into `master`. No further discussion or changes are needed.
