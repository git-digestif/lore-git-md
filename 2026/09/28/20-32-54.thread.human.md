This thread is about a documentation patch from Julia Evans that rewrites the introductory section of the `git(1)` man page. The goal is to make the help system more discoverable and actionable for new users. Instead of pointing to outdated tutorial documents like `gittutorial` and `giteveryday`, the new text directs users to concrete commands: `git push -h` for short help, `git push --help` for full documentation, and `git help --guides` or `git help --user-interfaces` to explore concept guides. The change is motivated by user feedback that the current text feels more aspirational than practical.

The patch is a single commit touching only `Documentation/git.adoc`, and Kristoffer Haugsbakk—who last edited this section—is cc’d. So far, there’s been no review or discussion, so the patch is still in its initial proposal stage. If you’ve been away from the list, this is a small but user-facing improvement to Git’s documentation, and it’s waiting for feedback from the community.
