This thread is about a documentation patch by Julia Evans to rewrite the introduction of the `git(1)` man page, replacing outdated tutorial references with direct instructions for accessing Git’s help system (`git push -h`, `git help --guides`, etc.). The goal is to make the guides more discoverable and the text more practical for new users.

The patch is under review and touches only `Documentation/git.adoc`. So far, Ben Knoble has provided substantive feedback, praising the conciseness of the rewrite but raising a concern about discoverability. He points out that `git help cmd` (e.g., `git help push`) is more powerful than `git cmd --help` because it supports aliases, HTML output, and other formats, though he acknowledges the challenge of fitting this nuance into the already streamlined text. The feedback suggests a tension between simplicity for new users and completeness for power users, leaving open whether the patch should hint at `git help cmd` as an alternative.

No other responses have been recorded yet, and the thread remains focused on the `git(1)` rewrite. The patch is self-contained and does not introduce new concepts or dependencies.
