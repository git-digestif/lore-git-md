This thread is about rewriting the introductory section of the `git(1)` man page to make it more useful for new users. Julia Evans proposed replacing outdated references to `gittutorial` and `giteveryday` with direct instructions for accessing Git’s help system, such as `git push -h`, `git push --help`, and `git help push`. After feedback from Ben Knoble and Junio C Hamano, Julia refined the approach to balance simplicity and functionality, resulting in a tiered presentation: simple commands upfront, with advanced features like HTML documentation (`git help --web push`) mentioned later.

Julia has now sent the second version of the patch, incorporating all prior feedback. The changes are confined to `Documentation/git.adoc` and remove the redundant link to `git.github.io/htmldocs/git.html` in favor of `git-scm.com/docs`. The patch is uncontroversial and ready for maintainer review. The only loose ends—minor issues like the cumbersome `git --html-path` and outdated tutorial content—are noted but not blockers for this patch. Kristoffer Haugsbakk, who last edited this section, hasn’t responded yet, but his input isn’t critical at this stage. The next step is Junio’s decision on whether to merge it.
