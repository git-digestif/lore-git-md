This is an RFC inquiry about a potential new feature: an `includeIf "hostname:..."` condition for Git configuration.

Isabella Caselli, an undergraduate student, proposes adding support for a `hostname:` condition in Git's `includeIf` mechanism. This would allow users to include different Git configuration files based on the machine's hostname, which is particularly useful for sharing dotfiles across multiple machines. The proposal references a GitHub issue (gitgitgadget/git#1665) where this feature was requested and a stalled 2022 proposal for an OS-based `includeIf` condition, which Isabella argues is a separate concern.

The email raises two key questions: whether the feature is still relevant to the project and if anyone is already working on it, and whether there are objections to the approach, particularly around hostname normalization (e.g., short name vs. fully qualified domain name). Isabella plans to model the implementation after the existing `onbranch:` condition, touching `config.c`, `t1305-config-include.sh`, and `config.adoc`.

No prior work on this specific feature is mentioned, and the email does not indicate any existing patches or ongoing efforts. The proposal appears well-scoped and motivated, though the hostname normalization question could become a point of discussion. The feature itself aligns with Git's existing `includeIf` functionality and would be a natural extension for users managing multi-machine setups.
