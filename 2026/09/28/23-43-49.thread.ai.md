Thread identity: RFC inquiry about adding an `includeIf "hostname:..."` condition to Git's configuration system. Originating author: Isabella Caselli (undergraduate student). Thread type: feature proposal (RFC).

Core problem or goal: Enable users to conditionally include Git configuration files based on the machine's hostname, facilitating dotfile sharing across multiple machines. The proposal aims to extend Git's existing `includeIf` mechanism with a new `hostname:` condition, modeled after the `onbranch:` implementation.

Current status: Early-stage RFC; no prior work or patches submitted. The proposal is motivated by a GitHub issue (gitgitgadget/git#1665) and references a stalled 2022 proposal for an OS-based `includeIf` condition, which Isabella distinguishes as a separate concern.
