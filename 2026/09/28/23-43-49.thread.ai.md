Thread identity: RFC inquiry about adding an `includeIf "hostname:..."` condition to Git's configuration system. Originating author: Isabella Caselli (undergraduate student). Thread type: feature proposal (RFC).

Core problem or goal: Enable users to conditionally include Git configuration files based on the machine's hostname, facilitating dotfile sharing across multiple machines. The proposal extends Git's existing `includeIf` mechanism with a new `hostname:` condition, modeled after the `onbranch:` implementation. The feature is motivated by a GitHub issue (gitgitgadget/git#1665) and aims to address hostname-based configuration needs distinct from the stalled 2022 OS-based `includeIf` proposal.

Current status: Early-stage RFC with constructive feedback received. No patches submitted yet. Jeff King (Peff) confirmed the feature is reasonable and not actively pursued by others, based on a list archive search. Ignacio Encinas, author of the 2024 hostname-normalization patch series, clarified that his effort stalled due to complexity and was not rejected or blocked, removing any ambiguity about prior objections. Peff suggested exposing Git’s view of the hostname via `git var GIT_HOSTNAME` as a debugging aid, adding a new technical detail to the proposal. Peff’s follow-up to Ignacio further reinforced that the path is clear for Isabella to proceed, framing the stalled 2024 work as a normal part of open-source contribution and a valuable reference for future implementation.

- New condition: `includeIf.hostname:<pattern>` (syntax to be finalized).
