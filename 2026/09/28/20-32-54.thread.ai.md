Subject: [PATCH] git(1): rewrite intro to orient users toward help system
Series version: standalone patch (v2)
Originating author: Julia Evans
Thread type: documentation patch

Core problem or goal
Rewrite the introductory section of the `git(1)` man page to replace outdated references to `gittutorial` and `giteveryday` with concrete, actionable instructions for accessing Git’s help system. The goal is to improve discoverability and practicality for new users by directing them to the help system (`git push -h`, `git push --help`, `git help push`, `git help --guides`, `git help --user-interfaces`), while balancing simplicity and functionality. The v2 patch adopts a tiered approach: simple commands (`-h`, `--help`) upfront, followed by `git help cmd` and its advanced features (e.g., HTML output via `--web`), and drops the redundant link to `git.github.io/htmldocs/git.html` in favor of `git-scm.com/docs`.

Current status

Julia Evans has now clarified the rationale for removing the `git.github.io` link: it offers the same content as `git-scm.com/docs` but lacks useful features like a table of contents, search, and an overview of all documentation.
