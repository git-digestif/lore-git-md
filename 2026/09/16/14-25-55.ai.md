This is a maintainer's follow-up in the `git-contacts` stdin feature thread. Junio C Hamano raises a design alternative for consideration: instead of silently reading from stdin when no arguments are given and stdin is not a terminal, the script could adopt the conventional UNIX idiom of treating `-` as a filename argument meaning "read from stdin." This would allow mixing file arguments and stdin input (e.g., `git contacts patch1 - patch3 <patch2`) and would not require changing the usage comment. The suggestion is framed as food for thought rather than a request for change; the v2 patch remains functionally endorsed and ready for pickup.
