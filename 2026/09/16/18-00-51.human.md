This is the **release candidate announcement for Git v2.56.0-rc1**, sent by Junio C Hamano. It marks the first testing milestone for the upcoming Git 2.56.0 release, which includes 721 non-merge commits from 90 contributors (37 of them new to the project).

The release notes highlight a mix of **user-facing features, performance improvements, internal refactoring, and bug fixes**. Key additions include:
- **New commands and options**: `git refs` gains `create`, `delete`, `update`, and `rename` subcommands; `git history` adds a `drop` subcommand; `git replay` introduces `--linearize` to flatten merge commits.
- **Behavioral changes**: `git status` now suggests `git pull <remote> <branch>` for diverged branches, `git branch` can delete merged branches with `--delete-merged`, and `git add` adds a `--resolved` option for conflict resolution.
- **Performance and scalability**: Optimizations for `git branch --contains`, `git for-each-ref --contains`, and `git status` (avoiding quadratic complexity in untracked file enumeration). The reftable backend is now more efficient with deletion tombstones.
- **Internal refactoring**: Continued progress on the `the_repository` removal effort, ODB (object database) abstraction, and pluggable object storage backends. The loose object backend is now more self-contained.
- **Bug fixes**: Over 50 fixes since v2.55, including memory leaks, segfaults, and edge cases in commands like `git clone --revision`, `git rebase`, and `git worktree repair`.

The release also **updates build system support**, including a switch to the URCR64 runtime for Windows and universal macOS binary support when Rust is enabled. Documentation improvements are widespread, with updates to `SubmittingPatches`, `git interpret-trailers`, and the new `gitdatamodel(7)` tutorial.

This RC is feature-complete for v2.56.0, with only last-minute fixes expected before the final release. Testing is encouraged, especially for the new commands and refactoring work. The tarballs are available at the usual locations, and the tag is present in all public repositories.
