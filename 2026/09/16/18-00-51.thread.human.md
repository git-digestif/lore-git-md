Git v2.56.0-rc1 has been tagged by Junio Hamano, marking the start of the stabilization period for the next major release. This release candidate includes 721 non-merge commits from 90 contributors, 37 of whom are first-time contributors. The changes span a wide range of areas, including UI improvements, performance optimizations, internal refactoring, and bug fixes.

Key highlights include new subcommands for `git refs` (create, delete, update, rename) and a `drop` subcommand for the experimental `git history` tool. The release also features updates to advice messages, promisor-remote handling, and the `ort` merge backend, along with new configuration options like `fetch.followRemoteHEAD`. Performance improvements touch the object database abstraction, reftable backend, and pack-objects, while ongoing efforts like `the_repository` removal and Rustification continue to modernize the codebase. The draft release notes also note numerous bug fixes, memory safety improvements, and platform-specific updates.

This is a testing release, and the final version is expected soon unless significant issues emerge. The changes reflect a balance of new features, internal cleanup, and stability improvements, with a notable emphasis on memory safety and reducing global state.
