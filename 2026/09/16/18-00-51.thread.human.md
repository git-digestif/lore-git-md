This thread is the announcement of Git v2.56.0-rc1, the first release candidate for the upcoming Git version. Junio C Hamano posted the announcement, summarizing the changes since v2.55.0—721 non-merge commits from 90 contributors, including 37 first-timers. The release candidate spans nearly every part of Git, with notable updates to commands like `git status`, `git pull`, `git history`, and `git refs`, as well as deeper changes like ODB abstraction, reftable backend improvements, and build system updates (including Rust support for macOS universal binaries).

The only follow-up so far is a minor editorial suggestion from Tuomas Ahola about the release notes entry for a `git history` segfault fix. The current phrasing notes that the command "can segfault when a necessary tree object is not found," but Tuomas suggests clarifying that the issue has been fixed to avoid ambiguity. The fix itself is already queued for the `maint` branch, so this is purely about wording in the final release notes. No technical changes or objections have been raised, and the release candidate remains on track for final release pending community testing.
