This is a small follow-up in the `git-contacts` stdin feature thread. Junio C Hamano notes that while he is not asking the author to change the current implementation, there is a conventional Unix alternative: using `-` as a placeholder for stdin instead of silently reading from stdin when no arguments are given. This would allow more flexible invocation patterns like `git contacts patch1 - patch3 <patch2` and would not require updating the usage comment. The current v2 patch remains functionally sound and ready for merging, but this observation might influence future design discussions or follow-up patches. No action is requested; the comment is purely advisory.
