This is a platform compatibility bugfix targeting the Windows-specific WinANSI layer in Git’s `compat/` directory.

The patch fixes a subtle variadic-argument mishandling in `die_lasterr()`. When `DuplicateHandle()` fails, the function currently passes a `va_list` directly to `die_errno()` as if it were a regular argument, causing the error message to print the raw `va_list` representation instead of the intended handle value. The fix introduces a temporary `strbuf`, formats the arguments into it with `strbuf_vaddf()`, saves `GetLastError()` before any strbuf operations can clobber it, and then hands the completed string to `die_errno()` via a literal `"%s"` to prevent double-formatting.

The change is minimal (7 insertions, 2 deletions), compiles cleanly with MinGW GCC 13, and has been verified under Wine to produce the correct integer value in the fatal message. No other callers of `die_lasterr()` are affected.
