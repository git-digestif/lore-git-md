This is the maintainer's final sign-off on the two-patch bugfix series that fixes pathspec handling during directory traversal. Junio C Hamano confirms the v4 iteration is ready for the `next` branch, meaning it will enter the integration-testing phase alongside other queued topics. The series addresses a heap-buffer-overflow in `match_pathspec_with_flags()` and a logical error in `common_prefix_len()` that broke an optimization for avoiding unrelated directory scans when exclude pathspecs appear first. All technical feedback from Elijah Newren and Junio has been incorporated, including deterministic test cases for both the memory-safety issue and the false-positive bug. The patches touch `dir.c`, the functional test script `t/t6132-pathspec-exclude.sh`, and the unit-test file `t/unit-tests/u-dir.c`. No further changes are expected; the series is narrowly scoped to pathspec handling and directory traversal, with no broader subsystem impact.
