This thread is about a small but long-standing bug in Git’s Windows compatibility layer. The patch, submitted by Yongqiang Tian, fixes a formatting error in `compat/winansi.c:die_lasterr()` that causes Windows API failure messages to incorrectly display the address of a `va_list` instead of the intended integer handle when `DuplicateHandle()` fails. The fix is minimal—just seven lines added and two removed—and targets only this specific function.

Junio C Hamano, the Git maintainer, has declined to review the patch himself, noting that he doesn’t work on Windows and lacks the expertise to assess it. He has instead CC’d Patrick Steinhardt and Johannes Schindelin, both of whom have deep experience with Windows portability. The patch itself is straightforward and well-motivated, with no open questions or objections raised so far. The next step is for one of the newly CC’d reviewers to weigh in on whether the fix is correct and ready to merge.
