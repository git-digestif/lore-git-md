This is an announcement email for the first release candidate of Git v2.56.0. Junio C Hamano, the Git maintainer, has tagged v2.56.0-rc1, marking the start of the stabilization period for the upcoming release. The release candidate includes 721 non-merge commits since v2.55.0, contributed by 90 people, 37 of whom are first-time contributors.

The email provides the usual download locations for the release candidate tarballs and lists the public repositories where the `v2.56.0-rc1` tag is available. It also includes a detailed list of new contributors and returning contributors, acknowledging their work on this release.

The draft release notes for Git v2.56.0 are extensive and cover a wide range of changes across multiple areas:

**UI, Workflows & Features:**
- Updates to advice messages in `git status` and `git pull`.
- Improvements to promisor-remote handling, the `ort` merge backend, and `git log --follow`.
- New subcommands for `git refs` (`create`, `delete`, `update`, `rename`).
- New `drop` subcommand for the experimental `git history` command.
- Optimizations in `git blame` output alignment and option parsing.
- New configuration options like `fetch.followRemoteHEAD` and `remote-object-info` for `git cat-file --batch-command`.
- Improvements to `git branch --delete-merged`, `git mv`, `git add --resolved`, and `git bisect --reset-when-found`.
- Userdiff patterns for Swift and updates to configuration file locking.

**Performance, Internal Implementation, Development Support:**
- Continued refactoring to remove global state, including `the_repository` removal efforts.
- Optimizations in object database (ODB) abstraction, reftable backend, and pack-objects.
- Pluggable object database housekeeping and improvements to the test suite.
- Updates to the build system, including support for universal macOS binaries when Rust is enabled.
- Memory safety improvements, including fixes for NULL-pointer dereferences and resource leaks.
- Updates to the CI infrastructure, including Dockerized jobs and GitLab CI.

**Fixes since v2.55:**
- A variety of bug fixes, including memory leaks, segfaults, and edge-case handling in commands like `git submodule`, `git rebase`, `git merge`, and `git clone`.
- Fixes for platform-specific issues, including Windows and macOS.
- Improvements to error messages and handling in commands like `git send-email`, `git cat-file`, and `git worktree`.
- Updates to the test suite to avoid flakiness and improve reliability.

Key recurring efforts noted in the release include the `the_repository` removal, ODB abstraction, reftable backend improvements, and Rustification. The release also includes contributions from Git for Windows, which have been upstreamed.

This release candidate is intended for testing, and the final release is expected soon, barring any last-minute fixes. The changes reflect a mix of new features, performance improvements, internal refactoring, and bug fixes, with a strong emphasis on memory safety and code modernization.
