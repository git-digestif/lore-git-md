# Thread deltas

## 2026/09/16

- [2026/09/16/04-23-12 by Yongqiang Tian <yqtian668@gmail.com>] Yongqiang Tian posted a patch fixing die_lasterr() in compat/winansi.c, which had passed its va_list to die_errno() as an ordinary variadic argument so the supplied handle was never formatted; the fix formats the arguments with strbuf_vaddf(), saves GetLastError() before formatting (since strbuf growth can change the thread's error value), converts it to errno afterward, and passes the completed message to die_errno() via a literal "%s".
- [2026/09/16/06-13-15 by Johannes Sixt <j6t@kdbg.org>] Johannes Sixt pointed out that the only variadic call site passes the Windows handle, which is opaque and unhelpful as a debugging aid, and suggested the simpler route of removing the formatting from that call and having die_lasterr() take just a single string with no variable argument list.
- [2026/09/16/06-33-19 by René Scharfe <l.s.r@web.de>] René Scharfe called the bug a good find and agreed the proposed fix makes sense but is quite complicated; noting that die_errno() itself uses a fixed-size buffer to avoid heap allocation and avoid changing errno, he proposed turning die_lasterr() into a macro that sets errno from GetLastError() and forwards to die_errno() for the same reasons.
- [2026/09/16/07-09-51 by Johannes Sixt <j6t@kdbg.org>] Johannes Sixt objected to René Scharfe's macro direction because it degrades the exact GetLastError() value into an errno (adding that die_errno should then be removed from the picture), but reiterated that the whole approach is overengineered, again favoring his earlier simpler single-string design.
