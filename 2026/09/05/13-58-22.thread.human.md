This thread is about updating Git's CI workflows to use Debian 12 instead of Debian 11, now that Debian 11 has reached end-of-life. Jeff King (Peff) sent a straightforward patch to make the switch, touching the GitHub Actions and GitLab CI configuration files. Junio C Hamano has queued it for merging, and the last technical question—whether to use the `oldstable` Docker tag instead of hard-coding `debian:12`—has been settled in favor of Peff's original approach.

The patch itself is uncontroversial and ready to go. What's still open is the longer-term question of how to handle older or niche platforms in CI, like the 32-bit `linux32` job (currently on Ubuntu 20.04, which is also out of support) and the `linux-TEST-vars` job. Patrick Steinhardt suggested Alpine Linux as a possible replacement for 32-bit testing, but no decision has been made yet. For now, the project is sticking with manual updates when Debian versions go out of support, treating this as a routine maintenance task rather than something that needs automation.
