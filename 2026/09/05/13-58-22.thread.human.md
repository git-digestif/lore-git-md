This thread is about updating Git's CI workflows to use Debian 12 instead of Debian 11, now that Debian 11 has reached end-of-life. Jeff King (Peff) sent a straightforward patch to switch the CI images in both GitHub Actions and GitLab CI, which Junio has queued with intent to merge.

The change itself is mechanical—just updating the Docker image tags—but Patrick Steinhardt followed up with a small but practical refinement: using the `oldstable` tag instead of hardcoding `debian:12`. This would let the CI automatically track the next Debian release when it enters oldstable, reducing future maintenance. The patch is already in Junio's `seen` branch and expected to graduate to `next` soon, so this tweak is more about long-term convenience than blocking progress.

The thread also surfaced some latent CI maintenance questions, like whether to keep testing on older LTS releases (AlmaLinux 8 is already covering that) and how to handle 32-bit testing now that Ubuntu 20.04 (the last LTS with i386 support) is out of support. Patrick suggested Alpine Linux as a possible alternative for 32-bit coverage, but these discussions remain open and aren’t holding up the current patch. For now, the focus is on getting the CI onto a supported Debian release with minimal fuss.
