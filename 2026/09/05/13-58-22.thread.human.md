The Git mailing list thread about updating CI to use Debian 12 instead of Debian 11 is now effectively closed. The patch, originally authored by Jeff King (Peff), updates GitHub Actions and GitLab CI workflows to use Debian 12, replacing the now end-of-LTS Debian 11. The change is mechanical—updating the `image` fields in `.github/workflows/main.yml` and `.gitlab-ci.yml` from `debian:11` to `debian:12`—and aligns with the project’s practice of keeping CI on supported distributions.

The last open technical question—whether to use the `oldstable` Docker tag instead of hard-coding the version—was resolved in favor of Peff’s approach, which Junio C Hamano has now explicitly endorsed. This means the patch will proceed as-is, with manual updates every few years when Debian’s LTS window ends. The patch is already queued in Junio’s `seen` branch and is expected to graduate to `next` in the next integration cycle.

Two latent CI maintenance tasks remain unaddressed but are explicitly deferred: the `linux32` job (still on Ubuntu 20.04, which lost i386 support) and the `linux-TEST-vars` job (also on Ubuntu 20.04). Patrick Steinhardt has proposed using Alpine Linux—already tested in CI via the `linux-musl-meson` job—as a replacement for 32-bit coverage, but no action is planned until problems arise. For now, the focus is on the straightforward Debian 12 update.
