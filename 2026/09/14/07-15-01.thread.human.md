This is an announcement for **Git for Windows 2.56.0-rc0**, the Windows-specific distribution of Git, maintained by Johannes Schindelin. It tracks upstream Git v2.56.0-rc0 and includes updates to bundled components like Git LFS, cURL, and OpenSSL. Key changes specific to Git for Windows include dropping support for Windows 8.1 (aligning with MSYS2), which alters internal paths, and fixes for installer regressions from v2.55.0—most notably restoring the "Use external OpenSSH" option and resolving a stack-smashing error during parallel checkouts. The release also enables committing objects larger than 4GB and fixes a vim integration bug that omitted the first line of files.

This is a downstream packaging effort and does not involve upstream Git development or patches. The announcement provides download links for multiple variants (64-bit, ARM64, 32-bit, portable, and MinGit) and advises users who upgraded to v2.55.0 and rely on external OpenSSH to rerun the installer to restore their configuration. No action or discussion is expected on the Git mailing list.
