This is the latest review feedback on Patrick Steinhardt’s 13-patch series to standardize Git’s ref storage terminology. Kaartic Sivaraam’s comment is a surface-level observation about test coverage: the v3 series updates all tests to use the new `--ref-storage-format=`, `GIT_REF_STORAGE_FORMAT`, and `init.defaultRefStorageFormat` names, but does not include explicit tests to verify that the deprecated aliases (`--ref-format=`, `GIT_REFERENCE_BACKEND`, `init.defaultRefFormat`) still work as intended. This is a minor completeness concern rather than a technical flaw—the backward-compatible aliases are implemented via `OPT_ALIAS_F()` and environment variable fallbacks, so they are expected to work, but the absence of tests means the behavior is not validated.

The feedback is non-blocking and does not challenge the series’ design or implementation. It merely suggests adding a few test cases to confirm the deprecated names remain functional, which would be a straightforward follow-up if Patrick chooses to address it. The series itself is otherwise ready for maintainer attention, with all substantive feedback from v2 resolved and no open technical issues.
