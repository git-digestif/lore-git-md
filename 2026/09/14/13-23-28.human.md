This is a brief follow-up in the ongoing bugfix series for merge driver temporary file cleanup. Michal Koutný, the original reporter, weighs in on Jeff King’s (Peff) v2 patch series, which replaces custom signal handling with Git’s `tempfile` API to ensure cleanup on SIGINT/SIGQUIT.

He argues that retrying the merge (after restoring state) is straightforward, and rare read errors can be worked around during merge tool development. This aligns with Peff’s earlier note that the current behavior already deletes files on read errors, making consistent cleanup the more user-friendly approach.

The exchange doesn’t introduce new technical concerns or objections; it’s a lightweight endorsement of the series’ direction. Peff had previously acknowledged the difficulty of testing interrupt scenarios in the test suite, and Michal’s feedback reinforces that the trade-off (prioritizing cleanup over potential debugging utility) is reasonable.
