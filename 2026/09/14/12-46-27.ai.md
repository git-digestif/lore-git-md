This is the first patch in a two-patch documentation series (v2) that mechanically updates the `git-pack-refs` man page and its included options file to use consistent backtick-quoting as part of the ongoing synopsis-style conversion effort.

The patch replaces the `[verse]` block in the SYNOPSIS with `[synopsis]`, removes single-quote formatting around the command name (`git pack-refs`), and backtick-quotes all option terms (`--all`, `--no-prune`, `--auto`, `--include`, `--exclude`) in the OPTIONS section. It also updates the included `pack-refs-options.adoc` to backtick-quote configuration keys and converts a literal `<branch>` placeholder in the BUGS section to italicized form.

No functional changes to Git are introduced; the patch only affects the rendered appearance of the man page and HTML documentation. The changes are uncontested and align with the project’s established documentation conventions. The files touched are `Documentation/git-pack-refs.adoc` and `Documentation/pack-refs-options.adoc`. This patch corresponds to the second patch in the original v1 series and is ready for integration.
