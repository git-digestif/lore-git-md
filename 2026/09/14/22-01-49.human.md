This is a maintainer-proposed patch that resolves the advice-scope-hint discussion by implementing the now-agreed uniform `--global` hint for all `advice.*` settings. Junio takes Vsevolod Myalitsyn’s original work, simplifies it to a single patch, and posts a ready-to-merge version that changes the turn-off instructions in every advice message from `git config set advice.FOO false` to `git config set --global advice.FOO false`.

The patch touches `advice.c` and updates a dozen test scripts to match the new output. No new fields or enums are introduced; the design is intentionally minimal. Junio’s commit message explains the rationale: advice messages are about silencing chatter for a *user*, not a specific repository, so `--global` is the appropriate scope. The patch also acknowledges that some advice (like `defaultBranchName`) is only relevant before a repository is created, making per-repository configuration pointless.

This version resolves all earlier build failures and mechanical feedback from v3/v4, and it reflects the consensus reached between Junio and Jeff King. The next step is likely for Junio to queue it in `next` unless Vsevolod or another reviewer spots a last-minute issue.
