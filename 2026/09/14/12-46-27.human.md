This is a documentation patch, part of Todd Zullinger’s v2 series to standardize backtick-quoting in the `git-pack-refs` and `git-refs` man pages. It is the first of two patches in the current iteration.

The patch mechanically converts the `git-pack-refs` man page to the new synopsis style: the SYNOPSIS block is switched from `[verse]` to `[synopsis]`, the command name is no longer wrapped in single quotes, and every option term (`--all`, `--no-prune`, `--auto`, `--include`, `--exclude`) is now backtick-quoted. It also updates the included `pack-refs-options.adoc` file to apply the same quoting rule to configuration keys and fixes a stray `<branch>` placeholder in the BUGS section to use italics.

No functional changes to Git itself are introduced; the patch affects only the rendered appearance of the man page and HTML documentation. It is uncontested and aligns with the ongoing, multi-month effort led by Jean-Noël Avila to bring all man pages into a consistent AsciiDoc formatting style. The series is ready for integration.
