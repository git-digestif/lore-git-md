This is a documentation patch series, part of the ongoing effort to convert Git man pages to a consistent AsciiDoc synopsis style. Todd Zullinger resubmits v2 after dropping the controversial lint script change from v1, leaving only two mechanical formatting patches that address inconsistent backtick-quoting in `git-refs` and `git-pack-refs`.

The issue is purely visual: in the rendered man pages and HTML documentation, the first two commands (`migrate` and `verify`) appear in bold while later commands do not, due to inconsistent use of backtick-quotes. The patches convert the synopsis block to the `[synopsis]` style, remove single-quote formatting around the command name, and backtick-quote all option terms and subcommands. No functional changes to Git are introduced.

Todd’s v2 is a direct response to Jean-Noël Avila’s objection to the lint script in v1, which was withdrawn to avoid false positives. The remaining patches are uncontested and align with the project’s established documentation conventions. The changes are confined to three AsciiDoc files in the `Documentation/` directory and appear well-scoped and ready for review.
