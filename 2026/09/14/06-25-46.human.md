This is a CI/build system patch under review. Patrick Steinhardt responds to Harald Nordgren’s proposal to remove a redundant `brew link --force gettext` command from the macOS CI dependency script, questioning whether the change is truly safe.

Patrick’s review is substantive. He explains that Homebrew’s gettext is *keg-only*—normally not symlinked into the system path—and that the `--force` flag was originally used to override this behavior, potentially replacing system-provided libraries. While the current CI runner emits an “Already linked” warning, that message does not confirm whether the library is actually in the system path or merely in Homebrew’s cellar. Patrick asks for evidence that the command is no longer needed, such as links to passing CI pipelines, and suggests the commit message should explain why the original command existed and why it can now be dropped.

The patch itself is small and uncontroversial in intent, but Patrick’s feedback raises a legitimate technical concern about whether removing the command could silently break the build on future runner images. No other reviews have appeared yet.
