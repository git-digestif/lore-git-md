This thread introduces an opt-in incremental connectivity check for Git fetches and pushes, now complete with a new auto mode in its sixth and final patch. The feature, authored by Kristofer Karlsson, lets users choose between a full check (the default), an incremental mode that scales with incoming changes rather than repository size, or an auto mode that dynamically switches between them based on a configurable 1,000-commit cutoff. Benchmarks show the incremental mode can be up to 190 times faster for small pushes to large repositories, while the auto mode avoids a modest slowdown for very long incoming histories.

The series has been through five revisions, addressing all prior feedback from Junio C Hamano and Patrick Steinhardt. The latest changes remove reliance on `repo->fetch_if_missing` for forward compatibility, and the auto mode implementation is minimal, touching only the necessary files and adding thorough test coverage. The design is conservative—opt-in, with fallback to the full check for edge cases—and the configurable cutoff balances performance and safety across repository sizes. Both maintainers have signaled the series is ready for integration, with no remaining blockers.
