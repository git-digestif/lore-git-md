Here’s a concise human-readable summary of the Git mailing list thread based on Junio’s "What’s cooking" report for September 2026:

The Git 2.56 release cycle is underway, with -rc0 tagged and finalization approaching. Several small fixes and documentation improvements have already graduated to `master`, including clarifications to `git cherry-pick --no-commit`, conflict-resolution safeguards for `--amend`, and memory-leak fixes in submodules and `git history`. The `next` branch holds about 80 topics likely to land in 2.56, among them performance tweaks like skipping empty multi-pack-index layers, ref-storage terminology standardization, and experimental features such as `git history squash` and `git rev-list --missing-only`.

Rust integration continues to advance, with Windows CI now building Rust code and cross-compilation support via `CARGO_BUILD_TARGET`. However, the effort to move Rust sources into a `rust/` subdirectory remains broken and needs review. Patrick Steinhardt’s ODB abstraction work is also cooking in `next`, including deferred alternate setup and pluggable fsck checks—these are high-impact changes that may conflict with other refactoring topics.

A handful of new topics await review, notably `--matched-only` for `git range-diff`, a `receive-report` hook for filtering packet-line status, and improvements to `rerere gc` heuristics. Stalled efforts include `--fixup` options for `git commit`, a `diff.<driver>.process` external hunk provider, and a refactor of the checkout frontends. The report flags potential contention around the new `git var` extensions and the `receive-report` hook, both of which may need broader discussion before merging.
