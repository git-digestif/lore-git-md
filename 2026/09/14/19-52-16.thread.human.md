This "What's cooking" report for Git 2.56-rc0 summarizes the state of all in-flight topics as of September 2026. The release candidate has been tagged, with several topics graduating to `master`, including fixes for `git history`, documentation updates, and memory leak patches. Around 80 commits are cooking in `next`, with key efforts around Rust integration, ODB abstraction, and ref storage format changes.

The ODB abstraction work led by Patrick Steinhardt continues to progress, with `ps/odb-pluggable-fsck` now receiving a substantive review and endorsement from Toon Claes. This series moves fsck checks into ODB backends, a critical step for pluggable storage formats, and is marked for `master` after addressing prior feedback. Other ODB topics, like deferring alternate setup to ODB creation time, are newly introduced. Rust integration topics, including Windows CI support and cross-compilation fixes, remain in `next`, though the move of Rust code to a `rust/` subdirectory is currently broken and may conflict with ODB refactoring.

The `git history` command is stabilizing, with a memory leak fix (`ks/history-commit-leakfix`) now ready for `next` after review and reroll. New commands and options, such as `git range-diff --matched-only` and `git var` extensions, are also in the pipeline, alongside performance optimizations like Bloom filters for `git last-modified`. Open questions remain around stalled topics needing rerolls, controversial changes like the `receive-report` hook, and potential conflicts between Rust and ODB refactoring efforts. Junio’s report highlights topics awaiting responses or updates, signaling where contributor attention is needed before the final 2.56 release.
