Patrick Steinhardt’s latest reply points out that the GitHub Actions pipeline link provided by Harald Nordgren in v1 did not actually test macOS jobs — most jobs were skipped, so the empirical evidence for the patch’s safety is still missing. While the historical rationale is now documented in the v2 commit message, the lack of macOS CI validation means the patch cannot yet be considered ready.
