This is a final maintainer comment on the `--matched-only` feature patch for `git range-diff`. Junio retracts his earlier suggestion to use `die_for_incompatible_opt3()` in the core range-diff logic, calling it a layering violation. The original code, which returned an error to the caller rather than dying immediately, is correct because it keeps the library reusable by different front-ends that may want to handle errors differently. While he still thinks a helper like `incompatible_opt_error()` might be useful in the future, he now considers that work orthogonal to this patch and not worth blocking it. The patch is otherwise ready and will proceed with the original error-handling approach.
