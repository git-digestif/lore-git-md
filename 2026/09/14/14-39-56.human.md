This is a **maintainer integration notice** for Ariel Keselman’s bugfix patch that skips the packed-refs lock when deleting root refs in the files backend. Junio C Hamano has queued the patch and marked it for the `next` integration branch, meaning it will undergo integration testing alongside other topics before graduating to `master`. The patch is now cooking in `next` and, barring any late-breaking issues, will be part of Git 2.56 unless it is deemed an emergency critical fix after the -rc1 cutoff. Patrick Steinhardt’s earlier approval ("this version looks good to me") was the final technical sign-off, and no further discussion or objections have surfaced. The fix remains a focused, well-tested improvement to the refs subsystem, addressing a real inefficiency that breaks `git update-ref --no-deref -d` for root refs when `.git/packed-refs.lock` is held.
