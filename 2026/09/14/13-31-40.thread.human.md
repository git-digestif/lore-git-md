This thread is about a bug in `git status --ignored` where pathspec matching was incorrectly treating substrings as matches (e.g., `ba` matching `bar/baz/`). The issue was introduced in 2020 by an optimization that skipped pathspec checks for excluded directories. René Scharfe posted a fix (v1) that restored exact-match behavior, and Junio C Hamano later identified a NULL-dereference crash in the new helper function, proposing a squash-in fix.

The v2 patch now incorporates Junio’s safety fix and adds a test case to verify the NULL pathspec edge case. The fix is minimal—touching only `dir.c`—and includes two regression tests: one for the original bug and one for the NULL safety fix. The patch is ready for maintainer integration, with no open questions remaining. Key participants are René (author), Junio (reviewer/safety fix), and Sean Whitton (original reporter). The trade-off—removing a minor optimization for correctness—has been accepted as the right call.
