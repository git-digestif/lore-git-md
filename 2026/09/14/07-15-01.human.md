This is an **announcement** for the release candidate of **Git for Windows 2.56.0-rc0**, the Windows-specific distribution of Git maintained by Johannes Schindelin. It tracks the upstream Git 2.56.0-rc0 release but includes Windows-specific fixes, packaging adjustments, and bundled dependencies.

Key changes since the last stable release (v2.55.0) include dropping support for Windows 8.1, which shifts the default internal paths from `/mingw64/bin/git.exe` to `/ucrt64/bin/git.exe`. Users relying on the old path should switch to `/cmd/git.exe` for stability. The installer for the previous version had a bug that forced the bundled OpenSSH over external installations; affected users need to rerun the installer to restore their preferred OpenSSH setup.

Notable fixes address a 32-bit installer limitation (now resolved), support for committing objects larger than 4GB, a stack-smashing crash in parallel checkouts, and a regression in Git for Windows v2.55.0(5) where Vim would open files with the first line missing. The release also updates bundled dependencies: Git LFS v3.8.0, cURL v8.22.0, and OpenSSL v3.5.8.

This is a routine pre-release for Windows users and packagers. The issues fixed are specific to the Windows distribution and do not affect upstream Git. No action is required for non-Windows users or those not using the affected installer options.
