This is the eighth iteration of Andrew Pleeter’s patch series extending `git var` to expose individual identity components (name, email, date), the resolved commit signing key (`GIT_SIGNING_KEY`), and support multiple variable arguments with NUL-terminated output (`-z`). The patch is part of the ongoing effort to provide a unified, scriptable interface for Git’s identity and signing configuration, replacing the earlier `git ident` proposal.

The v8 patch addresses the last two open issues from Junio’s v7 review: **output format ambiguity** and **exit code documentation**. The output now consistently uses `VARIABLE=value` pairs (or `VARIABLE\nvalue\0` with `-z`) for multi-variable queries, eliminating the need for scripts to know in advance which variables are multi-valued. The exit code behavior is now clearly documented: the command exits with code 1 if *any* requested variable has no value, and omits unset variables from the output. The implementation matches the documentation, resolving the prior discrepancy.

Key changes in v8:
- Multi-variable queries now print `VARIABLE=value` pairs (or `VARIABLE\nvalue\0` with `-z`), making the output unambiguous for scripts.
- Unset variables are omitted from the output, and the command exits with code 1 if any requested variable is unset.
- The documentation is updated to reflect the new output format and exit code behavior.
- Tests are expanded to cover the new multi-variable and `-z` behaviors, including edge cases like unset variables and multi-valued variables.
