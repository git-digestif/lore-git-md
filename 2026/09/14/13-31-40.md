Steps to reproduce:

git init foo
cd foo
mkdir bar
echo bar/ >.gitignore
git init bar/baz
git init bar/quux
git status --porcelain --ignored --untracked-files -- ba

Expected output:
none, "ba" doesn't match "bar".

Actual output:
!! bar/baz/
!! bar/quux/
