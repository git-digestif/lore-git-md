This is a maintainer-proposed patch that resolves the advice-scope-hint thread by implementing the now-consensus design: always recommending `--global` in the hint for *all* `advice.*` settings. Junio C Hamano posts a single-patch v5 that replaces Vsevolod Myalitsyn’s three-patch v4 series, eliminating the `is_global_hint` field entirely and updating every test that checks the advice message to expect the new `--global` wording.

The patch touches `advice.c` and twelve test scripts, changing only the translatable string and the corresponding test expectations. No new fields, enums, or helper functions are introduced; the design is now as simple as possible. Junio’s commit message explains the rationale: advice messages are about silencing chatter for a *user*, not a specific repository, so `--global` is the appropriate scope. The patch also notes that some advice (e.g., `defaultBranchName`) is only relevant before a repository is created, making per-repository configuration too late.

This patch is ready for review and appears likely to be merged as-is; the thread’s central design debate is resolved, and the implementation is minimal and mechanical. The next step is for reviewers to verify the test updates and confirm the string change. Key symbols to track in follow-up discussion: `turn_off_instructions`, `vadvise()`, and the updated test expectations.
