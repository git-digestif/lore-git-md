This is an **announcement email** for **Git for Windows 2.56.0-rc0**, a release candidate of the Windows-specific distribution of Git. It is **not** a patch or contribution to the upstream Git project itself, but rather a downstream packaging effort maintained by Johannes Schindelin.

The release tracks upstream Git v2.56.0-rc0 and includes updates to bundled components (Git LFS v3.8.0, cURL v8.22.0, OpenSSL v3.5.8). Key changes specific to Git for Windows include dropping support for Windows 8.1 (following MSYS2), which alters internal paths (e.g., `/ucrt64/bin/git.exe` replaces `/mingw64/bin/git.exe`), and fixes for installer regressions from the previous version (v2.55.0). Notably, the installer now correctly handles the "Use external OpenSSH" option, which was broken in v2.55.0, and resolves a bug where parallel checkouts could trigger a stack-smashing error. The release also enables committing objects larger than 4GB and fixes a vim integration issue where the first line of files was sometimes omitted.

The email provides download links for multiple variants (64-bit, ARM64, 32-bit, portable, and MinGit) along with SHA-256 checksums for verification. Users relying on external OpenSSH who upgraded to v2.55.0 are advised to rerun the installer to restore their configuration. The announcement is purely informational for packagers and Windows users; no upstream Git development discussion or patch review is involved.
