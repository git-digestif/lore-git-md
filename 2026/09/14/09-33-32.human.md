This is the first patch in Patrick Steinhardt’s v3 series to standardize Git’s ref storage terminology. The patch introduces `OPT_ALIAS_F()`, a variant of `OPT_ALIAS()` that allows passing flags like `PARSE_OPT_HIDDEN` to hide deprecated option aliases from help text while keeping them functional. Karthik Nayak’s review questions whether hiding aliases is necessary at all, noting that the alias (`--ref-format`) still appears in the help output when not hidden, which might confuse users more than help. He suggests the patch might be over-engineering but ultimately accepts it as a reasonable way to handle deprecation.

The patch itself is small and focused: it adds the new macro to `parse-options.h` and updates the `parse_options()` function to propagate flags from the alias to the target option. This enables the rest of the series to use hidden aliases for backward compatibility without cluttering help text. While Karthik’s concern about the necessity of hidden aliases is valid, the implementation is clean and aligns with the series’ goal of quiet deprecation. The change is unlikely to be controversial, but the discussion highlights a tension between transparency (showing deprecated options) and usability (keeping help text clean). The patch is well-motivated and ready for integration.
