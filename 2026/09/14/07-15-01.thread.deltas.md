# Thread deltas

## 2026/09/14

- [2026/09/14/07-15-01 by Johannes Schindelin <johannes.schindelin@gmx.de>] Johannes Schindelin announced the availability of Git for Windows 2.56.0-rc0 at https://github.com/git-for-windows/git/releases/tag/v2.56.0-rc0.windows.1.
- [2026/09/14/07-15-01 by Johannes Schindelin <johannes.schindelin@gmx.de>] Following MSYS2, Windows 8.1 support was dropped, changing internal paths so that /mingw64/bin/git.exe no longer exists and /ucrt64/bin/git.exe takes its role, with /cmd/git.exe recommended as a stable alternative.
- [2026/09/14/07-15-01 by Johannes Schindelin <johannes.schindelin@gmx.de>] The release explains that an installer issue in v2.55.0(5) had disabled the "Use external OpenSSH" option for some users, causing the bundled OpenSSH to overwrite previously-saved external choices, and advises affected users to re-run the installer with "Only show new options" unchecked.
- [2026/09/14/07-15-01 by Johannes Schindelin <johannes.schindelin@gmx.de>] New features include bundling Git v2.56.0-rc0, Git LFS v3.8.0, cURL v8.22.0, and OpenSSL v3.5.8.
- [2026/09/14/07-15-01 by Johannes Schindelin <johannes.schindelin@gmx.de>] Bug fixes include making the installer actually 64-bit (fixing the broken external OpenSSH option from v2.55.0(5)), enabling commits of 4GB objects or larger, fixing parallel checkouts aborting with "stack smashing detected", and fixing a v2.55.0(5) bug where vim often opened existing files with the first line missing.
