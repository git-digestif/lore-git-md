## 2026/09/18

- [2026/09/18/11-04-06 by René Scharfe <l.s.r@web.de>] René Scharfe posted a patch titled "dir: skip excluded directory with nested repo on prefix match" that introduces a `dir_match()` helper wrapping `match_pathspec_with_flags()` and modifies `treat_directory()` to run pathspec matching for an ignored directory containing a nested repository when `matches_how` is not already set, returning `path_none` if there is no match or only a recursive leading-pathspec match; the patch also adds a test in t/t7061-wtstatus-ignore.sh confirming that `git status --porcelain --ignored -u` omits an excluded directory with a submodule on prefix match.

## 2026/09/22

- [2026/09/22/04-57-43 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano reviewed the patch and noted that while the new `dir_match()` helper is a good extraction, the `nested_repo` branch in `treat_directory()` could call it with a NULL `pathspec`, which would segfault because `match_pathspec_with_flags()` dereferences `pathspec` via `GUARD_PATHSPEC`; he proposed wrapping the `dir_match()` call in an `if (pathspec)` guard and supplied a new test case ("replace directory with untracked nested repo") demonstrating the crash when `git checkout` invokes `verify_clean_subdirectory()` with `pathspec=NULL`.
