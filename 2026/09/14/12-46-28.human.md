This is a documentation patch, part of Todd Zullinger’s two-patch v2 series that mechanically backtick-quotes all subcommand and option references in the `git-refs` man page. The patch touches only `Documentation/git-refs.adoc`, converting the seven subcommands (`list`, `exists`, `optimize`, `create`, `delete`, `update`, and `rename`) from plain text to backtick-quoted form so they render consistently in bold in the final man page and HTML output. It also replaces a literal `<branch>` placeholder with an italicized version. No functional change to Git itself is introduced; the patch simply aligns the formatting with the project’s ongoing synopsis-style documentation effort. The series is uncontested and ready for integration.
