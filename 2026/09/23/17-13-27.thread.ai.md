Subject: [PATCH 0/2] ci: reduce resource exhaustion in GitHub Actions
Series version: v1 (initial submission)
Originating author: Tamir Duberstein
Thread type: patch series (CI/build system)

Core problem or goal
Address resource exhaustion in GitHub Actions CI jobs running the full test suite on Linux. Specifically: (1) `t4205-log-pretty-formats.sh` generates enormous output that triggers OOM kills when `diff` compares it, and (2) default `make` and `prove` parallelism is too aggressive for the Linux runner’s CPU cores, causing ENOSPC errors during large clone/repack tests.

Current status
Under review (v1 posted). No prior versions. No maintainer decision recorded.

Key technical details
- Patch 1: Replace `test_cmp` (which uses `diff`) with `test_cmp_bin` (which uses `cmp`) in `t/t4205-log-pretty-formats.sh` and delete the two large temporary files immediately after comparison, reclaiming ~4 GiB of memory.
- Patch 2: Dynamically set `-j` for `make` and `prove` to the runner’s CPU count, matching GitLab CI policy.
- Files touched: `.github/workflows/main.yml`, `t/t4205-log-pretty-formats.sh`.
- No new symbols, CLI options, or on-disk format changes.
- Test coverage: unchanged (long-running tests remain enabled).
