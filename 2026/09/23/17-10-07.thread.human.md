Tamir Duberstein’s two-patch series aimed to speed up `git ls-files` by reusing the untracked cache already populated by `git status`. The first patch fixed a bug that caused unnecessary cache invalidation, while the second implemented the core optimization—expanding cached directory listings on demand. Early benchmarks showed promising speedups (7× on synthetic workloads, 2× on mixed workloads), but Tamir has now withdrawn the second patch, calling it premature and still under active revision. The first patch remains under review, with no objections raised so far. Expect an updated version of the second patch in a future iteration.
