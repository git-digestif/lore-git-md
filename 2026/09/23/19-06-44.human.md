This is a documentation patch, part of the ongoing effort to modernize Git's man pages for better HTML navigation. Kristoffer Haugsbakk replies to Julia Evans' patch (already approved by Junio and queued for integration) with a brief note of approval: he calls the change "an obvious idea in hindsight" after reading the commit message.

The patch itself, which Kristoffer is responding to, systematically replaces informal plain-text section references (e.g., "see EXAMPLES below") with AsciiDoc cross-reference syntax (`<<EXAMPLES,EXAMPLES>>`) across 38 man pages. The two-part form ensures consistency and avoids broken links in HTML output, especially when the target section is in an included file. Julia Evans tested the change thoroughly by building all man pages before and after the patch, confirming no functional differences were introduced.

This reply doesn't add new technical content or objections—it's a surface-level endorsement of the patch's design. The patch remains on track for integration, with no open questions or loose ends. If you're following Git's documentation improvements, this is a small but well-executed step in the broader synopsis-style conversion effort.
