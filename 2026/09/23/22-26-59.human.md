This is the second patch in Tamir Duberstein’s three-patch performance series, which lets `git status` and `git ls-files` share the same untracked cache. The patch removes the long-standing limitation that `--untracked-files=normal` (stops after the first untracked file) and `--untracked-files=all` (lists every untracked file) must use separate caches. Instead, it records partial scans with a “check_only” bit and rescans only when a later command needs the full listing. The cache format is updated so older Git versions rebuild it before use, preserving compatibility. Tests confirm that switching between `-unormal` and `-uall` no longer forces a full filesystem scan, and wildcard pathspecs still benefit from the cache. The change is purely in-memory and touches only `dir.c`, `dir.h`, and the test suite.
