- [2026/09/23/07-10-11 by Xavier Morel <xmo@odoo.com>] Xavier Morel reported that git fails to send basic authentication on the second request when a credential helper returns an empty username with a non-empty password, resulting in an "authentication failed" error; the issue appears to originate in init_curl_http_auth, which exits immediately if the username is unset or empty unless proactiveAuth=basic is enabled, and was observed on git 2.47 and 2.55 with curl 8.5.0.
