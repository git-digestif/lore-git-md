This is a **CI/build system** follow-up in the ongoing thread about the Debian 12 HTTP/2 authentication failure workaround. Jeff King (Peff) provides a concrete implementation of his earlier suggestion: a patch that makes the test suite itself detect the buggy curl version (7.88.1) and skip the affected tests using a prereq (`!HAVE_CURL_HTTP2_BUG`). This addresses both limitations he identified in the original patch—it works locally as well as in CI, and it does not depend on hard-coded test numbers.

The patch is small and targeted, touching only `t/t5551-http-fetch-smart.sh` (the base script for `t5559`). It introduces a lazy prereq that checks for curl 7.88.1 when HTTP/2 is enabled, then marks the two half-auth clone tests with `!HAVE_CURL_HTTP2_BUG`. Peff notes that while a version-range check might be more future-proof, this single-version approach covers the same ground as the original CI-only workaround. The patch is presented as a proof-of-concept rather than a final proposal, leaving the door open for further refinement or adoption.

The thread remains focused on the trade-off between simplicity (original patch) and robustness (this alternative). No new objections have been raised; the discussion is now centered on which approach to integrate.
