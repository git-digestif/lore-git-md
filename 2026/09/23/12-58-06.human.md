This is the **third patch in a four-patch bugfix series** for `git stash`, authored by D. Ben Knoble. It adds a **test case** to verify that `git stash apply --index` correctly handles conflicts in the index by leaving the working tree and index untouched when the operation fails.

The test sets up a scenario where a stash contains staged changes, then introduces a conflict in the index by modifying a file that was also staged in the stash. It verifies that `git stash apply --index` fails gracefully (without corrupting the index or working tree) and emits the expected error message: *"conflicts in index. Try without --index"*. The test ensures the bug fixed in the next patch—where autostashing with staged index entries could previously fail or corrupt state—is properly covered.

This is a **well-scoped test addition** that directly supports the series’ goal of making index handling during stash application more robust. The test is narrowly focused on the edge case of conflicted index merges, which was a gap in the existing test suite.
