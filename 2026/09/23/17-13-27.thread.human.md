This thread is about a two-patch series from Tamir Duberstein that improves Git's CI stability and performance on GitHub Actions. The series is now fully resolved and ready for integration.

The first patch prevents out-of-memory kills in the `t4205-log-pretty-formats.sh` test by switching from `diff` to `cmp` for large outputs, reducing memory usage from 4 GiB to 1.2 MiB. This change has been stable since the first version and is endorsed by Jeff King, Junio C Hamano, and Patrick Steinhardt.

The second patch unifies parallel job-count selection across CI platforms, setting both `make` and `prove` parallelism to twice the detected CPU count. This change delivers a 7% speedup on Linux while avoiding a 26% slowdown on macOS, based on cross-platform benchmark data. After some discussion about trade-offs, Patrick Steinhardt accepted the final version in his latest reply, closing the last open question.

Both patches are now final, with no remaining objections or requested changes. The series is ready for Junio to pick up into his `next` branch.
