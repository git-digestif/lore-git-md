This thread is about a two-patch series from Tamir Duberstein aimed at reducing resource exhaustion in GitHub Actions CI jobs. The first patch, which replaces `test_cmp` with `test_cmp_bin` in `t/t4205-log-pretty-formats.sh` to avoid OOM kills during large diff operations, is settled and ready for integration. Jeff King, Junio Hamano, and Patrick Steinhardt have all endorsed it, and the next revision will drop some ineffective cleanup lines and include benchmark data in the commit message.

The second patch, which dynamically sets `-j` for `make` and `prove` to the runner’s CPU count, has been revised to unify GitHub and GitLab CI logic. Patrick Steinhardt’s review requested two commit-message improvements—adding benchmark data and clarifying the macOS justification—which Tamir has now accepted. The benchmark data showed no reliable performance change on Linux, and the macOS rationale has been tightened to explain the absence of `nproc`. With these tweaks, the patch is effectively final unless new concerns emerge. The series is now poised for integration once the next revision is posted.
