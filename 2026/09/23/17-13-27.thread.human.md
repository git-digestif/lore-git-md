This thread is about a two-patch series from Tamir Duberstein that improves Git's CI stability and performance. The series is now fully resolved and has been picked up by Junio C Hamano for integration into his `next` branch, meaning it will undergo final integration testing before graduating to `master`.

The first patch prevents out-of-memory kills in GitHub Actions by replacing `test_cmp` with `test_cmp_bin` in a test script that generates large outputs. This change was endorsed by Jeff King and Junio after benchmarking showed it reduced memory usage from 4 GiB to 1.2 MiB. The second patch standardizes parallel job counts across CI platforms (GitHub Actions and GitLab CI) to twice the detected CPU count, delivering a 7% speedup on Linux while avoiding a 26% slowdown on macOS. Patrick Steinhardt reviewed the data and gave his final approval, calling the series ready for integration.

The patches touch only the test script and CI configuration file, with no changes to user-facing behavior, on-disk formats, or test coverage. All open questions have been addressed, and the series is now cooking in Junio’s `next` branch.
