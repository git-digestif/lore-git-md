Thread identity: Performance optimization for `git ls-files` to reuse the untracked cache populated by `git status`. Two-patch series by Tamir Duberstein (v1).

Core problem or goal: Reduce directory traversal overhead in `git ls-files` by reusing the untracked cache, which is already populated by `git status`. The series first fixes a bug causing unnecessary cache invalidation (patch 1) and then implements cache reuse while preserving correctness for pathspecs and exclude patterns (patch 2).

Current status: Under review. No prior versions. The series is self-contained and does not modify the on-disk cache format or index state.

Key technical details:
- **Files touched**: `dir.c` (core directory traversal), `builtin/ls-files.c` (command implementation).
- **New symbols**: `untracked_cache_expand` flag in `struct dir_struct`.
- **New tests**: Performance tests in `t/perf/p3010-ls-files.sh` and regression tests in `t/t7063-status-untracked-cache.sh`.
- **Behavior changes**:
  - Patch 1: Fixes ignore-file hash computation by moving it *before* a trailing linefeed is added, ensuring consistent hashes for unchanged ignore files. This prevents spurious untracked cache invalidation. The change is confined to `dir.c` and updates test expectations in `t/t7063-status-untracked-cache.sh`.
  - Patch 2: Teaches `git ls-files` to reuse the untracked cache by expanding collapsed directories and filtering cached listings on demand. The expanded cache is *not* written back to the index. The implementation skips directory pruning for simple wildcard queries (no attribute/exclude magic) and filters results in memory, preserving correctness for complex pathspecs. Synthetic benchmarks show a 7× speedup (361 ms → 50 ms) on a tree with 100 k tracked files and a 2× improvement (659 ms → 339 ms) on mixed workloads. Literal queries show no regression.
- **Performance impact**: Patch 1 reduces cache invalidation frequency; patch 2 delivers the primary speedup. The impact of patch 1 alone is not quantified in real-world workflows but is expected to be positive.
