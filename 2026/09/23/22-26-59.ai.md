This is the second patch in Tamir Duberstein’s three-patch performance series. It removes the long-standing limitation that `git status -unormal` (stop after first untracked file) and `git status -uall` (list all untracked files) cannot share the same untracked cache. The patch introduces a new `dir_flags` value (`UNTRACKED_CACHE_LAZY`) that lets older Git versions rebuild the cache before using it, while retaining `DIR_SHOW_OTHER_DIRECTORIES` so index updates still invalidate parent directories. The core change is to record incomplete scans with the `check_only` bit and rescan directories on demand when all untracked files are requested. The implementation also refactors `read_directory_recursive()` to handle cached directories, and updates the test suite to verify that partial listings are expanded correctly and that nested repository changes do not corrupt the cache. No on-disk format changes are made, and the patch is backward-compatible.
