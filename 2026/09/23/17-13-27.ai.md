This is a two-patch CI/build system series from Tamir Duberstein targeting resource exhaustion in GitHub Actions CI jobs that run the full test suite on Linux.

The series addresses two specific pain points: (1) the `t4205-log-pretty-formats.sh` test generates enormous output that triggers OOM kills when `diff` tries to compare it, and (2) the default `make` and `prove` parallelism is too aggressive for the Linux runner’s available CPU cores, leading to ENOSPC errors during large clone/repack tests. Patch 1 replaces the `diff` call with a lightweight `cmp` and deletes the temporary files immediately after use; patch 2 dynamically sets `-j` to the runner’s CPU count, matching the policy already in place for GitLab CI.

The changes are minimal (6 insertions, 1 deletion) and keep the long-running test cases enabled rather than disabling them. The commit message notes that both patches were prepared and reviewed by Codex agents, but the technical rationale is clear and the adjustments are straightforward. No controversy is evident; this looks like a pragmatic fix for a real CI bottleneck.
