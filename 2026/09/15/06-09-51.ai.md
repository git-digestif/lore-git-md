This is the third patch in SZEDER Gábor’s four-patch series introducing precompiled headers for `git-compat-util.h` to speed up Git builds. The patch is purely mechanical and restores the `REFTABLE_OBJS` Makefile variable, which was removed in 2025 when the static `REFTABLE_LIB` was deleted. The goal here is to isolate reftable object files—except `reftable/system.c`—from precompiled-header processing, since those files deliberately avoid including `git-compat-util.h` to maintain embeddability in other projects.

The change moves all reftable object files from `LIB_OBJS` to `REFTABLE_OBJS` and then adds `REFTABLE_OBJS` back to `LIB_OBJS`, preserving the final link. The CMake build system is updated to parse `REFTABLE_OBJS` and include those sources in the `libgit` target. The commit message now leads with the series’ overall goal (precompiling `git-compat-util.h`), followed by the exclusion rationale and the mechanical change, addressing Junio C Hamano’s editorial feedback from v1.

No runtime behavior changes are introduced, and the patch is unlikely to be controversial. The main open question is whether the CMake adjustments—particularly the parsing of `REFTABLE_OBJS`—work correctly across platforms, but the author has flagged this as needing review from Windows/CMake builders. The patch is a prerequisite for the final precompiled-header implementation in patch 4/4.
