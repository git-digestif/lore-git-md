This is the final combined patch for the `http.sslVerifyStatus` security feature, now ready for merge to `master`. The patch adds a boolean configuration option (`http.sslVerifyStatus`, default `false`) that enables OCSP staple validation via libcurl’s `CURLOPT_SSL_VERIFYSTATUS`. When enabled, Git will reject HTTPS connections if the server does not provide a valid OCSP staple, closing a security gap where revoked certificates are currently accepted (notably affecting government and FIPS-compliant users, such as US DoD PKI deployments).

The v7 iteration merges the author’s original tests (covering fail-closed behavior, per-URL scoping, and edge cases in `t5551-http-fetch-smart.sh`) with Patrick Steinhardt’s OCSP test harness (now in `t5585-http-ssl-ocsp.sh`), which exercises success and failure paths for stapled responses. The `lib-httpd.sh` script gains an opt-in `LIB_HTTPD_OCSP` mode to support the new tests, including a certificate authority, OCSP responder, and Apache configuration for stapling. The `SSL_VERIFYSTATUS` prerequisite is now shared between both test files, and the Meson build is updated to include the new test script.

Key files touched: `http.c` (new config key and libcurl option), `Documentation/config/http.adoc` (user-facing documentation), `t/lib-httpd.sh` (OCSP infrastructure), `t/lib-httpd/apache.conf` (Apache stapling config), `t/t5551-http-fetch-smart.sh` (fail-closed and per-URL tests), and `t/t5585-http-ssl-ocsp.sh` (staple validation tests). The patch defaults to `false` to avoid breaking remotes that do not support stapling, but the fail-closed design ensures security when enabled. Error messages include libcurl error strings to distinguish missing features from other failures.

Junio C Hamano and Patrick Steinhardt have both confirmed the patch is technically complete, with no remaining procedural or test-coverage concerns. The patch is currently in `next` and awaits Junio’s merge action to graduate to `master`. The only open discussion points—whether the default should eventually change to `true` or if users should be warned when staples are ignored—are forward-looking and do not block this merge.
