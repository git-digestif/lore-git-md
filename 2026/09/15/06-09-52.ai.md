This is the final patch in SZEDER Gábor’s **build system** series (v2) that implements precompiled headers for `git-compat-util.h` to speed up Git builds. The patch introduces the core Makefile logic for generating and using the precompiled header (`tools/precompiled.h.gch`), including dependency tracking, exclusion rules, and a `NO_PRECOMPILED_HEADER` knob for disabling the feature.

The patch is mechanical and self-contained, touching only the `Makefile` and `.gitignore`. It defines `PRECOMPILED_HEADER_USERS` to include all object files except those in `COMPAT_OBJS`, `REFTABLE_OBJS`, and `THIRD_PARTY_SOURCES` (which avoid including `git-compat-util.h` for embeddability or compatibility reasons). The precompiled header is generated once per build, and object files in `PRECOMPILED_HEADER_USERS` are compiled with `-include tools/precompiled.h` and `-Winvalid-pch` to enforce correctness. The author notes that finer-grained exclusion logic (e.g., `_NOPCH` variants) was explored but abandoned due to minimal performance gains (1% speedup).

The patch includes a benchmark showing a **35% reduction in build time** (29.4s → 21.7s with `-j12`), though the measurement is anecdotal and lacks CI validation. The commit message thoroughly documents edge cases, such as the interaction between target-specific `EXTRA_CPPFLAGS` and `-Winvalid-pch`, and explains why the `.gch` suffix is hardcoded (for GCC/Clang compatibility). The `NO_PRECOMPILED_HEADER` knob allows testing or disabling the feature if needed.

This patch is unlikely to be controversial, but the lack of detailed benchmarks or cross-platform testing (e.g., Windows/CMake) may prompt follow-up discussion. The series as a whole is a build-time optimization with no runtime behavior changes, and this patch completes the implementation. Key files: `Makefile` (rules for precompilation, dependency tracking) and `.gitignore` (to exclude `tools/precompiled.h.gch`). The patch builds on prior Meson support for precompiled headers but is independent of other ongoing efforts.
