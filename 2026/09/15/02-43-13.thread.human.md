This thread is about a small but practical improvement to `git-contacts`, a contrib script that extracts likely reviewers from patch metadata. Brigham Campbell proposed allowing the script to read patch content from stdin when no arguments are given and stdin isn't a terminal, making it easier to integrate with external tools like `b4`. Junio C Hamano reviewed the initial patch and requested minor stylistic tweaks—adjusting the argument-handling logic, updating the usage comment, and cleaning up commit message trailers—while endorsing the feature itself.

Brigham has now posted a v2 that incorporates all of Junio's feedback. The patch remains narrowly focused, touching only the `git-contacts` script and reusing existing helper functions without introducing new CLI options or on-disk changes. The motivation is cross-project: this change enables `b4` to automatically determine patch recipients, though the `b4` integration itself will wait for a bug-fix release. With the stylistic adjustments addressed, the patch appears ready for merging unless new concerns arise. No functional objections have been raised so far.
