This thread began with Brigham Campbell’s patch to extend `git-contacts` (a contrib Perl script) so it can read patch content from stdin using the conventional `-` idiom, enabling mixed file/stdin usage like `git contacts patch1 - patch3 <patch2`. After four iterations the feature itself was merged, and the thread now continues with Junio’s follow-up patch to document the new behavior.

The documentation update is a two-line addition to `contrib/contacts/git-contacts.adoc` that explains how a single dash `'-'` in place of a `<patch>` argument tells the command to read from stdin. Junio’s patch is uncontroversial and ready to apply; the only minor question he raised—whether `scan_patches()` can handle multiple concatenated patches from stdin—does not block this update and can be addressed later if needed.
