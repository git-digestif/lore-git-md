This thread began with Brigham Campbell’s patch to extend `git-contacts` (a contrib Perl script) to read patch input from stdin using the conventional `-` idiom, enabling mixed file/stdin usage like `git contacts patch1 - patch3 <patch2`. The feature, motivated by interoperability with tools such as `b4`, was merged to `master` in its fourth iteration. The current follow-up is a two-patch series from Brigham: a re-send of the unchanged merged feature (for context) and a documentation update adding a sentence to `git-contacts.adoc` to explain the new behavior.

This is a minor procedural observation; the documentation patch itself remains uncontroversial and ready to apply. The feature supports mbox-separated concatenated patches via `From ` headers, though the documentation phrasing ("A single dash `'-'` reads a patch from the standard input") keeps it singular for clarity. No further discussion or changes are expected—this thread is effectively closed.
