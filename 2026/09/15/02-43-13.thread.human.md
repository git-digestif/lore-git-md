This thread began as a feature patch to extend `git-contacts` (a contrib Perl script) to read patch content from stdin using the conventional `-` idiom, enabling mixed file/stdin usage like `git contacts patch1 - patch3 <patch2`. The feature itself was merged to `master` some time ago, but the follow-up work to document the new behavior and update the script's internal usage comment has now been finalized.

Brigham Campbell, the author, initially submitted the feature across four versions, incorporating feedback from Junio Hamano on style and the `-` idiom. After the feature was merged, Brigham sent a two-patch v5 series to add documentation and update the internal usage comment, addressing Junio's observation that these should ideally have been part of the original submission. Junio also noted the usage comment should explicitly include `-` as a valid option. The v6 update consolidates all changes into a single commit, corrects the usage comment to `usage: git contacts ['-'] <file>...`, and expands the documentation to clarify that the feature supports multiple patches from stdin via mbox `From ` headers.

Junio has now accepted the v6 update, replacing the previous version in his queue and marking the topic for the `next` branch, where it will undergo integration testing. The update is uncontroversial and expected to graduate to `master` after cooking in `next`. No further discussion or changes are anticipated.
