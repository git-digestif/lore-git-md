This thread is about a small but useful enhancement to `git-contacts`, a contrib script that helps identify people likely to be interested in a patch. The feature, now in its sixth iteration, allows the script to read patch content from stdin when the user passes a single dash (`-`) as an argument, enabling mixed file/stdin usage like `git contacts patch1 - patch3 <patch2`. This was originally implemented in v4 and merged to `master`, but the documentation and internal usage comment updates were handled separately in follow-up patches.

Brigham Campbell, the author, has now rolled everything into a single v6 patch that updates the script’s internal usage comment to include `'-'` as a valid input option and expands the documentation to clarify that the feature supports multiple patches from stdin via mbox `From ` headers. Junio Hamano, the maintainer, had previously noted that the feature and its documentation should ideally have been submitted together and that the usage comment should reflect the new behavior. This final update addresses those points and is uncontroversial, ready to apply.

The change is minor but practical, improving interoperability with tools like `b4` while maintaining backward compatibility. The implementation is straightforward, touching only the script and its man page, with no impact on core Git functionality. The thread is now effectively closed, with all feedback incorporated and the patch ready for merging.
