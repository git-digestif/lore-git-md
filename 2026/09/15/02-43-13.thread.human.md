This thread is about a small but useful improvement to `git-contacts`, a Perl script in `contrib/` that helps identify people to CC on patches. The goal is to let the script read patch content from stdin when no arguments are given, making it easier to use with tools like `b4`. Brigham Campbell posted a second version of the patch after Junio Hamano suggested minor stylistic tweaks—cleaner commit message trailers, a refactor of the argument-handling logic, and an update to the usage comment.

The feature itself is uncontroversial, and Junio has already endorsed the concept. The only open question is whether to adopt the conventional UNIX `-` idiom (where `-` as a filename argument means "read from stdin") instead of the current approach, which triggers stdin reading only when no arguments are supplied and stdin isn’t a terminal. Junio floated this as a possible refinement but didn’t insist on it, so the decision is Brigham’s. In his latest reply, Brigham said he’s happy to make the change if Junio prefers it, but otherwise he’s content to leave v2 as-is for further review. No other reviewers have chimed in, and there’s no pressure to revise unless Junio speaks up.
