This thread is about a small but useful improvement to `git-contacts`, a contrib script that helps identify people likely to be interested in a patch. The feature itself—allowing the script to read patch input from stdin using the conventional `-` idiom—was merged to `master` in its fourth iteration. Brigham Campbell, the author, has now sent a follow-up documentation patch to update `git-contacts.adoc` with a single sentence explaining the new behavior: "A single dash `'-'` reads patch file(s) from the standard input."

The documentation update is straightforward and uncontroversial. Junio Hamano, the maintainer, had previously noted a minor wording question about whether the documentation should reflect that the feature supports multiple concatenated patches from stdin (which it does, via `From ` headers), but the phrasing remains singular for clarity. The patch is part of a two-patch v5 series, where the first patch is a re-send of the already-merged feature for context. There are no open questions or objections, and the update is ready to apply. The feature improves interoperability with tools like `b4` and enables mixed file/stdin usage, such as `git contacts patch1 - patch3 <patch2`.
