This is a small feature patch for `git-contacts`, a contrib script that extracts likely reviewers from patch metadata.

The patch teaches `git-contacts` to read patch content from stdin when two conditions are met: stdin is not a terminal and no arguments are supplied. The change is a single conditional check (`-t STDIN`) and a call to the existing `scan_patches()` helper with the stdin filehandle. The commit message explains the motivation: better interoperability with other tools, specifically `b4`, which the author is also patching in a separate effort.

The patch is narrowly scoped, touches only the Perl script in `contrib/contacts/`, and does not alter any core Git behavior. It includes a link to the corresponding `b4` patch thread, making the cross-project context explicit. The author notes that this patch is useful on its own even if the follow-up `b4` integration is delayed. No test coverage is added, but the change is simple enough that the risk of regression appears low.
