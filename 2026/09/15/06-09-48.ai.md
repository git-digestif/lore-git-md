This is a **build system** patch series (v2) from SZEDER Gábor that introduces precompiled headers for `git-compat-util.h` to speed up Git builds. The series is now on its second iteration, with only a commit message update in patch 3/4 to address Junio C Hamano’s editorial feedback—no technical changes were made.

The goal remains unchanged: reduce build times by roughly 35% (measured anecdotally on the author’s setup) by precompiling `git-compat-util.h`, a header included by nearly every source file. The series is self-contained, touching only the `Makefile`, `contrib/buildsystems/CMakeLists.txt`, and `.gitignore`. The first two patches clean up obsolete or problematic build system logic (removing `XDIFF_OBJS` and generalizing CMake’s Makefile parsing), while the third reintroduces `REFTABLE_OBJS` to exclude reftable source files from precompilation (they avoid including `git-compat-util.h` for embeddability). The fourth patch implements the core precompilation logic, including dependency tracking and a `NO_PRECOMPILED_HEADER` knob for disabling the feature.

The v2 update is minor: patch 3’s commit message now leads with the series’ goal (precompiling `git-compat-util.h`) before explaining the reftable exclusion rationale, making the motivation clearer. The technical substance of the series is unchanged, and the patches remain mechanical and unlikely to be controversial. However, the lack of detailed benchmarks or CI validation for the 35% speedup claim may draw scrutiny, as might the CMake adjustments (particularly the regex-based generalization in patch 2 and the `REFTABLE_OBJS` parsing in patch 3). The author has already noted that finer-grained exclusion logic (e.g., `_NOPCH` variants) yields minimal performance gains and is not worth the added complexity.

Key files modified: `Makefile`, `contrib/buildsystems/CMakeLists.txt`, and `.gitignore` (to exclude the `.gch` artifact). The series is not part of any larger effort but builds on prior Meson support for precompiled headers. No runtime behavior changes are introduced.
