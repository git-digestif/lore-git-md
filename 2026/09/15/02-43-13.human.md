This is a small feature patch for `git-contacts`, a contrib script that extracts likely reviewers and maintainers from patch files.

The patch lets `git-contacts` read patch content from stdin when no arguments are given and stdin is not a terminal. The change is tiny (one line added, one condition tweaked) and the commit message explains the motivation: better interoperability with tools like `b4` that pipe mbox data. The author notes this is the first half of a two-patch series meant to automate recipient discovery in `b4`, but the second patch is blocked on an upstream `b4` fix, so this piece stands alone.

The patch itself looks clean and well-scoped. It touches only the Perl script in `contrib/contacts/`, adds no new dependencies, and preserves the existing error message when stdin is a terminal. No controversy is evident; this is a straightforward usability improvement.
