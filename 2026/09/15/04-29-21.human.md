This is a small feature patch for the `contrib/contacts/git-contacts` script, now under review after Junio C Hamano's feedback. The patch extends the script to read patch content from stdin when no arguments are provided and stdin is not a terminal, improving interoperability with tools like `b4`.

Junio's review is substantive but constructive. He points out that the original patch's approach—adding a second `if (!@ARGV)` check after processing `@ARGV`—breaks the script's established pattern of sifting `@ARGV` into meaningful variables (`@files`, `@rev_args`) before acting on them. His suggested alternative introduces a `$read_from_stdin` flag set during the initial argument processing, then uses that flag later to trigger the stdin read. This keeps the logic flow consistent with the rest of the script. He also notes that the usage comment at the top of the file should be updated to reflect the new stdin capability.

The patch remains narrowly scoped, touching only the Perl script and not altering core Git behavior. The risk of regression is low, but Junio's feedback highlights a design-level concern about code consistency that the author will need to address in a follow-up version. No test coverage has been added, and the updated usage comment will be a necessary part of any revised patch.
