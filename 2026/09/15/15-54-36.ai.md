While René notes this is a "quick fix" and suggests the optimization might be repairable, the patch itself is minimal and directly addresses the reported bug.

This suggests the bug is context-dependent, likely tied to how ignored directories are processed when a pathspec is provided. The patch touches `dir.c`, specifically the `treat_directory()` function, which handles directory traversal logic in `git status` and related commands.

No test case is included with the patch, but the original report's reproduction steps remain valid for verification. The change is narrowly scoped to the pathspec matching logic for ignored files, with no new symbols or on-disk format changes.
