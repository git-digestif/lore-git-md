This is a documentation update for the recently discussed `git-contacts` stdin feature. Junio provides a proposed patch to `contrib/contacts/git-contacts.adoc` that adds a single line explaining the new `-` idiom for reading patch content from stdin. The update mirrors the style of the existing documentation, using `<patch>` in angle brackets as a placeholder and clarifying that a single dash tells the command to read from stdin. Junio notes a minor uncertainty about whether `scan_patches()` can handle multiple concatenated patches from a single stdin stream, suggesting the wording could be adjusted to "patch file(s)" if that is supported, but leaves that refinement for later.

The patch is straightforward and uncontroversial, addressing the only remaining loose end from the v4 implementation: ensuring users can discover the new stdin functionality through the built-in documentation. No functional changes are involved, and the update is narrowly scoped to the AsciiDoc file. The author, Brigham Campbell, has not yet responded to this proposal, but the change aligns with the feature already implemented and reviewed in the thread. This is a final polish step before the feature can be considered complete.
