This is a documentation rewrite targeting the beginner tutorial (`gittutorial.adoc`). Julia Evans proposes replacing the existing tutorial with a completely new version that covers only a minimal subset of Git commands: `git init`, `git add`, `git commit`, `git status`, `git diff`, `git push`, `git config`, and `git remote add`. Notably, branches are omitted, with the intention of covering them in a separate follow-up tutorial.

The motivation is pedagogical: the current tutorial is seen as overwhelming for beginners, and feedback from test readers suggests that even the reduced command set is a lot to absorb. Julia includes positive testimonials from Jeff King (Peff), who found the draft easier to follow than other Git tutorials he has tried. The draft is available for review on her GitHub fork, though she is prioritizing feedback from actual Git beginners at this stage and is not yet seeking detailed technical or editorial comments.

The patch is still in the early drafting phase, and no formal patch series has been sent to the list yet. The email is essentially a heads-up to the community about the direction, inviting high-level objections but not detailed critique. If the current draft is any indication, the rewrite looks like a serious, well-motivated effort to improve Git’s onboarding experience.
