This is a CI/build system patch series from Tamir Duberstein, now in its second version, addressing resource exhaustion in GitHub Actions CI jobs. The series tackles two specific issues: a memory-hungry `diff` operation in the `t4205-log-pretty-formats.sh` test that triggers OOM kills, and overly aggressive parallelism in `make` and `prove` that causes ENOSPC errors on Linux runners with only 2 CPU cores.

Patch 1 replaces `test_cmp` (which uses `diff`) with `test_cmp_bin` (which uses `cmp`) in the problematic test. The change is well-motivated: benchmark data shows `diff` peaks at 4 GiB RSS and takes 5 seconds for a 2 GiB comparison, while `cmp` uses just 1.2 MiB and finishes in 0.5 seconds. The earlier attempt to delete temporary files immediately after comparison has been dropped as ineffective, simplifying the patch. Both Jeff King and Junio C Hamano have endorsed this approach as a reasonable, targeted fix for the edge case.

Patch 2 dynamically sets `-j` for `make` and `prove` to the runner’s CPU count on Linux, aligning GitHub Actions with GitLab CI’s existing policy. The revised patch unifies the logic for both CI platforms, addressing Patrick Steinhardt’s earlier concern about divergent configurations. Benchmark data shows a modest 2% speedup with `1x CPU count` and a 7% speedup with `2x CPU count` on Linux, but Tamir opts for the conservative `1x` baseline to ensure consistency across providers. The change is minimal—just four lines added to `ci/lib.sh`—and keeps long-running tests enabled rather than disabling them.

The series looks like a pragmatic fix for a real CI bottleneck. Patch 1 is effectively settled, with maintainer endorsement and no remaining objections. Patch 2 is technically sound but still open to discussion about whether oversubscribing (e.g., `2x CPU count`) might offer a better performance/resource trade-off. No controversy is evident, and the changes are straightforward and well-explained. If you care about CI reliability or test suite performance, this series is worth a quick look.
