This thread is about a two-patch series from Harald Nordgren that improves GitHub Actions CI failure reporting for Git. The series makes leak sanitizer failures and test failures easier to locate and debug by stopping test scripts at the first failure and annotating failures with the test script name, line number, and full sanitizer output.

The first patch, which stops leak-sanitizer scripts at the first failure and annotates leaks with the test script name and sanitizer output, has been cooking in `next` and is ready to graduate to `master`. The second patch, rewritten as a compromise after feedback, embeds file and line context directly in failure annotations as plain text (e.g., `failed: t1060.17 partial clone of corrupted repository (t1060-object-corruption.sh:141)`). This resolves an earlier regression where annotation links only worked if the test file was modified in the same pull request. Phillip Wood, the primary reviewer, has accepted the compromise, and Junio C Hamano has now marked the series as ready for `next`. Both patches are technically complete and under review, with no further iteration expected unless new issues emerge during integration testing.
