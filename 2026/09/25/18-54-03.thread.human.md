This thread is about improving Git’s GitHub Actions CI to make leak sanitizer and test failures easier to debug. Harald Nordgren’s v5 patch series (two patches) aimed to stop leak-sanitizer scripts at the first failure and annotate failures with clickable links to the exact line in the test script. The series was cooking in `next` but is now blocked by a critical usability regression: the annotation links only work if the test file was modified in the same pull request, otherwise they point to a broken or irrelevant location. Phillip Wood identified this issue and demonstrated it with live examples, making it the top priority to resolve.

Harald has iterated on feedback, splitting the series, improving commit messages, and fixing correctness issues, but he has not yet addressed the broken annotation links. Junio C Hamano previously approved the series for `next`, but graduation to `master` is on hold until the regression is fixed. Phillip Wood’s review is substantive and includes live GitHub URLs showing the problem, while D. Ben Knoble’s feedback was surface-level and partially addressed. Harald’s latest email acknowledges the regression and asks whether the current behavior (linking to job output) is better than the new, broken links, seeking directional feedback from Phillip.
