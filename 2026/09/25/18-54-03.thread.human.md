This thread is about improving Git’s GitHub Actions CI to make leak sanitizer and test failures easier to debug. Harald Nordgren’s two-patch series (now at v3) is cooking in `next` and addresses earlier feedback from Junio C Hamano and others. The first patch stops leak sanitizer runs at the first failure and annotates leaks with the test script name and full output in a collapsible log group; the second ensures regular test failures point to their exact file and line in the test script.

Harald has fixed all substantive issues raised in v2, including a bug where annotations were dropped when `--immediate` was used, a non-portable `\r` escape in `sed`, and inconsistent output redirection. Junio has marked the series as ready for `next`. Phillip Wood, while supportive of the improvement, has raised two remaining usability questions: whether the filename and line number annotations actually produce clickable links in the GitHub Actions UI (his testing suggests they don’t), and why test descriptions are selectively escaped while other annotation markers are not. These are not blocking concerns but could refine the feature before it graduates to `master`. The series is otherwise stable and actionable.
