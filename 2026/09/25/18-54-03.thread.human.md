This thread is about a two-part patch series from Harald Nordgren that improves GitHub Actions CI failure reporting for Git. The series, now at version 3, aims to make leak sanitizer and regular test failures more actionable by providing precise annotations in the GitHub UI.

The first patch stops leak sanitizer runs at the first failure and annotates leaks with the test script name and full sanitizer output in a collapsible log group. The second patch adds exact file-and-line annotations for regular test failures and fixed breakages. Harald has addressed all substantive feedback from earlier versions, including correctness and portability issues raised by Junio C Hamano, who has marked the series as ready for the `next` branch.

Phillip Wood's latest review raises three usability concerns about the second patch: the annotations don't produce clickable links in the GitHub UI as intended, the new escaping logic may be unnecessary, and the line-finding logic fails for dynamically generated test descriptions. These issues don't block the patch but could affect its effectiveness. The series is otherwise complete and cooking in `next`, with no remaining open questions beyond Phillip's feedback.
