This is the first patch in Tamir Duberstein’s v2 CI/build system series, addressing a specific resource exhaustion issue in GitHub Actions CI jobs. The patch replaces `test_cmp` (which uses `diff -u`) with `test_cmp_bin` (which uses `cmp`) in `t/t4205-log-pretty-formats.sh` to avoid OOM kills when comparing enormous test outputs. The change is narrowly targeted: the test only needs an equality check, and `cmp` is far more efficient for this purpose, using 1.2 MiB of memory and completing in 0.5 seconds compared to `diff`’s 4 GiB RSS and 5-second runtime.

The patch is effectively settled. Both Jeff King and Junio C Hamano have endorsed the approach, agreeing that `test_cmp_bin` is a sufficient and reasonable fix for this edge case. The v2 revision drops the early file deletion that was present in v1, as it provided negligible benefit and was deemed unnecessary. The change is minimal—just one line in a single test script—and does not affect test coverage or introduce new CLI options or on-disk formats.

This is a pragmatic, well-motivated fix that directly addresses the observed CI failure without over-engineering.
