This is a documentation rewrite targeting the Git tutorial (`gittutorial.adoc`). Junio C Hamano, the maintainer, responds to Julia Evans’s proposal to replace the existing tutorial with a completely new version that omits branches and defers them to a follow-up tutorial (`gittutorial-2.adoc`). Junio expresses enthusiasm for the direction but raises a structural concern: learners should not end up having to read three separate documents (the new tutorial, the old `gittutorial.adoc`, and `gittutorial-2.adoc`) to cover the same material. He asks for clarity on how the remaining topics from the current tutorial will be handled—whether they will be discarded, integrated into other parts of Git’s documentation, or left to external resources like books.

The email also references a consensus from the Git Contributor’s Summit: the project should move away from incrementally polishing the existing tutorial and instead encourage ground-up rewrites when needed. Junio’s response suggests he supports this approach and is open to Julia’s rewrite, provided the plan for covering the omitted material is clear. The tone is constructive and forward-looking, but the question about topic coverage remains open. No technical implementation details or patch review are involved yet—this is purely a design and scope discussion.
