Subject: [PATCH v2] ci: improve leak sanitizer failure reporting in GitHub Actions
Series version: v2 (two-patch series)
Originating author: Harald Nordgren
Thread type: patch (CI/build system improvement)

Core problem or goal
Git’s GitHub Actions CI buries leak sanitizer failures at the end of test runs, producing only a generic “Process completed with exit code 1” message. The series now splits the improvement into two focused commits: the first stops leak-sanitizer scripts at the first failure (using `--immediate`) and annotates leaks with the test script name and full sanitizer output in a collapsible log group; the second ensures regular test failures and fixed known breakages also point to their exact file and line in the test script. The goal remains to provide actionable failure annotations while balancing early failure (simpler debugging) and comprehensive reporting (catching all leaks), and to avoid unintended side effects on CI usability (e.g., scrolling behavior in the GitHub Actions UI).
