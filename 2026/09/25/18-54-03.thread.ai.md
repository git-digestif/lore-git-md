Subject: [PATCH] ci: improve leak sanitizer failure reporting in GitHub Actions
Series version: standalone patch (no series)
Originating author: Harald Nordgren
Thread type: patch (CI/build system improvement)

Core problem or goal
Git’s GitHub Actions CI currently buries leak sanitizer failures at the end of test runs, producing only a generic “Process completed with exit code 1” message. Reviewers cannot see which test case or line triggered the leak, making debugging difficult. The goal is to stop the test script at the first leak failure and emit GitHub Actions annotations that point directly to the failing test file and line, including the actual leak error message.
