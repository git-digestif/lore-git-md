## 2026/09/25

- [2026/09/25/20-56-32 by Royce Remer <royceremer@gmail.com>] Royce Remer submitted a patch series to register temporary pack files created by git-gc(1) and git-maintenance(1) with the tempfile subsystem so they are removed on graceful exit, citing disk space exhaustion in Kubernetes pods running Gitea git mirrors where killed gc processes left orphaned tmp_pack_* and .tmp-*-pack-* files accumulating to ~224 GiB.

## 2026/09/28

- [2026/09/28/07-58-41 by Patrick Steinhardt <ps@pks.im>] Patrick Steinhardt questioned whether the `odb_mkstemp()` interface is misdesigned given that the patch adds `register_tempfile()` calls to almost every callsite, suggesting it could instead return a `tempfile` directly; he also wondered whether `odb_mkstemp()` sits at the right level since it is specific to the "files" backend and assumes files live in "objects/", proposing it could instead become part of the "tempfile.h" API (e.g., via a "_d" suffix for `mks_tempfile()` functions) to support leading directories.
