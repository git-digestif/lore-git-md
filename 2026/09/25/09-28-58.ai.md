This is a **test-infrastructure follow-up** in the `http.sslVerifyStatus` security feature thread. SZEDER Gábor confirms Patrick Steinhardt’s diagnostic hypothesis: the test failure was caused by using the GnuTLS backend for libcurl, which does not fully support OCSP stapling. Switching to the OpenSSL backend resolves the issue, and the test suite now passes. The root cause is environmental (backend choice) rather than a flaw in the test logic or prerequisite. No changes to the core feature or test infrastructure are needed; the fix is purely a local configuration adjustment. The thread’s focus remains on post-merge test robustness, and this reply closes the open diagnostic question without introducing new technical concerns.
