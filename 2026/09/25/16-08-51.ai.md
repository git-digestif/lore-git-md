This is a documentation rewrite targeting the Git tutorial (`gittutorial.adoc`). Julia Evans proposes replacing the existing tutorial with a completely new version that covers a much smaller set of commands: `git init`, `git add`, `git commit`, `git status`, `git diff`, `git push`, `git config`, and `git remote add`. Notably, the new tutorial omits branches entirely, with the intention of covering them in a separate follow-up tutorial. The goal is to reduce cognitive load for beginners, and early feedback from test readers (including Jeff King) has been positive.

The draft is available in Julia’s GitHub fork, but she is not soliciting detailed feedback yet—only high-level objections to the structure. The patch series is still in the early stages, and Julia is prioritizing input from actual Git beginners. No technical implementation details or edge cases are discussed in this email; it is purely a design and scope proposal.

The thread is unrelated to the earlier documentation cross-reference modernization effort, though both are documentation improvements. This is a standalone initiative focused on pedagogy rather than markup or toolchain behavior. The patch, when sent, will likely be a single large commit replacing the entire file, rather than a series of incremental changes. No review or integration status is yet applicable.
