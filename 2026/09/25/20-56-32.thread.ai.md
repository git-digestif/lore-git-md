Thread identity: Bugfix patch series (single patch) addressing resource leaks in the packfile subsystem during `git gc` or `git maintenance` operations when processes are terminated (e.g., via SIGKILL). Originating author: Royce Remer. Thread type: bug report and fix.

Core problem or goal: Temporary pack files (e.g., `tmp_pack_XXXXXX`, `tmp_idx_XXXXXX`) created via `odb_mkstemp()` in `pack-write.c` and `pack-bitmap-write.c` are not registered with Git's tempfile subsystem. This causes them to be left behind if the process is killed, leading to disk space exhaustion in environments like Kubernetes pods running Gitea mirrors, where orphaned temp files can accumulate to hundreds of gigabytes. The goal is to ensure these temp files are automatically cleaned up on process exit, matching the existing behavior in `git repack`.
