This is a minor follow-up in the RFC patch series improving Git’s error reporting for invalid `--git-dir` directories. The author, Kaartic Sivaraam, responds to Junio C Hamano’s surface-level review of the second patch, which flagged inconsistent brace and indentation style in the newly added code. Kaartic proposes two indentation patterns—one for short error messages and another for longer ones—and asks Junio whether these align with the project’s conventions. The email is purely about code style; there are no changes to the patch’s functionality, error-message design, or test coverage. The series remains in the RFC phase, awaiting broader feedback on its direction before any further revisions.
