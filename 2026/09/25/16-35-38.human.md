This is the first patch in Tamir Duberstein’s v2 CI/build system series, targeting a specific resource exhaustion issue in GitHub Actions. The patch replaces `test_cmp` (which uses `diff`) with `test_cmp_bin` (which uses `cmp`) in `t/t4205-log-pretty-formats.sh` to avoid OOM kills when comparing enormous test outputs.

The problem is clear: a test generates a 2 GiB line, and `diff -u` consumes 4 GiB of memory to compare it, triggering OOM kills on GitHub’s Linux runners (which have half the memory of public runners). The fix is simple and well-justified—`cmp` uses only 1.2 MiB and finishes in 0.5 seconds, a 10x speedup and 3000x memory reduction. Benchmark data is provided, and the change is endorsed by both Jeff King and Junio C Hamano, who agree `test_cmp_bin` is sufficient for this edge case.

The patch itself is minimal: a one-line change in a single test script. No new CLI options, on-disk formats, or test coverage changes are introduced. The early file deletion proposed in v1 was dropped as unnecessary, and the commit message now omits the "Prepared with Codex" attribution. This patch is effectively settled and unlikely to be controversial—it’s a pragmatic, targeted fix for a real problem. If you care about CI stability or large-test performance, this is worth noting, but it’s not a high-drama change.
