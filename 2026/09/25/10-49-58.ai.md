This is a feature patch series (v3) implementing the `remote.<name>.refmap`-based "matching-inspired" fetch mode for shallow repositories. The series replaces the abandoned v2 `+:` refspec design with a cleaner approach that reuses Git’s existing refmap mechanism. It consists of four patches:

1. **Adds `remote.<name>.refmap` configuration** – extends the refmap mechanism to allow namespace mappings without specifying what to fetch.
2. **Infers branches to fetch from a refmap-only remote** – when no explicit refspec is given, `git fetch` now dynamically fetches only the branches tracked by local branches at the remote, plus the remote’s default branch (priming mechanism).
3. **Adds `git remote add --limited-fetch`** – a new flag to explicitly create a refmap-only remote.
4. **Defaults to `--limited-fetch` in shallow repositories** – `git remote add` now automatically uses the new mode when the repository is shallow, avoiding the performance pitfall of fetching all remote branches.

The implementation touches `builtin/fetch.c` (core fetch logic), `remote.c`/`remote.h` (refmap parsing and dynamic branch enumeration), and documentation. The new behavior is backward-compatible: non-shallow repositories continue using wildcard refspecs by default, and the feature is implicitly enabled only when `remote.<name>.refmap` is configured without `remote.<name>.fetch`.

Key technical details:
- **Dynamic branch selection**: The fetch logic enumerates branches tracked by local branches at the remote (via `@{upstream}`) and always includes the remote’s default branch (falling back to the local current branch if `HEAD` is stale or missing).
- **Refmap integration**: The refmap now serves dual purpose: it defines where fetched refs are stored *and* (when no fetch refspec is given) what to fetch.
- **Edge cases**: The series handles stale `HEAD` references, empty repositories, and multiple tracking branches, though some open questions remain (e.g., whether the mode should be available outside shallow repositories).
- **Test coverage**: New tests in `t/t5585-fetch-refmap.sh` verify the refmap configuration, dynamic branch enumeration, and edge cases.
