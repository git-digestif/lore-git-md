This is a CI/build system patch that tidies up Git's continuous integration scripts. The change stops spurious warnings about missing Perforce, Git LFS, and JGit on platforms where those tools are never installed.

The patch modifies `ci/install-dependencies.sh` to scope each "did it install?" check to only the platforms that actually attempt the install: Perforce is checked on Ubuntu and macOS runners, while Git LFS and JGit are checked only on Ubuntu. Every other platform (Debian, i386/Ubuntu, Alpine, Fedora, AlmaLinux) now skips the checks entirely, so a warning will only appear if an install genuinely failed.

The diff is straightforward: the three global `if` blocks are replaced with `case` statements that match the relevant platform patterns. The commit message explains the motivation clearly and the code change is small and mechanical. No controversy is evident; this looks like a sensible cleanup.
