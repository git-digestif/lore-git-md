This is the first patch in a three-part documentation series that tightens AsciiDoc linting rules for the Git man pages. The patch modifies `lint-documentation-style.perl` so that the script now flags unquoted commands (e.g., `migrate::`) in synopsis-style blocks, not just unquoted options (e.g., `--option::`). The change is a single regex tweak that drops the leading-dash requirement and tightens the pattern to avoid false matches on `linkgit:` lines. It’s a small, mechanical update that aligns the linter with the project’s established documentation conventions and prepares the ground for the next two patches, which will actually fix the quoting in the affected man pages.
