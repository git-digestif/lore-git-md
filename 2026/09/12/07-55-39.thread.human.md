This thread is about a small but practical cleanup to Git’s macOS CI setup. Harald Nordgren sent a patch (v2) that removes a now-redundant `brew link --force gettext` command from the GitHub Actions dependency script. The command was originally added because gettext was a keg-only Homebrew formula, but a 2020 policy change made it link automatically on fresh installs. The patch’s goal is to eliminate spurious “Already linked” warnings in every macOS CI job log while keeping gettext available in the system path.

The patch touches only `ci/install-dependencies.sh` and is specific to GitHub CI builds—it doesn’t affect local macOS development. After some back-and-forth in v1 about whether the change was still needed, Harald provided a passing macOS CI pipeline as proof that the patch works as intended. Junio C Hamano’s question about the patch’s relevance was resolved by clarifying its scope, and Patrick Steinhardt’s request for empirical evidence has now been satisfied. No technical objections remain, and the patch is ready for final review. Unless new concerns surface, it’s likely to be merged soon.
