This thread is about a small but practical cleanup to Git’s macOS CI setup. Harald Nordgren sent a patch (v2) that removes a redundant `brew link --force gettext` command from the GitHub Actions dependency script. The command was originally needed because gettext was a keg-only Homebrew formula, but a 2020 policy change made it link automatically on fresh installs, so the `--force` is now just noise in the logs.

The patch is ready to go. Junio asked whether it’s still relevant, and Harald clarified it’s only for CI builds, not local development. Patrick Steinhardt had asked for proof the change works, and Harald provided links to passing CI pipelines on both GitHub Actions and GitLab CI. Patrick has now seen the v2 patch and confirmed he’s replied, so the last procedural step is complete. There are no open objections, and the patch should move to `next` soon.
