This thread is about a small but practical cleanup to Git’s macOS CI setup. Harald Nordgren sent a patch (v2) that removes a now-redundant `brew link --force gettext` command from the CI dependency installation script. The command was originally added because gettext was a keg-only Homebrew formula, but a 2020 policy change made it automatically linked on fresh installs, so the `--force` is no longer needed. The patch eliminates spurious "Already linked" warnings in every macOS CI job log.

The patch has been through one round of review. Patrick Steinhardt initially asked for empirical evidence and historical context, both of which Harald provided—first with a CI pipeline link (though the macOS job was skipped) and later with a clear explanation of the Homebrew policy change. In the latest email, Harald clarified that the change is specifically for GitHub CI builds, not local macOS development, addressing Junio C Hamano’s question about whether the patch is still relevant. With all feedback addressed and no remaining objections, the patch is now ready for final review and likely to proceed unless new concerns arise. The change is minimal, safe, and validated by a passing CI pipeline.
