This thread is about a small but practical cleanup to Git’s macOS CI setup. Harald Nordgren sent a patch (v2) that removes a now-redundant `brew link --force gettext` command from the dependency installation script. The command was originally added because Homebrew’s gettext formula used to be "keg-only" (not symlinked into the system path by default), but a 2020 policy change made it link automatically on fresh installs. The patch eliminates spurious "Already linked" warnings in every macOS CI job log while ensuring gettext remains available.

The patch has been through one round of review. Patrick Steinhardt, the only substantive reviewer, initially asked for two things: an explanation of why the command was originally needed and proof that removing it wouldn’t break anything. Harald addressed both in v2—adding the historical context to the commit message and providing a link to a passing macOS CI pipeline that confirms the patch works. Junio’s recent email checks whether the patch is still relevant, but the thread context shows all feedback has been resolved and no objections remain. The change is minimal (one line deleted in `ci/install-dependencies.sh`) and has no impact beyond reducing log noise. It’s now ready for final review and likely to be merged unless new concerns surface.
