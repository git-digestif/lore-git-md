Core problem or goal
Reduce noise in GitHub Actions CI logs by restricting "missing tool" warnings for Perforce, Git LFS, and JGit to only those platforms that actually attempt to install them. Currently every CI job emits warnings even when the tools are not expected on that platform (e.g., Alpine, Fedora, i386/ubuntu).

Under review; no prior versions.

Key technical details
- File touched: `ci/install-dependencies.sh`
- New behavior: warnings are scoped to platform-specific `case` blocks (ubuntu-* for all three tools, macos-* additionally for Perforce)
- No functional change; only log verbosity is affected
- Symbols: none (script-only change)
