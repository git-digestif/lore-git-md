Subject: [PATCH] ci: silence "missing tool" warnings on irrelevant platforms
Series version: standalone patch
Originating author: Harald Nordgren
Thread type: patch (build system / CI)

Core problem or goal
Reduce noise in GitHub Actions CI logs by restricting "missing tool" warnings for Perforce, Git LFS, and JGit to only those platforms that actually attempt to install them. Currently every CI job emits warnings even when the tools are not expected on that platform (e.g., Alpine, Fedora, i386/ubuntu).

Current status
Under review; no prior versions. Junio considers the trade-off (reduced log noise vs. slightly increased maintenance burden for future platform additions) reasonable and invites a second review.

Key technical details
- File touched: `ci/install-dependencies.sh`
- New behavior: warnings are scoped to platform-specific `case` blocks (ubuntu-* for all three tools, macos-* additionally for Perforce)
- No functional change; only log verbosity is affected
- Symbols: none (script-only change)

Open questions and loose ends
- Maintenance burden: future platform additions that require Perforce, Git LFS, or JGit must remember to update the `case` blocks in `ci/install-dependencies.sh` to avoid silent skips instead of warnings.

Participant positions
- **Junio C Hamano**: reviewed the patch, considers the trade-off reasonable, and invites a second review. Notes the risk of silent skips on new platforms but deems it low.
