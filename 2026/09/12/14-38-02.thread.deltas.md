# Thread deltas

## 2026/09/12

- [2026/09/12/14-38-02 by Harald Nordgren via GitGitGadget <gitgitgadget@gmail.com>] Harald Nordgren submitted a patch to `ci/install-dependencies.sh` scoping the perforce, git-lfs, and JGit presence checks to only the platforms that attempt to install them (ubuntu-* for all three, plus macos-* for perforce), because these tools test git's own interop code rather than platform-specific behavior and other platforms (debian, i386/ubuntu, alpine, fedora, almalinux) never install them yet were warning anyway; published as PR #2403.
