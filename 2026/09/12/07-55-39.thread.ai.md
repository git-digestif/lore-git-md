Core problem or goal
Remove a redundant `brew link --force gettext` command from the macOS CI dependency installation script (`ci/install-dependencies.sh`). The command was added to ensure gettext (a keg-only Homebrew formula) is symlinked into the system path, but a Homebrew policy change in 2020 made gettext no longer keg-only, so a fresh install now automatically links it. The goal is to reduce log noise (spurious “Already linked” warnings in every macOS job log) while ensuring gettext remains correctly exposed in the system path.
