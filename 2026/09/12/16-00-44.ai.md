This is the first patch in Souma's v3 series teaching `git history` to sign rewritten commits. It is a refactoring patch that extends the replay API (`replay.c` and `replay.h`) to accept a signing key parameter.

The patch adds a `sign_commit` field to the `replay_revisions_options` struct and threads it through the commit-creation call chain: `pick_regular_commit` -> `create_commit` -> `commit_tree_extended`. The plumbing is mechanical and does not change behavior yet; the actual signing logic will be wired up in the next patch. The commit message is concise and the diff is clean, addressing all prior review feedback about parameter ordering and callback placement. No new tests or documentation are added here; those appear in patch 2/2. The patch is ready for integration once the series as a whole is approved.
