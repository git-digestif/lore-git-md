This thread is about a small but practical improvement to Git's CI setup: silencing "missing tool" warnings for Perforce, Git LFS, and JGit on platforms where those tools aren't needed. The patch, now in its second version, takes a strict approach—if a tool is required for a platform, its installation must succeed, or the build fails immediately. This replaces the original version, which allowed silent skips and generated noisy warnings.

The discussion is effectively settled on the technical direction. Harald Nordgren implemented the stricter approach after Patrick Steinhardt argued that optional tools risked silent test skips. Junio C Hamano reviewed both versions, found no technical objections, and confirmed the patch aligns with the agreed design. However, Junio clarified in the latest email that his review wasn't a full endorsement—just an absence of objections—and the patch still needs a "real positive review" from another contributor before it can move forward. No one has raised new concerns, and the patch itself is uncontroversial, but it remains in the review queue awaiting that final sign-off.
