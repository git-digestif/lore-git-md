This thread is about a patch from Harald Nordgren that reduces noise in GitHub Actions CI logs by silencing "missing tool" warnings for Perforce, Git LFS, and JGit on platforms where they aren’t expected (e.g., Alpine or Fedora). The patch modifies `ci/install-dependencies.sh` to scope warnings to platform-specific blocks, avoiding false positives.

Junio initially reviewed the patch favorably, calling the trade-off between reduced log noise and future maintenance burden reasonable. However, Patrick Steinhardt has now raised a fundamental objection: he argues the warnings shouldn’t exist at all. Instead, he proposes that tools required for a platform should be mandatory, causing the build to fail if they can’t be installed. This would make failures explicit and eliminate the need for warnings entirely. The discussion now hinges on whether the project prefers strict failure (Patrick’s approach) or permissive skipping (Harald’s current patch). No decisions have been made yet, and the thread remains under review.
