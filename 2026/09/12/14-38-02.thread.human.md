This thread is about a small but practical improvement to Git's CI setup. Harald Nordgren originally proposed a patch to quiet "missing tool" warnings in GitHub Actions for tools like Perforce, Git LFS, and JGit on platforms where they aren't needed. After some discussion, the consensus shifted toward a stricter approach: if a platform *does* require one of these tools, the build should fail immediately if installation fails, rather than allowing silent skips or warnings. The updated patch (v2) implements this stricter rule, and Junio C Hamano has reviewed it without raising further objections.

The change is straightforward—it modifies `ci/install-dependencies.sh` to enforce mandatory installation of required tools on the relevant platforms (Ubuntu for all three, macOS for Perforce) and prints version confirmations after successful installation. The only minor quirk is that on macOS, the `xattr` step for Perforce is allowed to fail silently, while the `tar` extraction is not, but this was left as-is for simplicity. The patch is now ready for final review and appears uncontroversial. No open questions remain, though future platform additions will need to update the installation logic to avoid build failures.
