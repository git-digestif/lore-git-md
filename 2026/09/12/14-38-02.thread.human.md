This thread began with Harald Nordgren’s patch to reduce CI log noise by restricting "missing tool" warnings for Perforce, Git LFS, and JGit to only the platforms that attempt to install them. Junio Hamano reviewed the patch favorably, accepting the trade-off between reduced noise and the risk of silent test skips on future platforms, but Patrick Steinhardt challenged the premise, arguing that optional tools create a risk of silent test skips and proposing instead that tools required for a platform should be mandatory, causing the build to fail if installation fails.

The discussion has now shifted decisively: Harald agrees with Patrick’s stricter approach, effectively superseding his original patch. The thread’s central question—whether CI should allow optional tools to be skipped with warnings or enforce mandatory installation—is resolved in favor of strictness. The next step will likely be a follow-up patch modifying `ci/install-dependencies.sh` to replace conditional tool installation with mandatory checks, scoped to the same platform-specific blocks (ubuntu-* for all three tools, macos-* for Perforce). This change will eliminate warnings entirely by making failures explicit, shifting the maintenance burden from updating warning scopes to ensuring new platforms requiring these tools are explicitly listed in the installation logic. No functional changes to Git itself are involved; the impact remains confined to CI behavior.
