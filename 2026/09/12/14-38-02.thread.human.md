This thread is about reducing noise in GitHub Actions CI logs by making tool installation (Perforce, Git LFS, JGit) mandatory on platforms where they are required, rather than allowing silent skips or warnings. The discussion has settled on a stricter approach: if a tool fails to install on a platform that needs it, the build fails immediately.

The current v2 patch implements this stricter behavior and is under review. While Junio C Hamano and Patrick Steinhardt have both confirmed the patch aligns with the agreed direction, it still lacks a formal positive review (Reviewed-by or Acked-by) from another contributor. A minor cleanup—removing an unnecessary macOS `xattr` step for Perforce installation—has been proposed as a preparatory v3 patch, as the step is a no-op. Patrick Steinhardt supports this change, which will be tested on GitLab CI before submission, but it doesn’t block the v2 patch’s progress. The thread’s core goal is now resolved, with the v2 patch ready for final review.
