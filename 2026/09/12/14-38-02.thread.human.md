This thread is about a small but important cleanup in Git's CI system. Harald Nordgren's patch (now at v2) makes sure that GitHub Actions builds fail immediately if required tools like Perforce, Git LFS, or JGit can't be installed on the platforms that need them—rather than silently skipping tests or flooding logs with warnings. The core debate is settled: the project wants strict enforcement, not optional tools.

The patch itself is ready. Patrick Steinhardt, who originally pushed for the stricter approach, has reviewed it and confirmed it works as intended. Junio Hamano has no objections but won't merge it without a formal "Reviewed-by" from someone else. The only loose end is that minor redundancy in error handling (the patch's checks duplicate `set -e` in the CI scripts) was noted but deemed harmless. No further changes are needed—just a final sign-off from another contributor to move it forward.
