This thread began with Harald Nordgren’s patch to quiet "missing tool" warnings in GitHub Actions CI by restricting them to platforms that actually need Perforce, Git LFS, or JGit. The discussion quickly shifted when Patrick Steinhardt argued that optional tools risk silent test skips and proposed a stricter approach: tools required for a platform must install successfully or the build fails. Harald agreed, withdrew the original patch, and has now posted a follow-up that implements the stricter policy.

The new patch modifies `ci/install-dependencies.sh` to make Perforce, Git LFS, and JGit installation mandatory on ubuntu-* (all three) and macos-* (Perforce). If any tool fails to install, the script prints an error and exits, causing the CI job to fail immediately. The final presence checks and warnings are gone, replaced by inline version output after each successful install. Junio reviewed the original patch and found the trade-off reasonable but did not object to the stricter direction; Patrick’s position now carries the thread. No further objections or open questions remain, and the patch is ready for final review.
