This thread is about a two-patch series improving Git's CI setup by reducing log noise from missing tools. The series, now at version 3, makes Perforce, Git LFS, and JGit installation mandatory on platforms where they're required, causing builds to fail immediately if installation fails rather than allowing silent skips or warnings.

The first patch—a preparatory cleanup—removes an unnecessary macOS `xattr` step for Perforce binaries, which was confirmed safe via GitLab CI testing. This patch is nearly ready for final review, pending minor commit message tweaks requested by Patrick Steinhardt. The second patch, implementing stricter tool installation behavior, remains ready for review as previously described. Both patches lack an explicit Reviewed-by or Acked-by from a contributor other than Junio or Patrick, though neither has raised technical objections. Harald Nordgren, the author, has addressed all feedback and considers the series ready for final sign-off once the commit message is polished. The only remaining loose end is a stylistic question about redundant `&&` chains in the script, which Harald plans to address in a future iteration.
