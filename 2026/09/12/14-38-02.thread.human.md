This thread is about a two-patch series (v3) by Harald Nordgren that tightens GitHub Actions CI behavior to reduce log noise and fail fast when required tools (Perforce, Git LFS, JGit) are missing. The series is now under final review after resolving the core debate in favor of strictness: tools must install successfully on platforms that need them, or the build fails immediately.

The first patch removed a macOS-specific `xattr` step that had been a silent no-op for years, while the second (just posted) implements the stricter consensus by removing redundant error-handling logic and warnings, relying instead on `set -e` to abort on the first failed install. This matches how other install steps already work and simplifies the script by 19 lines. The change is confined to `ci/install-dependencies.sh` and doesn’t affect Git’s functionality.

Junio C Hamano and Patrick Steinhardt have both reviewed the series and agree with the direction, but neither has provided a formal Reviewed-by or Acked-by. The series is now ready for a final positive sign-off from another contributor before it can be merged.
