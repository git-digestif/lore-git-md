This thread is about a small but practical improvement to Git's CI system. Harald Nordgren sent a patch that cuts down on noise in GitHub Actions logs by making "missing tool" warnings for Perforce, Git LFS, and JGit appear only on the platforms where those tools are actually supposed to be installed (Ubuntu and macOS for Perforce, Ubuntu only for the others). Right now, every CI job—even those on Alpine, Fedora, or i386/ubuntu—shows these warnings, even though the tools were never meant for those platforms.

The change itself is simple: it moves the existing tool checks into platform-specific `case` blocks in `ci/install-dependencies.sh`. No behavior changes, just fewer false positives in the logs. So far, there’s been no review traffic on the list, so the patch is still waiting for feedback. If it gets a thumbs-up, it’ll be a quick win for anyone reading CI output.
