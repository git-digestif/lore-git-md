This thread is about a small but persistent CI annoyance: GitHub Actions logs cluttered with warnings about missing Perforce, Git LFS, or JGit tools on platforms where those tools aren’t actually needed. Harald Nordgren’s patch (now at v2) takes a strict approach—if a tool is required for a platform, its installation must succeed, or the build fails immediately. The patch itself is ready: it implements the agreed behavior, has no technical blockers, and only needs a formal Reviewed-by or Acked-by from someone other than Junio or Patrick Steinhardt to move forward.

The discussion has now circled back to a minor cleanup: the macOS Perforce installation includes an `xattr` step that’s always a no-op (the quarantine attribute it tries to remove is never set by the download tools). Harald proposes removing it in a v3 patch, which would simplify the script and eliminate the need for the `|| true` workaround. This change is uncontroversial and aligns with Patrick’s earlier suggestion, but it’s not urgent—the v2 patch can land as-is. The only real blocker remains the missing formal review.
