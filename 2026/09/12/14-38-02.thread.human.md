This thread is about a small but practical improvement to Git's CI infrastructure. Harald Nordgren proposed a patch to reduce log noise in GitHub Actions by restricting "missing tool" warnings for Perforce, Git LFS, and JGit to only the platforms that actually attempt to install them. Currently, every CI job emits these warnings, even on platforms like Alpine or Fedora where the tools aren't expected.

Junio C Hamano reviewed the patch and found the trade-off reasonable: while the change makes CI logs cleaner, it could make future platform additions slightly harder to notice since warnings will now be silenced on platforms that don't currently install these tools. However, the risk is low—tests requiring these tools will skip rather than fail—and the maintenance burden is minimal. The patch itself is a straightforward refactoring of `ci/install-dependencies.sh`, wrapping each tool check in platform-specific `case` blocks. No functional changes are introduced; only log verbosity is affected.

The patch is under review and appears likely to be accepted once a second review is completed. There are no open questions or objections so far, and the change is a clear quality-of-life improvement for CI log readability.
