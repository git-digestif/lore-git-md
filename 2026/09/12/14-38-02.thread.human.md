This thread is about a small but practical improvement to Git's GitHub Actions CI setup. Harald Nordgren proposed a patch to reduce log noise by ensuring warnings for missing tools (Perforce, Git LFS, JGit) only appear on platforms that actually need them. After discussion, the thread settled on a stricter approach: if a tool is required for a platform, the build should fail immediately if installation fails, rather than allowing silent skips.

The current patch (v2) implements this stricter behavior. It modifies `ci/install-dependencies.sh` to make tool installation mandatory on relevant platforms (Ubuntu for all three tools, macOS for Perforce), with clear error messages and version output for confirmation. Junio C Hamano reviewed the patch and found no objections but clarified that his feedback wasn't a full endorsement—it still needs a "real positive review" from another contributor. Patrick Steinhardt, who originally proposed the stricter approach, has now reviewed the patch, tested it, and confirmed it works as intended. His only minor question—whether the macOS `xattr` step should also be mandatory—was left to the author, who kept it optional for simplicity.

The patch is uncontroversial and ready for final review. No technical issues remain, and the only open step is securing that second review. Once that happens, it should be straightforward to merge.
