This is a CI/build system patch. Harald Nordgren removes a redundant `brew link --force gettext` command from Git’s macOS CI dependency installation script. The command was a no-op because gettext is already linked on the macOS CI runner image, and it only generated a spurious “Already linked” warning in every macOS job log. The change is a one-line deletion in `ci/install-dependencies.sh` and is uncontroversial. It’s a small but welcome cleanup for anyone reading CI logs.
