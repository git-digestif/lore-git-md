This is the second patch in Todd Zullinger’s three-part documentation series converting the `git-pack-refs` man page to the new synopsis style. It mechanically replaces the `[verse]` block in the SYNOPSIS with `[synopsis]`, removes the single-quote wrapper around the command name, and backtick-quotes every option term in both the main page and the included `pack-refs-options.adoc`. A single prose placeholder (`<branch>`) is also updated for consistency. The patch is purely visual—no Git behavior changes—and aligns with the ongoing effort led by Jean-Noël Avila to standardize all man pages on the same AsciiDoc formatting. The changes are small, well-scoped, and uncontroversial.
