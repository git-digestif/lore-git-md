This is a CI/build system patch that reduces noise in GitHub Actions logs.

The patch scopes the "missing tool" warnings for Perforce, Git LFS, and JGit to only the platforms that actually attempt to install them. Currently, every CI job emits warnings about these tools even if they were never meant to be installed on that platform (e.g., Alpine, Fedora, or i386/ubuntu). The change wraps each tool check in a `case` statement that matches only the platforms where the tool is expected (ubuntu-* for all three, plus macos-* for Perforce).

The commit message is clear and the diff is straightforward: it moves the existing checks inside platform-specific blocks, eliminating false-positive warnings on platforms that don’t need these tools. The patch touches only `ci/install-dependencies.sh` and does not alter behavior—it just silences irrelevant warnings. This is a small but useful quality-of-life improvement for CI log readability.
