This is the second patch in Kaartic Sivaraam’s three-part RFC series improving error reporting for invalid Git repositories when `--git-dir` is explicitly provided. It adds test coverage for three new error-reporting scenarios that the subsequent patch will enhance: a missing `HEAD` file, a `HEAD` symlink pointing outside the `refs/` directory, and an invalid `GIT_OBJECT_DIRECTORY` configuration.

The patch touches only the test suite (`t/t0009-git-dir-validation.sh`), adding 36 lines of new test cases. Each test sets up a specific failure scenario, runs a Git command with `--git-dir`, and verifies that the current error message ("not a git repository") is emitted. These tests serve as regression checks for the enhanced error messages that the next patch will introduce, ensuring that the new "reason" lines do not break existing behavior while adding diagnostic clarity. The test names and setup are clear and narrowly scoped, covering edge cases that users might encounter in real-world misconfigurations.
