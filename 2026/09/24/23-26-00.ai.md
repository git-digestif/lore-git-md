This is Junio’s "What’s cooking" report for September 2026 (#09), summarizing the state of all in-flight topics in his integration branches. The report is the authoritative snapshot of what is queued for the upcoming Git 2.56 release and what remains under review.

The most significant news is the versioning decision: Git 2.56 will be followed by Git 2.98, reflecting the project’s shift to a new numbering scheme after the Contributor’s Summit. No new feature topics are expected before 2.56 final, so the bulk of the topics listed will remain in ‘next’ until then.

Key highlights for a future AI summarizer:

- **New topics** (all in ‘seen’, some marked for ‘next’):
  - `jk/pull-null-merge-head` (1 commit): fixes a segfault in `git pull` when commit lookup fails on unparseable objects.
  - `je/doc-asciidoc-xrefs` (1 commit): converts plain-text documentation references to explicit AsciiDoc cross-references (`<<TARGET,TARGET>>`).
  - `js/ci-debian-12-http2-workaround` (1 commit): skips a flaky half-auth clone test in Debian 12 CI due to a curl HTTP/2 bug.
  - `ps/reflog-expiry-fix` (1 commit): corrects swapped default expiry periods for reachable and unreachable reflog entries.
  - `hn/shallow-history-advice` (1 commit): adds advice when `~N` or `^N` fails in a shallow clone.
  - `mc/refs-batched-deletions-old-oids` (3 commits): allows callers to supply old OIDs for batched ref deletions, retaining them in `git fetch`, `git remote`, `git branch`, and `git tag`.
  - `td/ls-files-untracked-cache` (3 commits): optimizes `git ls-files` by reusing and populating the untracked cache, sharing identical caches across `-unormal` and `-uall` outputs.
  - `je/doc-merge-conflicts` (7 commits): introduces a new `gitmergeconflicts(7)` man page and updates conflict-generating commands (`git merge`, `git rebase`, `git cherry-pick`, etc.) to link to it.
  - `kn/ci-unit-tests-on-windows-fix` (1 commit): fixes unit tests not running on Windows CI by checking one-indexed slice numbers.
  - `ps/meson-improvements` (7 commits): optimizes Meson builds by avoiding recompilation of HTTP sources, using precompiled headers for test-helpers and unit tests, and fixing shell completion tests and GitLab CI MSVC jobs.
  - `ps/setup-enforce-repo-passed-to-create-repository-has-no-state` (7 commits): refactors repository initialization to treat the repository object passed to `create_repository()` as a pure out-parameter, moving shared-repository logic and alternates setup into `setup.c`.

- **Stalled topics** (no activity for weeks):
  - `fz/rebase-autosquash-empty` (1 commit): honors `--empty` when a fixup/squash empties its target during `git rebase --autosquash`.

- **Cooking in ‘next’** (topics that have graduated from ‘seen’ and are candidates for ‘master’):
  - `rr/upload-pack-swap-shallow-wanted-ref` (1 commit): swaps the server-side protocol v2 response order for ‘wanted-refs’ and ‘shallow-info’ to match client expectations.
  - `js/coverity-fixes` (7 commits): assorted fixes for boundary and error conditions in various subsystems.
  - `of/commit-reach-repo-awareness` (1 commit): updates `can_all_from_reach()` and `can_all_from_reach_with_flag()` to accept a repository context, preventing submodule merging from reading the superproject’s commit-graph.
  - `ps/odb-alternates-at-creation` (9 commits): defers alternates setup to object database creation time during clone, removing the ad-hoc alternate writing API.
  - `ps/ref-storage-format` (13 commits): unifies terminology around reference storage formats, standardizing on “ref storage format” (e.g., `--ref-storage-format`, `GIT_REF_STORAGE_FORMAT`), and extends the option to accept payloads (`<format>://<payload>`).
  - `kn/receive-report-hook` (5 commits): introduces a new `report` hook in `git receive-pack` that runs after reference updates, allowing the server to filter or modify the packet-line status report sent back to the client.
  - `hn/history-squash` (8 commits): adds a `squash` subcommand to the experimental `git history` command, allowing a range of commits to be folded into a single commit with descendants replayed on top.

- **Notable needs-review topics** (awaiting community feedback):
  - `ps/setup-enforce-repo-passed-to-create-repository-has-no-state` (7 commits): refactors repository initialization to treat the passed repository object as stateless.
  - `je/doc-merge-conflicts` (7 commits): introduces a centralized merge conflicts guide.
  - `ps/meson-improvements` (7 commits): optimizes Meson builds and fixes CI issues.
  - `tc/push-force-if-includes-fixes` (3 commits): fixes `--force-if-includes` to consult the local branch’s reflog and allow fast-forward pushes.
  - `mm/diff-process-hunks` (11 commits): introduces `diff.<driver>.process` to allow external tools to act as hunk providers.

- **Topics with recent activity but still under discussion**:
  - `js/gitlab-ci-windows-rust` (4 commits): provisions GNU Rust for GitLab’s MinGW Windows CI builds.
  - `tb/rerere-wait-for-merge-rr-lock` (2 commits): makes `rerere` wait for `MERGE_RR.lock` instead of failing immediately.
  - `cc/early-scan-options` (3 commits): unifies early option scanning in commands like `git bisect` and `git rev-parse` using a new `early_scan_options()` API.
  - `ec/commit-fixup-options` (2 commits): extends `--fixup` to support `-m`, `-F`, `-c`, and `-C` options for supplying commit messages.

The report also lists several smaller fixes and cleanups (e.g., `yt/winansi-die-lasterr-fix`, `hd/diff-no-index-reverse-fix`, `ak/refs-files-root-ref-lock`) that are either cooking in ‘next’ or awaiting review. No topics are marked as merged to ‘master’ yet, as the 2.56-rc2 cycle is still open.
