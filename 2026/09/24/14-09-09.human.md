This is a build system patch series from Patrick Steinhardt targeting Git’s Meson build. It’s part of the ongoing effort to improve the Meson build’s performance, reliability, and compatibility with GitLab CI.

The series makes four concrete improvements. First, it speeds up clean builds by roughly 25 %—from 6.8 to 5.0 seconds—by avoiding redundant recompilation of HTTP-related sources and by introducing precompiled headers for test helpers and unit tests. Second, it fixes a test flakiness in shell completion by ensuring the completion scripts are up-to-date before tests run. Third, it updates the subproject wrappers (curl, expat, openssl, pcre2, zlib) to their current upstream versions. Finally, it unbreaks GitLab’s MSVC-Meson CI jobs, which were hanging due to a change in the runner images; the MinGW jobs remain broken but are being addressed separately by Johannes Schindelin.

The patches touch only the Meson build files, the CI script, and the completion build rules—no core Git code is changed. The series is self-contained and looks ready for review; the commit messages are clear and the motivation is well-documented. If you care about build speed or GitLab CI, this is worth a look.
