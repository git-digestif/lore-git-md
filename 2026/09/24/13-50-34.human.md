This is a bugfix patch for `git fetch-pack`. The patch addresses an inconsistency where `git fetch` correctly marks object IDs (OIDs) as "exact" when they are provided directly (e.g., `git fetch $OID`), but `git fetch-pack` fails to do the same. This oversight causes `fetch-pack` to incorrectly send `want-ref $OID` instead of `want $OID`, leading to errors like `fatal: unknown ref $OID` when the remote repository doesn’t have a ref matching the OID.

The fix is straightforward: in `builtin/fetch-pack.c`, the `add_sought_entry` function now sets the `exact_oid` flag when parsing a standalone OID (e.g., `deadbeef` rather than `deadbeef refs/heads/main`).
