This is a CI/build system patch, the second in Johannes Schindelin’s four-part series to restore GitLab CI for Windows after Rust support was enabled. The patch fixes a silent data loss in the PowerShell dependency-setup script: `New-Item -Force` was clobbering the `.git/info/exclude` file, wiping out the `/git-sdk` entry added by `install-sdk.ps1` and causing the CI pipeline to reject SDK files as unignored build artifacts. The fix is a simple existence check before creating the file, preserving any prior exclusions.

Patrick Steinhardt’s review is surface-level—he confirms the change makes sense and notes that it implies `install-dependencies.ps1` will now be called for MinGW builds, but he does not engage with the broader CI implications or question the script’s design. The patch itself is mechanical, well-motivated, and confined to CI infrastructure; it changes no Git behavior or user-facing features. Expect follow-up discussion to reference the `.git/info/exclude` file and the `New-Item -Force` behavior.
