This is the first patch in Patrick Steinhardt’s 7-patch Meson build improvement series. It addresses redundant compilation of HTTP sources (`http.c` and `http-walker.c`) in the Meson build system. Currently, these files are recompiled seven times—once for each Git command that links against libcurl—because they are listed as `sources:` in the dependency declaration. The patch refactors this by moving the HTTP sources into a dedicated static library (`libgit-curl.a`), which is then linked into the relevant commands. This change yields a measurable ~8% speedup in clean build times (from 6.78s to 6.27s), as demonstrated by the included benchmark.

The patch touches only `meson.build` and introduces no new symbols or behavioral changes; it is purely a build optimization. The approach is straightforward and aligns with Meson’s idiomatic use of static libraries for shared dependencies. No objections or open questions are evident from the patch itself, and the performance improvement is clearly quantified. This is a well-motivated, low-risk change targeting build efficiency rather than core Git functionality.
