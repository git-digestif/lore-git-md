Subject: fetch-pack: mark exact OIDs in refs
Series version: single patch (no version iteration yet)
Originating author: Nathan Froyd
Thread type: bugfix patch

Core problem or goal
`git fetch-pack` does not mark exact OIDs in refs, causing it to send `want-ref $OID` instead of `want $OID` when invoked as `git fetch-pack $OID`. This triggers “unknown ref” errors from the remote. The goal is to make `fetch-pack` consistent with `git fetch`, which already marks exact OIDs correctly.

Current status
Under review; no prior version posted. Patch touches `builtin/fetch-pack.c` (one line added to set `ref->exact_oid`) and adds test coverage in `t/t5703-upload-pack-ref-in-want.sh` for three scenarios: mixed refs and OIDs from command-line arguments, mixed refs and OIDs from stdin, and OID-plus-ref-name input.
