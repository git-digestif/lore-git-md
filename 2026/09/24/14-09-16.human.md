This is the final patch in Patrick Steinhardt’s seven-patch series improving the Meson build system. It fixes a GitLab CI hang in MSVC jobs that started with GitLab Runner 19.x.

The hang occurs because the runner’s cleanup phase runs `git credential reject` using the PortableGit version installed by the CI script. PortableGit’s default credential manager (Git Credential Manager for Windows) tries to access the Windows Credential Manager, fails, and blocks indefinitely. The patch works around this by explicitly unsetting the credential helper after PortableGit is installed, turning the `git credential reject` call into a no-op. The change is minimal—eight lines in `ci/install-dependencies.ps1`—and only affects the CI environment, not end-user builds. No performance impact or behavior change outside CI is expected. The fix is pragmatic and addresses a real, observed problem without touching core Git code.
