This is a bugfix for a regression in `git reflog expire` that swapped the default expiry times for reachable and unreachable reflog entries in Git 2.50. The patch restores the correct defaults (reachable: 90 days, unreachable: 30 days) and has been thoroughly reviewed and tested. Junio C Hamano approved the core fix and commit message in his latest review, but raised a minor test-structure concern about asymmetry in the test cases—this has since been addressed by the author in v2.

Patrick Steinhardt now asks whether this fix should be fast-tracked for the upcoming Git 2.56 release. The regression is clear, the fix is minimal and uncontroversial, and the patch has received positive feedback from Junio, Jeff King, and Patrick himself. There are no open technical issues, and the expanded test coverage ensures the bug won’t recur. This looks like a strong candidate for a late inclusion in the release cycle.
