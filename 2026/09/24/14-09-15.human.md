This is the sixth patch in Patrick Steinhardt’s seven-patch CI/build system series improving the Meson build. It updates the subproject wrapper files (`.wrap`) for curl, expat, openssl, pcre2, and zlib to their latest upstream versions via `meson wrap update`.

The patch is purely mechanical: it bumps the version numbers, updates the download URLs, hashes, and patch metadata, and modernizes the `[provide]` section syntax in each wrapper. These wrappers are used on platforms (notably Windows) where the dependencies are not natively available, allowing Git to build with bundled versions. No functional changes to Git itself are introduced; the patch ensures compatibility with newer upstream releases and fixes potential build issues on systems relying on these subprojects. The changes are low-risk and routine maintenance.
