This is a CI/build system patch, part of Johannes Schindelin’s four-patch series restoring GitLab CI for Windows after Rust was enabled. The email is a review reply from Patrick Steinhardt to the second patch, which fixes a silent data loss in the PowerShell dependency-setup script: `New-Item -Force` was clobbering `.git/info/exclude`, discarding the `/git-sdk` entry added by `install-sdk.ps1` and causing CI to reject SDK files as unignored artifacts.

Patrick’s review is surface-level. He acknowledges the fix (“Makes sense”) and notes that the commit message confirms the plan to start calling `install-dependencies.ps1` for MinGW builds, which aligns with the series’ broader goal of unifying Rust toolchain provisioning across Windows CI jobs. No technical objections or substantive questions are raised; the feedback is purely confirmatory. The patch itself remains uncontroversial, well-motivated, and narrowly scoped to CI infrastructure.
