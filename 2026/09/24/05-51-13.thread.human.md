This thread is about a new Afrikaans translation for `git-gui`, the graphical interface for Git. Stéfan Driaan Turvey contributed a complete translation of all 2,733 strings in the `git-gui` interface, covering menus, dialogs, error messages, and tooltips. The patch adds a single file (`po/af.po`) with no code changes, so it doesn’t affect Git’s functionality—it’s purely a localization effort.

Since this is the first version (`v1`) of the patch and translations are generally uncontroversial if accurate, it’s likely to be accepted once reviewed for quality. The submission follows the standard GitGitGadget workflow, and while there’s been no prior discussion, the patch is self-contained and ready for review by Afrikaans speakers or Git’s localization maintainers. No technical objections or open questions have surfaced yet.
