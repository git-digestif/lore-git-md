This thread is about adding an Afrikaans translation for `git-gui`, submitted by Stéfan Driaan Turvey as a single-patch series. The patch introduces a new `po/af.po` file with 2,733 translated strings, making the graphical interface accessible to Afrikaans speakers. There are no functional code changes—just a localization update.

The patch is currently under review. Johannes Sixt (Hannes) provided initial feedback, noting two procedural issues: the new `.po` file needs to be registered in `po/meson.build`, and the file should be stripped of location metadata (line numbers) before committing, following the project’s conventions for other translations. He referenced `po/README.md` for automation instructions and suggested a temporary workaround via `.git/info/attributes`. This review was purely about adherence to submission standards, not the translation’s accuracy.

No other reviews or objections have been raised yet. The next steps will likely involve the author addressing the procedural feedback before the patch can proceed toward integration. If you’re following this thread, watch for a v2 that includes these adjustments.
