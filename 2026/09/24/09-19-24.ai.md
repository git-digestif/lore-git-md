This is patch 6/7 in Patrick Steinhardt’s seven-patch refactoring series that prepares `create_repository()` for a stateless interface. The patch overhauls `repo_clear()` so that it reliably resets every field of the `struct repository` to zero, eliminating the risk of stale state leaking between calls. The change is mechanical: it replaces individual `FREE_AND_NULL()` calls with plain `free()` followed by a final `memset(repo, 0, sizeof(*repo))`, and removes redundant NULL assignments after freeing sub-structures. The header file is also updated to move the function declaration next to its sibling `repo_init()` for better locality. No behavior change is claimed, but the new implementation is more robust against future additions to the repository structure. This is a prerequisite for the final patch (7/7), which will enforce statelessness by clearing the input repository at the start of `create_repository()`.
