This is the fifth patch in Patrick Steinhardt’s seven-patch Meson build improvement series. It fixes an issue with outdated shell completion helpers that were causing test failures by reverting from Meson 1.3.0’s `fs.copyfile()` back to the older `configure_file()` mechanism.

The problem stems from the order in which Meson processes subdirectories: the `contrib/completion` directory is included *after* test dependencies are wired up, so any dependencies added here (like `fs.copyfile()`) are ignored during test execution. This forces users to manually run `meson compile` before tests can pass. The patch unconditionally switches to `configure_file()`, which automatically re-runs when source files change, ensuring tests always see up-to-date completion scripts. While `fs.copyfile()` is conceptually cleaner, its practical limitations make it unsuitable here.

The change touches only `contrib/completion/meson.build` and removes the version-dependent logic, simplifying the build file. Patrick notes that a more comprehensive fix—promoting completion helpers out of `contrib/`—would be ideal but is deferred to a future series. This patch is a targeted, low-risk fix that resolves immediate test failures without disrupting installed file paths or requiring broader refactoring. No new symbols or on-disk formats are introduced.
