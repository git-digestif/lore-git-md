This is a CI/build system patch, the fourth in Patrick Steinhardt’s seven-patch Meson build-improvement series. It extends precompiled-header support—already applied to the test-helper executable in patch 3—to the unit-test executable (`unit-tests`).

The change is small but technically interesting: because `clar.c` (the third-party Clar test framework) must not include Git’s `git-compat-util.h`, the patch refactors it into a separate static library (`libclar.a`). This allows the rest of the unit-test sources to use the precompiled header while keeping `clar.c` isolated. The result is a modest but measurable 5 % speed-up in clean build times (5.34 s → 5.08 s). The only file touched is `t/meson.build`; the new static library and the precompiled-header directive are the key symbols introduced. No on-disk format or public API changes occur. The patch is well-motivated, self-contained, and follows the same pattern established in the previous commit.
