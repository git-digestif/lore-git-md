This is a v2 CI/build system patch series from Johannes Schindelin, fixing GitLab CI breakage for Windows builds after Rust support was enabled. The series targets `.gitlab-ci.yml` and `ci/install-dependencies.ps1` to restore functionality in GitLab’s MinGW-based Windows jobs, with no changes to Git’s core behavior.

The v2 iteration rewords commit messages to clarify previously confusing statements, particularly around the "GNU Rust" toolchain and the `Gcc` feature in Rust’s MSI installer. The core technical changes remain the same as v1: ensuring the correct Rust toolchain (`gnu` target) is provisioned for MinGW builds, preserving `.git/info/exclude` contents to avoid silent data loss, and explicitly adding `/c/Rust/bin` to `PATH` to make `cargo` accessible. The `Gcc` feature is now confirmed to only ensure linker compatibility with the existing MinGW-provided GCC, not install a redundant toolchain.

The series is narrowly scoped to GitLab’s CI infrastructure and has been validated by Karthik Nayak’s internal GitLab merge request (MR #671) and pipeline (#2863888081), where both `build:mingw64` and `build:msvc-meson` jobs now succeed. All substantive review questions from v1—including Patrick Steinhardt’s queries about the `Gcc` feature and the "GNU Rust" toolchain—have been addressed. The unrelated GitLab Runner regression (credential-clearing timeout) remains unresolved but does not affect this series’ validity.

Key technical details for follow-up discussion include the `-Mingw` switch in `install-dependencies.ps1`, the `gnu` Rust target, the `Gcc` feature in Rust’s MSI installer, and the `PATH` adjustment in `.gitlab-ci.yml`. The `.git/info/exclude` preservation fix may influence future CI script design. The series is part of the broader Rustification effort but focuses solely on CI stability rather than advancing Rust adoption in Git itself.

No maintainer decision on integration status yet, but the series appears technically sound and well-motivated, with no remaining objections. The reworded commit messages improve clarity without altering the patches’ substance.
