This thread is about a bugfix for `git fetch-pack` that aligns its behavior with `git fetch` when handling exact object IDs (OIDs). Nathan Froyd identified an inconsistency where `git fetch` correctly marks exact OIDs in refs, but `git fetch-pack` does not, leading to "unknown ref" errors when fetching specific OIDs. The fix is minimal—adding a single line in `builtin/fetch-pack.c` to set the `exact_oid` flag when parsing OIDs from command-line arguments or stdin.

The patch includes thorough test coverage in `t/t5703-upload-pack-ref-in-want.sh`, verifying that `fetch-pack` now behaves consistently with `fetch` in three scenarios: mixed refs and OIDs from arguments, mixed refs and OIDs from stdin, and OID-plus-ref-name input. The fix is well-scoped, addresses a real issue, and has no apparent downsides. No objections or further discussion have been raised yet, so this appears to be a straightforward bugfix ready for review.
