This is a CI/build system patch, the fifth in Patrick Steinhardt’s seven-patch series improving the Meson build. It fixes a long-standing annoyance: the shell-completion helpers in `contrib/completion/` were not being copied into the build tree before the test suite ran, forcing developers to manually compile first. The root cause was a version-dependent code path that used `fs.copyfile()` (introduced in Meson 1.3.0) instead of the older `configure_file()`; the newer function does not automatically trigger when the source file changes, so test dependencies were not honored. The patch unconditionally switches back to `configure_file()`, eliminating the version check and restoring reliable test execution. The commit message also hints at a future cleanup—promoting the completion scripts out of `contrib/`—but that is explicitly deferred. The change is small (15 insertions, 23 deletions), touches only `contrib/completion/meson.build`, and carries no risk to production builds.
