This is a platform-compatibility report from Ramsay Jones, testing Git’s experimental Rust support on Cygwin using an unofficial Rust 1.91.0 package. The email is part of the Git 3.0 timeline discussion, specifically addressing the unresolved question of Rust portability.

Ramsay shares his experience building Git’s `master` branch (v2.56.0-rc2 plus one commit) with Rust enabled on Cygwin. The build succeeds, producing a working `git` binary, and the test suite fails in exactly the same places as the non-Rust build. This is encouraging but limited: the Rust codebase in Git is still small, so the test does not exercise much of the compiler. Ramsay notes that Brian Carlson likely has more extensive Rust code in a branch that could be tested, but he is about to enter the hospital for surgery and will be unavailable for follow-up.

The key takeaway is that Rust *can* compile on Cygwin, at least for the current minimal integration, but the platform’s lack of an official Rust package remains a concern. This report does not resolve the broader portability question (e.g., NonStop support) but provides a data point for Cygwin, one of the platforms where Rust support is uncertain. The tone is cautiously optimistic, framing the result as "slightly encouraging" rather than definitive.
