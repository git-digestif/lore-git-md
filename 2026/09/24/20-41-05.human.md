This is a CI/build system patch addressing a GitHub Actions resource exhaustion issue. Tamir Duberstein responds to Patrick Steinhardt’s substantive review of the first patch in his two-patch series, which aims to prevent out-of-memory (OOM) kills in the `t4205-log-pretty-formats.sh` test.

Tamir provides the requested evidence: benchmark data comparing `diff -u` (used by `test_cmp`) and `cmp` (used by `test_cmp_bin`) on identical 2 GiB files. The results show `diff -u` consumes over 4 GiB of memory and takes 5 seconds, while `cmp` uses only 1.2 MiB and completes in 0.5 seconds. This strongly supports replacing `test_cmp` with `test_cmp_bin` for large outputs. However, Tamir concedes that the early file deletion (`rm expect actual`) is likely ineffective, as Patrick noted the files are rewritten shortly afterward in subsequent tests.

The discussion is now focused on whether to retain the deletion in the next version. Tamir asks for Patrick’s preference: include the benchmark data in the commit message and drop the deletion, or keep both changes. The patch is otherwise well-justified by the data, and the remaining question is a minor implementation detail. If Patrick agrees, the patch could be ready for merging.
