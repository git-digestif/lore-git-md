This is a performance-focused build system patch, the first in Patrick Steinhardt’s seven-patch series improving the Meson build. It targets redundant compilation of HTTP-related source files (`http.c` and `http-walker.c`), which are currently recompiled seven times—once for each Git command that links against libcurl. By moving these files into a dedicated static library (`libgit-curl`), the patch reduces clean build time by nearly 10% (from ~6.8s to ~6.3s on the author’s machine).

The change is mechanical and low-risk: it replaces the `sources:` keyword in the `libgit_curl` dependency with a `link_with:` reference to a new static library, ensuring the files are compiled only once. The patch touches only `meson.build` and includes a clear benchmark demonstrating the speedup. No new symbols or on-disk format changes are introduced, and the behavior of the resulting binaries is unchanged. This is a straightforward optimization that aligns with the series’ goal of faster, more reliable builds.
