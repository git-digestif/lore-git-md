This is a documentation integration follow-up to the `gitmergeconflicts(7)` series. Jeff King (Peff) identifies the root cause of the `make check-docs` failure reported by Junio: the new man page is not listed in `command-list.txt`, which the `ta/command-list-guides-sync-lint` topic uses to validate documentation links. That topic is in `seen` but not yet in `master`, so the failure only surfaces when the two topics are merged together.

The fix is straightforward: add `gitmergeconflicts` to `command-list.txt` under the "guides" section, following the pattern established by `gitdatamodel(7)` in commit c655855559. This is a mechanical integration step, not a content issue, and will resolve the linting error so the series can proceed toward `next`. No changes to the guide itself or the cross-references in other man pages are needed.
