This is the second patch in Patrick Steinhardt’s seven-patch series improving the Meson build system. It addresses a minor inefficiency where the `git-remote-http` binary and its aliases (`git-remote-https`, `git-remote-ftp`, `git-remote-ftps`) were being recompiled multiple times for test dependencies, rather than reusing the already-compiled objects.

The change is straightforward: instead of rebuilding `remote-curl.c` for each alias, the patch stores the compiled `git-remote-http` executable in a variable (`git_remote_http`) and reuses its objects for the aliases via `extract_all_objects()`. This reduces redundant compilation, bringing the Meson build more in line with how the Makefile handles these targets. The performance gain is modest—about 1% faster clean builds—but the patch improves consistency and avoids unnecessary work.

The commit message is clear and includes benchmark results, though the author acknowledges the speedup is negligible. The approach is uncontroversial and aligns with Meson’s idioms. This patch is a small but logical follow-up to the first patch in the series, which introduced a static library to avoid recompiling HTTP sources.
