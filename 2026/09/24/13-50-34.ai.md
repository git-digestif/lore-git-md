This is a bugfix patch for `git fetch-pack`. It addresses an inconsistency where `git fetch` correctly marks exact OIDs (object IDs) in refs, but `git fetch-pack` does not. This causes `git fetch-pack $OID` to send `want-ref $OID` instead of `want $OID`, leading to "unknown ref" errors from the remote.

The patch modifies `builtin/fetch-pack.c` to set the `exact_oid` flag when parsing OIDs from command-line arguments or stdin. The change is minimal: it adds a single line to set `ref->exact_oid` when the input is an exact OID (no trailing ref name). The commit includes thorough test coverage in `t/t5703-upload-pack-ref-in-want.sh`, verifying that `fetch-pack` now behaves consistently with `fetch` in three scenarios: mixed refs and OIDs from arguments, mixed refs and OIDs from stdin, and OID-plus-ref-name input.

The motivation is clear and the fix is well-scoped. The patch looks correct and addresses a real issue. The test cases cover the edge cases and confirm the expected behavior. This is a straightforward bugfix with no apparent downsides.
