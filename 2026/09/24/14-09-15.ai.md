This is the sixth patch in Patrick Steinhardt’s seven-patch CI/build system series updating the Meson build’s subproject wrappers. The patch updates the `.wrap` files for curl, expat, openssl, pcre2, and zlib to their latest upstream versions (curl 8.10.1→8.12.1, expat 2.7.1→2.8.4, openssl 3.0.8→3.0.10, pcre2 10.45→10.48, zlib 1.3.1→1.3.2).

The motivation is to keep the bundled dependencies current for platforms (notably Windows) that rely on these wrappers for a nearly dependency-free build. The changes are mechanical: each `.wrap` file is updated to point to the new upstream source tarball, its hash, and the corresponding Meson wrapdb patch. The patch also modernizes the `[provide]` section syntax in some wrappers, switching from legacy variable-style declarations (`libcurl = libcurl_dep`) to the newer `dependency_names` list format.

No behavioral changes or performance impact are expected from this patch alone; it is purely a maintenance update to ensure compatibility and security. The patch is low-risk, touching only the `.wrap` files in `subprojects/`, and does not interact with any core Git code or on-disk formats. It complements the earlier patches in the series by ensuring the build environment is up-to-date, which is particularly important for the CI fixes addressed in patch 7.
