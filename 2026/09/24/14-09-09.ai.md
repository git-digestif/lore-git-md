This is a CI/build system patch series from Patrick Steinhardt targeting Meson build improvements. The series consists of seven patches that collectively aim to speed up clean build times (from ~6.8s to ~5.0s for a full build), fix shell completion test failures, update subproject wrappers to current versions, and resolve a GitLab CI issue causing MSVC jobs to hang.

The patches focus on reducing redundant compilation in the Meson build process, particularly for HTTP sources and the `git-remote-http` helper, by leveraging precompiled headers for test helpers and unit tests. The series also addresses outdated completion helpers that were causing test failures and updates the subproject wrappers (curl, expat, openssl, pcre2, zlib) to their latest versions. The final patch fixes a GitLab CI issue where MSVC jobs were hanging due to changes in runner images, though MinGW-based jobs remain broken (with Johannes Schindelin working on separate fixes).

Key files touched include `meson.build`, `contrib/completion/meson.build`, `t/helper/meson.build`, `t/meson.build`, and the subproject `.wrap` files. The series is well-motivated, with measurable performance gains and clear fixes for test and CI issues. The changes appear to be low-risk, focusing on build optimization and infrastructure rather than core Git functionality. No controversial design decisions are evident from the cover letter.
