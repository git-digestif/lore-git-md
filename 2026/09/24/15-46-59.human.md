This is a **bugfix** for the `git reflog expire` regression that swapped default expiry times for reachable and unreachable entries. Jeff King (Peff) replies to Patrick Steinhardt’s question about fast-tracking the fix for Git 2.56. Peff notes the bug was introduced in Git 2.50.0, so it’s not a new regression, but calls the fix "quite obvious and low-risk" and says he’s okay with either merging it now or waiting for the next cycle. The patch itself remains uncontroversial, well-tested, and ready to go—this reply is purely about timing.
