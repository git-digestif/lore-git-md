This thread is about a 7-patch series from Patrick Steinhardt aimed at improving Git’s Meson build system—speeding up clean builds, fixing test failures, updating dependencies, and resolving CI hangs in MSVC jobs. The series is under review, with no prior versions, and targets build infrastructure rather than core Git functionality.

Key improvements include refactoring HTTP sources into a static library (`libgit-curl.a`) for a ~8% build speedup, extending precompiled headers to test helpers and unit tests for a ~24% cumulative speedup, fixing shell completion test failures, updating subproject dependencies (curl, expat, openssl, pcre2, zlib), and disabling PortableGit’s credential helper to prevent MSVC CI hangs. The series has received mostly surface-level reviews, with two substantive discussions: one about compiler flags for the unit-test framework (resolved by design) and another about outdated subproject wrappers.

The latter issue—raised by Kaartic Sivaraam—highlighted a version gap between Meson’s wrapdb and upstream releases (e.g., curl 8.10.12 vs. 8.22.0). Patrick acknowledged the lag but deemed it non-urgent, suggesting the proper fix would be updating wrapdb upstream rather than documenting the issue or maintaining manual `.wrap` files. This resolves the open question in principle, though no immediate action is planned. The series remains merge-ready, with no unresolved technical objections. Karthik Nayak and Kaartic Sivaraam provided feedback, but only Kaartic’s review of Patch 6 engaged substantively with the build system’s long-term maintenance.
