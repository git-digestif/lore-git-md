This thread is about Patrick Steinhardt’s seven-patch series improving Git’s Meson build system—speeding up clean builds, fixing shell completion test failures, updating outdated dependencies, and resolving CI hangs in MSVC jobs. The series is under review in its first version, with no prior iterations.

The key changes include refactoring HTTP sources into a static library (`libgit-curl.a`) to avoid redundant compilation (yielding an ~8% speedup), reusing compiled objects for HTTP aliases (~1% speedup), extending precompiled headers to test helpers and unit tests (~19% and ~5% speedups, respectively), fixing shell completion test failures by reverting to `configure_file()`, updating subproject dependencies (curl, expat, openssl, pcre2, zlib), and disabling PortableGit’s credential helper to prevent MSVC CI hangs. Cumulatively, these changes reduce clean build times by about 35%.
