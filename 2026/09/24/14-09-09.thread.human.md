This thread is a seven-patch series from Patrick Steinhardt aimed at improving Git’s Meson build system—speeding up clean builds, fixing test failures, and resolving CI reliability issues. The first four patches focused on performance optimizations: refactoring HTTP sources into a static library (`libgit-curl.a`) to avoid redundant compilation, eliminating recompilation of `git-remote-http` objects for aliases, and introducing precompiled headers for test helpers and unit tests. These changes cumulatively reduced clean build times by about 35%, with the largest gain (19%) coming from precompiled headers for test helpers.

The latest patch (v1/7) addresses a specific test failure in shell completion by reverting from Meson 1.3.0’s `fs.copyfile()` back to `configure_file()`. The issue arose because Meson processes the `contrib/completion` directory too late for its dependencies to be recognized during test execution, forcing manual recompilation. While `fs.copyfile()` is conceptually cleaner, its practical limitations made it unreliable here. The fix is minimal—touching only `contrib/completion/meson.build`—and avoids broader refactoring (like moving completion helpers out of `contrib/`), which Patrick deferred to a future series. No objections or reviews have been posted yet, and the series remains under initial review. Johannes Schindelin’s separate work on MinGW CI fixes is related but not dependent on this effort.
