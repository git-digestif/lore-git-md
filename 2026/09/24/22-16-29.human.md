This is a review comment on the third patch of Kaartic Sivaraam’s RFC series improving error reporting for invalid Git repositories when `--git-dir` is explicitly provided. Junio C Hamano points out two mechanical issues in the implementation: a dead `strbuf_release()` call after `die()` (which never executes because `die()` is marked `NORETURN`), and an unconventional approach to assembling localized error messages. Instead of manually building the message with `strbuf_addf()`, Junio suggests using a single `die()` call with format arguments, which is the project’s standard practice for error messages. The feedback is purely surface-level—no objections to the patch’s direction or functionality, just a request to align with Git’s coding conventions. The series remains in the RFC phase, awaiting further discussion on edge-case coverage and implementation details.
