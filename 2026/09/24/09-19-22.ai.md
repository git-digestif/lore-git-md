This is the fourth patch in Patrick Steinhardt’s seven-patch series refactoring `create_repository()` to enforce stateless input. It moves the `core.sharedRepository` setting from `builtin/init-db.c` into `setup.c`, eliminating the last in/out usage of the repository parameter for this specific value.

The change is minimal: three lines removed from `cmd_init_db()` and three added to `create_repository()`. The caller (`git init`) no longer needs to pre-populate the repository with the shared-repository value; instead, it passes the value directly, and `setup.c` applies it internally. The other caller (`git clone`) already passes `-1` and is unaffected.

This patch is a straightforward, behavior-preserving refactoring that continues the series’ goal of simplifying the interface. No new symbols are introduced; the patch merely relocates existing logic. The commit message notes that the repository parameter is now effectively stateless for this call, paving the way for the final enforcement in patch 7.
