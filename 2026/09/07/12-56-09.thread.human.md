This thread is a small but user-facing documentation fix in Git’s advice subsystem. Vsevolod Myalitsin proposed correcting the on-screen instructions for disabling the `defaultBranchName` advice message, changing the recommended command from `git config set advice.defaultBranchName false` (repository-local) to `git config --global advice.defaultBranchName false` (global default). The change targets only this one advice key, leaving all others unchanged.

Ben Knoble reviewed the initial patch and suggested two improvements: using the more explicit `set --global` syntax and refactoring the logic into a helper function for better maintainability. Vsevolod revised the patch to address these points, introducing a `global_hint` field in the `advice_setting` struct instead of hard-coding the logic. The revised version is now under review, with Ben endorsing the cleaner design. The only remaining open question is whether to use `--global` or `set --global` in the displayed command—Ben prefers the latter, but the current patch uses the former. No objections have been raised, and the change remains low-risk, touching only `advice.c` with no new symbols or on-disk format changes.
