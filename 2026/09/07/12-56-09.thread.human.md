This thread is a simple but practical documentation fix from Vsevolod Myalitsin. When Git shows the `defaultBranchName` advice message, it currently tells users to run `git config set advice.defaultBranchName false`—which only disables the message for the current repository. The patch changes the on-screen instructions to recommend `git config --global` instead, so the setting applies to all future repositories. The change is minimal: a single conditional in `advice.c` that tweaks the string formatting in the `vadvise()` helper, leaving the rest of the advice subsystem untouched.

The commit message clearly explains why the current wording is "useless" for the intended purpose and how the fix addresses it. There are no tests or additional documentation updates, but the change is self-contained and unlikely to cause issues. This looks like a straightforward usability improvement that’s ready for review.
