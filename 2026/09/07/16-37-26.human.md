This is the first patch in Thomas Bachem’s v3 series to defer auto maintenance during sequencer operations. The patch introduces `git_config_append_parameter()`, a helper function that builds the `GIT_CONFIG_PARAMETERS` environment string with proper shell quoting. This helper will be used in the next patch to disable auto maintenance during `git rebase`, `git cherry-pick`, and `git revert`.

Patrick Steinhardt’s review identified two clarity issues: the commit message should briefly explain what `GIT_CONFIG_PARAMETERS` is and how its quoting works, and the parameter name `env` in the helper function is misleading because it is not tied to environment variables. Thomas has accepted both points and will update the commit message and parameter name (`env` → `buf`) in v3. He will also document the format in the header comment, addressing Patrick’s observation that neither the new helper nor the existing `git_config_from_parameters()` currently describes the string format.

The patch itself is a straightforward refactoring with no functional changes. It factors out reusable config-string logic for the sequencer’s use in the next patch, and the feedback is purely about naming and documentation. No substantive objections remain.
