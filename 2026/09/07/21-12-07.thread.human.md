This thread is a three-patch series from Beat Bolli improving TLS certificate verification in `git imap-send`. The series addresses OpenSSL compatibility, a latent bug in ASN1_STRING handling, and stricter compliance with RFC 6125 for certificate validation.

The first two patches modernize OpenSSL API usage and fix unsafe assumptions about ASN1_STRINGs, while the third (just summarized) enforces RFC 6125's requirement to skip the subject common name (CN) check if DNS subject alternative names (SANs) are present. This last patch is a minimal, nine-line change that aligns Git with security best practices, though no new tests accompany the series.

The patches touch only `imap-send.c` and introduce no new symbols or on-disk format changes. The series is under initial review, with no feedback yet from maintainers or other contributors. The changes are self-contained and focus on correctness and forward compatibility.
