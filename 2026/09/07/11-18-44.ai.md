This is the tenth patch in Patrick Steinhardt’s v2 series unifying Git’s terminology for "ref storage format." It renames the `init.defaultRefFormat` configuration key to `init.defaultRefStorageFormat` while retaining the old name as a backward-compatible alias.

The change is mechanical: the patch updates the config key in `setup.c`, documentation (`BreakingChanges.adoc`, `config/feature.adoc`, `config/init.adoc`), and the test suite (`t/t0001-init.sh`). The test updates ensure that the new key name works as expected and that the precedence rules (command-line option overrides environment variables, which override config) remain intact. No functional changes are introduced beyond the rename and aliasing.

This patch is part of the series’ broader goal of resolving inconsistencies ahead of the upcoming `--object-storage-format=` extension. The rename aligns the config key with the new `--ref-storage-format=` CLI option and environment variables introduced earlier in the series. The backward-compatible alias ensures existing scripts and tools continue to work, though third-party integrations parsing config output may need updates. The patch is uncontroversial and ready for review.
