This is a substantive review comment on the third patch of the v2 series that defers auto maintenance until sequencer completion. Patrick Steinhardt questions the necessity of disabling both `maintenance.auto` and `gc.auto` in the `disable_auto_maintenance()` helper, arguing that disabling only `maintenance.auto` should suffice since Git's maintenance infrastructure now exclusively uses `git maintenance` (which may internally invoke `git gc`, but only if auto maintenance is enabled). The comment targets a specific implementation detail—whether the redundant `gc.auto=0` setting is needed for correctness or can be safely removed for clarity. This is a technical point about Git's maintenance subsystem behavior, not a surface-level nit.
