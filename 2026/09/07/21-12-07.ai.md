This is a three-patch series from Beat Bolli targeting the `imap-send` subsystem, focusing on OpenSSL compatibility and correctness fixes.

The series addresses three distinct issues in `imap-send.c`. Patch 1 prepares the code for OpenSSL 4.1 by replacing a deprecated ASN1_STRING function with its newer equivalent, ensuring forward compatibility. Patch 2 fixes a latent bug where the code incorrectly assumed ASN1_STRINGs are NUL-terminated—a behavior not guaranteed by the OpenSSL API. Patch 3 aligns certificate validation with RFC 6125 by only falling back to checking the subject common name (CN) if no DNS subject alternative names (SANs) are present.

The changes are narrowly scoped to the IMAP TLS certificate verification logic and do not affect other parts of Git. The commit messages are clear and cite the relevant RFC, suggesting the author has done their homework. No test failures or regressions are mentioned, but the series does not introduce new tests either—likely because the fixes target edge cases in the OpenSSL interaction layer that are hard to trigger in the existing test suite.

This looks like a well-motivated, low-risk cleanup that removes sharp edges before they cause problems. The patches are small, self-contained, and address real (if obscure) correctness issues rather than hypothetical ones. The OpenSSL 4.1 preparation in particular is proactive and avoids last-minute scrambling when the new version ships. If you care about `git imap-send` or OpenSSL compatibility, this series is worth a quick look.
