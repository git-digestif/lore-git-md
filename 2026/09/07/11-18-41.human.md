This is part seven of Patrick Steinhardt’s eleven-patch series that unifies Git’s terminology for “ref storage format” and prepares for URI-style configuration. This patch is pure refactoring: it moves the URI-parsing logic from `setup.c` into a new public function `ref_storage_format_by_uri()` in `refs.c`/`refs.h`, eliminating 36 lines of duplicated code. No behavior changes; the next patch will use the new function to add URI payload support. The patch is clean, well-contained, and ready for review.
