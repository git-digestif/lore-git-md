This is part of Patrick Steinhardt’s v2 series to unify Git’s terminology for "ref storage format." Patch 4/11 renames the `--ref-format=` option to `--ref-storage-format=` in `git submodule` and its helper, keeping the old name as a hidden backward-compatible alias.

The changes are mechanical: the patch updates the option name in the man page (`Documentation/git-submodule.adoc`), the C helper (`builtin/submodule--helper.c`), the shell wrapper (`git-submodule.sh`), and one test script (`t/t7424-submodule-mixed-ref-formats.sh`). The backward-compatible alias (`--ref-format=`) is added via `PARSE_OPT_HIDDEN` so scripts using the old name continue to work. No functional changes are introduced; the patch is purely a rename for consistency with the rest of the series.

The patch is well-scoped and uncontroversial. It follows the same pattern as earlier patches in the series and maintains the backward-compatibility guarantees established in the cover letter. No review feedback has been incorporated yet, but the changes align with the series’ overall goals and prior feedback.
