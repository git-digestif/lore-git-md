This is the third patch in Patrick Steinhardt’s nine-patch series refactoring how Git handles ODB alternates during repository creation. The series is part of the broader ODB abstraction effort, which aims to simplify the ODB interface by making alternates an implementation detail of the backend.

This patch is a preparatory refactoring in `builtin/clone.c`. It moves the `setup_reference()` function further down in the file, closer to `copy_alternates()`, which it will soon call. The change is purely mechanical—no logic is altered—and is intended to avoid adding a forward declaration for `copy_alternates()` in a later patch. The diff swaps the order of `setup_reference()` and `copy_alternates()`, with no other modifications.

The patch is uncontroversial and well-motivated within the series’ context. It sets the stage for patch 5, which will rename `copy_alternates()` to `read_alternates()` and integrate it into `setup_reference()` to consolidate alternates handling. The change is small and self-contained, touching only one file and 20 lines, and carries no risk of introducing regressions. Reviewers are unlikely to object, as the patch’s purpose is clear and aligns with the series’ goal of simplifying alternates logic.
