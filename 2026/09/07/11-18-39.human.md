This is a refactoring patch in Patrick Steinhardt’s 11-patch series to unify Git’s terminology for “ref storage.” Patch 5/11 renames the `git rev-parse --show-ref-format` option to `--show-ref-storage-format` and keeps the old name as a hidden backward-compatible alias. The change is mechanical: it updates the option name in the documentation, the C implementation, shell completions, and ten test scripts. No functional changes are introduced; the patch exists solely to align the option name with the series’ goal of consistent terminology. The test updates are thorough, covering all affected code paths, and the backward-compatible alias ensures scripts relying on the old name continue to work. This is a low-risk, high-consistency cleanup that fits cleanly into the larger effort.
