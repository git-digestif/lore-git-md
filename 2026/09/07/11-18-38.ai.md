This is part 4 of Patrick Steinhardt’s 11-patch v2 series standardizing Git’s terminology for "ref storage format" across CLI options, environment variables, and configuration. The patch renames `--ref-format=` to `--ref-storage-format=` in `git submodule` and its helper, retaining the old name as a hidden backward-compatible alias.

The changes are mechanical: the patch updates `Documentation/git-submodule.adoc`, `builtin/submodule--helper.c`, `git-submodule.sh`, and one test script (`t/t7424-submodule-mixed-ref-formats.sh`). In the C helper, the new option is added alongside the old one with `PARSE_OPT_HIDDEN`, ensuring scripts using the old name continue to work. The shell script (`git-submodule.sh`) is updated to accept both `--ref-format` and `--ref-storage-format` as synonyms, and the test script is adjusted to use the new option name.

This patch is a straightforward refactoring with no functional changes. It aligns `git submodule` with the rest of the series, which has already renamed the option in `git init`, `git clone`, `git refs`, and `git rev-parse`. The backward-compatibility layer is thorough, covering both the C helper and the shell script, and the test updates ensure coverage remains intact. The patch is uncontroversial and ready for merging once the series as a whole is reviewed.
