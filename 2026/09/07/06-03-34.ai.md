This is a CI/build system follow-up in the ongoing thread about updating Git's CI to use Debian 12 instead of Debian 11. Patrick Steinhardt replies to Jeff King's patch, endorsing the change but proposing a refinement: using the `oldstable` Docker tag instead of `debian:12` to reduce future maintenance churn. The `oldstable` tag currently points to Debian 12 and will automatically track the next Debian release when it enters the oldstable phase, avoiding the need to manually update the CI configuration again in two years.

The suggestion is minor and pragmatic, touching only the `image` field in the CI files. It does not alter the patch's core goal (moving to a supported LTS release) or its scope (GitHub Actions and GitLab CI).
