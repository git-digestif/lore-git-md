This is a small platform-compatibility fix for a development helper script. The patch updates a Perl regex in `Documentation/lint-gitlink.perl` to avoid using the `{,n}` quantifier shorthand, which was introduced in Perl 5.34.0. Git's minimum Perl version is 5.26.0, so the script would fail on older installations. The change replaces `{,8}` with the equivalent but more widely supported `{0,8}`.

The patch touches only one line in a single file, making it a trivial and uncontroversial fix. The commit message clearly explains the motivation and the version constraint, and the change itself is mechanical. No tests are needed since this is a development tool rather than production code.

This is not part of any larger series; it stands alone as a minor cleanup. The fix is well-justified and aligns with Git's existing Perl compatibility policy. It should be safe to merge without further discussion.
