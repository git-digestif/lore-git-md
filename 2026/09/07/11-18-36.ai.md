This is part of Patrick Steinhardt's ongoing effort to unify and standardize Git's ref storage terminology. Specifically, this patch (2/11 in v2) renames the `--ref-format=` option in `git clone` to `--ref-storage-format=` while keeping the old name as a hidden alias. The change aligns `git clone` with a prior change to `git init` (referenced but not shown in this patch) and touches documentation, the command implementation, and seven test scripts to update option usage. The patch is mechanical and well-scoped, with no behavior change—only the user-facing option name is updated. The commit message is clear and the test coverage ensures the alias works and error messages remain accurate. This is a refactoring patch with a documentation component, part of a larger series that appears to be cleaning up ref-storage terminology across Git commands.
