This is the first patch in Beat Bolli’s three-part series improving `git imap-send`’s OpenSSL compatibility and certificate validation. It prepares the code for OpenSSL 4.1 by replacing the deprecated `ASN1_STRING_length()` with the new `ASN1_STRING_get_length()`. The patch adds a preprocessor macro that maps the new name to the old one when compiling against pre-4.1 versions, ensuring the code continues to work with both current and future OpenSSL releases.

The change is minimal—just six lines added—and touches only `imap-send.c`. It’s a forward-looking cleanup that avoids a deprecation warning and potential build breakage when OpenSSL 4.1 ships. No behavior change is introduced, so the risk is effectively zero. If you maintain a downstream Git package or care about OpenSSL compatibility, this patch is worth noting; otherwise, it’s a routine maintenance update.
