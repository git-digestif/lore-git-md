This is a three-patch series from Beat Bolli targeting `imap-send.c`, focusing on OpenSSL compatibility and correctness fixes.

The series addresses two correctness issues and one forward-compatibility concern. Patch 1 prepares the code for OpenSSL 4.1 by replacing a deprecated ASN1_STRING function with its newer equivalent, avoiding potential breakage when the old function is removed. Patch 2 fixes a bug where the code incorrectly assumed ASN1_STRINGs are NUL-terminated, which is not guaranteed by the OpenSSL API. Patch 3 aligns certificate validation with RFC 6125 by only checking the subject common name (CN) if no DNS subject alternative names (SAN) are present.

All changes are confined to `imap-send.c`, a self-contained file handling IMAP email submission. The patches look well-motivated and narrowly scoped, addressing specific API assumptions and standards compliance. No test failures or regressions are mentioned, but the fixes appear to target edge cases that might not be covered by existing tests. The series seems uncontroversial and ready for review.
