This is the first patch in an 11-patch series from Patrick Steinhardt that standardizes the naming of Git’s reference storage format options. The series addresses a long-standing inconsistency: the command-line flag `--ref-format=` clashes with the repository extension name `refStorage`, the environment variable `GIT_REFERENCE_BACKEND`, and the common documentation term “ref storage format.” The patch renames the flag to `--ref-storage-format=` in `git init`, updates the corresponding man pages, and keeps the old `--ref-format=` as a hidden alias for backward compatibility. Test scripts are updated to use the new flag name, and the commit message explains that the change paves the way for a future `--object-storage-format=` option without creating further naming conflicts. The patch touches 15 files, mostly documentation and test scripts, and is purely mechanical.
