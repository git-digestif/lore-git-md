Subject: [PATCH 0/3] imap-send: OpenSSL compatibility and correctness fixes
Series version: v1 (initial submission)
Originating author: Beat Bolli
Thread type: patch series

Core problem or goal
Three correctness and forward-compatibility fixes in `git imap-send`'s TLS certificate verification logic:
1. Replace a deprecated OpenSSL 4.1 ASN1_STRING function with its modern equivalent (now detailed: `ASN1_STRING_get_length()` replacing `ASN1_STRING_length()` via a version-gated macro).
2. Fix a latent bug: the code incorrectly assumed ASN1_STRINGs are NUL-terminated (they are not).
3. Align certificate validation with RFC 6125 by only falling back to checking the subject common name (CN) if no DNS subject alternative names (SANs) are present.
