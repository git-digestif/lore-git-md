This is the first patch in the v3 series "sequencer: defer auto maintenance until rebase completion," addressing feedback on the helper function `git_config_append_parameter()`. The patch introduces a reusable utility in `config.c` to build `GIT_CONFIG_PARAMETERS` strings with proper shell quoting, which the sequencer will use to disable auto maintenance during operations like `git rebase`, `git cherry-pick`, and `git revert`.

The author responds directly to Patrick Steinhardt’s surface-level review of v2: he will expand the commit message to explain that `GIT_CONFIG_PARAMETERS` is a space-separated list of `'key'='value'` pairs (each side single-quoted) used to pass `-c key=value` settings to child processes, and will document the format in the function’s header comment. The parameter name `env` will also be renamed to `buf` to avoid over-narrowing the helper’s purpose. These changes are purely clarifying and do not alter the patch’s functionality or structure.

The patch remains a straightforward refactoring with no open technical concerns. It is a prerequisite for the series’ core goal—deferring auto maintenance until sequencer completion—but does not itself change behavior. The author’s response confirms the changes will be included in v3, which is otherwise ready to post.
