This thread is about a small but important platform-compatibility fix for a development helper script. Tuomas Ahola identified that `Documentation/lint-gitlink.perl` uses a Perl regex quantifier shorthand (`{,8}`) that wasn't supported until Perl 5.34.0, while Git's minimum Perl version is 5.26.0. The patch replaces it with the equivalent but more widely supported `{0,8}` syntax.

The change is trivial—just one line in a single file—and uncontroversial. The commit message clearly explains the motivation and version constraint, and since this is a development tool rather than production code, no tests are needed. There’s no larger series or ongoing discussion; this is a standalone fix that aligns with Git’s Perl compatibility policy and should be safe to merge as-is. No objections or further feedback have been raised.
