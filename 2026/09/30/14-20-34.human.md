This is the first patch in Tamir Duberstein’s two-patch CI/build system series, now in its third iteration. It addresses a specific resource exhaustion issue in GitHub Actions CI: the `t4205-log-pretty-formats.sh` test generates a commit message larger than 2 GiB, and `test_cmp` (which uses `diff -u`) triggers an OOM kill when comparing it. The fix is simple and settled: replace `test_cmp` with `test_cmp_bin`, which uses `cmp` instead of `diff`. Benchmark data in the commit message shows `cmp` uses 1.2 MiB of memory and finishes in 0.5 seconds, compared to `diff -u`’s 4 GiB peak and 5.3 seconds. The patch touches only one line in `t/t4205-log-pretty-formats.sh` and has been endorsed by Jeff King, Junio C Hamano, and Patrick Steinhardt.

This is a well-motivated bugfix with clear evidence of the problem and solution. The change is minimal, targeted, and uncontroversial. It’s ready for integration and should have no impact beyond preventing CI failures in private repositories where GitHub runners have less memory. No further discussion is expected on this patch.
