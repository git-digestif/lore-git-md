This is the final patch in Jeff King’s seven-part series refactoring the xdiff subsystem’s buffer handling. It fixes a latent bug in the low-level merge machinery (`ll_ext_merge()`): when an external merge driver exits successfully (status 0) but its output file is missing or unreadable, the function returns `LL_MERGE_OK` with a `NULL` result buffer. Downstream callers like `rerere.c` then dereference this `NULL` buffer, leading to undefined behavior.

The patch forces `ll_ext_merge()` to return `LL_MERGE_ERROR` if `read_mmfile()` fails, regardless of the driver’s exit code. It also adds a regression test in `t/t4200-rerere.sh` that simulates the bug by configuring a custom merge driver that removes its own output file when instructed. The test verifies that `rerere` preserves the conflicted state rather than recording an empty resolution.

This is a targeted bugfix with no intended behavior changes outside the error path.
