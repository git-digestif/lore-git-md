This thread is about a small patch from Harald Nordgren that adds the `--label-ours`, `--label-theirs`, and `--label-base` options to `git stash pop`, mirroring functionality already available in `git stash apply`. The goal is to let users customize the conflict markers that appear when a stash pop results in a merge conflict.

Junio C Hamano, the maintainer, has raised a fundamental question about the patch: he’s not convinced these options should be exposed to users at all, even in `stash apply`. His review challenges the underlying motivation, tracing the feature back to internal machinery used by `git checkout` and suggesting that its presence in `stash apply` might have been a debugging convenience rather than a deliberate user-facing design. He’s asked the author to justify why users would routinely want to customize conflict markers when popping a stash, rather than simply accepting the default labels. The patch itself is technically sound, but its inclusion in the user interface is now in doubt. No other reviewers have weighed in yet, so the thread is waiting for the author to respond.
