This is the fifth patch in Jeff King’s v4 xdiff buffer-size refactoring series, now consolidated into a single commit that replaces the manual file-reading logic in `ll_ext_merge()` with a call to `read_mmfile()`. The patch touches only `merge-ll.c` and is purely mechanical: it removes 16 lines of open/stat/read/close boilerplate and replaces them with a single `read_mmfile()` call. The commit message highlights two behavior improvements that fall out of the refactoring: `read_mmfile()` uses `xsize_t()` to catch truncation risks, and it emits an error message to stderr when the file cannot be read, whereas the old code silently returned NULL. The patch is uncontested and procedurally ready; Junio has already acked the earlier patches in the series, and the only remaining loose end is a minor textual conflict with `jk/merge-ll-tempfile-cleanup` that Peff has offered to rebase if needed.
