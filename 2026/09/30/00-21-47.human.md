This is the second patch in Pablo Sabater’s five-patch series adding a `--dry-run` option to `git backfill`. It introduces an enum, `fetch_object_info_status`, so that `fetch_object_info()` can return a status code instead of dying when the server does not advertise the `object-info` capability. The enum has three values: `OK`, `ERR` (generic failure), and `NOT_ENABLED` (capability missing). This is a purely mechanical refactoring that enables the later dry-run implementation to handle servers that lack the capability gracefully. The patch touches only `fetch-object-info.h` and adds six lines. No behavior changes yet; the actual conversion of `fetch_object_info()` to use the enum comes in the next patch.
