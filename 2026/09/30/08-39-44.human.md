This is a call for contributions to the next **Git Rev News** edition (139). Git Rev News is the project's monthly newsletter, covering recent developments, community updates, interviews, and technical deep dives.

The draft for edition 139 is now open for review and additions [on GitHub](https://github.com/git/git.github.io/blob/master/rev_news/drafts/edition-139.md). Contributions are welcome in any form: proofreading, article suggestions, links to relevant discussions, or volunteering for interviews. The editors (Christian Couder, Jakub Narębski, Markus Jansen, and Kaartic Sivaraam) aim to publish the edition on **October 2, 2026**.

This is a low-pressure, community-driven effort—no technical expertise is required to help. If you’ve been part of recent discussions, have insights to share, or just want to improve the draft, this is a great way to participate. Replies to the email or edits via GitHub pull request are both accepted.
