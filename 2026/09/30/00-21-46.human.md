This is the first patch in Pablo Sabater’s five-part series adding a `--dry-run` option to `git backfill`. It is a small, preparatory documentation update: the comment in `transport-internal.h` describing the `fetch_object_info()` callback is tweaked to reflect that the `object-info` server capability can now return the object type, or even just confirm existence without returning size or type. The change is purely textual—no code or behavior is altered. It sets the stage for the subsequent refactoring patches that will make `fetch_object_info()` return status codes instead of dying, allowing `git backfill --dry-run` to handle servers that lack the `object-info` capability gracefully.
