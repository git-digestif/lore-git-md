This is the second patch in Pablo Sabater’s five-patch series adding a `--dry-run` option to `git backfill`. It introduces the `enum fetch_object_info_status` in `fetch-object-info.h` so that `fetch_object_info()` can return a status code instead of dying when the server does not advertise the `object-info` capability. The enum has three values: `FETCH_OBJECT_INFO_OK`, `FETCH_OBJECT_INFO_ERR`, and `FETCH_OBJECT_INFO_NOT_ENABLED`, which will allow the caller (in a later patch) to handle the fallback case gracefully. The change is purely preparatory and does not alter any behavior yet.
