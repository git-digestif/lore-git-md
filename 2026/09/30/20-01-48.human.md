This is a minor follow-up in Pablo Sabater’s patch series adding `--dry-run` to `git backfill`. Junio C Hamano suggests a small but meaningful refinement to the enum value name introduced in patch 3/5: replacing `FETCH_OBJECT_INFO_NOT_ENABLED` with `FETCH_OBJECT_INFO_NOT_AVAILABLE`. The change is cosmetic but clarifies semantics—"not available" avoids implying the server could enable the capability but chose not to, instead covering both cases where the server lacks support or simply declines to provide it. Pablo has accepted the suggestion, and the rename will appear in the upcoming v2 of the series, along with the corresponding update to the `die()` message in `git cat-file`. This is a surface-level improvement with no functional impact, but it removes a subtle ambiguity in the API. The series remains stalled on the larger conceptual question raised by Derrick Stolee: whether the `--dry-run` feature addresses a real user need.
