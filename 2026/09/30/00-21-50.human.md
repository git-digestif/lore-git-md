This is the final patch in Pablo Sabater’s five-part series adding a `--dry-run` option to `git backfill`. It extends the dry-run output to report not just the number of missing blobs but also their total uncompressed size when the remote server supports the `object-info` capability. If the server lacks that capability, it gracefully falls back to showing only the count.

The patch is clean and well-explained: it updates the man page to clarify that the reported size is an upper bound (since blobs are stored compressed and deltified), adds the necessary transport plumbing to query object sizes, and updates the output format to include the size in human-readable units (KiB). Tests verify both the object-info and non-object-info code paths. The implementation looks solid and addresses the feedback goal from the cover letter—giving users a meaningful preview of the download cost.
