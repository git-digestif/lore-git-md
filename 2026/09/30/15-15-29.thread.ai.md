Subject: [PATCH] refs/packed-backend: optimize packed-refs file rewrites
Series version: standalone patch (no series)
Originating author: Karthik Nayak <karthik.188@gmail.com>
Thread type: performance optimization patch

Core problem or goal
Speed up operations that rewrite the packed-refs file (e.g., deleting references) by avoiding redundant formatting of unchanged refs. The current implementation uses `fprintf()` for every entry; the patch tracks raw byte positions of unchanged refs and writes them directly with `fwrite()`.

Current status
Under review. No prior versions. No maintainer decision recorded.

Key technical details
- Files touched: `refs/packed-backend.c` only
- New/renamed symbols: `record_start` field added to `struct packed_ref_iterator`; `write_packed_entry()` now accepts a `raw` parameter
- Behavior change: unchanged refs are written as raw bytes instead of being reformatted
- On-disk format: unchanged
- Test coverage: performance benchmark included (deleting 100,000 packed refs, ~20% speedup from 28.7 ms to 23.8 ms)
