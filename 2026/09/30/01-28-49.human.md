This is the second patch in Taylor Blau’s four-patch series fixing MIDX reachability-closure corner cases. It targets a specific bug in `git pack-objects --stdin-packs=follow` where the walk starts only from commit objects, causing MIDXs to miss trees and tags that are not reachable from any commit in the closure.

The fix adds trees and tags from included and excluded-open (`!`) packs (and loose objects with `--unpacked`) as extra roots in `--stdin-packs=follow` mode. These roots are walked after the commit traversal to preserve path prefixes for delta attributes. The patch includes thorough test coverage in `t5331-pack-objects-stdin.sh` and `t7704-repack-cruft.sh`, verifying that the walk now rescues descendants of lone trees and tags, and respects delta attributes for subtree contents.

The commit message is detailed and explains both the problem (MIDXs failing to generate bitmaps when cruft packs contain unreachable trees/tags) and the solution (adding trees and tags as roots). The code changes are confined to `builtin/pack-objects.c` and the documentation, with no on-disk format changes. This is a well-motivated, narrowly scoped fix that addresses a real issue in the MIDX and cruft-pack machinery. The patch looks solid and is unlikely to be controversial.
