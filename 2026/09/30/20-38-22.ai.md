This is a test-case contribution for the ongoing `git filter-branch` `--state-branch` bugfix. Michele Locati provides a new test that directly exercises the commit-mapping inversion bug Patrick Steinhardt requested coverage for. The test performs an incremental two-run rewrite: the second run must attach the new commit to the parent rewritten by the first run, and the saved state file must contain correctly ordered "original:rewritten" entries. Without the fix, the new commit attaches to the original (un-rewritten) parent, causing the test to fail at `test_cmp_rev`. Michele confirms the test fails on current `master` (a018953) without the fix, passes with the fix, and also passes on Git v2.49.1 (the last version before the regression was introduced). He invites Grant Moyer to squash the test into the original patch. The test is self-contained, touches only `t/t7003-filter-branch.sh`, and adds no new symbols or on-disk format changes. It directly addresses the open test-coverage question raised in the thread and removes the last blocker for merging the fix.
