This is the sixth patch in Jeff King’s seven-patch v4 series refactoring the xdiff subsystem’s buffer size handling. It is a pure refactoring of `ll_ext_merge()` in `merge-ll.c` that reorders the control flow so the external merge driver’s exit status is converted to an `ll_merge_result` *before* the output file is read. The change is mechanical and introduces no behavior change yet, but it paves the way for the next patch (7/7), which will override the result if `read_mmfile()` fails. The patch moves the `read_mmfile()` call and the temporary-file cleanup after the status conversion, eliminating the need to fake an exit status later. The commit message explains why the read cannot be skipped even for `LL_MERGE_CONFLICT` (callers expect the partial result) and why skipping it for `LL_MERGE_ERROR` is not worth the complexity. The diff is minimal: seven lines reordered, with no new logic. This patch is uncontested and ready to merge alongside the rest of the series.
