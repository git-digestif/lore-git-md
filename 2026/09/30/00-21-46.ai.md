This is the first patch in Pablo Sabater’s five-patch series adding a `--dry-run` option to `git backfill`. It updates a comment in `transport-internal.h` to reflect the expanded capabilities of the `object-info` server feature: the callback can now report object type, size, or neither (just existence), not just size. The change is purely documentary and prepares the ground for the subsequent refactoring patches that will make `fetch_object_info()` return status codes instead of dying. No code behavior is altered.
