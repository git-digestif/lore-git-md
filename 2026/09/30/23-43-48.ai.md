This is the v2 cover letter for Jeff King’s seven-patch series converting the xdiff subsystem’s `mmfile_t` buffer sizes from `unsigned long` to `size_t`. The series is a refactoring plus a latent bugfix: it eliminates integer-overflow risks, consolidates the redundant `mmbuffer_t` type, defensively NUL-terminates all `mmfile_t` buffers via `xmallocz()`, and fixes a long-standing error-handling flaw in `ll_ext_merge()` where a successful external merge driver (exit code 0) with an unreadable output file could return `LL_MERGE_OK` with a `NULL` buffer, leading to undefined behavior in downstream callers like `rerere.c`.

The v2 reorders the patches so the defensive NUL-termination lands before the refactoring, eliminating an intermediate unsafe state. It also incorporates Junio’s stylistic suggestion for the regression test (replacing `chmod 0` with `rm`) and documents the new error-message behavior in the commit message. The series is now down to five patches after squashing follow-up fixes into the main bugfix patch. All technical concerns raised in review have been addressed; the remaining discussion is about commit-message clarity and defensive-programming philosophy.
