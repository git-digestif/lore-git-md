This thread is about adding `@{p}` as a shorthand for `@{push}` in Git’s revision syntax, mirroring the existing `@{u}` shorthand for `@{upstream}`. The patch, authored by Harald Nordgren, addresses a long-standing inconsistency where `@{u}` was introduced in 2010 alongside `@{upstream}`, but `@{push}` (added in 2015) lacked a similar shorthand. The change is purely additive, improving user convenience without altering existing behavior.

The patch has been queued in Junio Hamano’s `seen` branch with an unconditional intent to graduate to `next` and later `master`. No technical objections remain, and the only remaining task is for Harald to send a v2 with an updated commit message incorporating the historical context Junio provided. Participants, including D. Ben Knoble and Jeff King, have either supported the change or clarified historical discussions without raising concerns. The thread is now in a holding state awaiting the v2, after which the patch will proceed through the usual integration process.
