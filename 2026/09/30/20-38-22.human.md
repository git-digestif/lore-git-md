This is a test-case contribution for the ongoing `git filter-branch` `--state-branch` bugfix. Michele Locati provides a targeted test that directly exercises the commit-mapping inversion bug Patrick Steinhardt requested coverage for. The test performs an incremental rewrite in two runs: the second run must attach the new commit to the parent rewritten by the first run, and the saved state must contain "original:rewritten" entries. Without the fix, the new commit attaches to the original parent instead, causing the test to fail at `test_cmp_rev`. Michele confirms the test fails on `master` without the fix, passes with it, and also passes on Git v2.49.1 (the last version before the regression was introduced). The test is self-contained, touches only `t/t7003-filter-branch.sh`, and is ready to be squashed into Grant Moyer’s original patch. No new symbols or on-disk format changes are introduced. This addresses the last open technical blocker for the patch series.
