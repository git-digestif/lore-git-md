This is a brief follow-up in Pablo Sabater’s five-patch series adding `--dry-run` to `git backfill`. The patch in question refactors `fetch_object_info()` to return a status code instead of dying when the server lacks the `object-info` capability, allowing the dry-run feature to fall back gracefully.

Junio C Hamano suggested renaming the `FETCH_OBJECT_INFO_NOT_ENABLED` enum value to `FETCH_OBJECT_INFO_NOT_AVAILABLE` to avoid implying the server could enable the capability but chose not to. Pablo accepts the suggestion and will update both the enum and the corresponding `die()` message in `git cat-file` for consistency. The change is purely semantic and does not affect functionality. The next revision (v2) will incorporate this tweak alongside the already-planned squash of the enum-addition patch into this one. No other feedback has surfaced on this patch.
