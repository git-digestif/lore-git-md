# Thread deltas

## 2026/09/04

- [2026/09/04/10-36-01 by Patrick Steinhardt <ps@pks.im>] Patrick Steinhardt posted an 11-patch series unifying ref storage terminology: renaming `--ref-format=` to `--ref-storage=` in git-init/clone/refs/submodule, `--show-ref-format` to `--show-ref-storage`, `default-ref-format` to `default-ref-storage`, `GIT_REFERENCE_BACKEND`/`GIT_DEFAULT_REF_FORMAT` to `GIT_REF_STORAGE`/`GIT_DEFAULT_REF_STORAGE`, and `init.defaultRefFormat` to `init.defaultRefStorage`, keeping the old names as hidden aliases for backwards compatibility, and extending `--ref-storage=` to accept URIs with a payload (e.g. `files://foo/bar`).
- [2026/09/04/13-05-20 by Karthik Nayak <karthik.188@gmail.com>] Karthik Nayak, reviewing patch 01, asked whether the option's argument value should also be called "ref-storage", noted that keeping the old `--ref-format` as a hidden alias preserves backwards compatibility, and observed that the error message already said "ref storage" even while the option was named `ref_format`.
- [2026/09/04/13-12-35 by Karthik Nayak <karthik.188@gmail.com>] Karthik Nayak agreed with patch 07, which moves the URI-parsing code from setup.c into refs.c as `ref_storage_format_by_uri()` and uses it at all call sites.
- [2026/09/04/13-20-30 by Karthik Nayak <karthik.188@gmail.com>] Karthik Nayak asked on patch 09 whether a `GIT_DEFAULT_REF_STORAGE_ENVIRONMENT` macro should also be added and used alongside `GIT_REF_STORAGE_ENVIRONMENT`, saying the rest of the changes looked in order.
- [2026/09/04/13-23-47 by Karthik Nayak <karthik.188@gmail.com>] Karthik Nayak said the series was relatively easy to read, that he had a small question and a nit, and that it otherwise looked good.
- [2026/09/04/17-15-10 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano objected that unless everything is unified into a single "ref-storage-format", neither "ref-storage" nor "ref-format" is sufficiently clear: "ref-format" does not convey which aspect of refs (storage vs. name), and "ref-storage" does not convey which aspect of storage (format vs. medium).
