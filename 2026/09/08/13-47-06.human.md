This is a surface-level review of patch 7/11 in Patrick Steinhardt’s ref-storage terminology series. Kaartic Sivaraam notes that the patch changes error messages to show the full URI (e.g., `garbage://hello-world`) instead of just the format name (e.g., `garbage`). While this is technically accurate, he suggests rewording the error to clarify that the entire configuration is invalid, proposing "invalid ref storage format configuration: 'garbage://hello-world'" instead of "unknown ref storage format: 'garbage://hello-world'". The feedback is purely editorial and does not question the patch’s correctness or design. No other issues are raised.
