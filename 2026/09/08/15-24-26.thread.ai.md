Thread identity: Patch series addressing a cross-compilation issue in Git's Rust build script (`src/cargo-meson.sh`), specifically for the Meson build system. Originating author: James Le Cuirot.

Core problem or goal: Fix a bug in `src/cargo-meson.sh` where the script fails to locate the compiled Rust library (`libgitcore.a`) when `CARGO_BUILD_TARGET` is set, even if it matches the native target. The issue arises because Cargo writes the library to `$BUILD_DIR/$CARGO_BUILD_TARGET/$BUILD_TYPE/`, while the script assumes `$BUILD_DIR/$BUILD_TYPE/`. The patch ensures the script respects `CARGO_BUILD_TARGET` in the output path using shell parameter expansion (`${CARGO_BUILD_TARGET-}`).
