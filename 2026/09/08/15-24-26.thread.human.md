This thread is about a fix for a cross-compilation issue in Git's Rust build infrastructure, affecting both the Meson and `make`-based build systems. The problem occurs when `CARGO_BUILD_TARGET` is set: Cargo writes the compiled Rust library (`libgitcore.a`) to a target-specific subdirectory, but the build scripts previously assumed it would be in the top-level build directory. James Le Cuirot's v2 patch resolves this by updating both `src/cargo-meson.sh` and the `Makefile` to respect `CARGO_BUILD_TARGET` in the output path, ensuring consistency with Cargo's behavior.
