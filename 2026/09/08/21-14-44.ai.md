This is a small but user-facing improvement to Git's advice system. The patch addresses a UX papercut: when Git suggests disabling the `defaultBranchName` advice with `git config set advice.defaultBranchName false`, the command only affects the current repository, not future ones. The patch changes the suggestion to recommend `git config set --global` instead, which is what users almost certainly want in this case.

The implementation adds a `global_hint` boolean field to the `advice_setting` struct and sets it to `true` for `ADVICE_DEFAULT_BRANCH_NAME`. The `vadvise()` function now checks this field and conditionally includes `--global` in the turn-off instructions. The change is contained to `advice.c` and touches only the advice machinery, not any other subsystems.
