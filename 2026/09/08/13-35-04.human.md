This is a small but practical review of a user-facing documentation fix in the advice subsystem. The patch, originally from Vsevolod Myalitsin, updates the on-screen instructions for disabling the `defaultBranchName` advice message to recommend `--global` instead of `set`, ensuring the setting applies globally rather than just to the current repository.

Ben Knoble’s review is surface-level but constructive. He agrees with the goal but suggests a tweak to the command syntax: using `git config set --global` (the modern form) instead of `git config --global`. He also raises a scalability concern—if other advice keys later need global defaults, the current hardcoded `strcmp` check would become unwieldy—and proposes extracting a helper function to determine whether a given advice key should use `--global`.

The discussion is minor and focused, with no controversy or deeper technical debate. The patch itself is well-motivated and low-risk, addressing a real usability papercut. Ben’s feedback is reasonable but not urgent; it’s more about future-proofing than fixing a flaw in the current change. If the author incorporates the helper function suggestion, the patch will be even cleaner, but even as-is, it’s a clear improvement over the status quo. Worth a quick look for anyone interested in Git’s advice system or usability tweaks.
