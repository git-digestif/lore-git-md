This thread is about a bugfix for the multi-pack-index (MIDX) subsystem that prevents Git from publishing empty MIDX layers, which can cause subsequent bitmap writes to fail. The issue affects all MIDX write modes—incremental, non-incremental, and compaction—and was introduced as a regression. Pia Park’s v2 patch addresses the core problem by exiting early in `write_midx_internal()` when no objects are found, avoiding the creation of invalid layers.

The patch is under review, with Taylor Blau’s feedback shaping its evolution. The main discussion now centers on exit status consistency: should `git multi-pack-index write` return silent success (exit code 0) when no packs are present, mirroring the behavior of commands like `git repack -d`? Pia has proposed this alignment and is seeking Derrick Stolee’s input before finalizing a v3. The test suite is also being refined to focus on the core regression, with Taylor suggesting simplifications to avoid redundancy.

Key participants include Pia (author), Taylor (reviewer), and Stolee (sought for input). The fix touches `midx-write.c` and adds regression tests in `t/t5334` and `t5326`. No merge status has been reported, and the thread remains open pending resolution of the exit status question. Pia’s availability at Git Merge in Lisbon may help move the discussion forward.
