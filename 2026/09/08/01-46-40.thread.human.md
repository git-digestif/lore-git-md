This thread is about a bugfix for the multi-pack-index (MIDX) subsystem, where a regression causes Git to publish empty MIDX layers (with zero objects) without a reverse index, leading to failures in subsequent `--bitmap` writes. The patch, now in its second version, prevents publication of empty layers entirely by exiting early in `write_midx_internal()` when no objects are found.

Key participants include Pia Park (the author), Taylor Blau (who identified the broader scope of the bug and provided feedback on test refinements), and Junio C Hamano (who pinged the thread to check progress). The patch is under review, with the main open question being whether empty MIDX writes—including the "no packs" case—should return silent success (exit code 0) to align with commands like `git repack -d`. Derrick Stolee’s input on this is still pending, and Pia has signaled readiness to prepare a third version once this is resolved.

Progress stalled after Pia’s October 8 follow-up, where she proposed aligning the exit status but never properly resent the v3 patch. Taylor Blau’s recent reply confirms no further discussion has occurred, and the missing v3 submission is now a procedural blocker. The patch is otherwise ready, but without Stolee’s input or a resubmission, it remains in limbo. No merge status has been reported.
