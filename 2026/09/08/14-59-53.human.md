This is a documentation fix targeting the advice subsystem. Vsevolod Myalitsin’s patch series (a single patch in its initial version) corrects the on-screen instructions for disabling the `defaultBranchName` advice message, recommending `git config --global` instead of `git config set` to ensure the setting applies globally rather than just to the current repository.

The discussion has now advanced to a design refinement. Vsevolod proposes extending the `advice_setting` struct with a new `global_hint` field, allowing each advice key to specify its intended scope directly. This approach keeps the logic clean and avoids hardcoding key-specific behavior in the `vadvise()` helper. Ben Knoble, who previously suggested a helper function, now endorses this struct-based design as preferable.

The change remains small and self-contained, touching only `advice.c` and altering the displayed command string without affecting on-disk formats or introducing new symbols. No test coverage has been added, but the modification is considered low-risk. The only remaining open question is whether to adopt the more explicit `set --global` syntax (Ben’s earlier preference), though the current proposal uses `--global` alone, which is functionally equivalent.

This is a well-motivated, narrowly scoped fix that addresses a real usability issue. The design discussion is constructive and focused on maintainability, suggesting the patch is likely to land in a form close to the current proposal.
