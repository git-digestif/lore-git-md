This is a security feature patch that adds OCSP staple validation to Git’s HTTPS certificate verification. The patch introduces a new boolean configuration option, `http.sslVerifyStatus` (default `false`), which enables libcurl’s `CURLOPT_SSL_VERIFYSTATUS` to check for stapled OCSP responses. When enabled, Git will reject HTTPS connections if the server does not provide a valid staple, closing a security gap where revoked certificates could otherwise be accepted. This is particularly relevant for government and FIPS-compliant users (e.g., US Department of Defense PKI), where OCSP stapling is mandated but OpenSSL-linked Git binaries currently ignore staples.
