This thread is about a small but practical improvement to Git’s advice system. Vsevolod Myalitsin identified a minor but persistent UX annoyance: when Git suggests disabling the `defaultBranchName` advice, it tells users to run `git config set advice.defaultBranchName false`, which only affects the current repository. Most users would prefer this setting to apply globally, so the patch tweaks the advice message to recommend `git config set --global` instead.

The change is minimal and focused. It adds a `global_hint` flag to the `advice_setting` struct, sets it for `ADVICE_DEFAULT_BRANCH_NAME`, and updates the `vadvise()` function to include `--global` in the turn-off instructions when the flag is set. The patch touches only `advice.c` and doesn’t require new tests, as the advice system is already well-covered. There’s no broader discussion or controversy here—just a straightforward fix for a real, if minor, pain point. The patch is now at v2, suggesting it was previously sent and likely received no objections or only minor feedback. Unless someone raises a concern, this looks ready to be picked up.
