This is the tenth patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. The patch enforces a long-documented constraint in `git multi-pack-index --object-dir=`: the specified object directory must be an alternate of the current repository. Previously, Git would silently create an ad-hoc ODB source for non-alternate directories, contradicting the documentation and creating the last real-world caller of the ad-hoc source mechanism outside test helpers. Justin Tobler’s review confirms the change aligns with the intended behavior and removes the unintended workaround introduced in 2025.

The patch replaces the ad-hoc source creation with an explicit error message, making the constraint visible to users. It also updates one test chain in `t5319-multi-pack-index.sh` to retain a temporary repository (`repo64`) that provides the required alternate relationship, ensuring the test remains valid. The change is a breaking change in the strictest sense, but it aligns with documented behavior since 2021 and removes the only remaining non-test caller of the ad-hoc source API, clearing the way for its complete removal in the final patch of the series.
