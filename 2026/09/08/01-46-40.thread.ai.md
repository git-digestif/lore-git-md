Subject: [PATCH] midx: avoid publishing empty incremental layers
Series version: standalone patch (no series)
Originating author: Pia Park <pia@pierre.co>
Thread type: bugfix patch

Core problem or goal
A regression in the multi-pack-index (MIDX) subsystem causes MIDX writes (not limited to incremental writes) to publish empty layers (zero objects) without a reverse index. Subsequent writes with `--bitmap` fail when attempting to load the missing reverse index for the empty layer. The patch aims to prevent publication of empty MIDX layers entirely, regardless of write mode.

Current status
Under review. No prior versions. No merge status reported. The patch is likely to be revised to address Taylor Blau’s feedback about the bug’s scope.

Key technical details
- Files touched: `midx-write.c`, `t/t5334-incremental-multi-pack-index.sh`
- New test cases: three regression tests covering empty initial layers, empty packs, and packs with only duplicate objects (may require adjustment if the fix’s scope expands)
- Behavior change: proposed fix would exit early in `write_midx_internal()` for *any* MIDX write (incremental or not, compacting or not) when no objects are found, avoiding lock acquisition, temporary file creation, and publication of invalid layers
- Subsystem: MIDX (multi-pack-index), performance-critical for large repositories
- On-disk format: no changes; the fix prevents publication of invalid layers
- Symbols/functions: `compute_sorted_entries()`, `write_midx_internal()`

Open questions and loose ends
1. **Bug scope**: Is the issue limited to incremental non-compacting writes, or does it affect all MIDX writes (incremental/compacting/non-incremental) when no objects are present? Taylor Blau’s testing suggests the latter.
2. **Fix scope**: Should the fix target only incremental non-compacting writes (current patch) or all MIDX writes (Taylor’s proposed approach)? The broader fix would replace the warning for bitmap-less empty MIDXs with an error and early exit.
3. **Test adjustments**: If the fix expands to cover all MIDX writes, the existing regression tests may need updates to reflect the new behavior.
