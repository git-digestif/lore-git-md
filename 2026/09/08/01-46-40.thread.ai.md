Subject: [PATCH v2] midx: avoid publishing empty incremental layers
Series version: standalone patch, v2
Originating author: Pia Park <pia@pierre.co>
Thread type: bugfix patch

Core problem or goal
A regression in the multi-pack-index (MIDX) subsystem causes MIDX writes—regardless of mode (incremental, non-incremental, or compaction)—to publish empty layers (zero objects) without a reverse index. Subsequent writes with `--bitmap` fail when attempting to load the missing reverse index for the empty layer. The patch prevents publication of empty MIDX layers entirely by exiting early in `write_midx_internal()` when no objects are found.

Current status
Under review. This is the second version of the patch, addressing Taylor Blau’s feedback that the bug affects all MIDX write modes, not just incremental non-compacting writes. No merge status reported.

Key technical details
- Files touched: `midx-write.c`, `t/t5334-incremental-multi-pack-index.sh`, `t5326-multi-pack-bitmaps.sh`
- New test cases: three regression tests in `t/t5334` covering empty initial layers, empty packs, and packs with only duplicate objects. The existing test in `t5326` is updated to reflect the new behavior (no empty MIDX or bitmap).
- Behavior change: `write_midx_internal()` now exits early for *any* MIDX write when no objects are found, avoiding lock acquisition, temporary file creation, and publication of invalid layers. The exit status remains 0 for compatibility with callers.
- Subsystem: MIDX (multi-pack-index), performance-critical for large repositories.
- On-disk format: no changes; the fix prevents publication of invalid layers.
- Symbols/functions: `compute_sorted_entries()`, `write_midx_internal()`.

Open questions and loose ends
1. **Exit status**: Should the fix return success (0) or an error for empty writes? The current patch preserves the existing exit status for compatibility, but this may be debated.
2. **Test adjustments**: The regression tests are comprehensive but may require further refinement if the exit status or other behavioral details change.
