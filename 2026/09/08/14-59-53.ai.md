This is a documentation-adjacent patch in the advice subsystem, part of an ongoing thread about how to instruct users to disable the `defaultBranchName` advice message. The author (Vsevolod Myalitsin) has revised the approach in response to Ben Knoble’s review, proposing a cleaner design that adds a `global_hint` field to the `advice_setting` struct instead of hard-coding the logic in the `vadvise()` helper.

The change is small and surgical: it modifies the `advise()` machinery so that the `defaultBranchName` advice message now recommends `git config --global advice.defaultBranchName false` (or `git config set --global ...` if the author adopts Ben Knoble’s preferred syntax) instead of the repository-local `git config set advice.defaultBranchName false`. All other advice keys continue to use the original wording. The patch touches only `advice.c`, introduces no new symbols, and leaves the on-disk format untouched. No tests were added, but the change is self-contained and low-risk.

Ben Knoble’s review was substantive: he engaged with the design, suggested a refactoring for future extensibility, and now endorses the revised approach. The open question is whether to use `--global` or `set --global` in the displayed command; the author’s current proposal uses the former, but the latter is the more modern and explicit form. The thread is still under review, with no objections raised so far.
