Core problem or goal
Git’s advice system currently suggests disabling the `defaultBranchName` advice with a repository-local `git config set` command, but users almost always want this setting to apply globally. The patch modifies the advice machinery to recommend `git config set --global` instead for this specific advice.

Current status
Under review; v2 posted. No prior version summary available, but the v2 designation implies at least one earlier iteration.

Key technical details
- Files touched: `advice.c` only.
- New field: `global_hint` (boolean) added to `struct advice_setting`.
- Modified function: `vadvise()` now checks `global_hint` and conditionally emits `--global` in the turn-off instructions.
- Symbols: `ADVICE_DEFAULT_BRANCH_NAME` is the only advice setting with `global_hint = true`.
- No new CLI options, config keys, or on-disk format changes.
