The v2 patch expands the fix to cover *all* MIDX write modes (not just incremental non-compacting writes) and skips publication entirely when no objects are found, preserving the existing silent-success exit status.

The commit message clearly traces the regression’s origin (2018’s empty-MIDX behavior and 2025’s reverse-index requirement) and provides a minimal reproduction. Taylor Blau’s feedback from v1 is fully addressed: the fix now applies universally, avoids lock acquisition for empty writes, and maintains backward compatibility with existing callers.
