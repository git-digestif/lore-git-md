This is a small but sensible usability patch from Vsevolod Myalitsin. The advice message for configuring the default branch name currently suggests running `git config set advice.defaultBranchName false`, which only affects the current repository. Since the default branch name is a global setting (applies to all new repositories), the advice should recommend using `--global` instead.

The patch adds a `global_hint` field to the `advice_setting` struct, sets it to `true` for `ADVICE_DEFAULT_BRANCH_NAME`, and modifies the advice output to include `--global` in the suggested command when the hint is enabled. The change is minimal—just 8 lines added, 6 removed—and touches only `advice.c`.

The motivation is clear: the current advice is misleading because it doesn’t solve the problem it claims to. The fix is straightforward and doesn’t introduce new behavior, just corrects the guidance. No controversy is evident, and the patch looks well-crafted for its scope. Worth a quick review if you care about user-facing hints.
