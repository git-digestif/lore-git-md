Key technical details
- **ODB refactoring**: Patrick Steinhardt’s `ps/odb-*` topics abstract the object database, touching `odb/source.c`, `builtin/clone.c`, and `builtin/fsck.c`. These include API simplifications (`ps/odb-stop-registering-in-memory-sources`), alternates setup timing (`ps/odb-alternates-at-creation`), and fsck pluggability (`ps/odb-pluggable-fsck`).
- **Reftable backend**: `kn/reftable-optimize-reloading` reduces syscalls during ref writes, a critical optimization for scalability.
- **Pathspecs**: `yt/pathspec-negative-prefix` fixes a memory safety issue in negative pathspec handling, while `jc/pathspec-match-const` improves code hygiene.
- **Hooks**: `kn/receive-report-hook` introduces a new hook for filtering/modifying packet-line status reports, potentially impacting server-side workflows.
- **Performance**: `tn/fetch-pack-trace-packfile-uri` adds Trace2 observability for packfile URI downloads, and `tc/last-modified-bloom` optimizes `git last-modified` with Bloom filters.
- **Documentation**: `maintenance-doc-bullet-fix` corrects a misrendered bullet point in `Documentation/git-maintenance.txt`; the patch is trivial but now explicitly tied to procedural expectations (reroll or abandonment).
- **Breaking changes**: `bc/restrict-hex-to-lowercase` (not listed in this report but mentioned in prior summaries) prepares for Git 3.0 by rejecting uppercase hex in object IDs.
- **Safety checks**: `en/no-amend-during-conflicts` blocks `--amend` and partial commits during conflict resolution, aligning with existing protections for `cherry-pick`/`merge`.
