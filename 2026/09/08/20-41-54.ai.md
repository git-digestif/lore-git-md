This is the third patch in the **`git history squash` v15 series**, a refactoring that extracts the squash-message template helpers from `sequencer.c` into reusable functions in `sequencer.h`. The goal is to let `git history squash` (introduced later in the series) generate the same editor template as `git rebase -i` when combining commits.

The patch moves three static helpers—`add_squash_combination_header()`, `add_squash_message_header()`, and `squash_subject_comment_len()`—out of `sequencer.c` and into the header, along with the `todo_item_flags` enum that callers need to interpret the output of `todo_list_rearrange_squash()`. The changes are purely mechanical: the logic is unchanged, but the code is now accessible to other commands. No behavior changes are introduced.
