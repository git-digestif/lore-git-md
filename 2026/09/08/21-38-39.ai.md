This is a documentation-adjacent code patch in the advice subsystem, part of an ongoing thread to correct the on-screen instructions for disabling the `defaultBranchName` advice. The author, Vsevolod Myalitsin, has accepted Junio C Hamano’s architectural feedback and will revise the patch to use a more general `scope_hint` field (replacing the previous `global_hint`) and to pass the entire `advice_setting` struct to `vadvise()` instead of individual fields. This change narrows the interface and makes the code more future-proof, allowing other advice keys to suggest different configuration scopes (e.g., `--system`) without further refactoring.

The patch touches `advice.c` and modifies the `advice_setting` struct to include a `scope_hint` field, which will be set to `CONFIG_SCOPE_GLOBAL` for `defaultBranchName` and left as the default for other keys. The `vadvise()` helper will now receive a pointer to the struct, making it unaware of specific advice keys and thus easier to extend. The behavior change remains the same: the displayed command will recommend `git config --global advice.defaultBranchName false` (or possibly `git config set --global ...` if Ben Knoble’s syntax preference is adopted) instead of the current repository-local `git config set ...`.

The unresolved syntax preference (`--global` vs `set --global`) is still pending, but the architectural direction is settled.
