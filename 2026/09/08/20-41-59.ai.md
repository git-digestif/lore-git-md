The implementation builds on the series' earlier work (range validation, ref protection, and `--no-edit` support) by adding a new `build_squash_message()` helper in `builtin/history.c`. This function:
- Parses the revision range into a `todo_list` using `todo_list_parse_insn_buffer()`.
- Rearranges the list with `todo_list_rearrange_squash()` to group autosquash markers under their targets.
- Constructs an editor template that comments out `fixup!` messages, retains `squash!` bodies, and lets `amend!` replace its target unless a preceding `squash!` requires both bodies.
- Uses existing sequencer helpers (`add_squash_combination_header`, `add_squash_message_header`) to format the template consistently with interactive rebase.

The patch also updates `resolve_squash_range()` to pass the `edit_message` flag and build the template when editing is enabled, and modifies `cmd_history_squash()` to pass `COMMIT_TREE_EDIT_MESSAGE` to `commit_tree_ext()` when `--edit` is active (the default).
