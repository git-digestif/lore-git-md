# Thread deltas

## 2026/09/08

- [2026/09/08/13-27-55 by Juha-Matti Tilli <juha-matti.tilli@iki.fi>] Juha-Matti Tilli reported that git send-email 2.34.1 exits immediately upon receiving an SMTP rate-limiting error ("4.7.1 Error: too many recipients") instead of sleeping and asking the user whether to continue; the error occurred at mail 8/12 of a 13-mail series with 18 recipients per mail, and resuming from the first unsent patch caused the remaining mails to be sent in a different thread. He expects Git to sleep (e.g., 60 seconds) and prompt to continue on such errors, and plans to use --batch-size=4 --relogin-delay=60 for the next patchset.
