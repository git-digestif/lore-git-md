The patch introduces `http.sslVerifyStatus`, a boolean configuration option (default `false`) that enables OCSP staple validation via libcurl’s `CURLOPT_SSL_VERIFYSTATUS`. When enabled, Git will refuse HTTPS connections to servers that do not provide a valid OCSP staple, closing a security gap where revoked certificates are currently accepted. The feature is motivated by government and FIPS-compliant users (e.g., US DoD PKI) who mandate OCSP stapling, and it ensures OpenSSL-linked Git binaries (common in FIPS deployments) now behave identically to GnuTLS backends when staples are present.
