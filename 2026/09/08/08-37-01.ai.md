This is Junio’s "What’s cooking" report for September 2026 (#03), summarizing the state of integration branches and in-flight topics.

The report covers 616 non-merge commits that have graduated to `master` since Git 2.55, 72 commits cooking in `next`, and 219 commits in `seen`. Below are the key highlights for a future AI summarizer session, focusing on technical details and context for follow-up discussion:

---

**Graduated to `master` (irreversible for next release):**
- **gr/add-e-use-apply-api**: `git add -e` now uses the internal `apply_all_patches()` API instead of spawning `git apply`, eliminating a subprocess.
- **jc/you-still-use-that**: The deprecation warning for obsolete commands (`you_still_use_that()`) now uses firmer language, clarifying that removal is final and guiding users to replacements.
- **kn/reftable-optimize-reloading**: The reftable backend avoids redundant `stat()`/`reload` calls when the stack is already locked, reducing syscalls from O(n) to O(1) during ref writes.
- **ll/zsh-complete-git-potty-options**: Zsh completion now correctly skips global options (e.g., `-C <path>`) when locating the Git command, matching bash completion behavior.
- **yn/worktree-ambiguous-remote-advice**: `git checkout` and `git worktree add` now error out (instead of guessing) when a remote-tracking branch name is ambiguous. The `--guess-remote` flag is required to proceed.
- **yn/worktree-repair-relative**: `git worktree repair` now correctly detects and fixes `.git` files containing relative paths when run from the worktree itself.

**New Topics (candidates for `next`):**
- **jk/ci-bump-debian-to-12**: CI jobs now use Debian 12 (bookworm) instead of Debian 11 (bullseye), which is out of LTS.
- **tc/push-force-if-includes-fixes**: Fixes `--force-if-includes` to check the reflog of the *local* branch being pushed (not the remote branch). Also improves detached HEAD advice. *Expecting a reroll* due to a regression in the reflog timestamp check.
- **as/cherry-pick-no-commit-doc**: Documents that `--no-commit` in `git cherry-pick` intentionally skips setting `CHERRY_PICK_HEAD`, with a test to verify this behavior.
- **tn/fetch-pack-trace-packfile-uri**: Adds a Trace2 region for packfile URI downloads in protocol v2, enabling monitoring of download time and URI count without per-pack events.
