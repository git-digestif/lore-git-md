Subject: [PATCH 0/2] stash: fix autostash with staged index entries

Originating author: D. Ben Knoble
Thread type: patch series (bugfix)

Core problem or goal
Fix a bug in `git stash` where autostashing fails to correctly handle staged index entries when `stash.index=true` is set. The bug manifests during merge operations that trigger autostash, causing incorrect index state preservation due to a race condition in the subprocess-based logic (`git diff-tree` and `git apply`). The series replaces this with in-core merging via `merge-ort.c`, ensuring staged entries are properly preserved.

Current status
Under review (v1 feedback resolved; v2 pending). Two patches: (1) cleanup (remove unused `#include "oid-array.h"` from `builtin/stash.c`, accepted by Junio C Hamano), (2) functional fix (refactor index merge logic in `builtin/stash.c` and `merge-ort.c`, replacing 65 lines of subprocess calls with 23 lines of in-core merge logic; add test in `t/t7600-merge.sh`). All technical concerns raised by Phillip Wood—merge algorithm consistency, assertion safety, and merge option lifecycle—have been resolved in principle. The author will implement the agreed changes (standardize on `init_ui_merge_options()`, restore fixed ancestor/branch labels, use `merge_finalize()`, and add a test for graceful failure on index merge errors) for v2.

Key technical details
- Files touched: `builtin/stash.c`, `merge-ort.c`, `t/t7600-merge.sh`
- Subsystems: stash, merge-ort
- New/renamed symbols: None (internal refactoring only)
- Behavior change: Index state is now merged in-core during autostash, avoiding external process calls and eliminating a race condition that could corrupt the `MERGE_AUTOSTASH` ref. The patch standardizes on the `_ui` variant of the diff algorithm for both index and worktree merges to avoid behavioral mismatches. Fixed ancestor/branch labels prevent crashes, and `merge_finalize()` ensures proper cleanup of the `merge_result` strmap.
- On-disk format: Unchanged
- Test coverage: Added test case in `t/t7600-merge.sh` covering the bug scenario (staging a file before a fast-forward merge with `--autostash` and `stash.index=true`), reported by Eli Barzilay. Test verifies autostash application and stash list cleanup. A new test will be added to verify graceful failure (without SIGSEGV) if the index merge fails.
