## 2026/09/19

- [2026/09/19/14-47-26 by Harald Nordgren via GitGitGadget <gitgitgadget@gmail.com>] Harald Nordgren submitted a patch (PR #2412) adding a `fetch.shallow` configuration option, off by default, that causes a refspec-less `git fetch` or `git pull` in a shallow repository to fetch only the current branch's tracked upstream instead of every branch the remote advertises, while still updating `refs/remotes/<name>/HEAD`; the change is opt-in because it alters which remote-tracking refs a plain fetch leaves behind.
