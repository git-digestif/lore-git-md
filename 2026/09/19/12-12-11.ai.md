This is the second patch in Johannes Schindelin’s four-patch series restoring GitLab CI for Windows after Rust was enabled. It fixes a silent data loss in the dependency-setup script: the PowerShell `New-Item -Force` that creates `.git/info/exclude` was clobbering any existing exclusions, notably the `/git-sdk` entry added by `install-sdk.ps1`. The patch simply checks whether the file already exists before creating it, preserving prior contents. The change is mechanical, well-motivated, and confined to the CI infrastructure; no Git behavior or user-facing features are affected. Expect follow-up discussion to reference the `.git/info/exclude` file and the PowerShell `New-Item -Force` behavior.
