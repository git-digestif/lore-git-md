This thread fixes a bug in `git stash` where autostashing fails to preserve staged index entries when `stash.index=true` is set, particularly during merge operations. The issue stems from a race condition in the subprocess-based logic (`git diff-tree` and `git apply`), which the series replaces with in-core merging via `merge-ort.c`. The v3 series (five patches) is nearly ready for integration, with only one critical issue remaining: a NULL-dereference risk in Patch 5/5 where `merge_incore_nonrecursive()` may return an uninitialized `result.tree` on catastrophic failure (e.g., missing objects). The author has confirmed the issue and will address it by checking `result.clean` before dereferencing `result.tree`.
