This thread is a two-patch bugfix series from D. Ben Knoble aimed at fixing a bug in `git stash` where autostashing fails to correctly handle staged index entries when `stash.index=true` is set. The first patch is a simple cleanup—removing an unused `#include "oid-array.h"` from `builtin/stash.c`—which Junio C Hamano has already reviewed and deemed ready to accept. The second patch is the substantive fix, replacing subprocess-based logic (`git diff-tree` and `git apply`) with in-core merging via `merge-ort.c` to avoid a race condition that could corrupt the `MERGE_AUTOSTASH` ref.

The core issue is that the current implementation risks incorrect index state preservation during merge operations that trigger autostash. The fix has received substantive technical review from Phillip Wood, who identified several open questions: whether to standardize on the `_ui` merge variant for consistency, the safety of removing assertions in `merge-ort.c`, and the unused `verbosity` field in `merge_options`. Phillip also recommended additional test coverage for graceful failure handling. The author has acknowledged these points but hasn’t yet addressed them in a follow-up version. The series is still under review, with the second patch being the focus of ongoing discussion.
