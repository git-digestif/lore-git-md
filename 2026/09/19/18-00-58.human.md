This is a test modernization patch that updates two legacy diff-rename test scripts (`t4001-diff-rename.sh` and `t4009-diff-rename-4.sh`) to use current Git test conventions. The patch is the first in a three-part series (v4) and has drawn a **tested review** from Karthik Nayak, who identified two issues: a missing `git` prefix on an `update-index` command and an undefined helper function `initial_setup`. Both issues cause the tests to fail when run.

The modernization effort itself is uncontroversial and aligns with the project’s ongoing test cleanup goals. The patch replaces setup functions with `test_expect_success` blocks, standardizes file naming (`expect`/`actual`), and improves test readability. However, the introduced bugs—likely oversights from refactoring—undermine its readiness. The author will need to address these before the series can proceed. No other substantive feedback was raised in this review.
