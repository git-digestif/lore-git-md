Subject: Git’s automatic LESS=FRX injection affects custom pagers (delta, etc.)
Series version: N/A (bug report / RFC discussion)
Originating author: Francisco Boni
Thread type: platform-compatibility / user-experience bug report

Core problem or goal
Git unconditionally injects LESS=FRX into the environment whenever LESS is unset, even when the user’s core.pager is a third-party wrapper (e.g., delta) that internally chains to less. This causes unintended side effects—broken alternate-screen handling, disrupted keybindings, and inconsistent behavior between unset LESS (Git injects FRX) and LESS="" (Git leaves the environment alone). The report argues that this behavior, while documented and historically justified for direct less usage, feels like an implementation leak when applied to tools Git does not directly control.

Current status
No patch series yet; the thread is in the design-discussion phase. The author has not proposed a specific change but suggests reconsidering the scope of the automatic LESS default—either limiting it to Git’s own default pager path or making it suppressible via configuration.

Key technical details
- Configuration key: core.pager
- Environment variable: LESS (defaults to FRX when unset)
- Affected tools: any pager wrapper that internally invokes less (e.g., delta, bat)
- On-disk or CLI changes: none; purely environment-handling logic
- Test coverage: none yet; reproduction steps provided in the report

Open questions and loose ends
- Should Git’s automatic LESS=FRX injection be scoped more narrowly (e.g., only when core.pager is unset or set to less)?
- Should there be a configuration knob (e.g., core.pagerLessDefaults) to suppress the default?
- How should Git distinguish between unset LESS and LESS="" in its logic?
- What backward-compatibility guarantees apply to this behavior?

Participant positions
- Francisco Boni (author): argues the current behavior is unintuitive and creates sharp edges for users of pager wrappers; suggests reconsidering the scope of the automatic LESS default.
