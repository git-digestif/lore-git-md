This thread covers Harald Nordgren's v14 five-patch series introducing `remote.<name>.fetchRefmap` and a "matching-inspired" fetch mode that would let shallow clones fetch only the branches their local branches track, instead of negotiating history for every remote branch. The design itself is settled and endorsed by both Junio C Hamano and Phillip Wood: `fetchRefmap` selects which refs to fetch, `refmap` handles namespace mapping, and a new `--limited-fetch` option (default-on in shallow repositories in Patch 5/5) puts the feature into practice. The series is queued in `next` as an older version and is under final review, but it textually blocks Collin's `ch/remote-defer-follow-remote-head-validation` topic, which Patches 1--3 would unblock.

The biggest recent development is that the last major disagreement -- override semantics -- has now been resolved. Phillip Wood had argued that any refspec with an explicit destination (`src:dst`), whether on the command line or in config, should ignore the refmap entirely to avoid dual storage and match user expectations that the command line overrides config. Junio had initially preferred an explicit `--refmap=""` opt-out, but in his latest reply he reversed and endorsed Phillip's implicit-override model, noting it keeps a clean one-to-one relationship between config defaults and command-line overrides and removes the need to define special semantics for `--refmap=""`. With both the maintainer and the lead reviewer aligned, that question is closed.

What remains open are two strategic items. First, the architectural question of Patch 3/5's implicit fallback, which dynamically enumerates tracked branches when no refspec is configured: both Phillip and Junio agree implicit guessing is problematic now that explicit modes exist, but removing Patch 3/5 would reintroduce the textual conflicts with the dependent topic. Second, Phillip's partial-merge proposal -- landing Patches 1--3 now to unblock Collin's topic while deferring Patches 4--5 and revisiting the implicit behavior later -- awaits Junio's decision and Harald's response. Once those are settled, the series is positioned to graduate toward `master`.
