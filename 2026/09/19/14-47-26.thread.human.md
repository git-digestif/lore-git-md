This thread is about a patch series that introduces a new `remote.<name>.refmap` configuration and a "matching-inspired" fetch mode to improve performance for shallow repositories. The series, now at version 11, is queued in Junio’s `next` branch as of May 15, 2026, and is ready for merging.

The core idea is to let users define namespace mappings separately from what branches to fetch. When no explicit refspec is given, Git dynamically fetches only the branches tracked by local branches at the remote, avoiding the slow or hanging fetches that shallow repositories experience when negotiating history for all remote branches. The series also adds a `--limited-fetch` flag to `git remote add`, which configures the remote to use the new mode, and makes this the default for shallow repositories.
