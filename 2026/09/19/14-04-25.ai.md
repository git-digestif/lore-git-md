This is an RFC patch proposing a new warning in `git commit` when a new commit's date precedes its parent's date. The patch adds an advice message (`advice.clockSkew`) that triggers when such a skew is detected, aiming to alert users to potential issues with history traversal (e.g., `git log --since` silently skipping commits).

The motivation is clear: Git currently accepts any commit date without validation, even if it breaks the assumption that dates are non-decreasing. This can cause commands like `git log --since` to miss commits, as demonstrated in the commit message. The warning is narrowly scoped to `git commit` (excluding merges/replays) and only compares the new commit against its parents, avoiding false positives from cross-machine skew.

The implementation is straightforward: it hooks into `builtin/commit.c`, parses the committer date, compares it against parent dates, and emits a warning via the advice system if a skew is found. Tests in `t7502-commit-porcelain.sh` verify the warning triggers correctly and can be silenced via `advice.clockSkew=false`.

Key technical details:
- **Files touched**: `advice.c`, `advice.h`, `builtin/commit.c`, `Documentation/config/advice.adoc`, and `t7502-commit-porcelain.sh`.
- **New config**: `advice.clockSkew` (default: `true`).
- **Behavior**: Warning only; no enforcement (deliberate design choice).
- **Edge cases**: Handles timezone parsing, skips unparseable commits, and avoids warnings when dates are equal or increasing.

The RFC explicitly seeks feedback on three questions:
1. Whether the feature is wanted at all (prior discussions were inconclusive).
2. If advice is the right channel (stderr output may get buried).
3. Whether `fsck` should also warn about dates far ahead of "now" (though it cannot compare parents).

The patch is well-motivated and addresses a real usability issue, but its narrow scope (only `git commit`) and reliance on advice messages may spark debate. The tests are thorough, and the code is clean, suggesting the author has thought carefully about the design.
