This is the second patch in Jeff King’s five-part series refactoring the xdiff subsystem to use `size_t` for buffer sizes. Here, Peff consolidates two nearly identical buffer types—`mmfile_t` and `mmbuffer_t`—into a single type (`mmfile_t`). The change is purely mechanical: every `mmbuffer_t` variable or parameter becomes `mmfile_t`, and the now-redundant `mmbuffer_t` struct is removed from `xdiff/xdiff.h`.

The patch touches 16 files, mostly in the merge and diff plumbing, and updates both code and documentation to reflect the unified type. Peff acknowledges the change might be controversial but argues that the two types have long since diverged from upstream xdiff and that the distinction no longer serves a meaningful purpose. No behavior change is intended; the goal is simply to reduce cognitive overhead and make helper functions reusable for both input and output buffers.
