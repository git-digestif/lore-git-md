This is a refactoring and bugfix series targeting the xdiff subsystem, authored by Jeff King. The series addresses integer overflow risks in the xdiff library’s buffer handling, which were surfaced during an earlier attempt to clean up `ll_ext_merge()`’s temporary file handling. Peff’s patches systematically replace inconsistent integer types (notably `long`) with `size_t` for buffer sizes, eliminate a redundant `mmbuffer_t` type, and ensure proper NUL-termination of buffers read by `read_mmfile()`.

The series is well-motivated: the commit messages clearly explain the overflow risks and how each patch mitigates them. Patch 4 delivers the original cleanup goal (reading merge results via `read_mmfile()`), while the preceding patches lay the groundwork by making the xdiff API safer and more consistent. The changes touch 17 files, but most are mechanical type adjustments or call-site updates; the core logic remains unchanged.

Peff notes minor textual conflicts with his concurrent `jk/merge-ll-tempfile-cleanup` series but expects them to be easy to resolve. The series is under review and not yet in any integration branch.
