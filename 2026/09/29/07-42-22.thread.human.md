This thread is about extending `git stash create` to support the `--include-untracked` (`-u`) and `--all` (`-a`) options, bringing it into feature parity with `git stash push` and `git stash save`. The patch, authored by Kazumasa Shigeta, reuses existing internal plumbing (`do_create_stash()`) to expose these options without introducing new code paths or modifying the working tree, index, or `refs/stash`.

The change is motivated by a long-standing inconsistency in the stash command family, with historical context dating back to a 2014 proposal and a 2017 refactoring that added the internal support but left the user interface incomplete. The implementation is clean, and the test coverage is thorough, verifying option handling, edge cases, and the guarantee that `create` remains non-destructive. There are no open objections or requests for changes at this stage, and the patch appears ready for review and potential integration. Key participants include the author and, presumably, reviewers who will weigh in on the design and implementation.
