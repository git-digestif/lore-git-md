Thread identity: Patch series extending `git stash create` to support `--include-untracked` (`-u`) and `--all` (`-a`) options, authored by Kazumasa Shigeta. Thread type: feature addition to the stash subsystem.

Core problem or goal: Address the long-standing inconsistency where `git stash create` lacked support for `--include-untracked` and `--all` options, which were available in `git stash push` and `git stash save`. The goal is to bring parity to the stash command family by exposing these options in `create` without introducing new behavior or breaking existing scripts. The feature reuses existing internal plumbing (`do_create_stash()` and `INCLUDE_ALL_FILES`) to avoid on-disk format changes or new code paths.
