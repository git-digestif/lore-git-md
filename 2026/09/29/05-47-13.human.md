This is a documentation patch for the `contrib/contacts/git-contacts` script. The patch adds a single sentence to the script's man page (`git-contacts.adoc`) to document the recently merged feature that allows reading patch input from stdin using the conventional `-` idiom.

The change is straightforward and uncontroversial: it clarifies that a dash (`'-'`) in place of a patch filename tells the command to read patch file(s) from stdin. This aligns with Git's established conventions for stdin handling (e.g., in `` `git apply` `` or `` `git am` ``) and enables mixed file/stdin usage, such as `` `git contacts patch1 - patch3 <patch2` ``. The feature itself was merged to `master` in an earlier iteration (v4), and this patch is the routine follow-up to ensure the documentation reflects the new behavior.

The implementation supports reading multiple concatenated patches from stdin (separated by `From ` headers, as produced by `` `git format-patch` ``), but the documentation phrasing remains singular for clarity.
