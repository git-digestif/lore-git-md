This is a review of a bugfix for `git filter-branch`. Michele Locati confirms the bug and reports that he independently encountered the same issue. The problem was introduced in Git 2.50.0 by commit f6d855091e, which removed Perl dependencies from `filter-branch`. Michele tested the patch with Git 2.56.0, running `filter-branch` incrementally with `--state-branch`, `--prune-empty`, and `--subdirectory-filter`. Without the fix, new commits incorrectly attach to original parents, and the state branch is saved with swapped entries; with the fix, parents are correctly rewritten, and the state branch is saved properly.

Michele adds a `Tested-by` trailer and explains that while `filter-branch` is deprecated, his team relies on `--state-branch` for incremental repository splitting. He also notes a minor typo in the patch subject ("fiter-branch" instead of "filter-branch").
