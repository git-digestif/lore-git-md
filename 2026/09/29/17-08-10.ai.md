This is a test stabilization patch for `t5520-pull.sh`, addressing a flaky test failure caused by reflog expiration interfering with fork-point computation during `git pull --rebase -f`. The patch disables reflog expiration for the test script by setting `gc.reflogExpire` and `gc.reflogExpireUnreachable` to `never`, following the precedent set by `ea7d894f44` for rebase tests.

The issue stems from two upcoming changes: one that eliminates `git reset` calls during `git stash apply --index` (reducing reflog entries), and another that triggers auto-maintenance at the end of `git rebase`. Together, these shift when reflog expiration occurs, causing the test to fail when reflog entries—dated to 2005 in the test suite—are prematurely expired. The fix ensures the test no longer depends on the timing of reflog cleanup.

The patch touches only `t/t5520-pull.sh`, adding two `git config` lines in the `setup` block.
