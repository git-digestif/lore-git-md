This is the v4 submission of a five-patch bugfix series targeting `git stash`, authored by D. Ben Knoble. The series resolves a long-standing bug where autostashing fails to correctly handle staged index entries when `stash.index=true` is set, particularly during merge operations. The root cause is a race condition in the subprocess-based logic (`git diff-tree` and `git apply`), which the series replaces with in-core merging via `merge-ort.c`.

Key changes in v4:
- **NULL-dereference fix**: The critical crash risk in Patch 5/5 is resolved by checking `result.clean` before dereferencing `result.tree`, addressing the sole remaining blocker for integration. The fix ensures the index merge fails gracefully on catastrophic errors (e.g., missing objects).
- **Verbosity handling**: The series no longer silences merge output, preserving the original verbosity setting to avoid regressing user-visible conflict reporting (e.g., `git apply --cached` errors on stderr).
- **Test restructuring**: The test from Patch 3/5 (v3) is now squashed into Patch 5/5, replacing an existing test to preserve bisectability. The new test validates that `stash apply --index` correctly merges trees in the right order (a prior bug caused incorrect index state).
- **Interaction fix**: Patch 4/5 (authored by Thomas Bachem) resolves the `t5520-pull.sh` breakage by pinning `gc.reflogExpire` to `never` in the test setup, preventing premature reflog expiration that disrupted `git pull --rebase`.

Files touched:
- `builtin/stash.c`: Refactors `do_apply_stash()` to use `merge_incore_nonrecursive()` for index merges, eliminating subprocess calls.
- `t/t3903-stash.sh`: Adds a test for correct index merging and replaces an existing test to avoid bisectability issues.
- `t/t5520-pull.sh`: Configures reflog expiration to avoid test flakiness.
- `t/t7600-merge.sh`: Adds a test for `--autostash` with `stash.index=true`.

The series is now technically complete, with all prior issues (verbosity regression, bisectability, test interactions, and the NULL-dereference) resolved.
