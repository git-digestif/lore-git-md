This is a refactoring and bugfix series targeting the xdiff subsystem, authored by Jeff King. The series addresses integer overflow risks in the xdiff `mmfile_t` buffer handling by switching from `unsigned long` to `size_t` for buffer sizes, which is more appropriate for memory allocation and file operations. The patches touch core diff and merge machinery (`xdiff/xdiff.h`, `xdiff/xutils.c`, `xdiff/xmerge.c`), as well as higher-level consumers like `merge-ll.c`, `merge-ort.c`, and `builtin/merge-file.c`.

The motivation stems from a review by Elijah Newren on an earlier attempt to clean up `ll_ext_merge()`, where he flagged potential integer overflow issues. Peff’s investigation revealed similar problems elsewhere in the codebase, prompting this broader cleanup. Patch 4 delivers the original cleanup goal (simplifying `ll_ext_merge()` to use `read_mmfile()`), while the preceding patches lay the groundwork by making the xdiff buffer handling safer and more consistent.

The series is incremental and mechanical, with no intended behavior changes. It conflicts textually with the recently posted `jk/merge-ll-tempfile-cleanup` topic, but Peff notes the conflicts are minor and offers to rebase if needed.
