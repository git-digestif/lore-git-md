This is the second patch in Scott Chacon’s four-part performance series replacing Git’s SHA-1 collision-detection code with a faster, vectorized implementation. It focuses on the unavoidable-bitconditions (UBC) check, which is the main cost of collision detection. The patch adds SSE2, AVX2, and NEON implementations of the UBC filter, each with a vectorized “prefix” that runs on every block and a scalar “tail” that only runs for the few blocks the prefix leaves alive. The tables that drive the vectorized forms come from the same Rust solver that powers gitoxide’s sha1dc crate, and the unit tests verify bit-for-bit compatibility with the original sha1dc code across all 32 disturbance vectors. On x86-64 the patch delivers a 1.27–1.29× speedup over the baseline set up by patch 1, and on ARMv8 it reaches 1.27×. The build system is updated to compile the new files, and the backend-selection logic in sha1.c now prefers the fastest vector form the CPU supports. The code is dense but well-explained, and the test coverage is thorough.
