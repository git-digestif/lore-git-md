This is a documentation-only follow-up to the already merged `git-contacts` stdin feature. The patch itself (v5 1/2) is the code change that was previously accepted and is now in `master`; it allows the `git-contacts` contrib script to read patch input from stdin when the user passes a single dash (`-`). The change is small and mechanical: it adds a flag to detect `-` in the argument list and passes the stdin filehandle to the existing `scan_patches()` helper.

The feature is motivated by better interoperability with external tools like `b4` and enables mixed file/stdin usage (e.g., `git contacts patch1 - patch3 <patch2`). The implementation avoids implicit terminal checks and instead treats `-` as an explicit stdin marker, which is a common Unix convention. The patch is confined to `contrib/contacts/git-contacts` and introduces no new CLI options, symbols, or on-disk format changes.

This email is part of a two-patch series where the second patch (not shown here) updates the documentation to reflect the new behavior. The change is uncontroversial and aligns with established Git conventions for stdin handling. No further technical discussion is expected, and the patch is ready to apply.
