This is a brief, procedural reply in the ongoing documentation thread to modernize the `git(1)` man page’s introduction. Junio C Hamano clarifies a minor point about Git’s command-line style: options must precede arguments, so `git help --web push` is correct, not `git help push --web`. This is a surface-level correction to ensure the patch’s examples match Git’s published conventions. Julia Evans has already agreed to incorporate this and one other small wording tweak into the upcoming v2 patch, which will likely be the final version unless new concerns arise. The thread’s core design question—how to balance simplicity and functionality in directing users to Git’s help system—is settled.
