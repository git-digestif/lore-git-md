This thread is a seven-patch series from Jeff King (Peff) that refactors the xdiff subsystem to replace `unsigned long` with `size_t` for buffer sizes in the `mmfile_t` struct, eliminating integer overflow risks during memory allocation and file operations. The key technical achievement is fixing a latent error-handling bug in `ll_ext_merge()` where a successful external merge driver (exit code 0) with an unreadable or missing output file could return `LL_MERGE_OK` with a `NULL` buffer, leading to undefined behavior in downstream callers like `rerere.c`. The final patch in the series ensures that `ll_ext_merge()` returns `LL_MERGE_ERROR` if `read_mmfile()` fails, regardless of the driver’s exit status, and adds a regression test in `t/t4200-rerere.sh` to reproduce the bug.
