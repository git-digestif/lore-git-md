This thread is a seven-patch series from Jeff King (Peff) that refactors the xdiff subsystem to use `size_t` instead of `unsigned long` for buffer sizes in `mmfile_t`, eliminating integer overflow risks and consolidating redundant types. The series also fixes a latent memory leak, adds defensive NUL-termination to buffers, and addresses a subtle error-handling bug in `ll_ext_merge()` where a successful merge driver could return `LL_MERGE_OK` with a `NULL` buffer, leading to undefined behavior downstream. A regression test was added to catch this edge case, and Junio Hamano’s stylistic suggestion to use `rm` instead of `chmod 0` in the test was incorporated.

The series is now technically complete and under review, with all patches ready for integration.
