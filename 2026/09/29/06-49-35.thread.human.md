This thread is a seven-patch series from Jeff King (Peff) that refactors the xdiff subsystem to replace `unsigned long` with `size_t` for buffer sizes in `mmfile_t`, eliminating integer overflow risks and consolidating redundant types. The series also fixes a latent memory leak, adds defensive NUL-termination to buffers, and—most critically—addresses a latent error-handling bug in `ll_ext_merge()` where a successful external merge driver could return `LL_MERGE_OK` with a `NULL` buffer, leading to undefined behavior in downstream callers like `rerere.c`.

The final patch (7/5) centralizes the error check in `ll_ext_merge()` by forcing a driver error if `read_mmfile()` fails, converting the result to `LL_MERGE_ERROR` without requiring changes to downstream callers. It also adds a regression test in `t/t4200-rerere.sh` to reproduce the bug, ensuring the fix is exercised. Junio C Hamano, the maintainer, has already acked the first two patches, and the author’s follow-up patches (6/5 and 7/5) satisfy Junio’s requirement to resolve the error-handling issue before merging the full series.
