This is a feature patch for `git stash`. The author, Kazumasa Shigeta, extends `git stash create` to accept the same untracked-file modes (`-u`/`--include-untracked` and `-a`/`--all`) that `git stash push` and `git stash save` already support.

The patch is well-motivated: `git stash create` currently ignores untracked and ignored files, even though the underlying `do_create_stash()` helper already knows how to handle them. The change is small and surgical—it wires up the existing machinery rather than inventing new code paths. The commit message traces the history of the feature (including the author’s own 2014 attempt and a 2017 internal refactor) and explains the design choices clearly.

Documentation is updated to reflect the new options, and the test coverage is thorough: it verifies both short and long option forms, the boundary between untracked and ignored files, option/message parsing edge cases, the “no changes” behavior, and that the working tree, index, and `refs/stash` are left untouched.

The patch looks ready for review; it touches only the stash subsystem and does not appear to introduce any cross-cutting concerns.
