Thread identity: Meta-discussion on version numbering for the next major Git release after 2.56, initiated by Junio C Hamano. Thread type: design discussion (not a patch series or bug report).

Core problem or goal: Decide the version number for the next Git release after 2.56 (scheduled for late September 2026), focusing on whether to bump to 3.0, use a transitional version (e.g., 2.99), or continue with incremental numbering (e.g., 2.57).
