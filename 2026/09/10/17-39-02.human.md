This is Junio’s "What’s cooking in git.git" report for September 2026, issue #04. It’s the regular digest of what’s currently in flight across Git’s integration branches, aimed at contributors and maintainers who want to track the project’s pulse without reading every patch.

The report covers the state of topics as of Git 2.56-rc0, which was tagged recently. There are about 80 commits in `next` (the stabilization branch) and 228 in `seen` (the experimental integration branch). The focus now is on polishing what’s in `next` for the upcoming 2.56 final release, while `seen` remains a proving ground for longer-term work.

Key highlights:

- **Graduated to `master`**: Six topics made it into the upcoming release. Elijah Newren’s `en/midx-missing-pack-fallback` fixes a crash when a multi-pack-index references a pack that was removed during a concurrent geometric repack. Taylor Cipriani’s `tc/replay-linearize` adds a `--linearize` option to `git replay` to drop merge commits, mimicking `git rebase --no-rebase-merges`. René Scharfe’s `rs/worktree-add-basename-fixes` fixes edge cases in `git worktree add` when paths end with slashes. Jeff King’s `jk/rev-info-argv-to-free` plugs a subtle use-after-free in the revision machinery. There are also small fixes for CI, documentation typos, and reference handling.

- **New topics needing review**: Several patches are fresh and looking for feedback. Vadim Malkov’s `vm/advice-config-global-hint` teaches Git to suggest disabling certain advice messages in the global config (e.g., `advice.defaultBranchName`) since they only trigger once per repository. Patrick Steinhardt’s `ps/ref-storage-format` unifies the terminology around reference storage formats across command-line options, environment variables, and configuration keys, standardizing on “ref storage format” (e.g., `--ref-storage-format`, `GIT_REF_STORAGE_FORMAT`). Two Rust-related patches (`jc/rust-cargo-build-target` and `mh/rust-crate-subdir`) address build system issues when cross-compiling or embedding Git as a submodule in Rust projects. Karthik Nayak’s `kn/receive-report-hook` introduces a new `receive-report` hook to filter or modify the status report sent back to clients after reference updates.

- **Stalled topics**: Four topics have been stuck for months without updates. Patrick Steinhardt’s `ps/libgit-in-subdir` (moving `libgit.a` sources into a `lib/` directory) was ejected due to merge conflicts and hasn’t been rerolled. Hugo Salgado’s `hs/rebase-continue-edit` (adding `--[no-]edit` to `git rebase --continue`) and Son Luong Ngoc’s `sn/rebase-update-refs-symrefs` (fixing symref handling in `git rebase --update-refs`) are both waiting for author responses. Taylor Blau’s `tb/pack-with-duplicates` (hardening packfile handling for duplicate objects) has been stalled since July.

- **Cooking in `next`**: A mix of small fixes and medium-sized features. Tyler Cipriani’s `tc/push-force-if-includes-fixes` corrects a long-standing bug where `git push --force-if-includes` checked the wrong reflog (the local branch being pushed, not the remote-tracking branch). Elijah Newren’s `en/no-amend-during-conflicts` teaches `git commit --amend` and partial commits to refuse to run during conflict resolution, aligning them with `git cherry-pick` and `git merge`. Phillip Wood’s `tb/rerere-lock-grace` defers automatic maintenance tasks during sequencer operations to avoid lock contention. Johannes Schindelin’s `js/mingw-build-updates` upstreamed a batch of Git for Windows build improvements, including dropping obsolete compatibility flags and allowing `git.exe` to be used directly.

- **Longer-term efforts**: Several ongoing architectural projects are represented. Patrick Steinhardt’s `ps/odb-stop-registering-in-memory-sources` removes the ad-hoc mechanism for registering in-memory alternate object sources, a step toward migrating alternate tracking into the files backend. His `ps/odb-pluggable-fsck` moves fsck checks into the object source layers, making them pluggable for different storage formats. The `mm/diff-process-hunks` series (from Michael Montalbano) introduces a `diff.<driver>.process` configuration to let external tools act as hunk providers, enabling them to control which lines Git considers changed while leaving output formatting to Git.

- **Discarded**: Three topics were retracted or discarded. Patrick Steinhardt’s `ps/fetch-packfile-uris-parallel` (parallelizing packfile URI downloads) was pulled back for further work. Junio’s `jc/die-for-incompatible-opts` (a variadic helper for mutually exclusive options) was retracted after feedback. Zhihao Yao’s `zy/apply-abandoned-header-fix` (a memory leak fix in `git apply`) was discarded in favor of a different approach.

The report also includes the usual pointers to Junio’s integration branches and mirrors, and a reminder that topics in `seen` are ephemeral and may be dropped if they don’t progress. For anyone following Git development, this is the best snapshot of what’s likely to land in the next release and what’s still in flux.
