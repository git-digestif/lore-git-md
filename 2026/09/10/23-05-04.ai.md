This is a **bugfix series** targeting the `--force-if-includes` safety mechanism in `git push`. The v3 posting is a **procedural resend only**—no technical changes—correcting the threading of the two patches to reply to the v2 cover letter rather than the v1 cover letter. The series remains **technically complete and ready for merge**.

The core issue is that `--force-if-includes` currently checks the reflog of the *local* branch whose name matches the *remote* destination branch (e.g., `refs/heads/main` when pushing to `refs/remotes/origin/main`), rather than the branch actually being pushed (e.g., `refs/heads/src` in `src:main`). This flaw has been reported twice (2023 and 2025) and can cause false rejections (e.g., pushing from a differently named local branch or detached HEAD) or unintended data loss (e.g., pushing an unrelated branch that happens to share a name with a local branch containing the remote tip).

The series consists of two patches. The first fixes the core logic in `remote.c` to consult the reflog of the pushed ref (`ref->peer_ref->name`) instead of the destination ref (`ref->name`). It adds special handling for `HEAD`-based pushes (resolving the symref) and detached HEAD states (rejecting by default, with the `ref->unverifiable` flag set). The second patch adjusts the advice message for detached HEAD scenarios, introducing a new `advice.forceIfIncludesDetachedHead` config knob (documented as `advice.pushRefUnverifiable`) and updating the message to instruct users to specify the expected remote tip with `--force-with-lease=<ref>:<expect>` or bypass the check with `--no-force-if-includes`. All transport layers (direct pushes, transport helpers, send-pack) are updated for consistency.

Test coverage is expanded with eight new cases in `t/t5533-push-cas.sh`, covering mismatched local/remote names, `HEAD`-based pushes, detached HEAD states, and the new advice message. The series touches 12 files, including `remote.c` (core logic), `advice.c` (new advice message), and `t/t5533-push-cas.sh` (tests). No on-disk format changes are introduced.
