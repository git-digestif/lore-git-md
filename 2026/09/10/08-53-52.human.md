This is the second patch in Vsevolod Myalitsin’s three-part series introducing a `scope_hint` field to Git’s advice system. The patch implements the core mechanism: it adds an `enum config_scope scope_hint` field to the `advice_setting` struct and modifies the `vadvise()` function to include the appropriate scope flag (`--global`, `--system`, or none) in the advice message. The translatable string is updated to avoid interpolation, and the helper logic uses the existing `CONFIG_SCOPE` enum, with `CONFIG_SCOPE_UNKNOWN` (value `0`) treated as "use the default scope" (currently local).

The patch is narrowly focused on `advice.c` and does not change any user-visible behavior yet—those changes come in patch 3/3. The commit message is clear and the code is straightforward, addressing the mechanical feedback Junio raised in v3 (documentation, indentation). The series as a whole looks well-structured and motivated; this patch is a clean, uncontroversial step toward making advice messages more accurate.
