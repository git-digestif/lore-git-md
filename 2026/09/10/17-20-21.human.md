This is the **Git v2.56.0-rc0 release announcement** from Junio C Hamano, marking the first release candidate for Git 2.56.0. This preview includes **635 non-merge commits** from **82 contributors**, with **32 new contributors** joining the project since the last release.

### Key Highlights
The release introduces several **user-facing features**, including:
- **Improved advice in `git status`** for diverged or behind branches, now suggesting `git pull <remote> <branch>`.
- **New `git refs` subcommands** (`create`, `delete`, `update`, `rename`) for managing references directly.
- **`git history drop`**, an experimental command to remove commits while replaying descendants onto their parent.
- **`git branch --delete-merged`**, a new option to delete local branches already merged into their upstream.
- **`git bisect --reset-when-found`**, which automatically resets the bisect state after finding a culprit.
- **`git add --resolved`**, a new option to stage conflict-resolved paths while leaving unrelated changes unstaged.
- **`git replay --linearize`**, which mimics `git rebase --no-rebase-merges` by dropping merge commits.

### Performance and Internal Improvements
- **Continued `the_repository` removal**: Many subsystems (refs, worktree, tempfile/lockfile APIs) now avoid the global repository variable, moving toward explicit repository passing.
- **Object Database (ODB) abstraction**: Patrick Steinhardt’s ongoing work to make ODB backends pluggable progresses, with loose and packed backends now more self-contained. This includes refactoring `git receive-pack` to use ODB transactions.
- **Reftable backend optimizations**: Performance improvements for ref updates and reads, especially with many deletion tombstones.
- **Sparse-index optimizations**: `git stash push` avoids unnecessary sparse-index expansion for in-cone paths.
- **Geometric repacking**: Adjusted thresholds to match `git gc --auto`, preventing over-aggressive repacking during concurrent writes.

### Notable Fixes
- **Memory leaks and crashes**: Plugged leaks in Bloom filters, GPG/SSH signature parsing, and the reftable writer. Fixed segfaults in `git clone --revision`, `git diff --relative --cached`, and `git cat-file --batch-command`.
- **Windows-specific fixes**: Corrected memory corruption in the wincred helper and avoided NTLM credential leaks with crafted symlinks.
- **Protocol v2 fixes**: The `remote-object-info` command in `git cat-file --batch-command` now supports dynamic filtering based on server capabilities.
- **Submodule handling**: Fixed `url.*.insteadOf` alias resolution and restored the `-i` shorthand for `git submodule update --init`.

### Documentation and Developer Experience
- **Man page modernization**: Jean-Noël Avila’s ongoing effort to standardize synopsis formatting continues.
- **SubmittingPatches updates**: Clarified expectations for responding to review critiques, retracting abandoned patches, and trimming quoted text in replies.
- **New contributor guidance**: Added project-specific `b4` configuration and recommended shallow threading for cover letters.

### New Contributors
Welcome to **32 first-time contributors**, including Adrian Friedli, Alan Stokes, Antonio De Stefani, and others. Their contributions span features, fixes, and documentation.

### Testing and CI
- **CI improvements**: GitLab CI now enables the long test suite, and GitHub Actions cancels stale PR workflow runs.
- **Test modernization**: Added `test_grep` helper to replace bare `grep` assertions, and introduced a `greplint` linter to prevent regressions.

### Next Steps
This is a **release candidate**, so testing is encouraged. The final release is expected soon, barring major issues. The draft release notes provide a detailed breakdown of changes, and the tarballs are available at the usual locations.

For developers, this release continues foundational work on ODB abstraction, `the_repository` removal, and reftable backend improvements, setting the stage for future scalability and extensibility.
