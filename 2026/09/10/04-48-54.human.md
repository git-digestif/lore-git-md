This is the first patch in Delilah Ashley Wu’s three-patch v2 series fixing Git’s global config listing inconsistency. The patch addresses Windows path normalization for XDG config paths by ensuring `xdg_config_home_for()` always returns forward slashes, which aligns with Git’s cross-platform test expectations.

The discussion here centers on whether this patch is necessary for the series’ core goal. Delilah clarifies that the change supports `--show-origin` test assertions in patch 3, which expect forward slashes in output paths. Without this patch, Windows tests would show mixed slashes (e.g., `C:\Users\.../.config/git/config`), breaking the test suite’s assumptions. However, Junio questions whether this normalization belongs in the platform-agnostic `path.c` file and whether it should be handled at the caller level instead.

Delilah proposes an alternative: dropping this patch and modifying the tests in patch 3 to export `XDG_CONFIG_HOME` with forward slashes, avoiding the need for runtime normalization. This would keep the series focused on the global config fix while still satisfying test requirements. The exchange highlights a tension between cross-platform consistency and keeping the patch series tightly scoped. The outcome will likely determine whether this preparatory work is merged or deferred to a separate effort.
