This thread is about a bugfix for resource cleanup in Git’s low-level merge driver infrastructure when interrupted by signals like SIGINT (Ctrl+C). Michal Koutný originally identified the issue—temporary files (`.merge_file_*`) created during external merge driver execution were not being removed if the process was abruptly terminated. His initial patch used signal chain manipulation to address this, but Jeff King (Peff) proposed a cleaner alternative using Git’s `tempfile` API, which Michal has now confirmed works as intended.

The current state of the patch is effectively settled. Michal tested Peff’s version and found it resolves the cleanup issue for both normal termination and interrupts, though he noted a minor, non-blocking compiler warning about const-correctness in the `get_temp_path()` helper. The only remaining question is procedural: Michal asked whether he should send Peff’s patch as a formal `v2` or if Peff will submit it himself. No substantive objections or open technical questions remain, and the implementation is now aligned with Git’s established patterns for signal-safe resource cleanup.

The patch modifies `merge-ll.c` and replaces the original signal-handling workaround with `struct tempfile` objects, which handle cleanup atomically. While the solution is lightly tested, there’s still no automated test coverage for interrupt scenarios, though this is not currently a blocker. The thread is likely to wrap up with a `v2` submission soon, either from Michal or Peff.
