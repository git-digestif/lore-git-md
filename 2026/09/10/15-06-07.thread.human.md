This thread is about a three-patch bugfix series addressing resource cleanup in Git’s low-level merge driver infrastructure when interrupted by signals like SIGINT (Ctrl+C). The series, originally authored by Michal Koutný and resubmitted as v2 by Jeff King (Peff), ensures temporary files (`.merge_file_*`) created during external merge driver execution are reliably removed even if the process is abruptly terminated. The solution replaces custom signal handling with Git’s `tempfile` API for atomic, signal-safe cleanup, while also modernizing adjacent code—such as replacing manual buffer management with `strbuf` and fixing latent robustness issues like ignored `close()` errors after successful `write()` calls.

The series is technically complete but requires a v3 to address a latent type-safety bug in the first patch, identified by Elijah Newren. This bug—a type mismatch between `result->size` (`long`) and `strbuf_detach()` (`size_t`)—could cause buffer overreads on LLP64 platforms (e.g., Windows) if file sizes exceed `LONG_MAX`. Junio C Hamano has endorsed Elijah’s proposed fix (a simple `die()` check) as a sensible mitigation, and the series remains uncontroversial. The second patch, which treats `close()` errors as fatal, received substantive confirmation from Elijah, while the third patch (completing the `tempfile` API transition) was approved with minor commit-message nits. No merge status has been reported yet, but the series aligns with Git’s established patterns for resource cleanup and defensive programming.

Key participants include Peff (author of v2), Michal Koutný (original author), and Elijah Newren (substantive reviewer). The series touches only `merge-ll.c`, with no functional changes to cleanup guarantees but improved robustness and signal safety. Open questions are minor: the lack of automated tests for interrupt scenarios may prompt discussion, though it’s not a blocker, and a non-urgent shell-quoting limitation in `get_tempfile_path()` remains unresolved. The type-safety fix is the sole prerequisite for v3.
