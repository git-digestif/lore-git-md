This thread is a two-patch series from Jeff King (Peff) that fixes resource cleanup in Git’s low-level merge driver infrastructure when interrupted by signals like SIGINT (Ctrl+C). The series replaces custom signal handling with Git’s `tempfile` API for atomic, signal-safe cleanup of temporary `.merge_file_*` files, while also modernizing adjacent code (e.g., replacing manual buffer management with `strbuf`). The patches address latent robustness issues, including a type-safety bug in the `strbuf`-based refactoring that could cause buffer overreads on platforms like Windows, and a stylistic improvement to split error checks for clarity.

The series is now in its third version (v3) and is **ready for merging**. v3 incorporates minor refinements: a stylistic tweak to split a combined `write_in_full()`/`close()` error check into two separate `die_errno()` calls (to avoid a subtle pattern that could risk file descriptor leaks), and a commit-message adjustment to use `Reported-by:` trailers for attribution, as requested by Michal Koutný. The core logic remains unchanged from v2, which already resolved the type-safety bug and received substantive approval from Elijah Newren. The patches are uncontroversial and align with Git’s established patterns for resource cleanup.

Key participants include Peff (author of v2/v3), Michal Koutný (original author, who tested the patches and deferred formal submission to Peff), and Elijah Newren (who provided substantive review, identified the type-safety bug, and confirmed the correctness of the changes).
