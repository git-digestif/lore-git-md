Core problem or goal
This is the first release candidate for Git v2.56.0, summarizing the work integrated since the last stable release. The goal is to communicate the scope, themes, and key changes in this cycle to the community for testing and feedback before the final release.

Current status
Git v2.56.0-rc0 has been tagged and announced. The release includes 635 non-merge commits from 82 contributors, covering new features, performance improvements, bugfixes, and internal refactoring. No merge status is applicable (this is not a patch series under review).

Key technical details
- **Subsystems touched**: ODB abstraction (Patrick Steinhardt), reftable backend (Karthik Nayak, Patrick Steinhardt), repository discovery (Patrick Steinhardt), Rust integration (brian m. carlson, Taylor Blau), merge machinery (Kristofer Karlsson), ref filtering (Tamir Duberstein), pack-objects (Taylor Blau), sparse-index (Derrick Stolee), and nearly all user-facing commands.
- **New user-facing features**: `git history drop`, `git refs create/delete/update/rename`, `git replay --linearize`, `git branch --delete-merged`, `git bisect --reset-when-found`.
- **New or renamed symbols**: ODB streaming APIs (`odb_stream_*`), repository discovery functions (`discover_git_directory`), reftable tombstone handling, Rust FFI symbols (e.g., `git2::odb::Stream`).
- **Behavior changes**: Unified ODB streaming, repository discovery refactoring (detangles initialization from configuration), reftable performance optimizations (reduced syscalls, tombstone handling).
- **On-disk format changes**: None explicitly mentioned, but reftable backend optimizations may affect ref storage performance.
- **Test coverage**: Modernized test suite with new helpers (`test_grep`, `commit_body`), flaky test fixes (Patrick Steinhardt, Harald Nordgren), and continued adoption of `clar` unit tests.

Open questions and loose ends
None in this announcement. This is a release candidate, so the focus is on testing and regression reporting rather than open design questions.

Related work

- **Reftable backend**: Performance optimizations in this release build on prior integration work.
- **Rust integration**: Continues to progress, with this release addressing build system and memory safety issues.
- **`the_repository` removal**: Ongoing; this release includes incremental progress.
- **Test modernization**: Community-wide effort; this release adds new helpers and fixes flaky tests.
