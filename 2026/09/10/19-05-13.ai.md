This is a substantive review reply in the `advice: add scope hint` patch series. Jeff King (Peff) endorses Vsevolod Myalitsin’s proposal to replace the `scope_hint` enum with a single boolean `is_global_hint`, agreeing that `--system` and other non-global scopes are unlikely to be useful for advice settings. Peff frames this as a YAGNI ("You Aren’t Gonna Need It") decision: the simpler boolean design addresses the immediate goal (accurate scope hints for `--global` settings like `defaultBranchName`) without introducing unnecessary complexity, and can be expanded later if a use case for `--system` or other scopes emerges. This reply strengthens the case for the boolean simplification, which would resolve the build failures (unhandled `switch` cases in `vadvise()` and the unmatched brace syntax error) and simplify the translatable string construction. The thread remains under review; Junio has not yet responded to this proposal.
