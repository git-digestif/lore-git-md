Thread identity: Bugfix patch series addressing resource cleanup in low-level merge driver infrastructure when interrupted by SIGINT/SIGQUIT. Originating author: Michal Koutný; v2 submission by Jeff King (Peff). Thread type: standalone patch series (3 patches).

Core problem or goal: Ensure temporary files (`.merge_file_*`) created during external merge driver execution are reliably removed even when the merge process is abruptly terminated by the user (e.g., via Ctrl+C). The issue arises because SIGINT/SIGQUIT sent to the external merge driver propagates to the parent `git merge` process, preventing cleanup handlers from running. The solution replaces custom signal handling with Git’s `tempfile` API for atomic, signal-safe cleanup.

Current status: Series is technically complete and ready for review. v2 (Peff’s submission) incorporates feedback and testing from Michal Koutný, addressing the core issue and minor edge cases (e.g., error-checking bug, const-correctness). No merge status reported (not in `pu`, `next`, or `master`). The series is uncontroversial and aligns with Git’s established patterns for resource cleanup.
