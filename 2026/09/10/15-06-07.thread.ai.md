Thread identity: Bugfix patch addressing resource cleanup in low-level merge driver infrastructure when interrupted by SIGINT/SIGQUIT. Originating author: Michal Koutný. Thread type: standalone patch.

Core problem or goal: Ensure temporary files (`.merge_file_*`) created during external merge driver execution are removed even when the merge process is abruptly terminated by the user (e.g., via Ctrl+C). The issue arises because SIGINT/SIGQUIT sent to the external merge driver propagates to the parent `git merge` process, preventing cleanup handlers from running.

Current status: Patch effectively resolved technically; awaiting formal submission as `v2`. Jeff King's (Peff) alternative using Git's `tempfile` API has been tested and confirmed functional by Michal Koutný. No merge status reported (not in `pu`, `next`, or `master`).
