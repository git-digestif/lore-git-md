This is the second patch in Vsevolod Myalitsyn’s three-patch v4 series introducing a `scope_hint` field to Git’s advice settings. It implements the core mechanism: the `advice_setting` struct now includes an `enum config_scope scope_hint` field, and the `vadvise()` function uses this hint to construct the correct `git config set` command in the advice message (e.g., `--global` instead of omitting the scope). The translatable string has been rewritten to avoid interpolation, and the helper logic in `vadvise()` now programmatically inserts the scope flag based on the hint.

The patch touches only `advice.c` and is purely internal plumbing. No user-visible behavior changes yet—those come in the third patch, which assigns a specific scope hint to the `defaultBranchName` advice. The reuse of the existing `CONFIG_SCOPE` enum (with `CONFIG_SCOPE_UNKNOWN` as the default) and the clear separation of concerns between this patch and the follow-up scope assignment reflect the feedback from earlier iterations.
