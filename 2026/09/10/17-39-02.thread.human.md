This Git mailing list thread is Junio C Hamano’s recurring "What’s cooking in git.git" report, summarizing the current state of integration branches as of September 2026. The report lists which topics have recently graduated to `master`, which are cooking in `next` or `seen`, and which are newly proposed or withdrawn.

Since the last report, several topics have been merged to `master`, including fixes for object lookup in `git replay`, CI improvements, memory leak fixes, and new options like `--linearize` for `git replay`. New topics needing review include Rust-related changes, ref-storage terminology unification, and extended `git var` functionality. Patrick Steinhardt’s `ps/libgit-in-subdir` series was withdrawn due to lack of consensus but may resurface at the upcoming Contributor’s Summit. His ODB abstraction series (`ps/odb-stop-registering-in-memory-sources`) is now at v3 and ready to proceed after a trivial commit-message tweak.

Tuomas Ahola recently noted a minor but visible issue: two recently merged topics (`ps/ci-depends-on-ruby` and `jk/ci-use-system-asciidoctor`) contain an identical fix for a missing Ruby dependency in Git’s CI documentation job, with the earlier version including a typo in its commit message. The corrected version is already in `next`, so the fix itself is uncontroversial, but Ahola suggests dropping the earlier, typo-containing commit to avoid redundant or messy history in `master`. This is a low-stakes housekeeping observation and requires no further action beyond noting the preference.
