This is the second patch in Tuomas Ahola’s v2 contributor housekeeping series, which extends `lint-manpages.sh` to automatically verify that all non-command manual pages (guides and interface manuals) are listed in `command-list.txt`. The patch introduces a `MAN_GUIDES` variable derived from the Makefile’s `MAN5_TXT` and `MAN7_TXT` variables and updates the linter to fail if `command-list.txt` is incomplete. It exempts `gitweb.conf(5)` to avoid a confusing display name in `git help -a`.

The patch is a direct response to Junio C Hamano’s review feedback on v1, incorporating shell quoting fixes (`"$file"` and `$(dirname "$file")`) to handle paths with whitespace or metacharacters. The changes are mechanical and do not alter the series’ core functionality. The linter now acts as a regression test for documentation completeness, ensuring future omissions are caught early.

Key technical details include the new `MAN_GUIDES` variable, the dependency on commit `c655855559` (which added `gitdatamodel(7)`), and the exemption of `gitweb.conf(5)`.
