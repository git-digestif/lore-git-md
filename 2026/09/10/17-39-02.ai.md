This is a "What's cooking" report from Junio, summarizing the current state of integration branches for Git as of September 2026. The report lists topics cooking in `next` and `seen`, newly proposed topics, stalled efforts, and recently graduated patches.

Key highlights for a future AI summarizer:

**Graduated to `master` (since last report):**
- `en/midx-missing-pack-fallback`: Fixes object lookup when a multi-pack-index references a removed pack, including a segfault fix in `git replay`.
- `hk/typofix`: Routine typo fixes in comments and tests.
- `hn/ci-cancel-stale-pr-runs`: GitHub Actions CI now cancels stale PR workflow runs.
- `jk/rev-info-argv-to-free`: Memory ownership fixes in revision machinery to prevent use-after-free.
- `ns/ref-symref-additional-tests`: New tests for ref handling (forbidden characters, symbolic refs).
- `rs/worktree-add-basename-fixes`: Fixes for `git worktree add` path handling (out-of-bounds reads, trailing slashes).
- `tc/replay-linearize`: Adds `--linearize` option to `git replay` to drop merge commits.

**New topics (needing review):**
- `vm/advice-config-global-hint`: Introduces advice scoping to disable per-user config hints (e.g., `advice.defaultBranchName`).
- `jc/rust-cargo-build-target`: Fixes Rust cross-compilation by respecting `CARGO_BUILD_TARGET`.
- `mh/rust-crate-subdir`: Moves Rust code into a `rust/` subdirectory to avoid Cargo conflicts.
- `ps/ref-storage-format`: Unifies terminology for reference storage formats (e.g., `--ref-storage-format`, `GIT_REF_STORAGE_FORMAT`).
- `ap/var-broken-down-idents`: Extends `git var` to support broken-down idents, signing keys, and `-z` output.
- `ks/history-commit-leakfix`: Fixes a memory leak in `git history` by unusing the commit buffer.
- `kn/receive-report-hook`: Adds a new `receive-report` hook to filter/modify packet-line status reports.

**Notable stalled topics (may be discarded):**
- `ps/libgit-in-subdir`: Moving `libgit.a` sources to `lib/` (ejected due to merge conflicts).
- `hs/rebase-continue-edit`: Adding `--[no-]edit` to `git rebase --continue`.
- `tb/pack-with-duplicates`: Handling duplicate objects in packfiles (needs response).
- `cl/regexec-macos-leak`: macOS regex memory leak workaround.

**Active cooking topics (in `next` or under review):**
- `ps/odb-stop-registering-in-memory-sources`: Removes ad-hoc alternate registration, simplifying ODB management.
- `ps/odb-pluggable-fsck`: Moves fsck checks into backend-specific layers for pluggability.
- `en/no-amend-during-conflicts`: Blocks `commit --amend` and partial commits during conflict resolution.
- `tb/rerere-lock-grace`: Defers auto-maintenance during sequencer operations to avoid lock contention.
