This is the first patch in the v5 series that defers auto maintenance during sequencer operations. It introduces a reusable helper, `git_config_append_parameter()`, to build `GIT_CONFIG_PARAMETERS` strings for child processes. The helper formats a single `'key'='value'` pair with proper shell quoting, appending it to a provided `strbuf`. The existing `git_config_push_split_parameter()` is refactored to use this helper, reducing code duplication.

The patch is purely preparatory and does not change behavior. The header comment in `config.h` now documents the format of `GIT_CONFIG_PARAMETERS` (a space-separated list of quoted pairs) and clarifies that a `NULL` value is treated as a boolean `true`, addressing Patrick Steinhardt’s earlier feedback about undocumented assumptions. The implementation is straightforward and uncontroversial: it moves the quoting logic into a shared function and updates the sole existing caller. No objections have been raised to this patch in prior rounds, and it is ready for integration. The sequencer will use this helper in patch 2 to disable auto maintenance during intermediate steps.
