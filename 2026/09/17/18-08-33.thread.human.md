This is an announcement for **Git for Windows 2.56.0-rc1**, the first release candidate of the Windows-specific distribution of Git. It tracks the upstream Git v2.56.0-rc1 release but focuses on packaging, installer, and platform-specific fixes rather than core Git functionality.

Key changes include dropping support for Windows 8.1 (following MSYS2), which shifts the default installation path from `/mingw64/bin/git.exe` to `/ucrt64/bin/git.exe`—users are advised to use `/cmd/git.exe` for stability. The installer is now 64-bit, resolving a regression in v2.55.0(5) that disabled the "Use external OpenSSH" option for some users; affected users must re-run the installer to restore this setting. The release also bundles updated dependencies (Git LFS v3.8.0, cURL v8.22.0, OpenSSL v3.5.8) and fixes several bugs: a 4GB object commit limit, a stack-smashing crash in parallel checkouts, and a vim integration issue that omitted the first line of files.

This is a routine release with no impact on upstream Git development. Users relying on external OpenSSH or affected by the vim bug should follow the upgrade instructions. SHA-256 checksums are provided for all downloadable artifacts (installers, portable builds, and MinGit variants).
