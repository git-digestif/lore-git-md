This thread is about adding OpenBSD support for Git's `RUNTIME_PREFIX` feature, which allows Git to locate its support files when installed in non-standard locations. The patch, submitted by Brad Smith, uses OpenBSD's `getexecpath()` function to determine the binary's runtime path, following the established pattern for other platforms like BSD and Darwin.

Junio C Hamano has reviewed the patch and found the implementation itself sound, but he raised several questions about the commit message. He wants clarification on why `getexecpath()` is preferable to the existing BSD sysctl-based method, whether the old method is being deprecated, how accurate the new approach is, and which OpenBSD versions support `getexecpath()`. Junio also suggested the patch title should specify the OpenBSD version range (8.0+). The patch remains under review, and Brad will need to revise the commit message to address these points before it can proceed. No other reviewers have weighed in yet.
