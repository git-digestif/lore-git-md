# Thread deltas

## 2026/09/17

- [2026/09/17/18-08-33 by Johannes Schindelin <johannes.schindelin@gmx.de>] Johannes Schindelin announced that Git for Windows 2.56.0-rc1 is available from https://github.com/git-for-windows/git/releases/tag/v2.56.0-rc1.windows.1.
- [2026/09/17/18-08-33 by Johannes Schindelin <johannes.schindelin@gmx.de>] Following MSYS2, Windows 8.1 support was dropped, so /mingw64/bin/git.exe no longer exists and /ucrt64/bin/git.exe takes its role; users whose setups break were advised to switch to /cmd/git.exe, which is guaranteed to stay stable.
- [2026/09/17/18-08-33 by Johannes Schindelin <johannes.schindelin@gmx.de>] Users who updated to v2.55.0(5) and rely on an external OpenSSH installation were advised to re-run the latest installer with "Only show new options" unchecked to re-enable the external OpenSSH option, because an installer issue in that version had disabled the option and caused the bundled OpenSSH to overwrite previously-saved choices.
- [2026/09/17/18-08-33 by Johannes Schindelin <johannes.schindelin@gmx.de>] The release comes with Git v2.56.0-rc1, Git LFS v3.8.0, cURL v8.22.0, and OpenSSL v3.5.8.
- [2026/09/17/18-08-33 by Johannes Schindelin <johannes.schindelin@gmx.de>] The installer is now actually a 64-bit one, fixing the external OpenSSH option that was broken in Git for Windows v2.55.0(5).
- [2026/09/17/18-08-33 by Johannes Schindelin <johannes.schindelin@gmx.de>] It is now possible to commit 4GB objects or larger in Git for Windows.
- [2026/09/17/18-08-33 by Johannes Schindelin <johannes.schindelin@gmx.de>] A bug where parallel checkouts could abort with "* stack smashing detected *: terminated" was fixed.
- [2026/09/17/18-08-33 by Johannes Schindelin <johannes.schindelin@gmx.de>] A bug introduced in Git for Windows v2.55.0(5) that caused vim to often open existing files with the first line missing was fixed.
