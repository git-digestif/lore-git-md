Subject: [PATCH] exec-cmd: add OpenBSD getexecpath() support for RUNTIME_PREFIX
Series version: standalone patch (v1 under review, v2 expected)
Originating author: Brad Smith <brad@comstyle.com>
Thread type: platform compatibility patch

Core problem or goal
Enable `RUNTIME_PREFIX` support on OpenBSD by using the system’s `getexecpath()` function (introduced in OpenBSD 8.0) to resolve Git’s binary location at runtime. This replaces a legacy "pile of hacks" that produced inconsistent results, providing a more accurate and consistent API for package managers and custom installations. The goal is to align OpenBSD with the established `RUNTIME_PREFIX` patterns used on other platforms (e.g., Darwin’s `NSGetExecutablePath`, BSD sysctl).
