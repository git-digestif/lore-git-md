Subject: [PATCH] exec-cmd: add OpenBSD getexecpath() support for RUNTIME_PREFIX
Series version: standalone patch (v1 under review)
Originating author: Brad Smith <brad@comstyle.com>
Thread type: platform compatibility patch

Core problem or goal
Enable `RUNTIME_PREFIX` support on OpenBSD by using the system’s `getexecpath()` function to resolve Git’s binary location at runtime. This allows Git to be installed in non-standard prefixes while still locating its support files, aiding package managers and custom installations.

Current status
Under review; v1 posted. Junio C Hamano has provided substantive review feedback requesting improvements to the commit message to clarify the motivation, scope, and compatibility of the `getexecpath()`-based implementation. The technical implementation remains unchanged: it adds a `git_get_exec_path_getexecpath()` wrapper in `exec-cmd.c`, defines `HAVE_GETEXECPATH` in the `Makefile`, and gates the feature to OpenBSD 8.0+ in `config.mak.uname`. No merge status reported; still under review.

Key technical details

- New `HAVE_GETEXECPATH` define in `Makefile`

- No new CLI options, config keys, or on-disk format changes
