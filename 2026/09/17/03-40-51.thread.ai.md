Subject: [PATCH] exec-cmd: add OpenBSD getexecpath() support for RUNTIME_PREFIX
Series version: standalone patch (v1 under review)
Originating author: Brad Smith <brad@comstyle.com>
Thread type: platform compatibility patch

Core problem or goal
Enable `RUNTIME_PREFIX` support on OpenBSD by using the system’s `getexecpath()` function to resolve Git’s binary location at runtime. This allows Git to be installed in non-standard prefixes while still locating its support files, aiding package managers and custom installations. The new method replaces a legacy "pile of hacks" that produced inconsistent results, offering a more accurate and consistent API available starting with OpenBSD 8.0.
