This thread is about a small but important fix to the Git test suite. Jon Simons posted a patch to address flakiness in the `t/perf/p5551-fetch-rescan.sh` performance test, which started failing intermittently after Git commit 3f763ddf28 (late 2024) introduced automatic creation of a `HEAD` symref during `git fetch`. The fix is simple: adding `--no-deref` to a `git update-ref -d` call to prevent the test harness from attempting to delete both the symref and its target, which caused the test to abort.

Jeff King (Peff) reviewed the patch and confirmed it’s correct and well-motivated. His feedback was supportive but surface-level, focusing on the clarity of the fix rather than raising technical concerns. He noted that while the test could be modernized further (e.g., using `--setup`), that’s a separate issue and doesn’t affect the current patch. The fix is minimal—just a one-line change—and directly addresses the root cause of the flakiness. It only touches the performance test suite, with no impact on production code or user-facing behavior. The patch is uncontroversial and likely to be merged without further discussion.
