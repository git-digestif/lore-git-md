This thread is about a small but important fix to the Git test suite. The `t/perf/p5551-fetch-rescan.sh` performance test became flaky after a 2024 change that automatically creates a `HEAD` symref during `git fetch`. When the test tried to clean up refs before each run, `update-ref` would fail because it attempted to delete both the symref and its target, causing the test to abort.

Jon Simons identified the issue and proposed a one-line fix: adding `--no-deref` to the `git update-ref -d` call to prevent deletion of symref targets. Jeff King (Peff) reviewed the patch and confirmed it correctly addresses the regression without side effects. Junio C Hamano has now queued the patch for the `next` integration branch, meaning it’s on track to graduate to `master` in the next cycle unless any issues emerge during integration testing. The fix is uncontroversial, with no open questions or requested changes.
