This is a bugfix patch for `git status --ignored` that restores correct pathspec matching behavior. The patch is now in its second version, incorporating Junio C Hamano’s squash-in fix for a NULL-dereference crash in the new `dir_match()` helper.

The issue stems from a 2020 optimization that skipped pathspec matching for excluded directories, causing `git status --ignored` with a pathspec like `ba` to incorrectly match ignored directories whose names *contain* the pathspec as a substring (e.g., `bar/baz/`). The v2 patch removes this optimization, ensuring exact-match behavior, and adds a defensive NULL check to prevent crashes when `pathspec` is NULL. Two test cases verify the fix: one for the original regression and another for the NULL safety edge case.

The patch is technically complete, addresses all review feedback, and is ready for maintainer integration. René Scharfe’s response confirms the NULL-dereference issue was an oversight, and the squash-in fix resolves it without altering the core behavior. No open questions remain, and the patch is uncontroversial—it trades a minor optimization for correctness, with the possibility of revisiting the optimization later. The fix touches only `dir.c` and adds no new symbols or on-disk format changes.
