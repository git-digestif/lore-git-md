This is the first patch in Kristoffer Haugsbakk’s v2 series adding independent control over notes in `git format-patch` range-diffs. It is a small, targeted refactoring that simplifies the `get_notes_args` function by removing a redundant parameter.

The patch cleans up an inconsistency introduced in commit 85bd88a7 (2025-09-25): `get_notes_args` was taking both a `struct strvec *` (accessed via `rev->rdiff_log_arg`) and the full `struct rev_info *`, even though the latter already contains the former. The change reduces the function’s signature to a single parameter (`struct rev_info *`) and updates the call site in `cmd_format_patch` accordingly. It also reformats a long `for_each_string_list` line for readability.

The patch is mechanical and well-motivated; the commit message clearly explains the redundancy and the fix. It compiles cleanly and is covered by the existing test suite. This refactoring is a prerequisite for the second patch, which implements the new `--[no-]range-diff-notes` functionality with a simplified design. The series as a whole addresses the usability concerns raised in v1, and this patch is a sensible first step toward that goal.
