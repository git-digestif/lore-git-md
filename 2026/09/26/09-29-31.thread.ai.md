Core problem or goal
A crash occurs in `git pack-objects` (assertion failure at `builtin/pack-objects.c:5004`) when a partial clone configured with `tree:0` filter encounters a promised tree object (`d0daf5223f2367bd20fc2deb9d66aed05fcd30e8`) that is not present locally and cannot be fetched. The crash is triggered in `is_not_in_promisor_pack_obj()`, called from `process_tree()` in `list-objects.c`, during the `repack_local_links()` code path in `index-pack`.

Under investigation; no patch or resolution yet. The crash is confirmed to be non-deterministic but reproducible under the described conditions (partial clone with `tree:0` filter and a missing promised tree). Another user has shared partial-clone reproduction steps in a linked thread, but no minimal reproduction is provided in this report.
