Thread type: bug fix (test suite flakiness)

Core problem or goal
The `t/perf/p5551-fetch-rescan.sh` performance test became flaky after Git commit 3f763ddf28 (late 2024) introduced automatic creation of a `HEAD` symref during `git fetch`. When the test harness tries to delete refs before each run, `update-ref` fails because it attempts to delete both the symref target and the symref itself, causing the test to abort.

Patch v1 posted; under review. Peff endorsed the fix as correct and well-motivated. No prior versions; no changes requested.

- File touched: `t/perf/p5551-fetch-rescan.sh`
- New flag: `--no-deref` added to the `git update-ref -d` invocation
- Subsystem: test suite (performance tests)
- Behavior change: prevents deletion of symref targets, eliminating the conflict
- Test coverage: fixes flakiness in `p5551`; no new test files or symbols
