The issue is tied to the `repack_local_links()` code path in `index-pack`, suggesting the crash occurs during repacking of promisor objects. While no minimal reproduction is provided, another user has shared partial-clone reproduction steps in a linked mailing list thread. The report includes debug symbols and subsystem context but no core dump due to privacy concerns. The crash is not deterministic, but the conditions (partial clone with `tree:0` filter and a missing promised tree) are clearly identified.
