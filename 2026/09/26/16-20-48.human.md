This is the fourth and final patch in Andrew Pleeter’s v9 series extending `git var` to provide broken-out identity variables. It adds the six new variables (`GIT_AUTHOR_NAME`, `GIT_AUTHOR_EMAIL`, `GIT_AUTHOR_DATE`, `GIT_COMMITTER_NAME`, `GIT_COMMITTER_EMAIL`, `GIT_COMMITTER_DATE`) that scripts can query individually instead of parsing the monolithic `GIT_AUTHOR_IDENT` and `GIT_COMMITTER_IDENT` strings. The implementation is table-driven, type-safe, and reuses the existing `split_ident_line()` logic so the new variables are guaranteed to match the behavior of the original ident strings.

The patch is cleanly split from the earlier preparatory work (string-list conversion, `-z` mode, multi-variable support) and is ready for integration. Documentation and test coverage are thorough: the man page now shows examples of querying individual components, and the test script verifies that each new variable returns the expected part of the ident string, that unset identities are handled strictly, and that multi-variable queries work correctly. No open questions or loose ends remain for this patch; the only unresolved items from the thread (trailing delimiter in `-z` mode, `GIT_SIGNING_KEY` future, and `--` handling) are orthogonal to the identity variables themselves. The series as a whole is now waiting for Junio’s final review before moving to `next`.
