This thread is about a crash in Git 2.55.0’s promisor/partial-clone subsystem. Lourens Naudé reports that `git pack-objects` fails during a `git fetch` in a partial clone configured with a `tree:0` filter. The crash occurs when the code encounters a promised tree object that is missing locally and cannot be fetched, triggering an assertion in `builtin/pack-objects.c`. The issue surfaces in the `repack_local_links()` code path and is tied to the handling of promisor objects during repacking.

The report includes debug context and confirms the missing tree via `git cat-file` and `rev-list`, but no minimal reproduction or core dump is provided. Another user has shared partial-clone reproduction steps in a linked thread. The crash is not deterministic but is reliably triggered under the described conditions. No patches or reviews have been posted yet—this is the initial bug report.
