This is a **bugfix patch series** (3 patches) targeting the low-level merge driver infrastructure in `merge-ll.c`. The series replaces the original signal-handling approach with Git’s `tempfile` API to ensure cleanup of temporary files (`.merge_file_*`) even when the merge process is interrupted by SIGINT/SIGQUIT. Jeff King (Peff) is the author of this v2 submission, incorporating feedback and testing from Michal Koutný.

The series is now technically complete and addresses the core issue: temporary files are reliably removed on interrupt, aligning with Git’s established patterns for signal-safe resource cleanup. Patch 1 refactors file reading to use `strbuf`, patch 2 fixes a minor error-checking bug in the original code, and patch 3 implements the `tempfile` API conversion. The changes are confined to `merge-ll.c` and introduce no functional behavior changes—only robustness improvements.

Michal Koutný’s testing confirms the series works for both regular termination and SIGINT scenarios, though no automated test coverage exists for interrupt handling (Peff notes the difficulty of testing this in the suite). The series is well-motivated, with clear commit messages and no substantive objections remaining. It is ready for review and likely to be uncontroversial, though the lack of test coverage for edge cases may draw minor discussion.

Key technical details for follow-up:
