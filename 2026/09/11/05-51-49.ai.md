This is patch 6/13 in the v3 series refactoring the object database (ODB) subsystem to remove ad-hoc in-memory source registration. The series is part of Patrick Steinhardt’s ongoing ODB abstraction effort and the broader `the_repository` removal initiative.

The patch removes the now-unnecessary registration of submodule object databases as alternates in `git grep`. This cleanup is possible because prior work (commit 0693806bf8, 2021) ensured that submodule repositories are passed directly to worker threads, eliminating the need for the alternate registration mechanism. The change deletes 20 lines from `builtin/grep.c`, simplifying the code while preserving functionality.

A NEEDSWORK comment remains, noting a lingering thread-safety issue: initializing the subrepository still requires holding the object-read lock due to `get_main_ref_store()`. This is outside the scope of the current series but does not block the patch, as the lock was already required for other reasons. The patch is uncontroversial and has received substantive approval from Junio C Hamano in earlier revisions ("Yay. Very nice.").

The patch touches only `builtin/grep.c` and is a straightforward cleanup with no behavioral changes. It is one of the smaller steps in the 13-patch series, which is now fully reviewed and ready for Junio’s queue. The series as a whole removes ~80 lines of code while maintaining functionality, a clear maintainability win.
