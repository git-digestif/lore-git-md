This is the third patch in Patrick Steinhardt’s 10-part series refactoring Git’s object integrity verification (fsck) to make consistency checks pluggable per ODB backend. This patch is a pure refactoring that moves global fsck option variables into the `cmd_fsck()` function, converting them to local variables. The change is mechanical and preparatory: it reduces global state and improves code clarity ahead of later patches that will rework option handling for pluggable ODB backends.

The patch removes 23 lines of global declarations (including `check_full`, `keep_cache_objects`, `name_objects`, `check_references`, and the `fsck_opts` array) and adds 22 lines inside `cmd_fsck()`, with no behavior change. Karthik Nayak’s earlier review acknowledged the patch’s design rationale, noting that these variables were only used locally and did not need to be global. Feedback was purely observational and did not engage with technical implementation or correctness.

This is a straightforward, well-contained change that aligns with the series’ goal of making fsck logic more modular. It has no user-visible impact and is ready for integration as part of the larger ODB abstraction effort. The patch is already rebased onto Junio’s integration branch and has no unresolved feedback.
