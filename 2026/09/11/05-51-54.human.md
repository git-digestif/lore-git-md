This is the eleventh patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc in-memory source linking. The series is part of the ongoing ODB abstraction effort and continues the `the_repository` removal work.

This patch updates the `test-read-midx` helper to stop linking ad-hoc ODB sources into the main object database. Previously, the helper used `odb_add_to_alternates_memory()` to register a multi-pack index (MIDX) from an arbitrary object directory as an in-memory alternate. Now, it creates a standalone `odb_source_packed` instance instead, managing its lifecycle explicitly. The change is mechanical: the helper now allocates a packed source, passes it to `load_multi_pack_index()`, and frees it when done, rather than relying on the ODB’s automatic source management.

The patch touches only `t/helper/test-read-midx.c`, adding 31 lines and removing 12. It introduces no behavioral changes—test output remains identical—but ensures the helper no longer depends on the removed `odb_add_to_alternates_memory()` API. This aligns with the series’ goal of simplifying the ODB by eliminating dual-use of the sources list for both alternates and temporary sources.

The change is uncontroversial and well-motivated. Earlier patches in the series removed the infrastructure for ad-hoc source linking, and this patch updates the test helper to match. The commit message is clear, and the code changes are straightforward. The patch is ready for Junio’s queue alongside the rest of the series.
