## 2026/09/11

- [2026/09/11/23-29-44 by Ravi Mistry via GitGitGadget <gitgitgadget@gmail.com>] Ravi Mistry submitted patch v1 (PR #2224) to make git-blame(1) and git-annotate(1) automatically use a regular `.git-blame-ignore-revs` file at the working-tree root in non-bare repositories, with `lstat()`-based checks to skip symlinks, directories, and other non-regular files, and override semantics allowing `blame.ignoreRevsFile=""`, `--ignore-revs-file ""`, or `--no-ignore-revs-file` to disable the default file.

- [2026/10/05/21-12-13 by Ravi Mistry <rmistry@google.com>] Ravi Mistry agreed that reading the committed blob from HEAD instead of the working tree makes sense.
- [2026/10/05/21-12-13 by Ravi Mistry <rmistry@google.com>] Ravi Mistry reported that his review of the parser in oidset.c and `peel_to_commit_oid` in builtin/blame.c mostly looks good, and proposed two edge-case tightenings for v2: rejecting lines with embedded NUL bytes via memchr in oidset.c, and passing OBJECT_INFO_SKIP_FETCH_OBJECT and OBJECT_INFO_QUICK in `peel_to_commit_oid` and step-by-step tag peeling so missing OIDs or tag targets do not trigger lazy promisor fetches in partial clones; he asked whether this plan sounds good for v2.

## 2026/10/08

- [2026/10/08/21-07-22 by Ravi Mistry via GitGitGadget <gitgitgadget@gmail.com>] Ravi Mistry posted v2 of the series (PR #2224) splitting it into two commits: patch 1/2 hardens `oidset_parse_file_carefully()` and `peel_to_commit_oid()` against upstream-controlled content, and patch 2/2 reads the committed `HEAD:.git-blame-ignore-revs` blob by default in both bare and non-bare repositories instead of a working-tree file.
- [2026/10/08/21-07-23 by Ravi Mistry via GitGitGadget <gitgitgadget@gmail.com>] Patch 1/2 rejects ignore-revs lines containing embedded NUL bytes via `memchr()` so trailing bytes after a NUL are not silently ignored, and changes `peel_to_commit_oid()` to use `odb_read_object_info_extended()` with `OBJECT_INFO_LOOKUP_REPLACE | OBJECT_INFO_SKIP_FETCH_OBJECT | OBJECT_INFO_QUICK`, peeling tags one layer per iteration and verifying each target exists locally and matches the declared type to avoid lazy promisor fetches in partial clones.
- [2026/10/08/21-07-24 by Ravi Mistry via GitGitGadget <gitgitgadget@gmail.com>] Patch 2/2 teaches `git-blame(1)` and `git-annotate(1)` to automatically add the `HEAD:.git-blame-ignore-revs` blob as the initial ignore-revs entry, resolving it quietly via `get_oid_with_context()`, skipping non-regular entries (e.g., committed symlinks) via `S_ISREG()`, parsing the blob in memory with a new `oidset_parse_buffer_carefully()` helper, and allowing bypass via `blame.ignoreRevsFile=""`, `--ignore-revs-file ""`, or `--no-ignore-revs-file`.
