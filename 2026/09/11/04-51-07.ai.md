This is a translation (l10n) coordination email for the upcoming Git 2.56.0 release.

Jiang Xin, the Chinese (zh_CN) translation maintainer, announces the start of the localization cycle for Git 2.56.0. The email targets all Git translators, listing 163 new or updated catalog entries that need translation since the last release. The update window runs until **26 September 2026**, with `v2.56.0-rc0` already tagged as the baseline.

The workflow is streamlined: translators pull the latest `git-l10n/git-po` repository, refresh their `.po` files with `make po-update`, and may optionally use AI-assisted tools (referencing `po/AGENTS.md`) to generate draft translations. All `.po` files must be committed with location-comment filters (`msgcat --no-location`) to keep the repository tidy. Pull requests are validated by the l10n CI pipeline (`git-po-helper`), which enforces contribution conventions.

No technical changes to Git itself are proposed; this is purely a call for translation updates. The process is routine and well-documented, with clear deadlines and tooling support.
