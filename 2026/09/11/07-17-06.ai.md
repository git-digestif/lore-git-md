This is a pull request for `gitk`, the Git repository browser GUI, containing eight patches from Johannes Sixt. The series modernizes the color preference dialog and adds a README note discouraging AI-generated contributions.

The patches are mechanical UI improvements: consolidating repetitive code around color buttons into loops, making button labels more natural, reordering sections in the dialog, and displaying color swatches directly on buttons rather than adjacent labels. The most substantive change is a one-line addition to `README.md` that states the project does not accept AI-generated contributions, aligning with the broader Git project’s stance on the topic.

The series is already merged in Johannes’s repository and is being offered for integration into Junio’s tree. No technical controversy is evident; the changes are confined to the Tcl/Tk code in `gitk` and its documentation. The pull request itself is straightforward, with a clean merge base and no conflicts reported.
