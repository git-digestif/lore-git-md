This is patch 8/10 of Patrick Steinhardt’s v3 series refactoring Git’s fsck checks to make them pluggable per ODB backend. It moves bitmap verification from `builtin/fsck.c` into the packed ODB backend (`odb/source-packed.c`), continuing the pattern established in earlier patches.

The patch relocates `verify_bitmap_files()` to operate on a single `odb_source_packed` instance rather than iterating over all sources, since the loop is now handled by the central `odb_fsck()` helper. It replaces the dedicated `ERROR_BITMAP` bit with the generic `ERROR_OBJECT` bit, simplifying error reporting. The new implementation respects the `--no-full` and `--connectivity-only` flags, skipping bitmap checks when either flag is passed. The test script `t/t5326-multi-pack-bitmaps.sh` is extended to verify these semantics.

The diff removes 5 lines from `builtin/fsck.c`, adds 3 lines to `odb/source-packed.c`, and updates 26 lines in `pack-bitmap.c` to adapt the function signature and logic. The change is mechanical and does not alter user-visible behavior. Karthik Nayak’s earlier review flagged a single spelling nit ("focussed" → "focused"), which Patrick has incorporated. No unresolved feedback remains for this patch.
