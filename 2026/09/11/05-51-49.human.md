This is the sixth patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc in-memory source registration. The series is part of the ongoing ODB abstraction effort and continues the `the_repository` removal work.

This patch removes the now-unnecessary registration of submodule object databases as alternates in `git grep`. The change is straightforward: 20 lines of code are deleted from `builtin/grep.c`, eliminating the call to `odb_add_submodule_source_by_path()` and the associated object-read lock. The commit message explains that this registration was made obsolete by prior work (commit 0693806bf8, 2021), which ensured submodule repositories are passed directly to worker threads, allowing them to look up objects without relying on alternates.

The patch retains one remaining `obj_read_lock()` due to a thread-safety issue in initializing the subrepository (specifically, `get_main_ref_store()`), which is outside the scope of this series. A NEEDSWORK comment documents this limitation. The change is uncontroversial and aligns with the series’ goal of simplifying the ODB subsystem by removing dual-use of the sources list. Junio C Hamano’s earlier substantive review of this patch in v1 ("Yay. Very nice.") signals clear approval.

No behavioral changes are expected, and the patch is ready for merging as part of the fully reviewed series. The only remaining loose end is the thread-safety issue noted in the NEEDSWORK comment, but that is acknowledged as a separate concern.
