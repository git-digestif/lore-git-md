This is a localization (l10n) coordination email for the upcoming Git 2.56.0 release.

Jiang Xin, the Chinese (zh_CN) translation maintainer, announces the start of the translation cycle for Git 2.56.0. The email is addressed to all Git translators and the mailing list. Since the last release, 163 new or updated catalog entries need translation. Translators are asked to submit pull requests to the `git-l10n/git-po` repository by **Saturday, 26 September 2026**.

The email provides a concise workflow: how to generate the latest `po/git.pot` template, refresh individual `.po` files, use AI-assisted translation tools (with a reminder to review AI output carefully), and configure Git filters to strip noisy source-location comments before committing. It also points to the `git-po-helper` CI pipeline that validates pull requests for l10n conventions.

This is purely housekeeping for the translation teams; no code changes are involved. The update window is short (two weeks), so translators will need to act promptly.
