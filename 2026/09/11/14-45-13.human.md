This is the first patch in the v6 series adding path-related keys to `git repo info`. It introduces `path.toplevel.absolute` and `path.toplevel.relative` to expose the repository’s top-level working tree directory in a scriptable format.

The implementation is straightforward: the new keys use `repo_get_work_tree()` to retrieve the working tree path and `format_path()` to handle absolute or relative formatting. In bare repositories, both keys return an empty string, matching the behavior of other repository-centric keys. The patch includes clear documentation and thorough tests covering both normal and bare-repository cases, as well as subdirectory usage.
