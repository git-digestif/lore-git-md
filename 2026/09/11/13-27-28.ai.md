This is patch 4/10 of Patrick Steinhardt’s v3 series refactoring Git’s fsck checks to be pluggable per ODB backend. The patch fixes a long-standing discrepancy between the documented and actual behavior of the `--full` flag: the documentation claims `--full` controls verification of both loose objects and alternates, but the code only applied it to packfiles. This patch ensures `--no-full` skips loose objects in alternates, aligning the implementation with the man page.

The change is minimal: three lines in `builtin/fsck.c` add a conditional check `if (check_full || source->local)` to skip non-local sources when `--no-full` is passed. A new regression test in `t/t1450-fsck.sh` verifies that loose objects in alternates are not checked when `--no-full` is used. Karthik Nayak’s earlier review confirmed the patch’s intent and logic, and Patrick corrected Karthik’s restatement of the intended behavior in the commit message to accurately reflect the patch’s logic.

This is a pure bugfix with no new infrastructure or user-visible changes beyond the corrected flag semantics. The patch is uncontroversial and ready for integration; it has no unresolved feedback or dependencies. It is part of the larger ODB abstraction effort but stands alone as a self-contained correctness fix.
