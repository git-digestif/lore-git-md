This is the twelfth patch in Patrick Steinhardt’s 13-patch series removing ad-hoc ODB source registration. It updates the `test-ref-store` helper to stop linking submodule object databases into the main repository’s ODB.

The change is mechanical and uncontroversial. The `test-ref-store` command allows testing reference stores of submodules, but since the reference subsystem no longer depends on `the_repository`, object lookups are now correctly routed to the submodule’s repository without needing to register its ODB as an alternate. The patch removes the now-unnecessary call to `odb_add_to_alternates_memory()` and its supporting code (8 lines deleted from `t/helper/test-ref-store.c`).

This aligns with the series’ broader goal of eliminating dual-use of the ODB sources list for both alternates and temporary sources. The test helper’s behavior remains unchanged; it simply no longer relies on the removed API. No test updates are needed, as the existing test suite (`t1406`) already covers the functionality.

The patch is part of a fully reviewed and stable series. Junio C Hamano, Karthik Nayak, and Justin Tobler have all provided substantive approvals for earlier patches, and this patch follows the same pattern of removing obsolete infrastructure. The series is ready for Junio’s queue.
