- **File**: `merge-ll.c`, function `ll_ext_merge()`.
- **Bug**: Silent truncation of `result_buf.len` (size_t) to `result->size` (long) when file size exceeds `LONG_MAX`, risking buffer overreads by callers.
- **Fix**: `if (result_buf.len > LONG_MAX) die(_("external merge result is too large"));` before `strbuf_detach()`.
- **Platform relevance**: LLP64 (e.g., Windows), where `long` is 32-bit and `size_t` is 64-bit.
- **Prior art**: The old code failed fast via `xmallocz`; the new code must replicate this safety check.
- **Merge status**: Series is not yet in `pu`; this fix is a prerequisite for v3.
