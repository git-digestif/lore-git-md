This is the eighth patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc in-memory source registration. The patch removes the now-unused `tmp_objdir_add_as_alternate()` function from `tmp-objdir.c` and its declaration in `tmp-objdir.h`, deleting 11 lines of code.

The function became obsolete after commit `bdee7b3013` (July 2026) switched `builtin/receive-pack` to use ODB transactions instead of temporary object directories for staging incoming objects. This patch is a straightforward cleanup with no behavioral changes or dependencies, completing the removal of the temporary object directory’s alternate-registration mechanism. The series as a whole is uncontroversial and fully reviewed, with this patch requiring no further discussion.
