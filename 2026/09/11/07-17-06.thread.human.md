This thread is about a pull request from Johannes Sixt to modernize the `gitk` color preference dialog and add a README note about AI contributions. The series, consisting of eight patches, has now been merged by Junio C Hamano into his tree and will be part of the next Git release.

The changes are purely visual and confined to `gitk`'s Tcl/Tk code: repetitive UI code was consolidated, button labels were made more natural, dialog sections were reordered, and color swatches now appear directly on buttons instead of adjacent labels. The only non-UI change is a one-line addition to `README.md` stating that AI-generated contributions are not accepted, aligning with the project's stance. There were no technical objections, conflicts, or functional changes, and the series is now closed for review.
