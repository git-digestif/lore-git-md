This is the first patch in the **v7 series** converting `USE_NSEC` to runtime configuration (`core.useNanosec`). It addresses a long-standing inconsistency between Makefile and Meson builds by exposing a configurable `man_base_url` option in `meson_options.txt`. The default (`file://$(htmldir)/`) now matches the Makefile’s behavior, ensuring relative links in manual pages (e.g., `git.1`) render correctly with a trailing slash. This fix is motivated by the need to support correct links added in later patches (e.g., to `racy-git.adoc`), though the author notes no major distros currently override `MAN_BASE_URL`.

The patch is **uncontroversial and self-contained**, touching only `Documentation/meson.build` and `meson_options.txt`. It resolves a cosmetic but user-visible issue (broken links like `/usr/share/manuser-manual.html`) and aligns Meson’s behavior with the Makefile’s decade-old default. The change is backward-compatible: distributions using Meson can now override `man_base_url` if needed, just as they could with the Makefile. The author’s research suggests few (if any) distros actively use this knob, but the fix future-proofs the build system for edge cases like Git’s `dodoc.sh` script for kernel.org.

This patch is **ready to advance independently** and has no dependencies on the rest of the series. It carries no performance or correctness risks and is purely a build-system improvement. The conflict with `ty/repo-config-cleanups` (noted in the thread summary) does not affect this patch, as it operates in a separate build system layer. Junio’s local amendment of the typo fix in `Documentation/config/core.adoc` (from the cover letter) is unrelated to this change.

Key technical details:
- **New option**: `man_base_url` in `meson_options.txt`, defaulting to `file://$(htmldir)/` (with trailing slash).
- **Files touched**: `Documentation/meson.build`, `meson_options.txt`.
- **Behavior change**: Relative links in manual pages now resolve correctly (e.g., `/usr/share/man/user-manual.html`).
- **Backward compatibility**: Existing builds are unaffected unless `man_base_url` is explicitly set.

The patch is part of the broader `dk/use-nsec-runtime` effort but stands alone as a build-system fix. Its inclusion in v7 reflects the author’s attention to detail in addressing minor inconsistencies before graduation to `master`. No further changes are expected.
