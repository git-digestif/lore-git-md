This is the first patch in the v4 series that defers auto maintenance until sequencer completion. Patrick Steinhardt provides a **surface-level review**, focusing on the clarity of the commit message and the documentation comment in `config.h`. He acknowledges the improvement in the commit message ("much better now") but suggests a minor rewording of the header comment to avoid implying the helper is tied specifically to `-c` command-line arguments, since later patches use it for other purposes. His proposed alternative clarifies that the function appends a config option for `GIT_CONFIG_PARAMETERS` and describes the format more generically. The feedback is purely about wording and does not challenge the implementation or design. The patch itself remains uncontroversial: it introduces a reusable helper for building `GIT_CONFIG_PARAMETERS` strings, refactors the existing `git_config_push_split_parameter()` to use it, and prepares the ground for the sequencer to disable auto maintenance in the next patch.
