This is patch 1/10 of Patrick Steinhardt’s v3 series refactoring Git’s fsck checks to make them pluggable per ODB backend. The patch replaces 16 lines of open-coded loose-object verification in `builtin/fsck.c` with a single call to the existing `fsck_obj_buffer()` helper. The change is purely mechanical: both the old and new code parse the object buffer, mark the object, and call `fsck_obj()`, but the helper consolidates the logic and removes redundancy. No behavior changes are introduced.

The patch touches only `builtin/fsck.c` and is part of the larger goal of moving fsck logic out of the built-in command and into the respective ODB backends (loose, packed, etc.). Earlier feedback from Karthik Nayak on v1 suggested minor wording improvements to the commit message (dropping "Almost" and clarifying the redundant `ERROR_OBJECT` flag-setting), both of which are incorporated here. The patch is uncontroversial and ready for integration.
