This is the final patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. The patch deletes the `odb_add_to_alternates_memory()` function from `odb.c` and `odb.h`, completing the cleanup started in earlier patches. No functional changes remain; this is purely a removal of dead code after all callers were updated in patches 1–12.

The commit message explains that the series’ broader goal is to ensure the ODB’s sources list contains only the primary source and its alternates, eliminating dual-use for temporary in-memory sources (e.g., submodules). This simplification paves the way for future work moving alternate handling into the "files" backend. The patch itself is mechanical: 14 lines removed across two files, with no test updates needed since the function was already unused.

This patch is uncontroversial and ready for merging. It depends on all prior patches in the series, which have been reviewed and approved by Junio C Hamano, Karthik Nayak, and Justin Tobler. The series as a whole is part of Patrick Steinhardt’s ongoing ODB abstraction effort and the `the_repository` removal project, with no external dependencies or behavioral regressions beyond a previously documented constraint in `git multi-pack-index`. The removal of `odb_add_to_alternates_memory()` aligns with the series’ design goal of enforcing a clear separation between alternates and other ODB sources.
