This is the second patch in Patrick Steinhardt’s v3 series refactoring Git’s fsck checks to make them pluggable per ODB backend. It merges two nearly identical functions in `builtin/fsck.c`: `fsck_obj()` and `fsck_obj_buffer()`. The change is a pure refactoring with no behavior change.

The patch eliminates redundancy by combining the two functions. `fsck_obj_buffer()` previously parsed the object buffer and then called `fsck_obj()`, which did the actual verification. Now there is a single function, `fsck_obj_buffer()`, that handles both parsing and verification. This also removes an early return check for the `SEEN` flag, which was always cleared by the caller anyway.

The diff is mechanical: 27 lines are removed and 20 are added, all within `builtin/fsck.c`. The new function unconditionally sets the `SEEN` and `HAS_OBJ` flags and clears `REACHABLE`, preserving the prior behavior. Karthik Nayak’s earlier review suggested a minor wording improvement in the commit message (“early” → “early return”), which Patrick has incorporated in this version.

This patch is a small but necessary step toward the series’ goal of moving fsck logic into ODB backends. It simplifies the codebase and makes the call chain clearer, with no user-visible impact. The change is well-motivated and uncontroversial.
