This is the first patch in Patrick Steinhardt’s v3 series refactoring Git’s fsck checks to make them pluggable per ODB backend. It targets `builtin/fsck.c` and is a pure refactoring with no behavior change.

The patch replaces 16 lines of open-coded loose-object verification with a single call to `fsck_obj_buffer()`. The logic is identical: parse the object buffer, mark the object, and run fsck checks. Karthik Nayak’s earlier review suggested a minor commit message tweak (dropping "Almost" from "Almost the exact same steps"), which Patrick incorporated in v2. The patch also moves the `free(contents)` call into `fsck_obj_buffer()`, which Patrick explained as a defensive measure to avoid calling the function without checking its return value.

This is a straightforward cleanup that reduces redundancy and prepares the codebase for later patches that will move fsck logic into the ODB backends. The change is mechanical and uncontroversial, with all feedback addressed in previous iterations.
