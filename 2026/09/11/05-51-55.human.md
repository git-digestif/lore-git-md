This is the twelfth patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc in-memory source registration. The series is part of the ongoing ODB abstraction effort and continues the `the_repository` removal work.

This patch updates the `test-ref-store` helper to stop registering submodule object databases as alternates. The change is straightforward: the code that previously linked the submodule’s ODB into the main repository’s ODB (via `odb_add_to_alternates_memory()`) is removed. The commit message explains that this linkage is no longer necessary because the reference subsystem now routes object lookups to the correct repository without relying on the global `the_repository`. The patch deletes eight lines from `t/helper/test-ref-store.c` and is uncontroversial, aligning with the series’ goal of eliminating dual-use of the ODB sources list.

The patch is well-motivated and clearly explained. It touches only test infrastructure, so there is no risk of user-visible behavior changes. The removal of the alternate registration is safe because the submodule’s repository is already initialized and passed to the reference store, ensuring object lookups are correctly scoped. This is consistent with the broader refactoring in the series, which has already removed similar registrations in other test helpers and production code.
