This is a "What's cooking" report from Junio, summarizing the current state of integration branches for Git as of September 2026. The report lists topics in `next` (candidates for the next release) and `seen` (under review), along with their status, recent activity, and key details.

The report highlights several notable trends and efforts:

1. **Object database (ODB) refactoring** continues with multiple topics from Patrick Steinhardt (`ps/`), including:
   - `ps/odb-stop-registering-in-memory-sources` (graduated to `master`), which removes the ad-hoc alternate registration API and simplifies ODB management.
   - `ps/odb-alternates-at-creation` (cooking), which defers alternate setup to ODB creation time during clone.
   - `ps/odb-pluggable-fsck` (cooking), which moves fsck checks into backend-specific layers, making them pluggable.

2. **Rust-related topics** are active but contentious:
   - `jc/rust-cargo-build-target` (needs review) and `mh/rust-crate-subdir` (broken) address build system issues for Rust code, including cross-compilation and Cargo integration.
   - The Rustification effort remains a recurring theme, with ongoing debate about platform support (e.g., NonStop).

3. **Reference storage format unification** (`ps/ref-storage-format`) is a significant ongoing effort to standardize terminology and CLI options around ref backends (e.g., `--ref-storage-format`).

4. **Performance and correctness fixes**:
   - `pp/midx-write-skip-empty` (new) avoids writing empty multi-pack-index layers.
   - `jk/merge-ll-tempfile-cleanup` (new) improves tempfile handling in external merge drivers.
   - `tb/rerere-lock-grace` (cooking) defers maintenance tasks during rebase/cherry-pick to avoid lock contention.

5. **New features and usability improvements**:
   - `kn/receive-report-hook` (cooking) introduces a `receive-report` hook to filter/modify server responses.
   - `kj/repo-info-more-path-keys` (cooking) extends `git repo info` with more path-related keys.
   - `tc/last-modified-bloom` (cooking) optimizes `git last-modified` using Bloom filters.

6. **Documentation and linter updates**:
   - `ta/command-list-guides-sync-lint` (cooking) adds a linter to keep `command-list.txt` in sync with manual pages.
   - `kh/doc-datamodel` (graduated) links the new `gitdatamodel(7)` tutorial from key documentation pages.

7. **Breaking changes preparation**:
   - `bc/restrict-hex-to-lowercase` (cooking) updates hex parsers to reject uppercase characters in preparation for Git 3.0.

**Key observations**:
- The ODB refactoring is the most prominent architectural effort, with multiple topics either cooking or graduated.
- Rust-related topics remain technically challenging, with build system issues and platform compatibility concerns.
- Several topics address long-standing usability pain points (e.g., `en/no-amend-during-conflicts`, `hn/history-squash`).
- Junio is actively seeking responses on several topics (e.g., `pp/midx-write-skip-empty`, `jk/merge-ll-tempfile-cleanup`), indicating they may be close to graduation or need further discussion.
