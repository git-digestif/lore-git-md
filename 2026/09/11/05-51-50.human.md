This is the seventh patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove the mechanism for registering submodule sources. The series is part of the ongoing ODB abstraction effort and continues the `the_repository` removal work.

This patch removes the infrastructure for registering submodule object databases as alternates, which was introduced in 2021 as a transitional crutch (commit `a35e03dee0`). The preceding patches in the series have already eliminated the last two callers of `odb_add_submodule_source_by_path()`, making this infrastructure obsolete. The patch deletes the `submodule_source_paths` string list from `struct object_database`, removes the `odb_add_submodule_source_by_path()` and `register_all_submodule_sources()` functions, and cleans up related code in `odb.c` and `odb.h`. It also removes the now-obsolete `GIT_TEST_FATAL_REGISTER_SUBMODULE_ODB` test mode from the documentation (`t/README`) and its exports from seven test scripts.

The changes are mechanical and uncontroversial, reflecting the completion of the migration away from implicit submodule ODB registration. The patch is well-motivated and aligns with the series’ goal of simplifying the ODB subsystem by ensuring the sources list contains only alternates. No behavioral changes are expected, and the removal of the test mode is a natural consequence of the refactoring. The patch is fully reviewed and ready for Junio’s queue, with no open questions or loose ends.
