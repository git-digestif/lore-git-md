This is the eleventh patch in Patrick Steinhardt’s v3 series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. It updates the `test-read-midx` helper to stop linking newly created packed ODB sources into the main object database, instead managing them explicitly.

The patch modifies `t/helper/test-read-midx.c` to replace the now-removed `odb_add_to_alternates_memory()` API with direct creation and cleanup of standalone `odb_source_packed` instances. The `setup_midx()` function is updated to accept an output parameter for the created source, and all callers are adjusted to free the source after use. This change aligns the test helper with the series’ broader goal of eliminating dual-use of the ODB sources list for both alternates and temporary sources.

The diff is mechanical and self-contained, touching only the test helper. No behavioral changes are expected, and the patch is a prerequisite for the final removal of `odb_add_to_alternates_memory()` in patch 13/13. The series remains uncontroversial, with all prior patches reviewed and approved by Karthik Nayak, Justin Tobler, and Junio C Hamano. This patch continues the pattern established in patch 12/13, ensuring test infrastructure does not rely on the deprecated ad-hoc source mechanism.
