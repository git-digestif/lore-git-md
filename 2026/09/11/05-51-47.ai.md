This is the fourth patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. The series is part of the ongoing ODB abstraction effort and continues the `the_repository` removal work.

This patch eliminates the last two uses of `the_hash_algo` in `submodule-config.c`. The first use, in `gitmodules_cb`, is replaced with the repository’s hash algorithm (`repo->hash_algo`), which is already available in the caller’s context. The second use, in `hash_oid_string`, is replaced with the hash algorithm embedded in the object ID itself (`hash_algos[oid->algo].rawsz`). The patch adds a defensive check to ensure the object ID is properly initialized, guarding against potential bugs where an uninitialized object ID might be passed.

The change is mechanical and preserves behavior while eliminating an implicit dependency on global state. The patch touches only `submodule-config.c`, modifying two functions (`gitmodules_cb` and `hash_oid_string`) to use the repository’s or object ID’s hash algorithm instead of `the_hash_algo`. The commit message clearly explains the rationale and the defensive safeguard, making the change easy to follow.

This patch is uncontroversial and aligns with the series’ broader goal of removing implicit dependencies on `the_repository` and related globals. It has no external dependencies and is ready for integration. The series as a whole is fully reviewed and stable, with no open questions or objections.
