This thread proposes a small but user-visible change to `git blame`: if no ignore file is explicitly configured, Git will now automatically look for and use `.git-blame-ignore-revs` in the repository root. This aligns local behavior with web interfaces like GitHub and GitLab, which already respect this file by default, reducing user surprise when blame output differs between local and web views.

The patch, posted by Ravi Mistry, is self-contained and touches only the blame subsystem, documentation, and tests. It handles edge cases like symlinks, bare repositories, and subdirectory invocations, and ensures that user-configured ignore files (including empty values) take precedence over the default. No new options or symbols are introduced—just a default lookup for an existing file format.
