This is the fourth patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. It is a small, targeted refactoring that eliminates two remaining uses of the global `the_hash_algo` in `submodule-config.c`, continuing the broader `the_repository` removal effort.

The patch updates two sites: the `gitmodules_cb` callback now uses the repository’s hash algorithm (`repo->hash_algo`) instead of the global, and `hash_oid_string` now derives the hash length from the object ID’s embedded algorithm (`hash_algos[oid->algo].rawsz`). A defensive check is added to `hash_oid_string` to guard against uninitialized object IDs, though the commit message notes this case should never occur in practice.

The change is mechanical and uncontroversial, touching only six lines in a single file. It preserves behavior while eliminating implicit global state, aligning with the series’ goal of making repository dependencies explicit. The patch has no functional impact on users or tests, and no follow-up changes are required. It is part of a fully reviewed, uncontroversial series that is now ready for Junio’s queue.
