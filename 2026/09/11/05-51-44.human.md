This is the first patch in Patrick Steinhardt’s 13-part series refactoring the object database (ODB) subsystem to remove ad-hoc in-memory source registration. It specifically targets the `cache-tree` subsystem, eliminating an implicit dependency on the global `the_repository` variable.

The patch renames the original `cache_tree_fully_valid()` function to `cache_tree_fully_valid_recursive()` (now file-scoped static) and introduces a new wrapper that takes a `struct index_state` instead of a raw `struct cache_tree`. The wrapper extracts the repository from the index state and delegates to the recursive helper. This change ensures that all callers—now passing the index state—automatically use the correct repository, removing the need for `the_repository` in this code path. The seven callers (in `builtin/checkout.c`, `builtin/commit.c`, `sequencer.c`, `sparse-index.c`, and `unpack-trees.c`) are updated to pass the index state rather than the cache tree.
