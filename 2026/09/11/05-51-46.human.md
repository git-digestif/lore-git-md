This is part of Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc in-memory source registration. Specifically, this patch (3/13) continues the `the_repository` removal effort by eliminating implicit global state dependencies in the `submodule-config` subsystem.

The patch updates seven functions in `submodule-config.c` and `submodule-config.h` to accept an explicit `struct repository *` parameter, replacing hard-coded uses of `the_repository`. Callers in `builtin/fetch.c`, `builtin/grep.c`, `builtin/submodule--helper.c`, `submodule.c`, and `t/helper/test-submodule.c` are adjusted to pass `the_repository` (or the appropriate repository in context), though the patch notes that callers typically pass `the_repository` even when a different repository is available, simplifying migration without changing behavior.

No functional changes are introduced; this is a pure refactoring that maintains existing behavior while making repository dependencies explicit. The patch is uncontroversial and aligns with the series’ broader goal of simplifying the ODB codebase and preparing for future alternate-handling improvements. All prior reviews (from Junio C Hamano, Karthik Nayak, and Justin Tobler) have been substantive and approving, and this patch was unchanged between v2 and v3 of the series. The series as a whole is now fully reviewed and ready for Junio’s queue.
