This is the **third patch in a three-patch bugfix series** addressing signal-safe cleanup of temporary files in Git’s low-level merge driver infrastructure. The series, now awaiting a v3 to fix a latent type-safety bug in the first patch, replaces custom signal handling with Git’s `tempfile` API to ensure `.merge_file_*` files are reliably deleted even when the merge process is interrupted (e.g., via Ctrl+C). This patch completes the transition by introducing `xmks_tempfile()` for atomic tempfile creation, `close_tempfile_gently()` for error-checked cleanup, and a helper function (`temp_path_basename()`) to extract relative paths from the absolute paths returned by the `tempfile` API, preserving backward compatibility with user-configured merge drivers.
