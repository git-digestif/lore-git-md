This is patch 7/10 of Patrick Steinhardt’s v3 series refactoring Git’s fsck checks to make them pluggable per ODB backend. It moves reverse-index verification from `builtin/fsck.c` into the packed ODB backend (`odb/source-packed.c`), continuing the pattern established in earlier patches.

The patch deletes the `check_pack_rev_indexes()` function (37 lines) and replaces it with `verify_reverse_indices()` (39 lines) in the packed backend. It drops the dedicated `ERROR_PACK_REV_INDEX` bit in favor of the generic `ERROR_OBJECT`, simplifying error reporting. The new implementation respects the `--connectivity-only` and `--no-full` flags: reverse-index checks are skipped when either flag is passed, matching the documented intent of those flags. A new test in `t/t5325-reverse-index.sh` verifies these semantics.

Toon Claes’s review of this patch was surface-level, confirming the architectural fit and noting that negative return values from the callback are converted to `ERROR_OBJECT` in `builtin/fsck.c`. No unresolved feedback remains. The patch is a clean, mechanical refactoring with no behavior changes beyond the intentional flag-based skipping of checks. It is ready for integration.
