Core problem or goal
Extend Git’s runtime prefix detection to OpenBSD by adding a new code path in `exec_cmd.c` that uses the `getexecpath()` function. This allows OpenBSD builds to use `RUNTIME_PREFIX`, which locates runtime files (templates, system hooks) relative to the executable’s path rather than hardcoded installation directories.

Current status
Under review. The patch is a single, small change that introduces a new conditional block (`HAVE_GETEXECPATH`) in `git_get_exec_path()`. No prior versions of the patch are referenced in this thread. The only feedback so far is a surface-level review from Chris Torek noting a lack of documentation around the mutual exclusivity of `HAVE_GETEXECPATH` and `HAVE_BSD_KERN_PROC_SYSCTL`.
