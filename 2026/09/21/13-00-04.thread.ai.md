Core problem or goal
Extend Git’s runtime prefix detection to OpenBSD by adding a new code path in `exec_cmd.c` that uses the `getexecpath()` function. This allows OpenBSD builds to use `RUNTIME_PREFIX`, which locates runtime files (templates, system hooks) relative to the executable’s path rather than hardcoded installation directories.

Current status
Under review. The patch is a single, small change that introduces a new conditional block (`HAVE_GETEXECPATH`) in `git_get_exec_path()`. No prior versions of the patch are referenced in this thread. The mutual exclusivity concern raised by Chris Torek has been resolved by Johannes Sixt’s explanation: the `&&` chaining in `git_get_exec_path()` ensures only the first successful method is used, so no additional documentation or build-system constraints are needed.
