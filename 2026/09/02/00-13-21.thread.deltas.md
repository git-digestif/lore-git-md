# Thread deltas

## 2026/09/02

- [2026/09/02/00-13-21 by Wolfgang Faust <contrib-git@wolfgangfaust.com>] Wolfgang Faust posted a patch adding a `--draft`/`--no-draft` option to `git imap-send` to mark uploaded messages with the IMAP `\Draft` flag (default `--no-draft`), since without it some clients showed uploaded drafts as un-editable and un-sendable; with libcurl the flag requires version 8.13.0 or later, otherwise a warning is issued.
- [2026/09/02/03-25-25 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano agreed that defaulting to `--no-draft` is sensible, asked whether clients sending from Drafts without the flag would misbehave on seeing it (to inform possibly flipping the default), asked whether older libcurl would error or silently ignore `--draft` (mild preference for erroring over warning), and floated adding a configuration variable.
- [2026/09/02/04-28-55 by Wolfgang Faust <contrib-git@wolfgangfaust.com>] Wolfgang Faust argued the default should stay `--no-draft` because `git send-email --imap-sent-folder` and external tooling rely on sent mail not being marked draft, and because `--draft` depends on a recent libcurl or `--no-curl`, making a flipped default behave inconsistently across systems; he said the current behavior with older libcurl is a warning and that changing it to an error seems fine; he noted a config variable would share the same problems and that starting with a flag before adding config matches past practice.
- [2026/09/02/14-37-28 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano affirmed that starting with a flag and adding configuration only after demand appears is his strong personal preference, noting Wolfgang Faust appears to be the first to follow it.
