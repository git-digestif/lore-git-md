# Thread deltas

## 2026/09/02

- [2026/09/02/14-04-37 by Simon Cheng <cyqsimon@gmail.com>] Simon Cheng reported an inconsistency in commit message handling: `git commit -m MSG` appends a newline before cleanup, but `git merge --no-ff -m MSG BRANCH` does not, which causes `prepare-commit-msg` hook comments to clobber non-interactive merge commit messages (yielding "Merge message# My additional comments" instead of "Merge message") when `commit.cleanup = strip` is set; he suggested that `git merge` should also append the newline.
