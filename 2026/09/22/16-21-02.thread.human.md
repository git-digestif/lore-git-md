This is the announcement of Git v2.56.0-rc2, the second release candidate for the upcoming Git version. Junio C Hamano, the maintainer, has packaged 728 non-merge commits from 92 contributors—36 of them first-time contributors—since the last stable release, v2.55.0.

The release candidate introduces several notable changes. On the user-facing side, `git status` now offers advice for diverged branches, the `ort` merge backend has been hardened against corrupt trees, and new configuration like `fetch.followRemoteHEAD` has been added. The `git log --follow` command has improved handling of non-linear history, and new subcommands have been added to `git refs` (`create`, `delete`, `update`, `rename`) and the experimental `git history` (`drop`). The `git replay` command now supports `--linearize` to mimic `git rebase --no-rebase-merges`. Under the hood, the release continues the ongoing effort to remove global state (e.g., `the_repository`), optimizes ref updates and reads in the `reftable` backend, and introduces support for concurrent reachability bitmaps and delta-islands in `git pack-objects`. The build system now supports universal macOS binaries when Rust is enabled. Numerous bug fixes address memory leaks, segfaults, and edge cases in commands like `git clone`, `git bisect`, and `git worktree`.

The tarballs are available for testing, and the draft release notes provide a detailed breakdown of all changes. This release candidate is intended for community testing before the final release of Git v2.56.0. No major controversies or unresolved issues are noted in this announcement.
