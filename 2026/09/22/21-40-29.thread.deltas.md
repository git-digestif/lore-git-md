# Thread deltas

## 2026/09/22

- [2026/09/22/21-40-29 by Johannes Schindelin <johannes.schindelin@gmx.de>] Johannes Schindelin announced the availability of Git for Windows 2.56.0-rc2 at https://github.com/git-for-windows/git/releases/tag/v2.56.0-rc2.windows.1.
- [2026/09/22/21-40-29 by Johannes Schindelin <johannes.schindelin@gmx.de>] The release drops Windows 8.1 support following MSYS2, changing internal paths so that /mingw64/bin/git.exe no longer exists and /ucrt64/bin/git.exe takes its role (with /cmd/git.exe recommended as a stable alternative).
- [2026/09/22/21-40-29 by Johannes Schindelin <johannes.schindelin@gmx.de>] Schindelin noted that an installer issue in v2.55.0(5) had disabled the "Use external OpenSSH" option for some users, causing the bundled OpenSSH to overwrite saved external choices; users affected are advised to re-run the installer with "Only show new options" unchecked.
- [2026/09/22/21-40-29 by Johannes Schindelin <johannes.schindelin@gmx.de>] New features include Git v2.56.0-rc2, Git LFS v3.8.0, cURL v8.22.0, and OpenSSL v3.5.8.
- [2026/09/22/21-40-29 by Johannes Schindelin <johannes.schindelin@gmx.de>] Bug fixes include: the installer is now 64-bit (fixing the broken external OpenSSH option from v2.55.0(5)), support for committing 4GB objects or larger, a fix for parallel checkouts aborting with "stack smashing detected", and a fix for a v2.55.0(5) bug where vim often opened existing files with the first line missing.
