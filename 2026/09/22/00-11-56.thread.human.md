This thread is Junio C Hamano’s "What's cooking in git.git" report for September 2026 (#08), summarizing the state of all in-flight patch series as Git 2.56-rc1 has been tagged. The report covers what has graduated to the `master` branch, new topics under review, work cooking in `next`, stalled series needing attention, and preparations for Git 3.0’s breaking changes.

Since the last report, two topics have graduated: documentation updates for `git pack-refs` and `git refs`, and a fix for a pathspec-matching bug that could cause out-of-bounds memory access. New submissions include fixes for protocol v2 fetch, OpenBSD runtime prefix resolution, Coverity-reported boundary conditions, WinANSI error reporting, and a GitLab CI update to support Rust builds on Windows. Several topics are cooking in `next`, notably a compilation speed-up for `git-compat-util.h`, submodule merge fixes, Coccinelle semantic patch updates, ref storage format unification, and a new `git history squash` subcommand. Stalled work includes external diff hunk providers, multi-pack-index incremental writes, timestamp API modernization, and early option scanning unification.

Kristoffer Haugsbakk chimed in to update the status of his stalled `kh/format-patch-range-diff-notes` series, which adds a `--[no-]range-diff-notes` option to `git format-patch`. He committed to posting a reroll by the weekend, though no new technical feedback was addressed in his message. The series remains in the "expecting a reroll" state in Junio’s report.
