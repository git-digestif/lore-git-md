Core problem or goal
BlackGit is an external application that adds per-user permission controls to monorepo hosting. It provides a client that applies sparse-checkout rules and a server proxy layer that sits between users and upstream Git hosts (GitHub, GitLab, etc.). The server enforces access controls that Git itself does not provide, then filters directory and file visibility based on the authenticated user’s permissions.
