This is the first patch in a two-patch feature series that extends `git commit --fixup` to support non-interactive message specification via `-m` and `-F` for all `--fixup` variants. The series is now in its third iteration (v3), addressing all prior feedback and considered production-ready.

The patch unifies message handling for `--fixup`, `--fixup=amend:`, and `--fixup=reword:` by allowing `-m` (inline message) and `-F` (message from file) to work consistently across all three forms. Previously, only plain `--fixup` supported `-m`, while the amend/reword variants required interactive editing. The change simplifies both the code and the user interface by removing arbitrary restrictions that had no technical justification.

Key implementation details: the patch routes all message sources through `prepare_to_commit()`, preserving message origin information and maintaining backward compatibility (the editor still launches when no message options are provided).
