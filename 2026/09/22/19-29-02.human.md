This is a documentation patch from Julia Evans that improves cross-referencing in Git's man pages. The patch replaces plain-text references like "see EXAMPLES below" with AsciiDoc cross-reference syntax (`<<EXAMPLES,EXAMPLES>>`) across 38 documentation files. The goal is to make the web-rendered man pages easier to navigate by turning these references into clickable links.

The commit message explains the technical rationale: using the two-part `<<anchor,text>>` form avoids false "broken link" warnings from AsciiDoc when the target section is in an included file (like `REMOTES` in `git-push`). The patch is mechanical but large, touching nearly every major command's documentation. Julia included a testing script that builds all man pages before and after the change to verify no functional differences were introduced, and she spot-checked the HTML output.

This is part of the broader effort to standardize Git's documentation formatting, though it's not directly tied to Jean-Noël Avila's ongoing synopsis-style conversion. The patch looks well-motivated and carefully tested, with no obvious downsides. It's a quality-of-life improvement for users reading documentation on the web.
