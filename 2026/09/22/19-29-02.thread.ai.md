Thread identity: Documentation cross-reference modernization in Git's man pages. Single patch, originating author Julia Evans, thread type: documentation improvement.

Core problem or goal: Replace informal plain-text section references (e.g., "see EXAMPLES below") with AsciiDoc link syntax (`<<target,text>>`) across 38 man pages in the `Documentation/` directory. The goal is to make HTML-rendered man pages more navigable by ensuring all cross-references are clickable, especially when the target section is in an included file. Junio C Hamano confirmed the two-part link form is necessary for cross-file references and future-proofs same-file references. Julia Evans later clarified that while the single form (`<<target>>`) sometimes works, its behavior is inconsistent (e.g., `<<REMOTES>>` renders as `[REMOTES]` in some contexts), making the two-part form the pragmatic choice to avoid broken links.

Current status: Patch approved by Junio C Hamano; queued for integration in `next`. No prior versions. No merge to `master` yet.
