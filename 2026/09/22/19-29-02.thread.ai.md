Thread identity: Documentation cross-reference modernization in Git's man pages. Single patch, originating author Julia Evans, thread type: documentation improvement.

Core problem or goal: Replace informal plain-text section references (e.g., "see EXAMPLES below") with AsciiDoc link syntax (`<<target,text>>`) across 38 man pages in the `Documentation/` directory. The goal is to make HTML-rendered man pages more navigable by ensuring all cross-references are clickable, especially when the target section is in an included file. The two-part link form (`<<target,text>>`) is confirmed as necessary for consistent rendering across AsciiDoc and Asciidoctor backends, avoiding edge cases where the single form (`<<target>>`) produces broken or nonsensical output (e.g., `[REMOTES]` in HTML or duplicated text in man pages). The thread has now surfaced a design trade-off between link stability (manual anchors preserving existing fragment identifiers) and readability (auto-generated anchors following AsciiDoc toolchain conventions).

Current status: Patch approved by Junio C Hamano and queued for integration in `next`. No prior versions. No merge to `master` yet. The new email does not alter the integration status but raises a potential follow-up discussion about anchor style.

Key technical details:
- Files: 38 files in `Documentation/`, including `git-rebase.adoc`, `git-grep.adoc`, `git-notes.adoc`.
- Change: Systematic replacement of informal references with formal AsciiDoc cross-references using the two-part form (`<<target,text>>`). The patch uses manual anchors (e.g., `[[EDITING_PATCHES]]`) for section targets.
- Behavior: No functional change to man page content; only navigation in HTML output is improved. The two-part form ensures consistency across all references and backends (AsciiDoc 10.2.1, Asciidoctor 2.0.26), avoiding edge cases where the single form fails. Auto-generated anchors (e.g., `_editing_patches`) are now supported by Git's toolchain but would alter HTML fragment identifiers, breaking existing external links.

Auto-generated anchors (e.g., `_editing_patches`) would align with toolchain conventions but break external links. The project has not yet decided whether to prioritize link stability or readability.
