This is a CI/build system patch targeting a flaky test in Git's Debian 12 CI job.

The patch works around an intermittent HTTP/2 authentication failure in the `debian-12` CI job, which began appearing after the job was upgraded from Debian 11 to Debian 12. The failure occurs in `t5559`'s half-auth clone test (specifically subtests 15 and 16), where Apache returns an early 401 response and closes the HTTP/2 stream before libcurl finishes sending the request body. Debian 12's curl 7.88.1 treats this as a transport error rather than allowing an authentication retry, a behavior fixed in curl 8.3.0.

Johannes Schindelin proposes a minimal workaround: skip the problematic tests (`t5559.15` and `t5559.16`) on Debian 12 by setting `GIT_SKIP_TESTS` in the CI environment. This avoids the need to upgrade curl, which would defeat the job's purpose of testing older supported distributions. The commit message notes this is a regression in Git v2.56 but only affects CI, not production code, so it doesn't require fast-tracking into the release.

The change is confined to `ci/lib.sh` and adds a case block for `debian-12` that exports the skip directive. The patch is straightforward and well-motivated, with clear references to the upstream curl fix and the specific tests involved. It’s part of a single-patch series (PR #2236) and looks ready for integration.
