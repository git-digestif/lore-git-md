Thread identity: CI/build system fix for intermittent HTTP/2 authentication failure in Debian 12 CI job (`t5559.15` and `t5559.16`). Single-patch series (PR #2236) by Johannes Schindelin via GitGitGadget, now implemented as a three-patch series: (1) version-range-aware runtime workaround, (2) quoting fix for the `HAVE_CURL_HTTP2_BUG` test prerequisite, and (3) test infrastructure cleanup to support here-documents in lazy prerequisites.

Core problem or goal: Work around an intermittent HTTP/2 authentication failure in Git's Debian 12 CI job, triggered by Apache returning an early 401 response and closing the HTTP/2 stream before libcurl 7.88.0–8.3.0 (Debian 12) finishes sending the request body. The failure affects `t5559`'s half-auth clone tests (subtests 15 and 16), which curl 7.88.0–8.3.0 treats as transport errors rather than allowing authentication retries (a behavior fixed in curl 8.3.0). The follow-up patches fix a quoting bug in the `HAVE_CURL_HTTP2_BUG` test prerequisite and extend the test framework to support here-documents in lazy prerequisites, improving readability and maintainability of complex test snippets.

Current status: Patch series is ready for integration. The final implementation adopts Jeff King's version-range-aware runtime prereq (`HAVE_CURL_HTTP2_BUG`), which detects curl versions between 7.88.0 and 8.3.0 (exclusive) and skips the affected tests via test prerequisites. The version range (7.88.0–8.3.0) and implementation choice are settled by the maintainer (Junio C Hamano), author (Johannes Schindelin), and reviewer (Jeff King). The commit message has been updated to correctly identify curl 7.88.0 as the bug's introduction point and to document the version-range assumptions clearly. The first follow-up patch fixes a quoting bug in the prereq snippet, ensuring the version check works as intended by replacing outer double-quotes with single-quotes and escaping inner single-quotes in the `awk` script. The second follow-up patch extends `test_lazy_prereq` to support here-documents, eliminating awkward quoting in complex shell snippets and updating the `HAVE_CURL_HTTP2_BUG` prereq as a real-world example. All patches are confined to test infrastructure (`t/test-lib-functions.sh` and `t/t5551-http-fetch-smart.sh`) and do not affect production code or on-disk formats.
