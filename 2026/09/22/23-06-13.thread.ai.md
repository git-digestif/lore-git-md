Thread identity: CI/build system fix for intermittent HTTP/2 authentication failure in Debian 12 CI job (`t5559.15` and `t5559.16`). Single-patch series (PR #2236) by Johannes Schindelin via GitGitGadget.

Core problem or goal: Work around an intermittent HTTP/2 authentication failure in Git's Debian 12 CI job, which began after the upgrade from Debian 11 to Debian 12. The failure occurs in `t5559`'s half-auth clone test (subtests 15 and 16), where Apache returns an early 401 response and closes the HTTP/2 stream before libcurl finishes sending the request body. Debian 12's curl 7.88.1 treats this as a transport error rather than allowing an authentication retry, a behavior fixed in curl 8.3.0.

Current status: Patch is ready for integration into `master`. Junio C Hamano explicitly approved the patch, calling the diagnosis "superb" and agreeing with the minimal, targeted skip as the correct workaround. He confirmed the patch does not require fast-tracking into the v2.56.0 release but should land soon after to reduce developer friction.

Root cause: curl 7.88.1 (Debian 12) treats early 401 responses as transport errors, unlike curl 8.3.0. No on-disk format or production behavior changes; purely a CI workaround.
