Core problem or goal
This is the second release candidate for Git v2.56.0, providing a testing snapshot of the upcoming release. The goal is to solicit testing and feedback from the community before the final release. The release includes 728 non-merge commits since v2.55.0, covering new features, performance improvements, internal refactoring, and bug fixes across the codebase.

Current status
The release candidate is available for download and testing. No merge status is applicable (this is not a patch series). The final release of Git v2.56.0 is pending based on feedback from this RC.

Key technical details
- **New UI/workflow features**: `git status` advice for diverged branches; hardening of `ort` merge backend against corrupt trees; `fetch.followRemoteHEAD` configuration; improvements to `git log --follow` for non-linear history; new `git refs` subcommands (`create`, `delete`, `update`, `rename`); `git history drop` subcommand; `git replay --linearize` to mimic `git rebase --no-rebase-merges`.
- **Performance/internal changes**: Continued removal of `the_repository` global state; optimizations for ref updates/reads in `reftable` backend; pluggable object database housekeeping; concurrent reachability bitmaps and delta-islands in `git pack-objects`; universal macOS binary support when Rust is enabled.
- **Files/symbols touched**: Broad changes across `builtin/`, `refs/`, `reftable/`, `replay.c`, `merge-ort.c`, `pack-objects.c`, and documentation. New config keys (`fetch.followRemoteHEAD`), CLI options (`--linearize`), and test coverage for new features.
- **On-disk format**: No breaking changes, but hardening against corrupted reftables and trees.
- **Test coverage**: Expanded for new features (e.g., `git refs` subcommands, `git history drop`, `git replay --linearize`).
