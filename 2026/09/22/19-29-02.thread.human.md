This thread covers two related but distinct documentation efforts in Git. The first, a cross-reference modernization patch series by Julia Evans, is approved and queued in Junio’s `next` branch since mid-July 2024. It systematically replaces informal section references with formal AsciiDoc links across 38 man pages, improving HTML navigation without altering content. The patch is stable, with no technical changes since v2, though a minor design trade-off—whether to prioritize link stability or toolchain conventions—remains open for future discussion.

The second effort, a proposed rewrite of Git’s tutorial, has taken a clearer shape. Julia Evans now suggests a two-phase approach: first, a patch series removing the current tutorial and all references to it, and second, a separate series introducing the new, simplified version. This addresses Junio C Hamano’s concern about leaving broken references or losing useful content, while keeping the deletion and addition steps reviewable independently. The new tutorial would focus on core commands (`git init`, `git add`, `git commit`, etc.) and defer branches to a follow-up guide, but the exact triage of omitted topics is still unresolved. Junio remains skeptical of external links, preferring self-contained documentation, though Julia’s latest proposal sidesteps that debate by focusing on internal changes. The rewrite is still in the design phase, with no patches yet posted to the list.
