This thread is about two separate but related documentation efforts by Julia Evans to improve Git’s learning materials.

The first, already approved and queued in Junio’s `next` branch, modernizes cross-references in 38 man pages by replacing informal plain-text references with formal AsciiDoc links. The change improves HTML navigation while preserving man-page content, though it may break some external links due to manual anchor choices. Junio and Jeff King have reviewed and endorsed the technical approach, and the patch is awaiting graduation to `master`.

The second, just introduced, is a complete rewrite of the Git tutorial (`gittutorial.adoc`). Julia proposes a radically simplified version that covers only eight basic commands—omitting branches entirely—to reduce beginner cognitive load. Early feedback from test readers, including Jeff King, has been positive, but Julia is not yet seeking detailed technical review. Instead, she’s looking for high-level objections to the structure before refining the draft with input from actual beginners. This effort is still in the design phase, with no patches posted yet.
