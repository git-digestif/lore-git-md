This thread covers two related documentation improvements in Git. The first, a cross-reference modernization effort by Julia Evans, systematically replaces informal section references with formal AsciiDoc links across 38 man pages to improve HTML navigation. This patch (v2) is approved and has been queued in Junio C Hamano’s `next` branch since July 2024 but hasn’t yet merged to `master`. Jean-Noël Avila recently added a key technical justification for the patch’s use of the two-part link syntax (`<<target,text>>`): it’s necessary to support translated man pages, as it allows translators to adapt link text to different languages’ grammatical requirements. This strengthens the design choice without altering the patch’s status.

The second effort is Julia Evans’s proposed rewrite of Git’s tutorial, aiming to simplify it by focusing on core commands (`git init`, `git add`, `git commit`, etc.) and deferring branches to a follow-up tutorial. After initial discussion, Junio endorsed a two-phase workflow: first removing the current tutorial and its references, then adding the new version. This approach avoids past pitfalls like leaving outdated content in place and ensures a clean transition. While the rewrite has received positive early feedback, no patches have been sent yet, and the triage of omitted topics remains unresolved. The cross-reference work is part of Jean-Noël’s broader documentation synopsis-style conversion, while the tutorial rewrite aligns with the 2026 Contributor’s Summit consensus favoring ground-up rewrites.
