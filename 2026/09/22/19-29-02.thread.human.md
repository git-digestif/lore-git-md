This thread covers two related but distinct documentation efforts by Julia Evans. The first, **cross-reference modernization**, is a technical cleanup of 38 man pages to replace informal references with formal AsciiDoc links, improving HTML navigation. This patch series (v2) has been approved by Junio and is queued in `next` since July 18, 2024, with no technical changes between versions—only a commit message revision. The second effort, a **proposed rewrite of the Git tutorial**, aims to simplify the learning curve by focusing on core commands (`git init`, `git add`, `git commit`, etc.) and deferring branches to a follow-up tutorial. This rewrite is still in the early design phase, with Julia soliciting high-level feedback on the structure.

The cross-reference modernization is effectively settled, though a lingering design question remains: whether to prioritize link stability (manual anchors, which may break external links) or readability (auto-generated anchors, which align with toolchain conventions). Julia and Jeff King have documented the trade-offs, but no decision has been made, and the current patch accepts the link breakage. Meanwhile, the tutorial rewrite has hit a structural snag. Junio praised the rewrite’s goals but pointed out that learners shouldn’t have to navigate three documents (the new tutorial, the old one, and a follow-up) to cover the same material. He urged Julia to triage the omitted topics—either discard them, relocate them in Git’s documentation, or acknowledge they belong in external guides. This aligns with a broader project consensus from the 2026 Contributor’s Summit to favor ground-up rewrites over incremental polishing, but the proposal’s scope remains incomplete until the "rest" of the material is addressed. No technical implementation details or edge cases have been discussed yet for the rewrite.
