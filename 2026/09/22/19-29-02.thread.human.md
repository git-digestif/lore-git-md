This thread covers two related but distinct documentation improvements in Git. The first, **cross-reference modernization**, is a technical effort to replace informal section references with formal AsciiDoc links across 38 man pages. This patch (v2) has been approved by Junio C Hamano and is queued in `next` since July 18, 2024, with no technical changes since v1—only the commit message was clarified. The work improves HTML navigation but uses manual anchors, which may break some external links. The trade-off between link stability and readability remains an open question, though the patch itself is ready for integration.

The second effort is a **proposed rewrite of the Git tutorial** (`gittutorial.adoc`), aimed at simplifying the learning experience for beginners by focusing on core commands and deferring branches to a follow-up tutorial. Julia Evans has shared a draft and received early positive feedback, including from Jeff King. Junio endorsed the ground-up rewrite approach but flagged a key gap: the omitted topics from the current tutorial must be triaged into obsolete, relocatable within Git’s docs, or better suited for external resources. Julia now proposes addressing this by writing new internal guides for relevant material and curating external links (via `git-scm.com/learn`) for the rest, arguing that outdated guides harm user trust. The plan is pragmatic but still high-level, with no patch yet sent to the list. The rewrite aligns with the 2026 Contributor’s Summit consensus favoring fresh tutorials over incremental updates.
