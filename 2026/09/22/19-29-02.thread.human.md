This thread is about modernizing cross-references in Git’s man pages to make them clickable in HTML output. Julia Evans proposed replacing informal plain-text references (like “see EXAMPLES below”) with formal AsciiDoc links (`<<EXAMPLES,EXAMPLES>>`) across 38 files in the `Documentation/` directory. The key technical detail is the use of the two-part link form, which avoids rendering inconsistencies in AsciiDoc and Asciidoctor backends—single-part links (`<<EXAMPLES>>`) can produce broken or nonsensical output like `[EXAMPLES]` in HTML or duplicated text in man pages.

The patch was approved by Junio C Hamano and has been queued in the `next` branch since July 2024, though it hasn’t yet graduated to `master`. The only change from the first version was an updated commit message clarifying the necessity of the two-part form and the trade-off between link stability (manual anchors preserving existing fragment identifiers) and readability (auto-generated anchors following AsciiDoc conventions). Jeff King (Peff) provided a thorough technical review, testing both backends and documenting edge cases, while Junio requested only editorial refinements. The broader question of whether to prioritize link stability or readability remains open, but the current patch is ready for integration.
