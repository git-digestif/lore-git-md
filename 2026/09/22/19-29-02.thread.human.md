This thread is about modernizing cross-references in Git’s man pages to use AsciiDoc link syntax, making HTML-rendered documentation more navigable. Julia Evans authored a single patch that systematically replaces informal plain-text references (e.g., "see EXAMPLES below") with formal AsciiDoc links (`<<EXAMPLES,EXAMPLES>>`) across 38 man pages. Junio C Hamano reviewed and approved the patch, confirming the two-part link syntax is necessary for cross-file references and future-proofing, and queued it for integration in the `next` branch.

Julia’s follow-up clarifies an edge case in AsciiDoc’s behavior: while the single-form link (`<<target>>`) sometimes works for cross-file references, it fails in other cases (e.g., `<<REMOTES>>` rendering as `[REMOTES]` in HTML). This reinforces the patch’s pragmatic choice to use the two-part form universally, avoiding broken links without altering the man pages’ functional content. The patch remains ready for integration, with no open questions or changes needed.
