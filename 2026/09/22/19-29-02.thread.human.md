The Git mailing list is discussing two related but distinct documentation improvements. The first, already approved and queued, is a modernization of cross-references in 38 man pages to improve HTML navigation. Julia Evans led this effort, replacing informal references with formal AsciiDoc links, and Junio C Hamano has queued the patch in `next` since mid-July. The second is a proposed ground-up rewrite of the Git tutorial, also by Julia Evans, aiming to simplify the initial learning experience by focusing on core commands and deferring branches to a follow-up tutorial. This rewrite is still in the design phase, with no patch yet submitted.

The cross-reference modernization is largely settled, though a design question remains about whether to prioritize link stability (manual anchors) or readability (auto-generated anchors). The tutorial rewrite, however, is still shaping up. Julia Evans initially proposed addressing omitted topics by linking to external resources, but Junio has pushed back, arguing that stale external links could do more harm than good. He prefers a self-contained solution, urging the project to focus on removing outdated internal documentation rather than relying on external maintenance. Early feedback on the tutorial draft has been positive, but the discussion is now centered on how to handle the material that won’t fit into the new, streamlined version. No technical objections to the rewrite’s structure have emerged yet, but the project’s bandwidth for maintaining fresh documentation remains a key concern.
