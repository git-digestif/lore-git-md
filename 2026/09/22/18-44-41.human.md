This is a detailed recap of the Git Contributors' Summit 2026, written by Johannes Schindelin and aimed at the broader Git community. It summarizes discussions across multiple breakout sessions, including security processes, Git 3.0 planning, documentation improvements, Outreachy funding, pluggable object databases, AI policy, and push protocol v2.

The email is not a patch or technical proposal but a narrative report, so it doesn’t introduce new code or decisions. Instead, it provides context for several ongoing efforts mentioned in the "What's cooking" thread. Key takeaways: the Git 3.0 timeline (spring 2027) and scope (including Rust support as a goal but not yet guaranteed) are clarified, though portability concerns (e.g., NonStop platform) remain unresolved. The security process discussion highlights bottlenecks like triage overload and the need for clearer documentation of Git’s security model. Documentation improvements focus on making Git more approachable for beginners, with Julia Evans’ work cited as a model. The pluggable object database effort is progressing but still lacks commit-graph and multi-pack-index integration. AI policy remains contentious, with no consensus on acceptable use or DCO compliance. Push protocol v2 is motivated by scalability (e.g., repositories with millions of refs) and SHA-256 interoperability, though no final design has emerged.

Schindelin’s personal notes add candid commentary, particularly on Rust support (where he expresses skepticism about unresolved portability issues), SHA-256 interoperability (which he sees as underestimating real-world challenges), and the summit’s remote participation challenges. The tone is collaborative but frank, acknowledging disagreements and open questions. For readers tracking Git 3.0 or specific efforts like documentation or security, this email provides valuable background—though it’s clear that many topics will require further mailing list discussion before decisions are finalized. The call for other participants to share their summaries suggests this is one perspective among many.
