## 2026/09/25

- [2026/09/25/09-53-19 by Luca Milanesio <luca.milanesio@gmail.com>] Luca Milanesio added context that several pluggable JGit storage implementations are running in production today: Google's Git servers (including gerrit.googlesource.com) have operated for over a decade on a custom pluggable JGit backend built on Google's internal data-center storage using the same open-source JGit classes and interfaces; and the open-source global-refdb module (github.com/GerritCodeReview/modules_global-refdb), developed by GerritForge over six years ago and donated to AOSP, is used in several large multi-site Gerrit deployments worldwide for globally consistent ref updates across distributed sites.
- [2026/09/25/09-53-19 by Luca Milanesio <luca.milanesio@gmail.com>] Luca Milanesio stated that the earlier Cassandra backend implementation captured attention ten years ago without immediate adoption, which he suspects was due to timing preceding the current appetite for AI-generated code, and that JGit's architectural foundation built over 16 years ago is positioned to support such modern innovations.
- [2026/09/25/09-53-19 by Luca Milanesio <luca.milanesio@gmail.com>] Luca Milanesio expressed that it is exciting to see core Git moving in the same direction with Patrick's pluggable object database work, noting that pluggability has always been a core strength of JGit's design.
