Core problem or goal
This is a routine pre-release announcement for Git for Windows 2.56.0-rc2, the second release candidate of the Windows-specific fork of Git. The announcement details changes, bug fixes, and component updates specific to the Windows port, with no direct implications for the upstream Git project.

Current status
Announced; no upstream integration or review status applies. This is a downstream release candidate for Git for Windows users.

Key technical details
- Dropped Windows 8.1 support (aligns with upstream MSYS2), resulting in internal path changes (`/ucrt64/bin/git.exe` replaces `/mingw64/bin/git.exe`; users advised to switch to `/cmd/git.exe` for stability).
- Bundled component updates: Git v2.56.0-rc2, Git LFS v3.8.0, cURL v8.22.0, OpenSSL v3.5.8.
- Fixed bugs:
  - 32-bit installer bug breaking the "Use external OpenSSH" option (affected users should re-run the installer).
  - 4GB+ object commit limitation (long-standing).
  - Stack-smashing crash in parallel checkouts.
  - Vim regression in v2.55.0(5) where the first line of files was often missing.
- No upstream Git subsystems, symbols, or on-disk formats are affected.

Open questions and loose ends
None; this is a finalized release candidate announcement. No upstream discussion or action is expected.

Participant positions
Only Johannes Schindelin (announcer); no reviewers or positions expressed.

Related work
Git for Windows is a downstream fork of Git, maintained separately from the upstream project. This announcement is unrelated to any ongoing upstream efforts (e.g., ODB abstraction, Rustification, reftable). No dependencies or conflicts with upstream work are noted.
