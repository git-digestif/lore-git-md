This is a CI/build system patch from Johannes Schindelin. It works around a flaky test failure in Git’s Debian 12 CI job caused by a bug in the system’s libcurl version (7.88.1). The issue surfaces in `t5559.15` and `t5559.16`, which test half-authenticated clones over HTTP/2. Apache can close the HTTP/2 stream prematurely when authentication is required, and the older libcurl treats this as a transport error rather than allowing a retry. The fix simply skips those two tests on Debian 12 until the distro updates its libcurl package.

The patch is narrowly scoped and well-motivated: it preserves the job’s purpose (testing on older supported distributions) without introducing workarounds that would undermine that goal. The commit message clearly explains the root cause, the upstream fix, and why skipping the tests is the right solution here. This isn’t a regression in Git itself, just a CI annoyance, so it doesn’t need to be fast-tracked for the upcoming v2.56.0 release, but it’s worth merging soon to reduce developer friction.
