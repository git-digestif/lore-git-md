This is a design-discussion follow-up in the `fetch.shallow` thread. The thread is now converging on an alternative solution: modifying `git remote add` to avoid wildcard fetch refspecs in shallow repositories, rather than introducing a new `fetch.shallow` configuration option. Harald Nordgren, the original author, agrees with Phillip Wood’s suggestion that the root cause of the performance issue lies in `git remote add` defaulting to wildcard refspecs, which causes refspec-less fetches to negotiate history for all remote branches. The discussion has shifted from debating the original patch to exploring whether this narrower change to `git remote add` would be sufficient to address the problem. No code has been written yet for the alternative approach, and the original patch remains unmerged. The thread is still under active design consideration.
