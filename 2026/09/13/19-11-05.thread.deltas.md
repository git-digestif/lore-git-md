# Thread deltas

## 2026/09/13

- [2026/09/13/19-11-05 by Johannes Schindelin via GitGitGadget <gitgitgadget@gmail.com>] Johannes Schindelin submitted a 2-patch series to fix Perl-related test failures on Windows, explaining that Perl tests are skipped in CI for performance reasons and because git svn support was retired in Git for Windows, causing bit-rot; these were the only two bugs found when running the full test suite on Windows/ARM64 while preparing Git for Windows v2.56.0-rc0.
- [2026/09/13/19-11-06 by Johannes Schindelin via GitGitGadget <gitgitgadget@gmail.com>] In patch 1/2 (t9700), Schindelin changed the platform check from `$^O eq 'msys'` to `defined $ENV{MSYSTEM} && $ENV{MSYSTEM} ne 'MSYS'` because MSYS2 Perl now reports `$^O` as `cygwin` instead of `msys`, and using `cygwin` would break in actual Cygwin where git.exe reports pseudo-Unix paths.
- [2026/09/13/19-11-07 by Johannes Schindelin via GitGitGadget <gitgitgadget@gmail.com>] In patch 2/2 (t9129), Schindelin added the `!MINGW` prerequisite to the UTF-8 test cases because Git for Windows (native Win32 using Code Pages) and its MSYS2 Perl interpreter (using Unix locale environment variables) have incompatible encoding conversion concepts, so these tests cannot work on that platform.
