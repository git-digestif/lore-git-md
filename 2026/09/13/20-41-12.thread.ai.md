Subject: [PATCH] cmake: update UCRT64 toolchain prefix for Git for Windows
Series version: standalone patch (no series)
Originating author: Johannes Schindelin (via GitGitGadget)
Thread type: platform compatibility patch (build system)

Core problem or goal
Git for Windows has migrated its toolchain from MINGW64 to UCRT64, which installs Unix tools in `/ucrt64/` instead of `/mingw64/`. The CMake build system still hard-coded the old prefix, causing `git.exe` to fail to locate its dependencies. This patch updates the prefix in `contrib/buildsystems/CMakeLists.txt` to match the completed migration.

Current status
Under review. The patch is a follow-up to the recently merged `js/mingw-build-updates` series, which was merged before the UCRT64 migration to avoid breaking CI. This patch is only correct *after* the migration, which Johannes completed on 2026-09-10. It is required for Git for Windows (which runs the `vs-build` CI job) but optional for core Git (which skips it).

Key technical details
- File touched: `contrib/buildsystems/CMakeLists.txt` (one-line change)
- Subsystem: CMake build system (Windows-specific)
- New behavior: CMake now looks for Unix tools in `/ucrt64/` instead of `/mingw64/`
- No on-disk format changes, no new symbols, no test coverage (build system only)
- No impact on non-Windows platforms

Open questions and loose ends
