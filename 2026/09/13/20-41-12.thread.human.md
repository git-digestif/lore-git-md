This thread is about a small but important build-system patch for Git for Windows. Johannes Schindelin has updated the CMake configuration to match Git for Windows' recent migration from the MINGW64 toolchain to UCRT64, which uses the Universal C Runtime. The change is just one line in `contrib/buildsystems/CMakeLists.txt`, ensuring that the built `git.exe` looks for its Unix tool dependencies (like `sed` and `awk`) in the correct `/ucrt64/` directory instead of the now-deprecated `/mingw64/`.

This patch is a follow-up to an earlier series (`js/mingw-build-updates`) that was merged before the UCRT64 migration was finalized, to avoid breaking CI during the transition. Now that the migration is complete (as of September 10th, 2026), this update is necessary for Git for Windows' CI, though it doesn’t affect core Git’s behavior on other platforms. The change is uncontroversial—it simply aligns the build system with an already-completed infrastructure shift—and doesn’t alter any user-facing functionality. No further discussion or revisions are expected.
