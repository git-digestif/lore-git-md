This thread is about a two-patch series from Johannes Schindelin that fixes minor test failures on Windows/ARM64 in preparation for Git for Windows v2.56.0-rc0. The patches don’t affect core Git functionality but ensure clean test runs on the platform.

The first patch adjusts Perl environment detection in `t/t9700/test.pl` to correctly identify MSYS2 Perl environments via the `MSYSTEM` environment variable, replacing a check that relied on `$^O` (which now reports `cygwin`). The second patch, just summarized, unconditionally skips UTF-8 tests in `t/t9129` on Windows due to a fundamental encoding mismatch: Git for Windows uses Windows "Code Pages," while MSYS2 Perl relies on Unix-style `LC_ALL` variables, making the tests impossible to pass.

Johannes, the Git for Windows maintainer, authored both patches, and his rationale for the UTF-8 skip is pragmatic and well-explained. While the outright skip might spark discussion about whether a more targeted fix could preserve some test coverage, the patches are narrowly scoped and unlikely to be controversial. The series is under review, with no objections or requests for changes raised so far. It’s purely a platform-specific test suite adjustment, with no impact on upstream Git or its integration branches.
