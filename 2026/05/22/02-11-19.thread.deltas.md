## 2026/08/23

- [2026/08/23/19-38-04 by Michael Montalbo <mmontalbo@gmail.com>] Michael Montalbo retracted the "diff provider" abstraction introduced in v7, stating it is not ultimately helpful and shoehorns several concepts together that should be addressed separately, and clarified that "chain order is authority" was an unclear way to describe earlier providers overriding xdiff's default.
- [2026/08/23/19-38-04 by Michael Montalbo <mmontalbo@gmail.com>] He confirmed that the original intent was to configure a provider for a file type via .gitattributes and diff.<driver>.process, using xdiff when no provider is configured.
- [2026/08/23/19-38-04 by Michael Montalbo <mmontalbo@gmail.com>] He confirmed that the diff-hunks store stores xdl_opts directly so the in-memory representation cannot change without breaking the cache, and noted that on a separate branch he had a prune command removing entries based on time but nothing more intelligent.
- [2026/08/23/19-38-04 by Michael Montalbo <mmontalbo@gmail.com>] He agreed that "coordinates" was a term he invented to refer to offsets and lengths in hunk headers and said he would replace it with more explicit, established terminology.
- [2026/08/23/19-38-04 by Michael Montalbo <mmontalbo@gmail.com>] He stated his goals: to add a "cousin" interface to xdiff-interface allowing users to configure their own alternative to xdiff that composes with surrounding Git diff functionality; to still use xdiff for content rendering so an alternative stages hunks while xdiff renders; to allow current xdiff-interface callers to operate with OIDs only and no content loading when only hunk header info is needed; and to provide a consistent pkt-line interface for plugging in xdiff alternatives.
- [2026/08/23/19-38-04 by Michael Montalbo <mmontalbo@gmail.com>] He decided to return to the v6 line for future re-rolls, focusing on the "cousin" interface framing rather than v7's "diff provider" concept, and to eject the diff-hunks patches for now to focus on the "pkt-line xdiff-interface" line.
