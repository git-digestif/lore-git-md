This is a refactoring patch that is part of Kristoffer Haugsbakk’s ongoing `[PATCH v5 0/2] format-patch: add --[no-]range-diff-notes` series. As noted in the thread context, the preparatory patch (1/2) from earlier versions has already been merged, so this email is effectively a re-send of that merged patch for completeness in the v5 series.

The patch simplifies the `get_notes_args` function in `builtin/log.c` by removing an unnecessary parameter. Previously, the function took both a `struct strvec *arg` and a `struct rev_info *rev`, even though `arg` was always set to `rev->rdiff_log_arg`. The change makes the function signature cleaner by having it take only `rev` and operate directly on `rev->rdiff_log_arg`. The patch also tidies up a long line in the `for_each_string_list` call by breaking it into multiple lines for better readability.

This is a small, mechanical refactoring with no behavior change. The commit message is concise and directly explains the motivation. The patch itself is straightforward and aligns with Git’s coding style. Since this patch has already been merged, it is included here only for completeness in the v5 series, and no further action is needed on it. The substantive part of the series is the second patch, which introduces the new `--[no-]range-diff-notes` options.
