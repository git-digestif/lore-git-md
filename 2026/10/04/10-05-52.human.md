This is a small refactoring patch for the `git stash` command. Phillip Wood replaces a hard-coded integer (`2`) with the named constant `INCLUDE_ALL_FILES` in the option-parsing code for the `--all` flag. The constant is already used elsewhere in the same file to check the value of `include_untracked`, so this change makes the code more consistent and self-documenting.

The patch touches only `builtin/stash.c`, changing two lines where the `--all` option is defined in the option tables for `push_stash` and `save_stash`. No behavior change is introduced—this is purely about code clarity. The commit message is concise and to the point, and the change itself is straightforward.

Phillip is a well-known contributor with deep expertise in the sequencer and stash subsystems, so this patch is likely to be uncontroversial. It’s a minor cleanup, but the kind that helps future maintainers avoid confusion when reading the code.
