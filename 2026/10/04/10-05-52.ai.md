This is a small refactoring patch for the `git stash` command. Phillip Wood replaces a hard-coded integer (`2`) with the named constant `INCLUDE_ALL_FILES` in the option-parsing code for the `--all` flag. The constant is already used elsewhere in the same file (`builtin/stash.c`) to represent the same semantic value, so this change makes the code more consistent and self-documenting.

The patch touches only two lines in `builtin/stash.c`, both in the option-parsing tables for the `push_stash` and `save_stash` functions. No behavior change is introduced; this is purely a readability and maintainability improvement. The commit message is clear and concise, and the change itself is straightforward.

This is not part of a larger series; it is a standalone patch. The patch is well-motivated and uncontroversial, addressing a minor inconsistency that could otherwise lead to confusion or errors during future maintenance. The use of a named constant instead of a magic number is a standard best practice in C code.
