This is the first patch in Kristoffer Haugsbakk’s v4 series introducing `--[no-]range-diff-notes` options to `git format-patch`. It is a refactoring patch that simplifies the `get_notes_args` function by removing a redundant parameter.

The patch removes the now-unnecessary `struct strvec *arg` parameter from `get_notes_args`, instead having the function directly access `rev->rdiff_log_arg` (introduced in commit 85bd88a7, 2025-09-25). This change is mechanical and straightforward, touching only `builtin/log.c`. The commit message is concise, and the patch includes a minor formatting adjustment to a long `for_each_string_list` line for readability.

This refactoring is preparatory work for the second patch, which implements the new `--range-diff-notes` functionality. The change is well-motivated and aligns with the series’ goal of making notes handling in `git format-patch` more explicit and maintainable. No substantive concerns have been raised about this patch, and it is ready for integration alongside the rest of the series.
