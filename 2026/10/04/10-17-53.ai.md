This is the first patch in the v4 series introducing `--[no-]range-diff-notes` to `git format-patch`. It is a preparatory refactoring that simplifies the `get_notes_args` function by removing a redundant parameter.

The patch updates `get_notes_args` to take only a `struct rev_info *` instead of both a `struct strvec *` and a `struct rev_info *`. This change is possible because commit 85bd88a7 (2025-09-25) added the `rdiff_log_arg` field to `struct rev_info`, allowing the function to directly access `rev->rdiff_log_arg` instead of receiving it as a separate argument. The patch also reformats a long `for_each_string_list` line for readability.

The commit message is concise and directly states the motivation: the second parameter is now unnecessary. The diff is small and mechanical, touching only `builtin/log.c`. No behavior changes are introduced; this is purely a cleanup to prepare for the feature implementation in patch 2/2. The patch is well-motivated and uncontroversial, serving as a clean foundation for the new functionality.
