This is a bugfix patch restoring the previous behavior of `git init` and `git init --reinit` to show the absolute path of the initialized repository in its feedback message.

The patch addresses a regression introduced in commit 20e38cba3926 (setup: split up concerns of `init_db()`, 2026-09-10), which refactored the repository initialization code but inadvertently changed the output from an absolute path to a relative one (`.git/`). The author notes that the discussion around the original patch does not indicate this change was intentional, so the fix restores the absolute path by using `repo_get_git_dir()` in the new code location.

The change is minimal: it adds a new variable `full_git_dir` to hold the absolute path (since the original `git_dir` is later freed) and updates the `printf` calls to use it. The patch touches only `builtin/init-db.c` and includes no tests or documentation changes.
