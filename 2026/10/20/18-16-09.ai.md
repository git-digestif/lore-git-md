This is a documentation patch addressing minor but persistent inaccuracies in the `git-rebase` man page. The patch is now in its fourth iteration (v3 plus Junio’s editorial refinements) and is targeted at the `maint` branch for Git 2.56.0, since all the inconsistencies it fixes predate that release.

The patch removes stale cross-reference links to the "INCOMPATIBLE OPTIONS" section for `--allow-empty-message`, `--ignore-date`, and `--signoff`, which are no longer listed as incompatible with any other options. It also adds a missing cross-reference for `--onto`, which *is* incompatible with `--keep-base` but was never linked to the section. The changes touch only `Documentation/git-rebase.adoc` and affect six lines of markup: four lines removed, two lines added.

Junio’s feedback on v3 was purely editorial, focusing on commit-message phrasing ("these option" → "these options") and the patch’s base branch. Omri incorporated that feedback and confirmed the correct AsciiDoc syntax for the new `--onto` link: it should match the existing style in the file (plain text, no angle-bracket link) rather than the newer AsciiDoc cross-reference style introduced in 2fc11e3382 (2026-09-25), since the `maint` branch predates that commit. Junio queued the patch for `maint` with those refinements; no substantive objections remain.

The patch is uncontroversial, well-motivated, and ready for merging. It carries no behavioral or on-disk format changes, and the commit message now clearly explains when each inconsistency was introduced. The only open question—whether to use the newer AsciiDoc link syntax—was resolved in favor of consistency with the existing file style on the target branch.
