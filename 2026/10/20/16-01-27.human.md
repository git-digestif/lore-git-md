This is the second patch in Dorine Tipo’s two-part Outreachy series modernizing test patterns in `t/t0410-partial-clone.sh`. The patch fixes a specific anti-pattern: passing command substitution (`$(git ...)`) directly to `test_grep`, which discards Git’s exit code and risks silently masking failures. Instead, it stores the output of `git rev-parse` in shell variables (`FOO` and `HEAD_OID`) and passes those to `test_grep`, preserving the exit code chain.

The change is minimal and surgical—only six lines altered in a single test—and directly addresses the guidance in `t/README` about not discarding Git’s exit status. The commit message clearly explains the problem and the fix, and the patch itself is uncontroversial: it aligns with established test modernization practices and has already passed full test-suite validation under both SHA-1 and SHA-256.
