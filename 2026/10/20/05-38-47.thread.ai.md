Subject: [PATCH] init: restore absolute path output in "Initialized empty Git repository" message
Series version: standalone patch (v2, soon v3)

Core problem or goal
Restore the pre-20e38cba3926 behavior of `git init` and `git init --reinit` to print the absolute path of the initialized repository (e.g., `/home/user/repo/.git`) instead of the relative `.git/` path. The regression was introduced unintentionally in 20e38cba3926 (setup: split up concerns of `init_db()`, 2026-09-10) during the current development cycle (Git 2.56), making the fix urgent to avoid shipping the behavior change in the upcoming release.
