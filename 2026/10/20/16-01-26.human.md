This is a test modernization patch from Outreachy applicant Dorine Tipo, the first in a two-patch series updating `t/t0410-partial-clone.sh`. The patch replaces a brittle shell pipeline (`git ls-tree | grep | head | cut`) with a direct `git rev-parse HEAD:a_dir` call to fetch the OID of a specific subtree. The change eliminates three problems at once: exit-code masking (only the last command in the pipeline’s exit code was preserved), silent reliance on the first tree in `ls-tree` output being the desired one, and a hard-coded 40-character SHA-1 byte range that truncates SHA-256 OIDs.

The v2 iteration makes no code changes; it only expands the commit message to explicitly state the assumption that the first tree in the original pipeline was indeed `a_dir`. This addresses Junio C Hamano’s review feedback from v1, which noted the trade-off between the pipeline’s incidental correctness check and the new version’s directness. The updated message now documents the rationale clearly, making the test’s intent unambiguous.

The patch is narrowly scoped, touching a single line in `t/t0410-partial-clone.sh`, and passes the full test suite under both SHA-1 and SHA-256. It aligns with the project’s ongoing test modernization effort and avoids over-scoping by leaving other instances of similar anti-patterns in the same file for a follow-up series.
