Core problem or goal
Migrate the `pack.packsizelimit` configuration value from a standalone global variable (`pack_size_limit_cfg`) into the repository-scoped `repo_config_values` struct. This is a pure refactoring with no behavioral change, intended to reduce global state and make Git’s internals more modular and reusable as a library component.
