Core problem or goal
Migrate the `pack.packsizelimit` configuration value from a standalone global variable (`pack_size_limit_cfg`) into the repository-scoped `repo_config_values` struct. The v3 series retains the preparatory patch that uses `memset()` in `repo_config_values_init()` to reduce boilerplate and standardize initialization, making future additions to the struct less error-prone. This is a pure refactoring with no behavioral change, intended to reduce global state and improve Git’s modularity as a library component.
