This thread is about a small but urgent bugfix to restore the absolute path output in the "Initialized empty Git repository" message from `git init`. The regression was introduced in the current development cycle (Git 2.56) by commit 20e38cba3926, making the fix time-sensitive to avoid shipping the behavior change.

Matt Hunter identified the issue and posted a patch that restores the pre-regression behavior by printing the absolute path (e.g., `/home/user/repo/.git`) instead of the relative `.git/` path. The patch has gone through three iterations, with all review feedback incorporated. Patrick Steinhardt, the most substantive reviewer, confirmed the regression was unintentional and suggested minor test refinements, which were addressed in v3. Harald Nordgren and Junio C Hamano also reviewed the patch, with no further objections.

The fix is now complete and uncontroversial, touching only `builtin/init-db.c` and adding a regression test in `t/t0001-init.sh`. The patch is ready for integration, and its urgency is heightened by the upcoming Git 2.56 release. No open questions remain.
