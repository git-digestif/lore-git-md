This thread is about a small but user-visible regression in `git init`: since commit 20e38cba3926 (September 2026), the command has printed the relative path `.git/` instead of the absolute path (e.g., `/home/user/repo/.git`) in its "Initialized empty Git repository" message. Matt Hunter identified the issue and posted a minimal fix that restores the old behavior by using the repository's full git directory path.

Patrick Steinhardt reviewed the patch favorably, calling the changes "obviously good" and agreeing the regression should be fixed. He suggested two minor tweaks—dropping a redundant sentence in the commit message and changing a variable type from `int` to `size_t`—both of which Matt has accepted. The only open question is whether to add a regression test; neither participant sees it as urgent, so the patch is likely to proceed without one. The fix is uncontroversial and ready for a v2 update, after which it should be a straightforward merge.
