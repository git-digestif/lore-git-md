This thread is about a small but user-visible regression in `git init`: since 20e38cba3926 (September 2026), the command has been printing the relative path `.git/` instead of the absolute path (e.g., `/home/user/repo/.git`) in its "Initialized empty Git repository" message. Matt Hunter posted a minimal patch to restore the old behavior, touching only `builtin/init-db.c`.

Patrick Steinhardt reviewed the patch and called it "obviously good," agreeing the regression was unintentional. His only feedback was a minor stylistic tweak to the commit message—dropping a sentence about memory ownership—and a passing thought about whether to add a regression test. The patch itself is uncontroversial and ready to merge once the commit message is adjusted. No other reviews have appeared yet, but the fix is straightforward and aligns with the pre-regression behavior.
