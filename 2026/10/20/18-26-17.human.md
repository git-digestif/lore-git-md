This is a **documentation** patch discussion in the ongoing effort to replace `gittutorial` with a beginner-focused guide. Junio C Hamano and Julia Evans are debating a minor but visible detail in the new tutorial: whether to recommend `ssh-keygen -t ed25519` explicitly or let users rely on OpenSSH’s default key type.

Junio raises two pragmatic concerns. First, he notes that even though OpenSSH switched its default to ed25519 in 2023, many users on mainstream distributions may still be running older versions with RSA as the default. Second, he points out that if the tutorial omits the key type, the next step (copying the public key) will need to account for variable filenames like `id_rsa.pub` or `id_ed25519.pub`, which could confuse beginners.

Julia’s position is forward-looking: she prefers to avoid specifying a key type so the tutorial stays current if OpenSSH changes its default again (e.g., for post-quantum cryptography). She acknowledges the trade-off but considers it acceptable for a beginner-focused guide that prioritizes simplicity over absolute security.

The exchange is narrow and unlikely to block the series. It leaves one loose end—how to phrase the key-copying step if the key type is left unspecified—but this is a surface-level detail rather than a substantive objection. The broader tutorial design remains uncontroversial, and the series is still on track for merging once these minor tweaks are resolved.
