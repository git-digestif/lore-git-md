This is the second patch in Dorine Tipo’s two-patch Outreachy series modernizing test patterns in `t/t0410-partial-clone.sh`. It fixes the anti-pattern of passing `"$(git ...)"` directly to `test_grep`, which discards Git’s exit code and breaks the `&&` chain. The patch assigns the output of `git -C repo rev-parse foo` and `git -C repo rev-parse HEAD` to shell variables `FOO` and `HEAD_OID`, then passes those variables to `test_grep`. This preserves Git’s exit code and ensures the test fails if the `rev-parse` commands fail.

The change is minimal and surgical: only two lines are added (the variable assignments) and two lines are modified (replacing the command substitutions with the variables). The test file and the specific test case (`rev-list stops traversal at missing and promised tree`) are the same as in the first patch, and the series as a whole is now fully responsive to Junio C Hamano’s review feedback. No code changes were made between v1 and v2 for this patch—only the commit message in the first patch was expanded.

This patch is a textbook example of the test modernization effort: it addresses a documented anti-pattern (`t/README` explicitly warns against discarding Git’s exit code), is self-contained, and passes the full test suite under both SHA-1 and SHA-256. The technical details to track for follow-up discussion are the test file (`t/t0410-partial-clone.sh`), the test title, the use of `git rev-parse` for OID resolution, and the shell variables `FOO` and `HEAD_OID`.
