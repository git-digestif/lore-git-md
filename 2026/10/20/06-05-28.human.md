This is a brief follow-up in the ongoing `git stash` shell completion series, specifically about the fifth patch, which removes completion support for the deprecated `git stash save` subcommand. Patrick Steinhardt, in his substantive review, raised a usability question: if a user manually types `git stash save --<TAB>`, should option autocompletion still work? The author, D. Ben Knoble, acknowledged the oversight and plans to test the behavior with the patch applied, noting that if `GIT_COMPLETION_SHOW_ALL` preserves option completion, that might address Patrick’s concern. Patrick’s reply here is minimal and pragmatic: he is open to either outcome but emphasizes that if option autocompletion is removed, the availability of `GIT_COMPLETION_SHOW_ALL` as a fallback should be documented. The thread is now waiting on the author’s test results, which will likely inform a v2 update. No new objections or alternatives are introduced.
