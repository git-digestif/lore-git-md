This is the first patch in a four-part bugfix series restoring dynamic reload of alternate object databases in Git’s files-based ODB backend. It is a pure refactoring: the commit renames two internal functions (`odb_prepare_alternates` and `odb_add_alternate_recursively`) to drop the now-misleading `odb_` prefix, since these functions are now part of the files backend rather than the generic ODB layer. The change is confined to `odb/source-files.c` and touches only function names and their call sites.

The patch is mechanical and well-scoped, with no behavior change. It prepares the ground for the actual bugfix in patch 2 by making the code easier to follow. The commit message is concise and explains the rationale clearly. This is a typical tidy-up patch that should be uncontroversial and easy to review.
