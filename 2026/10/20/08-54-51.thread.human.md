This thread is about a six-patch bugfix series from Patrick Steinhardt that restores Git’s ability to dynamically reload alternate object databases—a feature accidentally broken in March 2026 during the ODB abstraction effort. The regression, though rare, has been observed in production systems where the alternates file is modified while Git is running. The series also fixes a related behavioral regression in `git receive-pack` when a quarantine directory is in use, ensuring objects moved to an alternate after quarantine creation are still found.

The series is now ready for integration. Junio Hamano reviewed the final version (v3) and declared it "pretty much done," signaling intent to merge it to `next`. All technical feedback has been addressed, including a design change to always reload the repository’s real alternates (resolving the `receive-pack` issue) and optimizations that nearly restored pre-regression performance. The only remaining issues were cosmetic: a typo in patch 4’s commit message (`dir_paths_iscase` instead of `dir_paths_icase`) and a spelling error ("mountpoint" → "mount point"). Junio has offered to fix the typo locally before applying the series, avoiding a full resend. The series is based on Patrick’s ODB cleanup branch, part of the ongoing ODB abstraction effort.

Key participants include Patrick (the author), Junio (the maintainer), and Christian Couder, who provided substantive feedback on the `receive-pack` regression and a race condition in patch 6. Christian’s later reviews were surface-level, focusing on commit message clarity and documentation. The series touches `odb/source-files.c` and adds a test in `t/t1006-cat-file.sh`, with no open technical questions remaining.
