This thread is a bugfix series from Patrick Steinhardt to restore dynamic reloading of alternate object databases in Git’s files-based ODB backend, a feature accidentally broken in March 2026 during the ODB abstraction effort. The regression, though rare, has been observed in production where the alternates file is modified while Git is running. The series also fixes a behavioral regression in `git receive-pack` when a quarantine directory is used, ensuring objects moved to an alternate after the quarantine was created can still be found.

The six-patch v2 series is now complete and under review. The core fix (patch 2) ensures alternates are always reloaded from the repository’s real object directory, addressing the quarantine interaction. Performance optimizations in later patches (4–6) nearly restore pre-regression lookup times, but a race condition in patch 6—where an in-place rewrite of the alternates file could cause Git to miss new alternates indefinitely—was identified by Christian Couder. Christian proposed a mechanical fix (reordering a `stat_validity_update()` call) that aligns with existing patterns in the codebase, but this hasn’t been implemented yet. The series is otherwise uncontroversial, with Junio and Christian providing substantive feedback that Patrick has addressed.

The latest email from Christian is a surface-level review of patch 2, correcting minor typographical issues in the commit message (adding quotes around “files” and fixing the filename “objects/info/alternates”). The feedback is purely cosmetic and doesn’t affect the patch’s correctness. The only remaining loose end is the unresolved race condition in patch 6, which Patrick will need to address before the series can graduate.
