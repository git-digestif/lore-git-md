This thread is about a bugfix series from Patrick Steinhardt that restores dynamic reloading of alternate object databases in Git’s files-based ODB backend. The regression, introduced during the ODB abstraction effort in March 2026, broke the ability to reload alternates when an object lookup fails—a rare but real issue in production systems where the alternates file may be modified while Git is running. The series also fixes a behavioral regression in `git receive-pack` when a quarantine directory is used, ensuring objects moved to an alternate after quarantine creation are still found.

The series is now in its second version with six patches, addressing earlier feedback from Junio Hamano and Christian Couder. Most issues have been resolved, but a few remain open. Christian identified a race condition in the alternates file reloading logic (patch 6) and a behavioral regression in patch 5, where the "object directory %s does not exist" error message is suppressed when a previously known alternate directory is removed. Patrick acknowledged the error suppression but argued it’s a niche edge case that doesn’t affect real-world debugging, as the alternate remains unusable regardless. The race condition in patch 6, however, still needs a fix—Christian proposed reordering a `stat_validity_update()` call to match existing patterns in the codebase, but Patrick hasn’t implemented it yet. Other minor issues include cosmetic inconsistencies in commit messages and an undocumented removal of a `NEEDSWORK` comment about case-insensitive deduplication concerns, which Patrick has agreed to restore.

The series touches `odb/source-files.c` and related files, introducing optimizations like a `strset` to track alternate paths and a `stat_validity` field to avoid unnecessary re-reads of the alternates file. Performance measurements show the fix nearly restores pre-regression lookup times, with patch 6 bringing the time for 20k missing objects down to 199.5ms (close to the original 185.3ms). The regression’s root cause was a design change in the ODB abstraction effort, and the fix is narrowly scoped to the files-based backend, avoiding broader changes to recursive alternates or other backends. Christian’s feedback has been substantive, focusing on correctness and edge cases, while Junio’s review was minor and already addressed. The series is under active review, with the race condition and error suppression as the main unresolved points.
