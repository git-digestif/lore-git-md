This thread is a bugfix series from Patrick Steinhardt to restore dynamic reloading of alternate object databases in Git’s files-based ODB backend, a feature accidentally broken in March 2026 during the ODB abstraction effort. The regression is rare but has been observed in production, where the alternates file may be modified while Git is running. The series also fixes a behavioral regression in `git receive-pack` when a quarantine directory is used, ensuring objects moved to an alternate after the quarantine was created are still found.

The series is now in its second version (six patches) and under active review. The only remaining technical issue is a race condition in the final patch, where an in-place rewrite of the alternates file during reading could cause Git to miss new alternates indefinitely. Christian Couder identified the problem and proposed a fix—moving the `stat_validity_update()` call before reading the file—which Patrick has accepted in principle, though he noted a minor flaw in Christian’s pasted variant. The fix is straightforward and aligns with existing patterns in the codebase. All other review feedback has been addressed, including restoring a previously removed `NEEDSWORK` comment about case-insensitive deduplication concerns and clarifying the scope of a suppressed error message in patch 5.

Patrick is the sole author, with Junio Hamano and Christian Couder as reviewers. Junio’s feedback was minor and focused on correctness, while Christian’s contributions were more substantive, identifying both the `receive-pack` behavioral regression and the race condition in patch 6. The series is now nearly ready for integration, pending Patrick’s implementation of the race condition fix and a few cosmetic cleanups.
