This thread is a bugfix series by Patrick Steinhardt to restore dynamic reloading of alternate object databases in Git’s files-based ODB backend, a feature accidentally broken during the ODB abstraction effort in March 2026. The regression is rare but has been observed in production, where the alternates file may be modified while Git is running. The series also fixes a behavioral regression in `git receive-pack` when a quarantine directory is used, ensuring objects moved to an alternate after quarantine creation are still found.

The series is now in its second version (v2) with six patches, covering preparatory refactoring, the core fix, and performance optimizations. The latest update addresses a race condition identified by Christian Couder in the sixth patch, where an in-place rewrite of the alternates file could cause Git to miss updates indefinitely. Christian’s proposed fix—reordering the `stat_validity_update()` call to occur before reading the file—resolves the issue while preserving the patch’s performance benefits. The series is uncontroversial, well-scoped, and backed by concrete performance data, with all prior feedback incorporated. It remains under review but appears ready for merging once the final race condition fix is applied. Key participants include Patrick (author), Junio (maintainer), and Christian, whose substantive reviews have shaped the series.
