This six-patch series from Patrick Steinhardt fixes a subtle but important regression in Git’s files-based object database backend: the loss of dynamic reloading of alternate object directories when an object lookup fails. The bug, introduced in March 2026 during the ODB abstraction effort, was rare but had real-world impact, particularly in production systems where the alternates file might be modified while Git is running. The series also corrects a behavioral regression in `git receive-pack` when a quarantine directory is in use, ensuring objects that move to an alternate after the quarantine is created are still found.

The fix is now complete, with all technical and editorial feedback addressed in this third iteration. The final patch optimizes performance by tracking the alternates file’s mtime and inode, avoiding unnecessary re-reads when the file hasn’t changed. Benchmarks show lookup time for 20,000 missing objects improved from 310ms in the unoptimized fix to 199.5ms—nearly matching the pre-regression baseline of 185.3ms. The series touches only the files-based ODB backend, leaving recursive alternates (an edge case never supported) untouched. New tests in `t/t1006-cat-file.sh` verify the fix, including the `receive-pack` quarantine scenario.

Key participants include Patrick, who authored the series and addressed all review feedback, and Christian Couder, who identified the `receive-pack` regression and a race condition in the final patch.
