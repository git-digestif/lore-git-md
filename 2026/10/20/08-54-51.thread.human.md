This bugfix series from Patrick Steinhardt, now at version 3, restores the dynamic reload of alternate object databases in Git’s files-based ODB backend—a feature accidentally broken in March 2026 during the ODB abstraction effort. The regression, though rare, has been observed in production where the alternates file is modified while Git runs, and it also caused a behavioral issue in `git receive-pack` when using quarantine directories. The six-patch series has addressed all technical and editorial feedback, including a minor typo in patch 4’s commit message and a race condition in patch 6.

Junio Hamano has now given the series his final review, calling it "pretty much done" and ready for the `next` branch. He flagged two issues in patch 4: a typo ("mountpoint" should be "mount point") and a more serious concern about the `core.ignoreCase` deduplication mechanism, which could theoretically cause Git to miss objects if deduplication produces false positives. However, he did not request a resend, indicating these are minor enough to address later if needed. The series is now poised for integration, with no further changes expected before it moves to `next`. All substantive reviews—from Junio, Christian Couder, and others—have been resolved, and the performance optimizations in patches 4–6 have nearly restored pre-regression lookup times.
