This thread is a bugfix series from Patrick Steinhardt aimed at restoring Git’s ability to dynamically reload alternate object databases—a feature accidentally broken in March 2026 during the ODB abstraction effort. The regression, though rare, has been observed in production systems where the alternates file is modified while Git is running, and it also introduced a behavioral issue in `git receive-pack` when using quarantine directories.

The series is now in its second version (v2) and consists of six patches. The first is a preparatory refactoring that renames internal functions to better reflect their scope in the files-based ODB backend. The core fix arrives in patch 3, which restores dynamic reloading, while patches 4 through 6 introduce performance optimizations to mitigate the overhead of the fix. A key design change in patch 2 ensures alternates are always reloaded from the repository’s real object directory, resolving the `receive-pack` regression identified by Christian Couder.

The series is under active review and appears uncontroversial. Junio Hamano provided minor feedback on an edge case in the first version, which Patrick addressed, and Christian’s substantive review led to the design change now incorporated in v2. Performance measurements show the optimizations nearly restore the pre-regression baseline, and the new test coverage verifies both the fix and the quarantine scenario. With no open objections, the series looks ready for final review and merging.
