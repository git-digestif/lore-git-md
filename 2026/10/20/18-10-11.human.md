The tool broke when Git’s `bisect` output format changed in commit `0c0f93e7fa64` ("bisect: print bisect terms in single quotes"). The Linux kernel team is already working on a fix for `ktest.pl`, but Steven wanted to flag this dependency for the Git project.

The message is brief and matter-of-fact: it doesn’t request changes to Git, just informs the list that external tooling relies on Git’s output stability. This is useful context for future changes to `git bisect` or other commands—developers may want to check for similar breakage before altering output formats.
