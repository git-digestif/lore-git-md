This thread is about a two-patch bugfix series for `git imap-send`, now at version 2, authored by Harald Nordgren. The series addresses two issues: a memory leak in tunnel-command handling and a parsing failure when email headers appear in non-canonical order (like `Subject` before `Date`), which breaks interoperability with tools like `b4`.

The first patch in the series, just posted, fixes the memory leak by adding a single line to clean up the `child_process` structure after the tunnel is started. It’s a simple, low-risk change with no behavior impact. The second patch, already summarized, rewrites the header-parsing logic to accept any order of `From`, `Date`, and `Subject` headers and uses case-insensitive matching to comply with RFC 5322. Junio Hamano reviewed the first version and requested the case-sensitivity fix, which Harald incorporated in this update.

The series is now complete and ready for integration. Both patches touch `imap-send.c`, and the second adds a test to verify the fix works with `b4`-style patches. No open questions remain, and the design and test coverage have been validated. The series is under review, with no merge status recorded yet.
