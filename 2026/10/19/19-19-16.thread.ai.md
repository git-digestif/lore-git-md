Thread identity: Bugfix series for `git imap-send` to handle non-canonical email header order (Subject before Date) and fix a minor memory leak. Core problem or goal: `git imap-send` fails when processing patches where the `Subject` header precedes the `Date` header, a valid but non-canonical order produced by tools like `b4` (used to fetch patches from lore.kernel.org). The series fixes the header-parsing logic to accept either order, plugs a minor memory leak in tunnel-command handling, and ensures RFC 5322 compliance (case-insensitive header name matching). The goal is to ensure interoperability with `b4` and other tools while maintaining backward compatibility.
