Thread identity: Bugfix series for `git imap-send` to handle non-canonical email header order (Subject before Date) and fix a minor memory leak. Two-patch series (`v2`) authored by Harald Nordgren via GitGitGadget, addressing RFC 5322 compliance (case-insensitive header name matching) and interoperability with tools like `b4`. The series also removes a special-case logic that previously ignored `Subject` headers for messages starting with `From git-send-email`, a change whose safety and rationale remain under discussion.

Core problem or goal: `git imap-send` fails when processing patches where the `Subject` header precedes the `Date` header, a valid but non-canonical order produced by tools like `b4`. The series fixes the header-parsing logic to accept either order, plugs a minor memory leak in tunnel-command handling, and ensures RFC 5322 compliance (case-insensitive header name matching). The goal is to ensure interoperability with `b4` and other tools while maintaining backward compatibility. The removal of the `git-send-email` special case (which previously ignored `Subject` headers for messages starting with `From git-send-email`) is contested, with Patrick Steinhardt questioning its safety and rationale.
