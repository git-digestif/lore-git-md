This thread is a small but important documentation update to *MyFirstContribution.adoc*, authored by Junio C Hamano. The patch reorganizes the tutorial to make it clearer that new contributors should engage in review discussion before preparing and sending a v2 patch, rather than treating v2 as a mechanical follow-up to v1. The key change moves the "Sending v2" sections (for both `git send-email` and `b4` workflows) from immediately after "Sending v1" to a new position after "Responding to Reviews," and strengthens the language to say "Do not send v2 before you are done" discussing the current iteration with reviewers.

The motivation is a recent uptick in contributors sending updated patches without first addressing review feedback, which wastes time for both authors and reviewers. This is a direct response to that trend, aiming to set clearer expectations in the tutorial. There’s no code or test impact—this is purely a documentation restructuring. The patch is now under review, and if accepted, it will help guide new contributors toward a more productive workflow.
