This is the final patch in Patrick Steinhardt’s seven-part series introducing the **object storage extension**, a major architectural effort to make Git’s object database pluggable. This patch teaches `git submodule` to propagate the `--object-storage-format=` option to newly cloned submodules, mirroring the existing behavior for ref storage formats.

The implementation is straightforward: the patch adds the new option to `git submodule add` and `git submodule update`, updates the shell script wrapper and the C helper (`builtin/submodule--helper.c`) to pass the format through to `git clone`, and validates the format using the same `odb_source_type_by_uri()` helper introduced earlier in the series. Documentation is updated to reflect the new option, and a new test script (`t7427-submodule-object-storage-format.sh`) verifies that the format propagates correctly during recursive clones, submodule updates, and explicit `--object-storage-format` invocations.
