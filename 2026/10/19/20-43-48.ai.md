This is a documentation patch to `MyFirstContribution.adoc`, authored by Junio C Hamano. It reorganizes the tutorial flow to emphasize that new contributors should engage in review discussion before sending a v2 patch, rather than treating v2 preparation as a mechanical step that follows immediately after v1.

The patch moves the "Sending v2" sections (for both `git send-email` and `b4` workflows) from their current position—immediately after "Sending v1"—to a new location after the "Responding to Reviews" section. It also strengthens the language around this expectation: the original text said "It is a good manners to do so," while the new version says "Do not send v2 before you are done" discussing the current iteration with reviewers.

The change is motivated by a perceived uptick in new contributors sending updated patch versions without first addressing review feedback, which wastes both their time and reviewers' time. The patch is a direct response to that trend, aiming to clarify the intended workflow in the tutorial. No code or test changes are involved; this is purely a documentation restructuring.
