This thread is about a small but useful internationalization improvement to `git fsck`. Aniket Gupta, a GSoC participant, has sent a patch that replaces a hardcoded plural form in the "Checking connectivity" message with Git's `Q_()` macro. This change allows translators to handle languages with more complex pluralization rules (like singular, dual, and plural forms) without altering the English output. The patch is minimal—just one line in `builtin/fsck.c`—and follows Git's established i18n practices.

The motivation is clear: the current message uses a fixed plural ("objects") that doesn’t accommodate languages where pluralization isn’t binary. While the patch notes that the displayed count is never 1 (a quirk left for a future fix), it’s still a step forward for translation support. The change is uncontroversial and doesn’t require test updates, as it only affects message formatting. So far, there’s been no review feedback, but given the patch’s simplicity and alignment with Git’s i18n conventions, it’s likely to be merged without issue.
