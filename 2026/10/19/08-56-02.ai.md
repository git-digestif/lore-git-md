This is the final patch in Patrick Steinhardt’s seven-part series introducing the **object storage extension** (`extensions.objectStorage`). It teaches `git submodule` to propagate the `--object-storage-format=` option through its `add` and `update` subcommands, mirroring the existing behavior for `--ref-storage-format=`.

The patch updates the `git-submodule` shell script and its C helper (`builtin/submodule--helper.c`) to accept the new option, validate it via `odb_source_type_by_uri()`, and pass it through to the underlying `git clone` invocations. Documentation is updated in `git-submodule.adoc` to document the new option, and a new test script (`t7427-submodule-object-storage-format.sh`) verifies that the format propagates correctly during submodule addition, recursive cloning, and explicit updates. The tests also confirm that invalid formats are rejected and that the relocated object directory (e.g., `.git/objs`) is created as expected.

This patch is a straightforward plumbing extension that completes the user-facing integration of the object storage mechanism. It follows the established pattern for ref storage, suggesting minimal controversy, but the test coverage (91 lines) indicates careful attention to edge cases. The series as a whole remains under review; this patch is unlikely to attract significant discussion on its own but rounds out the baseline functionality.
