Thread identity: Patch series introducing the **object storage extension** (`extensions.objectStorage`), a pluggable object database backend mechanism. Series version: initial (v1). Originating author: Patrick Steinhardt. Thread type: architectural RFC/patch series.

Core problem or goal: Enable alternative object storage backends (e.g., cloud storage, databases) by making Git’s object database pluggable. This series defines the configuration mechanism (`extensions.objectStorage`), modeled after the existing ref storage extension, and implements the baseline `files` backend. The `files` backend supports relocating the `.git/objects` directory via a payload (e.g., `files://objs` moves objects to `.git/objs`). The series also introduces environment variable support (`GIT_OBJECT_STORAGE_FORMAT` and `GIT_DEFAULT_OBJECT_STORAGE_FORMAT`) for overriding the configuration, user-facing configuration (`init.defaultObjectStorageFormat`), and inspection tools (`git rev-parse --show-object-storage-format` and `git repo objects.storageFormat`) to query the configured backend.
