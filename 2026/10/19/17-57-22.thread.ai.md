Thread type: bugfix

Core problem or goal
Git’s `status` and `checkout` commands currently emit a misleading message (“the upstream is gone”) when a local branch tracks a remote branch that was never created (e.g., after cloning an empty repository). The patch rewords the message to be neutral (“does not exist”) and tailors the advice: `git push` is suggested only when it would actually create the missing branch, otherwise `git branch --unset-upstream` is recommended.
