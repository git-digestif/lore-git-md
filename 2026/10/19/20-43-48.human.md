This is a documentation patch to `MyFirstContribution.adoc`, the guide for new Git contributors. Junio C Hamano restructures the tutorial to emphasize that contributors should *not* send a v2 patch until they have fully engaged with review feedback on v1. The current text presents the mechanics of sending v2 *before* explaining how to respond to reviews, which Junio suspects may encourage premature resends. He moves the "Sending v2" section after the "Responding to Reviews" section and strengthens the language from "It is good manners" to "Do not send v2 before you are done discussing." The patch is a straightforward reorganization with no code changes, motivated by a recent uptick in new contributors skipping review discussion. It looks well-crafted and directly addresses a real friction point for the community.
