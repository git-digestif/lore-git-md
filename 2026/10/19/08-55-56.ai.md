This is a refactoring patch that removes dead code, part of Patrick Steinhardt’s object storage extension series (1/7). The patch deletes `repo_write_loose_object_map()`, a function introduced in 2023 but never used—loose object maps are instead updated incrementally via `repo_add_loose_object_map()`. The dead function also had a hardcoded path for the loose-object index that conflicted with the rest of the codebase, which derives the path from the loose source’s location.

The change is straightforward: 46 lines of unused code are removed from `loose.c`, and the function’s declaration is dropped from `loose.h`. No behavior changes are introduced, and the patch is uncontroversial—it simply cleans up a historical artifact that could cause confusion or bugs if mistakenly used in the future. The commit message clearly explains the rationale and the inconsistency that motivated the removal. This patch is a safe, mechanical step in the larger series and unlikely to attract debate.
