This is a progress update on two microproject test modernizations. Srujith Poojary reports that he has submitted the third version of his patches for `t2030` and `t0001` to the mailing list via GitGitGadget. The patches replace legacy test constructs (`! test -f`, `test -f`) with modern helper functions (`test_path_is_file`, `test_path_is_missing`) and fix a pipe redirection issue in `t0001-init.sh`. Both series have been locally verified (104 tests pass) and include DCO sign-off.

The patches target the ongoing test modernization effort, which aims to replace brittle shell idioms with more robust test helpers. The changes are mechanical and confined to the `t/` directory, so they should not affect Git's behavior. Since these are microprojects, the scope is intentionally small, making them suitable for new contributors.
