This thread is about Patrick Steinhardt’s 13-patch series refactoring Git’s object database (ODB) to move alternates handling into the "files" backend. The goal is to resolve a long-standing architectural mismatch where alternates were managed at the ODB source level, complicating data structures like bitmaps and commit graphs and blocking future work such as pluggable backends. The series consolidates alternates into the files backend, making them a backend-specific implementation detail and enabling cleaner ODB extensions.

The series is now technically complete at v1, with all review feedback addressed. Karthik Nayak provided the primary review, which was mostly surface-level but did catch one critical issue: a potential NULL-dereference regression in `clear_midx_file()` (patch 12/13). Patrick resolved this by demonstrating the removed check was redundant. Karthik also raised a conceptual question about eliminating multiple sources per ODB, but this was clarified by Patrick’s explanation that alternates would instead be managed as a linked list of directories within the files backend. The only unresolved loose end is a minor inconsistency in the test helper `git_test_write_commit_graph_or_die()`, which Patrick dismissed as a test-suite hack.

The series touches 75 files, with the bulk of changes in `odb.c` (439 lines removed) and `odb/source-files.c` (482 lines added). Key technical details include the introduction of `struct odb_files_dir` to manage multiple object directories, the removal of the `read_alternates` callback from all ODB backends, and the absorption of quarantine logic into `tmp-objdir.c`. The on-disk format remains unchanged, but the internal refactoring is substantial. While the architectural direction is now clear, the series’ robustness in edge cases (e.g., promisor remotes, partial clones, or linked-list traversal order) remains untested. Karthik called for a second review, and the series may need a reroll to resolve minor merge conflicts with the `seen` branch. The next steps are likely additional review from ODB experts like Taylor Blau or Justin Tobler.
