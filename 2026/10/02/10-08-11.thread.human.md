This thread is a 13-patch refactoring series by Patrick Steinhardt that moves alternates handling into Git’s "files" object database (ODB) backend. The goal is to eliminate a long-standing architectural mismatch where alternates were managed at the ODB source level, causing performance regressions and blocking future work like pluggable backends. The series is under initial review (v1) and touches core ODB code, the commit-graph subsystem, and quarantine logic, with no on-disk format changes.

Key changes include consolidating alternates into the files backend, replacing the `read_alternates` callback with backend-specific logic, and introducing a linked list of object directories (`struct odb_files_dir`) to manage multiple directories. The final patch (13/13) removes the now-unused callback, completing the refactor. Karthik Nayak reviewed three patches, raising concerns about commit message clarity (resolved) and a potential edge-case issue in the test helper `git_test_write_commit_graph_or_die()`. Patrick dismissed the latter, arguing the helper’s current implementation is sufficient, leaving the inconsistency unresolved. No substantive objections have been raised, but the series’ size and merge conflicts with `seen` may require a reroll. The thread remains in review with no decisions on integration status.
