This thread is a 13-patch refactoring series by Patrick Steinhardt that moves alternates handling into Git’s "files" object database (ODB) backend. The goal is to eliminate a long-standing architectural mismatch where alternates were managed at the ODB source level, causing performance regressions and blocking future work like pluggable backends. The series touches core ODB code, the commit-graph subsystem, and quarantine logic, with no on-disk format changes.

The patches are under initial review, with Karthik Nayak providing feedback on three early patches. While Patrick addressed one concern about commit message clarity, he dismissed another about a test helper function (`git_test_write_commit_graph_or_die()`) that assumes the primary ODB source’s path. This could cause issues for tests involving alternates or quarantine directories, but Patrick considers it a minor edge case. The third review comment, on a mechanical type conversion, was acknowledged but not deeply engaged with.

The series is large (75 files touched) and has minor merge conflicts with `seen`, so a reroll may be needed. Key technical changes include introducing a `struct odb_files_dir` to manage multiple object directories, dropping the `read_alternates` callback, and refactoring commit-graph helpers to use explicit repository and path arguments. No substantive objections have been raised yet, but the test helper issue remains an open loose end.
