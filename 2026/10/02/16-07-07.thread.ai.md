Core problem or goal
Remove redundant empty SYNOPSIS blocks from Git’s section 7 man pages (conceptual guides and tutorials) and update the `lint-man-section-order.perl` script to exempt section 7 documents from requiring a SYNOPSIS, as these pages are descriptive rather than command-oriented. The implementation must correctly handle multiple input files without misclassifying or skipping sections in files after the first.

Current status
Under review; the multi-file processing regression has been resolved by Tuomas Ahola’s declarative implementation. The patch is self-contained, touches only documentation files (`lint-man-section-order.perl` and the 11 `.adoc` files from Julia’s original patch), and is ready for integration. The regression’s resolution removes the sole blocker before merging.

- No new symbols, CLI options, or on-disk format changes.

The man section number is now detected in the main loop and reset at each file boundary using `$.`, eliminating the need for explicit `eof` checks.
- Julia’s original `Tie::File` suggestion and Junio’s `eof`-based approach are no longer under active discussion, as Tuomas’s implementation resolves the regression without introducing new dependencies or complexity.
