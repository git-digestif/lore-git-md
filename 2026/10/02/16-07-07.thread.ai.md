Core problem or goal
Remove redundant empty SYNOPSIS blocks from Git’s section 7 man pages (conceptual guides and tutorials) and update the `lint-man-section-order.perl` script to exempt section 7 documents from requiring a SYNOPSIS, as these pages are descriptive rather than command-oriented. The implementation must correctly handle multiple input files without misclassifying or skipping sections in files after the first.

Current status

It touches only documentation files (`lint-man-section-order.perl` and 11 `.adoc` files in `Documentation/`), introduces no new symbols or on-disk format changes, and passed all linter checks (`make lint-docs`). The final implementation uses Tuomas Ahola’s declarative configuration (`optional_in_man_sections => { SYNOPSIS => [7] }`) and resets section tracking at file boundaries via Perl’s `$.` line counter.
