This is the third patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) to move alternates handling into the "files" backend. The patch introduces `struct odb_files_dir`, a new data structure that groups the loose and packed backends derived from the same object directory (primary or alternate) into a single entity.

The change is mechanical but far-reaching: every access to `files->loose` or `files->packed` is replaced with `files->dirs->loose` or `files->dirs->packed`, reflecting the new encapsulation. The patch touches 19 files, including core commands (`git fast-import`, `git index-pack`, `git multi-pack-index`, `git pack-objects`, `git repack`), the commit-graph subsystem, HTTP transport, and the multi-pack-index machinery. The diff is large (131 insertions, 85 deletions) but straightforward, with no behavior changes—this is pure refactoring to prepare for the next patch, which will turn `dirs` into a linked list of directories.

The motivation is clear: the current design treats loose and packed backends as separate entities even when they share an object directory, which complicates alternates handling and prevents backend-agnostic extensions. This patch lays the groundwork for consolidating alternates into the files backend, simplifying the architecture and enabling future ODB work.
