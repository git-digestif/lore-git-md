This is the first patch in a two-patch performance series targeting the commit-graph subsystem. It adds a new `commit-info` subcommand to `test-tool read-graph` to enable test scripts to verify whether specific commits are present in the commit-graph and to inspect their generation numbers.

The change is minimal and focused: it modifies only `t/helper/test-read-graph.c`, adding 22 lines to implement the new subcommand. The subcommand takes one or more commit object names as arguments, checks if each commit exists in the commit-graph, and prints its generation number if found. If any commit is not found, it returns exit code 1. This functionality is essential for the test coverage in the second patch, which verifies the incremental commit-graph write strategy introduced there.

The implementation is straightforward and uses existing Git APIs (`repo_get_oid`, `lookup_commit_in_graph`, `commit_graph_generation`). The patch does not alter any existing behavior; it only extends the test helper with a new capability. This is a clear example of test infrastructure work that directly supports a larger optimization effort. The patch is well-scoped and appears ready for review.
