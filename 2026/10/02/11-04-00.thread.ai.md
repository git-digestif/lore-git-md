Core problem or goal
A Windows user reports a memory usage regression in Git 2.56.0.windows.1, where `git status`-like commands (spawned by coding agents OpenCode and Oh My Pi) consume ~1 GB of RAM per process, totaling several GB across dozens of concurrent processes. The user seeks confirmation whether this memory footprint is expected and if configuration tweaks could mitigate it.
