*Git Rev News* is a community-driven newsletter that summarizes recent mailing list discussions, new features, bug fixes, and other developments in the Git project. This announcement is purely informational—no code changes or patches are involved. If you follow Git development casually, this is a convenient way to catch up on the past month’s highlights without reading every thread.
