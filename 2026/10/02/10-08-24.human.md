This is the final patch in Patrick Steinhardt’s 13-part series refactoring Git’s object database (ODB) to move alternates handling into the files backend. The patch itself is small and mechanical: it removes the now-unused `read_alternates` callback from all ODB source backends (`files`, `inmemory`, `loose`, `packed`) and drops the corresponding function pointer from the `struct odb_source` interface.

The change is the logical conclusion of the series’ architectural shift. Alternates are now an implementation detail of the files backend, so the generic ODB interface no longer needs to expose them. The patch touches five files, removing 55 lines of code, and leaves no loose ends—every backend’s callback was a no-op except for the files backend, which has already been refactored to handle alternates internally.

This is a clean-up patch that completes the series. It doesn’t introduce new behavior or edge cases, but it does lock in the architectural decision to make alternates backend-specific. If you’ve been following the series, this patch is the expected finale; if you’re just tuning in, it’s a good signal that the refactoring is now fully implemented. The series as a whole is well-motivated and thorough, and this patch is a tidy capstone.
