This is a documentation patch that removes empty SYNOPSIS sections from Git's section 7 man pages (conceptual guides and tutorials). The patch updates the `lint-man-section-order.perl` script to exempt section 7 documents from requiring a SYNOPSIS, then removes the now-redundant SYNOPSIS blocks from 11 `.adoc` files in `Documentation/`.

The change is motivated by the observation that section 7 man pages (e.g., `gitcli(7)`, `gitglossary(7)`) typically don’t need a SYNOPSIS, as they are descriptive rather than command-oriented. The author tested the change by running `make lint-docs` and manually inspecting the affected files with a small fish script. The Perl modification is minimal and targeted: it extracts the man section number from the first line of the input file and skips the SYNOPSIS check for section 7.

The patch is self-contained, touches only documentation files, and includes a clear commit message explaining the rationale. The author notes this is a small improvement and is open to dropping it if it proves controversial, but the change itself looks well-justified and uncontroversial. No prior discussion or cover letter is referenced, so this appears to be a standalone patch rather than part of a larger series.
