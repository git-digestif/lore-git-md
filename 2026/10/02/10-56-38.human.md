This is the first patch in Kristoffer Haugsbakk’s v3 series introducing `--[no-]range-diff-notes` to `git format-patch`. It is a small, targeted refactoring that simplifies the `get_notes_args` function by removing a redundant parameter.

The patch builds on a prior commit (85bd88a7, 2025-09-25) that added `rdiff_log_arg` to `struct rev_info`. Previously, `get_notes_args` took two parameters: a `struct strvec *` and a `struct rev_info *`. The first parameter was redundant because the function could access `rev->rdiff_log_arg` directly. This patch removes the redundant parameter, making the function cleaner and more consistent. The change is mechanical and does not alter behavior.

The patch touches only `builtin/log.c` and is compile-tested. The commit message is clear and explains the motivation well. This is a sensible cleanup that prepares the codebase for the feature addition in the second patch. There is no controversy here; it is a straightforward improvement.
