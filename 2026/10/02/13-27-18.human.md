This is the main feature patch in Souma’s v4 series teaching `git history` to sign rewritten commits. It adds `--gpg-sign[=<key-id>]` and `--no-gpg-sign` options to every `git history` subcommand (`drop`, `fixup`, `reword`, `split`, and `squash`), makes them respect the `commit.gpgsign` configuration variable, and threads the signing choice through the replay machinery so that descendant commits are re-signed with the same key. Command-line options override config, and the last option wins.

The patch touches the core commit-creation plumbing in `replay.c` (via a new `sign_commit` field in `replay_revisions_options`), updates the synopsis and description in `Documentation/git-history.adoc`, and adds GPG-gated regression tests in `t/t3451`–`t/t3455` that cover every subcommand, every config/flag combination, explicit key selection, and the no-new-commit case for `drop`. All feedback from Patrick Steinhardt and Junio C Hamano has been addressed; the series is now ready for queuing in `next`.
