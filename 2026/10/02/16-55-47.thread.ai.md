Thread identity: `[PATCH] branch --delete-merged: default to all upstreams when no pattern given` (feature patch), originating author Harald Nordgren.

Core problem or goal: Simplify the `git branch --delete-merged` workflow by making the branch pattern optional. The patch changes the command to default to considering every upstream branch (via an implicit `**` pattern) when no pattern is provided, replacing the previous requirement to specify a pattern like `*/*`. The stated goal is to make the command more ergonomic for cleaning up branches whose work has landed upstream, though Junio C Hamano’s review questions whether the implementation aligns with this intent.
