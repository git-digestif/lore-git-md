This is a refactoring patch in Patrick Steinhardt’s parse-options subcommand grouping series (v2 2/4). It extracts the logic for printing a single option or flag into two new helper functions—`usage_print_flag()` and `usage_print_option()`—to reduce nesting and improve readability in `usage_with_options_internal()`. The change is purely internal to `parse-options.c` and prepares the ground for the subsequent API extension that introduces subcommand grouping.

The patch is well-structured: it moves the existing logic verbatim into the new functions, preserving all behavior while making the code easier to extend. The extracted functions are cleanly named and handle the distinct responsibilities of printing flags (short/long names, argument hints) and full options (help text, aliases, opposite forms). No new symbols are exposed outside the file, and the diff is mechanical, which reduces review risk.
