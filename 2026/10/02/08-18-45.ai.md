This is the third patch in Scott Chacon’s four-patch RFC series proposing a new signing mechanism that embeds SHA-256 digests of tree contents in signed commits and tags. This patch teaches `git commit -S` the `--hash=sha256` option, mirroring the functionality already added to `git tag` in patch 2.

The implementation adds the `tree-sha256` header to the commit object immediately after the `committer` line and before the `gpgsig` block, ensuring the signature covers the digest. When amending, the patch deliberately drops any existing `tree-sha256` header and recomputes it only if the amended commit is signed with `--hash=sha256`. The code is straightforward: it parses the `--hash` argument, validates that signing is enabled, computes the digest using the helper introduced in patch 1, and appends the header to the commit’s extra headers list. Error handling is minimal but sufficient: unknown algorithms and missing signing are both rejected with clear error messages.

The documentation update is concise, explaining that the option adds a SHA-256 digest of every file in the tree (including submodules) so the signature covers content directly rather than only SHA-1 object names. The test script (`t/t7032-tree-sha256-signed.sh`) exercises the new option, verifying that the header is present when expected, absent when not, and correctly recomputed or dropped during amend operations. The tests also confirm that `--hash=sha256` without signing is rejected, and that unknown algorithms (`--hash=md5`) are caught.

This patch is a clean, self-contained addition to the series. It reuses the infrastructure introduced in patch 1 and follows the same design principles as patch 2, preserving backwards compatibility and requiring no changes to the object format itself. The only open question specific to this patch is whether the naming (`--hash=sha256`) and behavior (dropping the header on amend) are the right choices; the rest of the discussion will likely focus on the broader design questions already raised in the cover letter.
