This thread began when Alejandro Colomar asked whether Git provides a plumbing command to retrieve the commit identified by `git bisect` as the culprit, without parsing porcelain output. The question is now fully resolved: both Jeff King and Junio C Hamano confirmed that the culprit commit is reliably recorded in the `refs/bisect/bad` ref, which can be accessed via standard plumbing commands like `git rev-parse bisect/bad`, `git rev-list -1 bisect/bad`, or `git show bisect/bad`. Junio also clarified that this ref is updated in all cases, including when `git bisect` determines the current `HEAD` is already the culprit and does not move it—an optimization that initially surprised Alejandro but proved acceptable since the ref always holds the correct result. Alejandro tested `git show bisect/bad` and found it works as expected, closing the loop on his inquiry. No further discussion or action is needed.
