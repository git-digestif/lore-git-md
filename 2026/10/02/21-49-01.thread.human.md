This thread began when Alejandro Colomar asked whether Git provides a plumbing command to retrieve the commit identified by `git bisect` as the culprit, without parsing porcelain output. The question is now fully resolved: Jeff King and Junio C Hamano confirmed that the culprit commit is reliably recorded in the `refs/bisect/bad` ref, which can be accessed via standard plumbing commands like `git rev-parse bisect/bad`, `git rev-list -1 bisect/bad`, or `git show bisect/bad`. Alejandro tested these approaches and adopted `git rev-parse bisect/bad` in his scripts, noting that it works as expected even when `HEAD` does not move during the bisect. The thread is now closed with no remaining open questions.
