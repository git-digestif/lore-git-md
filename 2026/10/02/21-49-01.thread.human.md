This thread began when Alejandro Colomar asked whether Git provides a plumbing command to retrieve the commit identified by `git bisect` as the culprit, without parsing porcelain output. The question is now fully resolved: the culprit commit is stored in the `refs/bisect/bad` ref, which can be accessed reliably via plumbing commands like `git rev-parse bisect/bad`, `git rev-list -1 bisect/bad`, or `git show bisect/bad`. Jeff King and Junio C Hamano confirmed that this mechanism is stable, intended for script use, and works in all cases—including when `HEAD` does not move because it is already at the culprit. Alejandro tested `git show bisect/bad` and reported it works as expected, and Jeff later clarified that `git rev-parse bisect/bad` is the simplest plumbing option. No further action or patch is needed.
