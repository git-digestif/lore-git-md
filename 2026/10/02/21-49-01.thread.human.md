This thread began when Alejandro Colomar asked whether Git provides a plumbing command to retrieve the commit identified by `git bisect` as the culprit, without parsing porcelain output. The question is now fully resolved: the culprit commit is stored in the `refs/bisect/bad` ref, which can be accessed reliably using standard plumbing commands like `git rev-parse bisect/bad`, `git show bisect/bad`, or `git rev-list -1 bisect/bad`. Both Jeff King and Junio C Hamano confirmed that this mechanism is stable and intended for script use, with Junio providing a detailed explanation of how the ref is updated in all cases, including when `HEAD` does not move. Alejandro tested the solution and confirmed it works as expected. No further discussion or changes to Git are needed.
