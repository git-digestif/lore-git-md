This is the third patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to move alternates handling into the "files" backend. The patch introduces `struct odb_files_dir`, a new data structure that encapsulates both the loose and packed object sources derived from a single object directory (primary or alternate).

The change is mechanical but foundational: every `struct odb_source_files` now contains a single `struct odb_files_dir` (accessed via `files->dirs`) instead of separate `loose` and `packed` fields. The patch updates 19 files to reflect this shift, replacing direct references to `files->loose` and `files->packed` with `files->dirs->loose` and `files->dirs->packed`. The new structure also stores the absolute path to the object directory and a `local` flag indicating whether it is the primary repository directory.

This is a refactoring step with no behavior change; the commit message explicitly states that the linked-list capability for multiple directories will be added in a subsequent patch. The patch is well-scoped and the diff is clean, making it easier to review than later patches that will build on this foundation. If you are tracking the ODB refactoring effort, this patch is a key building block.
