This is a documentation patch. Todd Zullinger updates the `core.pager` section of the Git configuration manual to show more ways users can override the `LESS` environment variable that Git sets by default. The patch adds examples of prefixing `core.pager` with `LESS="RX"` or `LESS=""` to remove or clear options, which is useful when the pager command respects `LESS` but lacks command-line flags to control it. The change is motivated by a report that the unconditional setting of `LESS` can surprise users of other pagers.

The patch is small, focused, and well-explained. It touches only the documentation file and includes concrete examples that directly address the reported issue. The commit message is clear and the patch is ready for review. No controversy is expected.
