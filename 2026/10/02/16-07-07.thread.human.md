This thread is a minor follow-up to a now-merged documentation patch that removed empty SYNOPSIS blocks from Git’s section 7 man pages. The original patch, authored by Julia Evans with Tuomas Ahola as coauthor, was uncontested and merged to `master`. It updated the `lint-man-section-order.perl` script to exempt section 7 documents from requiring a SYNOPSIS and removed redundant empty blocks from 11 `.adoc` files.

The current discussion is a post-merge exchange between Junio and Julia about a small robustness detail in the Perl script. Junio initially suggested silently defaulting the man section number to `"0"` if the first line of a file doesn’t match the expected pattern, while Julia proposed instead reporting an explicit error in such cases. Junio now agrees that explicit error reporting is preferable, provided the script avoids using an undefined value for the section number when issuing the warning. The exchange is constructive and low-stakes—neither approach affects the patch’s correctness or merge status, and the discussion remains open-ended about which style the project prefers for the linter. No further action is needed on the merged patch itself.
