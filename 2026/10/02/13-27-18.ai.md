This is the main feature patch in Souma’s v4 series teaching `git history` to sign rewritten commits. It adds `--gpg-sign`/`--no-gpg-sign` command-line options and `commit.gpgsign` configuration support to the `drop`, `fixup`, `reword`, `split`, and `squash` subcommands, threads the signing key through the replay machinery, and updates the documentation and test suite.

The patch touches `builtin/history.c`, `Documentation/git-history.adoc`, and five test scripts (`t3451`–`t3455`). It introduces a new `sign_commit` field in the `replay_revisions_options` struct, a custom `history_config` callback to read `commit.gpgsign`, and the `OPT_HISTORY_GPG_SIGN` macro to parse the command-line options. Configuration is loaded before parsing options so that command-line flags override the config setting, and the last option wins. All five subcommands now respect the same signing semantics as `git commit`, `git rebase`, and `git cherry-pick`.

Test coverage is comprehensive: each subcommand has GPG-gated tests that verify config-driven signing, command-line overrides, explicit key selection, and the no-new-commit case for `drop`. The documentation patch adds a short section on signing options and cross-references the `git-commit` man page.
