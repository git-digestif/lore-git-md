This is the seventh patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) to move alternates handling into the files backend. The patch absorbs the temporary-primary-source logic into the `tmp-objdir` subsystem, eliminating two ODB-level functions (`odb_set_temporary_primary_source` and `odb_restore_primary_source`) that are now used only by `tmp-objdir`.

The change is a straightforward code relocation: the logic is lifted from `odb.c` and `odb.h` and reimplemented inside `tmp-objdir.c` as static helpers (`tmp_objdir_replace_primary_odb` and `tmp_objdir_restore_source`). The patch removes 45 lines from `odb.c` and 17 from `odb.h`, while adding 34 lines to `tmp-objdir.c`. No behavior changes are introduced; the only difference is that the ODB no longer exposes this functionality to other callers.

This is a clean, well-motivated refactoring step that aligns with the series’ goal of making alternates an implementation detail of the files backend. The commit message clearly explains why the move is safe (only one remaining user) and why it is desirable (alternates are becoming backend-specific). If you are following the ODB refactoring effort, this patch is a minor but necessary piece of the puzzle.
