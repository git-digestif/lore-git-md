This is a small feature patch for the `git-contacts` contrib script, now in its sixth iteration. The patch teaches `git-contacts` to read patch content from stdin when the user passes a single dash (`-`) as an argument, enabling mixed file/stdin usage (e.g., `git contacts patch1 - patch3 <patch2`). This version (v6) squashes the previously separate documentation and code changes into a single commit, updates the script’s internal usage comment to include `'-'` as a valid input option, and expands the documentation to clarify that the feature supports multiple patches from stdin (via mbox `From ` headers).

The implementation is straightforward: the script now sets a `$read_from_stdin` flag when it encounters `-` in `@ARGV` and calls the existing `scan_patches()` helper with the stdin filehandle if the flag is set. The documentation in `git-contacts.adoc` has been updated to reflect the new behavior, including an example showing stdin usage. The patch touches only `contrib/contacts/git-contacts` and its man page, with no changes to core Git functionality or on-disk formats.

This iteration addresses Junio’s feedback from v5, which noted that the feature and its documentation should have been submitted together and that the script’s internal usage comment should be updated to match the new behavior. The v6 update is uncontroversial and ready to apply, completing the follow-up work to the already-merged v4 feature patch. The change improves interoperability with external tools like `b4` while maintaining backward compatibility.
