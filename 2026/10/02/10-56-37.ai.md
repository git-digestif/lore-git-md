This is the v3 revision of Kristoffer Haugsbakk’s two-patch series adding `--[no-]range-diff-notes` options to `git format-patch`. The series is now technically complete and ready for maintainer decision after addressing Junio C Hamano’s feedback on v2.

The goal remains unchanged: allow users to control notes inclusion in the range-diff section independently of the patch output. The v3 iteration removes a redundant `test_when_finished` call in the test script (the only change from v2) and drops the CI link from the commit message, noting that only `t3206-range-diff` was re-tested. The implementation touches `builtin/log.c`, `Documentation/git-format-patch.adoc`, and `t/t3206-range-diff.sh`, introducing a new `struct rdiff_notes` to track range-diff notes preferences and simplifying parameter handling in `get_notes_arg`.

The CLI semantics are now stable: `--range-diff-notes=<ref>` requires an explicit ref argument, and `--no-range-diff-notes` suppresses notes in the range-diff without fallback. The interaction rule between patch notes and range-diff notes is preserved: if no range-diff notes options are given, the range-diff uses the same notes as the patches; otherwise, it uses only the explicitly specified notes. Tests cover all key scenarios, including suppressing all range-diff notes, using different notes refs for patches and range-diffs, and ensuring `--range-diff-notes` requires a value.

The series is uncontroversial and well-motivated, with clear separation between refactoring (patch 1/2) and new functionality (patch 2/2). The v3 changes are minimal and address the only technical feedback from Junio. The feature’s revival now depends solely on maintainer approval. Key names introduced: `--range-diff-notes`, `--no-range-diff-notes`, `struct rdiff_notes`, `rdiff_log_arg` (renamed in prior commit 85bd88a7). Files touched: `builtin/log.c`, `Documentation/git-format-patch.adoc`, `t/t3206-range-diff.sh`.
