This thread fixes a subtle packfile corruption bug caused by stale delta base cache entries referencing freed `packed_git` structs. The issue, which became visible after a 2024 commit stopped leaking packfiles, leads to logical corruption when Git reuses memory addresses for new packs, causing incorrect object reconstruction. Patrick Steinhardt’s two-patch series—one mechanical refactoring, one core fix—evicts stale cache entries when packs are closed, preventing the corruption.
