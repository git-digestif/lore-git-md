This is the first patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) to move alternates handling into the files backend. It targets the `git commit-graph` command’s `--stdin-packs` option, which currently expects relative packfile paths and resolves them internally. The patch shifts the responsibility of resolving packfile paths to the caller, requiring fully resolved paths to be passed in instead.

The change is mechanical but important for the series’ broader goal: untangling the ODB core from backend-specific logic. By removing the path resolution step from `fill_oids_from_packs()`, the patch eliminates a dependency on the ODB source’s filesystem path, making the code more backend-agnostic. The caller (`builtin/commit-graph.c`) now constructs the full packfile path before passing it to the commit-graph logic, which aligns with the series’ direction of consolidating alternates into the files backend.

The patch touches two files: `builtin/commit-graph.c` (where the caller now resolves paths) and `commit-graph.c` (where the resolution logic is removed). The diff is straightforward, replacing relative path handling with direct use of resolved paths. No behavior changes are introduced—this is purely a refactoring step.
