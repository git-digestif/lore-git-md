This is a three-patch series that completes the cleanup Patrick Steinhardt suggested in response to the original memory-leak fix. The series migrates the mergesort tests from the shell-based test suite to the Clar unit-test framework (`t/unit-tests/u-mergesort.c`), retires the now-unused `generate` and `test` subcommands from the test helper, and finally removes the obsolete `p0071-sort.sh` performance benchmark and the entire `test-mergesort.c` helper.

Patch 1 is the unchanged leak fix from v1: it plugs the two leaks in `sort_stdin()` and adds a shell test for the `sort` subcommand. Patch 2 moves all 1,680 test cases from the old certification test into Clar, adds new small-list and empty-list checks, and removes the unused subcommands while keeping the `sort` command available for the benchmark. Patch 3 deletes the benchmark, the helper, and their build-system registrations. The net result is a 106-line reduction in code size, all test coverage preserved, and the leak fix still applicable as a standalone patch if desired.
