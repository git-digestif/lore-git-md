This is the third and final patch in Muhammed Dilshad A’s three-patch series that migrates the mergesort tests to Clar and retires dead code. It deletes the obsolete `p0071-sort.sh` performance benchmark and the `test-mergesort.c` helper, along with their build-system registrations in `Makefile`, `meson.build`, and `t/meson.build`. The patch removes 124 lines of code, completing the 106-line net reduction promised by the series.

The commit message explains that `p0071-sort.sh` was the last user of the `test-tool mergesort sort` subcommand, so its removal allows the entire helper to be deleted. The rationale is straightforward: the benchmark was only relevant during the original mergesort implementation and is no longer needed; if performance measurements are required in the future, a new benchmark can be written. The patch is mechanical and uncontroversial, touching only test infrastructure files (`t/helper/`, `t/perf/`, and build files) with no user-facing behavior changes. All test coverage has already been preserved in the Clar unit tests introduced in Patch 2.
