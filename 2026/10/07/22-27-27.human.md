This is Junio’s "What’s cooking" report for early October 2026, summarizing the state of Git’s integration branches as the 2.98 cycle begins.

The report lists 38 topics currently cooking in Junio’s tree, split between new topics (not yet in `next`), cooking topics (in `next` or `seen`), and a handful of discarded efforts. Below are the highlights that a busy reader would want to know.

### What graduated to `master` this cycle

Five small, uncontroversial fixes graduated cleanly: a timestamp-initialization bug in `git push --force-if-includes` (as/push-force-if-includes-no-reflog), a curl credential-stripping regression (jk/http-curl-strip-creds), tempfile API adoption in the external merge driver (jk/merge-ll-tempfile-cleanup), a Windows GitLab CI Rust toolchain fix (js/gitlab-ci-windows-rust), and a test script quoting fix (js/p5551-fetch-rescan-fix). One documentation typo (kz/doc-add-rm-typofix) also made it.

### New topics that look ready to advance

- **jk/t5551-test-shell-quote-fix** and **jk/test-lazy-prereq-heredoc** are a two-patch series that fixes a shell-quoting bug in a test prereq and then generalizes the test library to allow here-docs for lazy prereqs. Both have positive feedback and are marked “Will merge to `next`?”.
- **ma/t0450-use-test-path-is-file** and **dk/fix-shattered-io-link** are small test and documentation cleanups that also look ready.
- **hn/status-push-rebased-on-newer-upstream** is a six-patch series that improves `git status` and `git push` advice when a pushed branch was cleanly rebased onto a newer upstream. The series is well-motivated and has received positive initial feedback; it is now waiting for broader review.
- **kk/fetch-write-commit-graph-incremental** optimizes `fetch.writeCommitGraph` to update the commit-graph incrementally using only newly fetched commits, avoiding a full reachability scan. The two-patch series is new and needs review.
- **kn/packed-refs-verbatim-write** is a micro-optimization that uses `fwrite()` instead of `fprintf()` when rewriting packed-refs records verbatim. It is small, self-contained, and looks ready.
- **tb/repack-cruft-less-midx-corner-cases** is an eight-patch series that fixes reachability-closure bugs in the cruft-less MIDX feature. It is still waiting for review but is part of Taylor Blau’s ongoing repack work.
- **dk/stash-apply-index-incore** is a four-patch series that replaces the external `git diff-tree`/`git apply` subprocesses in `git stash apply --index` with an in-core merge using the merge-ort machinery. It fixes a concurrent lock-file issue and has positive feedback; it is marked “Will merge to `next`?”.

### Notable cooking topics

- **ps/odb-files-alternates** (13 patches) refactors the odb_source API to move alternates handling into the files backend. It is a large, mechanical series that touches many subsystems; Junio is expecting a reroll.
- **ss/history-sign-rewrites** (2 patches) teaches `git history` and `git replay` to sign rewritten commits. It is small, well-explained, and looks ready.
- **pw/checkout-m-conflict-labels** (2 patches) remembers original conflict labels (branch names) in `.git/MERGE_LABELS` so that `git checkout -m` can restore them. It is still being discussed and needs a reroll.
- **hn/fetch-refmap** (4 patches) changes the default refspec for remotes added in shallow repositories to rely on `remote.<name>.refmap` instead of `remote.<name>.fetch`, pulling only the remote branches tracked by local branches. It is a behavior change that is still under discussion.
- **ps/setup-enforce-repo-passed-to-create-repository-has-no-state** (7 patches) refactors repository initialization to treat the repository object passed to `create_repository()` as a pure out-parameter. It is part of Patrick Steinhardt’s ongoing ODB abstraction work and is still waiting for response.
- **tb/rerere-wait-for-merge-rr-lock** (3 patches) makes `rerere` wait for the `MERGE_RR.lock` instead of failing immediately when the lock is busy. It is still under review.

### Small but useful improvements

- **hn/object-name-push-short** teaches `@{p}` as a short-hand for `@{push}`.
- **je/doc-promote-git-help** rewrites the early part of `man git` to explain how to use `git help` effectively.
- **ap/var-broken-down-idents** extends `git var` to output individual components of author/committer identities and to accept multiple keys.
- **kh/doc-trailers-cmd-examples** fixes grammatical errors in `git interpret-trailers` documentation.
- **ps/reftable-reflog-timezone** fixes the on-disk representation of reflog timezones in the reftable backend.

### Topics that may need attention

- **mc/refs-rename-transaction** (4 patches) refactors reference rename and copy to use the transaction API. Junio flagged it as “Broken???” and is waiting for a response.
- **am/p4-apply-commit-shell-injection-fix** plugs a potential shell injection in `git-p4.py`; it is still unreviewed.
- **gg/http-ssl-verify-status** adds OCSP stapling support to the HTTP transport. It has been stalled for weeks due to CI timeouts and needs a response from the author.

In short: the tree is open for 2.98, and the report gives a clear snapshot of what is cooking, what is ready, and what still needs review.
