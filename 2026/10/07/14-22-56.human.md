This is the first patch in a two-patch performance optimization series targeting the commit-graph subsystem. It adds a small but essential test helper to verify whether specific commits are present in the commit-graph and to print their generation numbers.

The patch introduces a new `commit-info` subcommand to `test-tool read-graph`. This tool allows tests to query the commit-graph for specific commits by object ID, returning their generation numbers if found or an error if any commit is missing. The implementation is straightforward: it parses command-line arguments as object IDs, looks them up in the commit-graph using `lookup_commit_in_graph()`, and prints their generation numbers or an error message. The tool exits with status 1 if any queried commit is not found, making it easy to use in test scripts.

This helper is uncontested and ready for merging. It doesn’t change any production behavior but enables precise verification of commit-graph contents in the tests for the second patch, which implements the actual fetch optimization. The changes are minimal (22 lines added to `t/helper/test-read-graph.c`) and focused solely on test infrastructure. No technical concerns or edge cases were raised about this patch in prior iterations, and it serves a clear purpose in supporting the series’ test coverage.
