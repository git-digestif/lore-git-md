Subject: [PATCH v4] doc: rewrite explanation of detached HEAD state
Series version: standalone patch, v4 (final, merged to `master`)
Originating author: Julia Evans
Thread type: documentation improvement

Core problem or goal
Improve the clarity and usefulness of Git’s documentation for detached HEAD state by addressing four specific shortcomings: (1) the current text does not explain *why* detached HEAD is useful, (2) it takes too long to define the concept, (3) it does not clarify how users might end up in this state accidentally, and (4) it includes overly complex diagrams. The patch replaces the existing section in `git-checkout.adoc` with a concise, practical explanation and moves it to a new standalone guide (`gitdetached-head(7)`) that can be referenced from Git’s advice messages. The thread also surfaced a broader usability concern about Git’s help system: the inconsistency between internal man page cross-references (e.g., `git-config(1)`) and the recommended `git help` command, which may confuse users who are unaware of the mapping.

Key technical details
- Files touched: `Documentation/git-checkout.adoc`, `Documentation/detached-head.adoc` (new), `Documentation/gitdetached-head.txt` (new man page), `advice.c` (update advice message to reference `git help detached-head`), `Documentation/Makefile`, `meson.build`, `command-list.txt` (whitespace alignment fix).
- New symbols: `gitdetached-head(7)` man page (hyphenated per existing guide conventions).
- Behavior change: advice messages about detached HEAD now point to the new standalone guide using `git help detached-head` (hyphenated). The new text frames detached HEAD as advantageous for experimentation (e.g., testing commits, browsing history, or working directly on remote-tracking branches) and removes the word “unintentionally” from accidental-detachment scenarios. It highlights the 2019 UI improvement in `git switch` that makes accidental detachment harder. The reflog expiry period is specified as 30 days (default for `gc.reflogExpireUnreachable`). Junio’s preferred phrasing for the opening paragraphs (“the commit for that tag” → “the tagged commit”; explicit `git checkout COMMIT_ID` and `git switch --detach COMMIT_ID` commands in the detachment methods list) is recorded for future reference but not incorporated into the merged patch.
- On-disk format: no changes.
- Test coverage: none added; this is documentation-only.
- Help-system usability: internal man page cross-references (e.g., `git-config(1)`) do not align with the recommended `git help` command, which may confuse users. The `git-help` man page does not explain how to map these references to `git help` commands. Julia Evans added a cross-reference to `git help datamodel` for deeper context in this version.
