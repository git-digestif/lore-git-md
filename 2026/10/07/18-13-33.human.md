This is a licensing and provenance clarification for the `sha1dc-accel` performance series. Scott Chacon responds to Junio C Hamano’s policy blocker about AI-generated code by confirming that the original Rust implementation (Sam Reis’s `sha1dc` crate) is dual-licensed under Apache 2.0 or MIT, both compatible with Git’s GPLv2. He also notes that he has discussed the port with Sam Reis and is confident the code complies with the Developer Certificate of Origin (DCO). Scott acknowledges that Sam Reis used AI tooling to create the Rust library but did so within Software Freedom Conservancy (SFC) guidelines, and that his own AI-generated C code was derived from Reis’s Rust implementation and accompanying blog post. He has CC’d both Sam Reis and Sebastian Thiel (gitoxide maintainer) for additional input, though he expects no objections. The response does not provide new technical details or performance data but aims to resolve the licensing concern so the series can proceed to technical review.
