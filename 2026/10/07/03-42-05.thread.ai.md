Core problem or goal
Fix memory leaks in `sort_stdin()` (Patch 1) and complete the broader cleanup Patrick Steinhardt suggested: migrate the mergesort tests from the shell-based test suite to the Clar unit-test framework, remove the unused `generate` and `test` subcommands, and retire the obsolete `p0071-sort.sh` performance benchmark and the `test-mergesort.c` helper. The goal is to reduce code size, eliminate dead code, and maintain test coverage while transitioning to the modern unit-test framework.

Current status
Under review; v2 is the current version. Patch 1 fixes the leaks in `sort_stdin()` by adding `mem_pool_discard()` and `strbuf_release()` calls, and adds a new test in `t/t0071-sort.sh` to verify the fix. Patch 2 migrates all 1,680 test cases to Clar, adds new edge-case tests (empty list, small list), and removes the unused subcommands; the new Clar test file includes explicit bounds checking and a cleanup fixture to prevent memory leaks on assertion failures. Patch 3 deletes the benchmark, the helper, and their build-system entries. The series is self-contained and ready for review; no prior versions of the cleanup patches exist. The series directly implements Patrick Steinhardt’s feedback and achieves the 106-line net code reduction promised.
