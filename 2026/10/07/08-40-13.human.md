This is a feature request for a new `git clone --non-intrusive` option.

Luca Di Carlo proposes a `--non-intrusive` flag for `git clone` that would disable all repository-local Git configuration (hooks, config, etc.) to protect users from malicious repositories that execute arbitrary commands via Git hooks. The idea is to prevent hooks from running during the clone, and possibly to signal this restriction to the user via a `.nogitconfig` file or similar marker in the working directory.

The motivation is security: job interview scenarios are cited where candidates are asked to clone untrusted repositories, exposing them to potential hook-based attacks. The proposal is lightweight and does not include a detailed design, but it clearly targets a real and growing concern about repository-local configuration being used as an attack vector.

This is a thread root; no prior discussion or patches are referenced. The request is well-motivated but remains at the idea stage—no code, tests, or implementation sketch are provided. It may attract attention from security-minded contributors, but it will need a champion to move from proposal to patch.
