This thread is a cleanup effort to modernize Git's test infrastructure by migrating mergesort tests from the shell-based test suite to the Clar unit-test framework. The series, now at version 3, was initiated by Muhammed Dilshad A in response to a suggestion from Patrick Steinhardt and has Junio C Hamano's endorsement.

The goal is to remove unused subcommands, retire an obsolete performance benchmark, and eliminate dead code while maintaining test coverage. The latest patch, the fourth in the series, removes the `p0071-sort.sh` benchmark and the `test-mergesort.c` helper, which had no remaining users after the numeric tests were migrated to Clar. This completes the cleanup, resulting in a net reduction of 307 lines of code. The test design has been simplified and edge-case coverage improved, with all prior feedback addressed.

Key participants include the author, Muhammed Dilshad A, who has addressed all review feedback, and Patrick Steinhardt, who suggested the cleanup and approved the simplified test design. Junio C Hamano has also endorsed the direction. The series is now ready for acceptance, with no open questions or loose ends remaining. This is purely internal test infrastructure work with no user-facing behavior changes.
