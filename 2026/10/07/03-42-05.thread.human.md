This thread is a cleanup effort by Muhammed Dilshad A to modernize Git’s mergesort test infrastructure. The three-patch series fixes memory leaks in the `sort_stdin()` function, migrates all 1,680 test cases from the shell-based suite to the Clar unit-test framework, and removes unused subcommands and obsolete files. The final patch, just posted, deletes the `p0071-sort.sh` performance benchmark and the `test-mergesort.c` helper, completing the 106-line net code reduction.

The work directly implements feedback from Patrick Steinhardt, who originally suggested removing the unused `generate` subcommand and benchmark. The series has been under review since v2, with no objections or open questions—just a straightforward implementation of the agreed-upon cleanup. All test coverage is preserved, and the Clar migration adds new edge-case tests and leak prevention. The changes are confined to test infrastructure and build files, with no impact on user-facing Git behavior. The thread appears ready for final review and integration.
