This is the first patch in a three-patch series targeting test infrastructure cleanup. It fixes two memory leaks in the `sort_stdin()` function of the `test-mergesort` helper: the input buffer (`strbuf sb`) and the memory pool (`lines_pool`) were allocated but never freed. The fix adds `mem_pool_discard()` and `strbuf_release()` calls after the sorted lines are printed. The patch also adds a new test in `t/t0071-sort.sh` to exercise the `sort` subcommand, ensuring the leaks are caught by the leak-sanitized test suite.

The changes are minimal and focused: two lines added to `test-mergesort.c` and a seven-line test case in `t/t0071-sort.sh`. The commit message clearly states the problem, the solution, and the test coverage added. This patch is a standalone bugfix that could be merged independently, though it is now part of a broader cleanup series. No behavior changes for user-facing Git; the leaks were internal to the test helper. The patch is well-motivated and ready for review.
