This is a bugfix patch targeting test infrastructure. It plugs two memory leaks in the `sort_stdin()` helper function in `t/helper/test-mergesort.c`: a memory pool (`lines_pool`) and a `strbuf` (`sb`) were allocated but never freed. The patch adds the missing cleanup calls (`mem_pool_discard()` and `strbuf_release()`) after the sorted lines are printed.

The patch also extends test coverage by adding a new test case in `t/t0071-sort.sh` that exercises the `sort` subcommand of `test-tool mergesort`. Previously, only the `test` subcommand was tested, so the leaks went undetected in the leak-sanitized test suite. The new test verifies that the `sort` subcommand correctly sorts input lines by comparing its output to an expected sorted list.
