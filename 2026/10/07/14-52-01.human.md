This is a documentation patch that completely rewrites the explanation of detached HEAD state in Git. The author, Julia Evans, is well-known for her clear, user-focused technical writing (e.g., her "Wizard Zines" on Git and other tools).

The patch replaces the current verbose, diagram-heavy explanation in `git-checkout.adoc` with a much shorter, more practical guide. Key improvements include: explaining *why* detached HEAD state is useful (e.g., for inspecting old commits), clarifying how users accidentally end up in it (checking out tags, remote branches, or commit IDs), and emphasizing how `git switch` (introduced in 2019) makes accidental detachment harder. The new content is split into a standalone guide (`gitdetachedhead(7)`), which can now be referenced directly from Git’s advice messages when users encounter detached HEAD state.

The rewrite is opinionated but well-motivated: it removes confusing diagrams, adopts a more conversational tone (e.g., "Git considers commits that aren’t on a branch to be garbage"), and explicitly addresses common pain points. The patch also updates the advice message to point users to the new guide. While the author acknowledges this was a "quick rewrite" without extensive user testing, the changes align with her track record of improving Git’s documentation for beginners. The patch looks like a clear win for usability.
