This is the second patch in a three-patch series that migrates Git’s mergesort tests from the shell-based test suite to the Clar unit-test framework. The patch removes the unused `generate` and `test` subcommands from the `test-mergesort` helper, keeping only the `sort` subcommand (which is still used by the now-obsolete performance benchmark, to be deleted in Patch 3). All 1,680 certification test cases—originally from Bentley and McIlroy’s 1993 paper—are ported verbatim to a new Clar test file (`t/unit-tests/u-mergesort.c`), preserving the same distributions, transformations, and validation logic. The Clar version adds new small-list and empty-list edge cases, exercises both the debug and non-debug variants of the sort macro, and ensures that node storage is properly freed even if an assertion fails. The net result is a near line-for-line migration that maintains identical test coverage while moving to the modern unit-test framework.
