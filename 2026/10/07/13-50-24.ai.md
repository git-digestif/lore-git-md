This is the second patch in a three-patch series migrating the mergesort test infrastructure from shell-based tests to the Clar unit-test framework. It focuses on moving all 1,680 certification test cases from the old `test-mergesort.c` helper into a new Clar test file (`t/unit-tests/u-mergesort.c`). The patch removes the unused `generate` and `test` subcommands from the test helper while preserving the `sort` subcommand for the still-active benchmark (which is deleted in patch 3). New edge-case tests for empty lists, small lists, and debug hooks are added, and the Clar test framework’s assertion macros ensure proper cleanup even if a test fails.

The patch touches five files: it updates `Makefile` and `t/meson.build` to register the new Clar test suite, strips ~330 lines of unused test infrastructure from `t/helper/test-mergesort.c`, deletes the now-obsolete shell test script `t/t0071-sort.sh`, and introduces the new `t/unit-tests/u-mergesort.c` file with all the migrated test logic. The core certification logic—distributions, transformations, and validation—is preserved verbatim, but the Clar version adds explicit bounds checking and a cleanup fixture to prevent memory leaks on assertion failures. The patch is purely a refactoring of test infrastructure; no user-facing Git behavior changes.
