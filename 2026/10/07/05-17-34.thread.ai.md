Core problem or goal
The `--relative` option in `git diff` ignores the requested prefix when displaying combined diffs (e.g., during merge conflicts), showing paths from the repository root instead. This patch ensures both human-readable and machine-readable combined-diff output respects the `--relative` prefix, restoring consistency with non-combined diffs.

Current status
Under review; no prior versions. The patch is self-contained, touching only `combine-diff.c` and the test suite. Junio C Hamano’s review raises two technical concerns: a coding style nit (long line in `strip_relative_prefix()`) and deeper design questions about path normalization (handling multiple slashes) and rename handling (whether `--relative` should strip prefixes from non-matching paths).

Open questions and loose ends

3. **Coding style**: `strip_relative_prefix()` helper line length exceeds Git’s guidelines.
