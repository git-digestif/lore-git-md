This is a bugfix patch series (v4 of 4) targeting the ref backend and hook infrastructure. The series fixes a long-standing issue where `reference-transaction` hooks were not seeing the full picture of branch rename (`git branch -m`) and copy (`git branch -c`) operations—hooks only received the deletion of the old ref, not the creation of the new one, breaking tools that rely on transactional ref updates.

The v4 iteration addresses the test breakages Junio C Hamano reported in v3: `t0600.16` (packed-refs locking) and `t5510.35` (fetch --prune rollback). The fix preserves the packed transaction error in `files_transaction_prepare()` so that failures early in the transaction cascade correctly. The series now passes the full test suite on macOS with both files and reftable backends, including the previously failing tests. No behavioral changes were made to the core logic; the four-patch structure (internal transaction flag, reflog replacement, copy/rename integration, and backend callback cleanup) remains intact.

Key technical details include new per-ref-update flags (`REF_COPY_SOURCE`, `REF_NEEDS_PACK`) and a `copy_from` field in `struct ref_update` to track rename/copy state without overloading the transaction struct. The `REF_TRANSACTION_FLAG_INTERNAL` flag suppresses hooks for nested backend operations, ensuring hooks only see the outer logical update. Performance regressions persist (~137% for files-based rename with large reflogs, ~20-25% for reftable) but are deemed acceptable for correctness. The series removes 656 lines of backend-specific logic, centralizing copy/rename handling in the transaction API.

The patch is well-motivated, thoroughly tested, and addresses a real pain point for hook-based tools. The v4 fixes are minimal and targeted, preserving the architectural improvements from v3 (per-ref state, centralized hook suppression) that lifted Patrick Steinhardt’s blocking objections. Junio’s test breakage report is now resolved, clearing the path for review. Expect this to land in `next` soon if no further regressions surface.

Files touched: `refs.c`, `refs.h`, `refs/files-backend.c`, `refs/reftable-backend.c`, `refs/refs-internal.h`, `t/helper/test-ref-store.c`, and new tests `t/t1424-ref-copy-transaction.sh` and `t/t1425-reflog-transaction.sh`. New symbols include `ref_transaction_replace_reflog()`, `REF_REPLACE_REFLOG`, and helper functions `ref_transaction_prepare_copy` and `ref_update_record_copy_source`. The series maintains backwards compatibility and does not change on-disk formats.
