This is a **behavioral change patch** targeting the `unpack-trees` subsystem, part of a six-patch RFC series (patch 5/6). The patch modifies how Git decides whether to clobber local changes during operations like `git switch` and `git checkout`. Currently, these commands overwrite ignored/excluded files; the patch restricts this to only "trashable" files (a subset of excluded files that excludes "precious" files, a concept introduced earlier in the series).

Key technical details:
- **Files touched**: `dir.c`, `dir.h`, `unpack-trees.c`
- **New function**: `is_trashable()` in `dir.c`/`dir.h` checks if a file is excluded *and* not marked as precious (using `PATTERN_FLAG_PRECIOUS`).
- **Modified logic**: `check_ok_to_remove()` in `unpack-trees.c` now calls `is_trashable()` instead of `is_excluded()`, preventing clobbering of precious files.
- **Behavior change**: Commands like `git switch` will no longer overwrite local changes in precious files (even if ignored), aligning with the series' goal of protecting such files.
