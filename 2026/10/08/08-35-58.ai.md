This is patch 8/13 of Patrick Steinhardt’s ODB alternates refactoring series, adapting the quarantine directory logic in `tmp-objdir.c` to manage the temporary object directory as a `struct odb_files_dir` instead of a standalone `struct odb_source`. The patch is part of the broader effort to relocate alternates handling into the files backend, making it a backend-specific implementation detail.

The change is mechanical but foundational: the `tmp_objdir` struct replaces its `prev_source` field with `temp_dir` (the new quarantine directory) and `orig_dir` (the original primary directory). The `tmp_objdir_replace_primary_odb()` function is updated to return a `struct odb_files_dir` and insert the quarantine directory at the head of the files backend’s linked list, propagating the `will_destroy` flag to both the loose and packed sources within the quarantine directory. The `tmp_objdir_restore_source()` helper is refactored to handle the new linked-list structure, ensuring the original primary directory is restored correctly.

Karthik Nayak’s review of this patch was surface-level, focusing on mechanical correctness rather than deeper edge cases like linked-list invariants or interactions with promisor remotes. His only substantive question—a conceptual concern about removing the ability to have multiple sources per ODB—was retracted after discovering Patrick’s explanation in patch 12/13, where the files backend’s linked-list mechanism is presented as the replacement. The patch itself introduces no new technical concerns, but the broader architectural shift (moving alternates into the files backend) remains a point of scrutiny for future patches.

The patch touches three files (`object-file.c`, `tmp-objdir.c`, `tmp-objdir.h`) and is a prerequisite for patch 12/13, which completes the alternates relocation. No behavior changes are introduced; the patch is purely preparatory. The linked-list traversal order (quarantine directory at the head) is now explicit, but the broader implications for alternates ordering remain unaddressed. Reviewers should verify that this ordering does not break assumptions in `git gc` or `git repack`.
