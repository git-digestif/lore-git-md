Subject: [PATCH 0/8] ci: housekeeping updates for CI configurations

Originating author: Patrick Steinhardt
Thread type: patch series (CI/build system maintenance)

Core problem or goal
Modernize and simplify Git's CI configurations by removing outdated dependencies (EOL Docker images, Python 2 coverage), eliminating redundant or unused jobs, and updating supporting scripts. The series targets GitHub Actions and GitLab CI workflows, along with minor test adjustments, to reduce complexity and improve reliability without introducing new functionality or behavioral changes.

Current status
Under review (initial v1 submission). No prior versions. The series consists of 8 patches touching `.github/workflows/main.yml`, `.gitlab-ci.yml`, `ci/install-dependencies.sh`, `ci/lib.sh`, `ci/run-build-and-tests.sh`, and `t/t5004-archive-corner-cases.sh`. Key changes include:
- Dropping the unused "linux-clang" job logic (patch 3/8 deletes dead code in `ci/run-build-and-tests.sh` left behind by commit d88d727143).
- Switching the `linux32` job from the unsupported `i386/ubuntu:20.04` image to `i386/debian:latest` (patch 4/8), ensuring 32-bit platform coverage until at least 2030. This update removes obsolete Ubuntu-specific logic in `ci/install-dependencies.sh` and updates `ci/lib.sh` to recognize the new image format.
- Renaming the `linux-TEST-vars` job to `linux-exotic` (patch 5/8) for clarity, as the job exercises Git with non-default "exotic" options (`OPENSSL_SHA1_UNSAFE`, `GIT_TEST_SPLIT_INDEX`, etc.).
- Updating the `linux-exotic` job to use `ubuntu:latest` (patch 6/8), replacing the EOL Ubuntu 20.04 image and removing the explicit `gcc-8` dependency. The job now uses the default GCC version provided by the image.
- Removing Python 2 coverage and the redundant `linux-reftable` job.
- Fixing the "fedora-breaking-changes-meson" job (restoring intended behavior via a typo fix in `ci/run-build-and-tests.sh`).
- Skipping a SHA-1-specific test in SHA-256 repositories for consistency.
Net effect: 18 insertions, 53 deletions, reducing CI complexity.
