Subject: [PATCH 0/8] ci: housekeeping updates for CI configurations
Series version: v1 (initial submission)
Originating author: Patrick Steinhardt
Thread type: patch series (CI/build system maintenance)

Core problem or goal
Modernize and simplify Git's CI configurations by removing outdated dependencies (EOL Docker images, Python 2 coverage), eliminating redundant or unused jobs, and updating supporting scripts. The series targets GitHub Actions and GitLab CI workflows, along with minor test adjustments, to reduce complexity and improve reliability without introducing new functionality or behavioral changes.

Current status
Under review (initial v1 submission). No prior versions. The series consists of 8 patches touching `.github/workflows/main.yml`, `.gitlab-ci.yml`, `ci/install-dependencies.sh`, `ci/lib.sh`, `ci/run-build-and-tests.sh`, and `t/t5004-archive-corner-cases.sh`. Key changes include:
- Dropping the unused "linux-clang" job logic (patch 3/8 deletes dead code in `ci/run-build-and-tests.sh` left behind by commit d88d727143).
- Switching the `linux32` job from the unsupported `i386/ubuntu:20.04` image to `i386/debian:latest` (patch 4/8), ensuring 32-bit platform coverage until at least 2030. This update removes obsolete Ubuntu-specific logic in `ci/install-dependencies.sh` and updates `ci/lib.sh` to recognize the new image format. The commit message's claim that "Ubuntu has dropped support for 32 bit entirely with the 20.04 release" is incorrect; Todd Zullinger noted Ubuntu 20.04 *did* include 32-bit support, and the phrasing should clarify this (e.g., "after the 20.04 release" or "in subsequent releases").
- Renaming the `linux-TEST-vars` job to `linux-exotic` (patch 5/8) for clarity, as the job exercises Git with non-default "exotic" options (`OPENSSL_SHA1_UNSAFE`, `GIT_TEST_SPLIT_INDEX`, etc.).
- Updating the `linux-exotic` job to use `ubuntu:latest` (patch 6/8), replacing the EOL Ubuntu 20.04 image and removing the explicit `gcc-8` dependency. The job now uses the default GCC version provided by the image.
- Removing Python 2 coverage (patch 7/8) by deleting conditional logic in `ci/lib.sh` and `ci/install-dependencies.sh` that set `PYTHON_PACKAGE=python2` for Ubuntu 20.04, replacing it with unconditional `PYTHON_PATH=/usr/bin/python3`. This aligns with Python 2's end-of-life in 2020 and the removal of the last Ubuntu 20.04-based job.
- Removing the redundant `linux-reftable` job (patch 8/8), as the `linux-reftable-leaks` job already exercises the reftable backend with leak sanitizer enabled. The patch deletes the job from both workflow files and updates `ci/run-build-and-tests.sh` to reflect its removal.
- Fixing the "fedora-breaking-changes-meson" job (restoring intended behavior via a typo fix in `ci/run-build-and-tests.sh` in patch 2/8, which corrects `musl` to `meson`).
- Adding the `SHA1` prerequisite to a test in `t/t5004-archive-corner-cases.sh` (patch 1/8) to skip it in SHA-256 repositories, preventing a CI failure once the Fedora job's typo is fixed.
Net effect: 21 insertions, 64 deletions, reducing CI complexity.
