This is the seventh patch in Patrick Steinhardt’s eight-patch CI/build system series. It removes the last remnants of Python 2 support from Git’s CI scripts after the preceding patch (6/8) dropped the final job that still used Ubuntu 20.04, the only image where Python 2 was still exercised.

The change is mechanical: it deletes the conditional logic in `ci/lib.sh` that set `PYTHON_PACKAGE=python2` for Ubuntu 20.04 and replaces it with an unconditional `PYTHON_PATH=/usr/bin/python3`. The corresponding update in `ci/install-dependencies.sh` hard-codes `python3` instead of the variable `$PYTHON_PACKAGE`. Eleven lines are removed, two are changed, and the result is simpler, more predictable CI behavior.

The commit message explains the rationale clearly: Python 2 reached end-of-life in 2020, none of the current CI images package it, and the world has moved on. The patch is uncontroversial and aligns with the series’ overall goal of reducing CI complexity. Expect future discussion to reference the `PYTHON_PACKAGE` variable and the Ubuntu 20.04 image, but no substantive debate is likely.
