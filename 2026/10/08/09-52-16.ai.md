This is the **v3 revision of a bugfix series** targeting a data-loss race in `git repack -d`. The race occurs when a concurrent push or fetch installs a `.keep` file mid-repack, causing `pack-objects` to skip objects in a pack that `repack` later deletes. The series replaces the racy `--honor-pack-keep` mechanism with a snapshot-based approach, ensuring `pack-objects` uses the same `.keep` list observed at repack startup.

**Key changes since v2**:
- Patch 2/5 (cruft-pack walk fix) now moves the kept-pack cache invalidation logic from `builtin/pack-objects.c` to `packfile.c`, addressing Junio’s layering concern. The new `repo_invalidate_kept_pack_caches()` helper groups the downcast with existing ones, though the architectural question of whether this is sufficient for long-term maintainability remains open. Junio has acked this patch for the current codebase.
- The rest of the series is unchanged. Patch 1/5 aligns `--keep-pack` behavior with on-disk `.keep` packs under `--stdin-packs=follow`. Patch 3/5 optimizes `--keep-pack` lookups with a sorted list (11× speedup). Patch 4/5 adds `--keep-pack-from-file` to handle repositories with too many kept packs for command-line limits. Patch 5/5 implements the snapshot-based fix, passing `pack-objects` the exact `.keep` list observed at repack startup.

**Files touched**:
- Core logic: `builtin/pack-objects.c`, `builtin/repack.c`, `packfile.c`, `packfile.h`, `odb/source-packed.h`
- Tests: `t/t5329-pack-objects-cruft.sh`, `t/t5331-pack-objects-stdin.sh`, `t/t7700-repack.sh`, `t/t7703-repack-geometric.sh`
- Documentation: `Documentation/git-pack-objects.adoc`

**Behavior changes**:
- `--stdin-packs=follow` now treats `--keep-pack` packs as traversal blockers (like `^` packs), fixing a long-standing inconsistency.
- The cruft-pack walk no longer uses a stale kept-pack cache, preventing objects from being omitted from the cruft pack.
- Alternate ODB packs are now packed (not deleted) for safety, trading disk space for data integrity.

**Test coverage**:
Each patch includes a test that fails without it. The race is reproduced in `t7703-repack-geometric.sh` by simulating a `.keep` file appearing mid-repack. The series passes the full test suite and merges cleanly into `seen` and `next`, with a minor textual conflict resolution for `ps/odb-files-alternates`.
