This thread is a patch series from Patrick Steinhardt updating Git's CI configurations to modernize and simplify the setup. The v3 series, now under review, addresses feedback from Junio C Hamano and SZEDER Gábor on earlier versions. The goal is to remove outdated dependencies (like Python 2 and EOL Docker images), eliminate redundant jobs, and streamline scripts without changing Git's behavior.

Key changes in v3 include renaming the `linux-TEST-vars` job to `linux-feature-testbed` (resolving a naming dispute), repurposing the `linux-reftable-leaks` job to test reftable with SHA-256, updating the 32-bit platform image to Debian, and removing dead code left behind by prior job removals. The latest patch (7/8) hard-codes `python3` in the CI scripts, as Python 2 is no longer supported in any active CI job. Junio has endorsed the coverage trade-offs and naming resolution, and the series is now uncontested.

The patches touch GitHub Actions and GitLab CI workflows, supporting scripts in the `ci/` directory, and one test file. All changes are mechanical and pass CI runs. Open questions remain about whether the reftable/SHA-256 coverage split or the Python 2 removal might draw feedback from contributors invested in those areas, but no substantive objections are expected. The series is ready for further review.
