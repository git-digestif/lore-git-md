This thread is a patch series from Patrick Steinhardt updating Git's CI configurations to modernize and simplify the setup by removing outdated dependencies, redundant jobs, and dead code. The v3 series, now under review, consists of eight patches touching GitHub Actions, GitLab CI workflows, and supporting scripts. Key changes include renaming the `linux-TEST-vars` job to `linux-feature-testbed` (resolving a naming dispute), repurposing the `linux-reftable-leaks` job to test SHA-256 with reftable, removing Python 2 support, updating Docker images, and fixing a typo in the Fedora breaking-changes job.

Most of the series is uncontested, with Junio C Hamano and Jeff King (Peff) providing surface-level and substantive reviews. The only remaining open question was Peff's concern about Icelandic locale support in the new `i386/debian:latest` image for the `linux32` job, which Patrick has now resolved by confirming that Debian's `locales-all` package provides the necessary locale data. This closes the last substantive technical issue for the series. The discussion around patch 1/8 (adding a `SHA1` prerequisite to a test) remains unresolved, with Peff proposing an alternative approach to make the test self-contained, but Patrick has not yet rerolled this patch. The series is otherwise ready for integration, with all other patches either uncontested or resolved.
