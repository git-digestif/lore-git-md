This thread is about a patch series from Patrick Steinhardt that modernizes Git's CI configurations by removing outdated dependencies (like Python 2 and EOL Docker images), simplifying job definitions, and improving test coverage for reftable and SHA-256 combinations. The series, now at version 4, consists of 8 patches touching GitHub Actions, GitLab CI, and supporting scripts in the `ci/` directory.

Key changes include renaming the `linux-TEST-vars` job to `linux-feature-testbed` (resolving a naming dispute), repurposing the `linux-reftable-leaks` job to test SHA-256 with reftable, and hard-coding `python3` now that Python 2 is no longer supported in CI. The series also fixes a test in `t/t5004-archive-corner-cases.sh` to work in both SHA-1 and SHA-256 repositories by creating a temporary SHA-1 repository, addressing feedback from Jeff King (Peff). All substantive technical concerns from prior versions have been resolved, and Junio C Hamano has mechanically backported version 3 to Git v2.56.0 for potential inclusion in the `maint` branch.

The series is now uncontested and ready for integration. Peff's final review confirms that all his feedback has been addressed, and he considers the series ready to merge. The discussion has also identified opportunities for future CI script improvements, such as using wildcard patterns (`*breaking-changes*`, `*-sha256*`) to reduce duplication and automate settings, but these are deferred to follow-up work. The net effect is a reduction in CI complexity (43 insertions, 56 deletions) while maintaining or improving test coverage.
