This patch series is a CI/build system housekeeping effort by Patrick Steinhardt to modernize Git’s CI configurations. The v4 reroll, now consisting of 8 patches, removes outdated dependencies (Python 2, EOL Docker images), eliminates redundant jobs, and updates supporting scripts without changing Git’s behavior. All substantive technical feedback—including Jeff King’s (Peff) concerns about test design, job naming, and reftable coverage—has been addressed, and Junio C Hamano has mechanically backported v3 to Git v2.56.0 for potential `maint` integration.

The series is now ready for integration. Key changes include: making a test in `t/t5004-archive-corner-cases.sh` self-contained by creating a temporary SHA-1 repository (resolving Peff’s feedback), renaming the `linux-TEST-vars` job to `linux-feature-testbed` (Junio’s preferred choice), repurposing the `linux-reftable-leaks` job as `linux-reftable-sha256` to cover SHA-256 + reftable (while preserving foreign-SCM interoperability), and updating 32-bit platform images to Debian. The latest patch (7/8) removes dead Python 2 logic, hard-coding `python3` now that Ubuntu 20.04 jobs are gone. All patches are uncontested and pass CI runs.

The only loose end is a deferred discussion about broader CI script refactoring—Peff and Patrick grouped `sha256`, `breaking-changes`, `reftable`, and `meson` as related job categories that could benefit from wildcard patterns (`*breaking-changes*`, `*-sha256*`) to reduce duplication, but this was explicitly deferred to a follow-up. The series reduces CI complexity (43 insertions, 56 deletions) while maintaining or improving coverage.
