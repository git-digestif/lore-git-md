This is the second patch in Patrick Steinhardt’s 13-patch series refactoring Git’s object database (ODB) to move alternates handling into the "files" backend. The patch decouples the commit-graph subsystem from `struct odb_source`, replacing it with explicit repository and object-directory path arguments. This is a foundational step toward making the commit-graph backend-agnostic and unblocking future ODB work, including pluggable backends.

The core change is mechanical but consequential: every function in `commit-graph.c` and `commit-graph.h` that previously took a `struct odb_source *` now takes a `struct repository *` and a `const char *dir` instead. The patch also canonicalizes object-directory paths to absolute form, ensuring that commit graphs loaded from the same directory compare equal regardless of how the path was spelled (relative, absolute, or via symlink). This fixes a subtle correctness issue where different path representations could lead to redundant or missed graph loads.

Key symbols renamed or introduced include:
- `get_commit_graph_filename()` and `get_commit_graph_chain_filename()` now take `const char *dir` instead of `struct odb_source *`.
- `load_commit_graph_one_fd_st()`, `load_commit_graph_one()`, `load_commit_graph_v1()`, `load_commit_graph_chain()`, and `read_commit_graph_one()` all gain a `struct repository *` and `const char *dir` parameter.
- `struct commit_graph` replaces its `odb_source` field with `repo` and `dir` (the canonicalized absolute path).
- `write_commit_graph_reachable()` and `write_commit_graph()` now take `(repo, dir)` instead of `source`.

The patch touches nine files, with the bulk of the changes in `commit-graph.c` (115 lines) and `commit-graph.h` (31 lines). The test helper `git_test_write_commit_graph_or_die()` is updated to take only a `struct repository *`, though it still hard-codes the object directory path from `repo->objects->sources->path`. This inconsistency was flagged in review but dismissed by Patrick as acceptable for a test-suite helper.

This is a well-crafted refactoring that aligns with the series’ architectural goals. The commit message clearly explains the motivation and the path-canonicalization fix is a nice bonus. If you care about ODB internals or the commit-graph subsystem, this patch is worth a quick skim—especially the path-handling logic in `commit-graph.c`. The series as a whole is now ready for integration, so this is likely to land soon.
