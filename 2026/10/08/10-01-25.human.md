This is a CI/build system patch, the seventh in Patrick Steinhardt’s eight-patch series cleaning up Git’s CI configurations. It removes the last remnants of Python 2 support from the CI scripts now that the Ubuntu 20.04 image (the only one that still carried Python 2) has been dropped in an earlier patch. The change is mechanical: `ci/install-dependencies.sh` hard-codes `python3` instead of the conditional `PYTHON_PACKAGE`, and `ci/lib.sh` removes the now-unused logic that set `PYTHON_PATH` based on the Ubuntu version. The result is a net deletion of 11 lines and a small step toward simpler, more maintainable CI scripts. No controversy is expected—Python 2 reached end-of-life in 2020, and none of the current CI images still package it.
