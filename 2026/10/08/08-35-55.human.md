This is patch 5/13 in Patrick Steinhardt’s v2 series refactoring the Git object database (ODB) to move alternates handling into the "files" backend. The patch refactors `odb_find_source()`—a generic ODB function that locates a source by its object directory path—into `odb_source_files_find_dir()`, a files-backend-specific function that returns a `struct odb_files_dir` instead of a generic `struct odb_source`.

The change is mechanical but foundational: it replaces all callers in `builtin/commit-graph.c`, `builtin/multi-pack-index.c`, and `t/helper/test-read-midx.c` to use the new function, updating them to reference `dir->abspath` instead of `source->path` and to use `odb_source_files_downcast()` where needed. The generic `odb_find_source()` and `odb_find_source_or_die()` functions are removed from `odb.c` and `odb.h`, completing the shift toward backend-specific APIs.

This patch is a small but necessary step in the larger architectural goal of making alternates a files-backend implementation detail. It introduces no behavior changes, but the new `odb_source_files_find_dir()` function will be critical in later patches (notably 12/13) that relocate alternates handling into the files backend.
