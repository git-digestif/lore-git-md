This thread is about a small but important bugfix for `git repack --drop-filtered --dry-run`, which had been incorrectly modifying the repository even when `--dry-run` was specified. The regression dated back to 2025 and was introduced when the `--dry-run` option was first added. Siddharth Shrimali submitted a two-part fix: the first version (v2) added an early return in `cmd_repack()` to prevent any repository modifications under `--dry-run`, and the follow-up (v3) cleaned up redundant `!dry_run` checks that were no longer reachable after the v2 change.

The fix has been reviewed and is now queued in Junio’s `next` branch for integration testing, with no further changes expected. D. Ben Knoble reviewed the v2 patch and confirmed its correctness, while Patrick Steinhardt noted the redundant checks that were later removed in v3. Junio queued the series after minor editorial feedback on the commit message, which Siddharth acknowledged but did not resend. The topic is uncontroversial and should graduate to `master` in the next cycle. No open questions remain, and the thread is effectively closed.
