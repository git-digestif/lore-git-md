This thread is about a bugfix for `git repack --drop-filtered --dry-run`, which incorrectly modified the repository despite the `--dry-run` flag. The regression, present since 2025, was fixed in a v2 patch series by Siddharth Shrimali. The fix—a simple early `return` in `cmd_repack()`—has been reviewed by D. Ben Knoble, queued in Junio’s `next` branch, and is on track to graduate to `master` in the next cycle.

The patch itself is complete and uncontroversial, with all review feedback incorporated. The only recent development is a technical observation from Patrick Steinhardt: the early `return` makes a later `(!dry_run)` check in the same function redundant. This is a minor code hygiene issue and not a blocker for the current fix. The thread is now in a holding pattern, awaiting integration. No further changes or discussion are expected for the bugfix itself.
