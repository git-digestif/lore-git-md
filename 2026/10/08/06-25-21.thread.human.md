This thread is about a bugfix for `git repack --drop-filtered --dry-run`, which has incorrectly modified repositories despite the `--dry-run` flag since the feature was introduced in 2025. The issue was reported and fixed by Siddharth Shrimali in a two-version patch series.

The fix is minimal: an early `return` in `cmd_repack()` after listing candidate objects for dropping, preventing the code from proceeding to the actual repack and deletion steps. The patch touches only `builtin/repack.c` and adds a new test in `t/t7706-repack-drop-filtered.sh` to verify the pack directory remains unchanged under `--dry-run`. Reviewer D. Ben Knoble has confirmed the fix is correct and aligned with existing patterns, and has offered his `Reviewed-by`. Junio C Hamano also reviewed the historical context, which is now documented in the commit message.

All review feedback has been incorporated, including rewording an in-code comment and expanding the diff context. The regression’s origin is clearly documented, and the test coverage is thorough. The patch is now ready for integration, with no open questions or loose ends remaining.
