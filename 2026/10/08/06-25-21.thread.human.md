This thread is about a bugfix for a long-standing regression in `git repack --drop-filtered --dry-run`, where the `--dry-run` flag was incorrectly ignored, causing packs to be rebuilt and deleted despite the flag's documented behavior. The regression has existed since `--dry-run` was introduced in 2025 (commit `1e746b00aa`).

Siddharth Shrimali authored the fix, which adds an early `return` in `cmd_repack()` to prevent the code from proceeding to the actual repack and deletion steps when `--dry-run` is used. The patch is minimal, touching only `builtin/repack.c` and adding a new test in `t/t7706-repack-drop-filtered.sh` to verify the pack directory remains unchanged under `--dry-run`. After incorporating review feedback—including rewording an in-code comment and documenting the regression's origin—the patch was deemed correct by D. Ben Knoble, who provided his `Reviewed-by`.

Junio C Hamano has now queued the topic for wider testing in the `next` branch, marking it as ready for integration. Unless integration issues arise, it will likely graduate to `master` in the next cycle. No further changes or discussion are expected.
