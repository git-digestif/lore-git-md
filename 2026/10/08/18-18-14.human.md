This is the final patch in Patrick Steinhardt’s eight-part CI housekeeping series, and Junio C Hamano raises a substantive review point about it. The patch removes the `linux-reftable` job, which Patrick justified as redundant because the `linux-reftable-leaks` job already exercises the reftable backend with leak sanitizer enabled. Junio points out that the `linux-reftable-leaks` job disables CVS, SVN, and Perforce tests (via `NO_{CVS,SVN,PR}_TESTS` in `ci/lib.sh`), meaning those foreign-SCM interoperability tests are no longer run against the reftable backend at all after this patch. While Junio does not insist on retaining the coverage, he asks that the loss be acknowledged in the commit message.

The patch itself is small and mechanical—three deletions in each workflow file and a one-line adjustment in `ci/run-build-and-tests.sh`—but Junio’s observation turns it into a minor trade-off between CI simplicity and test coverage. The series as a whole has been uncontroversial so far, and this feedback is unlikely to derail it, but expect a v2 that either restores the tests or updates the commit message to note the omission.
