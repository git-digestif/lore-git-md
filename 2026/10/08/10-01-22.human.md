This is a CI/build system patch, part of Patrick Steinhardt’s eight-patch series to modernize Git’s CI configurations. Patch 4/8 switches the `linux32` job away from the now-unsupported `i386/ubuntu:20.04` image to `i386/debian:latest`. The change is mechanical and uncontroversial: Ubuntu dropped 32-bit support after 20.04, so Debian is the only remaining 32-bit Docker image that still receives updates. The patch updates both GitHub Actions and GitLab CI workflows, trims dead code from `ci/install-dependencies.sh`, and adjusts a case pattern in `ci/lib.sh`. No user-visible behavior changes; the goal is simply to keep the 32-bit CI job running reliably.
