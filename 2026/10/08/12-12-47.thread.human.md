This thread introduces a new Git feature called "precious files," proposed by Mirko Faina based on a design by Elijah Newren. The feature adds a `precious` file attribute to mark files as important but not version-controlled, protecting them from accidental deletion by operations like `git clean` while keeping them out of the repository. The six-patch RFC series includes Elijah's design document and implements core functionality by modifying pattern handling in `dir.c`/`dir.h`, removal checks in `unpack-trees.c`, and adding support to `git ls-files`. Tests are included, but documentation updates and `git clean` integration are deferred pending feedback.

The proposal is in early RFC stage, seeking community input before further development. Key files touched include directory traversal logic, removal safety checks, and the `ls-files` command. No prior discussion appears to exist, making this the first public airing of the concept. The implementation closely follows Elijah's design, suggesting strong alignment with his vision for the feature.
