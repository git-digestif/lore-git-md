This thread is about a small but important fix to a flaky test in Git’s test suite. Harald Nordgren identified that `t7004-tag.sh` intermittently fails on Alpine Linux when the `rm -rf gpghome` command can’t remove a socket file that may not exist. The fix replaces this filesystem cleanup with an environment override (`GNUPGHOME=$GNUPGHOME_NOT_USED`) to simulate a missing public key, following the same pattern already used in `t7510`.

Junio C Hamano reviewed and queued the patch, calling it "a very good idea." The change is minimal—just two lines in `t/t7004-tag.sh`—and doesn’t alter the test’s behavior, only its reliability. The patch is now in Junio’s queue and is expected to graduate to `next` and eventually `master` without further discussion or revisions. No objections or open questions remain.
