This is an RFC patch series introducing the concept of "precious files" to Git, based on a design document by Elijah Newren. The series adds a new file attribute type (`precious`) that marks files as important but not version-controlled, preventing accidental deletion by operations like `git clean` while still excluding them from the repository.

The series consists of six patches. The first patch adds Elijah Newren's design document as `Documentation/technical/precious-files.txt`, outlining the motivation and behavior. The remaining five patches implement the core functionality: refactoring pattern macros in `dir.h` to use an enum, teaching `parse_path_pattern()` and `add_pattern()` to handle precious files, modifying `unpack-trees.c` to respect precious files during removal checks, and adding support for listing precious files in `git ls-files`.

Key files touched include `dir.c`/`dir.h` (pattern parsing and directory traversal), `unpack-trees.c` (removal safety checks), `builtin/ls-files.c` (new output support), and several test files. The series also includes test coverage in `t/t3001-ls-files-others-exclude.sh` and other test scripts. The author notes that documentation updates and `git clean` integration are not yet implemented, pending feedback on the current approach.

The implementation appears to be a direct translation of Elijah's design, with mechanical changes to pattern handling and removal logic. The series is marked as RFC, indicating it is seeking early feedback before further polish. No prior discussion or thread context is provided, so this is the first public proposal of the feature. The base is Git 2.98's start-of-cycle commit.
