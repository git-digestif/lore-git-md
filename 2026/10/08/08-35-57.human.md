This is a refactoring patch (7/13) in Patrick Steinhardt’s series to move alternates handling into the files ODB backend. The patch absorbs the temporary-primary-source logic into `tmp-objdir.c`, removing `odb_set_temporary_primary_source()` and `odb_restore_primary_source()` from the public ODB API.

The change is straightforward: the two ODB functions are now static helpers in `tmp-objdir.c`, which directly manipulates the ODB’s source list and `disable_ref_updates` flag. The `tmp_objdir` struct keeps its `prev_source` field, but the logic is now self-contained. This is a preparatory step for later patches that will make alternates a files-backend implementation detail, eliminating the need for multiple sources per ODB.

The patch is mechanical and well-contained, touching only three files. No behavior changes are introduced—this is purely about moving code. The commit message clearly explains the rationale: the functionality is only used by `tmp-objdir`, and the broader architectural shift (alternates as a backend detail) makes the ODB-level API unnecessary. If you’re following the series, this is a minor but necessary step toward the larger goal.
