This thread is exploring a new "precious files" attribute for Git, proposed by Mirko Faina, that would protect untracked but important files (like build artifacts or IDE metadata) from accidental deletion during operations like `git clean` or checkout. The RFC series includes a detailed design document by Elijah Newren and introduces a ternary state in `.gitignore` files (precious `$`, untracked `!`, and trashable unmarked).

The series is still in the early review stage, with no prior versions. The latest email covers a preparatory refactoring patch that moves pattern-related macros into an enum in `attr.h`—a small, mechanical change that sets the stage for the core implementation. While this patch is uncontroversial, the broader proposal faces open questions about its complexity and interaction with existing mechanisms like `.gitignore` and `git stash -u`. Key concerns include edge cases (e.g., submodules, sparse-checkout) and deferred features like `git clean` support. So far, only Mirko and Elijah have weighed in, with Elijah’s design document suggesting implicit support but no explicit stance yet. The thread remains focused on gathering feedback before proceeding further.
