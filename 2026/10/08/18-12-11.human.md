This is a brief, surface-level review comment on the CI/build system patch series. Junio C Hamano weighs in on Todd Zullinger’s earlier observation about the phrasing in Patrick Steinhardt’s commit message for patch 4/8. The original wording ("Ubuntu has dropped support for 32 bit entirely with the 20.04 release") could be misread as implying Ubuntu 20.04 lacked 32-bit support, when in fact the support was dropped in later releases.

Junio suggests a clearer alternative that avoids ambiguity: "Ubuntu has dropped support for 32-bit entirely, together with 20.04 release, so upgrading it to a more recent image would not help us keeping 32-bit support." This tweak makes it explicit that both 32-bit support and the 20.04 release itself are now obsolete, without falsely attributing the 32-bit drop to 20.04. The feedback remains purely editorial—no technical concerns are raised, and the patch’s substance (switching from `i386/ubuntu:20.04` to `i386/debian:latest`) is uncontroversial. Expect Patrick to incorporate this or a similar rephrasing in a future revision.
