This is a test fix targeting the `t7004-tag.sh` test script. The patch addresses a flaky test in Git's GPG signature verification suite by avoiding the deletion of the `gpghome` directory, which sometimes fails on Alpine Linux due to missing files.

The problematic test, "verify signed tag fails when public key is not present," previously relied on deleting the entire `gpghome` directory to simulate the absence of a public key. This approach occasionally fails on Alpine because the `rm -rf` command stumbles over a missing `S.gpg-agent.extra` socket file. The fix replaces the directory deletion with a cleaner method: pointing `GNUPGHOME` to an unused directory (stored in `GNUPGHOME_NOT_USED`), mirroring the approach already used in `t7510` for similar scenarios.

The change is minimal—just two lines modified in `t/t7004-tag.sh`—and aligns the test with existing patterns in the test suite. The commit message is clear and references the specific error observed, making the motivation easy to follow. This looks like a straightforward, well-targeted fix for a known flaky test.
