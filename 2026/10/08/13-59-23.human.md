This is a licensing clarification from Sam Reis, the original author of the Rust `sha1dc` crate that Scott Chacon’s `sha1dc-accel` series ports to C. Reis confirms that the unavoidable-bit-condition (UBC) check tables in his implementation are fully autogenerated by a custom tool he wrote with LLM assistance, based on the 2017 Stevens/Shumow paper. He included Stevens and Shumow in the copyright notice as a precaution, but the code itself is not hand-written.

On the licensing question D. Ben Knoble raised—whether the new C code should adopt the MIT license (matching the existing `sha1dc` submodule) or be relicensed to GPL-2—Reis points to the GPL compatibility of MIT. He cites the Wikipedia article on license compatibility, which states that MIT-licensed code can be combined with GPL-licensed code without conflict, as long as attribution is preserved. This suggests he sees no legal barrier to including MIT-licensed collision-detection code in Git, even if the rest of Git is GPL-2.

The message does not resolve the policy question Knoble raised about whether Git should standardize on MIT for collision-detection code or "license-wash" new contributions to GPL-2. Reis’s response is factual rather than prescriptive: he explains the origin of the code and the compatibility of the licenses, but leaves the project’s stance to the maintainers. No new technical or policy objections are introduced, and Reis reiterates his support for the series.
