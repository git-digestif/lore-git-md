This is the **final patch (5/5) in a well-crafted bugfix series** that closes a data-loss race in `git repack -d`. The race occurs when a concurrent push or fetch creates a `.keep` file after `repack` has decided which packs to delete but before `pack-objects` has finished building the replacement pack. The result is dangling refs pointing to nonexistent commits.

This patch replaces the racy `--honor-pack-keep` mechanism with a **snapshot-based approach**: `repack` writes the list of `.keep` packs observed at startup into a temporary file, then passes that file to `pack-objects` via the new `--keep-pack-from-file` option (added in patch 4/5). Both processes now work from the same snapshot, so a `.keep` appearing or disappearing mid-repack cannot make them disagree. The earlier patches in the series ensure the traversal logic and performance are correct; this one ties everything together.

The implementation is minimal and focused. The snapshot file is written next to the refs snapshot already used for `multi-pack-index write`, and its format (one `<name>.pack` per line) matches existing Git conventions. The patch also removes a redundant loop in `write_filtered_pack()` that was passing kept packs without the `.pack` suffix, and it refuses to proceed if a kept pack’s name contains a newline (which would split the name in two). Alternate ODB packs are now packed rather than skipped, trading disk space for safety.

Test coverage is thorough. The patch adds three new tests:
1. `t7700-repack.sh` verifies that `--keep-pack` with `--pack-kept-objects` still excludes the kept pack’s objects.
2. `t7703-repack-geometric.sh` reproduces the race (a `.keep` appearing mid-repack) and confirms objects are not lost.
3. A second test in `t7703-repack-geometric.sh` ensures kept packs do not block traversal of objects reachable through them.

The series as a whole is **production-tested and ready for integration**. Patch 2/5 (cruft-pack walk fix) is already acked by Junio, and this patch (5/5) is the logical culmination of the snapshot-based design. The commit message is clear, the tests are comprehensive, and the design avoids introducing new races. Likely reviewers include Patrick Steinhardt and Taylor Blau (repack/ODB maintainers), but the patch is unlikely to draw objections given the careful groundwork laid by the earlier patches.
