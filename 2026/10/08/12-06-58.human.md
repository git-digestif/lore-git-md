This is a refactoring patch that prepares the codebase for the "precious files" feature introduced in the RFC series. It moves pattern-related macro definitions from `dir.h` to `attr.h` and converts them into an `enum pattern_flags`, which is then used in the `pattern` struct and related functions.

The patch is mechanical and straightforward: it replaces the existing `unsigned flags` field in the `pattern` struct with the new `enum pattern_flags` type, updates function signatures to match, and adds the necessary `#include "attr.h"` directives in files that now depend on the enum. The changes are confined to header files and function declarations, with no behavioral modifications. This is a clean preparatory step for the later patches in the series, which will introduce the `PATTERN_TYPE_PRECIOUS` flag.

The patch is well-scoped and appears technically sound, though its value depends entirely on the broader "precious files" proposal. The commit message is clear, and the diff is minimal and focused. No test failures or regressions are expected from this change alone. If the RFC gains traction, this refactoring will make the subsequent patches easier to review; if the RFC is rejected, this patch can be safely dropped.
