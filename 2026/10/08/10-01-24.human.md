This is a CI/build system patch, the sixth in Patrick Steinhardt’s eight-patch series that tidies up Git’s CI configurations. It replaces the end-of-life Ubuntu 20.04 image in the `linux-exotic` job with `ubuntu:latest`, which always points to the most recent Ubuntu LTS release. The change is mirrored in both GitHub Actions and GitLab CI workflow files, and it drops the explicit `gcc-8` package requirement in favor of the default compiler. The commit message explains that the project already has coverage for older Linux versions via other jobs (AlmaLinux 8, Debian 12), so the loss of Ubuntu 20.04 coverage is not a concern. The patch is small (two files, six lines removed) and uncontroversial; it simply keeps the CI environment current without altering any test logic or user-visible behavior.
