This is a licensing and policy discussion in the ongoing thread about the `sha1dc-accel` series. D. Ben Knoble raises two main points: whether the new code’s MIT/Apache2 license is compatible with Git’s GPL-2 licensing, and how Git’s overall license should be described when it bundles MIT-licensed code like `sha1dc`.

Knoble notes that Git already includes MIT-licensed `sha1dc` code (imported in 2017) and asks whether the new `sha1dc-accel` code should follow the same pattern. He also wonders if Git’s license claims (e.g., by distributions like Gentoo) should reflect the MIT-licensed components, making the effective license “GPL-2 and MIT” rather than just “GPL-2.” The email does not resolve these questions but frames them as open issues that need clarification before the series can proceed.

The discussion is substantive but not adversarial; Knoble is asking for pointers to past discussions or legal guidance rather than objecting to the series itself. No new technical concerns are raised, and the licensing questions are now the primary remaining blocker alongside the earlier code-duplication issue in patch 1.
