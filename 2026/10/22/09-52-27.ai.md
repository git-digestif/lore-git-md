This is a feature request for a new Git command to update only the password component in a remote URL.

The author, Ján Waclawek, proposes a new command ``git remote set-password <remote> <new_password>`` that would replace just the password portion of a remote URL while preserving the username, hostname, path, and other components. The motivation is to simplify password rotation for users whose security policies require frequent password changes, avoiding the current need to manually reconstruct or script-modify the entire URL.

The request explicitly acknowledges the security drawbacks of embedding passwords in URLs but argues the feature would still be useful for users who already use this pattern and understand the risks. It also notes that credential managers, while preferable, are not always practical in all environments.

No prior discussion or related patches are mentioned in the email. The proposal is presented as a self-contained idea rather than part of an ongoing effort. The scope is narrow: a single new command with no indication of broader changes to credential handling or URL parsing.
