This is a security release announcement for **Git for Windows 2.56.0(3)**, addressing two security issues in the distribution's bundled components. Johannes Schindelin reports that the update mitigates the eMudhra Intermediate CA compromise and resolves CVE-2026-105803 in Git LFS by upgrading it to v3.8.1. The release also updates OpenSSH to v10.6.P1 and cURL to v8.23.0, but includes no changes to Git's core code—this is purely a packaging update for the Windows distribution.

The announcement provides download links for all variants (64-bit/32-bit installers, portable builds, MinGit, and busybox-based MinGit) along with SHA-256 checksums. This is the third build in the 2.56.0 series, following the October 5th 2.56.0(2) release. No upstream Git patches or mailing list discussion are involved; the fixes are specific to Git for Windows' bundled toolchain.
