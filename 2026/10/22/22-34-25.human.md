This is Junio’s final review of Taylor Blau’s v2 patch that fixes a correctness bug in Git’s skipping negotiator. The patch itself is already merged to `master`, but Junio raises a latent edge-case issue: if a commit cannot be parsed (due to corruption or a missing promisor object), the current implementation marks it as `SEEN` before attempting to parse it, which can later trigger a `BUG()` when the same commit is encountered again. Junio suggests deferring the `SEEN` mark until after parsing succeeds to avoid this. The concern is narrow—only relevant in error scenarios—but valid, as `BUG()` should never fire for data corruption or network issues. No action is required on the merged patch, but this observation may inform future error-handling improvements in the negotiator code.
