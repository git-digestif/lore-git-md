This is a follow-up in the `git stash` shell completion series, specifically about the fifth patch (removal of `git stash save` completion). The author, D. Ben Knoble, reports test results for the behavior of option autocompletion when a user manually types `git stash save --<TAB>`.

Testing confirms that even after removing `save` from the list of completable subcommands, option autocompletion for manually typed `save` still works (e.g., `git stash save --<TAB>` completes options like `--patch` or `--quiet`). This behavior persists regardless of the `GIT_COMPLETION_SHOW_ALL` setting, though `SHOW_ALL` does restore `save` to the list of completable subcommands when typing `git stash <TAB>`. Knoble plans to update the commit message to document this behavior, addressing Patrick Steinhardt’s earlier request for clarity about `SHOW_ALL`’s role. No further design questions remain for this patch.
