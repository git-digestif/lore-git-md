This is a refactoring patch in the log subsystem, part of a 4-patch series by Miklos Vajna. The patch extracts the logic that shows either a remerge diff or a combined diff for merge commits into a new helper function `log_tree_merge_diff()`. The commit message states no functional changes are intended; the goal is to avoid code duplication before a later patch in the series calls this logic again.

The change touches only `log-tree.c`, moving 14 lines of conditional logic into a separate function and replacing the original block with a single call to the new helper. The new function takes the same parameters as the original code block (`opt`, `commit`, `parents`, and `oid`) and preserves the existing behavior: skipping remerge-diff for octopus merges, calling `do_remerge_diff()` for remerge-diff, and falling back to `do_diff_combined()` for combined merges.

This is the second patch in the v3 iteration of the series. The cover letter for the series is not included in the input, so the broader goal of the series remains unclear, but the immediate motivation is to prepare for a future patch that will reuse this logic. The patch is clean, mechanical, and well-scoped, with no new behavior introduced.
