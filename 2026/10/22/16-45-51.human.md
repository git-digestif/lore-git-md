This is a brief follow-up in the SSH signing verification security thread, specifically about the documentation patch clarifying how Git checks SSH key lifetimes. Junio C Hamano accepts Patrick Steinhardt’s proposed wording for the `gpg.adoc` man page, which now explicitly states that Git uses the committer or tagger timestamp (not the signature timestamp) for `valid-before`/`valid-after` checks and adds a concise security note: "This does not provide any security guarantees as the timestamp can be chosen arbitrarily by the signer." The wording balances Junio’s preference for brevity with the need to warn users about the limitation, and the patch is now finalized and ready for integration. No new technical issues are raised; this email simply closes the discussion on the documentation wording. The separate revocation file security fix (which makes missing or unreadable revocation files fatal by default) remains technically complete and awaiting integration.
