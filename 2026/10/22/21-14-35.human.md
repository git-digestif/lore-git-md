This is Junio’s biweekly "What’s cooking in git.git" report for October 2026, summarizing the state of over 100 in-flight topics. The most striking news is the maintainer’s warning: the integration pipeline is severely overloaded, with only 30 of the 100 topics in or near `next` and the rest languishing in `seen`. Junio is considering aggressive pruning of stalled topics unless contributors respond promptly to review feedback.

### Graduated to `master` (irreversibly part of the next release)

- Unicode 18 width tables (bb/unicode-width-table-18)
- `uploadpack.lazyFetchTrusted` config to allow lazy-fetching from promisor remotes on trusted repos (cc/lazy-fetch-trusted-bit)
- Deferred validation of `fetch.followRemoteHEAD` (ch/fetch-followremotehead-lazy-validation)
- CI leak sanitizer annotations and immediate failure on first leak (hn/ci-leak-sanitizer-annotations)
- Fixed flaky GPG test in t7004 (hn/t7004-flaky-gpg-test-fix)
- `git status` now suggests `git merge --continue` instead of `git commit` (je/status-merge-specific-help)
- Optimized `fetch.writeCommitGraph` to update only newly fetched commits (kk/fetch-write-commit-graph-incremental)
- Packed-refs verbatim write optimization (kn/packed-refs-verbatim-write)
- Delta-islands pluralization fix (oa/delta-islands-i18n-use-q)
- ODB alternates refactoring (ps/odb-files-alternates)
- Fixed stale delta-base cache corruption (ps/packfile-stale-delta-base-cache-fix)
- Conflict labels preserved across `git checkout -m` (pw/checkout-m-conflict-labels)
- `git history` and `git replay` now sign rewritten commits (ss/history-sign-rewrites)

### New topics (just merged to `next` or about to graduate)

- Two small bugfixes from Olof Fairbrook: one plugs an uninitialized-memory read in `git bundle create` (of/bundle-uninitialized-memory-fix), the other fixes config blob parsing to treat bytes as unsigned (of/config-buf-fgetc-unsigned).
- `git fsck` verbose message pluralization (ag/fsck-connectivity-msg-i18n) and later a follow-up to report the true object count (ag/fsck-connectivity-count).
- `git init` now shows the absolute path of the created repository (mh/init-show-abspath).

### Notable stalled or controversial topics

- **SHA-1/SHA-256 interop (cc/pack-index-v3)**: 13-patch series implementing pack index v3 for dual-hash mapping. Junio’s review flagged correctness concerns; no response yet.
- **Object storage extension (ps/odb-object-storage-extension)**: Introduces `extensions.objectStorage` to configure ODB backends. Patrick Steinhardt’s review highlighted design questions around the payload format; the series is waiting for clarification.
- **Incremental connectivity check (kk/connectivity-check-incremental)**: Adds `transfer.connectivityCheck=incremental` to speed up fetches by comparing trees instead of walking full object closures. Taylor Blau’s review identified edge cases; a reroll is expected.
- **Refspec matching speedup (js/push-refspec-match-speedup)**: Replaces linear refspec traversal with string maps. Junio’s review noted potential regressions for duplicate destinations; the author has not yet addressed them.
- **Rust crate reorganization (mh/rust-crate-subdir)**: Moves Rust code into a dedicated `rust/` subdirectory. No review yet; the change is purely mechanical but touches build infrastructure.

### Documentation & usability

- New beginner tutorial (je/doc-new-git-tutorial) and a dedicated merge-conflicts guide (je/doc-merge-conflicts) are both in need of rerolls after community feedback.
- `git status` now compares against both upstream and push branches by default (hn/status-compare-branches-default), a usability win for triangular workflows.

### Performance & correctness

- **Shallow fetch speedup (hn/fetch-shallow-v2-fix)**: Fixes a severe performance regression in protocol v2 shallow fetches by sending all shallow roots upfront.
- **ODB alternates reload (ps/odb-reload-alternates)**: Restores the ability to find objects moved to newly added alternates during concurrent repository rewrites.
- **Index lock timeout (jw/wait-for-index-lock)**: Introduces `core.indexLockTimeout` to allow commands to retry when the index is locked, fixing write races in `git commit` and `git reset`.

### CI & build system

- GitLab CI whitespace jobs now disable shallow clones to avoid failures on large MRs (ps/gitlab-ci-whitespace-job-shallow-clone-fix).
- macOS CI updated to use macos-15 runners (jc/ci-update-macos-15).

### What to watch

- The **ODB abstraction** and **reftable** efforts continue to generate follow-up work (e.g., ps/odb-files-alternates-cleanups, mc/refs-rename-transaction).
- **Rustification** remains contentious; the NonStop port maintainer (Randall S. Becker) has reiterated concerns about platform support.
- **`the_repository` removal** is still active, with recent patches touching merge-blobs (oa/merge-without-the-repository) and the merge subsystem (oa/merge-without-the-repository).

### Actionable takeaways

- If you have a topic in `seen` that hasn’t seen activity in weeks, expect it to be dropped soon unless you respond to review comments.
- The **SHA-256 interop** and **object storage extension** series are high-impact but need author engagement to move forward.
- The **incremental connectivity check** and **shallow fetch fix** are worth testing if you work with large or shallow repositories.
