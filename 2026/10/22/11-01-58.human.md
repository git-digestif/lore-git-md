This is the second patch in a two-patch series targeting test infrastructure, specifically the `clar`-based unit test runner. It adds `-l`/`--long-tests` as a NOOP command-line argument to maintain compatibility with Meson's test runner, which forwards the flag when users run `meson test --test-args='-ilx'`.

The change is minimal—just one line added to `t/unit-tests/unit-test.c`—and follows the established pattern introduced in commit 9faf3963b6 for ignoring unrecognized flags. The motivation is practical: without this patch, the unit test binary fails when Meson passes `-l`, preventing tests from running at all. The fix ensures the flag is silently ignored, restoring expected behavior without altering test logic. This is part of the ongoing test modernization effort to adopt the `clar` framework.

The patch is well-scoped and unlikely to be controversial. It addresses a clear usability issue in the test infrastructure, and CI results confirm it doesn’t break existing functionality. The series as a whole (including the preparatory reordering patch) is under review, with no prior versions or open questions raised so far.
