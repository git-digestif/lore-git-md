This is a **Git for Windows security release announcement**.

Johannes Schindelin announces Git for Windows 2.56.0(3), a security-focused update addressing two issues: the eMudhra Intermediate CA compromise and Git LFS CVE-2026-105803 (resolved by upgrading Git LFS to v3.8.1). The release also bumps bundled dependencies: OpenSSH to v10.6.P1 and cURL to v8.23.0. No changes to Git itself are mentioned—this is purely a packaging update to mitigate security risks in the bundled toolchain.

The email provides download links for all variants (64-bit and 32-bit installers, portable builds, MinGit, and busybox-based MinGit) along with SHA-256 checksums for verification. This is the third build in the 2.56.0 series, following the October 5th 2.56.0(2) release.

No upstream Git patches are involved; the announcement is specific to the Git for Windows fork. The security fixes target the Windows distribution’s bundled components rather than Git’s core code.
