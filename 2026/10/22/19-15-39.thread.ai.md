Git for Windows security release: Johannes Schindelin announced Git for Windows 2.56.0(3), a security-focused packaging update addressing two issues: the eMudhra Intermediate CA compromise and Git LFS CVE-2026-105803 (resolved by upgrading Git LFS to v3.8.1). The release also updates bundled dependencies: OpenSSH to v10.6.P1 and cURL to v8.23.0. This is the third build in the 2.56.0 series, following 2.56.0(2) released on 2026-10-05. No changes to upstream Git are involved; the announcement is specific to the Git for Windows fork, targeting security risks in bundled components rather than Git’s core code. Download links and SHA-256 checksums for all variants (64-bit/32-bit installers, portable builds, MinGit, and busybox-based MinGit) are provided.
