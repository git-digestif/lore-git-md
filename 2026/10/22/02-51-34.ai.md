This is the first patch in a two-patch bugfix series targeting the branch and checkout subsystems. It refactors `setup_tracking()` in `branch.c` to return an error instead of calling `exit(1)` when it cannot write the tracking configuration, and updates its callers (`create_branch()` and `dwim_and_setup_tracking()`) to propagate that error. The patch does not change behavior yet—callers still exit with status 1 on failure—but prepares the ground for the second patch, which will make `git switch -c` and `git checkout -b` ignore tracking failures and complete the branch switch.

The refactoring is mechanical and well-contained, touching only `branch.c`, `branch.h`, `builtin/branch.c`, and `builtin/checkout.c`. The commit message is clear, and the patch itself is clean, with no functional changes in this step. This is a necessary precursor to the behavior change in patch 2/2, and the separation of refactoring from behavior change follows Junio’s earlier request.
