This is a small test infrastructure patch. Kaartic Sivaraam fixes a minor but annoying usability issue in Git’s `clar`-based unit tests: when running `meson test -v --test-args='-ilx'`, the `-l` (long-tests) flag is passed to the unit-test binary, which does not recognize it and fails with an “unknown switch” error.

The fix is straightforward: the patch adds `-l` and `--long-tests` to the list of NOOP arguments that the unit-test harness already ignores, following the pattern established in commit 9faf3963b6 (t: introduce compatibility options to clar-based tests, 2024-12-13). The change is contained to a single line in `t/unit-tests/unit-test.c`, and the author includes a small reshuffle of the NOOP list to keep the arguments in a logical order.

CI pipelines on GitHub and GitLab both pass, confirming the fix works without breaking anything else. The motivation is clear, the solution is minimal, and the patch is well-explained. This looks like a clean, uncontroversial improvement that should be easy to merge.
