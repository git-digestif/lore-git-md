This is a refactoring patch in the log subsystem, part of a four-patch series by Miklos Vajna. The patch extracts the logic that displays remerge or combined diffs for merge commits into a new helper function, `log_tree_merge_diff()`, to avoid code duplication. The change is mechanical and preparatory: no behavior is altered, but the extracted function will be reused in the next patch in the series.

The patch touches only `log-tree.c`, moving about 20 lines of conditional logic into a separate function. The new helper handles both the `--remerge-diff` and `--cc` (combined diff) cases, including the existing warning when remerge-diff is requested for octopus merges. The commit message is clear and concise, explaining the purpose without overpromising. The code itself is straightforward and follows Git’s style.
