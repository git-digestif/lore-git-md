This is Junio C Hamano ejecting Igor Wiedler’s second patch from the `seen` branch due to a Windows CI failure in its new test. The test, which verifies that refs from a shallow alternate are ignored, uses `"file://$TRASH_DIRECTORY"` to create a shallow clone, but the path format breaks on Windows. The failure is mechanical (path normalization) rather than a design flaw, and Jeff King (Peff) has already proposed two backward-compatible fixes in the thread: either replace `$TRASH_DIRECTORY` with `$(pwd)` or rewrite the test more idiomatically using environment variables and `--no-local`. No technical objections to the patch itself have been raised; the ejection is purely procedural until the test is fixed.

The patch remains a well-motivated, targeted fix addressing the root cause of the performance regression in connectivity checks for deepening fetches. It extends `odb_for_each_alternate_ref()` to ignore refs from shallow or grafted alternates, aligning with Junio’s earlier design feedback. The change is backward-compatible and includes a thorough test and documentation update. The only loose end is the deferred partial-clone (promisor remote) edge case, which the commit message explicitly punts as future work. Approvals from Patrick Steinhardt and Justin Tobler carry forward for the core regression fix (patch 1), but neither has reviewed this expanded scope. Junio’s ejection does not reflect dissatisfaction with the patch’s substance—only the test’s portability.
