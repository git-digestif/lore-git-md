Core problem or goal
Eliminate the implicit use of the global `the_repository` variable in `prune_packed_objects()` by converting it to accept an explicit `struct repository *` parameter. This is a step in the ongoing project-wide effort to remove all uses of `the_repository` for better modularity and libification.

Current status
Under review; no prior versions posted. The patch is mechanically sound and the substantive question about `NULL` `repo` handling has been resolved by the author: the calling commands (`git prune-packed`, `git prune`, `git repack`) are all registered with `RUN_SETUP` in `git.c`, ensuring `repo` is never `NULL`. The remaining feedback is surface-level (commit message phrasing, sign-off name).
