This is a build system patch targeting the Rust integration in Git. Andy Koppe fixes a Makefile bug where the build fails if the user has a custom Cargo target directory (set via `~/.cargo/config.toml` or `CARGO_TARGET_DIR`). The patch pins the target directory to `./target` explicitly in the Cargo build commands, matching the behavior already present in the Meson build system.

The change is minimal—just two lines in the Makefile—and clearly motivated: without it, the build breaks when Cargo’s default target directory is overridden. The commit message explains the problem, the fix, and why the `contrib/libgit-{sys,rs}` targets are left untouched. This looks like a straightforward, well-scoped bugfix that should resolve a real-world build issue for users with custom Cargo configurations.
