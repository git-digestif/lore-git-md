This is a build system patch targeting the Rust integration in Git. Andy Koppe fixes a Makefile bug where the build fails if the user has a custom Cargo target directory (set via `~/.cargo/config.toml` or `CARGO_TARGET_DIR`). The patch pins the target directory to `./target` by explicitly passing `--target-dir target` to Cargo commands, ensuring the `gitcore` library is found during linking. The change is minimal—two lines in the Makefile—and aligns the Make build with the existing Meson build behavior. No changes are made to the `contrib/libgit-{sys,rs}` targets, as their output location isn’t critical.

The issue is well-motivated: users with non-default Cargo configurations would hit a link error, and the fix is straightforward. The patch is narrowly scoped to the Rust build rules, avoiding broader Makefile churn. Key details for follow-up discussion: the `--target-dir` flag, the `RUST_LIB` and `RUST_MEMBER_LIBS` targets, and the `CARGO_ARGS` variable. The patch doesn’t touch platform-specific logic or introduce new dependencies.
