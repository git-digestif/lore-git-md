This is an Outreachy microproject proposal from a new contributor. The author, Keryle, is asking whether anyone else is already working on refactoring `archive-zip.c` to use Git’s `Q_()` pluralization macro for the "path too long" error message. The message in question currently hard-codes the singular form, which could be grammatically awkward when the length is 1.

The patch itself has not been sent yet—this email is a pre-submission check to avoid duplicate work. The microproject is a well-defined, self-contained task suitable for a newcomer: it touches only one file, requires no deep subsystem knowledge, and follows a common Git idiom (`Q_()` is already used elsewhere in the codebase). If no one else is working on it, Keryle plans to proceed with the change.
