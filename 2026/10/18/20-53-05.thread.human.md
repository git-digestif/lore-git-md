This thread is about a small but important fix to Git’s Rust build system. Andy Koppe identified a bug in the Makefile where builds would fail if the user had a custom Cargo target directory (set in `~/.cargo/config.toml` or via `CARGO_TARGET_DIR`). The patch ensures the build always uses `./target` by explicitly passing `--target-dir target` to Cargo, matching the behavior of the Meson build. The change is minimal—just two lines in the Makefile—and only affects the Rust integration, leaving other build targets untouched.

The issue is practical: users with non-default Cargo setups would hit a link error, and the fix is straightforward. No broader Makefile changes or new dependencies are introduced. The patch has not yet received review, so its status is still under discussion. If you’re using Git’s Rust features, this is a small but necessary fix to keep builds working reliably.
