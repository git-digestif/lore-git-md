This thread is about a bugfix for `git bundle create` that plugs a memory safety hole. Olof Fairbrook found that passing an unrecognized argument to the command could cause it to free uninitialized stack memory, a regression introduced in mid-2024. The fix is tiny—just one line in `bundle.c` to initialize a struct—and comes with a new test that exercises the error path cleanly. The patch is straightforward, cites the problematic commit, and explains the symptoms (valgrind warnings or crashes). So far there’s no discussion or pushback; it looks like a clean, uncontroversial fix ready for review.
