This is a test modernization patch from an Outreachy applicant. The patch modifies `t/t0001-init.sh` to avoid piping the output of `git version --build-options` directly into `sed`. Instead, it first redirects the output to a temporary file (`build-options`), then processes that file with `sed`. This change ensures that if `git version` fails, the test script will catch the failure rather than silently proceeding with an empty or partial input to `sed`.

The motivation is a long-standing test suite best practice: pipes (`|`) in shell scripts mask the exit status of the left-hand command, which can hide failures. The patch follows the established pattern of breaking pipes into separate commands with intermediate files or variables. The change is minimal (one line) and touches only the test script, not production code.
