This is a documentation patch proposal. A first-time contributor suggests a small but helpful clarification to the help text of `git remote add`. The current usage line (`git remote add [<options>] <name> <url>`) does not explain what `<name>` means or why `origin` is commonly used. The patch would add a two-line note under the synopsis that explains `origin` is the default name set by `git clone` but that any name can be chosen. The change is purely additive, does not alter behavior, and is motivated by a desire to make Git more approachable for beginners. The proposal is well-explained and narrowly scoped; it looks like a sensible, uncontroversial improvement.
