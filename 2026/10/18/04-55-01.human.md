This is a small test modernization patch from an Outreachy applicant. The patch updates `t/t0001-init.sh` to avoid piping the output of `git version --build-options` directly into `sed`. Instead, it first redirects the output to a temporary file (`build-options`), then processes that file with `sed`. This change ensures that if `git version` fails, the test script will catch the error rather than silently proceeding with an empty or partial input to `sed`.

The motivation is sound: Git’s test scripts are written in shell, and pipes suppress the exit status of the left-hand command by default. Breaking the pipe into separate steps with intermediate files makes the test more robust. The patch is minimal—only one line changed—and follows the established pattern seen elsewhere in the test suite.
