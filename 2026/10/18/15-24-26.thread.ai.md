Subject: [PATCH] config: fix misinterpretation of high-bit bytes in in-memory config
Series version: standalone patch
Originating author: Olof Fairbrook
Thread type: bugfix patch

Core problem or goal
Fix a long-standing (since 2013) bug in the config subsystem where `git config --blob` and other in-memory config readers misinterpret bytes with the high bit set (0x80–0xff) when `char` is signed (e.g., x86). The bug causes two symptoms: (1) a 0xff byte is treated as EOF, truncating the config blob, and (2) UTF-8 byte order marks trigger spurious "bad config line" errors. The fix ensures consistent behavior between in-memory and file-based config reading.
