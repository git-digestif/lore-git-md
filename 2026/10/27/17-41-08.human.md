This is the seventh patch in Jeff King’s eight-patch series refactoring Git’s unit test infrastructure. It removes the `test-tool run-command testsuite` mode, a legacy helper that let Visual Studio users run the test suite without `make` or `prove`. The commit message notes that the last in-tree caller was removed in an earlier patch, and Azure Pipelines support (another historical user) was dropped in January 2025. Peff marks this patch as RFC, asking whether the Visual Studio use case is still relevant; if it is, this patch should be dropped or reverted. The change deletes 173 lines from `t/helper/test-run-command.c`, leaving no functional code behind. The series as a whole is otherwise ready for integration, so this patch’s fate hinges on whether anyone still relies on the removed functionality.
