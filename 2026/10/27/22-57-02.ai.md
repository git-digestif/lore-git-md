This is Junio’s reply to Mike Hommey’s `v5` patch moving Git’s Rust code into a `rust/` subdirectory. The patch itself is technically complete and addresses all prior feedback, but Junio is now questioning whether the project actually wants to proceed with the reorganization at all.

Junio notes that the patch has sat idle for over a month with no new comments or updates, and that—other than Mike—nobody has shown strong enthusiasm for the change. He ties this lack of momentum to the unresolved discussion about how to handle Git 3.0’s mandatory Rust components and their impact on downstream projects that vendor Git’s C code while excluding its Rust components. While Mike’s proposed solution (publishing the `gitcore` crate to crates.io) remains on the table, Junio implies that the broader uncertainty about the post-3.0 landscape may be dampening interest in the reorganization itself.

The patch is still queued for `next`, but Junio’s tone suggests he is now leaning toward dropping it unless someone steps forward to advocate for it. No technical issues remain; this is purely a question of project appetite.
