This thread is about Jeff King’s (Peff) eight-patch series to refactor Git’s unit test infrastructure, making it easier to debug test failures in CI by integrating `clar`-based unit tests with the shell test suite. The series is under active review, with the first six patches now looking ready for integration.

The latest update is the third patch, which fixes a bug in the JUnit XML reporting code. Previously, empty test suites (like those that skip all tests) would cause shell errors because the code tried to call a function that had already been removed. Peff’s fix removes the problematic fallback logic, leaving JUnit XML output empty for such suites. This change is small, targeted, and unblocks later patches in the series, including the eventual removal of JUnit support entirely (in patch 8, which remains marked as RFC). The fix also aligns with the broader goal of unifying test execution environments.

So far, the series has been uncontroversial, with no objections raised. The first two patches were cleanups with no behavioral side effects, and patches 3–6 appear stable. The last two patches (7–8) are still marked as RFC, indicating they may need further discussion. The series is self-contained and doesn’t depend on or conflict with other in-flight work. If the current pace holds, the first six patches could be merged soon, while the final two may require additional feedback.
