Thread identity: Refactoring of Git's unit test infrastructure to integrate `clar`-based unit tests with the shell test suite, improving debuggability and removing obsolete code. Series authored by Jeff King (Peff), currently at version 1.

Core problem or goal: Unit test failures in CI are difficult to debug because their TAP output is suppressed by `prove`, unlike the shell-based test suite which provides verbose logs. The series aims to unify the execution environment, leak detection, and logging for unit tests by wrapping them in `test-lib.sh`, while also cleaning up redundant or deprecated test infrastructure. A minor usability bug in the `unit-test.c` driver (incorrect error message for unexpected arguments) was fixed in the first patch.

Current status: Under review. The series consists of 8 patches. Patches 1-6 are ready for integration, with patches 1-5 previously noted as ready and patch 6 removing redundant unit test invocations and obsolete infrastructure. Patch 7 removes the `test-tool run-command testsuite` mode, a legacy helper used to run unit tests before the unified wrapper script (`t/t0011-unit-tests.sh`) was introduced. Patch 8 (this update) removes the shell-based JUnit XML reporting code (`test-xml-encode` binary and `test-lib-junit.sh` script), which was previously used for Azure Pipelines but is now obsolete since Azure Pipelines support was removed in early 2025 and GitLab CI relies on Meson’s built-in JUnit reporting. No maintainer decision or merge status has been reported.

Key technical details:
- **Files touched**: `t/test-lib.sh` (core integration logic, cleanup, removal of `--write-junit-xml` option and JUnit-specific hooks), `t/Makefile` (build rules), `t/meson.build` (build dependencies), `t/t0011-unit-tests.sh` (wrapper script for unit tests), `t/unit-tests/unit-test.c` (bugfix in error message handling), `ci/run-test-slice.sh` (CI test slice logic), `t/helper/test-run-command.c` (removed `testsuite` subcommand), **`t/helper/test-xml-encode.c`** (removed), and **`t/test-lib-junit.sh`** (removed).
- **New behavior**: Unit tests now run under `test-lib.sh` via the wrapper script `t/t0011-unit-tests.sh`, inheriting its environment setup, leak detection (e.g., `LSAN_OPTIONS`), and logging capabilities. The wrapper forwards relevant options like `--immediate` to the unit test binary but omits support for `--run` (due to syntax differences) and `--write-junit-xml` (unsupported by unit tests). TAP output from external programs (e.g., `clar` unit tests) is accepted by `test-lib.sh` via the `test_external` variable, which suppresses the TAP header and plan count while preserving skipped-test accounting. The `unit-test.c` driver correctly reports unexpected arguments in error messages. The CI and build systems now invoke unit tests only once, via the wrapper script, eliminating redundant runs.
- **Removed infrastructure**: Shell-based JUnit XML reporting code (`test-xml-encode` binary and `test-lib-junit.sh` script, removed in patch 8), deprecated `test-tool run-command testsuite` mode (removed in patch 7), redundant test invocations (removed in patch 6), the `run-test.sh` wrapper script (removed in patch 6), the `UNIT_TESTS_NO_DIR` variable (removed in patch 6), the `unit-tests-test-tool` target (removed in patch 6), and the now-unused variable `test_external_has_tap` (removed in patch 2). Patch 3 removes the problematic fallback logic for empty JUnit XML suites. The `start_test_case_output` and `finalize_test_output` hooks in `test-lib.sh` are preserved for potential future use.
- **Net effect**: ~827 lines of code deleted (173 added in patch 7), improved debuggability for unit test failures in CI, a minor usability fix in the unit test driver, elimination of redundant test runs, and removal of obsolete infrastructure. Key symbols removed: `test-xml-encode` binary, `test-lib-junit.sh`, `--write-junit-xml` option, `xml-encode` subcommand in `test-tool`, `testsuite` subcommand in `test-tool run-command`, `UNIT_TESTS_NO_DIR` variable, `unit-tests-test-tool` target, and `run-test.sh` wrapper script.
- **Symbols**: New wrapper script `t/t0011-unit-tests.sh`; new binary path variable `UNIT_TESTS`; modified functions in `test-lib.sh` to handle TAP output from external programs (via `test_external`); corrected error message in `unit-test.c`; preserved hooks `start_test_case_output` and `finalize_test_output` in `test-lib.sh`.
