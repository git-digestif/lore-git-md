Thread identity: Refactoring of Git's unit test infrastructure to integrate `clar`-based unit tests with the shell test suite, improving debuggability and removing obsolete code. Series authored by Jeff King (Peff), currently at version 1 (implied by absence of `v2`+ markers).

Core problem or goal: Unit test failures in CI are difficult to debug because their TAP output is suppressed by `prove`, unlike the shell-based test suite which provides verbose logs. The series aims to unify the execution environment, leak detection, and logging for unit tests by wrapping them in `test-lib.sh`, while also cleaning up redundant or deprecated test infrastructure. Additionally, a minor usability bug in the `unit-test.c` driver (incorrect error message for unexpected arguments) is fixed in the first patch.

Current status: Under review. The series consists of 8 patches, with patches 1-3 now appearing ready for integration (patches 1-2 were previously noted as ready; patch 3 fixes a bug in JUnit XML reporting for empty test suites). Patches 4-6 also appear ready, while the last 2 (patches 7-8) remain marked as RFC by the author, indicating they may require further discussion. No maintainer decision or merge status has been reported.

Key technical details:
- **Files touched**: `t/test-lib.sh` (core integration logic and cleanup), `t/Makefile` (build rules), `t/t0011-unit-tests.sh` (new wrapper script for unit tests), `t/unit-tests/unit-test.c` (bugfix in error message handling), `t/test-lib-junit.sh` (bugfix for empty test suites).
- **New behavior**: Unit tests now run under `test-lib.sh`, inheriting its environment setup, leak detection, and logging capabilities. Empty test suites no longer trigger shell errors in JUnit XML reporting.

Patch 3 removes the problematic fallback logic for empty JUnit XML suites.
- **Net effect**: ~407 lines of code deleted (updated from ~400), improved debuggability for unit test failures in CI, a minor usability fix in the unit test driver, and elimination of a CI annoyance (empty test suites causing misleading errors).
