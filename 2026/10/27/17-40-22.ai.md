This is the sixth patch in Jeff King’s (Peff) 8-patch series refactoring Git’s unit test infrastructure. The series as a whole integrates `clar`-based unit tests with the shell test suite to improve debuggability and remove obsolete code, and this patch eliminates redundant unit test invocations now that the new wrapper script (`t/t0011-unit-tests.sh`) runs them through `test-lib.sh`.

The patch removes the separate Meson test entry for unit tests and the extra invocation in the first CI test slice, which previously caused unit tests to run twice. It also stops passing unit test binaries to `prove` alongside shell tests, simplifying the `prove` invocation to use `TEST_SHELL_PATH` directly and pass `GIT_TEST_OPTS` via `prove`’s `::` separator. This change removes the now-unused `run-test.sh` wrapper script and the `UNIT_TESTS_NO_DIR` variable, which supplied arguments for the deprecated `unit-tests-test-tool` target. The patch deletes 34 lines across four files (`ci/run-test-slice.sh`, `t/Makefile`, `t/meson.build`, and `t/run-test.sh`), leaving the direct `make unit-tests` target intact for manual runs.

The change is a straightforward cleanup that aligns with the series’ goal of unifying test execution. It has no behavioral impact on test outcomes, only removing redundancy and obsolete infrastructure. The patch is uncontroversial and appears ready for integration, though Peff has marked the series’ final two patches as RFC, indicating they may still need discussion. Key symbols removed include `UNIT_TESTS_NO_DIR`, `unit-tests-test-tool`, and `run-test.sh`.
