This is a small feature addition for `gitk`, the graphical history browser. The patch itself was already well-scoped and uncontroversial: it adds a "Cherry-pick with cross-reference" context-menu item that invokes `git cherry-pick -x`, appending the original commit hash to the new commit message for traceability in backporting workflows.

Johannes Sixt (Hannes), the current `gitk` maintainer, has now picked up the patch and pushed it to a public branch (`rh/cherry-pick-x`) on his GitHub fork for wider testing. He reiterates that the patch text itself looks good, but wants to hear from more users or contributors before merging it. This is a routine step for `gitk` changes—since the tool is optional and has a smaller user base than the core Git commands, maintainers often seek explicit confirmation that a new feature is genuinely useful rather than just "not harmful." No technical objections have been raised so far, and the patch remains confined to the Tcl/Tk code with no side effects on the rest of Git.
