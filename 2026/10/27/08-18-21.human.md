This is the first patch in Patrick Steinhardt’s eight-part CI/build system series consolidating test environment variables. It mechanically moves environment variable setup from `ci/run-build-and-tests.sh` into `ci/lib.sh`, eliminating the split that forced contributors to check two files to understand a job’s configuration. The patch is a pure refactoring—no behavior changes—though it introduces temporary duplication that later patches will clean up. The commit message is clear and the diff is straightforward, making this a low-risk but foundational step toward the series’ goal of reducing CI drift between GitHub Actions and GitLab CI.
