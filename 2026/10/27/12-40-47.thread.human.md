This thread is about a small but practical build-system tweak: enabling ccache to cache objects built with Git’s precompiled header (PCH). Harald Nordgren’s patch adds two ccache “sloppiness” flags to the Makefile, which should speed up rebuilds and branch switches by 3–6× once the cache warms up. The change is minimal—just two lines—but Ben Knoble’s review raised questions about whether the Makefile’s target-specific export of `CCACHE_SLOPPINESS` will work as intended and whether the Meson build should get the same treatment.

Harald’s follow-up clarifies that he sees this as a local optimization for the Makefile, not a cross-build-system fix, and he’s open to moving the variable assignment directly into the PCH recipes instead of using an export. That leaves the implementation details still open, though the core idea—letting ccache cache PCH builds—hasn’t been challenged. The thread is still under review, with no new patch version posted yet.
