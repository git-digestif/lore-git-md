This thread began with Harald Nordgren’s patch to enable ccache caching for Git’s precompiled header by setting two ccache “sloppiness” flags in the Makefile. The patch, now at v2, is a minimal one-line change that resolves a performance regression on rebuilds and branch switches—delivering a 3× speedup for warm-cache rebuilds and 6× for branch switching, at the cost of a roughly 25 % slowdown on the first build of each branch while ccache fills its cache.

The discussion initially raised two concerns: whether the Makefile’s target-specific export of `CCACHE_SLOPPINESS` would propagate correctly (resolved in v2 by moving the export outside target-specific rules), and whether the Meson build system should receive the same treatment. Patrick Steinhardt suggested the feature belonged upstream in Meson rather than in Git’s build scripts, and Harald accepted that approach. That upstream work is now complete: Meson pull request #16317 has merged, automatically enabling the same ccache sloppiness flags for precompiled headers. With both build systems now handling the issue consistently, the thread is effectively closed—no further changes to Git’s build system are needed.
