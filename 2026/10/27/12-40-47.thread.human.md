This thread is about a small but practical build-system patch by Harald Nordgren that enables ccache to cache objects built with Git’s precompiled header (PCH), introduced in an earlier commit. The patch adds two ccache "sloppiness" flags to the Makefile, which should speed up rebuilds and branch switches by about 3–6× once the cache warms up, at a modest cost to first-build time.

The patch itself is uncontroversial—no one disputes that the change is safe or that it improves performance—but two implementation questions remain open. First, Ben Knoble raised a technical concern about whether the Makefile’s target-specific export of `CCACHE_SLOPPINESS` will actually propagate to recipe processes as intended; Harald acknowledged the question but hasn’t revised the patch. Second, the patch leaves the Meson build system untouched, which could create inconsistency for users who switch between build tools. Ben briefly noted that it would be "nice" to address Meson as well, but he disclaimed expertise and stepped back, so the question of build-system parity is still unresolved.

Harald has framed the patch narrowly, focusing only on the Makefile, and no other reviewers have weighed in on either the Makefile semantics or the Meson omission. The thread is still under review, with no prior versions posted and no indication that Junio has picked it up yet.
