This is the second patch in Patrick Steinhardt’s 12-patch refactoring series that modernizes `git rerere`’s subcommand handling. It converts the existing integer bit-flags (`RERERE_AUTOUPDATE`, `RERERE_NOAUTOUPDATE`, etc.) into a proper C enum (`enum rerere_flags`). The change is purely mechanical: the flag values remain the same, but callers now see the expected type in function signatures, making the API more self-documenting and consistent with Git’s coding guidelines. Only `rerere.h` and `rerere.c` are touched; no behavior changes or new functionality are introduced. The patch is a small, uncontroversial step toward the series’ overall goal of aligning `git rerere` with Git’s standard subcommand-parsing conventions.
