This is a mechanical refactoring that prepares for the next patch, which will reuse this logic to implement dynamic branch enumeration for `remote.<name>.fetchRefmap`.

The helper takes a `struct repository *` parameter (following the `the_repository` removal effort), the remote, an optional refname (NULL means the current branch), and a `strvec` to populate with upstream refs. The logic remains unchanged: it checks if the branch has merge config and if its remote matches, then pushes the upstream refs into the `strvec`.
