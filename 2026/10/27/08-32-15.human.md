This is the first patch in Harald Nordgren’s v4 CI cleanup series. It removes a long-obsolete `xattr -d com.apple.quarantine` call that has been a no-op since 2022, when the macOS Perforce install method switched from Homebrew to direct `wget`. The commit message now leads with the key observation: the attribute is never set by `wget` (or `curl`) on either GitHub Actions or GitLab CI runners, so the call does nothing and can be dropped. This is a pure cleanup with no functional change—just one line deleted from `ci/install-dependencies.sh`. Junio and Patrick have already accepted the technical change in principle and only asked for minor commit-message polish, which this version delivers. The patch is unblocked and ready for a final positive review (Reviewed-by or Acked-by) from someone other than Junio or Patrick.
