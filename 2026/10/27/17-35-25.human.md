This is the third patch in Jeff King’s 8-patch series refactoring Git’s unit test infrastructure. It fixes a bug in the shell-based JUnit XML reporting code: when a test script skips all tests (e.g., `t0051-windows-named-pipe.sh` on Linux), the code tries to call a function (`write_junit_xml_testcase`) that was removed in an earlier refactoring, causing a shell error. The patch removes the fallback logic that attempted to invent a "all tests skipped" test case, leaving the JUnit suite empty for skipped scripts instead.

The fix is minimal and uncontroversial, addressing a clear regression introduced by the earlier refactoring. It also paves the way for scripts that delegate TAP output to external programs (like the unit test integration in later patches), where inventing fake JUnit results isn’t feasible. The commit message explains the problem, the solution, and the rationale clearly, and the patch itself is a straightforward deletion of the problematic code. This patch appears ready for integration, aligning with the broader goal of cleaning up obsolete test infrastructure while improving debuggability.
