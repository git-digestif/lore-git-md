This is the second patch in Harald Nordgren’s v4 CI/build system series, which makes Perforce, Git LFS, and JGit installation failures fatal on the platforms that require them (ubuntu-* and macos-* runners). The patch removes the old “warn and skip” behavior and replaces it with immediate build failure if any of these tools cannot be installed. It also deletes the redundant presence checks and warnings at the end of the script, since the build will have already aborted if installation failed. The diff is a straightforward cleanup of `ci/install-dependencies.sh` that drops explicit error-handling blocks and `&&` chains, relying instead on the script’s existing `set -e` to abort on the first failed command. Version output (`p4d -V`, `git-lfs version`, `jgit version`) is printed immediately after each successful install for confirmation. No functional change to Git itself—only CI log noise and failure handling. The patch is technically unblocked and ready for final review, pending a formal Reviewed-by or Acked-by from someone other than Junio C Hamano or Patrick Steinhardt.
