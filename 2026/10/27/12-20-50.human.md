This is a surface-level review from Christian Couder on the second patch in Patrick Steinhardt’s six-patch v2 series, which restores dynamic reloading of alternate object databases in the files-based ODB backend. The patch itself is a minimal, uncontroversial fix that enforces a key design change: alternates are now always reloaded from the repository’s real object directory rather than the current primary directory, which may be a quarantine directory. This resolves a behavioral regression in `git receive-pack` where objects moved to an alternate since the quarantine was created were not found.

Christian’s feedback is purely cosmetic, suggesting two minor wording tweaks in the commit message: adding quotes around "files" to match a later reference ("the 'files' source") and removing an unnecessary plural ("objects/info/alternates" -> "object/info/alternates"). Neither change affects the patch’s correctness or design. The feedback is actionable but trivial, and the patch itself remains well-motivated and narrowly scoped. This looks like a clean fix that should proceed without further discussion.
