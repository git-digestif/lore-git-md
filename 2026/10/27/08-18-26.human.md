This is a CI/build system patch, the sixth in Patrick Steinhardt’s eight-patch series consolidating Git’s CI test environment variables. It restores test coverage for non-Rust builds by adding a second `NO_RUST` job that uses glibc instead of musl. The change is a single-line edit to `ci/lib.sh` that disables Rust in the existing `linux-asan-ubsan` job, chosen because it already runs with AddressSanitizer and UndefinedBehaviorSanitizer—tools that are more valuable when testing C code than Rust, which is memory-safe by design. The patch is a direct follow-up to the Rust-by-default merge (32d5b90590, April 2026) and fits the series’ goal of ensuring consistent, maintainable test coverage across CI platforms. It looks like a small but deliberate step toward balancing Rust and non-Rust testing without adding new jobs.
