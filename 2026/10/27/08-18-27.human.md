This is a CI/build system cleanup patch, the seventh in Patrick Steinhardt’s eight-patch series consolidating Git’s CI test environment variables. It removes a single redundant line in `ci/lib.sh` that overrides `GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME` to "master" in the `linux-feature-testbed` job. The override is unnecessary because the initial branch name is already set globally via the `WITH_BREAKING_CHANGES` toggle, which selects either "main" or "master" depending on whether breaking changes are enabled. The change is purely mechanical—no behavior is altered, and the patch is uncontroversial.

The patch is part of the broader effort to eliminate duplication and improve maintainability in Git’s CI infrastructure. Earlier patches in the series centralized environment variable overrides using pattern matching, and this one continues that theme by removing a now-superfluous setting. The `linux-feature-testbed` job remains focused on testing experimental features (e.g., commit-graph changed paths, multi-pack index), and the removal of the override aligns it with the project’s default branch naming convention.

This is a minor but logical follow-up to the series’ goal of reducing drift between CI platforms.
