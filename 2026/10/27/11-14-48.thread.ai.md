Core problem or goal
Replace manual `strcmp()`-based command-line parsing in `t/helper/test-chmtime.c` with Git’s standard `parse_options()` API. The change is purely internal to the test helper and introduces no user-visible behavior change, except for three intentional behavioral differences: making `--verbose` and `--get` mutually exclusive via `die_for_incompatible_opt2()`, standardizing usage-error exit codes to 129, and rejecting `--get` after a timespec rather than silently ignoring it.

Key technical details
- File: `t/helper/test-chmtime.c`
- New symbols: none (internal refactoring only)
- Behavior: unchanged except for (1) `--verbose` and `--get` now incompatible via `die_for_incompatible_opt2()` (exits 128), (2) exit code for usage errors standardized to 129, (3) `--get` after a timespec now triggers usage error instead of silently ignoring the timespec

- Build integration: updated `t/meson.build` and `t/helper/test-tool.c` to include the new test script
