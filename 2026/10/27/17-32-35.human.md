This is the first patch in Jeff King’s 8-patch series refactoring Git’s unit-test infrastructure. It fixes a small but user-visible bug: when you accidentally pass an extra argument to the unit-test binary (e.g., `unit-tests foo`), the error message incorrectly reports the program name (`unit-tests`) instead of the unexpected argument (`foo`). The fix is a one-line change in `t/unit-tests/unit-test.c`, swapping `argv[0]` for `argv[1]` in the error message. The patch is clearly motivated, well-contained, and ready for integration.
