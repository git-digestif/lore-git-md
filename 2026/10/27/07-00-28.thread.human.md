This thread is about a bugfix for a `BUG()` crash in `git pack-objects` when using `--exclude-promisor-objects-best-effort` in partial clones. The crash happens when the revision walk encounters missing objects—like trees filtered out by `tree:0` or beyond a shallow boundary—because the callback assumes all objects exist. Patrick Steinhardt's patch replaces the crash with a graceful skip, treating missing objects as promisor objects, and includes tests to verify the fix.

The patch has been reviewed by Junio C Hamano, who suggested a minor improvement: explicitly passing `OBJECT_INFO_SKIP_FETCH_OBJECT` to `odb_read_object_info_extended()` for clarity, even though the current code works due to other settings. Patrick has agreed to this change, so a v2 patch is likely forthcoming. The fix is narrowly scoped to the callback function and doesn’t alter broader promisor-object handling. No merge decision has been made yet, but the discussion is now focused on this small refinement.
