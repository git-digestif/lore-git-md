This thread is about a bugfix for a crash in `git pack-objects` when using `--exclude-promisor-objects-best-effort` in partial clones. The crash happens when the revision walk encounters missing objects—like trees filtered out by `tree:0` or beyond a shallow boundary—because the code assumed all objects exist. Patrick Steinhardt's patch replaces the `BUG()` crash with a graceful skip, treating missing objects as promisor objects, matching existing behavior elsewhere.

The fix is narrow, touching only the callback function in `pack-objects.c`, and includes two new tests in `t/t5616-partial-clone.sh` to verify the fix works with `--unshallow`/`--deepen` and missing-tree scenarios. The patch is authored by Patrick, with a `Reported-by` trailer, and has thorough test coverage. Mark C.
