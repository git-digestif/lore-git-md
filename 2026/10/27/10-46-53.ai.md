This is the tenth patch in Patrick Steinhardt’s 12-patch series modernizing `git rerere`’s subcommand handling. It converts the "gc" action into a proper subcommand (`cmd_rerere_gc()`) that uses Git’s standard `parse_options()` machinery, matching the pattern already applied to the other rerere actions in earlier patches.

The patch extracts the "gc" logic into a dedicated function, adds a hidden `--skip-locked` option to the subcommand’s option table, and removes the now-redundant global `--skip-locked` flag from the top-level parser. The test suite drops one negative test that checked the old global-flag behavior; the new subcommand-specific option is implicitly tested by the existing positive test for `git rerere gc --skip-locked`.

No new behavior is introduced; the change is purely mechanical and preparatory for the final patch (12/12), which will switch the entire command to `OPT_SUBCOMMAND()`. The patch is small, well-scoped, and follows the established refactoring pattern of the series. Reviewers familiar with the earlier patches will find nothing surprising here.
