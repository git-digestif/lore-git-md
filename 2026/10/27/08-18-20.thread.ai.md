Core problem or goal
Clean up Git’s CI infrastructure by consolidating test environment variables across GitHub Actions and GitLab CI workflows. The goal is to reduce duplication, improve maintainability, and ensure consistent test environments (e.g., default ref storage format) across CI platforms. The series introduces a new `NO_RUST` build variant using glibc, improves documentation for the "feature-testbed" job, and replaces per-distribution variable assignments with platform-wide rules (e.g., `GIT_TEST_USE_SET_E` for Linux jobs). The refactoring prioritizes resilience to future job additions by using pattern-matching case statements instead of explicit job-name lists.
