This is the second patch in Harald Nordgren’s v4 CI/build system series. It makes the installation of Perforce, Git LFS, and JGit mandatory on the platforms that require them (ubuntu-* and macos-*), causing the CI build to fail immediately if any of these tools cannot be installed. The patch removes the redundant presence checks and warnings at the end of `ci/install-dependencies.sh` because, under the new behavior, the script will have already exited if installation failed. It also drops the explicit `echo "error: ..." / exit 1` blocks and redundant `&&` chains, relying instead on `set -e` (already active via `ci/lib.sh`) to abort on the first failed command. Version output (`p4d -V`, `git-lfs version`, `jgit version`) is printed immediately after successful installation for confirmation. The change is purely about CI behavior—no functional change to Git itself—and is now technically unblocked, pending a final positive review from a contributor other than Junio C Hamano or Patrick Steinhardt. The patch touches only `ci/install-dependencies.sh` and is a direct implementation of the stricter behavior agreed in the thread.
