This thread is a cleanup series from Patrick Steinhardt that consolidates Git’s CI test environment variables across GitHub Actions and GitLab CI. The goal is to reduce duplication, improve maintainability, and ensure consistent test environments—such as default ref storage formats—across platforms. The series introduces a new `NO_RUST` build variant using glibc, centralizes environment variable overrides in `ci/lib.sh`, and replaces per-distribution variable assignments with platform-wide rules. It also restores test coverage for non-Rust builds, which was lost after Rust was enabled by default in April 2026.

The seven-patch series (v2, with the eighth patch dropped) is now uncontroversial and ready for Junio C Hamano to merge into the `next` branch. Key reviewers—Jeff King, Phillip Wood, and Toon Claes—have all endorsed the changes as "obviously good" or "nice," with no outstanding technical objections. The series touches CI workflow files (`.github/workflows/main.yml`, `.gitlab-ci.yml`), `ci/lib.sh`, and test infrastructure (`t/test-lib.sh`, `t/test-lib-functions.sh`), but makes no on-disk format changes. The only loose end is the unresolved design tension around the dropped eighth patch, which proposed a `--feature-testbed` flag for local testing; that discussion is now closed, with Patrick abandoning the patch in favor of a simpler approach.
