This thread is a cleanup series from Patrick Steinhardt aimed at consolidating Git’s CI test environment variables across GitHub Actions and GitLab CI. The goal is to reduce duplication, improve maintainability, and ensure consistent test environments—such as default ref storage formats—across platforms. The series introduces a new `NO_RUST` build variant, improves documentation for the "feature-testbed" job, and replaces per-distribution variable assignments with platform-wide rules. Patches 1–7 are uncontroversial and likely to be merged soon, with Jeff King calling them "obviously good."

The sticking point was patch 8/8, which initially proposed a `--feature-testbed` command-line flag to toggle test environment settings. After review, the maintainer-backed consensus shifted to using a `FEATURE_TESTBED=1` environment variable instead, a simpler and more consistent approach endorsed by Junio C Hamano and Jeff King. Patrick has signaled he will reroll the patch to adopt this design, incorporating Junio’s minor shell portability fix. The series addresses a gap in test coverage for non-Rust builds created by the April 2026 default-enable-Rust commit, and while the cover letter doesn’t detail specific past bugs, the cleanup is seen as a mechanical but impactful improvement. No major objections remain, and a v2 is expected soon.
