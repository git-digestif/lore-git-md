This thread is a cleanup series from Patrick Steinhardt aimed at consolidating Git’s CI environment variables across GitHub Actions and GitLab CI. The goal is to reduce duplication, improve maintainability, and ensure consistent test environments—such as default ref storage formats—across platforms. The series introduces a new `NO_RUST` build variant, centralizes variable assignments, and replaces per-distribution rules with platform-wide patterns. Patches 1–7 are uncontroversial and likely to be merged as-is, with Jeff King calling them "obviously good."

The eighth patch, which proposed a `--feature-testbed` command-line flag, sparked debate over its design. Jeff King argued it was inconsistent (omitting `OPENSSL_SHA1_UNSAFE`) and overly complex, proposing instead a `FEATURE_TESTBED=1` environment variable to toggle all relevant settings. Junio C Hamano endorsed this approach as "simple" and conceptually coherent, and Patrick has confirmed he will reroll the patch to adopt it, incorporating Junio’s shell quoting fix for portability. Phillip Wood’s latest reply reinforces this consensus, framing the environment variable as better aligned with local reproducibility and existing tooling. No objections remain, and the series is now awaiting a reroll of patch 8/8 before merging.
