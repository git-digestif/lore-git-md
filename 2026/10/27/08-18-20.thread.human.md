This thread is a cleanup effort by Patrick Steinhardt to consolidate Git’s CI test environment variables across GitHub Actions and GitLab CI. The goal is to reduce duplication, improve maintainability, and ensure consistent test environments—such as default ref storage formats—across platforms. The series introduces a new `NO_RUST` build variant, centralizes environment variable overrides, replaces per-distribution rules with platform-wide patterns, and adds a `--feature-testbed` flag to the test suite for local reproduction of CI environments. It also addresses a gap in test coverage for non-Rust builds created by Git’s April 2026 default-enable-Rust commit.

The series is currently under review, with Phillip Wood providing substantive feedback on all eight patches. His review is broadly positive, praising the consolidation of job-dependent variables and the removal of redundant CI jobs while preserving test coverage. He endorses disabling Rust for the sanitizer job (`linux-asan-ubsan`), noting its focus on C code, though he leaves open the possibility of revisiting this if Git’s Rust codebase introduces more unsafe code. The only minor issue raised was the omission of `OPENSSL_SHA1_UNSAFE` in the `--feature-testbed` flag, which Patrick is expected to document in the commit message. No other objections or technical concerns have been reported, and the series appears likely to proceed without major changes.

Key changes include centralizing hardcoded variable overrides in `ci/lib.sh`, using pattern matching to future-proof configurations, and aligning test behavior with Git’s compiled-in defaults for ref storage. The series touches CI workflow files, test infrastructure, and documentation, but introduces no functional changes to test logic or on-disk formats. While the cover letter lacks detail on specific pain points motivating the work, the refactoring is framed as a mechanical but impactful cleanup, reducing redundancy while improving resilience to future job additions. The series remains under review, with no indication of merge status.
