This is a CI/build system patch, part of Patrick Steinhardt’s ongoing effort to consolidate Git’s CI test environment variables (series `[PATCH 0/6] ci: consolidate test environment variables`). This specific patch (2/8) simplifies the handling of `GIT_TEST_USE_SET_E`, a test variable that controls whether the test suite runs with `set -e` enabled.

The patch replaces explicit per-distribution assignments of `GIT_TEST_USE_SET_E` with a single, broader rule: the variable is now set for *all* Linux jobs, regardless of distribution. This eliminates redundancy (removing four lines of explicit assignments) and ensures consistency—e.g., the `linux32` job, which previously missed this setting, now inherits it automatically. The change is technically straightforward: it moves the variable assignment into a `case "$CI_OS_NAME"` block in `ci/lib.sh`, where other platform-specific logic already lives.

The rationale is clear: `set -e` works reliably on all supported Linux distributions, but not on macOS due to its older Bash version. The patch avoids the maintenance burden of keeping a list of compatible distributions up-to-date, instead relying on the platform name (`CI_OS_NAME`) as a stable proxy. No functional changes are introduced—this is purely a refactoring to reduce drift and future-proof the CI configuration.

The patch is well-motivated and mechanically sound, but it’s worth noting that the broader series (as summarized in the thread context) introduces temporary duplication in patch 1/6 as a stepping stone for later consolidation. This patch is an example of that consolidation in action, but reviewers may still question whether the intermediate state is necessary or if the series could have been structured to avoid it entirely.

No prior feedback or objections are recorded for this patch, and it appears uncontroversial. The change is limited to `ci/lib.sh` and does not touch test logic or behavior, so the risk of regressions is low. The patch is part of a larger cleanup effort and should be evaluated in that context.
