This is the first patch in a three-part bugfix series for the sequencer subsystem. Phillip Wood improves the `test_ref_missing()` helper in the test library to include the name of the problematic ref in its error messages. Currently, if multiple calls to this helper fail in the same test, the output doesn’t distinguish which ref caused the failure—this change fixes that by printing the ref name (e.g., `test_ref_missing: 'REBASE_HEAD' exists`).

The patch is small (4 insertions, 2 deletions) and purely a test infrastructure improvement. It doesn’t fix the main bug itself—that comes in later patches—but it makes diagnosing test failures easier, which is especially useful for the new tests added in this series. The change is uncontroversial and aligns with the project’s preference for clear, actionable test output. No behavior changes or new functionality are introduced; this is just about better diagnostics.
