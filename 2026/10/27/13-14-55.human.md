This is a brief follow-up in the ongoing bugfix series to restore dynamic reloading of alternate object databases. Patrick Steinhardt acknowledges Christian Couder’s observation that the fifth patch suppresses the "object directory %s does not exist" error when a previously known alternate directory is removed. Patrick considers this a niche edge case that does not affect the core functionality or correctness of the fix, but leaves the door open for further discussion if others disagree.

The exchange is part of a larger review process where the series has already addressed several substantive issues (a race condition, a behavioral regression in `git receive-pack`, and cosmetic inconsistencies). This particular point is minor and unlikely to derail the series, but it highlights the trade-off between performance optimizations and diagnostic clarity. The patch itself remains unchanged for now.
