This is a CI/build system patch, the seventh in Patrick Steinhardt’s eight-patch series consolidating Git’s CI test environment variables. It removes a single line in `ci/lib.sh` that overrides `GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME` to "master" in the `linux-feature-testbed` job. The commit message explains that this override is redundant: the initial branch name is already set to either "main" or "master" via the `WITH_BREAKING_CHANGES` toggle, so the explicit assignment serves no purpose. The change is mechanical and uncontroversial, eliminating a now-pointless configuration line without altering behavior. No other files or variables are touched. The patch is part of the broader effort to deduplicate and centralize CI environment settings, making the infrastructure more maintainable.
