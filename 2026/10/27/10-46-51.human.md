This is the eighth patch in Patrick Steinhardt’s 12-patch series modernizing `git rerere`’s subcommand handling. It extracts the "remaining" action into a proper `cmd_rerere_remaining()` function that uses Git’s standard `parse_options()` machinery, matching the pattern already established for the "forget", "clear", and "status" subcommands in earlier patches.

The change is purely mechanical: the logic that prints unresolved conflicts is lifted verbatim from the old `if (!strcmp(...))` branch into the new function, and the only new code is the `struct option` array (empty, since "remaining" takes no options) and the `parse_options()` call. The patch touches only `builtin/rerere.c` and is a straightforward, low-risk step toward the final goal of switching to `OPT_SUBCOMMAND()`. No behavior change is introduced, and the commit message clearly signals that this is preparatory work for the upcoming subcommand conversion.
