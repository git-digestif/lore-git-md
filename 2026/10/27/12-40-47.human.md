This is a build system patch that restores ccache effectiveness when Git is built with a precompiled header. Since the precompiled-header feature landed in September 2026, ccache has refused to cache the resulting object files unless two “sloppiness” flags are set. The patch enables `pch_defines` and `time_macros` for the precompiled header and every object that includes it. On the author’s machine a warm-cache rebuild drops from ~100 s to ~30 s, and branch switching becomes about 6× faster once the cache is populated. The change is confined to the Makefile and carries no risk for non-ccache builds.
