This is the fifth patch in Jeff King (Peff)'s 8-patch series refactoring Git's unit test infrastructure to integrate `clar`-based unit tests with the shell test suite. This patch is the technical centerpiece of the series: it introduces a new wrapper script (`t/t0011-unit-tests.sh`) that runs the `clar` unit test binary through `test-lib.sh`, ensuring unit tests inherit the same environment setup, leak detection, and logging as the shell-based test suite.

The patch directly addresses two long-standing pain points: unit test failures in CI are now debuggable (previously, `prove` swallowed their TAP output), and sanitizer options like `LSAN_OPTIONS` are now applied to unit tests, enabling full stack traces for memory leaks. The wrapper script forwards relevant options (`--immediate`) to the unit test binary, though it intentionally does not support `--run` (due to syntax differences) or `--write-junit-xml` (as the unit tests run separately and do not support this option). The implementation also adds a dependency in `t/meson.build` to ensure the unit test binary is built before the wrapper script runs.

This is a well-motivated, technically sound change that builds on the preparatory work in patches 1-4. The commit message clearly explains the rationale, trade-offs, and implementation details, and the patch itself is minimal and focused. The wrapper script is straightforward, handling the differing binary locations between Make and Meson builds. While the series marks the last two patches as RFC, this patch appears ready for integration. Key symbols introduced: `t/t0011-unit-tests.sh` (wrapper script), `UNIT_TESTS` (binary path variable), and the Meson dependency update.
