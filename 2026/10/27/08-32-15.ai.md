This is the first patch in Harald Nordgren’s v4 CI/build system series, a preparatory cleanup that removes an obsolete macOS quarantine-removal step for Perforce binaries.

The patch deletes the `xattr -d com.apple.quarantine` call that was added in 2020 to prevent GUI confirmation dialogs when Perforce was installed via Homebrew. Since 2022, when the install method switched to direct `wget`, the attribute has never been set—neither `wget` nor `curl` applies it, and GitHub Actions and GitLab CI runners do not use Safari or Finder. The call has therefore been a silent no-op for over four years. The commit message now leads with this observation, addressing Junio C Hamano’s and Patrick Steinhardt’s request for clarity.

The change is confined to `ci/install-dependencies.sh` and has no functional impact on Git itself; it merely removes dead code. The patch is technically unblocked and accepted in principle by both Junio and Patrick, pending only minor commit-message polish. It still lacks an explicit positive review (Reviewed-by or Acked-by) from a contributor outside that pair.
