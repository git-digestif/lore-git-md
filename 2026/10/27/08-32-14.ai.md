This is the v4 cover letter for a two-patch CI/build system series that makes Perforce, Git LFS, and JGit installation failures fatal on the platforms that require them (ubuntu-* and macos-*), while removing redundant error-handling logic and a long-obsolete macOS quarantine-removal step.

The series now fully implements the stricter behavior agreed in the thread: if any of these tools fail to install, the CI build fails immediately rather than allowing silent skips or warnings. The preparatory patch (1/2) removes the `xattr -d com.apple.quarantine` call for macOS Perforce binaries, which has been a no-op since 2022 when the install method switched from Homebrew to direct `wget`. The main patch (2/2) drops the explicit `echo "error: ..." / exit 1` blocks and redundant `&&` chains, relying instead on `set -e` (already active via `ci/lib.sh`) to abort on the first failed command, matching how every other install step in the file already works. Version output (`p4d -V`, `git-lfs version`, `jgit version`) is printed immediately after successful installation for confirmation.

The v4 changes are mechanical cleanups: removing the `&&` chains between `wget`, `tar`, and `chmod` steps (which were silently letting earlier failures fall through under `set -e`), and rewording the quarantine-removal commit message to lead with the observation that the call does nothing and can be dropped. The series touches only `ci/install-dependencies.sh` and does not alter Git’s behavior—only CI log noise and failure handling. Both patches are now technically unblocked and ready for final review, pending minor commit-message polish already requested by Junio C Hamano and Patrick Steinhardt. The series still lacks an explicit positive review (Reviewed-by or Acked-by) from a contributor other than Junio or Patrick.
