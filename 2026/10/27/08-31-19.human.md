The patch ensures that `From:`, `Date:`, and `Subject:` headers are recognized regardless of their case (e.g., `FROM:`, `date:`, `SUBJECT:`), aligning with RFC 5322’s requirement that header field names be case-insensitive. This fixes a real interoperability issue where `git imap-send` would reject valid emails generated by tools like `b4` that use non-lowercase headers.

The change is minimal and surgical: it replaces three `starts_with()` calls with `istarts_with()` in the `has_required_headers()` helper function in `imap-send.c`. The new test in `t/t9001-send-email.sh` verifies the fix by sending a message with lowercase headers (`from:`, `date:`, `subject:`) and confirming it is accepted.
