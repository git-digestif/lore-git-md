This is the seventh patch in Patrick Steinhardt’s 12-patch series modernizing `git rerere`’s subcommand handling. It extracts the "status" action into a dedicated `cmd_rerere_status()` function that uses Git’s standard `parse_options()` machinery, replacing the previous in-line logic. The change is purely mechanical: the new function has the same signature and behavior as the old code, but now follows the pattern established in earlier patches for "forget" and "clear". The patch touches only `builtin/rerere.c`, adding the new function and wiring it into the main dispatch table. No new options, config keys, or test updates are introduced; the existing `rerere_usage` string and `RERERE_READONLY` flag remain unchanged. This is a low-risk, guideline-aligned refactoring step that brings `git rerere` closer to the standard subcommand interface used by other Git built-ins.
