This is part of Jeff King’s (Peff) ongoing test-infrastructure refactoring series. Patch 6/8 removes redundant unit-test invocations that would now cause the `clar`-based unit tests to run twice—once through the new `t/t0011-unit-tests.sh` wrapper (introduced in patch 5) and once through the old direct-binary paths. The patch deletes the separate Meson test entry, drops the `unit-tests-test-tool` Make target, and stops passing the unit-test binaries to `prove`, switching instead to a pure-shell invocation via `TEST_SHELL_PATH`. The now-unused `run-test.sh` wrapper script is also removed. The result is a cleaner, single code path for unit tests while preserving the ability to run them directly or via `make unit-tests`. No behavioral changes; this is pure cleanup.
