This is a CI/build system patch, part of Patrick Steinhardt’s ongoing effort to consolidate Git’s CI test environment variables (series `[PATCH 0/6]`). This specific patch (2/8 in the current thread, but 2/6 in the original series) simplifies the handling of `GIT_TEST_USE_SET_E`, a test variable that controls whether the test suite runs with `set -e` enabled.

The change replaces explicit per-distro assignments (e.g., `almalinux-*`, `debian-*`) with a single rule: set `GIT_TEST_USE_SET_E=yes` for all Linux jobs. This works because all supported Linux distributions use a modern enough Bash version, unlike macOS, which remains an exception. The patch removes four lines of redundant configuration and adds six lines of centralized logic in `ci/lib.sh`.

The motivation is straightforward: reducing maintenance burden by eliminating distro-specific boilerplate. The patch is mechanical and uncontroversial, but it’s worth noting that the broader series introduces temporary duplication (later consolidated) as a deliberate trade-off. No functional changes are introduced here—just cleanup. The patch is well-explained and fits neatly into the series’ goal of making CI configurations more maintainable. If the series as a whole lands, this patch will likely be merged without fuss.
