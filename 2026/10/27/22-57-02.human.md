This is Junio’s brief status update on Mike Hommey’s Rust reorganization patch. The patch—now at v5—moves Git’s Rust code into a dedicated `rust/` subdirectory to improve project structure and support downstream projects that vendor Git’s C code while excluding its Rust components. Junio notes that the patch has been quiet for a month with no new comments, and that beyond Mike himself, enthusiasm for the change has been limited.

The patch itself is technically complete, addressing all prior feedback (including CI fixes) and applying cleanly on Git 2.56-rc1. Junio’s only hesitation stems from the unresolved discussion about how to handle Git 3.0’s mandatory Rust components for downstream projects—specifically, Mike’s proposal to publish the `gitcore` crate to crates.io. Junio doesn’t outright reject the patch but implies it may not be a high priority given the lukewarm reception and lingering forward-compatibility questions.

For now, the patch remains under review, not yet in `next`. If the Git 3.0 dependency discussion gains traction, this reorganization could become more urgent; otherwise, it may stall. The ball is in the community’s court to either revive the discussion or let the patch fade.
