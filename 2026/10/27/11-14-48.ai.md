This is a test-infrastructure refactoring patch. It modernizes the command-line parsing in `t/helper/test-chmtime.c` by replacing manual `strcmp()` checks with Git’s standard `parse_options()` API.

The patch is part of an Outreachy internship contribution. It touches only the test helper, so there is no user-visible behavior change. The key technical point is the use of `PARSE_OPT_KEEP_UNKNOWN_OPT` to preserve negative time offsets (e.g., `-86400`) that would otherwise be misinterpreted as unknown short options. The new code also switches from a single static usage string to the `usage_with_options()` helper, which is the project’s preferred pattern.

The diff is clean and mechanical: 25 lines of manual parsing are replaced with 21 lines of `parse_options()` boilerplate. No new functionality is introduced, and the commit message clearly states the motivation (modernization) and the edge case handled (`PARSE_OPT_KEEP_UNKNOWN_OPT`). The patch is self-contained and does not depend on any other series.
