This is the fifth patch in Patrick Steinhardt’s 12-patch refactoring series that modernizes `git rerere`’s subcommand handling. The series as a whole replaces the command’s custom subcommand-parsing logic with Git’s standard `OPT_SUBCOMMAND()` mechanism, and this patch specifically extracts the “forget” action into a dedicated `cmd_rerere_forget()` function that uses the parse-options API.

The change is purely mechanical: the existing “forget” logic is lifted verbatim from the main `cmd_rerere()` function into a new helper, and the main command now delegates to it. No behavior changes, no new options, and no test updates are needed. The patch touches only `builtin/rerere.c` and is a straightforward preparatory step for the later switch to `OPT_SUBCOMMAND()`. Reviewers familiar with Git’s command-line parsing conventions will recognize this as a textbook example of the pattern used by other multi-subcommand built-ins.
