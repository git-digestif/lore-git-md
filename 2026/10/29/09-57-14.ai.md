This is patch 5/12 in Patrick Steinhardt’s v2 series modernizing `git rerere`’s subcommand handling. The patch extracts the "forget" action into a dedicated `cmd_rerere_forget()` function that uses Git’s standard `parse_options()` machinery. The change is purely mechanical: the logic is lifted verbatim from the old `if (!strcmp(...))` branch in `cmd_rerere()` and wrapped in a new function that takes the same arguments (`argc`, `argv`, `prefix`, `repo`). The only difference is that the new function parses its own empty option table (no new flags are introduced) and then delegates to `rerere_forget()` exactly as before. The old hand-rolled pathspec parsing and warning are preserved, so behavior is unchanged. This is a preparatory step; the actual switch to `OPT_SUBCOMMAND()` happens in patch 11. The patch touches only `builtin/rerere.c` and is uncontested.
