This is the seventh patch in Patrick Steinhardt’s 12-part refactoring series that modernizes `git rerere`’s subcommand handling by adopting Git’s standard `OPT_SUBCOMMAND()` mechanism. The series is purely internal, with no behavior changes or new user-facing features.

This patch extracts the "status" subcommand into a dedicated `cmd_rerere_status()` function, mirroring the structure already established for "forget" and "clear" in earlier patches. The new function uses `parse_options()` with an empty option table (since "status" accepts no flags) and preserves the existing logic: it calls `rerere_cache_setup()` with `RERERE_READONLY`, prints the list of conflicted paths, and cleans up. The old inline code in `cmd_rerere()` is replaced with a simple dispatch to the new function.

The change is mechanical and well-scoped, touching only `builtin/rerere.c`. The patch follows the pattern set by the previous two subcommand extractions and keeps the series on track for the final conversion to `OPT_SUBCOMMAND()` in patch 11. No review feedback has surfaced on this patch yet, but given the uncontested status of the series so far, it is likely to be routine.
