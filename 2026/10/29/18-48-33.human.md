This is the first patch in a two-part contributor housekeeping series (v3) that keeps Git’s documentation build system in sync. It adds two missing entries to `command-list.txt`: `gitformat-loose(5)` as a "developerinterfaces" manual and `gitpacking(7)` as a "guide." The author explicitly excludes `gitweb.conf(5)` to avoid a confusing display name ("web.conf") in `git help -a`.

The change is mechanical and uncontroversial, confined to a single line in `command-list.txt` for each manual. No runtime behavior is affected; this is purely about ensuring the documentation index reflects the current set of non-command manual pages. The justification for omitting `gitweb.conf(5)` is clear and reasonable. This patch is ready for acceptance as part of the broader effort to prevent drift between `command-list.txt` and the Makefile.
