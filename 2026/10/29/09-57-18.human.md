This is the ninth patch in Patrick Steinhardt’s 12-part refactoring series that modernizes `git rerere`’s subcommand handling by switching to Git’s standard `OPT_SUBCOMMAND()` mechanism. The series is purely internal and makes no behavior or on-disk format changes.

This patch extracts the “diff” action into a dedicated `cmd_rerere_diff()` function that uses the `parse_options()` machinery. The new function preserves the existing logic: it reads the `MERGE_RR` file, iterates over conflicted paths, and invokes `diff_two()` to show each preimage. The only difference is that the code is now structured like the other subcommands (`forget`, `clear`, `status`, `remaining`) that were converted in earlier patches. The patch is mechanical, well-scoped, and uncontested; it simply moves the diff logic into a separate function with an empty option table, ready for the final `OPT_SUBCOMMAND()` conversion in patch 11.
