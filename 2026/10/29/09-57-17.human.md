This is the eighth patch in Patrick Steinhardt’s 12-part refactoring series converting `git rerere` to use Git’s standard `OPT_SUBCOMMAND()` mechanism. The series is purely internal restructuring with no behavior changes, and this patch extracts the "remaining" subcommand into a dedicated `cmd_rerere_remaining()` function.

The patch moves the existing logic for listing unresolved conflicts (reading the `MERGE_RR` file and printing paths where `util != RERERE_RESOLVED`) into a new function with an empty option table, preserving the exact same behavior. The only change is mechanical: the hand-rolled `if (!strcmp(argv[0], "remaining"))` branch in the main `cmd_rerere()` function now calls the new function instead of inlining the logic.

This is a straightforward, well-scoped refactoring that aligns with the series’ goal of bringing `git rerere` in line with other multi-subcommand built-ins like `git notes` and `git maintenance`. The commit message is clear, the diff is minimal, and the patch is uncontested. No new CLI options, config keys, or test changes are introduced. The series as a whole is now fully aligned with Junio C Hamano’s feedback and ready for integration.
