This is the fourth patch in Patrick Steinhardt’s 12-patch refactoring series that modernizes `git rerere`’s subcommand handling. The series is part of the ongoing effort to align `git rerere` with Git’s standard `OPT_SUBCOMMAND()` mechanism, and this patch specifically removes the unused `--[no-]rerere-autoupdate` flag from the "status" and "diff" subcommands.

The change is small and mechanical: the "status" and "diff" subcommands now hard-code `RERERE_READONLY` instead of accepting the `flags` parameter, which previously included the `--[no-]rerere-autoupdate` flag that these subcommands ignored. This cleanup makes the code easier to understand and prepares for the later patches that introduce dedicated subcommand functions. The patch touches only `builtin/rerere.c` and makes no behavior changes—it simply removes dead code paths.

The series as a whole is uncontested and ready for integration, with all feedback from Junio C Hamano addressed in v2. This patch is a straightforward refactoring that fits cleanly into the larger goal of bringing `git rerere` in line with other multi-subcommand built-ins like `git notes` and `git maintenance`. No new functionality, CLI options, or test updates are introduced here.
