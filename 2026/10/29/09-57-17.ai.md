This is patch 8/12 in Patrick Steinhardt’s v2 refactoring series converting `git rerere` to use Git’s standard `OPT_SUBCOMMAND()` mechanism. The patch extracts the "remaining" subcommand into a dedicated `cmd_rerere_remaining()` function with an empty option table, preserving the existing logic: it calls `rerere_remaining()` to populate a string list of conflicted paths, prints the unresolved ones, and cleans up. The hand-rolled `if (!strcmp(...))` ladder in the main `cmd_rerere()` function is updated to dispatch to the new function instead of inlining the logic.

The change is purely mechanical, touching only `builtin/rerere.c` (31 insertions, 11 deletions). No behavior changes, no new CLI options, and no test updates are introduced. The patch follows the established pattern from earlier patches in the series (patches 5–7 extracted "forget", "clear", and "status" in the same way) and prepares for patch 11, which will replace the `if` ladder with an `OPT_SUBCOMMAND()` table. The series remains uncontested and on track for integration.
