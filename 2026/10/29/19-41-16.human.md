This is a refactoring patch from Outreachy contributor Okhuomon Ajayi, part of the ongoing `the_repository` removal effort. The patch updates `pseudo-merge.c` to stop using the global `the_repository` variable and instead use the repository stored in the `bitmap_writer` struct (`writer->repo`). This is a mechanical but important change: the functions in this file previously assumed they were working with the global repository, which could cause issues if the writer was set up for a different repository.

The patch touches only `pseudo-merge.c`, removing the `USE_THE_REPOSITORY_VARIABLE` define and updating all repository-related calls (peeling refs, looking up commits, parsing commits, walking refs, and allocating commits) to use `writer->repo`. One function, `push_pseudo_merge()`, didn’t have access to the writer, so the patch adds a `struct repository *` parameter and updates its callers to pass `writer->repo`. The changes are straightforward and the commit message clearly explains the motivation.

This looks like a well-scoped, well-explained contribution that fits neatly into the larger `the_repository` removal project. No controversy or edge cases are apparent from the patch itself.
