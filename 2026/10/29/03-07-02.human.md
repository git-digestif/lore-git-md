This is Junio’s "What’s cooking in git.git" report for October 2026 (#10), the regular digest that gives a 30-second overview of what is happening in the integration branches.

The report lists 100+ topics, so here is the high-level summary:

What graduated to master
------------------------
A dozen small, uncontroversial patches landed in the last cycle:
- `ak/sequencer-head-refdup` – sequencer no longer clobbers the HEAD ref name when looking up worktrees.
- `ic/includeif-hostname` – new `includeIf hostname:...` condition and `git var GIT_HOSTNAME`.
- `je/doc-promote-git-help` – the first page of `man git` now explains how to use `git help`.
- `jk/test-lazy-prereq-heredoc` – test prerequisites can now be written as here-docs.
- `mb/fast-import-reference-pending` – `fast-import` no longer crashes when `from` refers to a just-created commit.
- `ps/ci-housekeeping-and-modernizations` – CI jobs now use modern OS images and drop Python 2.
- `ps/odb-files-alternates-cleanups` – alternates handling in the files backend is now faster and more robust.
- `ps/pack-check-bigfile-threshold` – `fsck` no longer reports false corruption on objects whose size exactly matches `core.bigFileThreshold`.
- `ps/setup-enforce-repo-passed-to-create-repository-has-no-state` – `create_repository()` now treats its repository argument as a pure out-parameter.
- `rm/blame-default-ignore-revs` – `blame` and `annotate` now automatically use `.git-blame-ignore-revs` if it exists.
- `ss/repack-drop-filtered-dry-run` – `git repack --drop-filtered --dry-run` no longer actually repacks.
- `sw/cache-tree-ignore-locked-index` – `write_index_as_tree()` no longer dies when the index is locked.

What is cooking in next
-----------------------
The `next` branch is where topics that look ready are tested together.  The report lists about 40 topics currently in `next`; the most notable ones are:

- `ps/rerere-subcommands` – `git rerere` subcommands (`clear`, `forget`, `gc`, etc.) are now implemented using the standard `OPT_SUBCOMMAND()` API instead of ad-hoc parsing.
- `pw/sequencer-delete-rebase-head` – the sequencer now reliably removes `REBASE_HEAD` and `AUTO_MERGE` when a rebase finishes, even if the final pick was interrupted by conflicts.
- `ps/commit-graph-cleanups` – the `commit-graph` builtin has been cleaned up to remove global state and prepare for pluggable backends.
- `tb/hook-enabled-covers-traditional-hooks` – `hook.<event>.enabled` now also disables traditional hookdir hooks.
- `ps/odb-reload-alternates` – the files backend now reloads alternates on retry, restoring the ability to find objects moved to a newly added alternate.
- `je/doc-new-git-tutorial` – a new beginner’s tutorial has been added, replacing the old `gittutorial`.
- `je/doc-remove-gittutorial-2` – the obsolete `gittutorial-2` has been removed.
- `kk/connectivity-check-incremental` – a new `transfer.connectivityCheck=incremental` mode speeds up connectivity checks by comparing trees instead of walking the full object closure.

What is still under review
--------------------------
The remaining 50+ topics are either waiting for a response from the author, need a reroll, or are still being discussed.  A few highlights:

- `tb/midx-incremental-custom-base` – `git multi-pack-index write --incremental` now correctly honors `--base`.
- `mm/diff-process-hunks` – a new `diff.<driver>.process` config allows an external process to decide which lines are changed.
- `pm/replay-add-signing-support` – the experimental `git replay` command now supports GPG signing.
- `hn/reflog-operations` – `git reflog` and `git log -g` learned the `%gb` format to show the branch name for each reflog entry.
- `jt/tmp-objdir-loose-idx-merge` – the temporary object directory migration logic now correctly merges the loose-object index.
- `mc/repo-structure-filtering` – `git repo structure` now accepts revision arguments to filter the set of objects being counted.
- `mv/log-follow-speedup` – `git log --follow` across merges is now faster.
- `hn/branch-delete-merged-squash` – a new `--delete-integrated` option finds and removes branches whose work has been squash-merged.
- `hn/fetch-refmap` – in a shallow repository, `git remote add` now defaults to `--limited-fetch`, pulling only the remote branches tracked by local branches.

What is stalled
---------------
Three topics have been stalled for months without updates:
- `tb/midx-incremental-custom-base` (needs a reroll)
- `mm/diff-process-hunks` (needs a reroll)
- `ij/subtree-reject-v2-config` (needs a reroll)

The report also includes the usual housekeeping patches (test modernizations, i18n fixes, CI tweaks, and `the_repository` removals) and a handful of new features and performance improvements.  If you are interested in any of the topics, the report gives the exact branch name, the number of patches, and the message-ID of the cover letter so you can look up the discussion on the list.
