This is patch 9/12 in Patrick Steinhardt’s v2 series modernizing `git rerere`’s subcommand handling. It extracts the "diff" action into a dedicated `cmd_rerere_diff()` function that uses Git’s standard `parse_options()` machinery. The logic is unchanged: it still calls `rerere_cache_setup()` with `RERERE_READONLY`, iterates over the conflicted paths in `MERGE_RR`, and invokes `diff_two()` on each preimage. The only difference is that the code is now structured as a proper subcommand handler with an empty option table, matching the pattern already established for "forget", "clear", "status", and "remaining" in earlier patches. The patch is mechanical, well-scoped, and uncontested; it moves the series one step closer to replacing the hand-rolled `if (!strcmp(...))` ladder with an `OPT_SUBCOMMAND()` table in patch 11. Files touched: `builtin/rerere.c` only. Key symbols: `cmd_rerere_diff()`, `rerere_cache_setup()`, `RERERE_READONLY`, `diff_two()`.
