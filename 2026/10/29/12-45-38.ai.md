This is the second patch in the v6 series fixing the shallow-fetch-with-tags regression. It introduces `transport_options_release()` to fix a pre-existing memory leak in the remote-helper transport's cleanup path. The leak was not caught by CI because no tests previously exercised this path, but the upcoming core fix (patch 3/3) exposes it by allocating `negotiation_include_tips` for all transport types.

The patch moves the existing cleanup logic from `disconnect_git()` into a new shared function, `transport_options_release()`, and calls it from both `disconnect_git()` and the remote-helper's `release_helper()`. This ensures proper cleanup of `negotiation_restrict_tips`, `negotiation_include_tips`, and `filter_options` for all transport types. The change is mechanical and low-risk, touching only the transport subsystem (`transport.c`, `transport-helper.c`, and `transport.h`). No behavior changes are introduced; the patch merely consolidates cleanup logic to prevent leaks. The commit message now clarifies that this patch exposes the leak it fixes, addressing Patrick Steinhardt's feedback on wording. The patch is a prerequisite for the core fix and has no outstanding technical objections.
