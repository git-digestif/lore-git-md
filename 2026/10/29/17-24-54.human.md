This is a **maintainer feedback email** on Kristofer Karlsson’s patch that skips self-referential alternates during Git’s object quarantine. Junio C Hamano engages directly with the patch’s core architectural question: *where* to fix the inefficiency, rather than *whether* it exists.

Junio proposes a cleaner alternative to the current path-comparison hack: repurpose the existing `GIT_QUARANTINE_ENVIRONMENT` environment variable (currently used only as a boolean flag) to instead carry the *real object directory path* of the parent process. This would let child processes (like `rev-list`) unambiguously identify and skip the repository’s own refs when enumerating alternates, eliminating the need for fragile path matching or new internal APIs. The suggestion is framed as a natural extension of the quarantine mechanism’s existing design, avoiding the introduction of yet another environment variable.

The email does not object to the patch’s goal or its performance measurements, but it does signal a preference for a more principled fix before merging. Junio’s tone is constructive and solution-oriented, focusing on how to integrate the fix into Git’s existing environment-variable conventions rather than questioning the patch’s motivation or data. This feedback is likely to shape the next iteration of the patch, especially if Patrick Steinhardt or Justin Tobler weigh in on the quarantine plumbing details.
