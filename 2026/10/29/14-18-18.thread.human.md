This thread is about Okhuomon Ajayi’s Outreachy project proposal to reduce Git’s global state—particularly the `the_repository` global variable—to enable libification. Ajayi has been deeply engaged, submitting 18 patches (1 merged, 6 in `next`, 7 in `seen`, and 4 awaiting review) and revising the proposal to address feedback from Christian Couder and Patrick Steinhardt. The revised scope now includes refactoring reusable code from `builtin/` into library helpers, a key expansion from the initial plan.

The work is purely internal refactoring, touching files like `merge.c`, `diffcore-rename.c`, and `environment.c`, with no user-visible changes. Open questions remain around handling complex globals like `git_log_output_encoding` and `have_git_dir()`, as well as identifying suitable `builtin/` code for conversion. So far, feedback from established contributors (Couder, Steinhardt, Karthik Nayak) has been substantive and constructive, with no objections to the core goal. Junio has queued patches but hasn’t weighed in on the proposal itself.
