This is a refactoring patch targeting the ongoing `the_repository` removal effort. It updates `pseudo-merge.c` to stop using the global `the_repository` variable and instead use the repository stored in the `bitmap_writer` struct. The patch adds a repository parameter to `push_pseudo_merge()` and updates all callers to pass `writer->repo`, then removes the now-unused `USE_THE_REPOSITORY_VARIABLE` macro.

The change is mechanical and well-scoped: every function in the file that previously called repository-aware functions with `the_repository` now uses `writer->repo` instead. The commit message clearly explains the motivation—avoiding implicit reliance on the global repository when the writer is configured for a different one—and the diff shows the straightforward substitution. No behavior change is introduced; this is purely about making the code more explicit and consistent with the broader effort to eliminate `the_repository`.

The patch is part of a long-running, community-wide refactoring series (driven in part by René Scharfe) that touches nearly every subsystem. This particular file (`pseudo-merge.c`) is part of the bitmap/pack-objects machinery, so the change affects the low-level object storage layer. The patch is small and self-contained, making it a typical example of the incremental progress in this effort. No test failures or edge cases are mentioned, suggesting the change is unlikely to introduce regressions.
