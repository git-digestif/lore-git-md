This is Junio’s "What’s cooking in git.git" report for October 2026 (#09), summarizing the current state of integration branches and in-flight topics.

The report highlights an unusually large backlog: 120 topics are in `seen`, but only 40 are in or near `next`. Junio warns that stalled topics—those without reviews or responses to feedback—may be aggressively discarded unless activity picks up. This is a clear signal to contributors that patches need timely engagement to avoid being dropped.

### Key Themes and Notable Topics

#### **New Topics (Waiting for Review or Reroll)**
- **`hn/reflog-operations`**: Enhances `git reflog` and `git log -g` with `--operations` (condensing entries like rebases) and `--historical-branch` (decorating entries with the branch HEAD was on). The feature is well-motivated but needs a reroll to address feedback.
- **`iy/sigchain-recover-concurrent-pops`**: Fixes a signal-handler corruption bug when the same signal is delivered concurrently to multiple threads. A critical correctness fix, but lacks reviews.
- **`ps/rerere-remove-global-state`**: Libifies the `rerere` subsystem to remove its dependency on `the_repository`, enabling multi-repo support. A significant refactoring with good test coverage; likely to merge soon.
- **`tb/hook-enabled-covers-traditional-hooks`**: Extends `hook.<event>.enabled` to disable traditional hookdir hooks. A usability improvement, but the change to treat missing boolean values as `true` might be controversial.
- **`cc/pack-index-v3`**: Implements pack index v3 for SHA-1/SHA-256 interoperability, allowing packed objects to store both hash algorithms. Part of the ongoing interop effort; needs review.
- **`ps/odb-object-storage-extension`**: Introduces `extensions.objectStorage` to configure the object storage backend. A foundational change for pluggable ODBs, but feedback suggests it may need adjustments.

#### **Stalled Topics (Risk of Being Dropped)**
- **`tb/midx-incremental-custom-base`**: Fixes `--base` handling in `git multi-pack-index write --incremental`. Stalled for months; needs a reroll.
- **`mm/diff-process-hunks`**: Adds `diff.<driver>.process` to delegate hunk detection to external tools. A powerful but complex feature; stalled due to unresolved feedback.
- **`pm/replay-add-signing-support`**: Adds GPG signing to `git replay`. Stalled for weeks; needs a response to Junio’s feedback.

#### **Performance and Correctness Fixes**
- **`hn/fetch-shallow-v2-fix`**: Optimizes shallow boundary computation for protocol v2 fetches, matching v0 behavior and fixing a performance regression.
- **`ps/odb-reload-alternates`**: Restores the ability to reload alternates during object lookups, fixing a regression in concurrent repository rewrites.
- **`kk/connectivity-check-incremental`**: Adds an incremental mode for connectivity checks (`transfer.connectivityCheck=incremental`), avoiding full object walks by comparing trees.

#### **Usability Improvements**
- **`hn/status-compare-branches-default`**: Makes `git status` compare against both upstream and push branches by default, helping users with triangular workflows.
- **`je/doc-new-git-tutorial`**: Rewrites the beginner’s tutorial to focus on minimal commands for quick onboarding. A welcome documentation update.
- **`je/doc-merge-conflicts`**: Introduces a new man page for resolving merge conflicts, linked from relevant commands. A useful addition for users.

#### **Cleanups and Modernizations**
- **`ps/rerere-remove-global-state`** (mentioned above) and **`oa/merge-blobs-stop-using-the-repository`** are part of the ongoing `the_repository` removal effort.
- **`tc/test-greplint-in-chainlint`**: Optimizes test linting by integrating `greplint` into `chainlint`, speeding up CI.
- **`ak/root-refs-vs-pseudorefs`**: Clarifies terminology in docs/tests to distinguish "root refs" (e.g., `HEAD`) from "pseudorefs" (e.g., `FETCH_HEAD`). A cleanup with potential for bikeshedding.

#### **Platform and Build Fixes**
- **`ak/cargo-pin-target-dir`**: Fixes a Rust build issue when `CARGO_TARGET_DIR` is set. A small but important fix for Rust contributors.
- **`jc/ci-update-macos-15`**: Updates macOS CI jobs to use `macos-15` (deprecating `macos-14`). A routine maintenance update.

### Likely Points of Contention
- **`hn/status-compare-branches-default`**: Changing `git status`’s default behavior could surprise users. The discussion around backward compatibility will be key.
- **`tb/hook-enabled-covers-traditional-hooks`**: The change to treat missing boolean values as `true` might be debated.
- **`ps/odb-object-storage-extension`**: The design of the ODB extension mechanism may need further iteration based on feedback.
