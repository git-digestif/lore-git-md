This thread introduces a small but useful GUI feature in `gitk`: a new context-menu item, "Cherry-pick with cross-reference," which automates the `git cherry-pick -x` workflow. The `-x` flag appends the original commit hash to the new commit message, a common practice in backporting to maintain traceability. Ralf Habacker authored the patch, which modifies only the Tcl/Tk code in `gitk` and requires no new symbols or on-disk changes.

Johannes Sixt, the current `gitk` maintainer, has given the patch a preliminary thumbs-up, calling it "looking good" and integrating it into a public testing branch (`rh/cherry-pick-x`) on his GitHub fork. However, he’s holding off on merging it into the main `gitk` codebase until more community feedback arrives. So far, no technical concerns or requested changes have been raised, but the patch remains under review rather than accepted. If you’re interested in trying it out, you can find it in Sixt’s testing branch.
