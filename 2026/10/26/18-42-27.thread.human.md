This thread introduces a small but practical feature for `gitk`, the graphical commit history browser. Ralf Habacker proposes adding a new context-menu item, "Cherry-pick with cross-reference," which invokes `git cherry-pick -x` instead of the plain `cherry-pick` action. The `-x` flag appends the original commit hash to the commit message, improving traceability for workflows like backporting.

The patch is narrowly scoped, modifying only the Tcl/Tk code in `gitk` to add the menu item and adjust the `cherrypick` procedure to support the `-x` flag. There’s no controversy here—it’s a self-contained change with no new dependencies or tests required. Johannes Sixt (Hannes), the maintainer of `gitk`, is the natural reviewer for this, and if he approves, it should integrate smoothly into the existing codebase. No objections or open questions have been raised yet, so this looks like a straightforward addition that addresses a clear workflow gap.
