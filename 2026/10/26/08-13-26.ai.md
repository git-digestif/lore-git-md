This is a **CI/build system** patch follow-up in the ongoing thread about silencing irrelevant tool warnings in GitHub Actions. The current v2 patch is ready for final review, but Harald Nordgren now proposes a small preparatory change: removing the macOS-specific `xattr` step for Perforce installation entirely, since it is a no-op (the `com.apple.quarantine` attribute is never set by `wget` or `curl`). This would eliminate the need for the `|| true` workaround and simplify the script. Harald suggests including the removal in a v3 patch and testing it on GitLab CI before sending it to the mailing list. The change is low-risk and aligns with Patrick Steinhardt’s earlier suggestion, but it is not blocking the current patch’s progress. The core v2 patch remains unchanged and still awaits a formal positive review (Reviewed-by or Acked-by) from a contributor other than Junio C Hamano or Patrick Steinhardt.
