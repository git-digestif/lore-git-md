This is an announcement for **Git for Windows 2.56.0(4)**, a security-focused bugfix release from Johannes Schindelin. The update addresses two critical issues: corrupt code-signatures in the 32-bit MinGit executables and a vulnerability in the included brotli compression library (CVE-2026-111497), which has been patched by upgrading brotli to version 1.2.1. This is the fourth build in the 2.56.0 series, released just four days after the previous version, reflecting the urgency of the security fixes.

The release includes all standard distribution formats (installers, portable builds, MinGit variants, and tarballs) with checksums for verification. While the announcement was sent to the Git mailing list, this is **not** an upstream Git release—it is specific to Git for Windows and contains no changes to Git’s core behavior or APIs. The focus is solely on Windows packaging and security hardening, particularly addressing the brotli vulnerability, which affects a third-party library used by Git for Windows rather than Git itself. Downstream redistributors and Windows users are the primary audience for this update.
