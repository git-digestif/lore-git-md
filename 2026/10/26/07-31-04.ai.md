This is a test infrastructure patch, part of a two-patch series that fixes Meson compatibility for Git’s `clar`-based unit tests. This first patch is a preparatory cleanup: it reorders the NOOP argument list in `t/unit-tests/unit-test.c` to maintain alphabetical order, moving `--with-dashes` to its correct position. The change is mechanical (one line moved) and has no functional impact, but it simplifies future additions to the NOOP list by ensuring consistent ordering.

The motivation is practical: the NOOP argument infrastructure (introduced in commit 9faf3963b6) allows unit tests to accept the same flags as integration tests, enabling unified invocations like `meson test --test-args='-ix'`. The alphabetical ordering is not strictly required, but it reduces cognitive overhead for contributors adding new flags. This patch sets the stage for the second patch, which adds `-l`/`--long-tests` as a NOOP argument to resolve a Meson compatibility issue.

The patch is uncontroversial and aligns with the project’s preference for small, self-contained cleanups. CI results (GitHub, GitLab) confirm no regressions, and the series as a whole is ready for integration. The only prior feedback on this patch was Patrick Steinhardt’s surface-level review noting the alphabetical ordering was now correct—no substantive discussion or objections were raised.
