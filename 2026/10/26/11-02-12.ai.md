This is a **follow-up to a substantive review** of Jasper Mayone’s `--branch=<branch>` filtering patch for `` `git worktree list` ``. The email is a **surface-level suggestion** that refines the composability example given in the commit message.

Phillip Wood proposes a small but practical improvement: replacing the `--format='--branch=%(refname)'` incantation with `--format='--branch=%(refname:lstrip=2)'`. This AsciiDoc format specifier consistently strips the `refs/heads/` prefix from branch names, eliminating the need for the patch to handle both short names and full refs. The change would simplify the implementation (the `strset` logic could accept only branch names) and make the example command more concise and robust.

The suggestion is purely additive and does not engage with the deeper architectural or usability questions raised in the parent review. It is a targeted, low-risk tweak that improves the patch’s documentation and maintainability without altering its core behavior.
