This is the first patch in a two-patch CI/build system series (v3) that cleans up dead code in GitHub Actions workflows.

The patch removes a macOS-specific `xattr -d com.apple.quarantine` step that was added years ago to prevent Perforce binaries from triggering macOS quarantine dialogs. The step became unnecessary in 2022 when Perforce installation switched from Homebrew to a direct `wget`/`tar` download, which does not set the quarantine attribute. Since then, the step has been a silent no-op, cluttering the CI script without purpose. The commit message explains the history clearly and confirms the change is safe.

This is a straightforward, low-risk cleanup that aligns with Patrick Steinhardt’s earlier suggestion. It touches only `ci/install-dependencies.sh` and has no functional impact on Git itself. The patch is ready for review and should be uncontroversial.
