This is a **CI/build system** patch, now in its final stages of review. The v2 patch makes GitHub Actions CI builds fail immediately if Perforce, Git LFS, or JGit fail to install on platforms where they are required (Ubuntu for all three, macOS for Perforce). The thread has already settled on this stricter approach—no silent skips or warnings—so the patch is uncontroversial and ready for merging once it gets a formal Reviewed-by or Acked-by.

Neither affects functionality. Patrick also suggests that `set -e` in `ci/lib.sh` would simplify error handling, but that’s outside this patch’s scope.

The patch itself is small, focused, and well-explained. It touches only `ci/install-dependencies.sh`, adds clear error messages, and prints version output after successful installation for confirmation.
