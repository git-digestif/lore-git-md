This is a brief follow-up in the ongoing CI/build system thread about silencing irrelevant tool warnings in GitHub Actions. Patrick Steinhardt agrees with Harald Nordgren’s plan to remove the macOS-specific `xattr` step for Perforce installation in a preparatory v3 patch, since it is a no-op (the `com.apple.quarantine` attribute is never set by `wget` or `curl`). Harald will include the removal in v3 and test it on GitLab CI before sending it to the mailing list. The change is low-risk and aligns with Patrick’s earlier suggestion, but it does not affect the core v2 patch, which remains ready for final review and still awaits a formal positive review (Reviewed-by or Acked-by) from a contributor other than Junio C Hamano or Patrick Steinhardt.
