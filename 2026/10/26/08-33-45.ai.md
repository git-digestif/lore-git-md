This is the second patch in Harald Nordgren’s four-part v4 series introducing `--delete-integrated` to `git branch`. The patch refactors `delete_branches()` so it can report where a deleted branch’s changes “landed” in the upstream history, using a new `landed_commits` strmap that maps branch names to the commit that integrated their changes. No caller passes a map yet, so the patch is purely preparatory: it extends the function signature, adds a conditional skip for the merge check when a branch is in the map, and updates the output format to show both the branch’s old tip and the landing commit (e.g., `Deleted branch topic (was 1a2b3c4, landed as 9f8e7d6)`). The change is mechanical and uncontroversial, touching only `builtin/branch.c` and laying the groundwork for the next two patches that implement rebase and squash detection.
