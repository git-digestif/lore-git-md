This is the second patch in a two-patch series targeting test infrastructure, specifically the `clar`-based unit test runner. It adds `-l`/`--long-tests` as a NOOP argument to the unit test binary, following the established pattern from commit 9faf3963b6. The change is a single-line addition to `t/unit-tests/unit-test.c` and is motivated by Meson compatibility: users running `meson test -v --test-args='-ilx'` currently encounter a hard failure because the test binary rejects the unrecognized `-l` flag. The fix ensures the flag is silently ignored, restoring compatibility without altering test behavior.

The patch is uncontroversial and narrowly scoped. It does not affect the `GIT_TEST_LONG` environment variable (used in CI to enable expensive tests) or any functional test logic. The series as a whole is ready for integration, with no substantive objections or requests for changes raised during review.
