This is the second patch in Julia Evans’s now-merged two-patch series that removes the obsolete `gittutorial-2` document from Git’s documentation. The patch updates cross-references in five documentation files (`MyFirstObjectWalk.adoc`, `git.adoc`, `gitcore-tutorial.adoc`, `gitcvs-migration.adoc`, `gitglossary.adoc`) to point to `gitdatamodel[7]` instead of `gittutorial-2[7]`, and makes a minimal edit to `gittutorial.adoc` to replace its reference to `gittutorial-2` with a pointer to `gitdatamodel[7]`. The change is mechanical and uncontroversial: every reference to `gittutorial-2` in the documentation was intended to explain Git’s object model, and `gitdatamodel[7]` (added in 2024) is the modern replacement for that content.

The update to `gittutorial.adoc` is intentionally minimal because the plan is to remove that document entirely in a future patch. The current edit simply replaces the outdated reference to `gittutorial-2` with a pointer to `gitdatamodel[7]` and removes the now-obsolete explanation of Git’s object database and index file, which are already covered in greater depth by `gitdatamodel[7]`. The rest of the file remains unchanged, preserving the basic tutorial content for now.

This patch, combined with the first patch in the series (which reduced `gittutorial-2.adoc` to a stub), completes the removal of `gittutorial-2` from the documentation landscape. The series was merged to `master` on 2025-06-10, and the procedural coordination with Tuomas Ahola’s doc-linter topic is fully resolved. The broader discussion about whether to remove `gittutorial` (the older, part-one tutorial) is still open, but it is outside the scope of this patch.
