Key technical details
- **ak/sequencer-head-refdup**: Fixes a bug in the sequencer where the HEAD reference name could be clobbered during worktree lookups by using an allocated buffer instead of a static one.
- **ic/includeif-hostname**: Introduces `includeIf:hostname:<pattern>` for Git configuration and adds `git var GIT_HOSTNAME` to query the machine’s hostname.
- **je/doc-promote-git-help**: Updates the `git` man page to better guide users toward `git help` for documentation.
- **mb/fast-import-reference-pending**: Fixes a crash in `git fast-import` when the `from` command references newly created commits or tags by checking the internal object table before the object database.
- **ps/ci-housekeeping-and-modernizations**: Modernizes CI infrastructure: drops Python 2 support, updates OS images, renames jobs, and improves reftable test coverage.
- **ps/odb-files-alternates-cleanups**: Optimizes the ODB "files" backend by prioritizing packfile checks across alternates before loose objects, reducing `stat` calls, and refactoring the ODB source interface to drop the generic `local` flag.
- **ps/pack-check-bigfile-threshold**: Corrects a boundary check in `git fsck` to avoid false corruption reports for packed objects whose sizes match `core.bigFileThreshold`.
- **ps/setup-enforce-repo-passed-to-create-repository-has-no-state**: Refactors repository initialization to treat the repository object passed to `create_repository()` as a stateless out-parameter, moving shared repository handling into `setup.c`.
- **rm/blame-default-ignore-revs**: Makes `git blame` and `git annotate` automatically use `.git-blame-ignore-revs` (or `HEAD:.git-blame-ignore-revs` in bare repos) as the default ignore list and hardens the parser for ignore-revs files.

New or modified symbols: `includeIf:hostname:<pattern>`, `GIT_HOSTNAME`, `core.bigFileThreshold`, `.git-blame-ignore-revs`, `safe_create_leading_directories_no_share_const()`.
