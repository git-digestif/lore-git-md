This is Junio’s latest "What’s cooking in git.git" report, the regular snapshot of the project’s integration branches. The October 2026 edition is unusually crowded: 120 topics are queued in `seen`, but only 40 have advanced to `next` or are close to doing so. Junio warns that stalled topics—those without reviews or without responses to reviewer feedback—may be dropped more aggressively in the future.

Below are the highlights that a busy reader might care about, grouped by urgency and impact.

### Topics likely to graduate soon (in `next` or marked “Will merge to next/master”)

- **ps/rerere-remove-global-state** (7 patches): libifies the `rerere` subsystem by removing its dependency on `the_repository` and global state. This is a clean, well-motivated refactoring that aligns with the ongoing `the_repository` removal effort.
- **tb/hook-enabled-covers-traditional-hooks** (2 patches): extends `hook.<event>.enabled` to also disable traditional hookdir hooks, making the configuration more intuitive.
- **tb/sideband-skip-unrecognized-allow-control-characters** (1 patch): fixes an infinite loop in the sideband configuration parser when an unknown control-character keyword is encountered.
- **jt/odb-keep-lockfile-fix** (4 patches): defers `.keep` lockfile creation to transaction commit time, preventing race conditions that could delete concurrent lockfiles.
- **kk/connectivity-check-incremental** (6 patches): adds an “auto” and “incremental” mode to the connectivity check in `git fetch` and `git receive-pack`, significantly speeding up fetches in large repositories by comparing trees instead of walking the full object closure.
- **je/doc-new-git-tutorial** (2 patches): replaces the aging `gittutorial.adoc` with a concise, one-hour guide focused on the minimal commands needed to create a repository, make commits, and push to a remote.
- **jc/myfirstcontribution-discuss-then-reroll** (2 patches): updates the `MyFirstContribution` document to emphasize discussing review feedback before sending a reroll, moving the “how to send v2” section after the review discussion.

### Notable new topics (still in `seen`, needing review)

- **hn/reflog-operations** (3 patches): adds `--operations` to `git reflog` and `git log -g` to condense reflog entries (e.g., folding rebases) and `--historical-branch` to decorate entries with the branch HEAD was on when the entry was recorded. This is a user-facing feature that could be useful for debugging complex histories.
- **iy/sigchain-recover-concurrent-pops** (1 patch): fixes a signal-handler corruption bug when the same signal is delivered concurrently to multiple threads, causing infinite loops.
- **ms/reftable-alloc-size-truncation** (2 patches): widens allocation size arguments in the reftable backend to `uintmax_t` to prevent truncation on 32-bit platforms before the overflow check.
- **ps/odb-reload-alternates** (6 patches): restores the ability to find objects moved to a newly added alternate during a concurrent repository rewrite, with caching optimizations to avoid performance regressions.
- **cc/pack-index-v3** (13 patches): implements pack index v3 as part of the SHA-1/SHA-256 interoperability work, allowing packed objects to be mapped between hash algorithms.
- **hn/fetch-shallow-v2-fix** (1 patch): optimizes shallow boundary computation for protocol v2 fetches from shallow repositories, matching v0 behavior and fixing a performance regression.
- **hn/status-compare-branches-default** (1 patch): changes `git status` to compare against both upstream and push branches by default, making triangular workflows more ergonomic.
- **mv/log-follow-speedup** (4 patches): optimizes `git log --follow` across non-linear history by checking for unmodified paths in parents first, resolving a performance regression.

### Stalled topics (risk of being dropped)

- **tb/midx-incremental-custom-base** (3 patches): fixes `--base` handling in `git multi-pack-index write --incremental`. Stalled since June 2026.
- **mm/diff-process-hunks** (11 patches): introduces `diff.<driver>.process` to allow external tools to control which lines Git considers changed. Stalled since August 2026.
- **pm/replay-add-signing-support** (2 patches): adds GPG signing to the experimental `git replay` command. Stalled since September 2026.

### Small but useful fixes

- **of/bundle-uninitialized-memory-fix** and **of/config-buf-fgetc-unsigned**: fix uninitialized memory reads and signedness issues in the bundle and config parsers.
- **ak/root-refs-vs-pseudorefs** (5 patches): clarifies terminology in documentation and tests to distinguish root refs (like `HEAD`) from pseudorefs (like `FETCH_HEAD`).
- **sp/diff-delta-safe-arithmetic** (1 patch): uses safe integer arithmetic in `diff-delta.c` to prevent wrap-around on 32-bit platforms.
- **mc/status-index-lock** (2 patches): optimizes `git status` to hold the index lock only when writing the updated index, reducing lock contention.

### CI and build system

- **hn/ci-fail-on-missing-deps** (1 patch): makes CI fail immediately when optional dependencies (Perforce, Git-LFS, JGit) fail to install, rather than silently skipping their tests.
- **ps/ci-housekeeping-and-modernizations** (8 patches): updates CI jobs to use modern OS images, drops Python 2 coverage, and renames the `linux-TEST-vars` job to `linux-feature-testbed`.

### Documentation

- **je/doc-detached-head** (2 patches): moves the detached HEAD explanation from `git help checkout` to a standalone guide for better discoverability.
- **je/doc-merge-conflicts** (6 patches): introduces a new `gitmergeconflicts` man page and links to it from commands that can encounter conflicts (`merge`, `rebase`, `cherry-pick`, `revert`, `pull`).

### Controversial or edge-case topics

- **ps/odb-object-storage-extension** (7 patches): introduces `extensions.objectStorage` to configure the object storage backend. This is part of Patrick Steinhardt’s ODB abstraction effort but has raised concerns about the design and terminology.
- **hn/branch-delete-merged-squash** (3 patches): extends `git branch --delete-merged` to find squash-merged or rebase-merged branches by comparing blobs. This could be useful but may also be controversial due to the heuristic nature of the comparison.

### Actionable advice for readers

- If you care about **reflog usability**, **shallow fetches**, or **status ergonomics**, review `hn/reflog-operations`, `hn/fetch-shallow-v2-fix`, and `hn/status-compare-branches-default`.
- If you work on **large repositories**, review `kk/connectivity-check-incremental` for performance improvements.
- If you maintain **CI pipelines**, review `hn/ci-fail-on-missing-deps` and `ps/ci-housekeeping-and-modernizations`.
- If you’re a **Windows user**, note that `jc/ci-update-macos-15` updates the macOS CI jobs to `macos-15` (the Windows-specific work is tracked separately in Git for Windows).
- If you’re **interested in SHA-256 interoperability**, review `cc/pack-index-v3`.
