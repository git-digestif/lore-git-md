This is a CI/build system patch that removes a redundant `brew link --force gettext` command from Git’s macOS CI dependency script. The patch is now ready for merging after addressing all feedback in its second iteration.

The change itself is minimal—deleting a single line in `ci/install-dependencies.sh`—and targets only GitHub Actions CI builds, not local macOS development. The commit message now clearly explains the historical context: Homebrew made gettext no longer keg-only in 2020, so fresh installs automatically link it into the system path, making the `--force` command unnecessary and a source of spurious "Already linked" warnings in every macOS job log.

Patrick Steinhardt’s review confirms the patch works as intended, with passing CI pipelines on both GitHub and GitLab. No technical objections remain, and the patch is uncontroversial. It’s a small but well-justified cleanup that reduces log noise without risking functionality.
