This is the first patch in Harald Nordgren’s two-part v3 series cleaning up GitHub Actions CI noise. The patch removes a macOS-specific `xattr -d com.apple.quarantine` step for Perforce binaries that has been a silent no-op since Perforce installation switched from Homebrew to direct download in 2022. The commit message explains that the quarantine attribute is only set by GUI tools (Safari, Finder, AirDrop), never by `wget`, so the step has had no effect on GitHub Actions runners for over four years.

Patrick Steinhardt’s review is brief and focused on a single open question: whether the `xattr -d` call still has any effect on GitLab CI. He links to a GitLab merge request that will test this once the pipeline completes. The rest of the patch is uncontroversial; the historical context in the commit message is clear, and the change itself is a straightforward cleanup. If the GitLab CI test confirms the step is also a no-op there, this patch is ready to land as a preparatory step for the stricter error-handling behavior in the series’ second patch.
