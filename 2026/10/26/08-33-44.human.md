This is the first patch in Harald Nordgren’s four-part v4 series extending `git branch --delete-merged` to detect squash-merged and rebase-merged branches. This patch is purely refactoring: it moves the existing `branch.<name>.deleteMerged` opt-out check into a new helper function, `branch_opted_out()`, so the same logic can be reused when the new `--delete-integrated` flag is introduced in patch 3. There is no change in behavior, and the patch is uncontroversial.

The helper is straightforward: it checks the config key, prints a skip message if the branch is opted out, and returns a boolean. The change is mechanical and confined to `builtin/branch.c`, touching only the deletion logic. This patch is ready for integration and sets the stage for the more complex changes that follow.
