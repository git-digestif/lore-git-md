This is a bugfix patch targeting a user-visible regression in `git init`. The final review feedback has been resolved: Patrick Steinhardt, the primary reviewer, has accepted Matt Hunter’s proposed test assertion that checks the full output message for the default case (`Initialized empty Git repository in /path/to/init-path/.git/`). The patch is now ready for integration.

The regression was introduced in the current Git 2.56 development cycle (commit 20e38cba3926) and restores the pre-existing behavior of printing the absolute path of the initialized repository, which is more useful in command transcripts than the relative `.git/` path. The fix is minimal, touching only `builtin/init-db.c` and adding a regression test in `t/t0001-init.sh`. All substantive review feedback has been incorporated, and the patch is uncontroversial. Given the urgency of avoiding a behavior change in the upcoming release, this should land soon.
