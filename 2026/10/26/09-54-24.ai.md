This is the first patch in the v3 series targeting GitHub Actions CI noise reduction. It removes a macOS-specific `xattr -d com.apple.quarantine` step for Perforce binaries that has been a silent no-op since Perforce installation moved from Homebrew to direct `wget`/`tar` download in 2022. The commit message explains the historical context: the quarantine attribute was only ever set by GUI tools (Safari, Finder, AirDrop), never by `wget`, so the `xattr -d` call has had no effect on GitHub Actions runners for over four years. The change is a straightforward cleanup with no functional impact, aligning with Patrick Steinhardt’s earlier suggestion to drop the redundant step. The patch touches only `ci/install-dependencies.sh` and is uncontroversial. It sets the stage for the second patch’s stricter error-handling behavior by removing dead code.
