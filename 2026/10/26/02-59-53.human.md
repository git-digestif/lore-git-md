This is a follow-up in a **completion bugfix** thread. The author, Tanga Joris, acknowledges René Scharfe’s observation that `git fast-import --git-completion-helper` currently requires the user to press Enter before options appear, breaking seamless tab-completion. To avoid regressing `fast-import`, Tanga proposes splitting the fix: a v2 patch will remove `NO_PARSEOPT` only from the three commands (`patch-id`, `diff-pairs`, and `var`) that return immediately, while `fast-import` will keep the flag until a separate patch teaches it to answer `--git-completion-helper` before reading input. That follow-up patch will build on Christian Couder’s “early-scan” series, which touches the same code path. The plan is clear and incremental, addressing the edge case without holding up the simpler part of the fix.
