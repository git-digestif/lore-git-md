This thread is a small but practical fix to Git’s test infrastructure. Kaartic Sivaraam sent a two-patch series to make the `clar`-based unit test runner ignore the `-l`/`--long-tests` flag that `meson test` sometimes passes through. Without the fix, running `meson test -v --test-args='-ilx'` fails because the test binary doesn’t recognize `-l`. The first patch reorders existing NOOP arguments alphabetically for future maintainability, and the second adds `-l`/`--long-tests` as a NOOP argument, following the precedent set by commit 9faf3963b6. The series is self-contained, has been validated in CI, and is ready for review—no open questions or objections have been raised so far.
