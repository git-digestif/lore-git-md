This thread is a test-focused patch series from Marc Strapetz, introducing new test cases in `t5516-fetch-push.sh` to verify Git's handling of redundant blob transmission during forced pushes of rebased branches. The first patch (this one) adds four test scenarios covering `--force`, `--force-with-lease`, and forced refspec (`+topic`) pushes, along with a case checking replacement ref behavior. The tests use `GIT_TRACE2_EVENT` to confirm only three objects (the rebased commit, its tree, and the unchanged blob) are sent, even when the receiver already has the old tip.

The patch is narrowly scoped to the test script, with no code changes to Git's push logic itself. The motivation—ensuring forced pushes don't resend unnecessary blobs—is clearly explained in the commit message, and the test design (including `test_when_finished` and `test_cmp_rev`) suggests careful attention to test reliability. So far, there’s no review feedback, so the patch’s correctness and design haven’t been independently verified.
