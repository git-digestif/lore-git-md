This is a documentation cleanup patch that removes the obsolete `gittutorial-2` document while preserving a minimal stub for manpage compatibility. The patch is the first in a two-patch series (v3) that has since been merged to `master`. It reduces `gittutorial-2.adoc` from 422 lines to just 6, stripping out the outdated tutorial content while retaining the NAME, SYNOPSIS, and DESCRIPTION headers. The DESCRIPTION now explicitly marks the document as obsolete and redirects users to `gitdatamodel[7]` for Git’s data model and `gitcore-tutorial[7]` for practical internals exploration.

The commit message clearly explains why the document is being removed: it hasn’t been updated in 20 years, uses outdated terminology (e.g., "the index file"), and encourages users to inspect `.git/` internals in ways that are no longer relevant. The author argues that this approach is ineffective for most beginners and that modern alternatives (`gitdatamodel[7]` and `gitcore-tutorial[7]`) already cover the material more effectively. The patch also notes that removing `gittutorial-2` simplifies future work on rewriting the main `gittutorial`, which is also considered outdated.

The patch is uncontroversial and well-motivated, with no functional changes or new symbols introduced. The author’s testing (`git grep tutorial-2`) confirms no functional references remain outside build infrastructure and example text in `user-manual.adoc`. The procedural coordination with Tuomas Ahola’s `ta/command-list-guides-sync-lint` topic has been finalized, ensuring the doc-linter remains compatible while keeping the document out of the `git(1)` man page. The broader discussion about the future of `gittutorial` (the older, part-one tutorial) remains unresolved but is outside the scope of this patch.
