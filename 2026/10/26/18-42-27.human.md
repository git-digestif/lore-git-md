This is a small feature patch for `gitk`, the graphical commit history browser.

Ralf Habacker adds a new context-menu item labeled "Cherry-pick with cross-reference" that invokes `git cherry-pick -x` instead of the plain `cherry-pick` action. The `-x` flag automatically appends a line to the commit message recording the original commit hash, which is useful for traceability in workflows like backporting.

The change itself is minimal: one new menu entry, a tweak to the `cherrypick` Tcl procedure to accept an optional `-x` argument, and a few line-number adjustments in the menu-configuration code. The commit message explains the motivation clearly—closing a gap for projects that need to keep backported commits linked to their upstream sources.

`gitk` is maintained by Johannes Sixt (Hannes), so his review will be the key gate. The patch looks well-scoped and uncontroversial; if it works as advertised, it should be a straightforward addition.
