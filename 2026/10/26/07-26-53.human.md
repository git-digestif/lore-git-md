This is an **announcement for Git for Windows**, not a patch to the Git project itself. Johannes Schindelin releases Git for Windows 2.56.0(4) to address two urgent issues: corrupt code-signatures in the 32-bit MinGit variant and a security vulnerability (CVE-2026-111497) in the bundled brotli component, which is upgraded to v1.2.1. The release is available in all standard Git for Windows variants (installer, portable, MinGit, and tarballs) for 32-bit, 64-bit, and ARM64 architectures. No changes to upstream Git are involved; this is purely a packaging and security update for the Windows distribution.
