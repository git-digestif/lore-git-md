## 2026/10/19

- [2026/10/19/13-27-28 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano diagnosed that calling `advertise_shallow_grafts(1)` in `send_shallow_info()` breaks protocol v2 when sideband-all is enabled because that function uses `packet_write_fmt()` (protocol v0) instead of the `packet_writer` API, so `shallow` lines are written without the `\001` band designator and the client interprets `s` (byte 115) as a sideband channel, dying with a protocol violation.
- [2026/10/19/13-27-28 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano added a test to `t/t5702-protocol-v2.sh` that clones from a shallow server over protocol v2 with `uploadpack.allowsidebandall` set to true.
- [2026/10/19/14-50-51 by Harald Nordgren <haraldnordgren@gmail.com>] Harald Nordgren acknowledged the protocol violation report and said he would take a look.
