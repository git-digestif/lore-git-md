This is a bugfix patch for the pretty-printing subsystem, specifically the `%w()` format specifier in `git log` and related commands. The patch (now at v2) fixes a long-standing regression where the first whitespace character after a hard line break (e.g., `%n`) is incorrectly skipped, causing misaligned output in real-world scenarios like wrapped commit messages or indented lists. The issue has been present since 2007 but was undocumented and likely unintentional.

The fix itself is surgical: it modifies `strbuf_add_wrapped_text()` in `utf8.c` to distinguish between "line too long" (where skipping a space is correct) and "hard line break" (where skipping is wrong). The v2 patch also adds missing documentation for `%w` in `Documentation/pretty-formats.adoc` and includes a regression test in `t/t4205-log-pretty-formats.sh`. The change is well-motivated, with clear examples showing how the bug breaks alignment in practice—for instance, `%w(11) This is%n  the %s` previously output " the ..." instead of the intended "  the ...".

Both René Scharfe and Junio C Hamano have engaged substantively with the patch, raising the only significant concern: backward compatibility. The behavior being fixed has stood for 18 years, and some users might rely on it (e.g., the existing test in `t4205` needed updating). However, the undocumented nature of the behavior weakens the case for preserving it, and the author has addressed the concern by documenting the corrected behavior in v2. René’s review was thorough, citing specific commit history and edge cases, and his tone suggested the fix was reasonable once the documentation gap was closed.

The patch looks ready to proceed. It touches only the pretty-printing logic, adds test coverage, and updates documentation—no on-disk formats or user-facing behavior changes beyond fixing the misalignment. The author has responded thoughtfully to feedback, and the maintainer’s endorsement signals it’s likely to land in `next` soon. If you care about `git log --format` output or use `%w()` for wrapping, this is worth noting.
