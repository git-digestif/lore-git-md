This is a **translation (l10n)** patch. It fixes a missing runtime translation in `git difftool` when the user tries to use `--dir-diff` with a combined diff format (`-c` or `--cc`). The error message was already marked for extraction (`N_()`) but not for runtime lookup (`_()`), so users saw it in English regardless of their locale. The patch replaces `N_()` with `_()` and tidies the indentation of the wrapped message lines.

The change is minimal: one line in `builtin/difftool.c`, touching only the error message in the `run_dir_diff()` function. The commit message clearly explains the problem (a missing `_()` wrapper) and the fix. No new strings are introduced; the message was already present in the `.po` files, so this is purely a plumbing fix to make the existing translation effective.

This is a standalone patch, not part of a larger series. It is well-motivated and narrowly scoped, addressing a real but minor usability gap for non-English users. The patch looks correct and uncontroversial.
