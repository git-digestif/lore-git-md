This thread is about a small but user-facing enhancement to `gitk`: adding a right-click menu option to cherry-pick a commit with the `-x` flag, which appends a “(cherry picked from …)” trailer to the commit message. The patch, submitted by Ralf Habacker, touches only the Tcl/Tk frontend and has no impact on Git’s core code or documentation.

Johannes Sixt (Hannes), the `gitk` maintainer, has reviewed the patch and raised usability concerns—specifically, whether the feature justifies adding another entry to an already crowded context menu. He also suggested refinements to the menu label wording and the underlying Tcl procedure’s default behavior. The discussion so far has focused on these design choices rather than technical correctness, and Hannes has left the door open for broader community input before deciding whether to accept the patch.

The only recent activity is a minor exchange between Kristoffer Haugsbakk and Hannes about punctuation in the commit message—whether to use an em-dash, hyphens, or a comma. This is purely stylistic and doesn’t address the open questions about the feature’s value or implementation. The thread is still under review, with no clear consensus yet on whether the enhancement will be merged.
