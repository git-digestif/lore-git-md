This thread is about a small but user-facing enhancement to `gitk`: adding a right-click menu option to cherry-pick a commit with the `-x` flag, which appends a "cherry picked from..." trailer to the commit message. The patch, submitted by Ralf Habacker, is a straightforward Tcl/Tk change that doesn’t touch core Git code.

Johannes Sixt, the maintainer of `gitk`, has raised concerns about whether the feature is worth adding. He argues that the `-x` option is rarely used and that cluttering the already-crowded context menu with a variant of an existing command might not be justified. He’s asked for broader input from the community to gauge interest. On the implementation side, he suggested minor improvements: clearer wording in the menu label (avoiding jargon like "-x"), a tweak to the Tcl procedure to simplify the calling logic, and a note about translation file handling. None of these are showstoppers, but they reflect his preference for a cleaner UI and codebase.

The patch is still under review, and no other contributors have weighed in yet. If others find the feature useful, it’s likely to move forward with Hannes’s suggested adjustments. Otherwise, it may be dropped due to the lack of clear demand. The discussion is purely about usability and polish—there are no technical objections or deeper design questions at this point.
