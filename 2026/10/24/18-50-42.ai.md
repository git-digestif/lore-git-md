This is a bugfix targeting the oss-fuzz integration. The patch addresses a regression introduced in commit f1141b4391 (2025-08-15), where `parse_commit_graph()` was refactored to take a repository parameter and now calls `prepare_repo_settings()`. The fuzzer's repository lacks a `gitdir`, causing `prepare_repo_settings()` to trigger a BUG assertion before the fuzzer can test optional chunks like generation data or Bloom filters.

The fix is minimal: setting a placeholder `.git` gitdir (freed by `repo_clear()`) to satisfy the check in `prepare_repo_settings()`. The change mirrors an existing pattern in `test-path-utils.c`. The patch touches only the oss-fuzz harness (`oss-fuzz/fuzz-commit-graph.c`), adding a single line. No behavior changes are expected outside the fuzzer environment.
