This is a **platform compatibility / UI enhancement** patch for `gitk`, the graphical history browser. Ralf Habacker adds a context-menu action that invokes `git cherry-pick -x` on the selected commit. The patch touches only the Tcl/Tk code in `gitk-git/gitk`; no core Git code or documentation is changed.

The implementation is straightforward: a new menu entry “Cherry-pick with -x” is added to the right-click popup, and the existing `cherrypick` proc is extended to accept an optional `-x` flag that appends the “(cherry picked from …)” trailer to the commit message. The patch includes a minimal test in the `gitk` test suite (`t9001-gitk.sh`) that verifies the new menu item appears and that the trailer is added when the action is triggered.

Ralf’s commit message explains that the feature is motivated by workflows that rely on the `-x` trailer to track cherry-picks across branches. The patch is self-contained, has no external dependencies, and does not alter any existing behavior. It is a single-patch series with no cover letter.
