This thread is about a small but visible inconsistency in `git reflog expire --dry-run --verbose`: when you name specific refs on the command line, the output says "prune" instead of the correct "would prune" that you see with `--all`. Laveesh Bansal sent a one-line patch that fixes the bug by ensuring the dry-run flag is properly passed through for named refs. Junio C Hamano reviewed it and suggested a broader refactoring to eliminate the duplicate code paths for `--all` and named refs, but Laveesh has now proposed a two-step approach: merge the minimal fix first, then send a follow-up patch for the refactoring. The new tests Laveesh added cover both cases and will work with either version, so the fix is safe to land now. No one has objected to either the fix or the plan; the only open question is whether the refactoring will happen in a v2 or as a separate patch later.
