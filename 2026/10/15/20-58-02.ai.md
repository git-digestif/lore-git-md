This is the third iteration of a documentation patch that rewrites Git’s explanation of detached HEAD state. The patch is now polished and addresses all feedback from previous rounds, including Junio C Hamano’s requests for precision and Kristoffer Haugsbakk’s build-system and textual refinements. It introduces a new standalone guide (`gitdetached-head(7)`) and updates the advice message in `advice.c` to reference it.

The new explanation is concise and practical, framing detached HEAD as useful for experimentation (e.g., testing commits or browsing history) while clarifying the risks of creating commits in this state. It highlights the 2019 UI improvement in `git switch` that reduces accidental detachment and specifies the 30-day reflog expiry period to avoid misleading users. The patch also removes overly complex diagrams from the original text and adds a cross-reference to `git help datamodel` for deeper context. All requested corrections—hyphenation in the help command, sign-off from co-author Marie Claire LeBlanc Flanagan, and whitespace alignment in `command-list.txt`—are now incorporated.

Files touched include `Documentation/git-checkout.adoc`, a new `detached-head.adoc` (included in both the checkout man page and the new guide), `advice.c`, and build system files (`meson.build`, `Makefile`). The patch is self-contained, well-motivated, and ready for merging. The broader help-system usability concern (internal cross-references vs. `git help`) remains noted but is not a blocker. This version looks final and uncontroversial.
