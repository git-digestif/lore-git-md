This is a brief follow-up in the CI/build system maintenance series. Patrick Steinhardt acknowledges Kaartic Sivaraam’s observation that the `NO_RUST=UnfortunatelyYes` flag has been accidentally retained in CI for six months—since Rust was enabled by default in April 2026—because the flag was tied to the now-removed `linux-clang` job. While the current patch (3/8) simply removes the dead code, Patrick agrees the issue should be addressed and suggests doing so in a separate follow-up series. The discussion leaves open whether to reintroduce `NO_RUST` in the `linux-feature-testbed` job or create a new job specifically for testing the non-Rust build path. This is a low-priority but technically valid housekeeping item that does not block the current series, which remains uncontested and ready for integration.
