This is a CI/build system patch, part of Patrick Steinhardt’s eight-patch series modernizing Git’s CI configurations. Patch 6/8 updates the `linux-feature-testbed` job to use `ubuntu:latest` instead of the now end-of-life `ubuntu:20.04`. The change drops the explicit `gcc-8` dependency, letting the job use the system-provided GCC version. The commit message explains that `latest` always points to the most recent Ubuntu LTS release, preserving coverage for reasonably current environments while eliminating the need for manual updates. Other jobs (AlmaLinux 8, Debian 12) still test older distributions, so overall coverage remains balanced. Jeff King (Peff) has already endorsed the direction, calling the commit message “nicely explained.” The patch is uncontested and ready for integration.
