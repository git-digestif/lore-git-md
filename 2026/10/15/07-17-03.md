I would like to raise this issue, as suggested when I erroneously posted on the git-for-windows repo (https://github.com/git-for-windows/git/issues/6466)

## Issue

On Git for Windows git help user-manual looks for the wrong file.
Git looks for gituser-manual.html, instead of user-manual.html.

The Git User's Manual is installed as:
```
`C:\Program Files\Git\mingw64\share\doc\git-doc\user-manual.html`

However, git help user-manual fails with:
`fatal: 'C:/Program Files/Git/mingw64/share/doc/git-doc/gituser-manual.html': documentation file not found.`
```


## Actual behaviour

$ git help user-manual
fatal: 'C:/Program Files/Git/mingw64/share/doc/git-doc/gituser-manual.html': documentation file not found.
