This thread is about a proposal by Kristoffer Haugsbakk to deprecate the experimental `git format-rev` command. The argument is that `git diff-tree --stdin --format=medium` already provides the same core functionality—pretty-formatting revisions from standard input—while offering additional features like `--notes` and full integration with `rev-list` machinery. Although `git format-rev` has some conveniences, such as accepting revision expressions directly and annotating object names in running text, these can be replicated using existing tools like `git cat-file`. The proposal suggests that `git format-rev` may no longer be necessary and could be removed to reduce maintenance overhead. No responses or objections have been raised yet, so the discussion is still open.
