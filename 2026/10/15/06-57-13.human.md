This is the fourth patch in Patrick Steinhardt’s eight-part CI housekeeping series, now in its fourth iteration. It updates the 32-bit CI job (`linux32`) to use `i386/debian:latest` instead of the now-unsupported `i386/ubuntu:20.04` image. Ubuntu 20.04 was the last 32-bit Ubuntu release, and its end-of-life status made the switch necessary; Debian’s i386 images are confirmed to be available until at least 2030.

The patch touches both GitHub Actions (`.github/workflows/main.yml`) and GitLab CI (`.gitlab-ci.yml`) workflows, along with the supporting scripts `ci/install-dependencies.sh` and `ci/lib.sh`. The change is purely mechanical: it replaces the image name and removes Ubuntu-specific logic for Icelandic locale support (`language-pack-is`), since Debian’s `locales-all` package provides the same functionality. Jeff King’s earlier concern about Icelandic locale availability has been resolved, and the patch is uncontested.

This is a straightforward platform-compatibility update that reduces CI maintenance burden while preserving 32-bit test coverage. The patch is ready for integration and has already been backported to Git v2.56.0 for potential `maint` inclusion.
