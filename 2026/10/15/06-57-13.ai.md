This is the fourth patch in Patrick Steinhardt’s **v4 CI/build system housekeeping series**, which is now uncontested and ready for integration. This specific patch updates the 32-bit CI job (`linux32`) to use `i386/debian:latest` instead of the now-EOL `i386/ubuntu:20.04` image.

The change is straightforward: the `linux32` job in both GitHub Actions and GitLab CI workflows now pulls the Debian image, which guarantees support until at least 2030 (Debian’s current release cadence). The patch also cleans up dependency-installation logic in `ci/install-dependencies.sh` by removing Ubuntu-specific branches that are no longer needed—Debian’s `locales-all` package provides the Icelandic locale (`is_IS`) that was previously handled separately. The net effect is a small reduction in complexity (6 deletions, 1 insertion) while maintaining identical test coverage.

This patch was the subject of a substantive but resolved discussion in v3: Jeff King (Peff) raised a concern about whether the new Debian image would still support the Icelandic locale, but Patrick confirmed that `locales-all` covers it, and Peff accepted the explanation. The patch is now uncontested and passes linked CI runs. Expect future discussion to reference the `i386/debian:latest` image and the simplified dependency logic as the new baseline for 32-bit testing.
