This is the sixth and final patch in Patrick Steinhardt’s v3 series refactoring and optimizing alternates handling in Git’s object database (ODB) "files" backend. The patch removes the `local` flag from the generic `struct odb_source` and moves it into the packed source (`struct odb_source_packed`), where it is still needed.

The change is a cleanup that aligns with the series’ broader goal of simplifying the ODB source API after alternates were migrated into the "files" backend. The `local` flag originally indicated whether an object directory was directly attached to the current repository, but with alternates now handled within the backend, the flag no longer makes sense as a generic property. The packed source retains it to propagate the bit into packfiles, while the loose and in-memory sources no longer use it. The patch also updates the `ODB_FOR_EACH_OBJECT_LOCAL_ONLY` iteration logic to skip non-local object directories in the "files" backend, preserving the intended behavior.

The diff touches ten files, primarily adjusting constructor calls and field accesses to reflect the flag’s new location. The change is mechanical and well-contained, with no behavior changes or on-disk format implications. Reviewer Justin Tobler has already endorsed the design, though he previously raised concerns about the `ODB_FOR_EACH_OBJECT_LOCAL_ONLY` flag’s long-term viability—Patrick deferred that discussion to a follow-up series. This patch is ready for integration and completes the series’ goal of cleaning up the ODB source API.
