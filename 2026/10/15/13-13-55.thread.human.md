This thread is about a patch series by Harald Nordgren that adds two new options to `git reflog` and `git log -g`: `--operations` (collapsing multi-step operations like rebase into single entries) and `--historical-branch` (showing which branch HEAD was on when each reflog entry was recorded). The series is now at v2, addressing earlier feedback on commit message clarity and output formatting, but faces significant architectural and correctness challenges.

Junio C Hamano, the maintainer, has weighed in on the `--operations` debate, endorsing the *goal* of making reflog output more usable but sidestepping the question of whether the feature belongs in Git’s core. Instead, he proposes a broader refactoring: making multi-step commands like `git am` and `git cherry-pick` work on detached HEAD by default, which would naturally produce cleaner reflog entries without needing a heuristic-based filter. This aligns with Phillip Wood’s earlier suggestion that `git reflog` should default to the current branch rather than HEAD, but Junio’s proposal would require significant changes to long-standing commands, making it a long-term architectural shift rather than an immediate fix. He does not engage with the `--historical-branch` correctness issues or the alternative of using a format specifier (e.g., `%gb`) proposed by Phillip and D. Ben Knoble.

The series remains under active review, with key unresolved questions: whether `--operations` is viable given its heuristic limitations (e.g., missing operations like `git cherry-pick A B C`), how to correctly handle `--historical-branch` for edge cases like `git rebase <upstream> <branch>`, and whether the features should be implemented as dedicated flags or integrated into Git’s existing format specifier system. Phillip Wood’s substantive review has shifted the discussion toward architectural concerns, while Junio’s latest reply suggests a preference for addressing the root cause (messy reflog entries) rather than adding filters. No maintainer decisions or merge status have been reported, and the series is unlikely to progress until these debates are resolved.
