Core problem or goal
Fix a silently broken test (`t5004-archive-corner-cases.sh`) that verifies Git’s ability to handle ZIP archives containing objects larger than 4GB. The test was broken in SHA-256 repositories because it extracts SHA-1 objects from a pre-generated packfile (`big-pack.zip`) without ensuring the receiving repository uses the same object format. The fix ensures the test runs in a dedicated SHA-1 repository, preventing format mismatches in CI environments (e.g., Fedora CI with breaking changes enabled).
