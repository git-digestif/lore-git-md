This is the seventh iteration of a feature patch adding revision-based filtering to the `git repo structure` command. The patch is now a single-commit series and addresses the last remaining nit from v6: a word duplication in the commit message ("standard the standard" → "the standard"). No other changes are introduced.

The feature itself remains unchanged from v6. It allows users to filter the repository structure report by revision specifications (e.g., `git repo structure --branches --not --tags`), enabling targeted diagnostic analysis of specific parts of the object graph. The implementation uses Git’s standard `setup_revisions()` machinery, which processes objects reachable from included revisions unless they are exclusively reachable via excluded revisions. This approach avoids the transitive dependency issues of earlier versions and aligns with Git’s established revision-parsing idioms.
