This is a CI/build system patch series from Patrick Steinhardt, now in its fourth iteration (v4). The series modernizes Git's CI configurations by updating EOL Docker images, removing obsolete dependencies (Python 2, unused job logic), and improving test coverage for reftable and SHA-256 combinations. The v4 reroll addresses the last open technical question from prior rounds: **patch 1/8 now makes the test in `t/t5004-archive-corner-cases.sh` work in both SHA-1 and SHA-256 repositories** by forcing the test repository to use SHA-1, replacing the v3 approach that simply skipped the test in SHA-256 environments. This resolves Jeff King's (Peff) earlier suggestion to make the test self-contained while preserving its intent.

The series touches `.github/workflows/main.yml`, `.gitlab-ci.yml`, and supporting scripts (`ci/install-dependencies.sh`, `ci/lib.sh`, `ci/run-build-and-tests.sh`), along with the test file. Key changes include:
- **Patch 1/8**: The test now creates a temporary SHA-1 repository (`git init --object-format=sha1`) to ensure it runs regardless of the CI environment's default hash algorithm, addressing Peff's feedback about long-term maintainability.
- **Patch 5/8**: Renames the `linux-TEST-vars` job to `linux-feature-testbed`, adopting Junio C Hamano's preferred name from 14 alternatives proposed in v1.
- **Patch 8/8**: Repurposes the `linux-reftable-leaks` job as `linux-reftable-sha256` to test the SHA-256 + reftable combination, a resolution to Junio's v1 concern about losing foreign-SCM interoperability coverage.
- **Patches 4/8 and 6/8**: Update Docker images (`i386/ubuntu:20.04` → `i386/debian:latest`, `ubuntu:20.04` → `ubuntu:latest`) to supported versions, with the Icelandic locale (`is_IS`) concern resolved via Debian's `locales-all` package.
- **Patch 7/8**: Hard-codes `python3` in CI scripts, removing Python 2 logic now that Ubuntu 20.04 jobs are gone.

The series is **uncontested and ready for integration**, with all substantive feedback addressed. Junio has mechanically backported v3 to Git v2.56.0 for potential `maint` inclusion, and Patrick confirmed he will leave the patch base unchanged. The net effect is a reduction in CI complexity (43 insertions, 56 deletions) while maintaining or improving coverage. For future discussion, expect references to the `linux-feature-testbed` job name, the `*breaking-changes*` wildcard pattern (deferred to a follow-up), and the `WITH_BREAKING_CHANGES` flag's behavior (grouped with `sha256`, `reftable`, and `meson` as related CI job categories). The test in `t5004` may also be cited as a model for self-contained test design.
