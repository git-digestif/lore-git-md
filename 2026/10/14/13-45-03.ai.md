This is the first patch in Dorine Tipo’s Outreachy test-modernization series for `t/t0410-partial-clone.sh`. It replaces the brittle `git ls-tree | grep | head | cut` pipeline that extracts the OID of `a_dir` with a single `git rev-parse HEAD:a_dir` call. The change eliminates two problems: the pipeline masked Git’s exit code (only the last command’s status was preserved), and the hard-coded byte range `13-52` truncated SHA-256 OIDs. The new command returns the full OID in one step, matching how `TREE` is already computed with `git rev-parse foo^{tree}` in the same test. The patch touches only one line in the test script and is a direct, uncontroversial cleanup that restores SHA-256 compatibility.
