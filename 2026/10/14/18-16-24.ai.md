This is a **platform compatibility bugfix** targeting the Windows credential helper (`contrib/credential/wincred`). The patch (v4) refactors how the wincred helper parses multi-line secret blobs—such as credentials containing both a password and an OAuth refresh token—fixing several long-standing issues: incorrect size limits in `wcsncpy_s`, inconsistent line separator detection, failure to advance past the initial password line, and deep nesting in the parsing loop.

The new implementation uses `wmemchr` to scan for line endings (`\r\n` or `\n`) in immutable blob data, avoiding unsafe string operations and eliminating the need for temporary copies. The code is split into two helper functions—`write_credential_item` (for key-value pairs) and `write_credential` (for the full credential block)—which improve readability and maintainability.
