Thread identity: standalone bugfix patch for the reftable backend, authored by Matthew Suozzo via GitGitGadget. Thread type: bug report and fix.

Core problem or goal: fix a potential buffer overflow in the reftable backend's object record decoder (`reftable/record.c`). The decoder fails to validate that the 64-bit varint offset count does not exceed the remaining record length, which could lead to writing past an allocated array on 32-bit systems or unnecessarily large allocations on 64-bit systems. The bug is latent but poses a security risk if malformed records are processed. The root cause is now identified as `reftable_alloc_size()`'s overflow check being ineffective on 32-bit platforms due to `size_t` truncation of 64-bit values.

Current status: patch under active discussion; no revised version posted.
