This is the **ninth patch in the v2 performance series** that speeds up `git push` refspec matching. It optimizes `match_explicit_refs()` by replacing two linear traversals of local and remote refs with `strmap` lookups, reducing the complexity from O(R * N + R * M) to O(R * rules) for R refspecs, N local refs, and M remote refs.

The patch consolidates the `match_explicit_lhs()` and `match_explicit_lhs_map()` functions (the latter introduced earlier in the series) into a single implementation that uses `strmap` for all lookups. It also modifies `match_explicit()` to accept `strmap` parameters and updates `match_explicit_refs()` to build temporary `strmap` structures for both source and destination refs. A key correctness fix ensures that later refspecs see the refs added by earlier ones by updating the destination `strmap` in-place.

Performance measurements in the commit message show **68–79% speedups** for 100 refspecs in the "empty" and "mirror" client scenarios (timings drop from 0.47s to 0.15s and 0.87s to 0.18s, respectively). The patch touches only `remote.c` and introduces no new symbols, relying on helpers (`count_refspec_match_in_map()`, `ref_map_init()`) added earlier in the series.
