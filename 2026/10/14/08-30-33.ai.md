This is the seventh patch in Patrick Steinhardt’s v3 CI/build system housekeeping series. It removes now-dead Python 2 logic from the CI scripts after the last Ubuntu 20.04 job was dropped in an earlier patch.

The change is mechanical: `ci/install-dependencies.sh` hard-codes `python3` instead of the conditional `PYTHON_PACKAGE` variable, and `ci/lib.sh` simplifies the `MAKEFLAGS` assignment by removing the Ubuntu-20.04-specific branch that set `PYTHON_PACKAGE=python2`. The patch deletes eleven lines and adds two, with no behavioral impact beyond eliminating the no-longer-possible Python 2 code path.

The rationale is straightforward: Python 2 reached end-of-life in 2020, none of the current CI images package it, and the world has moved to Python 3. The commit message explicitly states that exercising Python 2 no longer feels useful, so the conditional logic is removed rather than ported to another job.

This patch is uncontroversial and ready for review. Future discussion is likely to reference the `PYTHON_PATH` variable and the `ci/install-dependencies.sh` script, but no substantive debate is expected.
