This is a **CI/build system** update in the ongoing CI housekeeping series. The email resolves the naming dispute for the `linux-TEST-vars` job, which tests Git with non-default `GIT_TEST_*` variables. After Junio C Hamano proposed 14 alternative names and expressed a preference for `linux-feature-testbed`, Patrick Steinhardt agrees to adopt this name, calling it a clear and accurate description of the job's purpose. The rename is purely mechanical (three one-line substitutions in `.github/workflows/main.yml`, `.gitlab-ci.yml`, and `ci/run-build-and-tests.sh`) and does not alter the job's behavior or options.

The broader series (v3 of 8 patches) modernizes Git's CI configurations by removing outdated dependencies, eliminating redundant jobs, and updating supporting scripts. This patch specifically addresses the last unresolved issue from v2, where SZEDER Gábor criticized the proposed `linux-exotic` name as misleading. The new name, `linux-feature-testbed`, explicitly ties the job to testing experimental or optional Git features, avoiding ambiguity about whether it tests an exotic platform. The resolution clears the way for the v3 reroll, which is otherwise ready for review.

Key technical details remain unchanged: the job continues to exercise Git with non-default options like `OPENSSL_SHA1_UNSAFE`, `GIT_TEST_SPLIT_INDEX`, and `GIT_TEST_FULL_IN_PACK_ARRAY`. The patch touches CI configuration files and supporting scripts but introduces no new functionality or behavioral changes. The series as a whole reduces CI complexity while maintaining or improving test coverage, including a resolved trade-off between reftable's foreign-SCM interoperability and SHA-256 coverage.

No further objections or alternatives are raised in this email. The naming consensus removes the final blocker for the v3 series, which is now expected to proceed to review with this patch updated to use `linux-feature-testbed`. The discussion highlights the project's emphasis on clear, descriptive naming in CI workflows, even at the cost of brevity.
