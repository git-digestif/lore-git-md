This thread is an Outreachy applicant’s two-patch series modernizing test patterns in `t/t0410-partial-clone.sh`. Dorine Tipo is replacing brittle shell pipelines and direct command substitutions with Git-native commands to eliminate silent exit-code masking and SHA-256 length assumptions. The first patch swapped a `git ls-tree | grep | head | cut` pipeline for `git rev-parse`, and the second patch just posted fixes a related anti-pattern: using `$(git rev-parse)` directly as a `test_grep` argument, which discards Git’s exit code. Both changes are small, mechanical, and grounded in `t/README`’s guidance.

The series is under initial review with no feedback yet. The patches are self-contained, touch only the test script, and pass the full test suite under both SHA-1 and SHA-256. Dorine has offered to clean up other direct-command-substitution instances in the same file in a follow-up series, but no objections or requests for changes have been raised so far. The changes align with the project’s preference for incremental improvements and are likely uncontroversial.
