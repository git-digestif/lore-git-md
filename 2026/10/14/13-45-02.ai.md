This is a test modernization patch series from an Outreachy applicant. The two patches target `t/t0410-partial-clone.sh`, fixing two related issues in the "rev-list stops traversal at missing and promised tree" test.

The first patch replaces a brittle `git ls-tree | grep | head | cut` pipeline with `git rev-parse HEAD:a_dir`. The old pipeline silently dropped Git’s exit code and hard-coded a SHA-1 length, so it produced truncated OIDs under SHA-256. The second patch stores the output of `git rev-parse` in shell variables before passing them to `test_grep`, ensuring that any Git failure breaks the `&&` chain rather than being masked.

The commit message reports that the full test suite passes under both SHA-1 and SHA-256. The author also notes that other instances of `"$(git ...)"` as direct arguments remain in the same file and offers to clean those up in a follow-up if this approach is approved.
