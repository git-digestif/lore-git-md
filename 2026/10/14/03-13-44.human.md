This is the ninth patch in Jon Simons' v2 series to speed up refspec matching in `git push`. It optimizes `match_explicit_refs()` by replacing two linear traversals of local and remote refs with `strmap` lookups, reducing the complexity from O(R * N + R * M) to O(R * rules) for R refspecs, N local refs, and M remote refs.

The patch consolidates the previously introduced `match_explicit_lhs_map()` helper into `match_explicit_lhs()` now that all call sites use the `strmap` variant. It also modifies `match_explicit()` to take `strmap` parameters and ensures the destination ref map is updated as new refs are added, so later refspecs see the current state. The performance impact is substantial: in the perf script, pushing 100 refspecs to a mirror client drops from 0.87s to 0.18s (a 79.3% improvement), while the empty-client case improves by 68.1%.

The change is well-scoped, touching only `remote.c` and maintaining the series' disciplined approach of introducing helpers in earlier patches before using them here. The commit message includes clear before/after timings and explains the algorithmic improvement. No behavioral changes are introduced—this is purely a performance optimization. The patch looks solid and is a key contributor to the series' overall 10–100x speedup claims.
