This is the **second patch in the v2 performance series** that speeds up `git push` refspec matching for large-scale deletions. It adds a **new perf test script** (`t/perf/p5516-push-delete-refspec.sh`) to measure the client-side cost of matching explicit delete refspecs against a server with 100,000 refs.

The test exercises two scenarios: an empty client (no local refs) and a mirror client (full local copy of server refs), each pushing 1, 10, or 100 delete refspecs with `--dry-run`. This isolates the refspec-matching overhead by avoiding object transfers or ref updates. Baseline timings on the author’s machine show **O(n²) scaling**: 100 refspecs take **2.5s (empty client)** or **6.85s (mirror client)**, while 1 refspec takes only **0.14s** or **0.21s**. These numbers will be used to demonstrate the **10–100x speedups** delivered by later patches in the series.

The test is minimal but effective: it creates a bare server with 100k branches, sets up the two clients, and runs `git push --dry-run` with varying numbers of delete refspecs. The use of `--dry-run` ensures the test remains non-destructive and repeatable. No behavioral changes are introduced here—this is purely infrastructure for measuring the performance regression the series aims to fix.

The patch is well-scoped and directly supports the series’ goal. The baseline numbers provide a clear benchmark for evaluating later optimizations, and the test design (isolating matching overhead, using `--dry-run`) is sound.
