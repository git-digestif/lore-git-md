This is the **final patch (6/6)** in Patrick Steinhardt’s **v2 ODB refactoring series**, completing the internal API cleanup by removing the `local` flag from the generic `struct odb_source`. The patch moves the flag into `struct odb_source_packed`, where it is still needed to propagate locality to packfiles, and updates all callers accordingly.

The change is **mechanical and well-scoped**: the `local` flag is no longer meaningful at the generic ODB source level now that alternates are handled entirely within the "files" backend. The patch updates the `odb_source_init()` signature, removes the flag from the base struct, and adjusts the packed and loose source implementations to match. The `ODB_FOR_EACH_OBJECT_LOCAL_ONLY` flag’s behavior is preserved by the "files" backend’s existing logic, which already skips non-local object directories.

The diff touches **10 files**, with the most significant changes in `odb/source.h` (removing the flag and updating the init function), `odb/source-packed.h` (adding the flag to the packed source), and `odb/source-loose.c` (simplifying its constructor). The patch also updates `midx.c` and `repack.c` to use the packed source’s `local` field instead of the generic one. No new tests are introduced, as the series relies on existing ODB tests to verify correctness.

Justin Tobler’s **substantive review** of v1 raised concerns about the `ODB_FOR_EACH_OBJECT_LOCAL_ONLY` flag’s abstraction leakage, and this patch directly addresses that by confining the `local` flag to the packed source. The change is uncontroversial and aligns with the series’ goal of simplifying the ODB API. The patch is **ready for `next`** and should merge cleanly once the rest of the series is approved.
