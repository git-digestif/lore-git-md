This is the **second patch in Jon Simons' v2 performance series** that speeds up refspec matching in `git push` for large-scale branch deletions. It adds a **new performance test script** (`t/perf/p5516-push-delete-refspec.sh`) to measure the client-side cost of matching explicit delete refspecs against a server with 100,000 refs.

The test exercises two scenarios: an empty client (no local refs) and a mirror client (full local copy of the server's refs), each pushing 1, 10, or 100 delete refspecs with `--dry-run`. This isolates the refspec-matching overhead without triggering object transfers or ref updates. Baseline timings on the author's machine show the current bottleneck: pushing 100 refspecs takes **2.5 seconds** (empty client) or **6.85 seconds** (mirror client). These numbers will be used to demonstrate the **10–100x speedups** achieved in later patches.

The test is well-designed for its purpose—it’s minimal, repeatable, and directly tied to the series' performance claims. No behavioral changes are introduced here; this is purely infrastructure for validating the upcoming optimizations. The patch itself is straightforward and unlikely to be controversial, though its value depends on the rest of the series landing. If you care about `git push` performance in large repositories, this test provides the benchmark to watch.
