This is the first patch in Patrick Steinhardt’s six-patch **refactoring and performance series** for the Git object database’s "files" backend. The patch fixes a **performance regression** introduced by earlier ODB abstraction work: when alternates are present, Git now checks loose objects before packfiles, leading to unnecessary `stat()` syscalls. The fix reorders loops in `odb_source_files_read_object_info()` to prioritize packfile checks across all alternates before falling back to loose objects, restoring the pre-abstraction behavior and delivering a **1.89x speedup** in object lookup benchmarks.
