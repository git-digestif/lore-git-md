This is the seventh patch in Patrick Steinhardt’s eight-patch CI housekeeping series (v3). It removes now-dead Python 2 logic from the CI scripts after the last Ubuntu 20.04 job was dropped in an earlier patch.

The change is straightforward: `ci/install-dependencies.sh` hard-codes `python3` instead of the conditional `PYTHON_PACKAGE` variable, and `ci/lib.sh` drops the Ubuntu-version check that once selected between Python 2 and Python 3. The commit message explains that Python 2 reached end-of-life in 2020, none of the current CI images still package it, and the world has moved on, so keeping the conditional logic serves no purpose.

The patch is mechanical, well-motivated, and uncontroversial. It touches only the CI infrastructure and has no user-visible impact. If any follow-up discussion arises, it will likely focus on whether the hard-coded `python3` could cause issues for legacy workflows not covered by the current CI matrix, but the commit message already addresses this concern.
