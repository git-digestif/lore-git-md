This is a **documentation** patch series, the fourth and final reroll of Julia Evans’s beginner-focused Git tutorial. The series replaces the outdated `gittutorial` man page with a two-part guide tested on 112 users, covering local repository setup and pushing to a remote host. The v4 update finalizes platform-specific authentication instructions (SSH for macOS/Linux, Git Credential Manager for Windows) and incorporates all remaining surface-level feedback from prior rounds, including editor warnings, SSH key handling, and Windows tooling clarifications.

The patch touches only `Documentation/gittutorial.adoc`, deleting the old content in the first patch and adding the new tutorial in the second. No code or behavior changes are introduced. The author frames the tutorial as "good enough" for merging, with post-merge iteration planned to address branching and collaboration topics based on user feedback. Junio has marked the topic as "Expecting a reroll" for v4, signaling readiness to merge once this version is submitted.

Key technical details include the tutorial’s compatibility with Git 2.23.0+ (due to `git switch` usage) and its reliance on user-tested workflows. Open questions—such as whether to start with `git init` or `git clone`, or how to handle editor configuration—remain unresolved but are explicitly scoped as post-merge improvements. The platform-specific split in v4 resolves earlier tensions about Windows tooling assumptions, while SSH key instructions now use generic `ssh-keygen` commands with notes about filename variability.

Review feedback has been exclusively surface-level since v2, focusing on wording, formatting, and UX refinements. Ben Knoble’s latest review confirmed the editor warning phrasing is neutral and clear, and Junio’s AsciiDoc formatting suggestions were incorporated (though the author retained Setext-style headings due to linter constraints). The series is uncontroversial and mechanically complete, pending Junio’s final review.
