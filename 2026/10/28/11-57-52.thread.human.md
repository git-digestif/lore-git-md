This thread is a seven-part refactoring series by Patrick Steinhardt that prepares `builtin/commit-graph.c` for pluggable commit-graph backends. The goal is to eliminate global state, simplify option handling, and remove reliance on `the_repository`, all while touching only this single file. The series is now complete with the final patch, which moves the last remaining global (`opts`) into local scope, removing the need for a `static` options array.

The series has been under review since its initial v1 posting. The most debated change was the removal of the undocumented global `--object-dir=` switch, which Patrick argues is atypical for Git commands and unused in tests, though it could break existing scripts. The rest of the series is uncontroversial cleanup: de-globalizing structures, replacing dynamic option handling with a preprocessor macro, and propagating an explicit repository pointer through the call chain. No on-disk format or test coverage changes were made.

Key participants include Patrick as the author, but no other reviewers have weighed in yet. The series is part of his larger effort to abstract commit-graph backends and aligns with the ongoing `the_repository` removal project. The next steps will likely depend on whether reviewers object to the global `--object-dir=` removal or request any adjustments to the mechanical cleanups.
