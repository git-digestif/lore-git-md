This thread is Patrick Steinhardt’s seven-patch series refactoring `git commit-graph` to remove global state and prepare for pluggable backends. The series targets only `builtin/commit-graph.c`, reducing its line count slightly while eliminating reliance on `the_repository` and simplifying option handling.

The first five patches have already been posted; this sixth patch moves the commit-graph write options from a file-scope static variable into a local stack variable, using a small helper struct to keep the config parser working. The change is purely internal and doesn’t alter user-visible behavior. The only notable change so far is the removal of the undocumented global `--object-dir=` switch, which Patrick flagged for discussion—it could break scripts, even if it wasn’t tested or documented.

No reviews have landed yet, and Junio hasn’t weighed in on merge status. The series is still under review, with one more patch to come. The refactoring is part of Patrick’s larger effort to abstract commit-graph backends, aligning with the ongoing project to remove `the_repository` globals.
