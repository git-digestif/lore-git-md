This is the third patch in Patrick Steinhardt’s seven-patch series refactoring `builtin/commit-graph.c` to prepare for pluggable commit-graph backends. It removes all remaining uses of the `the_repository` global in favor of the repository pointer passed to each subcommand function.

The patch is a straightforward, mechanical conversion: every call that previously referenced `the_repository` now uses the `repo` parameter instead. The changes are confined to `builtin/commit-graph.c` and touch only internal plumbing; there are no user-visible behavior changes, no on-disk format changes, and no test coverage changes. The commit message explains why the conversion is safe: the command cannot run outside a repository, and the repository pointer is already available in every code path.

This patch aligns with the ongoing `the_repository` removal effort and is uncontroversial on its own. The only potential friction in the series comes from a later patch that removes the global `--object-dir=` switch, but that is unrelated to this change. The patch is well-scoped, clearly motivated, and looks ready for review.
