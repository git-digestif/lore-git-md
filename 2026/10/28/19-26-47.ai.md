This is a refactoring patch targeting the `git diff-files` built-in command. It converts ad-hoc option parsing in `cmd_diff_files()` to use Git’s standard `parse-options` API, replacing a manual loop that checks for `--base`, `--ours`, `--theirs`, and `-q` with a declarative array of `OPT_*` macros. The patch touches only `builtin/diff-files.c` (28 lines changed) and adds `#include "parse-options.h"`. The new implementation prevents negated forms (`--no-base`, etc.) via `PARSE_OPT_NONEG`, matching the pattern used in `builtin/checkout.c` for similar stage-selection options. No behavior change is intended; the patch is purely about code hygiene and consistency.
