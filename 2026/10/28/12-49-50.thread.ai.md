Subject: `git check-ignore -v` incorrectly matches paths with trailing slashes against CRLF blank lines
Series version: standalone patch (no series)
Originating author: Mike Beaton
Thread type: bug report

Core problem or goal
The `git check-ignore -v` command incorrectly matches directory paths ending in a trailing slash (`foo/`) against a blank line in `.gitignore` when that blank line uses CRLF line endings. The same path is correctly ignored (no match) when the blank line uses LF line endings. This violates the documented semantics of blank lines in `.gitignore`, which should never match any file or directory.
