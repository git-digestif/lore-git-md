This is a brief follow-up in the build system thread about enabling ccache to cache objects built with Git’s precompiled header. Harald Nordgren acknowledges Patrick Steinhardt’s suggestion that ccache sloppiness settings for precompiled headers should ideally be handled upstream in Meson rather than in Git’s build scripts. He agrees to leave the Meson build system untouched in this patch and hints that he might pursue a separate contribution to Meson itself, though no concrete action is proposed yet.

The thread’s earlier open question about cross-build-system consistency remains unresolved, but the focus stays on the minimal Makefile-only fix for now. No new technical concerns are raised, and the patch’s core premise — enabling ccache caching for precompiled-header builds — is still uncontested. The discussion feels like a polite detour rather than a roadblock; the patch itself looks ready to move forward once the Makefile semantics question (raised by Ben Knoble) is clarified.
