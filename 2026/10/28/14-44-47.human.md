This is the second patch in Julia Evans’s **v4 documentation series**, replacing the outdated `gittutorial` man page with a beginner-focused two-part guide. The new tutorial is user-tested with 112 participants and covers local repository setup (steps 1–7) and pushing to a remote host (steps 8–12). This patch deletes the old content and introduces the new guide, which is designed to be completed in under an hour and avoids overwhelming beginners with concepts like branching or collaboration.

The tutorial makes pragmatic choices to simplify the onboarding experience: it starts with `git init` (not `git clone`), uses `git commit -m` for quick commits, and provides platform-specific authentication instructions (SSH for macOS/Linux, Git Credential Manager for Windows). It also includes troubleshooting sections for common pain points (e.g., SSH key setup, `vi` editor traps) and explicitly defers advanced topics like branching to future iterations. The content is vendor-neutral but acknowledges the prevalence of GitHub/GitLab, and it targets Git 2.23.0+ due to `git switch` usage.

The patch is **mechanically complete and uncontroversial**. All substantive feedback from prior rounds (v1–v3) has been addressed, including platform assumptions, editor warnings, and SSH key handling. The latest refinements—such as neutral phrasing around `vi` and generic `ssh-keygen` instructions—were finalized in response to surface-level reviews from Ben Knoble and Junio. The series is now ready for merging, with post-merge improvements planned based on user feedback. No code or behavior changes are introduced; this is purely a documentation update.
