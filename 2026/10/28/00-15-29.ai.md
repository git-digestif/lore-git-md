This is the third and final patch in William Hatfield’s v2 series enhancing `git submodule foreach` with dependency-ordered traversal options. It introduces `--reversive` as a shorthand combining `--recursive`, `--reverse-traversal`, and `--include-superproject`, addressing the ergonomic concern that users would otherwise need to remember and type three separate flags for a common workflow.

The implementation is straightforward: the new flag is added to the option parser in `builtin/submodule--helper.c`, where setting it flips the three underlying boolean flags. The shell script wrapper (`git-submodule.sh`) and bash completion (`contrib/completion/git-completion.bash`) are updated to recognize the new option, and the documentation (`Documentation/git-submodule.adoc`) is extended to explain the shorthand in both the synopsis and the detailed description. The test suite (`t/t7427-submodule-foreach-reversive.sh`) gains a new test that verifies the shorthand produces the same output as the three long options.

This patch is a clean, minimal addition that does not alter the existing behavior—all three long options remain available and work exactly as before. The only open question is whether the name `--reversive` will be accepted; Junio has previously suggested algorithmic (`--postorder-traversal`) or directional (`--bottom-up-traversal`) alternatives, but no technical objections to the implementation itself remain. The series as a whole is now feature-complete and awaits only a final naming decision before it can be queued.
