This thread is a small, uncontroversial refactoring patch from Okhuomon Ajayi as part of the ongoing effort to remove Git’s global `the_repository` variable. The patch updates two functions in `bundle-uri.c` to use an explicitly passed `struct repository *` instead of the global, making no behavioral changes. Karthik Nayak reviewed it and confirmed the approach is safe, as the callers already pass the correct repository. The only loose end—a remaining indirect dependency on `the_repository` via `fetch_pack_fsck_objects()`—was noted by the author but not contested, and no follow-up work has been requested. The patch is ready for integration.
