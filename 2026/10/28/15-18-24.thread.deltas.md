## 2026/10/28

- [2026/10/28/15-18-24 by Kristofer Karlsson via GitGitGadget <gitgitgadget@gmail.com>] Kristofer Karlsson proposed a fix in odb.c to skip an alternate whose repository is our own when listing alternate refs, implemented by comparing paths (described as a hack mainly to measure the bug's cost), because inside the quarantine the repository's own object directory is passed as an alternate and --alternate-refs therefore lists all of its refs including hidden ones.
- [2026/10/28/15-18-24 by Kristofer Karlsson via GitGitGadget <gitgitgadget@gmail.com>] He explained the fix is safe because alternate refs only serve as negative tips assumed to be complete, so dropping some can only make the traversal walk further, never make it accept a missing object.
- [2026/10/28/15-18-24 by Kristofer Karlsson via GitGitGadget <gitgitgadget@gmail.com>] He added tests that the quarantine no longer lists the repository's own refs as alternate refs, that refs of a real alternate are still listed, and a perf test pushing a single commit into a repository with about 200,000 refs hidden by receive.hideRefs.
- [2026/10/28/15-18-24 by Kristofer Karlsson via GitGitGadget <gitgitgadget@gmail.com>] The perf test showed push time with hidden refs dropping from 0.31s to 0.10s (-67.7%) and without hidden refs from 1.25s to 1.03s (-17.6%), since previously hidden refs were loaded via --alternate-refs and without hidden refs every ref was listed twice.

## 2026/10/29

- [2026/10/29/16-57-42 by Justin Tobler <jltobler@gmail.com>] Justin Tobler analyzed the quarantine alternate-refs issue: because the "real" ODB is passed as an alternate, all of the main repository's refs (including the hidden refs the connectivity check deliberately excludes) are considered a second time as uninteresting tips. He judged the patch's path comparison a hack, attributing the underlying problem to child processes having no concept of an ODB transaction, and suggested that for the git-rev-list(1) connectivity check the quarantine directory need not be the primary object directory (since rev-list writes no objects), which would avoid reprocessing the real ODB's refs; he was unsure whether other in-quarantine processes would be affected in practice, floated a mechanism to explicitly propagate a pending transaction across process boundaries, and proposed making the connectivity check an explicit part of the ODB transaction interface (e.g., an `odb_transaction_files_check_connected()` callback for the "files" backend), which he offered to explore further if it seemed reasonable.
- [2026/10/29/17-24-54 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano asked whether exporting the parent's real object directory via a `GIT_QUARANTINE_OBJECT_DIRECTORY` variable would let quarantine children identify which alternate is the real ODB and skip its refs, and wondered whether the value of the existing `GIT_QUARANTINE_ENVIRONMENT` (currently used only as a one-bit "are we in quarantine" flag) could instead be changed to name the real object directory, avoiding a new variable.
