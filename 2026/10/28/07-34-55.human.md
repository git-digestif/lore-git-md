This is a build system follow-up in the thread about enabling ccache to cache objects built with Git’s precompiled header. Patrick Steinhardt weighs in on the earlier side discussion about whether the Meson build system should receive the same ccache sloppiness treatment as the Makefile.

Patrick suggests that ccache-related optimizations like this belong upstream in Meson itself rather than in Git’s build scripts. He points to an open Meson issue (14662) discussing ccache and precompiled headers as evidence that the problem is already on Meson’s radar. While he doesn’t object to someone adding the same sloppiness flags to Git’s Meson instructions, he clearly frames it as a lower priority and implies that the proper fix should come from the Meson project. The thread remains open on the question of build-system parity, but Patrick’s reply effectively closes the door on making it a requirement for this patch.
