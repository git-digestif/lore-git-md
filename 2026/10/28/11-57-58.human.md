This is the sixth patch in Patrick Steinhardt’s seven-patch series refactoring `builtin/commit-graph.c` to prepare for pluggable commit-graph backends. The patch de-globalizes the write options handling by moving the `write_opts` structure from a global variable into a local context passed explicitly through the configuration callback.

The change is confined to `builtin/commit-graph.c` and introduces a new `commit_graph_write_config_data` struct to hold the write options during configuration parsing. This eliminates the global `write_opts` variable, replacing it with a locally scoped instance initialized in `cmd_commit_graph_write`. The `options` array, which previously relied on the global `write_opts`, is now non-static to reference the local variable.

The refactoring is mechanical and does not alter user-visible behavior. It aligns with the series’ broader goal of removing global state to simplify future backend pluggability. The commit message notes that the new struct is slightly over-engineered for its current single-member use but anticipates expansion in the next patch. No test failures or performance regressions are expected, as this is purely internal restructuring. The patch is uncontroversial and looks well-crafted, continuing the series’ steady progress toward its goal.
