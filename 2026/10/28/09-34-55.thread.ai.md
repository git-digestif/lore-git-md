Subject: [PATCH] bundle-uri: use passed repository parameter
Series version: v1 (first iteration, no cover letter)
Originating author: Okhuomon Ajayi
Thread type: patch series (refactoring, part of the `the_repository` removal effort)

Core problem or goal
Refactor two functions in `bundle-uri.c` (`unbundle_from_file()` and `fetch_bundle_uri()`) to use an explicitly passed `struct repository *r` instead of the global `the_repository`, advancing the project-wide goal of eliminating implicit global state. The change is mechanical and does not alter behavior.

Current status
Queued in Junio's `next` branch for integration testing (announced 2025-06-12 in "What's cooking" context). The patch is uncontroversial, aligns with established project direction, and was previously reviewed by Karthik Nayak as safe. One deliberate limitation remains: `unbundle_from_file()` still depends on `the_repository` indirectly via `fetch_pack_fsck_objects()`, which reads config from the global repository; this is left for a potential future patch.

Key technical details
- Files touched: `bundle-uri.c`
- Functions updated: `unbundle_from_file()`, `fetch_bundle_uri()`
- Symbols changed: `the_repository` → `r` in calls to `get_main_ref_store()` and `trace2_region_enter`/`leave`
- No new or renamed symbols; no on-disk format changes; no test coverage changes
