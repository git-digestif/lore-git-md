This is a **documentation** patch, the first of two in Julia Evans’s v4 series replacing the outdated `gittutorial` man page with a beginner-focused guide. This patch deletes the old tutorial entirely, clearing the way for the new content in the follow-up patch. The removal is done as a separate commit to improve patch readability on the mailing list, since none of the old content is reused.

The deleted tutorial is a 671-line AsciiDoc file that walks users through basic Git operations—initializing a repository, making commits, branching, merging, and collaborating via `git pull`/`git push`. While comprehensive, it reflects workflows and tooling assumptions (e.g., `vi`, SSH, Linux-centric paths) that have become outdated or confusing for modern beginners, particularly Windows users. The new tutorial, slated for the next patch, addresses these issues with user-tested content and platform-specific instructions.

No technical changes or new symbols are introduced here; this is purely a deletion. The patch is uncontroversial and mechanically complete, pending Junio’s final review of the v4 series. The series as a whole is ready for merging, with all substantive feedback incorporated in prior iterations.
