This is a test modernization patch in the ongoing effort to replace legacy test patterns. Junio C Hamano replies to Hardik Kumar’s standalone patch that replaces `! git refs rename` with `test_must_fail git refs rename` in `t/t1467-refs-rename.sh`.

The patch itself remains unchanged; only the rationale in the commit message needs adjustment.
