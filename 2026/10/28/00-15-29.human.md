This is the final patch in William Hatfield’s v2 series enhancing `git submodule foreach` with dependency-ordered traversal options. It adds `--reversive` as a shorthand flag that combines `--recursive`, `--reverse-traversal`, and `--include-superproject` into a single option.

The implementation is straightforward: the new flag sets the three underlying options in `builtin/submodule--helper.c`, updates the command-line usage and completion scripts, and extends the test suite to verify that `--reversive` produces the same output as the longhand combination. Documentation is updated to explain the shorthand and show it in the synopsis and option list.

The patch is clean, well-tested, and follows the project’s conventions. It directly addresses the feedback from v1 that users would benefit from a concise way to express the common case of visiting submodules in post-order and then the superproject. No new technical concerns are raised; the only remaining discussion is about the name itself (`--reversive` vs more algorithmic or directional alternatives), which the maintainer has already flagged as the last open question.
