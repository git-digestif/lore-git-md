This is the second patch in Patrick Steinhardt’s seven-patch series refactoring `builtin/commit-graph.c` to prepare for pluggable commit-graph backends. The patch removes a single line: the now-unused `extern int read_replace_refs` declaration. The variable was made file-local in commit d24eda4e03c (repository: create disable_replace_refs(), 2023-06-06), and users now interact with it via the `disable_replace_refs()` function instead. This is a straightforward cleanup with no behavior change, no test implications, and no user-visible impact. The change is uncontroversial and aligns with the series’ goal of eliminating stale or redundant declarations as part of broader refactoring.
