This is a small refactoring patch from Junio C Hamano. It removes the unused function `author_ident_sufficiently_given()` from Git's ident subsystem, which handles author and committer identity information.

The commit message explains that the function was introduced in 2012 alongside `committer_ident_sufficiently_given()` but was never actually used in Git's codebase. Only the committer version remains relevant, as it checks whether the committer's identity is properly configured and nudges users to set `user.name` and `user.email` if needed.

The change is straightforward: the function is deleted from `ident.c`, and its declaration is removed from `ident.h`. The patch is minimal, touching only two files and removing six lines of code. There’s no behavior change, as the function was unused.

This looks like a clean, well-motivated cleanup—exactly the kind of small improvement Junio often contributes to keep the codebase tidy. No controversy or follow-up work is expected.
