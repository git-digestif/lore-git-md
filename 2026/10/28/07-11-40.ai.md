This is the second patch in Patrick Steinhardt’s six-patch v3 series restoring dynamic reload of alternate object databases in the files-based ODB backend. The patch is a targeted fix for a behavioral regression in `git receive-pack` when a quarantine directory is active: it ensures alternates are always reloaded from the repository’s real object directory, not from the quarantine.

The change is minimal—just two lines in `odb/source-files.c`—replacing `files->dirs->abspath` with `files->base.path` in `odb_files_dir_is_usable()` and `prepare_alternates()`. This guarantees that even when the quarantine is the current primary ODB, the alternates file is read from the repository’s real object directory, restoring the pre-regression behavior introduced by commit bdee7b3013 (July 2026). The fix is well-motivated, narrowly scoped, and does not affect the performance optimizations introduced later in the series. All feedback from v2 has been addressed, and the patch is ready for integration.
