Core problem or goal
Refactor `range-diff.c` to eliminate implicit use of the global `the_repository` variable in two functions (`output_pair_header` and `patch_diff`) by instead using the repository stored in the `diffopt` structure that is already passed to them. The patch also updates `get_filespec` to accept a hash algorithm parameter rather than relying on the global `the_hash_algo`. This change is mechanical and aligns with the ongoing, high-volume effort to remove `the_repository` from Git’s codebase.

Under review; v2 posted in response to surface-level feedback on commit message and title clarity. The code itself is unchanged from v1. The patch remains a single, self-contained refactoring that touches only `range-diff.c` and does not introduce new behavior or on-disk format changes.
