This is a maintainer review of a bugfix patch that stops `git pack-objects --exclude-promisor-objects-best-effort` from crashing when it encounters missing objects in partial clones. The patch itself is already well-motivated, narrowly scoped, and thoroughly tested by Patrick Steinhardt, the subsystem maintainer.

Junio’s feedback is a single, focused suggestion: the call to `odb_read_object_info_extended()` should explicitly pass `OBJECT_INFO_SKIP_FETCH_OBJECT` rather than relying on the global `.fetch_if_missing` being set to 0 elsewhere. This is a clarity and robustness improvement, not a functional change. The patch is otherwise ready; once this bit is added, it will almost certainly graduate to `next` and then `master`.
