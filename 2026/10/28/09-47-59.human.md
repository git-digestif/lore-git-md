This is a memory-leak bugfix in the transport subsystem, part of a three-patch series (v5, patch 1/3). Karthik Nayak identifies a leak in `transport-helper.c`: when a remote helper is used, the `git_transport_options` structure is not properly freed, while the same structure is correctly cleaned up in `transport.c`. The patch introduces a new helper function `transport_options_release()` that centralizes the cleanup logic and calls it from both files. The change is small, mechanical, and well-motivated: it plugs a leak without altering behavior, and the commit message clearly explains the problem and the fix. No controversy is evident; this looks like a straightforward improvement that should be uncontroversial.
