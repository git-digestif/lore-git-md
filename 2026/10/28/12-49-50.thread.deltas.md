# Thread deltas

## 2026/10/28

- [2026/10/28/12-49-50 by Mike Beaton <mjsbeaton@gmail.com>] Mike Beaton reported that `git check-ignore -v` incorrectly reports paths with trailing slashes (e.g., `foo/`, `.foo/`) as ignored by an empty pattern when `.gitignore` contains a single blank CRLF line, while the same paths without trailing slashes and the same check with an LF-only blank line return no matches; reproduced on Git 2.56.0 and 2.51.1 on Linux, with real files inside the directories remaining visible to `git status` and eligible for `git add`.
