This is a brief follow-up in the build system thread about ccache and precompiled headers. Harald Nordgren acknowledges Patrick Steinhardt’s suggestion that ccache sloppiness settings for precompiled headers should ideally be handled upstream in Meson rather than in Git’s build scripts. He accepts leaving the Meson build system unmodified for now and hints at possibly opening a pull request in the Meson project itself to address the issue there. The thread’s open question about cross-build-system consistency remains unresolved, but no further action is proposed for Git’s build system at this time.
