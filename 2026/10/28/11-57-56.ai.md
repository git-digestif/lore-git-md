This is the fourth patch in Patrick Steinhardt’s seven-patch series refactoring `builtin/commit-graph.c` to prepare for pluggable commit-graph backends. The patch removes the global `--object-dir=` switch, which previously allowed users to specify the object directory either before or after the subcommand (e.g., `git commit-graph --object-dir= write` or `git commit-graph write --object-dir=`). The change restricts `--object-dir=` to subcommand-specific use only, aligning the command’s option handling with Git’s typical conventions.

The commit message justifies the removal on two grounds: the global switch is undocumented, unused in tests, and atypical for Git commands, and it forces the code to track the object directory via global state. The patch itself is minimal, removing the concatenation of `builtin_commit_graph_options` with `common_opts` (which included the global `--object-dir=` option) and simplifying the option-parsing logic. The result is a single `options` array that only includes subcommand-specific options.

This is the most user-visible change in the series and the one explicitly flagged for discussion in the cover letter. While the patch is technically straightforward, the removal of a previously accepted global option could break existing scripts or workflows, even if the behavior was undocumented. The patch does not introduce new tests or modify existing ones, reflecting its focus on internal cleanup rather than new functionality.

The change is part of Patrick’s broader effort to eliminate global state in `builtin/commit-graph.c`, which will simplify future work on pluggable backends. The patch is confined to a single file and does not affect on-disk formats or performance. Key details for follow-up discussion include the renamed `options` array (formerly `builtin_commit_graph_options`) and the removal of the `parse_options_concat` call, which previously merged global and subcommand-specific options. The patch also removes the `FREE_AND_NULL(options)` call, as the options array is now statically allocated.
