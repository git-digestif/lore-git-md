This is the final patch in Patrick Steinhardt’s seven-part refactoring series preparing `builtin/commit-graph.c` for pluggable backends. It completes the de-globalization effort by eliminating the last remaining global state in the file: the `opts` structure that holds common options for the "verify" and "write" subcommands.

The patch moves the `opts` structure from file scope into the local scope of each subcommand function, making it a stack variable. Because the `options` array now references this local variable, it can no longer be `static`, so the `static` modifier is removed. The change is purely mechanical and confined to `builtin/commit-graph.c`; no other files are touched. The `struct commit_graph_write_config_data` introduced in patch 6/7 is extended to carry a pointer to the local `opts` structure, allowing the config callback to access it without relying on global state.

This patch is a straightforward cleanup that aligns with the series’ goal of eliminating globals and simplifying option handling. It has no user-visible behavior changes and is unlikely to be controversial. The only technical consequence is the loss of the `static` modifier for the `options` array, which is a necessary trade-off for removing global state. The patch is well-scoped and completes the series’ refactoring of `builtin/commit-graph.c`. Key names modified include the `opts` structure (now local to each subcommand) and the `options` array (no longer `static`).
