This is patch 6/7 in Patrick Steinhardt’s seven-patch series refactoring `builtin/commit-graph.c` to prepare for pluggable commit-graph backends. The patch de-globalizes the commit-graph write options by moving them from a file-scope `static struct commit_graph_opts write_opts` into a local variable inside `cmd_commit_graph_write()`. To keep the config parser working, it introduces a small helper struct `commit_graph_write_config_data` that carries the write options pointer through the config callback. The change is purely internal: no user-visible behavior is altered, and the only mechanical consequence is that the `options` array can no longer be `static` because it now references a stack variable.

The patch is a straightforward refactoring step that continues the series’ theme of eliminating global state. It is well-scoped, confined to a single function, and clearly paves the way for the next patch (7/7), which will add a second field to the new config-data struct. No test failures or performance regressions are expected. Key names introduced: `struct commit_graph_write_config_data`, `config_data`, and the local `write_opts` variable.
