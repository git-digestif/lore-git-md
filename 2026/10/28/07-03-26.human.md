This is a bugfix patch that restores the absolute path output in the "Initialized empty Git repository" message for `git init` and `git init --reinit`. The regression was introduced in the current development cycle (Git 2.56) and is now fully resolved with this third iteration of the patch.

Patrick Steinhardt, the primary reviewer, has confirmed he is satisfied with the latest version. The patch touches `builtin/init-db.c` to use the absolute path and includes a refined test in `t/t0001-init.sh` that verifies the full output message. All prior feedback—including test improvements—has been incorporated, and the patch is uncontroversial and ready for integration. The urgency stems from the need to avoid shipping the behavior change in the upcoming Git 2.56 release.
