This thread is about a performance bug in Git’s object quarantine mechanism during `receive-pack`. When a push is received, Git quarantines incoming objects and checks connectivity by listing all refs from the repository’s object directory—including hidden ones—even though hidden refs were explicitly excluded from connectivity checks in prior work (`bcec6780b2`). This causes a measurable slowdown: in repositories with 200,000 hidden refs, small pushes take 67.7% longer (0.31s → 0.10s), and even without hidden refs, every ref is listed twice, creating a 17.6% regression.

Kristofer Karlsson proposed a patch that skips self-referential alternates in `odb.c` as a proof-of-concept workaround, along with performance tests demonstrating the issue. Justin Tobler suggested a cleaner long-term fix: adding an `odb_transaction_files_check_connected()` callback to the ODB transaction interface, framing it as a natural extension of Patrick Steinhardt’s ongoing ODB abstraction effort. No objections to either approach had been raised—until Junio C Hamano weighed in with a third option.

Junio proposed repurposing the existing `GIT_QUARANTINE_ENVIRONMENT` variable—currently a boolean flag—to carry the parent’s object directory path. This would let child processes (like `rev-list --alternate-refs`) identify and skip the repository’s own refs without path comparisons or new APIs, fixing the root cause in the quarantine plumbing (`tmp-objdir.c`) rather than papering over it in `odb.c`. His framing suggests a preference for this approach over the current patch or Justin’s callback idea, though he hasn’t explicitly rejected either.

The thread is now focused on architectural trade-offs: whether to merge the path-comparison hack as a stopgap, adopt Junio’s environment variable tweak, or pursue Justin’s ODB callback. The bug’s existence and performance impact are settled; the open question is how to fix it cleanly. No maintainer decision has been made yet, and the patch remains under review. Key participants—Kristofer, Justin, and Junio—are all engaged, with Patrick Steinhardt (ODB maintainer) still to weigh in.
