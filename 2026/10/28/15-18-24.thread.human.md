This thread is about a performance bug in Git’s object quarantine mechanism during `receive-pack`. When a quarantine environment passes the repository’s own object directory as an alternate, `rev-list --alternate-refs` lists every ref twice, creating a measurable slowdown—especially in repositories with many hidden refs. The discussion has settled on Jeff King’s minimal fix: a 10-line commondir comparison in `builtin/rev-list.c` that avoids quarantine-specific logic entirely. This approach is faster (67.7% speedup with 200,000 hidden refs) and more robust than earlier versions, and it’s compatible with Patrick Steinhardt’s concurrent ODB abstraction work.

Kristofer Karlsson originally proposed the fix and provided performance data and tests. After several iterations, the design debate was resolved when Justin Tobler, the ODB abstraction maintainer, endorsed Peff’s commondir comparison as the best short-term solution. Junio merged Kristofer’s v2 patch to `next` on June 12, but the thread has since moved toward Peff’s simpler approach. The only remaining work is to implement the commondir comparison and adjust the commit message to clarify that the patch doesn’t overgeneralize about how alternate refs are used. Junio has just approved Kristofer’s proposed rewording, so the patch is now ready for its final form.

The fix touches `builtin/rev-list.c` and is expected to graduate to `master` once the updated version is posted. No open technical objections remain, and the performance benefits are well-documented in the perf test suite.
