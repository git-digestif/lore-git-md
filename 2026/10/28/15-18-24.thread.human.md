This thread is about a performance fix for Git’s object quarantine mechanism in `receive-pack`, which was unnecessarily loading all refs—including hidden ones—from the repository’s own object directory during connectivity checks. The issue caused a measurable slowdown, particularly in repositories with many hidden refs, where a 65.5% speedup was measured after the fix. The discussion converged on Jeff King’s minimal 10-line fix in `odb.c`, which compares the alternate’s path directly against the repository’s commondir to skip self-referential alternates. This approach is now the definitive solution, endorsed by Jeff King, Justin Tobler, and Junio C Hamano, and has been merged to the `next` branch as v3.

The patch touches `odb.c` (core logic), updates documentation, and adds a new performance test (`p5552-push-hidden-refs.sh`). It avoids quarantine-specific logic, making it future-proof and compatible with Patrick Steinhardt’s concurrent `odb-reload-alternates` series. The only remaining work is adjusting the commit message to better reflect the rationale behind the commondir comparison, but this is not a blocker for merging. The thread is effectively closed on the technical side, with no further changes expected.
