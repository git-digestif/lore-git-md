Core problem or goal
Git’s object quarantine mechanism in `receive-pack` unnecessarily loads all refs—including hidden ones—from the repository’s own object directory during connectivity checks. When the quarantine environment passes the repository’s object directory as an alternate, `rev-list --alternate-refs` lists every ref twice, creating a measurable performance regression. The discussion has **fully converged on Jeff King’s commondir comparison** as the **definitive short-term fix**: compare the alternate’s path directly against the repository’s commondir in `refs_from_alternate_cb()`, eliminating quarantine-specific logic entirely. This approach is minimal (10 lines), future-proof, and avoids heuristics. The performance impact is significant: a **65.5% speedup** in repositories with 200,000 hidden refs (0.29s → 0.10s) and a **16.7% improvement** even without hidden refs, as documented in the perf test (`p5552-push-hidden-refs.sh`).
