This is a refactoring patch targeting the `git diff-files` built-in command. It converts the manual, ad-hoc option parsing in `cmd_diff_files()` to use Git's standard `parse-options` API, replacing a hand-rolled loop with `strcmp()` calls with structured `OPT_*` macros.

The patch touches only `builtin/diff-files.c` and is a pure code cleanup with no behavior change. It adds the `parse-options.h` header, defines a `struct option` array for `--base`, `--ours`, `--theirs`, and `-q`, and replaces the manual parsing loop with a single `parse_options()` call. The `--base`, `--ours`, and `--theirs` options are marked `PARSE_OPT_NONEG` to prevent negated forms (e.g., `--no-base`), matching the pattern used in `builtin/checkout.c` for similar stage-selection options.

The commit message is clear and specific, justifying the change with consistency, maintainability, and the benefits of the `parse-options` API (auto-generated help, completion support, option abbreviation).
