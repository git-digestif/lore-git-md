This is a process-oriented reply from Junio C Hamano, the Git maintainer, flagging a technical issue with the email threading of Domen Kožar’s `[PATCH v3 0/2]` series. The cover letter and two patches are not properly linked in the mailing-list archive: the patches reference a `cover.1791152172.git.domen@cachix.org` message-ID that does not exist, while the actual cover letter uses a different message-ID (`d550ede0-6a33-4eea-a6dd-051d110b68e5@mtasv.net`). Junio reports that his automation tools cannot locate the thread, and he confirms the missing message-ID returns a 404 from the public archive. He requests that someone investigate how `git send-email` was misconfigured to produce this breakage, document the pitfall, or update the tool to detect and prevent it. There is no discussion of the patch content itself.
