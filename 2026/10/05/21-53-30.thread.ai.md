Core problem or goal
Git for Windows 2.56.0(2) is a bugfix release addressing regressions introduced in the original v2.56.0 (2026-09-28) related to the MINGW64 → UCRT64 migration. The release restores functionality broken by the toolchain switch: Git Credential Manager compatibility, suppression of user-wide config via `GIT_CONFIG_GLOBAL=NUL`, Authenticode signatures on x64 executables, and client-certificate authentication for pushes. OpenSSL is updated to v3.5.9, but this is not framed as a regression fix.

Current status
Released. All artifacts (installers, portable builds, MinGit variants) are published with SHA-256 checksums. The announcement is distributed to the Git mailing list and `git-packagers@googlegroups.com` for downstream redistributors.
