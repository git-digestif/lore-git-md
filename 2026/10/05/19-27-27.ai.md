This is a surface-level review of the first patch in Patrick Steinhardt’s 13-patch series refactoring the Git object database (ODB) to move alternates handling into the files backend. The reviewer, Karthik Nayak, notes that the patch itself looks correct but criticizes the commit message for not explaining *why* the change is being made. The patch shifts packfile path resolution from `fill_oids_from_packs()` to its caller (`builtin/commit-graph.c`), requiring fully resolved paths to be passed in instead of relative ones. While the technical change is straightforward and unlikely to be controversial, the reviewer’s feedback highlights a gap in the commit message’s motivation—it describes *what* the patch does but not how this step fits into the larger architectural goal of making the ODB more backend-agnostic. This is a minor nit, but it underscores the importance of tying individual patches to the series’ broader context, especially in a large refactoring effort. The patch itself is a small, mechanical step with no behavior changes, and existing tests for `--stdin-packs` should cover it.
