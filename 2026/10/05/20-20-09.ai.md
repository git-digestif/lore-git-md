This is the first patch in a merged documentation cleanup series (v2) that removes the obsolete `gittutorial-2` document. The patch replaces the 400+ line tutorial with a six-line stub that directs readers to modern alternatives: `gitdatamodel[7]` for Git’s data structures and `gitcore-tutorial[7]` for practical internals exploration. By removing it, the patch clears the way for a future rewrite of the main `gittutorial` without needing to maintain backward compatibility with `gittutorial-2`’s structure. The diff shows the surgical change: the stub retains only the NAME, SYNOPSIS, and DESCRIPTION headers, explicitly marking the document as obsolete. No other files are modified in this patch; cross-references and build infrastructure updates are handled in the follow-up patch. The series is already merged to `master`, and this resend aligns the commit message with project conventions (using the `doc:` prefix) after surface-level feedback.
