This is an **announcement email** for **Git for Windows 2.56.0(2)**, a bugfix release following the v2.56.0 update. It is **not** a patch to upstream Git, but a downstream release of the Windows-specific fork maintained by Johannes Schindelin.

The email announces a second build of Git for Windows 2.56.0, addressing regressions introduced in the original v2.56.0 release (September 28, 2026). The key changes are all tied to the **MINGW64 → UCRT64 migration** that shipped in v2.56.0: a compatibility shim for the Git Credential Manager, a fix for `GIT_CONFIG_GLOBAL=NUL` not suppressing user-wide config, restoration of Authenticode signatures on x64 executables, and an assertion failure that broke pushes to servers requiring client certificates. The release also updates OpenSSL to v3.5.9, though this is not framed as a bugfix.

All artifacts (installers, portable builds, MinGit variants) are listed with SHA-256 checksums. The announcement is addressed to both the Git mailing list and the `git-packagers@googlegroups.com` group, indicating it is intended for downstream redistributors as well as end users. No upstream Git changes are involved; this is purely a Git for Windows maintenance release.
