This is a build system maintenance patch in Patrick Steinhardt’s seven-part series improving the Meson build. The patch updates the `.wrap` files for five bundled dependencies (curl, expat, openssl, pcre2, zlib) to newer upstream versions, ensuring Windows builds remain nearly dependency-free.

Kaartic Sivaraam’s reply raises a valid but low-urgency question: the versions pulled from Meson’s wrapdb are significantly older than the latest upstream releases (curl 8.12.1 vs 8.22.0, OpenSSL 3.0.10 vs 3.0.22/4.0.1). He asks whether this gap should be documented or addressed. The patch itself is uncontroversial and already matches the output of `meson wrap update`, so it is likely to proceed unchanged. The version lag is a separate concern that may prompt follow-up discussion about whether Git should manually track newer releases or accept the wrapdb’s slower cadence.
