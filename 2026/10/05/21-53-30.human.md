This is an **announcement email** for **Git for Windows 2.56.0(2)**, a bugfix release following the 2.56.0 release from September 28, 2026.

The update primarily addresses fallout from the recent migration from MINGW64 to UCRT64, which introduced several regressions in v2.56.0. Key fixes include restoring the ability to suppress user-wide Git config via `GIT_CONFIG_GLOBAL=NUL`, repairing lost Authenticode signatures in x64 executables, and resolving an assertion failure that broke pushes to servers requiring client certificates. Additionally, the release includes a compatibility shim to help users update stale references to the Git Credential Manager and updates OpenSSL to v3.5.9.

The changelog is concise and focused on Windows-specific issues, with no upstream Git changes mentioned. This is a routine maintenance release for Git for Windows users, particularly those affected by the UCRT64 migration. The provided SHA-256 checksums cover all installer variants (64-bit, ARM64, 32-bit, portable, and MinGit). No further discussion or review is expected on the Git mailing list, as this is purely a downstream release.
