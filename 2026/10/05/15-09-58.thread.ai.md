Core problem or goal
Introduce a new warning when a commit’s date is earlier than any of its parents, which can break date-based history traversal commands like `git log --since`. The warning is controlled by the new `advice.clockSkew` configuration setting and is surfaced via Git’s advice system.

Current status
Under review; no prior versions. Patch adds a check in `builtin/commit.c`, emits the warning through the advice system, and includes tests in `t/t7520-commit.sh` (correction: the file is actually `t/t7502-commit-porcelain.sh`).

- New symbols: `advice.clockSkew` (config key), internal advice message string
- Behavior: warning emitted only for the commit being created, not for existing history or merges
- Test coverage: warning trigger, no-warning case, silencing via `advice.clockSkew=false`
