Thread identity: Refactoring patch series `pw/stash-optimize-check_changes-calls/v1` by Phillip Wood, targeting redundant change-detection logic in `git stash push` and `git stash create`.

Core problem or goal: Eliminate duplicate checks for unstaged or uncommitted changes in `git stash push` and `git stash create`.
