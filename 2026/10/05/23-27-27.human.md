This is Junio’s biweekly “What’s cooking in git.git” report for October 2026 (#02), the maintainer’s summary of what is in flight across the integration branches.

The report lists 14 topics that graduated to `master` since the last update, 12 new topics that have entered the integration pipeline, and 38 topics still cooking in `next` or `seen`.  The highlights:

- **Graduated to `master`**: a mix of small fixes (e.g., `diff --no-index -R` handling file/directory conflicts, `git pull` segfault on unparseable objects, reflog expiry periods swapped by a regression) and infrastructure improvements (precompiled `git-compat-util.h`, CI workarounds for Debian 12 HTTP/2 auth bugs, Meson build tweaks, and AsciiDoc cross-reference markup).

- **New topics**:
  - `ps/odb-files-alternates` (13 patches) – a major refactor that moves alternates handling from the core ODB layer into the files backend, simplifying the API.
  - `ss/history-sign-rewrites` – teaches `git history` and `git replay` to sign rewritten commits, closing a gap in cryptographic traceability.
  - `ps/packfile-stale-delta-base-cache-fix` – fixes a corruption bug when a packfile is closed and its memory address reused while stale cache entries remain.
  - `pw/stash-change-check-only-once` – micro-optimization to avoid duplicate change detection in `git stash create/push`.

- **Still cooking**:
  - `ps/repo-ref-storage-format-fix` – renames the `references.format` field in `git repo info` to `references.storageFormat` for consistency.
  - `tb/repack-cruft-less-midx-corner-cases` (8 patches) – fixes reachability closure bugs in the cruft-less MIDX feature.
  - `je/doc-merge-conflicts` (7 patches) – adds a new `gitmergeconflicts(7)` man page and links to it from all commands that produce conflicts.
  - `mm/diff-process-hunks` (11 patches) – introduces `diff.<driver>.process` to let external tools act as hunk providers, enabling richer diff semantics without rewriting Git’s output pipeline.
  - `hn/fetch-refmap` (4 patches) – changes the default refspec for remotes added in shallow repos to rely on `remote.<name>.refmap`, reducing unnecessary fetches.

The report also notes a few stalled topics (`tc/last-modified-bloom`, `gg/http-ssl-verify-status`, `tb/midx-incremental-custom-base`) that have seen no recent activity and may be dropped unless new interest arises.
