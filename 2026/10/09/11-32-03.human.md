This is the sixth patch in Patrick Steinhardt’s eight-part CI housekeeping series (v2). It updates the `linux-exotic` job to stop using the now-EOL Ubuntu 20.04 image and instead use `ubuntu:latest`, which always points to the most recent Ubuntu LTS release. The change is mechanical: two files (`.github/workflows/main.yml` and `.gitlab-ci.yml`) each lose three lines that specified the old image and pinned GCC 8, replaced by a single line that specifies `ubuntu:latest`.

The commit message acknowledges the trade-off—dropping explicit coverage of Ubuntu 20.04 and GCC 8—but argues that the loss is acceptable because other jobs still test older distributions (AlmaLinux 8, Debian 12) and the `latest` tag will always track an LTS release, avoiding the need for manual updates. The patch itself is uncontroversial and aligns with the rest of the series’ goal of reducing maintenance overhead.
