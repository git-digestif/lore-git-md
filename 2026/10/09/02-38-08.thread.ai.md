Core problem or goal
`git diff` (and GitHub's diff viewer) generates a distorted diff for a commit that should show only deletions, whereas GNU `diff -u` produces the expected clean deletion-only diff. The distortion makes the diff harder to read and review, raising the question of whether this is a bug in Git's diff algorithm.
