This is a new bug report from David Yang about `git diff` producing distorted output compared to GNU `diffutils`. When preparing a patch for the Linux kernel, Yang noticed that `git diff` (and GitHub's diff viewer) showed confusing changes for a commit that should have been a clean deletion-only diff, while `diff -u` handled it correctly. The report includes a link to the problematic commit on GitHub and references a prior patch series, but no one has yet responded to confirm whether this is a bug or intended behavior. The issue appears credible and actionable, but so far there’s no discussion or investigation from the Git community.
