This is a user-interface bugfix for `git status` and `git checkout`. The patch rewords the message shown when a branch is configured to track a remote branch that does not exist. Currently Git says “Your branch is based on 'origin/master', but the upstream is gone,” which is misleading when the remote repository is empty and the branch was never created. The new wording is “Your branch is set up to track 'origin/master', which does not exist,” and it suggests `git push` only when that command would actually create the missing branch (i.e., when the push destination is the upstream itself and the push policy is not “matching” or “nothing”). The patch also updates the tests to match the new output and adds new test cases for edge configurations (push.default=nothing, push.default=matching, custom pushRemote, etc.). The change is backward-compatible: short formats (`git status -sb`, `git branch -vv`, `%(upstream:track)`) still show “[gone]” for script compatibility.
