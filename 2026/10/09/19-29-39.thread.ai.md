Originating author: Jon Simons
Thread type: patch series (bugfix)

Core problem or goal
Tighten input validation for `--force-with-lease` in `git push` to prevent a silent behavior change when a later patch in the series removes `mkpath()` from `refname_match()`. The current code silently ignores invalid refnames like `./refs/heads/main` because `mkpath()` strips leading `./`; after the refactoring, the lease would no longer be applied at all. The patch adds an explicit `check_refname_format()` call in `parse_push_cas_option()` to fail fast with a clear error message.
