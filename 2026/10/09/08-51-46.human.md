This is the second and final patch in Delilah Ashley Wu’s v3 series fixing Git’s global config file handling inconsistency. The patch makes `git config list --global` and `git config get --global` read both `$HOME/.gitconfig` and `$XDG_CONFIG_HOME/git/config`, aligning their behavior with unscoped operations and the documentation.

The implementation reuses `do_git_config_sequence()`—the same function Git already uses to read all config scopes—to handle the global scope by introducing an `ignore_system` flag and updating `git_config_system()` to respect it. This consolidates scope-filtering logic into `struct config_options`, allowing callers to ignore all scopes except global. The patch also adds a `global_had_success` flag to ensure `git config --global` fails if neither global config file is readable, preserving existing error-handling behavior.

Key changes include modifying `builtin/config.c` to set ignore flags for non-global scopes, updating `config.c` to track whether at least one global config file was read, and adding comprehensive tests in `t1300-config.sh` to verify the fix. The patch maintains backward compatibility and avoids duplicating config-file reading logic. No new CLI options or on-disk format changes are introduced.
