This is the seventh patch in Patrick Steinhardt’s eight-patch CI housekeeping series (v2). It removes the last remnants of Python 2 support from Git’s CI scripts. The commit is straightforward: after the previous patch dropped the last job that still used Ubuntu 20.04, the conditional logic that switched between Python 2 and Python 3 became dead code. The patch hard-codes Python 3 everywhere, deleting eleven lines of conditionals and replacing them with a single unconditional assignment. No behavior changes—just cleanup of obsolete scaffolding. The rationale is clear: Python 2 reached end-of-life in 2020, none of the current CI images still package it, and the project has long since moved on. This looks like a safe, uncontroversial simplification.
