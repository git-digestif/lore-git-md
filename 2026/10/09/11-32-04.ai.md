This is the seventh patch in Patrick Steinhardt’s v2 CI housekeeping series (8 patches total). It removes now-dead Python 2 logic from the CI scripts after the last Ubuntu 20.04 job was dropped in an earlier patch.

The change is mechanical: `ci/install-dependencies.sh` hard-codes `python3` instead of the conditional `PYTHON_PACKAGE` variable, and `ci/lib.sh` removes the distro-specific check that set `PYTHON_PACKAGE=python2` for Ubuntu 20.04. The `PYTHON_PATH` Make flag is now unconditionally set to `/usr/bin/python3`. No behavior change; the patch simply cleans up code that became unreachable when the Ubuntu 20.04 job was removed. The rationale is straightforward: Python 2 reached end-of-life in 2020, none of the current CI distros still package it, and the project has moved on.
