This is the second patch in the v3 series migrating `test-mergesort` to Clar and retiring unused subcommands. It focuses on simplifying the unit tests by replacing the original certification grid (which combined five distributions with eight transformations, totaling 1,680 test cases) with direct tests for four key scenarios: sorted input, reversed input, equal-value input, and repeatable random input. The patch removes all the distribution and transformation helper functions (`dist_sawtooth`, `mode_reverse`, etc.) and replaces them with a streamlined `check_sort` helper that verifies sorted output, stable equal-value ordering, and correct list length. The test sizes (100, 1023, 1024, 1025) are preserved to exercise merges across power-of-two boundaries, and the Clar test file (`t/unit-tests/u-mergesort.c`) is reduced from 288 to 105 lines.

The simplification was suggested by Patrick Steinhardt and directly addresses review feedback from earlier versions, which noted that the original grid was overkill for unit tests and made the code harder to follow. The new design maintains the same core guarantees (sorted output, stability, list length) while being more maintainable and easier to debug. No behavior changes are introduced; this is purely a refactoring of the test logic. The patch is well-motivated, clearly explained in the commit message, and aligns with the series' goal of modernizing the test infrastructure. The code is clean, and the test coverage remains thorough despite the reduction in complexity.
