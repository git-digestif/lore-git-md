This is the sixth patch in Patrick Steinhardt’s v2 CI housekeeping series (8 patches total). It updates the `linux-exotic` job to use the `ubuntu:latest` Docker image instead of the now-EOL `ubuntu:20.04`, removing the explicit `gcc-8` dependency in the process. The change is mechanical: two files (`.github/workflows/main.yml` and `.gitlab-ci.yml`) each drop three lines and add one, switching the image tag and removing the `cc_package`/`CC_PACKAGE` specification. The commit message explains that `ubuntu:latest` always points to the most recent Ubuntu LTS release, preserving test coverage for a supported platform while eliminating the need for manual updates. It also acknowledges the trade-off: the job no longer tests with GCC 8, but other CI jobs (e.g., AlmaLinux 8, Debian 12) still cover older distributions. No behavior changes; this is purely a maintenance update to keep the CI environment current.
