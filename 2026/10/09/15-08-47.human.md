This is the first patch in a four-part test-infrastructure cleanup series. It migrates the numeric sorting tests for Git’s mergesort implementation from the shell-based test suite (`t0071-sort.sh`) to the Clar unit-test framework (`t/unit-tests/u-mergesort.c`). The patch preserves all existing test inputs and correctness checks (sorted order, stable ordering of equal values, list length) while converting the test harness to Clar’s idioms.

The helper’s unused `generate` and `test` subcommands are removed, and the obsolete `t0071-sort.sh` script is deleted. The `sort` subcommand is kept temporarily for the still-present performance benchmark (`p0071-sort.sh`), which will be retired in the final patch. The new Clar test file stores list items in an array so cleanup can free them even if the sort leaves the links broken, addressing a memory-leak concern raised in earlier reviews.

The patch is mechanical and well-structured: it moves the test logic verbatim, adds a cleanup fixture, and updates the build system (`Makefile`, `meson.build`). No user-facing behavior changes; this is purely internal test modernization. The commit message clearly explains the rationale and scope, and the diff is clean. The series as a whole has strong support from Patrick Steinhardt and Junio C Hamano, and this patch is a straightforward first step toward the goal of reducing code size and adopting the modern Clar framework.
