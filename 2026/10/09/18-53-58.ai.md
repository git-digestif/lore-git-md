Key updates for v3 include:
- **Omissions addressed**: Julia will add `git am -3` and `git checkout -m` to the list of conflict-causing commands, with a note in the commit message explaining the deliberate scope of the guide.
- **Terminology clarified**: The "WHAT IS A MERGE CONFLICT?" section will define "original" (common ancestor) and replace "configuration option" with "configuration variable" for consistency.
- **Conflict markers explained**: The `|||||||` marker in `diff3` output will be documented where `diff3` is introduced.
- **Semantic conflicts acknowledged**: A brief note will clarify that Git cannot detect semantic conflicts (e.g., inconsistent function renames), setting user expectations.
- **`zdiff3` deprecated**: Julia agrees to remove or deprecate `zdiff3` in the guide, calling it a "failed experiment" that reduces `diff3`’s usefulness. A note will discourage its use.
- **Contractions removed**: Informal phrasing like "Here's" and "there's" will be replaced with more formal alternatives.
