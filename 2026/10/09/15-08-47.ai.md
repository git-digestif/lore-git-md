This is the first patch in a four-part test infrastructure cleanup series. It migrates the numeric sorting tests for Git’s mergesort implementation from the shell-based test suite (`t0071-sort.sh`) to the Clar unit-test framework (`t/unit-tests/u-mergesort.c`). The patch preserves all existing test inputs and validation logic—checking for sorted order, stable ordering of equal values, and correct list length—while restructuring the code for Clar’s idioms.

The key technical change is the shift from a grid of 1,680 test cases (5 distributions × 8 modes × 4 sizes × 10 multipliers) to a more maintainable Clar test file. The test logic is now organized around five test functions (`test_mergesort__*`), each certifying one distribution (sawtooth, rand, stagger, plateau, shuffle) across the same set of sizes and modes. The Clar version stores list items in an array so cleanup can free them even if the sort leaves the links broken, addressing a potential leak in the original helper.

Build-system files (`Makefile`, `t/meson.build`) are updated to include the new Clar test suite and remove the obsolete shell test. The `test-mergesort` helper is stripped of its unused `generate` and `test` subcommands, leaving only the `sort` command (which remains for the now-deleted performance benchmark in a later patch). No user-facing behavior changes; this is purely internal test infrastructure work. The patch adds 288 lines and removes 345, for a net reduction of 57 lines.
