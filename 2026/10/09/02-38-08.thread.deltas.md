# Thread deltas

## 2026/10/09

- [2026/10/09/02-38-08 by David Yang <mmyangfl@gmail.com>] David Yang reported that git 2.53.0 on Debian testing generates distorted diff patches compared to diffutils 3.12 and asked whether this should be considered a bug.

## 2026/10/13

- [2026/10/13/05-57-29 by Toon Claes <toon@iotcl.com>] Toon Claes explained that the distorted diff depends on the diff algorithm, noting that git defaults to 'myers' (which he described as not great) and that running with `--diff-algorithm=histogram` produces a cleaner diff; he concluded this is not a bug, stating git is simply stuck at an ancient default algorithm.
