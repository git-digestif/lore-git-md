This is a **licensing policy clarification** from Junio C Hamano, the Git maintainer, in response to D. Ben Knoble’s questions about the `sha1dc-accel` series. Junio explains how Git handles mixed-license components—specifically, how permissive licenses (like MIT or BSD) interact with Git’s GPL-2-only licensing.

The key takeaway is that Git’s overall package is distributed under GPL-2, but individual files retain their original licenses (e.g., MIT for `sha1dc` and `sha1dc-accel`). This means downstream distributors (like Gentoo) are correct to label the Git package as GPL-2-only, while still acknowledging that parts of the codebase carry different licenses. Junio confirms that the new `sha1dc-accel` code can remain MIT-licensed, provided its copyright notices and disclaimers are preserved—no "license-washing" to GPL-2 is required.
