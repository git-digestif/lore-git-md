This is the fourth patch in Patrick Steinhardt’s v2 CI housekeeping series (8 patches total). It updates the `linux32` job to use the `i386/debian:latest` Docker image instead of the now-unsupported `i386/ubuntu:20.04`.

The change is straightforward: the patch edits `.github/workflows/main.yml`, `.gitlab-ci.yml`, `ci/install-dependencies.sh`, and `ci/lib.sh` to replace the Ubuntu 20.04 image with Debian’s latest 32-bit image. The commit message explains that Ubuntu 20.04 was the last release to support 32-bit, while Debian will continue providing 32-bit Docker images until at least 2030. The patch also removes obsolete Ubuntu-specific logic in `ci/install-dependencies.sh` that handled missing `libsvn-perl` on 32-bit Ubuntu, simplifying the dependency installation script.

This is a clean, well-motivated maintenance update. The commit message clearly states the problem (EOL image), the solution (switch to Debian), and the long-term coverage outlook (2030). The diff is minimal and mechanical, touching only CI configuration files and supporting scripts. No user-visible behavior changes are introduced, and the patch aligns with the series’ overall goal of reducing CI complexity while maintaining test coverage. The only potential point of discussion would be whether Debian’s reduced 32-bit support (noted in the linked release notes) could affect test reliability, but the commit message addresses this by confirming that 32-bit Docker images are still being released.
