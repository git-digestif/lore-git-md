Core problem or goal
Fix a platform-specific bug in the Windows credential helper (`contrib/credential/wincred/git-credential-wincred.c`) where multi-line secret blobs (e.g., credentials containing both a password and an OAuth refresh token) are parsed incorrectly. The current implementation uses unsafe string operations (`wcsncpy_s` with incorrect size, `wcstok_s`) that can cause buffer overreads or misinterpret the blob content when newlines are present.
