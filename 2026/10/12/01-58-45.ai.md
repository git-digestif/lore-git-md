This is a test fix patch, part 2 of Isabella Caselli’s three-patch series implementing `includeIf.hostname:<pattern>`. It updates `t/t6500-gc.sh` to use `git var GIT_HOSTNAME` instead of the external `hostname` command when simulating a concurrent `git gc` process. The change ensures the test and the actual `git gc` command agree on what the hostname is, preventing silent mismatches that could cause the test to exercise the wrong code path. The fallback to "unknown" is preserved, matching `git gc`’s behavior when the hostname cannot be determined. This is a small but important consistency fix that directly supports the reliability of the new hostname-based configuration feature.
