This is a platform compatibility patch updating Git's Unicode character width tables to Unicode 18, released in September 2026. The patch adjusts the `zero_width` and `double_width` interval tables in `unicode-width.h` to reflect changes in the new standard, including new zero-width combining marks, expanded ranges for existing scripts, and additional double-width characters such as emoji and CJK ideographs.

The change is mechanical and well-scoped: it touches only the header file that defines which Unicode code points are treated as zero-width or double-width when Git computes display widths for terminal output. The commit message is minimal but sufficient, linking to the official Unicode announcement for context. No tests or documentation outside the header itself are affected.

Beat Bolli has been the regular maintainer of these Unicode updates for several years, and this patch follows the established pattern of previous version bumps. The update is routine housekeeping rather than a new feature or bugfix, so it is unlikely to be controversial.
