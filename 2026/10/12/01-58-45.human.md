This is the second patch in Isabella Caselli’s three-patch series implementing `includeIf.hostname:<pattern>` for Git’s configuration system. It is a test-only change that improves reliability in `t6500-gc.sh`.

The patch replaces the test’s use of the external `hostname` command with `git var GIT_HOSTNAME`, ensuring the test and the `git gc` command under test agree on what the hostname is. This prevents silent mismatches that could cause the test to exercise the wrong code path — for example, when the system’s `hostname` command returns a fully-qualified domain name but Git internally uses the short name. The fallback to `unknown` is preserved, matching Git’s own behavior when the hostname cannot be determined.

The change is small (one line) and uncontroversial. It directly addresses a latent test flakiness without altering any production code, and it builds on the new `git var GIT_HOSTNAME` debugging aid introduced in the first patch. No open questions or objections are apparent; this patch looks ready for review.
