This is the third patch in D. Ben Knoble’s five-patch series improving `git stash` shell completion. It **fixes a Zsh-specific bug** where stash names (e.g., `stash@{0}`) were not completing correctly. The issue stems from Zsh’s brace expansion behavior when the `-Q` (no quoting) flag is used in `compadd`. The patch removes `-Q`, allowing Zsh to quote metacharacters like braces, which resolves the completion failure. While this changes the displayed format slightly (users now see `stash@\{0\}` instead of `stash@{0}`), it ensures completion works as expected. The fix is minimal, touching only `contrib/completion/git-completion.zsh`, and introduces a new helper function `__git_complete_stashes` to override the default stash-listing logic for Zsh. No tests are added, but the change addresses a real usability issue reported by Zsh users. This patch is uncontroversial and stands alone as a clear bugfix within the broader series.
