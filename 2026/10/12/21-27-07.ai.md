This is a platform compatibility bugfix targeting the Windows credential helper (`contrib/credential/wincred`). The patch (v3) finalizes the fix for a long-standing parsing bug in how the wincred helper handles multi-line secret blobs—credentials containing newlines, such as OAuth refresh tokens alongside passwords. The previous implementation used unsafe wide-character string operations (`wcsncpy_s`, `wcstok_s`) that could corrupt memory, misinterpret line endings, or fail to process all credential items. The new version operates immutably on the original blob data, using `wmemchr` to scan for newlines and carriage returns, and splits the blob into lines before processing key-value pairs. The code is now refactored into helper functions (`write_credential_item`, `write_credential`) to reduce nesting, improve readability, and ensure consistent wide-character handling (character counts, not bytes).

The patch is confined to `contrib/credential/wincred/git-credential-wincred.c` and does not affect other platforms or credential helpers.
