This is a small, targeted patch to the `tig` text-mode interface for Git. The patch adds syntax highlighting for two common Git trailers, `Fixes:` and `Link:`, which are widely used in projects like the Linux kernel. The change is a two-line addition to the default `tigrc` configuration file, assigning both trailers the same yellow-on-default color scheme already used for similar trailers like `Original-patch-by:` and `Assisted-by:`.

The patch is well-scoped and uncontroversial. It doesn’t touch Git’s core codebase, only the configuration file for `tig`, a popular but separate tool that visualizes Git history. The commit message is concise and explains the motivation clearly: these trailers are common in real-world workflows, so highlighting them improves readability in `tig`’s output.

There’s no indication this is part of a larger series, and the change itself is trivial—just adding two color rules. If you use `tig` and work with patches that include `Fixes:` or `Link:` trailers, this patch will make them stand out visually. Otherwise, it’s unlikely to affect you.
