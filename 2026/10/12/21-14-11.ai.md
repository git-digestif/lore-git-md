This is a small patch to the `tig` pager's configuration file (`tigrc`). It adds syntax highlighting for the `Fixes:` and `Link:` trailers, which are commonly used in commit messages on mailing lists like the Linux kernel's. The change is trivial: two new `color` directives are added to the existing list of highlighted trailers, both styled in yellow text on the default background.

The patch is self-contained and does not touch any Git code—it modifies only the sample configuration file shipped with `tig`, a popular text-mode interface for Git. There is no behavior change in Git itself, and the patch carries no risk of regression. The commit message is minimal but sufficient: it states the motivation (these trailers are common) and the action taken.

This is not part of any larger series; it is a standalone patch. The author, Beat Bolli, is a known contributor to `tig` rather than to Git itself, so this is effectively a third-party project update that happens to be sent to the Git mailing list because `tig` is closely associated with Git workflows. There is no indication of prior discussion or review in the thread context provided.
