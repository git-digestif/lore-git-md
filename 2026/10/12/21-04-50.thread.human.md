This thread updates Git’s Unicode character width tables to Unicode 18, ensuring that commands like `git add -p` and `git diff --color-words` correctly handle newly assigned scripts, combining marks, and emoji. The patch, authored by Beat Bolli, is a standalone platform-compatibility update touching only `unicode-width.h`.

Junio C Hamano reviewed the patch, verified its correctness using the `update_unicode.h` script, and confirmed he will queue it for integration. The update is mechanical, adjusting zero-width and double-width code point intervals to match Unicode 18, with no changes to functionality, tests, or on-disk format. No objections or further discussion have emerged, and the patch is ready for inclusion.
