This is the second patch in D. Ben Knoble’s five-part series improving shell completion for `git stash`. It is a **refactoring** patch that extracts the repeated stash-listing logic into a new helper function `__git_complete_stashes`. The change is purely internal to the Bash completion script (`contrib/completion/git-completion.bash`) and introduces no behavior changes—it simply centralizes the code that generates stash-name candidates (e.g., `stash@{0}`) so that later patches can modify it in one place.

The patch is small, mechanical, and well-motivated: the same `sed` pipeline appears three times in the existing code, and extracting it reduces duplication. It is uncontroversial and looks like a clean preparatory step for the rest of the series. No tests or documentation are affected.
