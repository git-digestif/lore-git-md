This is a brief follow-up in the ongoing `imap-send` OpenSSL compatibility thread. Beat Bolli, author of the earlier series that Junio referenced, replies to clarify his plans. He is working on a new branch that will replace the current low-level ASN.1 certificate validation code with OpenSSL’s built-in hostname verification functions. This would make the manual string-handling fixes in Xiangfei Ding’s patch obsolete, since the entire problematic code path would be removed.

The message does not change the immediate status of Xiangfei’s patch—it remains under review, and the OpenSSL 4.1.0 deprecation warning still needs to be addressed—but it adds a longer-term dimension. If Beat’s new branch lands, it will supersede both Xiangfei’s patch and his own September series, rendering the current discussion moot. For now, the patch can proceed independently, but readers should be aware that a more comprehensive solution may be on the horizon.
