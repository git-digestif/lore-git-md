This is the first patch in Isabella Caselli’s three-patch series implementing `includeIf.hostname:<pattern>` for Git’s configuration system. It adds a `GIT_HOSTNAME` variable to `git var` so users can see exactly which hostname Git will use for conditional includes. The implementation is straightforward: it calls `xgethostname()` and exposes the result through the existing `git var` command, with documentation and a minimal test that verifies the output is non-empty. The patch follows the design consensus reached in 2024 and addresses Peff’s suggestion from the RFC phase. No open questions remain here; this piece is ready for review and looks clean and well-motivated.
