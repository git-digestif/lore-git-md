This is the second patch in Isabella Caselli’s three-patch series implementing `includeIf.hostname:<pattern>`, now under review by Junio C Hamano. The patch updates `t/t6500-gc.sh` to use `git var GIT_HOSTNAME` instead of the external `hostname` command, ensuring the test and the `git gc` command agree on what the hostname is. Junio’s reply probes the implications of the original mismatch: if the external `hostname` command and Git’s internal `xgethostname()` return different values, the test writes a bogus hostname to `.git/gc.pid`, simulating a lock held by a process on a different machine rather than the intended concurrent-local case. The fix is small (one line) but critical for test reliability, as it prevents the test from silently exercising the wrong code path. No objections or further discussion are present in this email; the change appears uncontroversial and directly addresses the consistency issue raised during the RFC phase.
