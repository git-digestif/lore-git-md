This is the second patch in D. Ben Knoble’s five-patch series improving `git stash` shell completion. It is a **refactoring** of the Bash completion script (`contrib/completion/git-completion.bash`).

The patch extracts the duplicated stash-listing logic (currently repeated three times) into a new helper function `__git_complete_stashes`. The helper simply runs `git stash list`, strips the `:.*` suffix from each line, and passes the result to `__gitcomp_nl`. No behavior changes are introduced; the patch is purely preparatory, centralizing the candidate-generation code so that later patches can modify it in one place. The diff is small (7 insertions, 4 deletions) and mechanical.
