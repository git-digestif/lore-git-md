This is the third patch in D. Ben Knoble’s five-part series improving `git stash` shell completion. It **fixes a Zsh-specific bug** where stash names like `stash@{0}` were not completing correctly.

The issue is that Zsh’s `-Q` (quote) flag in `compadd` prevents proper handling of the curly braces in stash names, leaving users stuck at `stash@{` with no way to complete the full reference. The patch removes `-Q`, letting Zsh escape metacharacters automatically, which makes completion work as expected—though users will now see escaped output like `stash@\{0\}` instead of the raw form. This is a clear usability win over the current broken state.

The fix is minimal (five lines added to `git-completion.zsh`) and self-contained, targeting only Zsh completion. No tests are added, but the problem is real and the solution is straightforward. This patch looks uncontroversial and ready to merge, assuming no edge cases emerge in testing. The rest of the series (refactoring and deprecation cleanup) can proceed independently.
