This is the fourth patch in D. Ben Knoble’s five-patch series improving `git stash` shell completion. It removes the deprecated `git stash save` subcommand from the command’s `-h` usage text and the man page synopsis, while leaving the full description intact for users who still rely on it.

The patch is small and surgical: it deletes two lines from `Documentation/git-stash.adoc` and one line from `builtin/stash.c`. The motivation is straightforward—`save` has been deprecated since Git 2.16 (2018), yet it keeps reappearing in documentation and help output. This change nudges users toward the modern `git stash push` syntax without breaking existing scripts or workflows, since the full manual page still documents `save`. Whether to go further (removing completion support in patch 5 or eventually the subcommand itself) remains an open question, but this patch is uncontroversial and ready to merge.
