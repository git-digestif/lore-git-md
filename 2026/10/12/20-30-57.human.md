This is the second patch in Beat Bolli’s v2 series for `git imap-send`, addressing OpenSSL compatibility. It replaces Git’s manual hostname verification logic with OpenSSL’s built-in `SSL_set1_host()` function, which has been available since OpenSSL 1.1.0.

The patch deletes the custom `verify_hostname()` and `host_matches()` functions (72 lines removed) and instead configures OpenSSL to perform RFC 6125-compliant hostname validation automatically. This change not only simplifies the code but also picks up OpenSSL’s ongoing improvements, such as support for IP addresses in subject alternative names (SANs), which the old code did not handle. When verification fails, the error message now includes OpenSSL’s descriptive string rather than a generic “certificate owner does not match” message.

The commit message is clear and cites the OpenSSL wiki, and the change is attributed to brian m. carlson’s suggestion in the v1 thread. No new tests are added, but the patch is compile-time only and should not alter runtime behavior beyond stricter RFC compliance. This looks like a clean, uncontroversial improvement that removes maintenance burden while improving correctness. If you care about `imap-send` or OpenSSL integration, this patch is worth a quick look.
