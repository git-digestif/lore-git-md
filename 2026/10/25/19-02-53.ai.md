This patch is part of the ongoing `the_repository` removal effort. It modifies `partial_clone_register()` and `partial_clone_get_default_filter_spec()` to accept a `struct repository *` parameter instead of implicitly using `the_repository`, and updates their callers in `builtin/clone.c` and `builtin/fetch.c` to pass `the_repository` explicitly. The change is mechanical and does not alter behavior, but it moves the dependency on the global one level up the call stack.

The patch touches four files: `builtin/clone.c`, `builtin/fetch.c`, `list-objects-filter-options.c`, and `list-objects-filter-options.h`. The core logic remains unchanged; the only difference is that the repository is now passed as an argument rather than hardcoded. The commit message notes that `USE_THE_REPOSITORY_VARIABLE` is left in place for now, with a follow-up patch left as an option.

The patch is well-scoped and aligns with the project's long-term goal of eliminating global state. It introduces no new behavior or edge cases, and the changes are straightforward.
