This is the first patch in the v11 series introducing `remote.<name>.refmap` for Git's fetch subsystem. It lays the groundwork for the "matching-inspired" fetch mode by adding a new per-remote configuration variable that provides the default value for the `--refmap` option, mirroring how `remote.<name>.fetch` provides default refspecs.

The patch adds the `remote.<name>.refmap` configuration key to Git's config system, parsed in `remote.c` alongside existing remote configuration. The key difference from `remote.<name>.fetch` is that `refmap` only maps refs that are *explicitly* being fetched—either via command-line refspecs or `remote.<name>.fetch`—and has no effect when there is nothing explicit to fetch. This ensures backward compatibility: a refspec-less fetch with only a refmap configured falls back to the same defaults as a remote with no refspec or refmap at all. The patch also updates `remote_find_tracking()` to use `remote->refmap` as a fallback when `remote->fetch` contains no matching refspec, while preserving negative refspec exclusion (e.g., `^refs/heads/secret`).

The implementation touches `remote.c`/`remote.h` (adding the `refmap` field to `struct remote` and updating config parsing), `builtin/fetch.c` (integrating `remote->refmap` into the refspec resolution logic in `get_ref_map()`), and documentation (`config/remote.adoc` and `fetch-options.adoc`). The test suite (`t/t5510-fetch.sh`) gains 101 new lines covering edge cases: refmap behavior with and without explicit refspecs, precedence over `remote.<name>.fetch`, tracking of branches outside `remote.<name>.fetch`, and negative refspec exclusion.

The patch is uncontroversial and well-tested, with clear documentation and no new technical debt. It reuses existing refspec machinery and adheres to Git's configuration conventions. The fallback logic in `remote_find_tracking()` is now fully clarified, addressing prior review concerns from D. Ben Knoble. Key names introduced: `remote.<name>.refmap`, `remote->refmap` (struct field), and the updated `remote_find_tracking()` behavior. Files modified: `remote.c`, `remote.h`, `builtin/fetch.c`, `Documentation/config/remote.adoc`, `Documentation/fetch-options.adoc`, and `t/t5510-fetch.sh`.
