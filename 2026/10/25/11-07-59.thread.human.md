This thread is about a small but useful documentation fix for `git rebase`. Omri Sarig noticed that the "INCOMPATIBLE OPTIONS" section of the `git-rebase` man page still listed some options (`--allow-empty-message`, `--ignore-date`, and `--signoff`) as incompatible with others, even though they no longer are. He also spotted that `--onto` with `--keep-base` was missing from the list entirely. After six iterations addressing minor feedback—mostly around wording and formatting—the patch is now ready to go.

The fix itself is straightforward: it removes the outdated references and adds the missing one. The only wrinkle was a minor formatting choice: the patch keeps the older plain-text cross-reference style ("See also INCOMPATIBLE OPTIONS below") for the new `--onto` entry, matching the `maint` branch it’s based on. This avoids merge conflicts and keeps the file consistent; any style updates can happen later. Reviewers—including Tuomas Ahola and Julia Evans—confirmed the changes are correct, and Junio has just queued the patch for integration testing in the `next` branch. It should graduate to `master` in the next cycle unless any last-minute issues surface.
