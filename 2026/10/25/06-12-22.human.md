It also adds thorough test coverage in `t/t1400-update-ref.sh` for both singular ("1 entry") and plural ("2 entries") cases, using proper commit dates to ensure reflog ordering. Junio C Hamano previously identified a test breakage in `t/t1506-rev-parse-diagnosis.sh`, which expected the old (always-plural) message format, and provided a concrete patch to update the test to match the new behavior.

The change is minimal and focused—it doesn’t alter behavior, only improves message correctness.
