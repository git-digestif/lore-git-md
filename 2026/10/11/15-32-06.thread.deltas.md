# Thread deltas

## 2026/10/11

- [2026/10/11/15-32-06 by Jon Simons <jon@jonsimons.org>] Jon Simons submitted a patch adding text to Documentation/SubmittingPatches documenting the preference to avoid the 'add a failing test and fix it in a subsequent commit' anti-pattern, recommending instead that a bug fix submit the test as `test_expect_success` in the same commit as the code change.
- [2026/10/11/23-44-26 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano reviewed the patch, stating it matches what contributors have been told, but suggested removing the initial advice to first write a `test_expect_failure` test, arguing that none of the alternatives (writing no tests, manual testing, or sending `test_expect_failure` separately) is recommended, and proposed the shorter replacement sentence: "A bugfix patch should include tests in `test_expect_success()` blocks that demonstrate the breakage when the code change that implements the fix is omitted."
