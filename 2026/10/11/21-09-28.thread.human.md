This thread began with a patch from Xiangfei Ding to fix a latent correctness issue in `imap-send.c`, where the code incorrectly assumed OpenSSL’s `ASN1_STRING_get0_data()` returns a null-terminated buffer. This could cause buffer overreads or crashes, particularly with OpenSSL derivatives like BoringSSL. Junio provided substantive feedback on the patch’s hygiene and commit message, while Aniket Gupta flagged a build-breaking deprecation warning in OpenSSL 4.1.0-beta2. However, the patch’s future was always uncertain: Beat Bolli was already working on a new branch to replace the low-level ASN.1 certificate validation with OpenSSL’s built-in hostname verification, which would render both Xiangfei’s patch and Bolli’s earlier September 7 series obsolete.

Xiangfei has now formally retracted the patch, citing Bolli’s upcoming branch as the reason. The thread is effectively dormant until Bolli posts the new branch, and no further action is expected on the current patch. The core issue—OpenSSL’s non-guaranteed null termination—remains unaddressed in the codebase, but the project is now waiting on Bolli’s architectural overhaul rather than iterating on the stopgap fix.
