This is a feature patch series that extends `git branch --delete-merged` to detect branches whose changes (but not their tips) have been integrated via squash merges, rebases, or patch-based workflows. The series is now in its fifth iteration and consists of four patches: a preparatory refactoring, a helper for reporting where branches "landed," the core `--delete-integrated` flag, and squash-detection logic that handles upstream modifications.

The CLI design is finalized and explicitly approved by Junio: `--delete-merged` retains its strict tip-reachability behavior (unchanged), while `--delete-integrated` is a new opt-in flag that detects both rebase-merged and squash-merged branches. The two flags cannot be combined, and the help output now reflects this. The series addresses two of Jasper Mayone’s usability nits from v4: `--delete-integrated` is now listed in `git branch -h`, and combining the flags produces a concise error message instead of the full usage text.

The core algorithm remains unchanged from v4. Rebase detection uses tree-based diffing (no blob fetches), while squash detection employs a path-by-path three-way merge approximation via `ll_merge`, which may download blobs in partial clones when upstream modified the same files. The output format consistently reports the landing commit (e.g., `Deleted branch topic (was 1a2b3c4, landed as 9f8e7d6)`). The test suite includes Junio’s false-positive case, Knoble’s "npm update" scenario, and coverage for upstream modifications.

The first two patches (refactoring and landing-message helper) are uncontroversial and ready for integration. The third and fourth patches (core flag and squash-detection) remain under review, with the primary open question being whether to implement Jasper’s proposed author-check mitigation to reduce false positives in forge workflows. The series is well-motivated, thoroughly tested, and aligns with common user expectations for squash-merged branches. The changes are self-contained and touch only `builtin/branch.c`, documentation, and tests.
