This is a **substantive review confirmation** for the final documentation patch in the SSH signing verification flaws thread. Patrick Steinhardt explicitly endorses the v3 patch, which clarifies that Git checks SSH key lifetimes (`valid-before`/`valid-after`) against the committer or tagger date (not the signature timestamp) and warns that this provides no security guarantees. His brief reply ("this version looks good to me") signals agreement with the wording proposed in the patch, which he originally suggested and which Junio C Hamano has already accepted.

The patch itself is now fully reviewed and ready for integration. It addresses the first of the two reported flaws (time-of-signature confusion) by documenting the current behavior and its limitations, closing the ambiguity Phillip Wood highlighted in earlier discussion. The second flaw (revocation file fails open) is handled by a separate security bugfix patch, also ready, and both may be held together to avoid splitting security fixes across releases. No further changes are expected to this documentation patch.
