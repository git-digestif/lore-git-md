This is the **fifth and final version of a documentation patch series** that replaces the outdated `gittutorial` man page with a new beginner-focused two-part guide. The series is now **mechanically complete and ready for merging to `next`**, having addressed all substantive and surface-level feedback from prior rounds. Junio has already merged the v4 series to his `seen` branch and called it "in a pretty good shape to be merged to 'next'."

The new tutorial has been **user-tested with 112 participants**, most of whom completed it successfully. The primary goal is to provide a modern, practical introduction to Git that reflects current workflows while avoiding confusion about its decentralized model. The author, Julia Evans, frames this version as "good enough" for merging, with plans to gather post-merge feedback to refine branching and collaboration content in future iterations.

Key changes in **v5** are minimal and procedural:
- Fixed a pronoun ambiguity in the commit message ("it" → "GCM" for Git Credential Manager) to clarify that GCM, not SSH, comes with Git for Windows.
- Removed trailing whitespace flagged by GitHub CI (though `make check-docs` does not catch this).

The **only remaining loose end** is a missing cross-reference update in `Documentation/git.adoc`, which breaks `make check-docs`. Junio acknowledged this in v4 but did not treat it as a blocker, suggesting it could be addressed in a follow-up if needed. The series otherwise passes all checks and is uncontroversial.

The tutorial’s **core design choices**—starting with `git init` locally, using `git commit -m` for simplicity, and splitting authentication instructions by platform (SSH for macOS/Linux, GCM for Windows)—remain unchanged from v4. Open pedagogical questions (e.g., whether to prefer `git clone` over `git init`, or how to handle SSH key generation) are noted as areas for future refinement but are not blockers for merging.

Files touched: `Documentation/gittutorial.adoc` (replaced entirely) and `Documentation/git.adoc` (cross-reference needs updating). No new symbols or behavior changes are introduced. The old tutorial is deprecated but remains accessible in Git’s history until removed in a future release. Compatibility requires Git 2.23.0+ due to `git switch` usage.
