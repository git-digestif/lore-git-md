Core problem or goal
Define Git’s security boundary in an authoritative man page (`gitsecurityboundary(7)`) to reduce misaligned security reports. The document clarifies that Git’s security guarantees cover only *unexpected or implicit execution of attacker-controlled code*, not inspection of repository contents or attacks from users with local disk write access. It codifies existing practice, cites historical CVEs (e.g., CVE-2019-19604), and explains how to create a “sanitized clone” via `git clone --no-local`.
