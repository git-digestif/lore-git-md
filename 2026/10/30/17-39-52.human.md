This is a refactoring patch series from Junio C Hamano that marks four functions as `static` after confirming they are no longer used outside their respective source files. The series touches `ident.c`, `add-interactive.c`, `read-cache.c`, and `unpack-trees.c`, removing unnecessary global visibility and cleaning up the corresponding header files.

The motivation is straightforward: over time, some functions that were once global have become unused outside their original files, and this series restores them to file scope. The commit messages are brief but clear, and the changes themselves are mechanical—no behavior is altered, only symbol visibility. Patch 3/4 (`read-cache: hide refresh_cache_entry()`) is the most invasive, involving a large code movement in `read-cache.c`, but Junio notes that this is a long-term readability win since the function’s scope is now properly limited.

The series looks well-scoped and uncontroversial. Each patch removes a single function from a header and makes it `static`, with no cross-file dependencies or subtle interactions. The only minor note is that Junio muses in the cover letter that an earlier version of patch 3/4 might have been better with a forward declaration, but he ultimately prefers the current approach for its simplicity.
