This is the **final patch in a documentation series** that replaces the outdated `gittutorial` man page with a new beginner-focused two-part guide. The new tutorial is **user-tested with 112 participants** and designed to be completed in under an hour. It covers local repository creation (`git init`, `git add`, `git commit`, `git status`, `git diff`) and pushing to a remote host (`git remote add`, `git push`). Key pedagogical choices include starting with `git init` (not `git clone`), using `git commit -m` for simplicity, and splitting authentication instructions by platform (SSH for macOS/Linux, Git Credential Manager for Windows). The tutorial avoids explaining branches, instead deferring to a future guide, and includes a troubleshooting section for common pitfalls (e.g., SSH host verification prompts).
