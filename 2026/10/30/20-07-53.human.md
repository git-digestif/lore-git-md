This is a refactoring patch in the `log-tree.c` subsystem, part of a six-patch series by Miklos Vajna. The patch extracts the logic that decides whether to show a remerge diff or a combined diff for a merge commit into a new helper function, `log_tree_merge_diff()`. The commit message states this is preparatory work for a later patch in the series that will reuse this logic after the parent loop in `log_tree_diff()`.

The change is mechanical: the extracted code is identical to what was previously inlined, so no functional changes are intended. The patch touches only `log-tree.c` and is small (22 insertions, 14 deletions). It looks clean and well-scoped, with a clear rationale for the refactoring. If the series as a whole is addressing a real need, this patch is a sensible step toward that goal.
