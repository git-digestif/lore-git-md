This thread is about a small refactoring in Git’s merge-diff display code. Miklos Vajna has sent a six-patch series that tidies up how merge commits are shown when using `--remerge-diff` or the combined-diff options (`-c`/`--cc`). The first patch simply moves the existing logic into a new helper function, `log_tree_merge_diff()`, inside `log-tree.c`; no behavior changes are intended. The goal is to avoid code duplication later in the series, where the helper will be reused after the parent loop in `log_tree_diff()`. So far there’s been no review traffic, so the patch is still waiting for feedback.
