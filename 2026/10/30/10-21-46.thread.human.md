This thread is a three-part bugfix series from Patrick Steinhardt that fixes a regression in `git grep --recurse-submodules` when grepping nested submodule trees. The bug, introduced in September 2026 (commit 93cd344e34f), occurs because the code incorrectly reads objects from the global `the_repository` instead of the submodule’s own repository instance.

The first patch fixes the immediate regression and adds test coverage for nested submodule trees, while the second and third patches apply defensive fixes to related code paths (sparse directory trees and `.gitmodules` file reading) to prevent similar issues. The series is under review, with no acks or objections yet, and is intended for backporting to stable branches. The changes are minimal and focused, touching only `builtin/grep.c` and the test script `t/t7814-grep-recurse-submodules.sh`, with no on-disk format changes. The work aligns with the broader effort to eliminate implicit reliance on `the_repository`.
