This thread is a straightforward bugfix series from Patrick Steinhardt that fixes `git grep --recurse-submodules` when dealing with nested submodules. The issue—a regression introduced in Git v2.56.0—causes Git to incorrectly read objects from the wrong repository instance, breaking grepping in nested submodule trees. Patrick’s v1 series includes a fix, a new test case, and defensive updates to related code paths to prevent similar bugs.

The series is under review, with only minor feedback so far. Toon Claes tested the fix and suggested two small improvements to the first patch: noting the regression version in the commit message and using `test_when_finished` for cleanup. Patrick accepted the version note but deferred the test cleanup, arguing the current approach is clearer in context. No other concerns have been raised, and the series remains self-contained and ready for further review. The defensive changes in the later patches are seen as worthwhile future-proofing.
