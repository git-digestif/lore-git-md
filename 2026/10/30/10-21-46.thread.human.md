This thread is a focused bugfix for `git grep --recurse-submodules`, which fails when grepping nested submodule trees due to incorrect object reading from `the_repository`. The issue, introduced in Git v2.56.0, is addressed in a three-patch series by Patrick Steinhardt, now at v2 with only a commit message update clarifying the regression's release version.

The fix ensures submodule trees, sparse directory trees, and `.gitmodules` files are read via their correct repository instance. The series includes a new test for nested submodule trees and defensive checks in related code paths. Toon Claes provided a substantive review of v1, confirming the regression and endorsing the approach, while a minor test-style suggestion was deferred. The series is under review, with no open technical questions, and is intended for backporting to stable branches.
