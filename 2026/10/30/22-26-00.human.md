This is a brief follow-up in the build system thread about ccache and precompiled headers. Harald Nordgren reports that the ccache sloppiness settings for precompiled headers have now been merged upstream in Meson (linking to the merged PR). This resolves the earlier open question about cross-build-system consistency: both Git’s Makefile and the Meson build system now enable ccache to cache objects built with precompiled headers. The original Git patch (v2) remains unchanged, but its premise is now fully aligned with Meson’s behavior. No further action is needed on the Git side.
