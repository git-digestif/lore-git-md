This is a refactoring patch in the merge-diff display subsystem, part of a six-patch series by Miklos Vajna. It extracts the logic that decides whether to show a remerge diff (`--remerge-diff`) or a combined diff (`-c`/`--cc`) for a merge commit into a new helper function `log_tree_merge_diff()`. The commit message states that a later patch in the series will reuse this helper after the parent loop in `log_tree_diff()`, so the extraction avoids code duplication. No behavior change is intended; the patch only moves existing code into a separate function and updates the call site. The diff touches only `log-tree.c` and is mechanical in nature.
