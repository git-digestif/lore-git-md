This thread began when Ulrich Windl asked whether the `*` wildcard in `.gitignore` patterns matches an empty string. The discussion quickly clarified that it does, but noted that the existing `gitignore(5)` man page was ambiguous on this point. Junio C Hamano proposed a patch to rewrite the relevant section, explicitly stating that `*` matches "strings of any length" (or equivalent) while preserving the rule that wildcards do not match slashes.

The patch has since seen minor refinement. Tuomas Ahola suggested tweaking the wording to "strings of length of zero or more" to eliminate any residual ambiguity, a change Ulrich confirmed was unambiguous. Junio, however, prefers the original phrasing, arguing that "a string of any length" already includes zero-length strings and that the alternative is unnecessarily verbose. The disagreement is purely editorial—no code or behavior is affected—and the patch’s core goal remains uncontroversial. The series is now at version 1, with the patch under review but not yet queued for merging. No further technical concerns have been raised.
