This is the fourth and final patch in Junio C Hamano’s four-part refactoring series to mark functions as `static` where they are no longer needed outside their source files. This patch targets `unpack-trees.c`, making the `verify_uptodate()` function file-scoped again after it was exposed to external callers in 2018 to support the now-removed "recursive" merge strategy.

The change is straightforward: the function is marked `static` in `unpack-trees.c` and its declaration is removed from `unpack-trees.h`. The commit message explains the history clearly—`verify_uptodate()` was made public to support the recursive merge strategy, which was fully removed in April 2025, leaving no remaining external callers. This patch restores tighter encapsulation by limiting the function’s visibility to its original file.

Like the rest of the series, this is a pure refactoring with no behavior changes. The patch is uncontroversial and aligns with the ongoing effort to improve Git’s code hygiene by reducing unnecessary global symbols. The diff is minimal and mechanical, touching only the function signature and header declaration.
