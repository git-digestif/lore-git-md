This is a brief follow-up in the build system thread about ccache and precompiled headers. Harald Nordgren reports that the ccache sloppiness settings for precompiled headers, which were the subject of his earlier patch to Git’s Makefile, have now been merged upstream in Meson. The upstream Meson pull request (#16317) addresses the same performance issue (ccache refusing to cache objects built with precompiled headers) by enabling the necessary ccache sloppiness flags automatically. This resolves the cross-build-system inconsistency noted earlier in the thread: users of either the Makefile or Meson build system will now benefit from ccache caching when precompiled headers are in use. No further changes to Git’s build system are proposed or needed.
