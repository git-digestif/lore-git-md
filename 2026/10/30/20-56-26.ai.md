This is the **first patch in the final (v5) version of a documentation series** that removes the outdated `gittutorial` man page. The patch deletes the existing `Documentation/gittutorial.adoc` file entirely, clearing the way for the new beginner-focused guide introduced in the second patch. This is a **pure deletion** with no new content or behavior changes.

The removal is part of a **two-patch series** that replaces the old tutorial with a modern, user-tested alternative. The author, Julia Evans, chose to split the removal and addition into separate commits to improve mailing-list readability, as the old content is not reused. The deleted file is a 671-line AsciiDoc document that has not been substantially updated since Git’s early days, covering basic concepts like commits, branches, and collaboration in a way that no longer aligns with current workflows or tooling (e.g., it assumes CVS-like collaboration patterns and does not mention modern commands like `git switch`).

The patch itself is **mechanically trivial**—a single file deletion with no functional impact. The only loose end is a missing cross-reference update in `Documentation/git.adoc`, which breaks `make check-docs`. Junio acknowledged this in the v4 review but did not block the patch, noting the fix could be addressed in a follow-up if needed. The series is otherwise ready for merging to `next`, with all substantive and surface-level feedback addressed in prior versions.

No new symbols, on-disk formats, or compatibility concerns are introduced. The old tutorial remains accessible in Git’s history until explicitly purged in a future release. This patch is uncontroversial and serves as a prerequisite for the second patch, which introduces the new content.
