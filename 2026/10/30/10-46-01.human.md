This is a documentation question about `.gitignore` pattern matching.

A user asks whether the asterisk wildcard (`*`) in `.gitignore` patterns matches an empty string, and whether `foo*.log` would match files like `foo.log` and `foo-whatever.log`. The current `gitignore(5)` man page states that `*` matches "anything except a slash," but does not explicitly clarify whether "anything" includes zero characters (i.e., an empty string).

The question is straightforward and highlights a potential ambiguity in the documentation. It is not a patch or a feature request, but a request for clarification that could lead to a documentation improvement if others agree the current wording is unclear. No code changes are proposed yet.
