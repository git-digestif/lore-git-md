This is a **bugfix follow-up** to the `git grep --recurse-submodules` regression. Patrick Steinhardt has sent a patch series ([20261030-pks-grep-recurse-submodule-v1](https://lore.kernel.org/git/20261030-pks-grep-recurse-submodule-v1-0-d4eb5c87d8fb@pks.im)) to address the issue reported by Root. The regression, introduced in Git 2.56.0 by commit `93cd344e34`, causes `git grep` to fail when encountering directories inside submodules during tree searches, due to incorrect object database (ODB) resolution.

The proposed fix targets `builtin/grep.c`, specifically the `grep_tree()` function, which now incorrectly reads submodule directory trees from the superproject’s ODB (`the_repository->objects`) instead of the submodule’s ODB. Patrick’s patch series aims to restore the correct ODB lookup logic, though the exact implementation details and test coverage are not yet clear from this reply. The series is likely to be small and focused, given the narrow scope of the regression.
