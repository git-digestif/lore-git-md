This is a small but meaningful documentation cleanup patch in D. Ben Knoble’s five-part series improving `git stash` shell completion. The patch removes the deprecated `git stash save` subcommand from the command’s `-h` usage text and the man page synopsis, aligning visible help output with the project’s long-standing deprecation policy (the subcommand was marked deprecated in 2017).

The change is uncontroversial in itself—Patrick Steinhardt explicitly agrees with dropping `save` from the synopsis—but it sets the stage for the series’ final patch, which removes completion support for `save` entirely. That broader question—whether to accelerate the removal of a deprecated feature that has lingered for eight years—remains open for discussion. The commit message notes that `save` was accidentally re-added to the documentation in 2022 and has even received new options since deprecation, underscoring the tension between cleanup and user familiarity.

No code behavior changes or test updates are involved; the patch is purely mechanical, touching only `Documentation/git-stash.adoc` and `builtin/stash.c`. The detailed description of `save` remains in the man page for now, preserving a reference for users who still rely on it. This patch is a logical precursor to the completion removal in patch 5/5, and Patrick’s endorsement suggests it is likely to proceed without further debate.
