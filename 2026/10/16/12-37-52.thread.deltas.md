# Thread deltas

## 2026/10/16

- [2026/10/16/12-37-52 by Ian Hu via GitGitGadget <gitgitgadget@gmail.com>] Ian Hu submitted a patch to sigchain.c that adds a `pushed` counter incremented in sigchain_push() and modifies the `n < 1` guard in sigchain_pop() to reinstall `s->old[0]` (the disposition from before the chain was built) when the chain is empty but was previously pushed, repairing the corruption caused by concurrent double-pops of the same signal that otherwise leaves the process spinning at 100% CPU with only SIGKILL able to recover it; fault-injected A/B testing showed the unpatched code froze in 121 of 300 runs while the patched code never froze in 300 runs.
