This is a CI/build system patch from Junio C Hamano. GitHub notified the project that the macOS 14 runner image is being retired, so this patch updates the GitHub Actions workflow file (`.github/workflows/main.yml`) to use macOS 15 instead. The change affects four macOS-based CI jobs: `osx-clang`, `osx-reftable`, `osx-gcc`, and `osx-meson`.

The patch is straightforward and conservative—it picks macOS 15 over the newer macOS 26 (which would be `macos-latest`) to minimize potential disruption. Junio notes that the change hasn’t been tested, as he doesn’t work on macOS himself, but the modification is mechanical and unlikely to introduce issues.

This is a routine maintenance update rather than a feature or bugfix, and it’s part of the ongoing effort to keep Git’s CI infrastructure functional. Since it’s a small, targeted change with no behavioral impact on Git itself, it’s likely to be uncontroversial and merged without much discussion. If you follow Git’s CI or macOS compatibility, this is worth noting but not urgent.
