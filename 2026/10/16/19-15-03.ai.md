This is the final version (v3) of a documentation patch that rewrites the introductory section of the `git(1)` man page. The patch is now ready for integration into `master`.

The rewrite replaces outdated references to `gittutorial`, `giteveryday`, `user-manual`, `datamodel`, and `cli` with concrete, actionable instructions for accessing Git’s help system. New users are now directed to `git push -h` for short help, `git push --help` or `git help push` for full documentation, and `git help --guides` / `git help --user-interfaces` to discover concept guides. The patch also removes the link to `git.github.io/htmldocs/git.html` in favor of `git-scm.com/docs`, which tracks the latest *released* version of Git rather than the tip of `master`.

The commit message now fully documents the rationale for removing outdated guides: `cli` is developer-focused and not useful for interactive users, `user-manual` is outdated (e.g., still recommending `git format-patch` for collaboration), and `datamodel` feels orphaned once the other guides are removed. The patch adopts an "every page is page one" model, where documentation is self-contained and does not assume prior reading of other guides. All prior feedback has been incorporated, including Junio’s requested clarification of the design philosophy behind the new presentation order.

The patch touches only `Documentation/git.adoc` and has no on-disk format or test coverage changes. It is uncontroversial and on track for `master`.
