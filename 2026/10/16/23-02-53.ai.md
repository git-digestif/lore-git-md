This is Junio's "What's cooking" report for October 2026 (#06), summarizing the state of Git's integration branches. Below are the key technical details an AI summarizer would need to track follow-up discussion:

**Graduated to master (irreversible)**
- `ap/var-broken-down-idents`: `git var` now outputs individual identity components (author/committer name, email, date), accepts multiple keys, and supports `-z` NUL-delimited output.
- `dk/stash-apply-index-incore`: `git stash apply --index` now merges the index in-core using merge-ort, fixing a concurrent lockfile issue with autostash.
- `jk/xdiff-size_t`: Internal diff/merge machinery converted to use `size_t` for buffer sizes, fixing LLP64 overflows and uninitialized memory leaks.
- `ps/reftable-reflog-timezone`: Fixed reflog timezone storage in reftable to use minutes (not `+HHMM` integers).
- `ss/history-sign-rewrites`: `git history` and `git replay` now sign rewritten commits when `commit.gpgSign` is set.
- `ps/odb-files-alternates`: Object database "files" backend now checks all alternate packfiles before loose objects, reducing `stat()` calls.
- `ps/packfile-stale-delta-base-cache-fix`: Fixed corruption from stale delta base cache entries when packfiles are closed/reopened.

**New topics (active)**
- `ak/pretty-wrap-fix`: Fixes lost indentation after newlines in `%w()` pretty formatting.
- `ak/sequencer-head-refdup`: Prevents HEAD ref name clobbering in worktree lookups during sequencer operations.
- `js/coverity-overflow-fixes`: Adds `signed_mult_overflows` macro and fixes integer overflows in date parsing, wrapper I/O, and archive-tar.
- `ps/pack-check-bigfile-threshold`: Fixes false corruption reports in `git fsck` when object size equals `core.bigFileThreshold`.
- `iw/connected-deepen-fetch-no-alternate-refs`: Fixes severe performance bug in deepening fetches by excluding alternate refs from connectivity checks.
- `yn/worktree-repair-fix`: `git worktree repair` now validates worktree IDs and gitdir paths to avoid corrupting unrelated `.git` files.
- `mb/fast-import-reference-pending`: Allows `fast-import`'s `from` command to reference newly created commits/tags by OID.
- `mc/repo-structure-filtering`: `git repo structure` now accepts revision arguments to filter counted objects.
- `mv/log-follow-speedup`: Optimizes `git log --follow` for non-linear history by skipping tree diffs when a path is unchanged in any parent.
- `oa/merge-without-the-repository`: Removes `the_repository` usage from `merge.c` by passing repository context explicitly.
- `ps/gitlab-ci-whitespace-job-shallow-clone-fix`: Disables shallow clones for GitLab CI whitespace/style jobs to avoid failures on large MRs.
- `sw/cache-tree-ignore-locked-index`: Makes `write_index_as_tree()` skip cache-tree updates when the index is locked, preventing `git rebase` failures.
- `vs/refs-seek-fix`: Fixes loose-ref seeking across directory boundaries by including trailing slashes in comparisons.
- `ab/describe-no-i18n-of-debug-messages`: Disables localization for `git describe --debug` output.
- `je/doc-detached-head`: Moves detached HEAD documentation to a standalone guide.
