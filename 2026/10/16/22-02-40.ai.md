This is a follow-up to the already-merged documentation patch that rewrote Git’s explanation of detached HEAD state. Junio C Hamano reports that the v4 patch broke the test suite (`t2020-checkout-detach.sh`) because the new advice message added a backtick-quoted command (` `git help detached-head` `) that the test did not expect. He provides a two-line fix: replace the backticks with single quotes in `advice.c` and update the test to match the new message. The change is mechanical and uncontroversial; it restores test coverage without altering the patch’s intent. Since the original patch is already in `master`, this follow-up is effectively a post-merge bugfix.
