This is a CI/build system patch from Patrick Steinhardt. It fixes a long-standing annoyance in GitLab CI where the "check-whitespace" and "check-style" jobs fail for merge requests with more than 50 commits. The root cause is that GitLab's default shallow clone (depth=50) prevents the jobs from accessing the base commit they need to compare against. The fix is simple: set `GIT_DEPTH: 0` for both jobs to force a full clone.

The patch touches only `.gitlab-ci.yml`, adding three lines. It mirrors an existing fix already in place for GitHub CI. Patrick notes that while this issue rarely affects upstream patch series (which are typically shorter), it does crop up in GitLab's internal development branches. The change is minimal, targeted, and directly addresses the observed failure mode without introducing new complexity.
