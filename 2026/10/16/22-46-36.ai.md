This is a CI/build system patch. Junio updates the GitHub Actions workflow file (`.github/workflows/main.yml`) to switch the macOS CI jobs from `macos-14` to `macos-15` after receiving a deprecation notice from GitHub. The change affects four jobs (`osx-clang`, `osx-reftable`, `osx-gcc`, and `osx-meson`) and is purely mechanical: every instance of `pool: macos-14` is replaced with `pool: macos-15`. Junio notes the patch is untested and that he does not use macOS himself.

The motivation is straightforward: GitHub is retiring the `macos-14` runner image and requires users to migrate to either `macos-15` or `macos-latest` (which currently points to `macos-26`). The patch opts for the more conservative choice (`macos-15`) to minimize potential disruption. No functional changes to Git's codebase are introduced; this is purely about keeping the CI infrastructure operational.

The patch touches only the GitHub Actions workflow file and does not interact with any other part of Git's code or documentation. Since it is a routine maintenance update triggered by an external deprecation, it is unlikely to be controversial. However, because it is untested, there is a small risk that the new macOS version could expose previously unseen platform-specific issues in the CI jobs.

Key details for follow-up discussion: the file modified is `.github/workflows/main.yml`, the runner image is updated from `macos-14` to `macos-15`, and the jobs affected are `osx-clang`, `osx-reftable`, `osx-gcc`, and `osx-meson`. The patch does not introduce new configuration keys or alter job behavior beyond the runner image change.
