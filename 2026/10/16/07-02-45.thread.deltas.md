# Thread deltas

## 2026/10/16

- [2026/10/16/07-02-45 by Harald Nordgren via GitGitGadget <gitgitgadget@gmail.com>] Harald Nordgren submitted a patch to make `branch.autoSetupMerge=inherit` use a remote-tracking start point directly as the upstream (as `true` does), so that `git switch -c new_branch origin/main` and similar commands set the remote branch as upstream without a warning.
- [2026/10/16/16-55-05 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano corrected the proposed documentation wording to "A remote-tracking branch given as a starting point" rather than "A remote-tracking starting point".
- [2026/10/16/16-55-05 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano questioned whether the same direct-tracking behavior should apply when the starting point is not a remote-tracking branch, proposing alternative text where the new branch tracks the starting point itself if it has no tracking configuration.
- [2026/10/16/16-55-05 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano said he is not sure users want a new branch forked from a non-tracking starting point to suddenly track that point, noting the original commit d3115660b4 only specified behavior for tracking start points and the previous "do nothing" behavior may be the right thing.
- [2026/10/16/16-55-05 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano suggested that if the behavior change proves undesirable, `inherit` could gain synonyms such as `inherit-or-ignore` (preserving the current behavior), `inherit-or-fail` (die if the starting point has nothing to inherit), and `inherit-or-direct` (use the fallback direct tracking).
