This is the first patch in Justin Tobler’s v2 four-patch bugfix series that plugs a race in the ODB transaction machinery. It is a **refactoring** that removes a hard-coded SHA-1 assumption from a code comment in `pack-write.c`. The comment now describes the `git-index-pack` output format generically (“hexadecimal name” instead of “SHA1”), matching the actual implementation which already works with any hash algorithm. The change is purely textual—no code or behavior is altered—and was split out from the original patch 1 at Patrick Steinhardt’s request to keep the series bisectable. The patch touches only one file (`pack-write.c`) and is uncontroversial.
