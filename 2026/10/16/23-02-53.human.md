This is Junio Hamano’s biweekly “What’s cooking in git.git” report for October 2026 (#06), summarizing the state of integration branches and in-flight topics. It’s the canonical pulse-check for Git development, listing what graduated to `master`, what’s newly cooking, what’s stalled, and what’s actively under review.

The report is organized by integration status. **Graduated to `master`** lists 22 topics that were deemed stable and merged since the last report. Highlights include Patrick Steinhardt’s reftable timezone fix (`ps/reftable-reflog-timezone`), D. Ben Knoble’s stash in-core index merge (`dk/stash-apply-index-incore`), Jeff King’s xdiff size_t conversion (`jk/xdiff-size_t`), and a handful of documentation and usability improvements (e.g., `hn/object-name-push-short` adding `@{p}` as a shorthand for `@{push}`).

**New Topics** introduces 15 fresh patches that entered the integration pipeline. Several are bugfixes: Andy Koppe’s pretty-format wrap fix (`ak/pretty-wrap-fix`), Patrick Steinhardt’s pack-check threshold fix (`ps/pack-check-bigfile-threshold`), and a reftable loose-ref seek fix (`vs/refs-seek-fix`). There are also small usability tweaks like `ab/describe-no-i18n-of-debug-messages` and `je/doc-detached-head`, which moves detached-HEAD documentation into a dedicated guide. Two larger efforts stand out: `iw/connected-deepen-fetch-no-alternate-refs` plugs a performance bug in deepening fetches, and `yn/worktree-repair-fix` hardens `git worktree repair` against corrupting unrelated `.git` files.

**Stalled** lists three topics that have seen no activity for weeks: OpenBSD runtime-prefix support (`bs/runtime-prefix-obsd-getexecpath`), OCSP stapling for HTTP (`gg/http-ssl-verify-status`), and Bloom-filter acceleration for `git last-modified` (`tc/last-modified-bloom`). These are not dead, but need renewed interest or fixes to CI breakage.

**Cooking** is the largest section, with 30+ topics in various stages of review. Notable efforts include Johannes Schindelin’s push refspec speedup (`js/push-refspec-match-speedup`), René Scharfe’s ZIP archive timestamp fix (`rs/archive-zip-omit-out-of-range-mtime`), and Patrick Steinhardt’s ODB alternates cleanups (`ps/odb-files-alternates-cleanups`). Two user-facing improvements are `hn/status-push-rebased-on-newer-upstream`, which improves advice after a clean rebase, and `je/doc-merge-conflicts`, a new guide for resolving conflicts. The section also includes several CI and test modernizations (`ps/ci-housekeeping-and-modernizations`, `hn/ci-leak-sanitizer-annotations`).

The report is dense but well-structured; each topic entry includes the number of commits, a one-line summary, and links to discussion threads. For a busy reader, the key takeaway is that the project is in a healthy state: many small fixes and documentation improvements are graduating, while larger architectural efforts (reftable, ODB abstraction, CI modernization) continue to cook. The stalled topics are a gentle reminder that some long-running efforts need attention.
