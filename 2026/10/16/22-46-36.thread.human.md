This thread is about a routine maintenance update to Git's GitHub Actions CI workflow. Junio C Hamano posted the fifth iteration of a patch to split macOS CI jobs between two explicit runner versions, `macos-15` and `macos-26`, replacing the deprecated `macos-14` image. The goal is to ensure CI remains operational while testing across both the oldest supported macOS version (for backward compatibility) and the latest explicit version (to align with GitLab CI, which lacks a `latest` tag).

The design was settled in earlier iterations, with Patrick Steinhardt successfully arguing for explicit versions over floating tags like `macos-latest`. The final job distribution places `osx-clang` and `osx-meson` on `macos-15`, and `osx-reftable` and `osx-gcc` on `macos-26`. Junio initially favored `macos-latest` for maintainability but withdrew that approach in favor of Patrick's preference. The patch touches only the workflow file (`.github/workflows/main.yml`) and introduces no functional changes to Git itself.

The thread is effectively closed. Patrick's surface-level review of v5 confirmed the patch "looks good," and Junio's commit message and retitling note indicate it is ready for integration. The only remaining risk—whether the new macOS versions expose platform-specific quirks—would be a runtime issue unrelated to the patch's correctness. This update is uncontested and awaits Junio's queue.
