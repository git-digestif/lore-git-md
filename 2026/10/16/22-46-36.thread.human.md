This thread began with Junio C Hamano’s routine maintenance patch to update Git’s GitHub Actions workflow file, switching macOS CI runners from the deprecated `macos-14` to `macos-15`. The change is purely mechanical—no functional impact on Git itself—but ensures CI jobs (`osx-clang`, `osx-reftable`, `osx-gcc`, `osx-meson`) remain operational. Brian m. carlson endorsed the patch, preferring `macos-15` over `macos-latest` (currently `macos-26`) to avoid potential compatibility surprises with newer macOS features, though the patch itself remains untested due to lack of macOS access.

Patrick Steinhardt has now proposed expanding the scope of the change. Instead of moving all four macOS jobs to `macos-15`, he suggests splitting them: `osx-clang` would stay on `macos-15`, while the other three (`osx-reftable`, `osx-gcc`, `osx-meson`) would run on `macos-26`. The goal is to broaden test coverage by exercising two major macOS releases simultaneously. This introduces a new technical consideration—cross-version compatibility—but Patrick hasn’t provided test results or implementation details, leaving the proposal as an open question. No other participants have weighed in yet, and the patch remains unmerged. The thread is now at a decision point: proceed with the original minimal change or adopt Patrick’s more ambitious split.
