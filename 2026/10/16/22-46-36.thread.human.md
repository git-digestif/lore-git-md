This thread is about a routine update to Git's GitHub Actions CI workflow to replace the deprecated `macos-14` runner image. Originally, Junio C Hamano proposed a simple mechanical replacement with `macos-15`, but after Patrick Steinhardt suggested splitting the jobs across two macOS versions (`macos-15` and `macos-26`) to improve cross-version compatibility coverage, Junio agreed to adopt this approach.

The plan now is to send a v2 patch that assigns `osx-clang` to `macos-15` and the remaining jobs (`osx-reftable`, `osx-gcc`, `osx-meson`) to `macos-26`, matching GitLab CI's configuration. This change is purely about CI infrastructure and involves no functional changes to Git's codebase. The thread is now waiting for the v2 patch to be posted, with no major open questions remaining—just the implementation details of the job split. Brian m. carlson had previously endorsed the original patch, while Patrick's review was the only substantive input.
