This thread is a routine maintenance update from Junio C Hamano to keep Git's CI infrastructure running on GitHub Actions. The patch switches the macOS CI jobs from the deprecated `macos-14` runner image to `macos-15` after GitHub issued a deprecation notice. The change is purely mechanical—replacing every instance of `pool: macos-14` with `pool: macos-15` in `.github/workflows/main.yml`—and affects four jobs: `osx-clang`, `osx-reftable`, `osx-gcc`, and `osx-meson`.

Junio notes the patch is untested (he doesn’t use macOS himself), but the motivation is straightforward: avoiding CI failures once GitHub retires `macos-14`. The choice of `macos-15` over `macos-latest` (currently `macos-26`) is conservative, minimizing potential disruption. No functional changes to Git’s codebase are involved, and the patch is unlikely to be controversial. However, there’s a small risk the new macOS version could expose platform-specific issues in the CI jobs. So far, there are no replies or objections to the patch.
