This thread is about a routine maintenance update to Git's GitHub Actions CI configuration. Junio C Hamano posted a patch (now at version 5) to split macOS CI jobs between two explicit runner versions, `macos-15` and `macos-26`, replacing the deprecated `macos-14` image. The goal is to maintain backward compatibility while aligning with GitLab CI's versioning scheme, which lacks a `latest` tag.

The design was settled earlier in the thread: `osx-clang` and `osx-meson` run on `macos-15` (oldest supported version), while `osx-reftable` and `osx-gcc` run on `macos-26` (latest explicit version). Patrick Steinhardt, whose input shaped the final approach, has now reviewed v5 and confirmed it looks good. The patch is uncontested and ready for Junio to queue. The only file touched is `.github/workflows/main.yml`, with no changes to Git's code or behavior—just CI infrastructure. The thread is effectively complete, pending integration.
