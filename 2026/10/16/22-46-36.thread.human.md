This thread updates Git's GitHub Actions CI workflow to handle GitHub's deprecation of the `macos-14` runner image. Junio C Hamano posted the initial patch to replace `macos-14` with `macos-15`, but after Patrick Steinhardt suggested splitting jobs across two macOS versions for better test coverage, Junio sent a v2 patch that distributes the four macOS CI jobs (`osx-clang`, `osx-reftable`, `osx-gcc`, `osx-meson`) between `macos-15` and `macos-26` (the current `macos-latest`). Specifically, `osx-clang` and `osx-meson` now run on `macos-15`, while `osx-reftable` and `osx-gcc` use `macos-26`. The split is arbitrary—Junio described it as "roll a die"—but aligns with GitLab CI's configuration.

The change is purely infrastructural, touching only `.github/workflows/main.yml` with no impact on Git's codebase, test coverage, or functionality. The thread has converged on this approach, with no objections or alternative proposals raised. The main open question is whether the new macOS versions might expose toolchain or environment quirks, but no specific issues have been reported yet. The patch is now ready for review and integration, with no further changes expected unless testing reveals platform-specific problems.
