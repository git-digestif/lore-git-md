This is the **Zsh stash completion bugfix** in the five-patch series improving `git stash` shell completion. The patch addresses a long-standing usability issue where Zsh users could not properly complete stash names like `stash@{0}` due to Zsh’s brace expansion behavior.

The problem occurs because Git’s Zsh completion script uses `compadd -Q`, which leaves braces unquoted. When a user types `git stash show stash@{` and presses Tab, Zsh treats the braces as part of a brace expansion pattern rather than literal characters, preventing completion. The fix removes the `-Q` flag, allowing Zsh to quote metacharacters like braces (e.g., displaying `stash@\{0\}` instead of `stash@{0}`). This change makes stash name completion work reliably in Zsh, though the displayed format is slightly altered as a side effect.

The patch is minimal and targeted: it adds a Zsh-specific override for stash listing completion (`__git_complete_stashes`) that replaces the default behavior. The author confirms Bash is unaffected by the bug, and no portable solution exists, so the Zsh-specific fix is the only viable approach for now.
