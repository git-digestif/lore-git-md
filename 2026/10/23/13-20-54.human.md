This is the fourth patch in D. Ben Knoble’s five-patch v2 series improving `git stash` shell completion. It removes the deprecated `git stash save` subcommand from the `-h` usage text and the man page synopsis, while leaving the detailed description intact for users who still rely on it.

The change is small and surgical: two lines are removed from `Documentation/git-stash.adoc` and one from `builtin/stash.c`. The commit message explains that `save` was deprecated in 2017 and has since been inconsistently re-added to the synopsis, so this patch aligns the documentation with the project’s long-standing deprecation policy. The author frames it as a cleanup rather than a breaking change, since the full description of `save` remains available for reference.

This patch is unlikely to be controversial on its own, but it sets the stage for the next patch (5/5), which removes completion support for `save`. The series as a whole is still open to feedback, and the author has explicitly stated they are willing to drop these two patches if they prove too disruptive. No objections have been raised yet.
