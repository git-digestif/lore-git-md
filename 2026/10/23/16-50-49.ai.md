This is a CI/build system patch that implements the stricter approach agreed in the thread: failing the build immediately if Perforce, Git LFS, or JGit fail to install on platforms where they are required.

The patch replaces the original warning-based approach with mandatory installation checks. If any of these tools fail to install on ubuntu-* (all three tools) or macos-* (Perforce), the script now prints an error message and exits with status 1, causing the CI job to fail. The final presence checks and warnings are removed entirely, since the build would have already failed if installation had not succeeded. Version output (p4d -V, git-lfs version, jgit version) is now printed immediately after each successful install, providing clear confirmation in the logs.

The diff is clean and focused: it adds error handling blocks around each tool installation step, removes the now-dead final presence checks, and moves version output inline. The change is confined to `ci/install-dependencies.sh` and does not affect Git's core functionality. This aligns with Patrick Steinhardt's proposal and addresses the thread's consensus that silent skips are riskier than explicit failures. The patch is ready for review and appears to be a straightforward implementation of the agreed direction.
