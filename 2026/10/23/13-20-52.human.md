This is the second patch in D. Ben Knoble’s five-part series improving `git stash` shell completion. It is a **pure refactoring** with no behavior change: the patch extracts the duplicated stash-listing logic into a new helper function `__git_complete_stashes` so that future patches can modify how stashes are completed without touching the same code in multiple places.

The change is small and mechanical, replacing two identical `__gitcomp_nl "$(__git stash list | sed -n -e 's/:.*//p')"` calls with a single call to the new helper. The helper itself is a one-liner that does exactly what the original code did. The patch touches only `contrib/completion/git-completion.bash` and is uncontroversial; it was not mentioned in the v1 feedback from Patrick Steinhardt, so it appears to be a straightforward cleanup that reviewers are likely to accept without comment.

This patch is a prerequisite for the Zsh bugfix (patch 3/5) and the `git stash save` removal (patch 5/5), both of which will modify the stash-completion logic. By centralizing the candidate generation now, the author ensures those later changes are cleaner and less error-prone. The commit message is clear and to the point, and the diff is minimal and easy to verify.
