This is the first patch in Julia Evans’s **v3 documentation series** replacing the outdated `gittutorial` man page with a beginner-focused guide. This patch **removes the old tutorial entirely**, clearing the way for the new content in the next patch. The removal is done as a separate commit to make the diff easier to review on the mailing list, since none of the old content is reused.

The old tutorial, last updated in 2006, is a dense, technical introduction that assumes familiarity with centralized version control systems and covers advanced topics like merge conflicts, branching, and history exploration early on. It also uses outdated commands (e.g., `git switch` is not mentioned) and workflows (e.g., local repository creation is buried in the middle). The new tutorial, which follows in the next patch, is based on user testing with 112 participants and focuses on practical, modern workflows for beginners.

No technical changes or new symbols are introduced here—this is purely a deletion. The patch is uncontroversial and part of a series that has already addressed all substantive feedback. The only remaining step is Junio’s final review before merging. The motivation is clear: the old tutorial is no longer fit for purpose, and the new version has been validated through user testing. This patch is a straightforward cleanup step in that process.
