Thread type: patch series (refactoring, part of ODB abstraction effort)

Core problem or goal
Refactor the loose object mapping logic to eliminate implicit reliance on the repository global (`the_repository`) and prepare for integration into the ODB abstraction layer. Specifically, extract the core OID-mapping operation (converting between hash algorithms) into a reusable helper function, `source_loose_object_map_oid()`, that operates on an explicit `struct odb_source_loose` parameter. This is a mechanical, behavior-preserving change that enables future pluggable ODB backends to reuse the same logic without coupling to the repository.
