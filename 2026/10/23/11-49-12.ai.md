This is the third patch in Patrick Steinhardt's v3 series extending the ODB abstraction effort. It introduces `GIT_OBJECT_STORAGE_FORMAT`, an environment variable that overrides the `extensions.objectStorage` repository configuration, mirroring the existing `GIT_REF_STORAGE_FORMAT` behavior for ref backends.

The patch adds the new environment variable to `environment.h`, implements the override logic in `setup.c` (reusing the existing `object_storage_format_by_uri()` helper), and documents the variable in `git.adoc`. The test in `t/t0001-init.sh` verifies that the environment variable takes precedence over the config, that objects are written to the correct backend, and that invalid formats are rejected with a clear error message.

This is a plumbing-level change that does not alter user-visible behavior by default; it is infrastructure for the ODB abstraction series. The commit message is minimal but the code is straightforward and the test coverage is thorough. No controversy is evident from the patch itself.
