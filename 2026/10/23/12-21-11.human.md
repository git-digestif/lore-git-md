This is a bugfix patch addressing a user-visible regression in `git init`. The author, Matt Hunter, has sent a v3 update incorporating the final review feedback from Patrick Steinhardt. The patch restores the pre-20e38cba3926 behavior of printing the absolute path (e.g., `/home/user/repo/.git`) in the "Initialized empty Git repository" message, rather than the relative `.git/` path that was unintentionally introduced in the current Git 2.56 cycle.

The v3 patch tightens the test coverage by removing an unnecessary intermediate variable and now verifies the full output message for the default case, as Patrick suggested. The author considered testing all four possible message variants (reinitialized/initialized, shared/non-shared) but opted to focus on the most common case to keep the test simple and targeted. The fix itself remains minimal and uncontroversial, touching only `builtin/init-db.c` and adding a regression test in `t/t0001-init.sh`.

All substantive feedback has been addressed, and the patch is now ready for integration. The urgency remains high, as the regression was introduced in the current development cycle and should not ship in the upcoming release. No further discussion or changes are expected.
