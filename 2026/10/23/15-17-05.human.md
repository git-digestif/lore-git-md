This is the **second patch in the v3 series** replacing Git’s outdated `gittutorial` man page with a beginner-focused two-part guide. The series is now **mechanically complete and ready for merging**, pending only Junio’s final review.

The new tutorial is a **user-tested, practical introduction** designed to be completed in under an hour. It covers local repository creation (`git init`, `git add`, `git commit`), making changes (`git diff`, `git status`, `git restore`), and pushing to a remote host (GitHub/GitLab via SSH). The author, Julia Evans, emphasizes that the tutorial is "good enough" for merging, with plans to iteratively improve it post-merge—particularly for branching and collaboration, which were intentionally omitted to keep the scope manageable.

Key design choices include starting with `git init` (instead of `git clone`) to avoid requiring an existing project, using SSH for authentication (with generic `ssh-keygen` instructions), and warning users about `vi` being the default editor. The tutorial is **vendor-neutral** but acknowledges the prevalence of GitHub/GitLab, and it specifies compatibility with Git 2.23.0 or later (required for `git switch`). Platform-specific notes (e.g., Git Bash for Windows) and troubleshooting sections address common pain points identified during testing with 112 users.

The patch **replaces `Documentation/gittutorial.adoc` entirely** with 782 lines of new content. No code changes are involved, and the old tutorial remains accessible until removed in a future release. The commit message and in-file documentation are clear and well-structured, reflecting the author’s iterative approach to feedback. Unresolved questions—such as whether to prefer `git init` or `git clone`, or how to handle forge-specific authentication instructions—are noted but not blockers.

This is a **low-risk, high-value documentation update** that directly addresses a long-standing gap in Git’s onboarding materials. The user testing and attention to beginner pain points make it a compelling replacement for the outdated tutorial. If merged, it will likely become the default starting point for new Git users.
