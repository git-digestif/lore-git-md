Subject: [PATCH] ci: pin GitHub Actions to full commit IDs
Series version: standalone patch (v2 posted and accepted)
Originating author: Taylor Blau <ttaylorr@openia.com>
Thread type: patch

Core problem or goal
Pin all GitHub Actions in the main workflow file to full commit SHAs instead of version tags or branches to mitigate supply-chain attacks and malicious action updates. The patch is purely a CI infrastructure hardening measure with no functional changes to Git’s behavior.

Current status
**Accepted and queued for `next`**. Junio C Hamano has queued the v2 revision of the patch after the commit message was strengthened to clearly document the security rationale (direct control over CI dependencies, reduced attack surface, mitigation of supply-chain risks). The prior **substantive policy objection**—that the change addressed a downstream constraint rather than an upstream need—has been resolved by the revised commit message. Junio’s lingering concern about precedent ("last one wins") remains noted but is no longer a blocker. No technical objections exist. The patch is expected to appear in `next` shortly.

Key technical details
- File touched: `.github/workflows/main.yml`
- 32 action references replaced (e.g., `actions/checkout@v6` → `actions/checkout@d23441a48e516b6c34aea4fa41551a30e30af803`)
- Actions affected: `actions/checkout`, `actions/github-script`, `actions/upload-artifact`, `actions/download-artifact`, `actions/setup-python`, `git-for-windows/setup-git-for-windows-sdk`, `git-for-windows/get-azure-pipelines-artifact`, `microsoft/setup-msbuild`
- Each replacement retains the original version tag in a trailing comment for readability
- No functional changes to Git’s behavior; purely CI infrastructure
- Aligns with GitHub’s security recommendations for Actions
- Part of broader CI modernization efforts (branches `ps/ci-housekeeping-and-modernizations` and `jk/http-curl-strip-creds`)

Open questions and loose ends

- **Maintenance trade-offs**: The overhead of updating SHAs for security fixes is acknowledged and framed as justified by the security benefits, as documented in the commit message.
