This is a bugfix patch in the delta compression subsystem, correcting a misunderstanding in the original submission about how the safe integer helpers behave.

The patch replaces manual arithmetic in `diff-delta.c:create_delta_index()` with `st_mult()`, `st_add()`, and `st_add3()` to prevent silent overflows during allocation size calculations. The original commit message claimed the change would "preserve NULL returns on failure," but Junio points out that the safe integer helpers (`st_add` and friends) actually call `die()` on overflow, not return NULL. The code itself is correct—it uses the helpers properly and still returns NULL if `malloc()` fails—but the commit message misrepresents the behavior. This is a straightforward mechanical change with no on-disk format impact, part of the broader effort to adopt safe integer helpers across the codebase.
