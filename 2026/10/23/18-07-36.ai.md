This is the **author's reply** to Junio C Hamano's review of the fifth patch in the `git stash` shell completion series. The patch removes Bash completion support for the deprecated `git stash save` subcommand. Junio had proposed an enhancement: automatically rewriting `git stash save --<TAB>` to `git stash push --<TAB>` on the first tab press, then completing options for `push`. The author **declines to implement the enhancement**, citing increased complexity and lack of personal motivation to seek consensus for it. The response is polite but firm, framing the enhancement as a "nicety" best left for a future contributor. The patch itself remains unchanged, and the thread is now waiting for further feedback or potential objections to the removal of `save` completion. Key technical detail: the author acknowledges Zsh's capability to implement such a rewrite but does not extend the same to Bash, leaving the door open for future work. The exchange highlights a tension between preserving user muscle memory and simplifying the codebase.
