This is the second patch in D. Ben Knoble’s five-patch v2 series improving `git stash` shell completion. It is a **pure refactoring** with no behavior change: the patch extracts the duplicated stash-listing logic (currently inlined in three places within `_git_stash()`) into a new helper function `__git_complete_stashes()`. The helper is then called in place of the original inlined code.

The change is mechanical and safe. The extracted helper does exactly what the inlined code did: run `git stash list`, strip the `:.*` suffix from each line, and feed the result to `__gitcomp_nl`. No new edge cases are introduced, and the patch does not touch Zsh completion, documentation, or the deprecated `save` subcommand. It is a straightforward cleanup that reduces duplication and prepares the codebase for the later patches in the series, particularly the Zsh bugfix (patch 3/5) and the `save` removal (patch 5/5).

The patch touches only `contrib/completion/git-completion.bash` and is unlikely to be controversial. It has not received specific feedback in the thread so far, but the overall series has been reviewed by Patrick Steinhardt, who raised no objections to this refactoring. The commit message is clear and concise, and the diff is small and focused.
