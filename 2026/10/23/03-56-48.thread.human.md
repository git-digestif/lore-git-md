This thread is a straightforward bugfix patch from Outreachy contributor Srujith A Poojary, replacing manual integer arithmetic in Git’s delta compression code with safe helpers to prevent silent overflows during allocation size calculations. The patch targets `diff-delta.c:create_delta_index()` and uses the `st_mult()`, `st_add()`, and `st_add3()` helpers, which call `die()` on overflow rather than risking memory corruption. Junio C Hamano reviewed the initial version, catching a minor error in the commit message that incorrectly stated the helpers return NULL on overflow (they actually terminate the program). Srujith has since posted a v2 with the corrected wording, leaving the code itself unchanged.

The patch is uncontroversial and part of a broader effort to adopt safe integer helpers across the codebase. No new tests were added, as existing delta-compression tests already cover the code path. The only remaining action is for Junio to pick up the revised version for integration.
