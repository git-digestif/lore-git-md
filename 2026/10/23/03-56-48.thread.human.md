This thread is about a small but important bugfix to Git’s delta compression code. Srujith A. Poojary, an Outreachy contributor, submitted a patch that replaces unsafe integer arithmetic in `diff-delta.c` with Git’s safe integer helpers (`st_mult`, `st_add`, `st_add3`). The change prevents silent memory corruption on overflow by making the function fail early instead. The patch is mechanical, confined to two allocation-size calculations, and doesn’t alter behavior except for the new overflow checks.

So far, the patch has not drawn any review comments or objections, so it remains in its initial state. It’s a targeted fix rather than part of a larger series, and it touches only the one file. If it’s accepted, it will likely be queued for the next maintenance release.
