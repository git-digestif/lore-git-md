This thread is about a bugfix patch by Outreachy contributor Srujith A Poojary that replaces manual integer arithmetic in Git’s delta compression code with safe integer helpers to prevent silent overflows during memory allocation. The patch, targeting `diff-delta.c:create_delta_index()`, was initially uncontroversial, with only a minor commit-message correction needed between v1 and v2.

However, Junio C Hamano has now raised a substantive question about whether the patch is actually necessary. He points out that existing bounds checks in the code may already prevent the overflow scenario the patch aims to address, making the fix theoretical rather than practical. This shifts the discussion from a straightforward review to a deeper technical evaluation of the patch’s motivation. The author will need to either demonstrate that an overflow is possible under the current constraints or withdraw the patch if it proves unnecessary. No other participants have yet responded to Junio’s concern. The outcome will determine whether this change is merged or abandoned as part of the broader effort to adopt safe integer helpers across the codebase.
