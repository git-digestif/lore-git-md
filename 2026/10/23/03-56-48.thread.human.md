This thread is about a precautionary bugfix patch in Git’s delta compression subsystem. Srujith A. While Pablo Sabater’s analysis confirmed that overflow is impossible under current conditions—struct `unpacked_index_entry` is 12 bytes on 32-bit systems, and bounds on `entries` and `hsize` are strict—Junio C Hamano has emphasized that compiler padding makes struct layout unpredictable across platforms, reinforcing the patch’s justification as future-proofing.

Junio’s evaluation of the trade-off between defensive coding and over-engineering is still pending, with portability now a key factor.
