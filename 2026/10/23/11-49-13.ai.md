This is part 4 of Patrick Steinhardt's 7-patch series extending the object database (ODB) abstraction. It exposes the repository's object storage format to users via two new interfaces: `` `git rev-parse --show-object-storage-format` `` and the `` `git repo` `` field `objects.storageFormat`. The patch adds the plumbing in `odb.c`/`odb.h`, updates the two built-ins, documents the new options, and adds tests in `t0001-init.sh` and `t1900-repo-info.sh`.

The change is purely additive and mirrors the existing ref-storage-format inspection commands. It prints the value of `extensions.objectStorage` (or `files` if unset) and, when a payload is present, appends it after a `://` separator. The implementation is straightforward: a new `object_storage_format_to_name()` helper in `odb.c`, a `get_object_storage_format()` callback in `builtin/repo.c`, and a new `--show-object-storage-format` branch in `builtin/rev-parse.c`.

No behavioral changes are introduced; the patch simply surfaces information that was already stored in the repository struct. The commit message is concise but sufficient, and the tests cover the basic happy path. This looks like a well-crafted, uncontroversial step in the ODB abstraction effort.
