This is the **final patch (7/7)** in Patrick Steinhardt’s **v3 object storage extension series**, which introduces pluggable object database backends for Git. This patch teaches `git submodule` to propagate the `--object-storage-format=` option to newly cloned submodules, mirroring the existing behavior for `--ref-storage-format=`.

The patch extends `git submodule add` and `git submodule update` to accept `--object-storage-format=<format>`, ensuring that submodules inherit the parent repository’s object storage configuration. The implementation follows the established pattern for ref storage: submodules receive the *type* (e.g., `files`) but **not the payload** (e.g., `files://objs` becomes `files`), a deliberate design choice for consistency with the ref backend. The patch also updates `git clone` to pass the object storage format to submodule checkouts, enforcing the same payload-stripping rule.

Key changes:
- **Documentation**: Updates `git-submodule.adoc` to document the new `--object-storage-format` option for `add` and `update` subcommands.
- **Code**: Modifies `builtin/submodule--helper.c` to parse and propagate the object storage format in `module_clone()`, `module_add()`, and `module_update()`. The `checkout()` function in `builtin/clone.c` is updated to pass the format to submodule clones.
- **Tests**: Adds `t7427-submodule-object-storage-format.sh`, covering:
  - Adding existing submodules with a non-default format.
  - Explicitly setting the format during `submodule add`.
  - Rejecting invalid formats (e.g., `garbage` or payloads like `files://objs`).
  - Recursive clone propagation (payloads are stripped).
  - `submodule update --init` with an explicit format.

The patch is **mechanically complete** and aligns with the series’ design goals. It introduces no new open questions, though the payload-stripping behavior (inherited from the ref backend) may attract discussion about whether it is overly restrictive. The implementation is technically sound, with thorough test coverage and clear documentation.
