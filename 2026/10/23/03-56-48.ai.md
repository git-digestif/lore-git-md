This is a bugfix patch targeting the delta compression subsystem in Git’s diff-delta.c. It replaces manual multiplication and addition in the `create_delta_index()` function with the safe integer helpers `st_mult()`, `st_add()`, and `st_add3()`, which automatically check for overflow and return NULL if the arithmetic would exceed `size_t` limits. The change is mechanical and confined to two allocation-size calculations; no behavior is altered except that overflows now trigger early failure rather than silent corruption. The patch is part of an Outreachy contribution and touches only the one file.
