This is a **review reply** from Junio C Hamano to the fifth patch in D. Ben Knoble’s v2 series, which removes Bash completion support for the deprecated `git stash save` subcommand. The review is **substantive** and proposes a **behavioral enhancement**: instead of simply dropping `save` from the completion list, Junio suggests **automatically rewriting `git stash save --<TAB>` to `git stash push --<TAB>` on the first tab press**, then completing options for `push`. This would preserve the muscle-memory escape hatch while nudging users toward the modern `push` subcommand. The patch itself is uncontroversial (Junio calls it "nice to see this go"), but the proposed enhancement could significantly improve the user experience by making the deprecation transition smoother. The thread is now open for the author to respond or implement the suggestion. Key technical details: the change would affect `_git_stash()` in `contrib/completion/git-completion.bash`, and the enhancement would require detecting `save` in the command line and dynamically rewriting it to `push` before proceeding with completion.
