This is the first patch in Patrick Steinhardt’s six-patch v2 series restoring dynamic reloading of alternate object databases in Git’s files-based ODB backend. The functions were originally part of the object database layer but have since moved into the files-specific backend (`odb/source-files.c`), so the old names no longer reflect their scope.

The change is mechanical and confined to a single file. No behavior is altered; the patch simply updates the function names and their call sites. This preparatory step makes the subsequent patches (which introduce new logic) easier to read by using consistent, backend-specific naming. The commit message is clear and the diff is straightforward, so there is nothing controversial here—it is a routine cleanup that sets the stage for the real bugfix in patch 3.
