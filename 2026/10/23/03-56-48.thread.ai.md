Thread type: bugfix patch

Core problem or goal
Replace manual integer arithmetic in `diff-delta.c:create_delta_index()` with the safe integer helpers `st_mult()`, `st_add()`, and `st_add3()` to prevent silent overflows during allocation size calculations. The helpers call `die()` on overflow, whereas the original code could proceed with an undersized buffer; the patch ensures correct behavior by returning NULL only on `malloc()` failure.
