This is the **documentation patch** that concludes Christian Couder’s 13-part series implementing **pack index v3** for SHA-1/SHA-256 interoperability. The patch moves the v3 index format specification from the transitional `hash-function-transition.adoc` document into the canonical `gitformat-pack.adoc`, where users and implementers will naturally look for it. The original text is preserved in the transition document for historical reference.

The change itself is straightforward: 75 lines of AsciiDoc are copied verbatim, ensuring the v3 format is now documented alongside v1 and v2. The new section describes the v3 header (signature, version, format descriptors), the per-algorithm tables (short-name, full-name, order-map, CRC, offset), and the trailer. It also clarifies alignment requirements, the meaning of the `PSRC` key, and the order in which algorithms are written.

This patch is **low-risk and uncontroversial**; it touches only documentation and does not alter code or on-disk formats. It is a logical follow-up to the preceding 12 patches, which implemented the v3 reading, writing, and validation logic. The commit message is clear, and the patch is ready for merging once the rest of the series lands.
