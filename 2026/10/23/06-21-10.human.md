This is the final exchange in the review of the fifth patch in D. Ben Knoble’s five-part series improving `git stash` shell completion. The patch removes completion support for the deprecated `git stash save` subcommand.

Patrick Steinhardt acknowledges Knoble’s test results: even after removing `save` from the list of completable subcommands, option autocompletion for manually typed `git stash save --<TAB>` still works, and the `GIT_COMPLETION_SHOW_ALL` setting restores `save` to the subcommand list without affecting option autocompletion. Steinhardt concludes that adding extra logic to suppress option autocompletion for `save` would not be worthwhile. The patch is now effectively approved, pending Knoble’s update to the commit message to document the observed behavior. No further changes are requested.
