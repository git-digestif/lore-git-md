This is part 3 of Patrick Steinhardt’s 7-patch series extending the ODB abstraction. It adds the `GIT_OBJECT_STORAGE_FORMAT` environment variable so users can override the repository’s configured object-storage backend (`extensions.objectStorage`) at runtime, mirroring the existing `GIT_REF_STORAGE_FORMAT` mechanism for ref backends. The patch touches `setup.c`, adds a short entry to `git.adoc`, defines the new constant in `environment.h`, and includes a 26-line test in `t/t0001-init.sh` that verifies the override works and rejects unknown formats. The implementation is straightforward and the commit message is clear; the patch looks well-crafted and directly supports the series’ goal of making object storage pluggable.
