The patch replaces a hardcoded singular/plural error message with Git’s `Q_()` macro to support pluralization in languages with complex rules (e.g., Polish), even though the English singular case (`pathlen == 1`) is unreachable in this context (the error only triggers for `pathlen > 65535`). The commit message now explicitly clarifies this pluralization context, addressing Phillip Wood’s earlier feedback.

The change is confined to `write_zip_entry()` in `archive-zip.c` and involves no logic, test, or documentation updates. The error message components (path length, object SHA-1, and path itself) remain unchanged; only the pluralization wrapper is added. No new strings are introduced to the translation catalog—existing strings are split into singular and plural variants.
