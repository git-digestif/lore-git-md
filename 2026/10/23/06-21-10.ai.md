This is a review follow-up in the `git stash` shell completion series, specifically about the fifth patch (removal of `git stash save` completion). Patrick Steinhardt responds to D. Ben Knoble’s test results and confirms the current behavior is acceptable.

The discussion centers on whether to preserve option autocompletion for manually typed `git stash save --<TAB>` after removing `save` from the list of completable subcommands. Knoble’s testing showed that option autocompletion still works even without `GIT_COMPLETION_SHOW_ALL`, and Steinhardt agrees this is sufficient. He notes that adding logic to explicitly block option autocompletion would be unnecessary complexity. The patch will proceed as-is, with Knoble updating the commit message to document the observed behavior. This resolves the last open design question for the patch.
