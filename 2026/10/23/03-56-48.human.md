This is a bugfix patch from an Outreachy contributor. It replaces manual arithmetic in `diff-delta.c` with Git’s safe integer helpers (`st_mult`, `st_add`, `st_add3`) to prevent potential overflows when calculating memory allocations. The change is confined to `create_delta_index()` and preserves the existing NULL-return-on-failure behavior.

The patch is small (5 insertions, 5 deletions) and mechanical: every multiplication or addition that could overflow is now wrapped in a helper that checks for overflow before proceeding. The commit message is clear and the diff is easy to verify.

This is part of Git’s low-level delta-compression code, so the impact is narrow but important—any overflow here could lead to silent memory corruption. The patch looks well-motivated and uncontroversial.
