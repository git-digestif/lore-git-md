This is a test infrastructure patch, specifically the second and final part of a two-patch series that fixes argument parsing compatibility in Git’s `clar`-based unit test runner. The patch adds `-l`/`--long-tests` as a NOOP command-line argument to `t/unit-tests/unit-test.c`, ensuring the test binary silently ignores the flag when forwarded by `meson test --test-args='-ilx'`. Without this change, the unrecognized `-l` flag causes the test run to fail entirely, disrupting common Meson workflows.

The fix is minimal, well-motivated, and follows an established pattern (commit 9faf3963b6) for handling compatibility flags. The commit message clearly explains the practical problem—users encountering test failures when running tests via Meson—and the solution, which introduces no functional behavior change. CI pipelines confirm no regressions, though some macOS runners did not execute, a minor note that doesn’t affect the patch’s viability.
