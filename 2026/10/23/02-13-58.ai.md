The three-patch series is now fully detailed and addresses the core goal of eliminating redundant directory traversals in common workflows. Patch 1 fixes a long-standing inconsistency in ignore-file hash computation, ensuring consistent object IDs between direct file reads and index lookups. Patch 2 enables cache sharing between `git status -unormal` (stops after first untracked file) and `git status -uall` (lists all untracked files) by recording incomplete scans and expanding them on demand.
