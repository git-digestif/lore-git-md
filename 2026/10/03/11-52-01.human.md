This is the latest update in the RFC series to introduce the `gitbreaking-changes(7)` manpage. Kristoffer Haugsbakk responds to Junio C Hamano’s suggestion to use a hybrid URL+message-ID format in the documentation, reporting that the proposed syntax produces unintended `mailto:` links in HTML output, making the message-IDs look like email addresses. He argues that plain URLs are more user-friendly and require no preamble, while the hybrid format risks confusing readers unfamiliar with message-IDs. He suggests dropping the patch if consensus cannot be reached on which approach is an improvement.

The email is a **substantive technical discussion** about documentation usability, not a code change. It advances the thread by surfacing a concrete rendering issue with Junio’s proposal and questioning whether the hybrid format is worth the added complexity. The files touched remain `Documentation/gitbreaking-changes.adoc`, and the change is still documentation-only. The key detail for future discussion is the rendering behavior of the hybrid format in HTML and man output, which may determine whether the patch proceeds or is abandoned.
