This is a bugfix for `git filter-branch` targeting the `--state-branch` commit mapping inversion regression introduced in Git 2.50.0 (commit f6d855091e). The patch is now in its third version (`v3`), addressing Junio C Hamano’s final review requests from `v2`. The core issue remains the same: the state branch file stores mappings in "from_commit:to_commit" format, but the code was incorrectly reading them as "to_commit:from_commit", causing the map directory to be populated backwards. This leads to errors like "Is a directory" when `--prune-empty` is used, as the script attempts to create files with empty names on subsequent runs.

The fix itself is unchanged from `v2`: a two-line modification in `git-filter-branch.sh` that splits each line on the colon, assigns the parts to `from_commit` and `to_commit` variables, and writes the `to_commit` into the file named by the `from_commit`. This version adds the requested clarifications to the commit message, explicitly naming the regressing commit (f6d855091e) and explaining the test change rationale (replacing `touch file || :` with `exit 1` to force reliance on the state branch). The test hygiene issue is resolved by adding `test_when_finished "rm -fr incremental"` to clean up the repository after the new test case. The typo in the patch subject ("fiter-branch") has been corrected in this version.

The patch touches the same two files as before: `git-filter-branch.sh` and `t/t7003-filter-branch.sh`. The test coverage remains comprehensive, with Michele Locati’s new test case directly verifying the commit mapping correctness in incremental runs with `--prune-empty` and `--subdirectory-filter`. This test fails on current `master` without the fix and passes with it, confirming both the bug and the fix. The original test is updated to ensure the state branch is the only reason HEAD remains unchanged, and the new test checks that the rewritten parents are used correctly and that the state branch file contains the expected "original:rewritten" entries.

This version incorporates all feedback from the previous round, including substantive, tested reviews from Michele Locati, Patrick Steinhardt, and Junio C Hamano. The patch is now self-contained, well-motivated, and has no remaining loose ends. It introduces no on-disk format changes or new symbols, and the test coverage is thorough. The regression is clearly documented, and the fix is minimal and targeted. This version should be ready for merging.
