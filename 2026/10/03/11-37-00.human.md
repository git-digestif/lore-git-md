This is a documentation patch that removes redundant empty SYNOPSIS blocks from Git’s section 7 man pages and updates the linter script to exempt these pages from requiring a SYNOPSIS. The patch is now ready for integration after resolving the last technical hurdle—a multi-file processing regression—with Tuomas Ahola’s clean, declarative implementation.

Julia Evans, the original author, confirms she will incorporate Tuomas’s linter logic into a v2 patch and credit him as coauthor. The change is uncontroversial and touches only documentation files: the `lint-man-section-order.perl` script and eleven `.adoc` files in `Documentation/`. No new dependencies, CLI options, or on-disk formats are introduced.

Tuomas’s solution moves man-section detection into the main loop and resets it at each file boundary using Perl’s `$.` line counter, avoiding the need for explicit `eof` checks. The script’s existing design is preserved, and `make lint-docs` continues to work correctly across multiple input files. The patch is self-contained, well-tested, and aligns with the project’s documentation hygiene goals. It looks like a straightforward merge candidate once the v2 is posted.
