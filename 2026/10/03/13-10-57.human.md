This is a documentation patch that removes empty SYNOPSIS sections from Git’s section 7 man pages (conceptual guides and tutorials) and updates the `lint-man-section-order.perl` script to exempt these documents from requiring a SYNOPSIS. The patch is now in its second version, incorporating a cleaner implementation from Tuomas Ahola that fixes a multi-file processing regression and uses a declarative configuration to mark SYNOPSIS as optional for section 7.

The change is straightforward and well-motivated: section 7 man pages like `gitglossary(7)` or `gitcli(7)` are descriptive rather than command-oriented, so a SYNOPSIS block is redundant. The patch touches only documentation files—11 `.adoc` files and the Perl linter script—and includes clear testing instructions (running `make lint-docs` and a fish script for manual inspection). The commit message explains the rationale and credits Tuomas as co-author for the Perl improvements.
