This is the fifth patch in Harald Nordgren’s six-patch series improving `git status` and `git push` handling of rebased branches. It focuses on the push rejection message when the local branch has been amended or rebased after being pushed.

The patch adds a new rejection reason flag, `REJECT_NON_FF_HEAD_REWRITE`, which is set when the remote branch’s tip appears in the local branch’s reflog. This signals that the remote carries no new work—only commits the local branch has since rewritten. When this condition is detected, the push rejection message now names the specific remote branch and offers both `git pull` and `git push --force-with-lease` as options, rather than just the generic pull advice.

The implementation touches `transport.c` (where the reflog check is performed), `builtin/push.c` (where the new advice message is added), and `transport.h` (where the new flag is defined). The test in `t/t6040-tracking-info.sh` verifies that the new message appears when pushing an amended commit to a branch that was previously pushed.

This change complements the earlier patches in the series by making the push rejection message more actionable and context-aware. The reflog-based detection is a lightweight way to distinguish between a true divergence (where the remote has new work) and a clean rewrite (where the remote only has older versions of the same commits). The new advice is opt-in and consistent with Git’s existing advice patterns, so it should not surprise users who have not enabled status hints.

The patch is well-scoped and the commit message clearly explains the motivation and implementation. The reflog check is a clever way to detect rewrites without requiring new on-disk state, but it may have edge cases around reflog expiration or shallow clones. The test coverage is thorough for the main scenario, but real-world testing will likely surface additional corner cases. The new advice (`--force-with-lease`) is generally safe in this context, but reviewers may question whether it should be offered unconditionally or gated behind additional safety checks.
