This is a brief follow-up in the ongoing ODB refactoring series. Karthik Nayak and Patrick Steinhardt exchange a short clarification about patch 2/13, which decouples the commit-graph subsystem from `struct odb_source`.

Karthik asks whether the test helper `git_test_write_commit_graph_or_die()` should accept an explicit object-directory path rather than hard-coding `repo->objects->sources->path`. Patrick dismisses the concern, calling the function a "hack for our test suite" and opting for the minimal change. The issue remains unresolved: the helper still assumes the primary ODB source’s path, which could break tests that need to write commit graphs to non-default directories (e.g., alternates or quarantine directories).

The exchange is purely surface-level — no new technical points are raised, and the series proceeds without modification. Future test failures may prompt a revisit, but for now the loose end stays open.
