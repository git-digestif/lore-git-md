This is a CI/build system patch series that has reached a stable, well-reviewed state. Phillip Wood, the most engaged reviewer, has given his explicit approval to merge the series as v6, calling it ready for integration. The two-patch set improves GitHub Actions CI failure reporting by making leak sanitizer and test failures easier to debug.

The first patch stops leak-sanitizer test scripts at the first failure (`--immediate`) and annotates leaks with the test script name and full sanitizer output in a collapsible log group. This patch has been cooking in `next` since v5 and remains viable for graduation to `master`. The second patch, rewritten as a compromise, embeds file and line context directly in failure annotations as plain text (e.g., `failed: t1060.17 partial clone of corrupted repository (t1060-object-corruption.sh:141)`), avoiding the broken annotation links that doomed the earlier version. Phillip Wood has accepted this solution, resolving the show-stopper issue from v5.

The implementation touches `ci/lib.sh` (enabling `--immediate` for leak sanitizer jobs), `t/test-lib-github-workflow-markup.sh` (new functions for finding test case lines and formatting annotations), and `t/test-lib.sh` (reordering annotation logic to ensure failures are reported before `--immediate` exits). The compromise avoids on-disk format changes and maintains backward compatibility with existing CI workflows. Test coverage is implicit in the GitHub Actions workflow, as demonstrated in the linked CI job.

This iteration addresses all substantive feedback from the v5 discussion. The broken annotation links are resolved, escaping logic is simplified, and the commit messages now include concrete examples of the new annotation format. The only remaining loose ends are low-priority UI suggestions and the `--immediate` trade-off, neither of which are blocking. The series is technically sound, has buy-in from the most vocal reviewer, and delivers a clear quality-of-life improvement for contributors and reviewers. It looks ready for `next`.
