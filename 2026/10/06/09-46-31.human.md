If any commit is not found, the command returns a non-zero exit code. This is a test infrastructure patch, not user-facing, and it directly supports the series' goal by enabling precise verification of commit-graph state after fetch operations.

The implementation is straightforward and aligns with existing test-tool patterns. It uses `the_repository` (consistent with the rest of the file) and leverages the commit-graph subsystem's existing APIs (`lookup_commit_in_graph()` and `commit_graph_generation()`).
