This is a documentation bug report about a broken link in the Git website's hash-function-transition page.

The email reports that the page at `https://git-scm.com/docs/hash-function-transition` (version 2.55.0) currently links to `https://shattered.io`, which was originally the site for the "SHAttered" paper demonstrating a SHA-1 collision. The domain has since been hijacked and now hosts unrelated cybersecurity content. The reporter provides archive.org links showing the domain was already parked in May 2026 and suggests replacing the link with the last known good snapshot from February 2026.

The issue is straightforward: a key reference in Git's documentation now points to misleading content, which could confuse readers about the security implications of SHA-1. The fix would be a simple URL update in the documentation source. No code changes are involved, and the patch would likely be uncontroversial. The reporter does not submit a patch themselves but provides all necessary details for someone else to do so.
