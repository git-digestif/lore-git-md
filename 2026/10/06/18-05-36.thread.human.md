The Git Contributor's Summit 2026 thread continues to refine its most contentious topic: the proposed community voting process for resolving divisive decisions like the AI contribution policy. All seven original follow-ups—security process, Git 3.0 planning, documentation, Outreachy sponsorship, pluggable ODB, AI policy, and Protocol v2 for pushes—have been delivered and are actionable to varying degrees, but the voting process now dominates discussion.

The latest exchange between Phillip Wood and Junio C Hamano sharpens the debate over voter eligibility. Phillip clarifies that the system would automatically notify eligible contributors, addressing Junio’s concern about excluding engaged but inactive participants. However, he defends a two-year activity window as a pragmatic safeguard against administrative overhead (e.g., outdated email addresses) and potential bad actors, citing the 2020 default branch name debate as a cautionary tale. On counting contributions, Phillip concedes to Junio’s preference for a flat commit threshold (e.g., five commits) over tracking patch series, noting that most reviewers would likely qualify via authored patches anyway. The discussion now hinges on balancing inclusivity with practicality, with no resolution yet.

Elsewhere, the thread’s other topics remain in limbo pending the voting process’s adoption. The AI policy vote, for example, cannot proceed until the eligibility criteria and tooling are finalized. Meanwhile, the security process (Peff drafting a public proposal), Git 3.0 rollout (SHA-256 and Rust inclusion confirmed, but LTS status unresolved), and pluggable ODB (repository extension planned for Git 2.57) await further action. The documentation tooling debate has seen progress—Junio confirmed pre-built docs have used Asciidoctor since mid-2024, removing the last infrastructure blocker—but structural and funding questions linger. Outreachy sponsorship and Protocol v2 for pushes are similarly stalled, though no objections have been raised to either. The thread’s focus has narrowed to governance, with the voting process serving as the linchpin for broader progress.
