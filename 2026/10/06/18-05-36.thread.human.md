This aligns with Emily Shaffer’s earlier preference for CIVS’s simplicity but reinforces the trade-off between ease of use and dependency on an external service.

The eligibility debate remains the most contentious, with positions evolving rapidly. Jeff King’s latest proposal—a hybrid model combining an algorithmic threshold (e.g., "X commits in the last Y years") with a human-curated list for edge cases (e.g., former maintainers)—has gained traction as a way to reconcile inclusivity with practicality. Junio C Hamano has broadened the scope of eligibility to include non-code contributions (documentation, reviews, community support), while Phillip Wood and others advocate for safeguards like a two-year activity window and substantive review requirements. Tuomas Ahola’s data-driven suggestion to use the average commit count (26) as a threshold provides a concrete middle ground, but the project must still decide how to operationalize non-code contributions, handle abstentions, and govern the human-curated list.
