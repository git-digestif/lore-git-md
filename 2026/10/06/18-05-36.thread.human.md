Here’s the human-mode summary for a developer catching up on the Git Contributor’s Summit 2026 thread:

The Git Contributor’s Summit 2026 covered seven major topics—security process, Git 3.0 planning, documentation, Outreachy sponsorship, pluggable ODBs, AI contribution policy, and Protocol v2 for pushes—and has since expanded to include a formal community voting process to resolve contentious decisions like the AI policy. All seven original follow-ups are now delivered, with the voting process patch under active review by Phillip Wood, brian m. carlson, Junio Hamano, and others. The security topic is actionable (Peff is drafting a public proposal for faster releases), Git 3.0 planning has consensus on a two-stage rollout (2.99 → 3.0) and SHA-256 support but still debates Rust mandates and LTS status, and documentation tooling is now unblocked (Fedora compatibility resolved, Asciidoctor standardization possible as a Git 3.0 breaking change). Outreachy sponsorship needs follow-up outreach, pluggable ODBs are planned for Git 2.57 with known gaps in commit-graph/MIDX support, and Protocol v2 for pushes is likely to see a patch series soon.

The community voting process is the most active subthread. The patch proposes a formal mechanism for contentious decisions, modeled after the 2019 Code of Conduct adoption, but key details remain unresolved: the eligibility threshold (Junio suggested five commits for simplicity, but brian m. carlton and Tuomas Ahola argue this is too low compared to Peff’s original 50-patch suggestion), whether to count substantive reviews or non-code contributions, and a two-year activity window to prevent "drive-by" voting. Weijie Yuan’s recent email clarifies a misunderstanding about Junio’s threshold proposal but reinforces contributor discomfort with a low bar influencing high-stakes votes. The discussion is still open, with no consensus on how to balance inclusivity with ensuring voters have a meaningful track record. The AI contribution policy vote now hinges on this process, as does any future contentious decision.
