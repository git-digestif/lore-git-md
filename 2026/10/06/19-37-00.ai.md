This is a cover letter for a **documentation** patch series proposing a new beginner-focused Git tutorial. The series replaces the existing `gittutorial` with a two-part guide: first creating a local repository and making commits, then pushing to a remote host like GitHub or GitLab.

The author, Julia Evans, has already tested the tutorial with 112 beta testers, most of whom completed it successfully. Two structural questions remain open for feedback:
1. **Repository creation**: Whether to start with `git init` locally (current approach) or clone from a forge (which risks confusion about Git’s decentralized nature). The current solution attempts to guide users through creating an empty repository on GitLab/GitHub, though UI changes make this fragile.
2. **Authentication**: How to handle SSH/HTTPS setup generically. The current draft uses SSH with simplified instructions and disclaimers about security policies, along with guidance for converting HTTPS URLs to SSH.

The series touches `Documentation/gittutorial.adoc` only, replacing the old content entirely. The motivation is clear: the existing tutorial is outdated, and user testing shows the new approach works despite rough edges. The questions posed are practical and likely to generate discussion about balancing simplicity with accuracy for beginners. No code changes are involved.
