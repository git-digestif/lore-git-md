This thread introduces a new beginner-focused tutorial for Git, `gittutorial(7)`, written by Julia Evans as part of a two-patch series. The tutorial is a 600-line AsciiDoc document designed for absolute beginners, covering the basics of creating a repository, making commits, and pushing to a remote host. It uses plain language, step-by-step instructions, and concrete examples (like creating `README.md` and `hello.py` files) to guide users through core Git workflows, including SSH key setup and troubleshooting common errors like `git push` failures. The tutorial is positioned as a more approachable alternative to existing resources like `gittutorial(1)` and `giteveryday(7)`, with a conversational tone and practical focus.

Julia Evans, known for her work on pedagogical improvements to Git’s documentation (such as the `git reset` man page rewrite), authored the patch. The tutorial is structured linearly, starting with installation and configuration, moving through commands like `git init`, `git add`, `git commit`, and `git push`, and addressing common pitfalls like SSH errors and branch name mismatches. It includes warnings about irreversible actions (e.g., `git restore`) and security implications of public repositories. The patch adds no code—only the new `Documentation/gittutorial.adoc` file—and is purely documentation.
