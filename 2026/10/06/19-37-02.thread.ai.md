Core problem or goal
Introduce a beginner-focused tutorial (`gittutorial(7)`) to Git’s documentation, targeting users with no prior Git experience. The tutorial provides a linear, step-by-step walkthrough of core workflows (repository creation, committing, pushing to a remote) using plain language, concrete examples, and troubleshooting guidance. It is explicitly positioned as complementary to existing resources like `gittutorial(1)` and `giteveryday(7)`, addressing users who find those too terse or abstract.
