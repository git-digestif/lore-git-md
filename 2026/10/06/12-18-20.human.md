This is a brief follow-up in Patrick Steinhardt’s 13-patch ODB refactoring series, specifically addressing Karthik Nayak’s review comment on patch 2/13. The exchange centers on the test helper `git_test_write_commit_graph_or_die()`, which now takes only a `struct repository *` but internally hard-codes the object directory path from `repo->objects->sources->path`. Karthik suggested the function should accept an explicit path argument to avoid assumptions about the primary ODB source, particularly for test cases involving alternates or quarantine directories. Patrick dismisses the concern, calling the function "just a hack for our test suite" and opting for the minimal change.

The response sidesteps the broader architectural goal of the series—eliminating implicit ODB source assumptions in favor of explicit repository and path arguments. While the immediate impact may be limited (the helper is test-only), the decision risks perpetuating inconsistencies in the codebase’s design. No further discussion or alternative proposals are offered; the thread remains open but appears to have reached a stalemate on this point. The rest of the series continues under review.
