This is a documentation patch introducing a new beginner-friendly Git tutorial. It adds a 600-line `gittutorial.adoc` man page that walks new users through the absolute basics: creating a repository, making commits, and pushing to a remote host. The tutorial is conversational, uses concrete examples (a `README.md` and `hello.py` file), and includes troubleshooting advice for common `git push` errors.

The patch is the second in a two-part series (the first patch is not shown here). Julia Evans, a well-known technical blogger, wrote it; her name on a documentation contribution signals a focus on clarity and pedagogy rather than deep subsystem expertise. The tutorial is explicitly aimed at users who have never used Git before and deliberately avoids advanced topics like branching or rebasing.

The prose is clear and the examples are tested, suggesting this is a well-crafted addition rather than a hasty draft. There is no controversy here—this is a straightforward documentation improvement that should make Git more approachable for newcomers.
