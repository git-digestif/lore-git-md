This thread is about replacing Git’s outdated `gittutorial` man page with a modern, beginner-focused two-part guide tested on 112 users. Julia Evans authored the series, which is now in its third version and nearly ready for merging. The new tutorial covers local repository creation and commits in Part 1, and pushing to a remote host (GitHub/GitLab) in Part 2, aiming to reflect current workflows while avoiding confusion about Git’s decentralized model.

The series has addressed all substantive feedback, with only trivial AsciiDoc formatting fixes remaining. Julia opted to retain Setext-style headings (underlines) for consistency with Git’s existing documentation, despite Junio C Hamano noting that Atx-style (`==`) might be easier to maintain. The final task is adding blank lines before two Setext-style headings to resolve linter warnings. Junio has no preference between the styles, and the choice is left to Julia. The patches are now ready for merging once this mechanical adjustment is made.

A few open questions remain, though none are blockers. These include whether to start with `git init` or `git clone`, how to handle SSH/HTTPS setup generically, and minor pedagogical choices like using `git commit -m` or newer `git config set` syntax. Julia also plans post-merge refinements based on user feedback, particularly for branching and collaboration. Junio and D.
