This thread is about replacing Git’s outdated `gittutorial` man page with a modern, beginner-focused two-part guide authored by Julia Evans. The new tutorial, tested with 112 users, covers local repository creation and pushing to a remote host (GitHub/GitLab) in under an hour, avoiding branches and collaboration to focus on core concepts like commits and the `.git` directory. The series is now in its third version (v3), which is mechanically complete and ready for merging after addressing all feedback—both substantive and surface-level—from earlier revisions.

Key changes in v3 include clarifications for Windows users (Git Bash recommended), warnings about the default `vi` editor, improved SSH key handling (generic `ssh-keygen` instructions with notes about filename variability), and minor UX tweaks like emphasizing `git status` and clarifying `--set-upstream`. The old tutorial was removed in the first patch of v3, with the new content added in the second, simplifying review. The series is compatible with Git 2.23.0 or later (required for `git switch`) and touches only `Documentation/gittutorial.adoc`, introducing no new symbols or behavior changes.

While a few open questions remain—such as whether to start with `git init` or `git clone`, how to handle SSH/HTTPS setup generically, and the use of `git commit -m`—they are not considered blockers. Julia frames the tutorial as "good enough" for merging, with plans to refine branching and collaboration content post-merge based on user feedback.
