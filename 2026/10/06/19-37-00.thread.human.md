This thread is about replacing Git’s outdated `gittutorial` man page with a modern, beginner-focused two-part guide tested on 112 users. Julia Evans authored the series, which is now in its third version and nearly ready for merging. The new tutorial covers local repository creation and commits in Part 1, and pushing to a remote host (GitHub/GitLab) in Part 2, aiming to reflect current workflows while avoiding confusion about Git’s decentralized model.

The series has addressed all substantive and surface-level feedback from Junio C Hamano and D. Ben Knoble. The only remaining task is a trivial AsciiDoc formatting fix: adding blank lines before Setext-style section delimiters or switching to Atx-style headings (`==`). Junio has clarified that either approach is acceptable, though Atx-style may be easier to maintain. The patches are now accessible in the mailing list archive after an initial delay, and the series is otherwise ready for merging once the formatting is resolved.

A few open questions remain, though none are blockers. These include whether to start with `git init` or `git clone`, how to handle SSH/HTTPS setup generically, and minor pedagogical choices like using `git commit -m` or newer `git config set`/`get` syntax. Julia plans to iterate on these and other aspects (e.g., branching and collaboration content) post-merge based on user feedback. Junio’s recent email reaffirmed that the formatting choice is the final hurdle, with no further content or design concerns raised.
