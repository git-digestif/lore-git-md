This thread is about replacing Git’s outdated `gittutorial` man page with a new beginner-focused guide, written by Julia Evans and tested with 112 users. The series is now at version 2, incorporating minor feedback from D. Ben Knoble, such as clarifications on `git status` output, platform assumptions, and accessibility considerations (e.g., `+`/`-` sigils in `git diff` for colorblind users). The first patch deletes the old tutorial, while the second introduces the new two-part guide: one covering local repository creation and commits, and the other covering pushing to a remote host like GitHub or GitLab.

The tutorial makes pragmatic choices, such as starting with `git init` (to avoid forge-specific confusion) and using SSH for authentication (with security disclaimers). It omits branching and collaboration to keep the scope manageable but plans to address these in post-merge iterations. While the series is under review, two open questions remain: whether to start with `git init` or `git clone`, and how to handle authentication generically without tying instructions to specific forges. Julia frames the tutorial as "good enough" for merging, and given its documentation-only focus and user-tested design, it seems likely to be queued for `next` soon. No substantive objections have been raised, though broader input on the unresolved design questions would be welcome.
