This thread is about replacing Git’s outdated `gittutorial` man page with a modern, beginner-focused two-part guide tested on 112 users. Julia Evans authored the series, now in its third version, which covers local repository creation, commits, and pushing to remote hosts like GitHub or GitLab. The goal is to provide a practical introduction that avoids confusing beginners about Git’s decentralized model.

The series is ready for merging, with all substantive feedback addressed. The only remaining task was a mechanical fix—adding blank lines before Setext-style section delimiters—to resolve AsciiDoc formatting warnings. Julia opted to retain Setext-style headings for consistency with Git’s existing documentation, despite acknowledging that Atx-style might be easier to maintain, due to a linter constraint. Version 3 includes minor improvements: a compatibility note (Git 2.23.0 or later), platform clarifications for Windows users, warnings about the default `vi` editor, better SSH key instructions, and small UX tweaks like emphasizing `git status` and clarifying `--set-upstream` behavior.

Some pedagogical choices remain unresolved but are not blockers. These include starting with `git init` (instead of `git clone`), using `git commit -m` for simplicity, and leaving SSH key generation generic (`ssh-keygen` without `-t ed25519`). The author plans to refine the tutorial post-merge based on user feedback, particularly for branching and collaboration. Junio Hamano, the maintainer, has reviewed the series and provided surface-level feedback, while D. Ben Knoble and Tuomas Ahola contributed minor observations. The patch is uncontroversial and touches only documentation, making it a straightforward candidate for merging.
