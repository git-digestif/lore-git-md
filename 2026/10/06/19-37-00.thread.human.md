This thread is about a new beginner-focused Git tutorial proposed by Julia Evans, replacing the outdated `gittutorial` with a two-part guide. The first part covers creating a local repository and making commits, while the second part introduces pushing to a remote host like GitHub or GitLab. Julia has already tested the tutorial with 112 beta testers, most of whom completed it successfully, but two structural questions remain open for feedback:

First, whether to start with `git init` locally (the current approach) or clone from a forge, which could confuse beginners about Git’s decentralized nature. The current draft guides users through creating an empty repository on GitLab or GitHub, though this may be fragile due to UI changes. Second, how to handle SSH/HTTPS authentication generically—the draft uses SSH with simplified instructions and disclaimers about security policies, along with guidance for converting HTTPS URLs to SSH.

The series is documentation-only, touching only `Documentation/gittutorial.adoc`, and aims to balance simplicity with accuracy for beginners. The open questions are practical and likely to spark discussion about the best way to introduce Git’s concepts without overwhelming new users. No code changes are involved, and the thread is still in the early stages of gathering feedback.
