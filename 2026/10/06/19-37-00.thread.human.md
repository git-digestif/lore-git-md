This thread is about replacing Git’s outdated `gittutorial` man page with a modern, beginner-focused two-part guide tested on 112 users. The series, now at v2, is authored by Julia Evans and aims to provide a practical introduction to Git that reflects current workflows while avoiding confusion about its decentralized model. The first patch deletes the old tutorial, and the second introduces the new one, which includes expanded explanations, troubleshooting sections, and accessibility considerations.

The series has been under review since v1, with feedback from D. Ben Knoble addressing minor editorial and pedagogical clarifications. Julia incorporated some of these suggestions in v2 but deferred others, such as adopting newer `git config` syntax and simplifying repository creation, to maintain compatibility with older Git versions. Junio C Hamano initially noted a logistical issue with the v2 patches but confirmed their presence in the public archive, clearing the way for further review. His recent feedback focuses on surface-level improvements—formatting, SSH key generation, and key copying—without engaging with the tutorial’s core design or unresolved questions about repository creation and authentication.

The tutorial is framed as "good enough" for merging, with plans for iterative improvements based on post-merge user feedback. While the series is uncontroversial in its goals, a few open questions remain, including whether to start with `git init` or `git clone` and how to handle authentication generically. The maintainer’s latest review suggests the tutorial is nearing readiness, pending minor polish. No substantive objections have been raised, and the series is likely to proceed once these final tweaks are addressed.
