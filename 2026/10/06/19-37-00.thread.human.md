This thread is about replacing Git’s outdated `gittutorial` man page with a modern, beginner-focused two-part guide tested on 112 users. The series, now at version 2, was authored by Julia Evans and aims to provide a practical introduction to Git that reflects current workflows while avoiding confusion about its decentralized model. The first patch deletes the old tutorial, and the second introduces the new one, which includes expanded explanations, troubleshooting sections, and accessibility considerations.

The series is under review, with the v2 patches recently resent after a GitGitGadget delivery delay noted by Junio C Hamano. Julia has incorporated minor feedback from D. Ben Knoble, addressing editorial and pedagogical clarifications, though some open questions remain. These include whether to start with `git init` or `git clone`, how to handle authentication generically, and whether to adopt newer `git config` syntax. Julia has defended pragmatic choices (e.g., `git commit -m`, local `git init`, and SSH authentication) while remaining open to post-merge iteration based on user feedback.

D. Ben Knoble’s feedback has been surface-level, focusing on wording, platform assumptions, and minor UX details rather than the tutorial’s core design. Junio’s involvement has been limited to logistical concerns, with no technical feedback or merge decision yet. The series is documentation-only, with no code or on-disk format changes, and is unlikely to be controversial given its user-tested design.
