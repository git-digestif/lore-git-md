This thread is about replacing Git’s outdated `gittutorial` man page with a modern, beginner-focused guide tested on 112 users. The new tutorial, authored by Julia Evans, is split into two parts: local repository creation and commits (Part 1) and pushing to a remote host like GitHub or GitLab (Part 2). The goal is to provide a practical introduction that reflects current workflows while avoiding confusion about Git’s decentralized model.

The series is now in its third version and is effectively ready for merging. All substantive feedback from Junio C Hamano and D. Ben Knoble has been addressed, leaving only trivial AsciiDoc formatting fixes—adding blank lines before Setext-style section delimiters—to resolve warnings. Junio has clarified that these are purely mechanical adjustments and has even suggested switching to `==` Atx-style headings as an alternative, though Julia may retain the Setext style with the required whitespace. A minor logistical hiccup (a 10-hour delay in the v2 patches appearing in the mailing list archive) has been resolved, and the patches are now accessible for final review.

Key open questions remain unresolved but are not blockers: whether to start with `git init` or `git clone`, how to handle SSH/HTTPS authentication generically, and minor pedagogical choices like using `git commit -m` or newer `git config set`/`get` syntax. Julia has also noted plans to refine branching and collaboration content post-merge based on user feedback. Junio’s feedback has been limited to surface-level details (e.g., SSH key generation and copying instructions), while Ben Knoble’s review focused on wording and minor UX tweaks. The series is framed as "good enough" for merging, with iterative improvements expected later.
