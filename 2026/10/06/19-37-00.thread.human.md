This thread is about replacing Git’s outdated `gittutorial` man page with a modern, beginner-focused two-part guide tested on 112 users. The new tutorial, authored by Julia Evans, covers local repository creation and commits in Part 1 and pushing to a remote host (GitHub/GitLab) in Part 2. The goal is to provide a practical introduction that reflects current workflows while avoiding confusion about Git’s decentralized model.

The series is now at v2, with minor feedback incorporated from D. Ben Knoble and Junio C Hamano. Julia has addressed most of Junio’s recent surface-level suggestions—fixing AsciiDoc formatting and capitalization—but pushed back on recommending `ssh-keygen -t ed25519`, citing OpenSSH’s defaults and future-proofing concerns. The key copying instruction remains unresolved but is not a blocker. D. Ben Knoble’s earlier feedback on `git config` syntax and directory creation was deferred for compatibility and clarity reasons, with no objections raised.

The first patch deletes the old `gittutorial.adoc`, while the second introduces the new guide with expanded explanations, troubleshooting sections, and accessibility considerations. No code or on-disk format changes are involved. Open questions include whether to start with `git init` or `git clone`, how to handle forge-agnostic authentication, and whether to adopt newer `git config` syntax. Julia plans post-merge iteration based on user feedback, particularly for branching and collaboration.

The series is under review, with no merge decision made yet. The core design remains uncontroversial, and the remaining feedback is minor. Julia has confirmed the v2 patches are publicly archived, resolving an earlier logistical delay.
