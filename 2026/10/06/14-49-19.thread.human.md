This thread is about a simple but important documentation fix. Mae Eckert reported that the `hash-function-transition` page on the Git website contains a broken link to `shattered.io`, which now hosts unrelated content after being hijacked. The page references the SHAttered SHA-1 collision paper, which is central to Git's rationale for moving away from SHA-1, so the link needs to point to a stable archive.

D. Ben Knoble has now submitted a patch that replaces the broken link with an archive.org snapshot from February 2026, exactly as Mae suggested. The change is a one-line edit to `Documentation/technical/hash-function-transition.adoc`, preserving the original context while ensuring readers can still access the paper. The patch is uncontroversial, affects only documentation, and is ready for review. Once someone confirms the archive.org link is appropriate, this should be a quick merge.
