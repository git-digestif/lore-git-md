This is the first patch in Harald Nordgren’s v3 series extending `git branch --delete-merged` to detect squash-merged and rebase-merged branches. It is a pure refactoring patch that moves the existing `branch.<name>.deleteMerged` opt-out check into a helper function, `branch_opted_out()`. The change is mechanical and does not alter behavior; it prepares the codebase for the subsequent patches that add new detection logic.

The patch touches only `builtin/branch.c`, extracting the config-checking logic from `delete_merged_branches()` into a standalone function. The helper takes a `strbuf` for the config key, the branch name, and the flags, and returns a boolean indicating whether the branch should be skipped. This makes the opt-out check reusable for the new detection code paths introduced in patches 2 and 3.

The commit message is clear and concise, explaining the motivation (honoring `deleteMerged=false` for branches whose tips are not reachable) and the scope (no behavior change). The diff is clean and focused, with no unrelated changes. This patch is uncontroversial and ready for integration; it serves as a solid foundation for the feature work that follows.
