This is the documentation patch (3/3) for the `--concern` feature in `git repo structure`. It completes the three-patch series by adding full documentation for the new config keys and CLI option.

Each key is documented as the floor of the base-2 logarithm of the threshold value, matching the implementation in earlier patches. The `git-repo.adoc` man page is updated to describe the `--concern` option, explain the star-based/numeric output formats, and document the logarithmic calculation method. The documentation also points users to the config section for threshold customization.
