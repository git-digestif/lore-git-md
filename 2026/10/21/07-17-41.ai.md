This is the fourth and final patch in the v3 series introducing copy-on-write worktree creation and ephemeral branch reaping. It is a **build-system fix** targeting Windows compatibility.

The patch addresses a compilation error in the mingw build caused by `-Werror=unused-function`. The `reflink_supported()` helper was previously called only in the non-Windows branch, leaving it unused (and thus triggering a build failure) on Windows. The fix moves the function call into the common code path while preserving the early return for Windows, ensuring the helper remains referenced and the build succeeds. The change is minimal: three lines added, two removed, all within `builtin/worktree.c`.

This patch is a direct response to the **permanent disablement of Windows reflink** in patch 3/4, which left the filesystem probe function unused on Windows. The fix is purely mechanical and does not alter runtime behavior. The Windows reflink ioctl remains disabled due to the silent corruption risk in ReFS (Git LFS #6312, build 26200), but the probe infrastructure is preserved for potential future use. The commit message clearly explains the rationale and the interaction with the `-Werror` flag.
