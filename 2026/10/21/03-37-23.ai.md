This is a test modernization patch from an Outreachy applicant. The patch fixes a common shell-test anti-pattern in `t/t2104-update-index-skip-worktree.sh`: instead of piping `git ls-files -t` into `test_cmp` (which suppresses the exit code of the Git command), it writes the output to a temporary file and then compares that file. This ensures that if `git ls-files` crashes, the test will fail rather than silently passing.

The change touches four test assertions in the script, replacing each pipeline with a two-step sequence: `git ls-files -t >actual` followed by `test_cmp expect.full actual`. The patch is mechanical, minimal, and clearly motivated. It follows the ongoing community effort to modernize Git’s test suite by eliminating unreliable patterns. No new behavior is introduced; the patch merely makes existing tests more robust.
