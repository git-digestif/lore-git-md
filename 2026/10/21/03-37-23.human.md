This is a test modernization patch from an Outreachy applicant. The patch updates `t/t2104-update-index-skip-worktree.sh` to avoid suppressing Git's exit code in pipeline commands. Currently, the test uses `git ls-files -t | test_cmp expect.full -`, which discards the exit code of `git ls-files`; if the command crashes, the test would still pass. The fix redirects the output to a file first (`git ls-files -t >actual`), then compares it with `test_cmp expect.full actual`, preserving the exit code.

The change is small but meaningful: it makes the test more robust by ensuring failures in `git ls-files` are detected. The patch touches four test assertions in the same file, all following the same pattern. No new behavior is introduced—this is purely about test correctness.
