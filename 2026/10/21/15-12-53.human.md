This is a small bugfix patch for `git rev-list`. The issue is that when `--grep` is used without an equals sign (e.g., `git rev-list --grep --missing-only HEAD`), the command fails to parse the next argument (`--missing-only`) as the grep pattern, instead treating it as another option. The patch makes the argument parser skip the next argument when it sees `--grep`, allowing patterns that start with `--` to work correctly.

The fix is minimal: it adds a single line in `builtin/rev-list.c` to increment the argument index `i` when `--grep` is encountered, and a new test in `t/t6022-rev-list-missing.sh` that verifies the behavior with a pattern beginning with `--`. The test is well-scoped and confirms the edge case is handled.
