This is the third part of brian m. carlson’s long-running SHA-1/SHA-256 interoperability effort. The series introduces **pack index v3**, a new index format that stores object IDs in *both* the main and the compatibility hash algorithms, so that packed objects can be mapped between algorithms just as loose objects already can.

The 13-patch series is a careful re-roll of the first 11 commits from brian’s `sha256-interop-part-2` branch, plus one new validation patch by Christian Couder and a documentation patch cherry-picked from brian’s full `sha256-interop` branch. Christian has adapted the patches to Patrick Steinhardt’s recent ODB refactoring (`ps/odb-files-alternates`), fixed several subtle bugs (duplicate-object detection, hash-context initialization, bounds checks in the v3 reader), and added test coverage for the new edge cases. The result is a well-motivated, thoroughly tested step toward full interoperability; it looks ready for serious review and is clearly worth the attention of anyone following the SHA-256 transition.
