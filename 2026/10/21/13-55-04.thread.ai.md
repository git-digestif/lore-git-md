Thread type: patch series (feature addition)

Core problem or goal
Add a `--concern` option to the `git repo structure` command that annotates repository structure statistics with a visual (star-based) or numeric indicator of how problematic each metric is, based on empirical thresholds derived from a sample of real repositories. The feature is configurable per-repository via Git config (`repo.structure.concern.*`), allowing users to override default thresholds.

Current status
Under review (initial v1 posted). All three patches now available: 1/3 (core functionality), 2/3 (configurability), and 3/3 (documentation). No prior discussion; this is the first public iteration of the idea.

Key technical details
- Files touched: `builtin/repo.c`, `Documentation/config/repo.adoc`, `Documentation/git-repo.adoc`, `t/t1901-repo-structure.sh`
- New CLI option: `--concern` (visual or numeric output)
- New config section: `repo.structure.concern.*` (hyphenated keys: `commit-count`, `blob-size`, etc.) for threshold overrides; note discrepancy with implementation (`repo.concern.*`)
- Concern calculation: exponential scale (base-2 logarithms) where each doubling beyond the threshold adds a star; defaults set at mean(log₂) + one standard deviation from a representative repository sample
- Output formats: concern indicators added to table, lines, and nul-terminated output
- On-disk format: no changes; purely informational output
- Test coverage: added to `t/t1901-repo-structure.sh` for functionality, configurability, and output format correctness

Open questions and loose ends
