Originating author: Mark C. Chu-Carroll
Thread type: patch series (feature addition)

Core problem or goal
Add a `--concern` option to the `git repo structure` command that annotates repository structure statistics with a visual (star-based) or numeric indicator of how problematic each metric is, based on empirical thresholds derived from a sample of real repositories. The feature is configurable per-repository via Git config (`repo.concern.*`), allowing users to override default thresholds.

Current status
Under review (initial v1 posted). Patches 1/3 (core functionality) and 2/3 (configurability) now available; patch 3/3 (documentation) pending. No prior discussion; this is the first public iteration of the idea.

Key technical details
- Files touched: `builtin/repo.c`, `Documentation/config/repo.adoc` (patch 3/3), `t/t1901-repo-structure.sh`
- New CLI option: `--concern` (visual or numeric output)
- New config section: `repo.concern.*` (hyphenated keys: `commit-count`, `blob-size`, etc.) for threshold overrides
- Concern calculation: exponential scale (base-2 logarithms) where each doubling beyond the threshold adds a star; defaults set at mean(log₂) + one standard deviation from a representative repository sample
- Output formats: concern indicators added to table, lines, and nul-terminated output
- On-disk format: no changes; purely informational output
- Test coverage: added to `t/t1901-repo-structure.sh` for functionality, configurability, and output format correctness
