Subject: [PATCH 0/3] Add degree-of-concern reporting to `git repo structure`
Series version: v2 (addresses feedback from v1)
Originating author: Mark C. Chu-Carroll
Thread type: patch series (feature addition)

Core problem or goal
Add a `--concern` option to the `git repo structure` command that annotates repository structure statistics with visual (star-based) or numeric indicators of how problematic each metric is, based on empirical thresholds derived from a sample of real repositories. The feature is configurable per-repository via Git config (`repo.concern.*`), allowing users to override default thresholds. The feature is directly inspired by `git-sizer(1)` but integrated into Git's native tooling.
