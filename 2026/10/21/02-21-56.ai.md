This is a small i18n (internationalization) bugfix patch from an Outreachy applicant. The patch changes a single line in `builtin/checkout.c` to use Git’s `Q_()` pluralization macro instead of the plain `_()` gettext wrapper for the message " ... and %d more." that appears when `git checkout` leaves orphaned commits behind. The commit message explains that while English does not distinguish plural forms here, some languages (e.g., Polish) require different words for counts of 2–4 versus 5 or more, so the plural-aware macro is needed even though the count is always ≥ 2. The change is mechanical: the English string remains identical, but translators now receive the correct plural context. The patch touches only one file, adds no new tests, and carries a clear, concise rationale. It looks like a well-scoped, uncontroversial fix.
