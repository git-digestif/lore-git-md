This is a **substantive review** from Christian Couder on the second patch of Patrick Steinhardt’s four-patch series restoring dynamic reload of alternate object databases. The review identifies a **behavioral regression in `git receive-pack`** introduced by the interaction between Patrick’s fix and an earlier change (bdee7b3013, July 2026) that made the quarantine directory the temporary primary ODB in `receive-pack`.

Christian’s key observation: when a temporary primary directory (like the quarantine) is in use, `prepare_alternates(files, NULL)` reloads alternates from that directory — which has none — rather than from the repository’s real alternates. This means objects that have moved to an alternate since the quarantine was created will not be found, even if the alternates file was updated. Before the ODB abstraction regression (5946a564cd, March 2026), `receive-pack` would reload the repository’s real alternates because it only passed the quarantine to child processes via environment variables, not as its own primary ODB.

The review suggests a **design change**: always reload the repository’s real alternates, not the current `files->dirs`'s alternates. This would restore the pre-regression behavior for `receive-pack` and extend it to any context using a temporary primary directory. Christian notes that with Patrick’s fourth patch (which adds `stat_validity` tracking), this change would incur no additional I/O cost.

He also flags two related code paths in `odb_files_dir_is_usable()` that would need adjustment if the design changes: the hashmap seeding and the realpath comparison, both of which currently use `files->dirs` and would become reachable once real alternates are reloaded.

The review is **technical and precise**, referencing specific commits, functions, and control flow. It does not question the overall goal of the series but points out a **subtle correctness gap** that could affect production workflows (notably `git push` with object quarantine). The tone is constructive and forward-looking, proposing a clear path to resolution. This feedback is likely to require a v2 of the series.
