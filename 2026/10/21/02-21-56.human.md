This is a small but meaningful i18n (internationalization) patch from an Outreachy contributor. The patch fixes a pluralization issue in the message that `git checkout` shows when it leaves orphaned commits behind. Currently the message uses `_()` (the basic gettext wrapper), which doesn’t allow translators to provide language-specific plural forms. The patch switches it to `Q_()`, the gettext pluralization macro, so languages like Polish that have more than two plural forms can handle the count correctly. The English output remains unchanged.

The change is confined to a single line in `builtin/checkout.c` and comes with a clear explanation in the commit message: the count is always 2 or more (when only one commit is left, Git lists it explicitly instead of using this message), but some languages still need the plural form flexibility. The patch is well-scoped and addresses a real, if minor, usability gap for non-English users. It looks like a solid first contribution.
