This is the first patch in Harald Nordgren’s two-patch v2 series fixing `git imap-send`. It plugs a minor memory leak in the tunnel-command handling: when `imap.tunnel` is configured, `imap_open_store()` starts a child process but never releases its argument list. The fix is a one-line addition—`child_process_clear(&tunnel)`—immediately after the tunnel is started, freeing the now-unneeded `child_process` structure while keeping the pipes open. No tests exercise `imap.tunnel`, so the leak went unnoticed until now. The patch is a straightforward cleanup with no behavior change, ready for integration alongside the rest of the series.
