The patch touches `builtin/repo.c` to read these config values, renames the threshold array to reflect its new role, and updates the test suite (`t/t1901-repo-structure.sh`) with extensive new coverage for configurable thresholds and their effect on output.

The config keys use hyphenated names (`commit-count`, `blob-size`, etc.) that match the CLI output labels, making them intuitive to users. The test suite now verifies that configured thresholds produce the expected star ratings in both table and key-value output formats, and that the config mechanism itself works as intended.
