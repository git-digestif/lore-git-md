This is a documentation patch, the final piece of the 13-part series implementing **pack index v3** for SHA-1/SHA-256 interoperability. The patch moves the technical specification of the new index format from the transitional hash-function document (`Documentation/technical/hash-function-transition.adoc`) into the canonical pack-format reference (`Documentation/gitformat-pack.adoc`), where users and developers will naturally look for it.

The change is straightforward: 75 lines of AsciiDoc are copied verbatim from the transition document into `gitformat-pack.adoc`, preserving the original text for compatibility. The new section documents the v3 header fields (signature, version, object count, format count, per-format metadata), alignment rules, the dual-format table layout, and the trailer checksums. It also clarifies that the two hashes at the end of the index file always use the repository’s main algorithm, regardless of the order in which the formats appear.

This patch is purely mechanical and uncontroversial; it simply relocates existing documentation to a more discoverable location. The series as a whole is a well-crafted, critical step toward full SHA-256 interoperability, and this final patch ensures the on-disk format is properly documented for future reference.
