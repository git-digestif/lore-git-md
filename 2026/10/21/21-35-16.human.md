This is the first patch in a three-part bugfix series for `git switch` and `git branch --set-upstream-to`. It fixes a misleading hint message that appears when tracking configuration fails due to a locked config file. Currently, the hint incorrectly includes the full ref name (e.g., `origin/refs/heads/feat`) instead of the short name (e.g., `origin/feat`), causing the suggested command to fail if run as printed.

The patch strips the `refs/heads/` prefix from the hint, matching the behavior already used in the success message of the same function. The fix is minimal and targeted, touching only the hint formatting logic in `branch.c` and adding a comprehensive test in `t/t3200-branch.sh`. The test verifies the entire multiline hint message and confirms the suggested command works once the lock is removed, addressing feedback from the v1 review.

This is a straightforward usability fix with no behavior changes beyond the hint text. The regression was introduced in 2021 (commit a3f40ec4b0) and has been present since. The patch is well-explained, includes thorough test coverage, and aligns with the project's preference for small, focused changes. No controversy or objections have been raised in the thread.
