This is a small, targeted patch to the bash-completion script in Git’s `contrib/` directory. It adds tab-completion support for the `--graph-indent` and `--no-graph-indent` options that were recently introduced to `git log`. The change is a single line that plugs the new flags into the existing `__git_log_common_options` list, so they’ll be offered whenever the user types `git log --<TAB>`.

The patch is well-scoped and uncontroversial: it matches the style of the surrounding code, the commit message is clear, and the options it adds are already part of the Git binary, so there’s no new behavior being proposed—just better discoverability. If you use bash completions and care about the `--graph-indent` feature, this is a nice quality-of-life improvement.
