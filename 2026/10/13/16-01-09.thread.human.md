This thread is about a bug in `git pull --rebase` that causes it to miscompute the fork-point when a user has configured a custom fetch refspec (e.g., `+refs/heads/*:refs/remotes/origin/custom/*`). The issue stems from hardcoded assumptions in `get_tracking_branch()` about the default remote-tracking ref layout, which can lead to incorrect or missing ref lookups. Both Junio C Hamano and Harald Nordgren have confirmed this is a legitimate defect, not a design limitation, and it affects an in-flight topic rather than `master`.
