This Outreachy microproject proposes a small but meaningful improvement to Git's translation infrastructure. Okhuomon Ajayi submitted a patch converting the hard-coded English pluralization message `"Marked %d islands, done."` in `delta-islands.c` to use the `Q_()` ngettext wrapper, which allows translators to handle singular and plural forms correctly in languages with more complex pluralization rules than English.

The patch itself is straightforward: it replaces the simple gettext wrapper `_()` with `Q_()` and provides both singular and plural message forms. Junio C Hamano reviewed the patch positively, calling the change sensible and aligned with Git's l10n efforts. His only feedback was about the commit message's inclusion of the grep command used to find the issue, which he noted produces false positives and isn't particularly actionable for other contributors. This is a surface-level suggestion rather than a technical objection.

The patch touches only one file and requires no additional test coverage beyond verifying the English output remains unchanged. As a standalone Outreachy microproject, it follows the pattern of similar past contributions and appears likely to be accepted once the minor commit message adjustment is made. No substantive concerns have been raised, and the change is uncontroversial.
