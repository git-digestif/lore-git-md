This is a maintainer review of the v2 patch that fixes a crash in `git fast-import` when resolving commits or tags created earlier in the same session. Junio C Hamano provides a targeted suggestion to improve the test case in `t/t9300-fast-import.sh` by reducing duplication between the SHA-1 and SHA-256 variants. The current test uses two nearly identical input files (`Y-reference-pending-sha1` and `Y-reference-pending-sha256`), differing only in the embedded object names, which makes the test harder to maintain.

Junio proposes using Git's `test_oid_cache` and `test_oid` mechanisms to abstract the object names, allowing a single test script to work for both hash algorithms. This approach is standard in the test suite and would make the test more concise and easier to update. The suggestion is purely about test hygiene—no changes to the core fix in `builtin/fast-import.c` are requested or implied. The patch remains technically sound and ready for integration once this minor test improvement is addressed. The author, Marc Becker, has not yet responded to this feedback.
