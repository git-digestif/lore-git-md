# Thread deltas

## 2026/10/13

- [2026/10/13/14-44-39 by Rong Bao <rong.bao@csmantle.top>] Rong Bao submitted a patch fixing `git fetch --all --depth=` and `--all --unshallow`, which failed to deepen shallow clones because the parent process did not pass the depth flag to the fetcher subprocess; the fix adds `--depth=%s` to the subprocess argv in `builtin/fetch.c` when deepening is requested, with new tests in `t/t5514-fetch-multiple.sh` covering both flags.

## 2026/10/15

- [2026/10/15/20-03-32 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano questioned whether the same lack of `--depth` propagation affects submodule fetches under `--recurse-submodules` (which also uses `add_options_to_argv`) and whether the fix might regress users depending on current submodule depth behavior; he also asked whether the `depth` variable is NULL when only `--deepen-since` is specified (since `deepen` is set by any of the three shallow options), proposed rewriting the patch as three separate conditionals for `depth`, `deepen_since`, and `deepen_not` rather than checking `deepen`, and warned that propagating `--shallow-exclude` to submodules is likely inappropriate given their unrelated history.

## 2026/10/16

- [2026/10/16/10-26-39 by Rong Bao <rong.bao@csmantle.top>] Rong Bao agreed with Junio C Hamano that "--depth=" given to the outer "fetch --all" is not propagated down to subfetches.
- [2026/10/16/10-26-39 by Rong Bao <rong.bao@csmantle.top>] Rong Bao disputed that propagating --depth= to --recurse-submodules fetches would be a regression, arguing the documentation does not state --depth= should not apply to submodules, noting that --[no-]tags is already passed through to recursive submodule fetches, and stating he reads "git fetch --unshallow --recurse-submodules" as unshallowing the tree including all submodules.
- [2026/10/16/10-26-39 by Rong Bao <rong.bao@csmantle.top>] Rong Bao said he will revise in v2 to check depth, deepen_since, and deepen_not as separate conditions rather than using the 'deepen' variable.
- [2026/10/16/10-26-39 by Rong Bao <rong.bao@csmantle.top>] Rong Bao decided to limit the patch scope to --depth= and --shallow-since=, excluding --shallow-exclude, since --depth= is the original fix and --shallow-since= is minimal to implement.
