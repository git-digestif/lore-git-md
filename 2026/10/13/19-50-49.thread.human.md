This thread is about adding shell completion support for three `git log` options (`--graph-indent`, `--no-graph-indent`, and `--graph-lane-limit`) to the bash-completion script in `contrib/`. The patch, now in its second version, has incorporated feedback from the initial review.

Mirko Faina, the author, has updated the patch to group these options with `--graph` in the `__git_log_gitk_options` block, as suggested by Pablo Sabater. This change reflects the semantic relationship between the options, all of which modify graph rendering and are only relevant when `--graph` is used. The patch also now includes `--graph-lane-limit`, which was missing in the first version. The update is mechanical and low-risk, touching only the completion script without affecting Git's core functionality.

The discussion has also touched on broader architectural questions, such as whether the completion script should suppress `--graph`-dependent options unless `--graph` is present, and whether Git could expose completion hints via `parse-options.h` to make the system self-maintaining. However, these ideas remain speculative and are not addressed in this patch. The immediate goal—adding missing completions—has consensus, and Mirko plans no further changes beyond this version. The patch is ready for final review and integration.
