This thread is a small but useful housekeeping patch from Mirko Faina, adding bash-completion support for the `--graph-indent` and `--no-graph-indent` options to `git log`. These options, originally implemented by Pablo Celayes, were missing from the completion script in `contrib/completion/git-completion.bash`. The patch itself is straightforward and uncontroversial, following existing patterns for completion updates.

Mirko followed up on their own patch to cc Pablo as a courtesy, ensuring the original feature author is aware of the completion addition. There’s been no review feedback yet, and the patch remains ready for review or merge. The only minor open question—whether these completions should be restricted to `git log` rather than shared via `__git_log_common_options`—hasn’t been raised in the thread so far. Unless Pablo or another reviewer objects, this is likely to be merged as-is.
