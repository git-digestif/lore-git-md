This thread is about a small but useful improvement to Git's bash completion script. Mirko Faina proposed adding completion support for three `git log` options: `--graph-indent`, `--no-graph-indent`, and `--graph-lane-limit`. These options were already part of Git but missing from the completion system, which meant users couldn't tab-complete them.

The discussion touched on some broader architectural questions—like whether completion should be conditional (only showing `--graph-indent` if `--graph` is already on the command line) and whether Git could generate completion hints automatically—but the patch itself was straightforward. After a round of review from Pablo Sabater and Toon Claes, Mirko sent a revised version (v2) that moved the options to the right place in the completion script and added the missing `--graph-lane-limit`. Toon gave it a "Looks good to me," and Junio, the maintainer, has now endorsed it for merging.

The patch is uncontroversial and ready to go. It doesn't change how Git works, just makes the command-line interface a little more convenient. Expect to see it in the next release. The bigger questions about how to improve completion in the long run remain open, but for now, this fills a clear gap.
