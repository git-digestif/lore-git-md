Key technical details
• **Refs/remotes** – `js/push-refspec-match-speedup` (15 commits) replaces linear refspec traversals with `strmap` lookups; `mc/refs-rename-transaction` (4 commits) refactors ref renames to use transactions.
• **ODB/packfiles** – `ps/odb-files-alternates` (13 commits) makes alternates an implementation detail of the “files” backend; `ps/packfile-stale-delta-base-cache-fix` (2 commits) fixes corruption from stale cache entries; `tb/repack-cruft-less-midx-corner-cases` (8 commits) addresses MIDX reachability closure issues.
• **Connectivity checks** – `kk/connectivity-check-incremental` (4 commits) adds `transfer.connectivityCheck=incremental` to compare trees instead of walking full object closures.
• **Configuration** – `ic/includeif-hostname` (3 commits) extends `includeIf` to support hostname matching and adds `git var GIT_HOSTNAME`.
• **Merge/conflict handling** – `pw/checkout-m-conflict-labels` (3 commits) preserves original conflict labels in `.git/MERGE_LABELS`.
• **Performance** – `kn/packed-refs-verbatim-write` (1 commit) optimizes packed-refs rewrites with `fwrite()`; `ps/odb-files-alternates-cleanups` (5 commits) refactors ODB alternates to prioritize packfiles.
• **Stash completion** – `dk/stash-completion-updates` (5 commits) updates `git stash` completion to dynamically discover subcommands (replacing hardcoded lists), fixes a Zsh-specific formatting issue where stash references were improperly unquoted, extracts common stash-listing code, and removes the deprecated `save` subcommand from completions and documentation. Files touched: `contrib/completion/` and `Documentation/git-stash.txt`.
• **Repository initialization** – `ps/setup-enforce-repo-passed-to-create-repository-has-no-state` refactors the repository initialization sequence to treat the repository object passed to `create_repository()` as a pure out-parameter, removing any assumption that it carries pre-existing state. Touches `repo_clear()`, `git clone`, and `git init` handling of `core.sharedRepository`.
• **New symbols** – config keys: `transfer.connectivityCheck`, `core.indexLockTimeout`, `uploadpack.lazyFetchTrusted`; CLI options: `--[no-]graph-indent`; files: `.git/MERGE_LABELS`, `.git-blame-ignore-revs` (now default).
