Core problem or goal
Convert the hard-coded English pluralization message `"Marked %d islands, done."` in `delta-islands.c` from the simple gettext wrapper `_()` to the ngettext wrapper `Q_()` so that translations can correctly handle singular and plural forms for languages with more than two plural rules.

Current status
Patch posted; under review. Junio C Hamano provided feedback on the commit message (specifically the inclusion of the grep command used to find the issue), noting it produces false positives and is not actionable for others. The author has acknowledged the feedback and will remove the grep command in a follow-up version. The change itself remains uncontroversial and aligns with the ongoing l10n effort.

Key technical details
File: `delta-islands.c`
Line: 42 (the message `fprintf(stderr, _("Marked %d islands, done.\n"), nr);` is replaced with `fprintf(stderr, Q_("Marked %d island, done.\n", "Marked %d islands, done.\n", nr), nr);`)
New symbol: `Q_()` replaces `_()`
Subsystem: l10n (translation infrastructure)
