Core problem or goal
Convert the hard-coded English pluralization message `"Marked %d islands, done."` in `delta-islands.c` from the simple gettext wrapper `_()` to the ngettext wrapper `Q_()` so that translations can correctly handle singular and plural forms.

Current status
Patch posted; under initial review. Junio C Hamano provided feedback on the commit message (specifically the inclusion of the grep command used to find the issue), noting it produces false positives and is not actionable for others. The change itself remains uncontroversial and aligns with the ongoing l10n effort.

Key technical details
File: `delta-islands.c`
Line: 42 (the message `fprintf(stderr, _("Marked %d islands, done.\n"), nr);` is replaced with `fprintf(stderr, Q_("Marked %d island, done.\n", "Marked %d islands, done.\n", nr), nr);`)
New symbol: `Q_()` replaces `_()`
Subsystem: l10n (translation infrastructure)
Test coverage: none required beyond verifying the English output remains unchanged

Open questions and loose ends
Whether to retain the grep command in the commit message. Junio’s feedback suggests it should be dropped or revised.
