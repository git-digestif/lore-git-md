Thread identity: Bugfix patch series (single patch) addressing a regression in `git fetch --all --depth=<n>` and `git fetch --all --unshallow` introduced in Git 2.56.0. Originating author: Rong Bao. Thread type: bug report and fix.

Core problem or goal: When running `git fetch --all --depth=<n>` or `git fetch --all --unshallow` with multiple remotes configured, the `--depth` or `--unshallow` flags are not forwarded to the fetcher subprocesses spawned for each remote, causing the shallow repository to remain shallow instead of being deepened or unshallowed as intended. The goal is to restore the expected behavior by ensuring these flags are explicitly passed to all subprocesses.
