This is the second patch in the v7 rerere race-condition fix series. Patrick Steinhardt replies to Thomas Bachem’s implementation of `--skip-locked` for `git rerere gc` with a small but clear design preference: he now thinks the original approach—using a single `RERERE_NOWAIT` flag in the existing bitmask—was cleaner than the current version, which introduces a separate `enum rerere_gc_flags` and requires translating between the two. The change is purely internal (no user-visible behavior or documentation is affected) and does not block integration, but it reflects a minor API design disagreement. Thomas can either drop the enum and revert to the shared bitmask or keep the current structure; either way, the patch remains technically complete and ready for Junio’s queue.
