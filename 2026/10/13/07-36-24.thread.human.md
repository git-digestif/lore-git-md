This thread is a six-patch refactoring series by Patrick Steinhardt that optimizes and cleans up alternates handling in Git’s object database (ODB) "files" backend. The series, now at v3, has addressed all substantive feedback, including a new regression test (authored by Tyrie Vella) that verifies the performance optimization—objects in alternate packfiles are checked before loose objects in the main repository, yielding a 1.89x speedup for `git cat-file --batch-check`.

Key changes include reordering loops to prioritize packfile checks, confining the second-read logic to the "files" backend, removing redundant read loops and error-handling logic in `do_oid_object_info_extended()`, and moving the `local` flag from the generic ODB source API into the packed source. The series touches 13 files, including a new test script (`t/t5615-alternate-env.sh`), and achieves a net reduction of 11 lines while preserving all existing behavior. Justin Tobler provided thorough, tested reviews for all patches, endorsing the design and implementation, while Johannes Schindelin’s feedback focused on test coverage.

The only unresolved question is the long-term viability of the `ODB_FOR_EACH_OBJECT_LOCAL_ONLY` flag, which Patrick and Justin agree is redundant but defer removing until a future series.
