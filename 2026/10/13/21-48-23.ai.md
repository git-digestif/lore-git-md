This is a **substantive, tested review** of the fourth patch in Patrick Steinhardt’s five-patch ODB refactoring series. Justin Tobler confirms the patch’s core rationale—removing a redundant read loop in `do_oid_object_info_extended()`—and traces the code path to verify that the "files" backend now handles retries internally.
