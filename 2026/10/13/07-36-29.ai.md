This is the fifth and final patch in Patrick Steinhardt’s five-part series refactoring and optimizing alternates handling in the Git object database’s "files" backend. The patch removes the `local` flag from the generic `struct odb_source` and moves it into the packed source (`struct odb_source_packed`), completing the internal cleanup begun in earlier patches.

The change is mechanical and confined to the ODB plumbing layer. The `local` flag, which previously indicated whether an object source was the primary object directory of the repository, is no longer meaningful at the generic source level now that alternates are handled entirely within the "files" backend. The packed source still needs the flag to propagate it to opened packfiles, so it is retained there. The loose source no longer uses the flag at all, and the in-memory source was already ignoring it.

The diff touches ten files, with the bulk of the changes in `odb/source.h` (removing the flag from the generic source struct), `odb/source-packed.h` (adding it to the packed source struct), and the corresponding source files that initialize or use the flag. The net effect is a small reduction in code complexity and a clearer separation of concerns within the ODB source API.

No user-visible behavior changes are expected, and the patch relies on existing test coverage. It is a natural follow-up to the alternates migration and the earlier patches in this series, further simplifying the ODB internals. The change looks uncontroversial and well-motivated.
