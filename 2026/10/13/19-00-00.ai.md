This is a bug report about `git log --graph` misrendering an orphaned branch.

The author describes a specific rendering error in `git log --graph --all --oneline`: an orphaned commit (5a2cecdd9) is drawn with a spurious parent connection, causing the rightmost lane to extend incorrectly into empty space. The expected behavior is that the orphaned commit should appear as a standalone node without any parent lines. The issue is reproducible with the public repository `packagecontrol/thecrawl.git` and requires `--all` to manifest; the author has not produced a smaller test case.

The report includes system information (Git 2.56.0.windows.2 on Windows 10) and a clear before/after ASCII-art illustration of the rendering problem. No patch is provided; this is purely a bug report. The issue appears to be in the graph-drawing logic, likely in the `graph.c` subsystem, where the algorithm fails to recognize that an orphaned commit should not have any parent connections in the graph layout. The report is well-structured and actionable, though the lack of a minimal reproduction may make debugging slightly harder.
