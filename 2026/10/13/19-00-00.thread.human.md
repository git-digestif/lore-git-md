This thread is about a bug in `git log --graph --all --oneline` that causes orphaned commits (like those created with `git merge --allow-unrelated-histories`) to be misrendered with a spurious parent connection. The issue, introduced in July 2026, was reported by Caspar Duregger (herr.kaste) with a clear reproduction case and a minimal fix targeting `graph.c`.

The patch modifies `graph_is_visual_root()` to avoid incorrectly indenting orphaned commits when there are columns to their right, ensuring they appear as standalone nodes. Pablo Sabater identified the root cause (a misalignment in the `GRAPH_PRE_ROOT` state) and explicitly approved the fix, calling it "good to me." Junio C Hamano has now queued the patch, signaling it’s in the integration pipeline. The fix includes a new test case in `t/t4218-log-graph-indentation.sh` and is confirmed to be platform-agnostic with no side effects.

No objections or edge cases have been raised, and the thread is effectively closed pending formal merge. The only remaining step is resending the patch via `git send-email` to enable `b4` processing, though Junio’s note suggests this may already be underway. The fix is ready for integration.
