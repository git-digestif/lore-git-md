# Thread deltas

## 2026/10/13

- [2026/10/13/21-24-41 by SZEDER Gábor <szeder.dev@gmail.com>] SZEDER Gábor reproduced the performance regression in the git repository, benchmarking `git log --follow` on `t/valgrind/valgrind.sh` at 8.825s with commit 304812ed33 versus 3.275s with its parent (2.69x slower).
- [2026/10/13/21-24-41 by SZEDER Gábor <szeder.dev@gmail.com>] Trace performance analysis showed 4.45s of the 8.8s total runtime is spent in `propagate_follow_pathspec_to_parent()` when processing second...N-th parents of merge commits.
- [2026/10/13/21-24-41 by SZEDER Gábor <szeder.dev@gmail.com>] He observed that line-level log (`-L1,40`) runs faster than `--follow` even before the regression (1.454s vs 3.260s on the pre-regression commit).
- [2026/10/13/21-24-41 by SZEDER Gábor <szeder.dev@gmail.com>] He hypothesized the cause: `--follow` diffs merge commits against all parents and always checks for renames, while line-level log skips the diff when the path is unmodified versus the first parent and only checks renames when the path is absent.
