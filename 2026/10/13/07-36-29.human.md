This is the fifth and final patch in Patrick Steinhardt’s five-part series refactoring and optimizing alternates handling in Git’s object database (ODB) "files" backend. The patch removes the `local` flag from the generic `struct odb_source` and moves it into the packed source implementation where it is still needed.

The change is a clean-up follow-up to the earlier patches in the series, particularly the migration of alternates handling into the "files" backend. The `local` flag, which indicated whether an ODB source was the primary object directory of the repository, no longer makes sense as a generic property now that alternates are managed within the backend. The packed source still requires the flag to propagate it to packfiles, so the patch relocates the field into `struct odb_source_packed` and updates all callers accordingly.

The diff touches ten files, with the most significant changes in `odb/source.h` (removing the field), `odb/source-packed.h` (adding it), and the corresponding source files that initialize or use the flag. The net effect is a small reduction in code complexity and a clearer separation of concerns within the ODB source API. No user-visible behavior changes are expected, and the patch relies on existing test coverage.

This is a well-scoped, mechanical refactoring that aligns with the series’ goal of simplifying the ODB internals. It looks uncontroversial and is consistent with Patrick’s established expertise in this area. The series as a whole appears ready for integration once review feedback is addressed.
