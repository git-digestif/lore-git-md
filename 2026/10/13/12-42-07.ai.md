This is a documentation patch discussion, specifically a follow-up on naming conventions and usability of Git’s help system. Julia Evans reflects on the tension between the recommended way to access Git documentation (`git help detached-head`) and the traditional man page references (`git-config(1)`) used within the documentation itself. She notes that users seeing `git-config(1)` in a man page are likely to type `man git-config`, not realize they can use `git help config`, and that the `git-help` man page does not explain how to map these references to `git help` commands. While she acknowledges this is not an immediate blocker for the current patch, she flags it as a potential future usability improvement: if the project wants to encourage `git help` over raw `man`, the internal cross-references in man pages may need to be revisited. The discussion remains documentation-only and does not affect the technical content of the detached HEAD rewrite; it is purely about how users discover and navigate the documentation.
