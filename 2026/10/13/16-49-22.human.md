This is a translation (l10n) patch from an Outreachy applicant. Okhuomon Ajayi sends the first version of a microproject that converts a hard-coded English pluralization message in `delta-islands.c` from the simple gettext wrapper `_()` to the ngettext wrapper `Q_()`. The change is mechanical: the single line `fprintf(stderr, _("Marked %d islands, done.\n"), island_counter);` becomes a two-line `Q_()` call that supplies both singular and plural forms, allowing translators to handle languages with more than two plural forms correctly.

The patch is well-scoped and uncontroversial. The commit message explains the motivation clearly, the grep command shows the author searched for similar patterns, and the diff is minimal. No test changes are needed because the patch only affects translation infrastructure, not program behavior. This is a typical Outreachy microproject: small, self-contained, and a good way for a new contributor to get familiar with the codebase and the mailing-list workflow.
