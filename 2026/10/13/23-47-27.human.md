This is Junio’s "What’s cooking" report for October 2026, summarizing the state of 50+ in-flight topics. Below are the highlights a busy Git developer should know.

The report is organized by topic maturity: new topics at the top, cooking (mostly in `next`) in the middle, and discarded at the end. Each topic is labeled with its current integration branch (`next` or `seen`), its state (needs review, expecting a reroll, waiting for response, etc.), and any open discussion threads.

Notable new topics
- **js/push-refspec-match-speedup** (15 patches): replaces linear refspec matching with strmap lookups, speeding up `git push` with many delete refspecs against a server with thousands of refs. The series is marked “expecting a reroll” after Junio and Peff pointed out edge cases around duplicate destinations and `./`-prefixed refspecs.
- **rs/archive-zip-omit-out-of-range-mtime**: omits the UT extra field in ZIP archives when the commit time exceeds 32-bit signed range, avoiding 2038 wraparound. René is rerolling after a SQUASH note about timestamp_t vs time_t width.
- **ic/includeif-hostname** (3 patches): extends `includeIf` to match the machine’s hostname and adds `git var GIT_HOSTNAME`. Junio asked for clarification on whether the hostname should be FQDN or short name; the author has not yet responded.
- **kk/connectivity-check-incremental** (4 patches): introduces `transfer.connectivityCheck=incremental` to compare incoming trees against trusted parent trees instead of walking the full object closure. The series is marked “expecting a reroll” after Peff and Stolee raised concerns about boundary conditions and performance regressions in pathological cases.
- **kn/fetch-tag-backfill-batch-fix**: fixes a shallow-fetch bug where batched reference updates were not committed before tag backfilling, causing negotiation to restart from scratch. Junio asked for a test; no response yet.

Topics cooking in `next` (likely to graduate soon)
- **ps/odb-files-alternates** (13 patches, merged to `next`): moves alternates handling from the core ODB layer into the files backend, eliminating redundant `stat(3p)` calls and simplifying the API. The follow-up **ps/odb-files-alternates-cleanups** (5 patches) is still under review.
- **rm/blame-default-ignore-revs** (2 patches): makes `.git-blame-ignore-revs` the default ignore list for `git blame` and `git annotate`. Junio signaled “will merge to next” after the parser hardening was addressed.
- **pw/checkout-m-conflict-labels** (3 patches): remembers original conflict labels (branch names) in `.git/MERGE_LABELS` so `git checkout -m` can restore them instead of showing generic labels. Junio asked for a test; Phillip is preparing one.
- **tb/rerere-wait-for-merge-rr-lock** (2 patches): makes `rerere` wait for `MERGE_RR.lock` instead of failing immediately, and adds `gc --skip-locked` to avoid auto-maintenance races. Junio and Peff both signaled approval.
- **cc/lazy-fetch-trusted-bit** (5 patches): adds `uploadpack.lazyFetchTrusted` to allow lazy fetching from promisor remotes when serving trusted repositories. Junio asked for a test; Christian is working on it.

Topics that may need attention
- **hn/fetch-refmap** (5 patches): changes the default refspec for remotes added in shallow repositories to rely on `remote.<name>.refmap` instead of `remote.<name>.fetch`, pulling only tracked branches. Junio and Taylor Blau raised concerns about backward compatibility; the author has not yet responded.
- **mc/refs-rename-transaction** (4 patches): refactors ref rename and copy to use the transaction API, ensuring hooks see unified logical updates. The series currently breaks `seen`; Maciej is addressing the fallout.
- **je/doc-merge-conflicts** (7 patches): introduces a new `gitmergeconflicts(7)` man page and links to it from `git merge`, `git rebase`, etc. Junio asked for a SQUASH to fix a formatting nit; the author has not yet replied.

Discarded
- **ds/trace2-tolerate-failed-timestamp**: retracted after the author realized that banning `xcalloc()` and friends from trace2 would require a larger refactoring than originally scoped.

In short: if you care about performance, watch **js/push-refspec-match-speedup** and **ps/odb-files-alternates**; if you care about shallow fetches, **kn/fetch-tag-backfill-batch-fix**; if you care about merge conflicts, **je/doc-merge-conflicts**. Everything else is either polishing, documentation, or waiting for a reroll.
