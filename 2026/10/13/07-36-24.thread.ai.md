Subject: [PATCH 0/5] odb: refactor and optimize alternates handling in files backend
Series version: v1 (initial submission)
Originating author: Patrick Steinhardt
Thread type: patch series (refactoring/performance)

Core problem or goal
Refactor and optimize the alternates mechanism in the Git object database’s "files" backend. The series addresses performance inefficiencies in reading and streaming objects when alternates are present, then performs internal cleanup to simplify the ODB source API and remove redundant code. No user-visible behavior changes are intended.

Current status
Under review; v1 posted. No prior versions of this specific series. Built on Patrick’s earlier `ps/odb-files-alternates` branch, which migrated alternates handling into the files backend.

Key technical details
Files touched: 12 total (series-wide); primary changes in `odb.c`, `odb/source-files.c`, `odb/source.h`, `odb/source-loose.c`, `odb/source-packed.c`, `odb/source-packed.h`. Patch 1/5 reorders loops in the "files" backend to prioritize packfile checks over loose-object `stat()` calls, achieving a 2x speedup in object lookup when alternates are present (benchmarked by Patrick). Patch 2/5 applies the same optimization to object streaming, aligning its behavior with the direct-read optimization in patch 1/5. Patch 3/5 removes the `OBJECT_INFO_SECOND_READ` flag and moves the second object read logic into the "files" backend, replacing it with `OBJECT_INFO_QUICK` in the packed source to determine when to scan packfiles covered by a MIDX (expected to have minimal performance impact). Patch 4/5 removes a redundant read loop in `do_oid_object_info_extended()` by replacing it with a single explicit re-read after fetching from a promisor remote. Patch 5/5 removes the now-unused `local` flag from the generic `struct odb_source` and moves it into `struct odb_source_packed`, completing the internal API cleanup.
Behavior changes: none (plumbing-level). On-disk format: unchanged.
Test coverage: relies on existing ODB tests; no new tests introduced in this series.

Open questions and loose ends
None raised; series remains uncontroversial.

Participant positions
Patrick Steinhardt (author): identified and fixed performance regressions in alternates handling (patches 1/5 and 2/5), providing benchmark data for the first patch and arguing for consistency in the second. Removed the redundant read loop in `do_oid_object_info_extended()` (patch 4/5) and the `local` flag from the generic ODB source struct (patch 5/5), retaining it only in the packed source where it is still needed.
