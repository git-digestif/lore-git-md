Core problem or goal: reduce redundant computation in `git stash` by reusing the already-prepared index state and untracked file list when `do_push_stash()` calls `do_create_stash()`, yielding measurable performance gains (16-18% for `git stash -p`, 6% for `git stash push` on the Linux kernel repository).

The change is confined to the stash subsystem; `git stash create` behavior is preserved. No new symbols, CLI options, or on-disk format changes.
