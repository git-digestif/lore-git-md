# Thread deltas

## 2026/10/31

- [2026/10/31/15-57-00 by Ravi Mistry via GitGitGadget <gitgitgadget@gmail.com>] Ravi Mistry posted a 4-patch series addressing four gaps in HTTP 429 retry handling: an off-by-one retry count and Retry-After Trace2 timing bug, lack of exponential backoff when Retry-After is absent, inability to retry transient 5xx errors, and lack of retry support for HTTP POST requests in post_rpc().
- [2026/10/31/15-57-01 by Ravi Mistry via GitGitGadget <gitgitgadget@gmail.com>] Ravi Mistry fixed the off-by-one retry count bug in http_request_recoverable() (where http.maxRetries=N performed only N-1 retries) and moved CURLINFO_RETRY_AFTER extraction into finish_active_slot() so the http/429-retry-after Trace2 event logs the actual Retry-After value instead of -1.
- [2026/10/31/15-57-02 by Ravi Mistry via GitGitGadget <gitgitgadget@gmail.com>] Ravi Mistry added exponential backoff for HTTP 429 retries when no Retry-After header is present, doubling http.retryAfter on each subsequent attempt (1s, 2s, 4s, ...) capped at http.maxRetryTime.
- [2026/10/31/15-57-03 by Ravi Mistry via GitGitGadget <gitgitgadget@gmail.com>] Ravi Mistry added the http.retryStatusCodes config option (and GIT_HTTP_RETRY_STATUS_CODES environment variable), defaulting to "429", allowing environments to opt into retrying additional status codes such as 502, 503, and 504.
- [2026/10/31/15-57-04 by Ravi Mistry via GitGitGadget <gitgitgadget@gmail.com>] Ravi Mistry extended retry support to HTTP POST requests in probe_rpc() and post_rpc() by extracting a shared http_retry_wait() helper, deferred RPC error reporting until retries are exhausted, and re-attached the Content-Encoding: gzip header when retrying compressed requests.
