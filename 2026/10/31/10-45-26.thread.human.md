This thread began as a patch to add a protective guard around `notes-utils.h` to prevent unsafe use of `the_repository`, but the approach was withdrawn after Patrick Steinhardt raised architectural concerns. The discussion has now shifted to a more direct solution: refactoring `notes.c` to use the repository stored in `struct notes_tree` instead of the global `the_repository`. This will eliminate the root cause of the dependency and remove the need for guards entirely.

Junio C Hamano recently clarified why the original protective measure guarded the entire `notes-utils.h` header rather than a subset of functions. He explained that nearly every function in the header ultimately depends on unsafe helpers in `notes.c`, making a targeted guard impractical. This context underscores the necessity of the new approach, which directly addresses the issue in `notes.c`. The thread is now awaiting Okhuomon Ajayi’s forthcoming patch series to implement this refactoring. No code has been merged yet, and the architectural direction is now settled in favor of fixing the root cause.
