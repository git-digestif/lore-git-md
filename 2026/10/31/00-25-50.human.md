This is a test fix patch from Jeff King (Peff). It updates the test script `t5702-protocol-v2.sh` to handle changes in how GNU coreutils 9.12 quotes environment variable output in the `env` command.

The problem: some tests in `t5702` check whether the Git protocol version is set via `GIT_PROTOCOL` by grepping the output of `env`. Older coreutils (like 9.10) output `GIT_PROTOCOL=version=2`, but newer versions (9.12) quote it as `GIT_PROTOCOL='version=2'`, breaking the tests. Peff’s fix replaces the `env` grepping with a direct shell echo of the variable, making the tests more robust and slightly stricter in what they accept.

The patch is small (15 insertions, 8 deletions) and well-motivated. Peff notes that he originally wrote the now-broken `env` approach, so this is a self-contained cleanup. The change is unlikely to be controversial—it’s a clear improvement to test reliability. If you care about test flakiness or protocol v2 behavior, this is worth a quick look.
