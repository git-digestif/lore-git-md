Subject: [PATCH v2 0/6] notes: store repository in `struct notes_tree` and remove `USE_THE_REPOSITORY_VARIABLE` guard
Series version: v2 (six-patch series, now complete)
Originating author: Okhuomon Ajayi (Outreachy intern)
Thread type: patch series (architectural refactoring)

Core problem or goal
Remove implicit uses of the global `the_repository` in the notes subsystem by storing the repository in `struct notes_tree` and updating all notes API functions to use it. This directly addresses Patrick Steinhardt’s architectural concern by fixing unsafe functions at the source, eliminating the need for downstream guards and making the API repository-agnostic.

Current status
Six-patch series now complete and under active review; no merge status (not in `seen`, `next`, or `master`). Patches 1/6–6/6 have been posted, incrementally refactoring `notes.c` and `notes-utils.c` to use `struct notes_tree->repo` or explicit `struct repository *` parameters. The series is structured to handle remaining `the_repository` uses incrementally; temporary use in callers (e.g., `builtin/notes.c`, `notes-cache.c`) will be addressed in later work.
