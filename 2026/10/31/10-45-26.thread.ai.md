Core problem or goal: Remove implicit uses of the global `the_repository` in the notes subsystem by storing the repository in `struct notes_tree` and updating all notes API functions to use it. This directly addresses Patrick Steinhardt's architectural concern by fixing unsafe functions at the source, eliminating the need for downstream guards and making the API repository-agnostic.
