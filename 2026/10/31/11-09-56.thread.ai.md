Thread identity: bugfix series addressing object-size truncation on 32-bit platforms (Windows); originating author Elia Pinto; thread type patch series (v1).

Core problem or goal: fix truncation bugs when object sizes exceed 4 GiB on 32-bit platforms by converting function signatures and call sites from `unsigned long` to `size_t` for object sizes and message buffer indices. User-visible symptoms include `git fsck` inspecting only a prefix of large objects (e.g., `.gitmodules`), `git tag -v` failing to find signatures, and `copy_subject()` misindexing due to integer overflow.

The final patch also fixes an integer-overflow bug in `copy_subject()` by changing its loop index from `int` to `size_t`.
