This is a call for contributions to the next **Git Rev News** edition (140), the community newsletter that highlights recent developments, discussions, and events in the Git project.

The draft is available on GitHub, and Christian Couder invites everyone to help improve it—whether by proofreading, suggesting articles or links, volunteering for interviews, or addressing open issues in the GitHub repository. The edition is scheduled for publication on **November 2, 2026**, so contributions are needed soon.

This is not a code patch or technical discussion but a community coordination email. It’s a routine part of the project’s outreach efforts, and participation is open to all. The draft includes summaries of recent mailing list activity, so contributors can help ensure accuracy or add missing context. No prior experience is required—just an interest in Git development.
