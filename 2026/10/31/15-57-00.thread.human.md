This thread is a four-patch series from Ravi Mistry improving Git’s HTTP transport resilience, covering an off-by-one retry counter bug, missing exponential backoff, configurable retry for transient 5xx errors, and—now reviewed—retries for HTTP POST requests. Junio C Hamano has reviewed all four patches: the first three drew design questions about exponential backoff behavior and documentation clarity, while the fourth (POST retries) received a brief, positive review noting the clean refactoring of retry wait logic into a shared helper. The series is still under review, awaiting the author’s response to Junio’s earlier feedback on patches 2 and 3; no objections have been raised, and the code remains in its initial v1 form. Key changes include a new config key `http.retryStatusCodes`, exponential backoff doubling, and test coverage verifying POST retries survive 429/502 errors and preserve gzipped headers.
