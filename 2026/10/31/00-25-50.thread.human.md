This thread is about a small but important test fix in `t5702-protocol-v2.sh`. The issue arose when newer versions of GNU coreutils (9.12+) started quoting environment variable output in `env`, breaking tests that relied on grepping for `GIT_PROTOCOL=version=2`. Jeff King (peff) proposed a targeted fix that replaces the fragile `env`-grepping logic with explicit shell-based variable printing, making the tests resilient to coreutils behavior changes while maintaining strict validation of the protocol version.

The patch has been reviewed by Junio C Hamano, who traced the original problematic test logic back to his own commit and confirmed the fix is correct. Todd Zullinger also endorsed the approach, noting it’s a net improvement over the prior workaround (`QUOTING_STYLE=literal`). The only minor clarification in this follow-up was Jeff correcting Junio’s interpretation of one test case—fetch expects `version=2`, while push and archive do not—but this doesn’t affect the patch’s validity. The fix is self-contained, touches only the test script, and is ready for integration. No open questions or objections remain.
