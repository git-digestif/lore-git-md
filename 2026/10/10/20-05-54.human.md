This is a bugfix for `git repack` addressing a long-standing regression in `--dry-run` behavior when combined with `--drop-filtered`. The issue has been present since `--dry-run` was introduced in 2023, as the author’s bisection confirms: the `--dry-run` block in `cmd_repack()` never returned early, causing it to fall through into the regular repack code and modify the repository despite the flag’s documented behavior. The fix remains minimal—adding an early `return` after listing candidate objects for dropping—and the author will update the commit message in v2 to document the regression’s origin.

The patch touches only `builtin/repack.c` and adds test coverage verifying that the pack directory remains unchanged under `--dry-run`. D.
