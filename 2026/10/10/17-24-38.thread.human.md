This thread is about a bugfix for `git fast-import` that prevents a crash when resolving commits or tags created earlier in the same session but not yet reachable via the object database. The issue was reported and fixed by Marc Becker, with review and testing from Aniket Gupta and final approval from Junio Hamano.

The fix is now complete and has been queued for merging into `master`. It modifies `parse_from_existing()` in `builtin/fast-import.c` to check the fast-import object cache before falling back to the ODB, ensuring that in-session objects are resolved correctly. The patch includes thorough test coverage for both SHA-1 and SHA-256 repositories and addresses all prior feedback, including commit message clarity and test hygiene. No further changes or discussion are expected, and the fix is uncontroversial.
