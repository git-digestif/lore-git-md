Subject: [PATCH v2] fast-import: fix crash when resolving unreachable in-session commits
Series version: standalone patch, v2
Originating author: Marc Becker
Thread type: bugfix

Core problem or goal
`git fast-import` crashes with `not a valid commit: <oid>` when attempting to resolve a commit or tag created earlier in the same session but not yet reachable via the object database (ODB). The object exists in the fast-import object cache and can be queried for file content (e.g., via `ls`), but the ODB lookup fails because the object is not yet written to disk.

Current status
Under review; v2 posted addressing all feedback from v1. The test verifies resolution of pending commits and tags (including tag-of-tag scenarios) without crashing, while preserving existing behavior for objects already in the ODB.
