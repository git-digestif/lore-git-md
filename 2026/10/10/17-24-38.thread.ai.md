Subject: [PATCH v2] fast-import: fix crash when resolving unreachable in-session commits
Series version: standalone patch, v3
Originating author: Marc Becker
Thread type: bugfix

Core problem or goal
`git fast-import` crashes with `fatal: not a valid commit: <oid>` when attempting to resolve a commit or tag created earlier in the same session but not yet reachable via the object database (ODB). The object exists in the fast-import object cache and can be queried for file content (e.g., via `ls`), but the ODB lookup fails because the object is held in an in-progress packfile until a `checkpoint` or session end.

- File touched: `builtin/fast-import.c`
