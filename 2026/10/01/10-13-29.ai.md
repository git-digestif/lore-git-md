This is a refactoring patch extending the parse-options API to support grouping subcommands. It is the second patch in a three-patch series by Patrick Steinhardt.

The patch introduces a new `OPT_SUBCOMMAND_H()` macro that allows subcommands to carry a help-text description. Previously, only options could be grouped using `OPT_GROUP()`; now subcommands defined with the new macro are also considered for grouping. The change touches the core parse-options machinery (`parse-options.c`, `parse-options.h`), updates the API documentation, and adds a test case demonstrating the new behavior.

Key technical details: the `help` field in the `option` struct is now inspected for subcommands; if non-NULL, the subcommand is included in usage output and can be grouped. The test helper and shell test (`t/t0040-parse-options.sh`) verify that subcommands with help text appear under their designated group in the usage message.

The patch is narrowly scoped, well-tested, and appears to be a natural extension of the existing grouping mechanism. No backward-compatibility issues are introduced; existing subcommands without help text remain unlisted in usage output.
