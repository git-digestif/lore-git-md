This is a brief reply in the ongoing RFC series to create a `gitbreaking-changes(7)` manpage. Patrick Steinhardt agrees with Junio C Hamano’s suggestion to use a hybrid format for message-ID references—embedding both the clickable URL and the raw message-ID in the source (e.g., `cf. https://lore.kernel.org/git/xmqqa59i45wc.fsf@gitster.g/[<xmqqa59i45wc.fsf@gitster.g>^]`). This approach preserves the message-ID for future reference while keeping the rendered output clean and user-friendly.

The discussion is now focused on this minor technical refinement; no broader objections or new concerns have been raised. The series remains on track to improve discoverability of Git’s breaking changes, with all substantive feedback from earlier reviews already addressed. The next step is likely a v3 patch incorporating Junio’s proposed format. If you’re following the effort to make breaking changes more visible to users, this is a small but useful iteration to watch.
