This is a bugfix patch targeting the parse-options subsystem, specifically the `--git-completion-helper` output formatting. It is the first patch in a three-part series from Patrick Steinhardt.

The patch addresses a subtle but long-standing issue in `show_gitcomp()` where the completion helper can emit a leading space when the first option in the list is skipped (e.g., because it is a group or hidden option). The fix replaces the problematic `opts == original_opts` check with an explicit boolean flag (`first`) that tracks whether anything has been printed yet. The change is minimal: one new variable, one line of initialization, and a one-line update to the printf format string.

The test helper is updated to include an `OPT_GROUP` as the first option, which exercises the bug and verifies the fix. The commit message is clear and self-contained, explaining both the symptom and the root cause.
