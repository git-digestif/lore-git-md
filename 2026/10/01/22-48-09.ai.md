This is Junio’s "What’s cooking" report for October 2026 (#01), summarizing the state of 60+ in-flight topics across the four integration branches (`maint`, `master`, `next`, `seen`).

Key headlines
- The next release is named **Git 2.98** (not 2.57) to prepare for the upcoming **Git 3.0** in spring 2027.
- **Nine topics graduated to `master`** since the last report, touching reflog expiry, reference storage terminology, ODB alternates, reflog timezone handling, and the new `receive-report` hook.
- **`next` is cooking 25 topics**, including Patrick Steinhardt’s ODB and ref-storage clean-ups, Jeff King’s xdiff size_t conversion, Taylor Blau’s cruft-less MIDX corner-case fixes, and Phillip Wood’s conflict-label preservation.
- **`seen` holds 30+ topics**, among them the Rust crate re-org, `git var` identity component extraction, `git fetch --refmap` inference, and the new `gitmergeconflicts(7)` man page.

Notable graduations
- **ps/ref-storage-format** unified the terminology around reference storage (e.g., `--ref-storage-format`, `GIT_REF_STORAGE_FORMAT`) and made the option accept payloads like `reftable://`.
- **ps/odb-alternates-at-creation** deferred alternates setup to ODB creation time, removing the ad-hoc alternate-writing API.
- **hn/history-squash** added a `git history squash` subcommand that folds a range of commits into one, with descendants replayed on top.
- **kn/receive-report-hook** introduced a new `receive-report` hook that runs after reference updates and can filter or modify the packet-line status report sent back to the client.

Topics likely to land soon
- **jk/xdiff-size_t** (7 patches) converts xdiff internals to `size_t` for buffer sizes, fixing LLP64 overflows and plugging uninitialized-memory leaks.
- **tb/repack-cruft-less-midx-corner-cases** (8 patches) ensures reachability closure when writing bitmaps after incremental repacks that omit cruft packs.
- **ps/reftable-reflog-timezone** (3 patches) fixes the on-disk timezone representation in reflogs to store minutes instead of the parsed `+HHMM` integer.
- **dk/stash-apply-index-incore** (4 patches) merges the index in-core using merge-ort, eliminating external `git diff-tree`/`git apply` subprocesses and fixing a concurrent lock-file issue with autostash.

Controversial or stalled topics
- **mh/rust-crate-subdir** (1 patch) moves Rust code into a dedicated `rust/` subdirectory to avoid confusing Cargo when Git is used as a submodule.  Junio has asked for a re-roll to address review comments.
- **tb/rerere-wait-for-merge-rr-lock** (3 patches) makes `rerere` wait for the `MERGE_RR.lock` instead of failing immediately.  Taylor Blau and Phillip Wood have requested changes to the lock-waiting logic.
- **je/doc-remove-gittutorial-2** (3 patches) removes the outdated `gittutorial-2` man page.  Jean-Noël Avila is preparing a re-roll to address translation fallout.
- **tc/push-force-if-includes-fixes** (3 patches) fixes `--force-if-includes` to consult the local branch’s reflog rather than the remote-tracking branch’s.  The topic has been waiting for review since mid-September.

New topics since last report
- **jk/http-curl-strip-creds** (1 patch) handles curl stripping credentials from the effective URL during redirects, preventing spurious credential prompts.
- **hn/fetch-refmap** (5 patches) changes the default refspec for remotes added in shallow repositories to rely on `remote.<name>.refmap`, pulling only remote branches tracked by local branches.
- **gm/filter-branch-state-map-fix** (1 patch) fixes `git filter-branch`’s commit map initialization from the state branch to use the correct original-to-rewritten order.

Housekeeping
- The `maint` branch now points at `maint-2.56`.
- CI improvements: Johannes Schindelin fixed the Windows GitLab CI Rust setup, and Hannes Sixt improved GitHub Actions leak sanitizer annotations.
