This is the first patch in a two-part CI/build system series (v4, 1/2) that improves GitHub Actions failure reporting for leak sanitizer jobs. The patch stops leak-sanitizer scripts at the first failure (using `--immediate`) and adds GitHub Actions annotations that link the leak to the test script where it occurred, with the full sanitizer output displayed in a collapsible log group.

The change is narrowly scoped to `ci/lib.sh` and the test markup helpers. It adds a new `finalize_test_leak_output` function in `t/test-lib-github-workflow-markup.sh` that emits an error annotation pointing to line 1 of the test script (since the exact line is unknown) and wraps the sanitizer log in a collapsible group. The `--immediate` flag is added to `GIT_TEST_OPTS` for leak sanitizer jobs to prevent duplicate "not ok" reports from later tests that inherit the same sanitizer log entries. The patch also reorders `test_failure_()` in `t/test-lib.sh` to ensure annotations are written before any `--immediate` exit, preventing them from being silently dropped.

The commit message justifies the `--immediate` trade-off: stopping at the first leak avoids polluting the output with false failures while still surfacing the real issue. The escaping logic for test descriptions is simplified in this version (only percent signs are escaped), addressing Phillip Wood’s concern about overreach for single-line descriptions. The patch is well-motivated and addresses a real pain point for CI reviewers, though the lack of clickable links in the GitHub Actions UI remains an unresolved limitation.

This patch is cooking in `next` and appears ready for broader testing. The changes are focused, the commit message is clear, and all substantive review feedback has been addressed. The remaining open questions are usability refinements (clickable links, dynamic test descriptions) rather than correctness issues. The patch introduces no on-disk format changes and relies on existing test infrastructure for coverage. Key symbols added: `finalize_test_leak_output`, `github_markup_script_name`, and the `--immediate` flag in `GIT_TEST_OPTS`.
