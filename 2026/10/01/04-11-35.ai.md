This is the first patch in Taylor Blau’s v2 eight-patch series fixing MIDX reachability closure corner cases. It is a pure refactoring that introduces a new `stdin_packs_context` struct to wrap the `rev_info` pointer and `--stdin-packs` mode enum that are currently passed separately through the object-enumeration callbacks in `builtin/pack-objects.c`.

The patch is mechanical: it adds the new struct, updates function signatures to take a `stdin_packs_context *` instead of a bare `rev_info *`, and propagates the context through the call chain. The only behavioral change is a small readability improvement in `add_loose_object()`, where the conditional `if (ctx && type == OBJ_COMMIT)` replaces the previous `if (revs && type == OBJ_COMMIT)`. A comment was added to clarify that `ctx->revs` must be non-NULL, addressing Junio C Hamano’s feedback from v1.

This patch does not fix any bugs or change any user-visible behavior; it simply prepares the codebase for the substantive fixes that follow in patches 2–8. The refactoring is clean, narrowly scoped, and well-justified by the need to reference the `--stdin-packs` mode in future callbacks. No test failures or regressions are expected, and the patch has already received maintainer approval in spirit. It is uncontroversial and ready to merge.
