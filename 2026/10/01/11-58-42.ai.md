This is a user-contributed shell script proposal for a new helper command, `git-rebase-walk`.

The email presents a short Bash script that automates an "iterative rebase" workflow: given a target commit, it finds the merge base between HEAD and that commit, lists all commits reachable from the target but not from HEAD, reverses the list, and then rebases HEAD onto each commit in sequence. The author (Alejandro Colomar) uses this to handle large conflicts by resolving them incrementally rather than all at once. The script is offered as-is, with an invitation to adapt it for inclusion in Git's contrib/ area.

No prior discussion or cover letter is referenced, so this is a standalone RFC. The script is simple and self-contained; it does not touch Git's C code, build system, or test suite. The author volunteers to help polish it if the project is interested.
