This is the first patch in an eight-patch bugfix series targeting Git’s multi-pack-index (MIDX) and cruft-pack machinery. It is a pure refactoring that introduces a `stdin_packs_context` struct to wrap the `rev_info` pointer and `--stdin-packs` mode, preparing the ground for later patches that need to reference the mode within object enumeration callbacks.

The patch is mechanical and well-contained: it touches only `builtin/pack-objects.c`, renames the `_data` parameter to `ctx` in callbacks, and updates function signatures to pass the new struct. A comment clarifies that `ctx->revs` must be non-NULL, addressing Junio C Hamano’s feedback from v1. The commit message is concise and explains the motivation clearly.

This is a preparatory step with no behavior change, so it should be uncontroversial. The refactoring is clean and sets up the rest of the series without introducing risk. Reviewers can focus on whether the new struct is used consistently and whether the non-NULL invariant is maintained. The patch looks ready for integration.
