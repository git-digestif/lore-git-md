Thread identity: Bugfix patch series (2 patches, at v2) addressing `git fetch --prune-tags` behavior inconsistency between documentation and implementation. Originating author is Orgad Shaneh. Patch 1/2 is test-only; patch 2/2 contains the implementation change.

Core problem: The `--prune-tags` flag is documented to perform both (1) pruning local tags not present on remote and (2) force-updating tags that differ between local and remote, but current implementation only does (1) and instead rejects changed tags with "would clobber existing tag". Historical analysis shows the flag was added (commit 97716d21) before tag clobbering protection (commit 0bc8d71b99, Git 2.20), suggesting an oversight rather than intentional design.

Current status: Series at v2, rebased on current master, awaiting substantive ruling from Junio C Hamano. Patch 2/2 modifies `builtin/fetch.c` at two `refspec_append` call sites -- one for the remote-configured path and one for the command-line or non-config path -- to prepend a "+" force prefix to the implied `refs/tags/*:refs/tags/*` refspec whenever `--prune-tags` (or `fetch.pruneTags`) is active, scoping force behavior strictly to the auto-following tag refspec and not to explicit refspecs passed on the command line. Documentation in `Documentation/git-fetch.adoc` and `Documentation/config/fetch.adoc` updated to quote the refspec as `+refs/tags/*:refs/tags/*`. Tests in `t/t5516-fetch-push.sh` add a case inside `test_force_fetch_tag` that creates a changed tag on the remote, confirms a plain `git fetch origin tag testTag` fails, verifies `git fetch --prune --prune-tags origin` succeeds and updates the local tag object (checked via `check_child1_tag`), and confirms that with `fetch.pruneTags=true` configured, an explicit tag fetch still fails while a prune-tags fetch succeeds. Junio C Hamano has raised concerns about historical intent and test coverage sufficiency but has not yet provided a substantive ruling; the thread remains open pending his input or clarification from Ævar Arnfjörð Bjarmason.
