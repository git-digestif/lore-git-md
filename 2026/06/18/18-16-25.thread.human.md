This thread is about a patch series (v3) by Michael Montalbo that extends `git log -L` (line-log) to support range-scoped diff stat formats (`--stat`, `--numstat`, `--shortstat`), whitespace checking (`--check`), and the `-G` pickaxe. Originally implemented by Karthik Nayak, the series aims to make these common diff options work consistently with line-range filtering, so only changes within tracked ranges are reported. The implementation reuses helpers introduced in earlier patches to avoid duplication and updates documentation to clarify limitations (e.g., `--dirstat` and `-S` are excluded due to architectural constraints).

The series has been complete since v2, with v3 only tightening commit messages. Junio C Hamano reviewed patch 5 in v1, approving its simplicity and suggesting minor documentation tweaks, which were incorporated. However, the series has since stalled due to lack of review attention. Junio now warns that unless reviewers engage soon, he will drop the topic from his `seen` branch to reduce backlog. No new technical objections have emerged, but the absence of feedback risks the effort being abandoned. Tests cover edge cases like renames, multiple ranges, and textconv fallback behavior, and the series builds on recent `mm/line-log-cleanup` work.
