The issue causes the state branch file to be read backwards, leading to errors like "Is a directory" when `--prune-empty` is used in incremental runs. The patch, now in its third version (`v3`), is a minimal two-line fix in `git-filter-branch.sh` that ensures the correct mapping format is used.
