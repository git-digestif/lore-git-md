Git has formally applied to participate in the Outreachy December 2026 cohort, with Christian Couder submitting the application on behalf of the project. The submission includes two approved project ideas for interns: improving Git’s command argument and option parsing (to reduce technical debt by porting ad-hoc code to established APIs) and reducing Git’s global state to support libification (shifting focus from the largely completed `environment.{c,h}` work to broader architectural goals). The application locks in Git’s intent to mentor and sponsor two interns, though Christian has expressed willingness to step back from one project if additional mentors volunteer.

The thread has moved from planning to execution, with the immediate focus on recruiting co-mentors and refining project details before the September 11 deadline. Christian, Usman Akinyemi, Kaartic Sivaraam, and Pablo Sabater remain confirmed as mentors or org admins, but no new volunteers have emerged since the submission. Sponsorship outreach is still limited, with Christian mentioning GitLab, GitHub, and OpenAI as potential targets and adding the topic to the agenda for the upcoming Git Contributor’s Summit 2026. No objections or technical discussions have arisen—this is purely a logistical phase.
