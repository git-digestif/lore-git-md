# Thread deltas

## 2026/08/21

- [2026/08/21/13-53-43 by K Jayatheerth <jayatheerthkulkarni2005@gmail.com>] K Jayatheerth posted a two-patch GSoC series to add Unicode box-drawing characters and bullets to `git repo structure` table output when a UTF-8 locale is detected, with ASCII fallback otherwise.
- [2026/08/21/13-53-44 by K Jayatheerth <jayatheerthkulkarni2005@gmail.com>] K Jayatheerth's first patch modifies `is_utf8_locale()` in gettext.c to fall back to the environment-derived charset (LC_ALL, LC_CTYPE, LANG) whenever the static charset is unset, rather than only under NO_GETTEXT, fixing false UTF-8 detection in uninstalled builds.
- [2026/08/21/13-53-45 by K Jayatheerth <jayatheerthkulkarni2005@gmail.com>] K Jayatheerth's second patch updates `stats_table_setup_structure()` and `stats_table_print_structure()` in builtin/repo.c to emit Unicode borders (│, ├, ─, ┼, ┤) and bullets (•) under UTF-8 locales, and adds UTF8_LOCALE tests to t/t1901-repo-structure.sh while pinning existing ASCII tests to LC_ALL=C.
- [2026/08/21/16-59-17 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano stated he is "not very enthusiastic about this change" because terminals often do not agree on how wide Unicode box-drawing characters should be rendered.

## 2026/08/23

- [2026/08/23/13-19-45 by Oswald Buddenhagen <oswald.buddenhagen@gmx.de>] Oswald Buddenhagen countered the concern that terminals often disagree on box-drawing character widths by citing mutt and midnight commander, which use box-drawing characters daily without receiving many complaints; he proposed adding an option to opt out of the Unicode output if compatibility with broken terminals/fonts is considered important, and asked whether anyone would give `git log --graph` the same treatment.
- [2026/08/23/15-01-46 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano agreed that an opt-out option is needed, explaining that his earlier objection was to the implementation only consulting locale settings, which left no way to opt out without abandoning UTF-8 altogether.
- [2026/08/23/17-06-45 by Tuomas Ahola <taahol@utu.fi>] Tuomas Ahola pointed out that mutt falls back to ACS (alternative character set) characters when not in a UTF-8 locale, a detail of uncertain relevance to git but worth considering.
