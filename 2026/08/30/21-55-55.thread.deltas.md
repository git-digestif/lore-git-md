# Thread deltas

## 2026/08/30

- [2026/08/30/21-55-55 by Nicolas Le Cam <niko.lecam@gmail.com>] Nicolas Le Cam reported a use-after-free in `git stash show --src-prefix`/`--dst-prefix` since 2.52.0: the diff header prints fragments of freed heap memory (e.g., "ributes", "Uf.txt") instead of the requested prefixes, reproducible on 2.52.0–2.54.0 but not 2.49.1, while `git diff` with the same flags remains correct.
- [2026/08/30/21-55-55 by Nicolas Le Cam <niko.lecam@gmail.com>] He traced the regression to commit 3ea35c64b, which set `.free_removed_argv_elements = 1` in `show_stash()`; because OPT_STRING_F stores pointers into argv elements rather than copying them, freeing those elements leaves `diff_options.a_prefix`/`b_prefix` dangling when the diff header is emitted.
- [2026/08/30/21-55-55 by Nicolas Le Cam <niko.lecam@gmail.com>] He warned that the same hazard applies to any diff option parsed with OPT_STRING* into a `struct diff_options` field, not only the prefix options.

## 2026/09/01

- [2026/09/01/06-36-45 by Jeff King <peff@peff.net>] Jeff King posted a follow-up cleanup, "[PATCH 2/1] revision: simplify mark_argv_for_free() callers", pushing the `free_removed_argv_elements` check into `mark_argv_for_free()` so callers no longer duplicate it.
- [2026/09/01/08-51-26 by Patrick Steinhardt <ps@pks.im>] Patrick Steinhardt reviewed the fix, noting a trivial per-option string copy could have worked but agreeing the central approach is more defensive ("I'm in line with the proposed patch"); he also questioned the `const` parameter hiding the ownership transfer to the strvec.
