# Thread deltas

## 2026/08/14

- [2026/08/14/18-55-36 by Matthew Hughes <matthewhughes934@gmail.com>] Matthew Hughes reported that bash completion for `git add` (and other commands calling `git ls-files`) hangs for seconds in large repositories (367,628 files across 58,404 directories), tracing the slowdown to `git ls-files` iterating the filesystem via `_git_add->__git_complete_index_file->__git_index_files`, with strace showing approximately 100,000 `getdents64`, 75,000 `openat`, and 50,000 `fstat` calls per directory.
- [2026/08/14/18-55-36 by Matthew Hughes <matthewhughes934@gmail.com>] He proposed a workaround adding a `GIT_COMPLETION_NO_COMPLETE_INDEX` environment variable check to `__git_complete_index_file` in `contrib/completion/git-completion.bash` to skip index completion and fall back to default Bash file completion.
