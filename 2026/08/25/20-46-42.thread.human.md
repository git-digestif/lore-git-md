This thread is about extending `git var` to provide a unified, scriptable interface for Git’s identity and signing configuration, replacing an earlier `git ident` proposal. Andrew Pleeter is the author, and the series is now at its sixth iteration (v6).

The patch adds new variables like `GIT_AUTHOR_NAME`, `GIT_SIGNING_KEY`, and others, allowing users to query individual identity components and signing keys in a machine-readable way. The latest version addresses Junio C Hamano’s concerns from v5 by switching to a `string_list`-based approach for multi-valued variables, tightening error handling with `BUG()` checks, and expanding documentation to clarify how identity variables relate to `git commit`. The `-z` output format now strictly matches `git config -z`, and argument parsing enforces strict ordering.

Junio’s review of v5 had blocked integration due to concerns about documentation clarity, output format backward-compatibility, and error handling robustness. While v6 resolves most of these, Junio may still have minor adjustments in mind before the series graduates from `seen`. Phillip Wood and Jeff King had previously provided substantive feedback, all of which has been addressed. The patch touches `builtin/var.c`, documentation, and tests, with no new configuration options or on-disk format changes. The focus now is on finalizing the output format and error handling before integration.
