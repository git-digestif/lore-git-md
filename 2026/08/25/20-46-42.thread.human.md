This thread is about extending Git’s `git var` plumbing command to provide a unified, scriptable interface for identity (author/committer names, emails, dates) and signing configuration (GPG/SSH/X.509 keys). The goal is to replace the earlier `git ident` proposal with a solution that supports both interactive use and scripting, using composable arguments and machine-readable output.

Andrew Pleeter’s latest patch (v8) resolved all prior technical feedback from Junio Hamano and Phillip Wood, addressing concerns about output format ambiguity, exit code behavior, multi-valued variable handling, and documentation clarity. However, Junio’s review of v8 requested splitting the patch into three smaller, more focused patches: one for the `-z` output mode, one for multi-variable queries, and one for the new variables (`GIT_AUTHOR_NAME`, `GIT_SIGNING_KEY`, etc.). Andrew has now agreed to this reorganization and will post a v9 series shortly. The thread remains in the `seen` branch, awaiting this structural update before moving toward integration.

The technical details are settled: the patch touches `builtin/var.c`, adds new variables with consistent behavior, supports `-z` for NUL-terminated output, and handles multi-valued variables predictably. The only remaining open question is whether `GIT_SIGNING_KEY` alone is sufficient for callers to determine the signing mechanism, but this is not a blocker. The series is technically complete and ready for `next` once the structural reorganization is addressed.
