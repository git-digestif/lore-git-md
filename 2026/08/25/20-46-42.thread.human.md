This thread is about Andrew Pleeter’s patch series extending `git var` to provide a unified, scriptable interface for Git’s identity and signing configuration. The series is now in its seventh iteration (v7) and is technically complete, addressing all prior feedback from high-weight reviews by Junio Hamano and Phillip Wood. The patch extends the existing `git var` plumbing command to support new variables like `GIT_AUTHOR_NAME`, `GIT_COMMITTER_EMAIL`, and `GIT_SIGNING_KEY`, with features such as `-z` for NUL-terminated output and multi-variable queries.

The latest review from Junio highlights two remaining issues: a discrepancy between the documentation and implementation regarding exit codes, and lingering ambiguity in the output format for multi-valued variables. The exit code behavior currently allows successful execution (exit code 0) for multi-variable queries as long as at least one variable is set, even if others are unset, which contradicts the documented design. Junio also suggests improving the output format by prefixing each line with the variable name to eliminate parsing ambiguity, though this would require script updates. These issues are narrow and non-blocking, and the series is otherwise ready for integration into Junio’s `next` branch once the documentation is corrected.

Key participants include Andrew Pleeter, who implemented the series and addressed all prior feedback; Junio, who raised the latest concerns but considers the patch close to ready; and Phillip Wood, whose earlier reviews identified critical issues now resolved. The series remains in Junio’s `seen` branch and is awaiting final confirmation before graduating to `next`. No fundamental objections remain, and the focus is now on polishing these last details.
