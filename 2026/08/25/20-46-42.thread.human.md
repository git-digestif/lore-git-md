This thread is about extending Git’s `git var` plumbing command to provide a unified, scriptable interface for identity and signing configuration, replacing an earlier `git ident` proposal. Andrew Pleeter is the author, and the series is now at version 8 after addressing all prior feedback from Junio C Hamano and Phillip Wood.

The patch is technically complete and ready for integration, with no outstanding technical objections. It adds support for querying multiple variables in a single invocation, NUL-terminated output (`-z`), and new variables like `GIT_AUTHOR_NAME` and `GIT_SIGNING_KEY`. The implementation touches `builtin/var.c`, the documentation, and tests, and it maintains backward compatibility while introducing structured output for scripting.

Junio’s latest review, however, raises a structural concern: the patch is too large and should be split into at least three smaller patches (adding `-z` mode, enabling multi-variable queries, and introducing the new variables). He also notes the commit message could be more concise. This isn’t a blocker but a request for better organization. The series remains in Junio’s `seen` branch, awaiting Andrew’s response to the proposed split or a counterargument for keeping it as a single patch. No further technical changes are needed unless the split reveals new edge cases.
