This thread began as a security feature patch adding `http.sslVerifyStatus`, a boolean option (defaulting to `false`) that enables OCSP staple validation in Git’s HTTPS certificate checks. The feature was motivated by government and government-adjacent customers who mandate OCSP stapling, as Git’s OpenSSL-linked builds currently ignore staples, leaving a gap where revoked certificates might be accepted. After thorough review and iteration, the patch was merged to `master` on June 12, 2025, but later reverted from `next` on June 18 due to test failures reported by SZEDER Gábor.

The core functionality remains intact, but Gábor identified two test infrastructure issues: the test’s expectation that a revoked certificate would be accepted without `http.sslVerifyStatus` was invalid on systems where libcurl checks CRLs by default, and the `SSL_VERIFYSTATUS` prerequisite’s error-message check was overly broad. Junio and Gábor agreed on improvements to the prerequisite—tightening the error-message check and renaming it to `CURL_SSL_VERIFYSTATUS`—but no follow-up patch has been posted yet. Patrick Steinhardt later suggested the failures might stem from an unsupported libcurl backend, a hypothesis Gábor has now confirmed: the test failures were caused by using the GnuTLS backend, which lacks full OCSP stapling support. Switching to OpenSSL resolves the issue, closing the diagnostic question without requiring changes to the feature or test infrastructure.

The thread is now effectively resolved. The feature is technically complete and merged to `master`, with all review feedback addressed. The remaining loose ends—whether the default should eventually change to `true`, the feature’s long-term maintenance burden, and the two minor code-quality nits in the test script—are post-merge considerations and do not block graduation. The only actionable item is the agreed-upon prerequisite improvement, which can be addressed in a follow-up patch if needed. For now, the focus is on ensuring the test suite passes reliably across environments.
