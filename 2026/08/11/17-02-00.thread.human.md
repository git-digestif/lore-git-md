This thread is about a security feature patch that adds OCSP staple validation to Git’s HTTPS certificate verification. The patch introduces `http.sslVerifyStatus`, a boolean configuration option (defaulting to `false`) that, when enabled, causes Git to refuse connections to servers that don’t provide a valid OCSP staple. This closes a security gap where revoked certificates could be accepted, particularly affecting government and FIPS-compliant users (e.g., US Department of Defense PKI) who mandate OCSP stapling.
