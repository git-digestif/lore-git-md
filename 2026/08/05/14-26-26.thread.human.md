This thread is about a 13-patch series from Johannes Schindelin (Dscho) that upstreamed Git for Windows-specific build and runtime adjustments into the main Git codebase. The series has already been merged to Junio’s `next` branch after three prior iterations, with v4 being a final polish pass. The core goal was to improve Windows compatibility—addressing hard-coded assumptions, MSYS2 integration, linker behavior, deprecated build artifacts, a locale-handling regression, and direct `git.exe` invocation—without affecting non-Windows platforms. These changes were urgently needed for Git for Windows’ migration from MINGW64 to UCRT64.

The first 12 patches delivered the substantive work: removing obsolete compiler flags, dynamically setting build paths based on MSYS2 environment variables, fixing a locale-handling regression (GitHub issue #1036), enabling direct `git.exe` invocation (GitHub issue #2283), and beginning the phased deprecation of dashed-form executables. Junio and Johannes Sixt reviewed the series thoroughly, with Sixt validating stability in personal builds and CI. The final patch, v4’s 13/13, is a trivial style fix to a test script—restoring a misplaced quote—with no functional impact. The series is now complete, and the only loose end is Junio’s non-blocking suggestion to add a build-system guard for an edge case in Patch 12, which Dscho declined to address.
