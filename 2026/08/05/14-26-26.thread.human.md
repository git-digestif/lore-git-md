This thread is about a 12-patch series from Johannes Schindelin (Dscho) that upstream Git for Windows-specific build and runtime adjustments into the main Git codebase. The series addresses hard-coded assumptions, MSYS2 integration, linking behavior, deprecated build artifacts, a locale-handling regression in the MSYS2 runtime, and direct `git.exe` invocation—all aimed at improving Windows compatibility without affecting other platforms.

The series is now at v2, with most patches uncontroversial and ready for integration. Patches 10 (simplifying path logic for `ETC_GITCONFIG`/`ETC_GITATTRIBUTES`) and 11 (fixing a locale-handling regression) have no open feedback, while Patch 12 (direct `git.exe` invocation) still has an unresolved discussion about guarding against an empty `MSYSTEM` export. Johannes Sixt has been running a subset of these patches in personal builds since November 2025 without issues, and the full series passes GitHub CI on Windows.
