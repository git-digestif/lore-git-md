This thread is about Kristoffer Haugsbakk’s `[PATCH v3 0/2]` series adding `--[no-]range-diff-notes` options to `git format-patch`. The goal is to let users control Git notes inclusion in the range-diff section independently of the patch output—suppressing notes in the range-diff while keeping them in the patches, or using different notes refs for each.

The series is now technically complete at v3. The first patch refactors `get_notes_args` to simplify the code, while the second implements the new options: `--range-diff-notes=<ref>` (requiring an explicit ref) and `--no-range-diff-notes` (suppressing range-diff notes without fallback). The design adopts Junio C Hamano’s suggested rule from v1 feedback, eliminating the problematic toggle mechanism and arg-less variant. Tests cover edge cases like single-patch scenarios and ensure the options behave predictably. Junio reviewed v2 and found only a minor test redundancy, which was fixed in v3.

The feature is ready for maintainer approval, with no remaining technical concerns. The only open question is whether Junio will accept it—no decision has been made yet. Kristoffer’s v3 redesign addresses all prior usability issues, and the implementation is uncontroversial. D. Ben Knoble provided early feedback on v1 but hasn’t reviewed v2 or v3. The series is self-contained and doesn’t conflict with other in-flight work.
