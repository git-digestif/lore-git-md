# Thread deltas

## 2026/08/28

- [2026/08/28/20-35-48 by Diogo Castro via GitGitGadget <gitgitgadget@gmail.com>] Diogo Castro submitted a patch to fix negative pathspecs in `git ls-files` and `git add`, proposing to strip the common prefix only from positive pathspecs in `do_match_pathspec()` and adding regression tests.
- [2026/08/28/21-37-06 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano questioned the proposed fix, asking whether a command like `git ls-files -- a/b/c a/b/d !a/b/` should instead strip `a/b/` from all three pathspecs, and wondered if the common prefix should be computed across both positive and negative pathspecs.

## 2026/08/30

- [2026/08/30/14-57-27 by Diogo Castro <dc@diogocastro.com>] Diogo Castro objected to extending common-prefix stripping to negative pathspecs, explaining that the optimization avoids unnecessary working-directory walks; applying it to a negative pathspec such as `':!*.md'` could force a full walk even when `a/b/` would suffice.
- [2026/08/30/22-58-18 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano cited `git add -- a/b/c a/b/d ':!a/b/x'` and agreed that computing the common prefix from only positive pathspecs and then stripping it from both positive and negative pathspecs is incorrect and needs correction.

## 2026/08/31

- [2026/08/31/14-30-22 by Diogo Castro <diogo.filipe.acastro@gmail.com>] Diogo Castro clarified that the common-prefix calculation affects only traversal performance, not which files `git ls-files` or `git add` report, and argued that including negative pathspecs in that calculation would not improve performance and could force walking more directories, using `git add -- a/b/c a/b/d ':!a/**/x'` as the example.
- [2026/08/31/18-26-39 by Junio C Hamano <gitster@pobox.com>] Junio C Hamano agreed with ignoring negative pathspecs when determining the common prefix, stripping it only from positive pathspecs, and matching full paths against negative pathspecs; he judged the posted patch good and noted that optimizing the case with many more negative than positive patterns would be a separate topic.

## 2026/10/02

- [2026/10/02/21-52-53 by Diogo Castro <dc@diogocastro.com>] Diogo Castro reports that the negative pathspec fix has been incorporated into the referenced lore.kernel.org thread and states he is closing the PR on git/git.
